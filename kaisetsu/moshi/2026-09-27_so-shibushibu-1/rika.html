【素材文】部品は下線部aの前後、リカ子の「素揚げにするとナスの皮の色もそのままになって、色を守ることができる」に丸 → 色素が皮から出なくなった、と直して書く。選択肢は「出やすくなる／出なくなる」で切る。

📚 前提知識

  • ナスの皮の紫色は水に溶けやすい色素。油は水と混ざらないので、油の膜で皮をおおうと汁にふれにくくなる。

🔍 こう読み解く

  1. 揚げていないナスではみそ汁が黒くなった → 色素が汁に溶け出した。揚げると色が保たれる → 油のはたらきで色素が外に出にくくなった（SAPIXの解説と同じ流れ）。
  2. ア「より汁に溶け出しやすくなる」は逆。イ「油に溶け出してナスに残っていない」なら皮の色は残らない。ウ「固体になって沈む」は会話文に根拠がない。
  3. エ「油が表面を覆うため汁にふれにくくなる」だけが「出にくくなる」の説明になっている。
答え：エ
今回：エ ○

2 問2 コンニャクの凝固剤に使える物質（2つ） 2点｜会話文＋水溶液の性質

👀 まず見るところ

【素材文】部品は下線部bそのもの「水に溶けるとアルカリ性になる凝固剤」に丸 → 設問は「アルカリ性の水溶液になる物質はどれか」に直して読む。6つの物質を「酸性／中性／アルカリ性／溶けない」で仕分けする。

📚 前提知識

  • アルカリ性になるもの：炭酸ナトリウム（重そうの仲間）、水酸化カルシウム（消石灰。水に溶かすと石灰水）。
  • 酸性になるもの：ホウ酸、ミョウバン。酸化鉄（さび）は水にほとんど溶けない。硫酸カルシウム（せっこう）は溶けても中性。

🔍 こう読み解く

  1. 「アルカリ性」の合図で、名前に「水酸化」が入るエ 水酸化カルシウムをまず取る。
  2. もう1つは「炭酸〜ナトリウム」のア 炭酸ナトリウム。重そう（炭酸水素ナトリウム）を熱してできる物質で、水溶液は重そうより強いアルカリ性。
  3. ウ ミョウバン・オ ホウ酸は酸性、イ 酸化鉄は溶けない、カ 硫酸カルシウムは中性なので外れる。2つそろって1問なので、片方だけ合っていても点にならない。
答え：ア・エ
今回：ウ・エ と書いていた ×。決め手は「水に溶けるとアルカリ性」。ミョウバンは酸性の水溶液になる物質なので、アルカリ性の仲間には入らない。

2 問3 pH13.5 を pH11 にする薄め方 2点｜条件文の計算

👀 まず見るところ

【まざり型→条件文】部品は会話文の決まり「10倍に薄めるたびに pH は1変わる」と設問の「凝固剤10 mLに水を□mL加える」。水の量ではなく「全体が何倍か」に直して書く（10＋990＝1000 mL＝100倍）。

📚 前提知識

  • アルカリ性を薄めると pH は下がり、7に近づく。10倍で1、100倍で2、1000倍で3下がる。

🔍 こう読み解く

  1. 各選択肢を「全体÷10 mL」で倍率に直す。ア 110 mL＝11倍、イ 310 mL＝31倍、ウ 1000 mL＝100倍、エ 3000 mL＝300倍。
  2. 100倍 → 13.5−2＝pH11.5。1000倍 → 13.5−3＝pH10.5。pH11 はその間なので、100倍より多く1000倍より少なく薄める（SAPIXの解説：水は990 mLより多く9990 mLより少なく）。
  3. この範囲に入るのはエの300倍だけ。
答え：エ
今回：ウ と書いていた ×。ウは100倍で pH11.5 にしかならない。決め手は「100倍で2下がる」と数えてから、11 がその先にあると気づくこと。

2 問4(1)①② 水素イオンの個数から pH を求める 2点×2｜条件文の計算

👀 まず見るところ

【条件文】部品は問4の文「水溶液1L中に水素イオンが1モル個含まれる水溶液の pH を0とする」と、②の「2Lの水溶液に0.02モル個」。②は 1Lあたりに直して書く（0.02÷2＝0.01）→ あとは pH0 から10倍ずつ数える。

📚 前提知識

  • 会話文の決まり：酸性の水溶液を10倍に薄めると pH は1増える。1Lあたりの水素イオンが 1→0.1→0.01 モル個と10分の1になるたびに pH は 0→1→2。

🔍 こう読み解く

  1. ①：1Lに0.1モル個 ＝ pH0 の水溶液（1Lに1モル個）を10倍に薄めたもの → pH1。
  2. ②：2Lに0.02モル個 → 1Lあたり 0.02÷2＝0.01モル個。
  3. 0.01 は 1 の100分の1 ＝ 100倍に薄めたもの → pH2。
答え：① 1　② 2
今回：① pH1 ○　② pH2 ○。②で「1Lあたり」に直してから数えられている。

2 問4(2)A・B 1L中の水素イオンの個数を A×10B で表す 2点×2｜条件文の計算

👀 まず見るところ

【条件文】部品は「0.4Lの水溶液に0.018モル個」「1L用意すると」と、答え方の指示「A・Bともに二桁の整数」。まず 1Lあたりのモル個に直して書く（0.018÷0.4）。次に例の 60×1022 をかける。

📚 前提知識

  • 1モル個＝6のうしろに0が23個＝60×1022。かけ算しやすいように 600×1021 と書き直してよい（0を1つ前に出すと 10 の肩の数が1減る）。

🔍 こう読み解く

  1. 1Lあたりの水素イオン：0.018÷0.4＝0.045モル個。
  2. 個数に直す：0.045×600×1021＝27×1021（SAPIXの解説と同じ式）。
  3. Aは 27（二桁）、Bは 21（二桁）で条件に合う。2.7×1022 と書くと A が二桁にならないので、その形にはしない。
答え：A…27　B…21
今回：A 35・B 18 と書いていた ×。決め手は「0.4Lに0.018モル個」を1Lあたり 0.045 に直すことと、1モル個を 600×1021 の形で置いてから 0.045 をかけること。

2 問5 塩酸30 mL＋水酸化ナトリウム水溶液20 mL の pH 2点｜中和の計算

👀 まず見るところ

【まざり型→条件文】部品は「1Lに1モル個の塩化水素…から30 mL」「1Lに1.25モル個の水酸化ナトリウム…20 mL」「混ぜ合わせた水溶液50 mL」。それぞれ「何モル個入っているか」に直して書く（1L＝1000 mL）。1モル個どうしが打ち消し合うので、多いほうの余りが液性を決める。

📚 前提知識

  • 塩化水素1モル個 → 水素イオン1モル個。水酸化ナトリウム1モル個 → 水酸化物イオン1モル個。同じ個数で過不足なく中和（問5の文のとおり）。
  • pH は「1Lあたり」の水素イオンの個数で決まる（問4のルール）。余りを混ぜた後の体積で割る。

🔍 こう読み解く

  1. 塩化水素：1×30÷1000＝0.03モル個。
  2. 水酸化ナトリウム：1.25×20÷1000＝0.025モル個。
  3. 0.025モル個ずつ打ち消し合い、塩化水素が 0.03−0.025＝0.005モル個余る → 水素イオン0.005モル個が残る。
  4. 混ぜた後は 50 mL＝0.05L。1Lあたりに直すと 0.005÷0.05＝0.1モル個。
  5. 1Lに0.1モル個 ＝ pH0 を10倍に薄めたもの → pH1（問4(1)①と同じ状態）。
答え：1
今回：空欄だった ×。決め手は「30 mL・20 mL をモル個に直す → 引き算 → 余りを 0.05L で割る」の3行。数字は問4(1)①と同じ 0.1 に戻ってくる。

2 問6(2) 図2の ● がアルカリ性になる理由（X〜Z） 2点｜説明文の穴うめ

👀 まず見るところ

【素材文】設問は「アルカリ性になる理由」。部品は説明文の最後「この反応によって液中には（Z）の方が多くなります」に丸 → アルカリ性＝水酸化物イオンが多い、だから Z＝水酸化物イオン。ここだけで ア か ウ にしぼれる。

📚 前提知識

  • 中和でできる物質は「酸の名前＋ナトリウム」。酢酸＋水酸化ナトリウム → 酢酸ナトリウムと水。「塩化〜」ができるのは塩化水素（塩酸）を使ったときだけ。
  • 酢酸ナトリウムは水の中でこわれて元の酢酸に戻ろうとする（問6(2)の文に書いてある。知らなくてよい）。

🔍 こう読み解く

  1. Z：文末「Zの方が多くなる」＝アルカリ性の原因 → 水酸化物イオン。ア・ウが残る。
  2. X：酢酸と水酸化ナトリウムの中和なので酢酸ナトリウム。塩素の入った物質がどこにもないので「塩化酢酸」はできない（SAPIXの解説と同じ）。
  3. Y：酢酸ナトリウムが「元の物質（酢酸）に戻る」には、酢酸イオンに水素イオンがくっつく必要がある → 水から水素イオンをうばう＝Y＝水素イオン。うばわれた水の残りが水酸化物イオン → Z と話がつながる。
答え：ウ
今回：エ と書いていた ×（X は酢酸ナトリウムで合っていた）。決め手は文末の「Zの方が多くなる」を「アルカリ性＝水酸化物イオンが多い」と読むこと。Y と Z は、Z を先に決めると自動的に決まる。
