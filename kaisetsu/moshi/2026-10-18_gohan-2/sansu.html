1 (1) 小数と分数のまざった計算 A・5点｜計算（分数に直す）

👀 まず見るところ

【条件文】部品は「0.375」「0.875」→ 3/8・7/8 に直して書く。かっこの中は小数のままたして 2.65。残る 5.7÷15.9 と 0.375÷2.65 は、10倍・100倍して整数の分数にしてから約分する。

📚 前提知識

  • よく出る小数と分数の対応。0.125＝1/8、0.375＝3/8、0.625＝5/8、0.875＝7/8。
  • 小数どうしのわり算は、両方を同じ倍にして整数にしてから分数にする。5.7÷15.9 は 57/159。

🔍 整理して解く

  1. かっこの中から。0.875÷5/12 ＝ 7/8×12/5 ＝ 21/10 ＝ 2.1。
    0.25＋2.1＋0.3 ＝ 2.65。
  2. 前の部分。5.7÷15.9 ＝ 57/159。57 も 159 も 3 でわれる → 19/53。
  3. 後ろの部分。0.375÷2.65 ＝ 375/2650。25 でわる → 15/106。
  4. たす。106 は 53×2 だから、19/53 ＝ 38/106。38/106＋15/106 ＝ 53/106 ＝ 1/2。
  5. 落としやすい所: 57/159 を約分しないまま進むと、分母がふくらんで最後の 1/2 が見えにくい。分母に 53 が2回出たら、まとまる合図。

1 (2) □をふくむ式の逆算 A・5点｜逆算

👀 まず見るところ

【条件文】部品は □ の入っていないかたまり「13/98÷1 17/35×84」→ 先に計算して1つの数（7.5）に直して書く。残った「（13−□÷6/7）÷2.5」は、10.18−7.5 から後ろ向きにもどす。

📚 前提知識

  • 逆算は計算の順番を逆にもどす。○÷2.5＝2.68 なら ○＝2.68×2.5。わり算の逆はかけ算。
  • 13−△＝6.7 なら △＝13−6.7。ひかれる数から答えをひく。

🔍 整理して解く

  1. □のないかたまりを先に。1 17/35 ＝ 52/35。13/98÷52/35×84 ＝ 13/98×35/52×84。
    13 と 52 → 1 と 4。35 と 98 → 5 と 14。84 と 14 → 6 と 1。残りは 5×6÷4 ＝ 7.5。
  2. 10.18−7.5 ＝ 2.68。これが「（13−□÷6/7）÷2.5」の値。
  3. 2.68×2.5 ＝ 6.7。これが「13−□÷6/7」。
  4. 13−6.7 ＝ 6.3。これが「□÷6/7」。
  5. □ ＝ 6.3×6/7 ＝ 5.4。
  6. 確かめ。5.4÷6/7＝6.3、13−6.3＝6.7、6.7÷2.5＝2.68、7.5＋2.68＝10.18。合っている。
  7. 落としやすい所: 最後の「□÷6/7＝6.3」で 6.3÷6/7 とわってしまう。□ はわられる数だから、6.3 に 6/7 をかける。
答え：5.4

2 (2) 旅館の部屋割り A・6点｜過不足算

👀 まず見るところ

【条件文】部品は「10人が泊まることができません」と「部屋が3つ余り」。10人＝あふれる＋10、部屋3つ余り＝8×3＝24人分の空き＝−24 に直して書く → 全体の差 34人を、1部屋あたりの差 8−6＝2人でわる。

📚 前提知識

  • 過不足算は「1部屋の人数を変えると、全体で何人分変わるか」を見る。1部屋2人ずつ増やせば、部屋の数×2人だけ多く泊められる。
  • 「部屋が3つ余り、残りはすべて8人ずつ」は、8人ずつなら 3×8＝24人分の空きがあるということ。

🔍 整理して解く

  1. 部屋の数を□として、2通りの泊め方を表にする。
    泊め方部屋を全部使うと実際の人数とのちがい
    6人ずつ6×□人10人あふれる → 人数＝6×□＋10
    8人ずつ8×□人24人分空く → 人数＝8×□−24
  2. 8人ずつは 6人ずつより、10＋24＝34人多く泊められる。
  3. 1部屋あたり増えるのは 8−6＝2人。部屋の数は 34÷2＝17部屋。
  4. 生徒の数は 6×17＋10＝112人。確かめ: 8×(17−3)＝112。合っている。
  5. 落としやすい所: 「部屋が3つ余る」を 3人の差と読む。部屋の数は 8人分ずつに直してから差に入れる。

2 (3) 食塩水と水を混ぜて同じ濃度にする A・6点｜食塩水（食塩の重さは変わらない）

👀 まず見るところ

【条件文】部品は「330gと…330g」（同じ重さ）と「水□g」。同じ重さを混ぜる → 濃度は 11 と 1 の真ん中 6% と直して書く。水は 0% の食塩水と考える。食塩 36.3g は増えないから、6% の食塩水全体の重さが出る。

📚 前提知識

  • 同じ重さの食塩水を混ぜると、濃度は2つの平均。11% と 1% なら (11＋1)÷2＝6%。
  • 水を加えても食塩の重さは変わらない。食塩の重さ÷濃度＝食塩水全体の重さ。

🔍 整理して解く

  1. 前半の混ぜ合わせ。同じ重さだから (11＋1)÷2＝6%。
  2. 後半。11% の食塩水 330g に入っている食塩は 330×0.11＝36.3g。
  3. 水を加えて 6% になった。食塩水全体は 36.3÷0.06＝605g。
  4. 加えた水は 605−330＝275g。
  5. 確かめ（てんびん）。0% と 11% で 6% を作る。うでの長さは 6：5 → 重さは逆の 5：6 → 水は 330×5/6＝275g。合っている。
  6. 落としやすい所: 前半の 660g を後半に持ちこまない。後半に使うのは 330g と水だけで、前半からもらうのは「6%」という数だけ。
答え：275

2 (4) ジュースの空きびん交換 B・6点｜空きびんの交換

👀 まず見るところ

【条件文】部品は「5本持っていくと…1本と交換」と「全部で333本」。333本＝買った本数＋もらった本数 に直して書く → もらった本数が出れば 333 からひくだけ。表で「はじめ5本で1本、あとは4本ごとに1本」が見えたら手を付ける。

📚 前提知識

  • もらった1本も、飲めば空きびんになる。だから2回目からは4本買えば（もらった分の空きびん1本＋4本＝5本で）また1本もらえる。
  • 「飲む本数」＝「買った本数」＋「もらった本数」。問題の 333本は飲む本数。

🔍 整理して解く

  1. 流れを表にする。
    買う空きびんもらう飲んだ合計
    はじめ 5本5本1本（1回目）5＋1＝6本
    次に 4本もらった1本＋4本＝5本1本（2回目）6＋4＋1＝11本
    次に 4本1本＋4本＝5本1本（3回目）11＋4＋1＝16本
    はじめの5本のあとは、5本飲むごとに1本もらえる。
  2. 333本からはじめの5本をのぞく。(333−5)÷5＝65 あまり 3。2回目以降に 65回もらえる。
  3. はじめの1回とあわせて 1＋65＝66本もらった。
  4. 買う本数は 333−66＝267本。
  5. 確かめ。267本買う → はじめ5本で1本、残り 262÷4＝65 あまり 2 → 1＋65＝66本もらえる → 267＋66＝333本。266本だと 261÷4＝65 あまり 1 で、もらえるのは同じ 66本。飲めるのは 332本で足りない。
答え：267
別の見方: 飲んだ 333本は全部空きびんになる。5本ずつ交換に使うと 333÷5＝66 あまり 3 で、もらえるのは最大 66本。333−66＝267 と同じになる。

  3. AB＝240−192＝48。
  4. (3)で使う長さも、ここで出しておく。AF＝120−48＝72。Pは 5×16＝80 進んだので FE＝80−72＝8。DC＝AB−FE＝48−8＝40。
  5. 落としやすい所: 「16秒で出会った」を「ABの長さが192」と読まない。2点が出会ったのはEで、ABは通っていない。
答え：48(cm)

7 (2) PとRが2度目に重なるのが30秒後 → Rの速さ B・6点｜点の移動（2度目の出会い＝和＋1周）

👀 まず見るところ

【条件文】部品は「PとRが2度目に重なったのは…30秒後」と、Rは「F→A」の向き。PとRはAFの上で向かい合う → 1度目の和はAF＝72、2度目はさらに1周240 と直して書く。(1)でAFが出ていれば式は1本。

📚 前提知識

  • 向かい合って進む2点は、1度目に出会うまでの道のりの和＝はじめの間の道のり。そのあと2度目に出会うまでに、2点の道のりの和はちょうど1周分ふえる。
  • 速さの和＝道のりの和÷時間。Rの速さ＝速さの和−Pの速さ。

🔍 整理して解く

  1. PとRの向きを図に書く。
  2. 2度目に重なるまでの道のりの和は 72＋240＝312cm。
  3. 速さの和は 312÷30＝10.4。Rの速さは 10.4−5＝5.4。
  4. たしかめ。30秒でPは 5×30＝150、Rは 5.4×30＝162。和は312で合う。
答え：(毎秒)5.4(cm)

7 (3) QとRがはじめて重なった場所がD → 六角形の面積 C・6点｜点の移動（追いつき＝道のりの差）

👀 まず見るところ

【条件文】本番では後回し。部品は「QとRがはじめて重なった場所はD」と、QもRも同じ向き（B→C→D→…、F→A→B→…）。同じ向きなら追いつき＝道のりの差 → 追いつく時間を出し、Qが進んだ道のりからBC＋CDが決まる。

📚 前提知識

  • 同じ向きに進む2点が重なるまでの時間＝はじめの間の道のり÷速さの差。はじめにQはB、RはFにいて、Qの進む向きでBからFまでは BC＋CD＋DE＋EF。AB＋AF＝120 だから、この残り半分も 240−120＝120。

🔍 整理して解く

  1. QがRに追いつく時間は 120÷（7−5.4）＝120÷1.6＝75秒。
  2. Qは75秒で 7×75＝525cm 進む。525＝240×2＋45 だから、2周してさらに45cm。Bから45cm進んだ所がD → BC＋CD＝45。CD＝40 だから BC＝45−40＝5。
  3. DE＝AF−BC＝72−5＝67。
  4. 面積は、大きい長方形から右下の長方形を引く。48×72−40×67＝3456−2680＝776。
答え：776(cm²)
コツ：この図は長さの割合どおりではない（BCはとても短い）。問題の図の見た目で長さを決めず、出した数を書きこんで考える。
