1 (1) 123＋234＋345＋456＋567 A・5点｜計算のくふう（等差数列の和）

👀 まず見るところ

【条件文】部品は「123」「234」…の数の並び。となりとの差を出して書く → どれも111ずつふえている。だからまん中の345が平均になり、345×5 で出せる。

📚 前提知識

  • 同じ数ずつふえる数を並べると、まん中の数が平均になる。たとえば 2＋4＋6 は、まん中の4が平均。だから 4×3＝12。

🔍 整理して解く

  1. 差を書く。234−123＝111、345−234＝111。どれも111ずつふえている。
  2. 5つの数のまん中は345。平均が345なので、合計は 345×5＝1725。
  3. たしかめ。はしの2つをたすと 123＋567＝690。これは345の2倍と同じ。
  4. 落としやすい所。そのまま筆算でたすと、くり上がりのまちがいが起きやすい。
答え：1725

1 (2) 15×14＋13×12−14×13−12×11 A・5点｜計算のくふう（分配法則）

👀 まず見るところ

【条件文】部品は2回ずつ出てくる「14」と「12」。式を「15×14−14×13」と「13×12−12×11」に並べかえて書く → 14×(15−13) と 12×(13−11) にまとめられる。

🔍 整理して解く

  2. 前の組は 14×(15−13)＝14×2＝28。
  3. うしろの組は 12×(13−11)＝12×2＝24。
  4. 合わせて 28＋24＝52。
  5. 落としやすい所。並べかえるときは「−14×13」の−も一緒に動かす。

1 (5) A/14 と 252/A がどちらも整数 A・5点（完答）｜約数と倍数

👀 まず見るところ

【条件文】部品は「A/14」と「252/A」。A/14が整数＝Aは14の倍数、252/Aが整数＝Aは252の約数、と直して書く → 252＝14×18 なので、A＝14×(18の約数) と決まる。

📚 前提知識

  • 「□/14 が整数」は「□が14でわり切れる」と同じ。28/14＝2 なら整数、30/14 は整数ではない。

🔍 整理して解く

  5. 落としやすい所。完答なので6つ全部が必要。A＝14（○＝1）と A＝252（○＝18）のはしの2つを忘れやすい。

1 (6) 製品A・B・Cを袋につめる（余りが同じ） B・5点（完答）｜余りと公約数

👀 まず見るところ

【条件文】部品は「ちょうど同じ数だけ余り」と「余りが出ません」。余りが同じ＝差の450−331＝119は袋の数でわり切れる、と直して書く → 袋の数は119と238の公約数で、2枚以上。

📚 前提知識

  • 同じ数でわった余りが同じなら、2つの数の差はその数でわり切れる。たとえば 17と10を7でわると、どちらも余り3。差の7は、7でわり切れる。
  • 「余りが出ない」は「わり切れる」と同じ。

🔍 整理して解く

  1. 袋の数を□枚とする。AとBは同じ数だけ余るので、差の 450−331＝119 は□でわり切れる。
  2. Cは余りが出ないので、238は□でわり切れる。

  4. 袋は2枚以上なので、1を消す。残りは 7, 17, 119。

1 (7) 円柱の容器を45°傾けてもどす A・5点｜水の体積（傾ける）

👀 まず見るところ

【条件文】部品は「45°」と「半径2cm」。45°なら、直径4cmの横はばで水面は4cm下がる、と図に置く → こぼれたあとの水面は、ふちの12cmから反対側の8cmまでのななめの面。

📚 前提知識

  • 45°にかたむいた線は、横に1進むと縦に1下がる。直角二等辺三角形と同じ形になる。
  • 円柱を水面でななめに切った立体の体積は、底面積×(高いほうの高さ＋低いほうの高さ)÷2。高さの平均を使えばよい。

🔍 整理して解く

  1. 傾けると水はふちからこぼれる。水面は、こぼれるふちの所が高さ12cm。容器にそって見た図を描く。
  2. 45°なので、直径4cmの横はばで水面は4cm下がる。反対側の水面は 12−4＝8cm。8cmは底より上なので、底は出ない。
  3. 残った水は、高さ12cmと8cmのななめの立体。もどすと高さは平均の (12＋8)÷2＝10cm になる。
  4. 体積は 2×2×3.14×10＝40×3.14＝125.6cm³。
  5. 落としやすい所。はじめの11cmは使わない。残る量は、傾けた角度と容器の高さだけで決まる。
答え：125.6cm³

    船P船Q差
    静水での速さ時速6km時速10km4km
    上りの速さ（比）③⑦④
  3. ④が4kmなので、①は1km。Pの上りの速さは③＝時速3km。
  4. 流れの速さは 6−3＝時速3km。

  • 広尾さんの1往復は 4800÷60＝80分。

🔍 整理して解く

  1. 80分後に2人ともA地点にいる。ここは和も差も、ちょうど4800mの倍数になる所。
  2. すれ違いが6回あって、その次の「7回め」がA地点での到着。だから和は 4800×7＝33600m。
  3. 小石川さんの道のりは 33600−4800＝28800m。たしかめ。差は 28800−4800＝24000＝4800×5。追い越し4回と、5回めがA地点での到着。合っている。
  4. 速さは 28800÷80＝分速360m。小石川さんは80分で6往復している。
  5. 落としやすい所は、すれ違い6回をそのまま和4800×6にすること。最後にA地点でいっしょになる所が、もう1回分ある。
答え：分速360m
コツ：往復の問題は、ダイヤグラムを描くと回数を数えられる。黒線と青線が「ちがう向き」で交わる所がすれ違い、「同じ向き」で交わる所が追い越し。

4 (2) 初めてすれ違う地点とAの距離 B・5点｜往復の旅人算（出会い）

👀 まず見るところ

【条件文】部品は「初めてすれ違う」と「A地点との距離」。初めてのすれ違いは、和が1往復分の4800mになったとき → 4800÷（60＋360）で時間を出し、広尾さんの道のりを答える。

📚 前提知識

  • 2人の道のりの和は、1分に 60＋360＝420m ずつふえる。
  • 広尾さんはまだB地点に着いていないので、広尾さんの道のりが、そのままA地点からの距離になる。

🔍 整理して解く

  1. ダイヤグラムを描く。はじめのすれ違いは、小石川さんがB地点で折り返したあと。
  2. 時間は 4800÷420＝80/7分（11 3/7分）。
  3. 広尾さんの道のりは 60×80/7＝4800/7＝685 5/7m。
  4. たしかめ。小石川さんは 360×80/7＝28800/7m。2400×2−28800/7＝4800/7。B地点で折り返してもどってきて、同じ所にいる。
  5. 落としやすい所は、2400m（片道）を和にしてしまうこと。小石川さんはBで折り返すので、和は1往復分の4800m。
答え：685 5/7m

4 (3) 最後の追い越しはB地点で折り返してから何分後 B・5点｜往復の旅人算（追い越し）

👀 まず見るところ

【条件文】部品は「最後に」と「B地点で折り返してから」。追い越しは4回で、最後は4回め → 差が4800×4になる時間を出し、広尾さんがB地点に着く40分をひく。

📚 前提知識

  • 2人の道のりの差は、1分に 360−60＝300m ずつふえる。差が4800mで1回め、9600mで2回めの追い越し。
  • 広尾さんがB地点で折り返すのは 2400÷60＝40分後。

🔍 整理して解く

  1. 追い越しの時間を順に出す。差÷300。
    追い越し1回め2回め3回め4回め
    差4800m9600m14400m19200m
    時間16分32分48分64分
    差が24000mになる80分は、A地点での同時の到着。追い越しには数えない。
  2. 最後の追い越しは64分後。(2) のダイヤグラムで、もどり道の黒線と青線が同じ向きで交わる所。
  3. B地点で折り返すのは40分後。64−40＝24分後。
  4. たしかめ。64分後の広尾さんは 60×64＝3840m 進んだ所。Bから 3840−2400＝1440m もどり、Aから960m。小石川さんは 360×64＝23040m 進む。4800m（1往復）の4倍をひくと3840m。広尾さんと同じく、Aから960mの所をAに向かって進んでいる。
  5. 落としやすい所は、64分を答えること。聞かれているのは「B地点で折り返してから」。
答え：24分後

2〜4 まとめ

  • 流水算で同じ道のりを上るときは、時間の比を逆にして速さの比にする。比の差と静水の速さの差を合わせる。
  • 「2でわり続ける」は0からもどすと「2倍」か「2倍＋1」。回数ごとに一番小さい数と一番大きい数を表にする。
  • 往復のすれ違いは和が、追い越しは差が、1往復分（4800m）ふえるたびに1回。同時に着く所も1回分に数える。

5 (1) 三角形BMNの面積 A・4点｜正方形の中の三角形（まわりをひく）

👀 まず見るところ

【条件文】部品は「真ん中の点」が2つと「三角形DMNの面積が8cm²」。辺に「4」「4」と長さを書きこむ（図に置く）→ 正方形の面積が出て、まわりの3つの三角形をひけば三角形BMNが決まる。

📚 前提知識

  • 三角形DMNは、DMもDNも正方形の一辺の半分。だから面積は正方形の 1/2×1/2×1/2＝1/8。8cm²なら正方形は64cm²。
  • ななめの三角形は、正方形からまわりの直角三角形をひくと出る。

🔍 整理して解く

  1. 正方形は 8×8＝64cm²。一辺は8cm。MとNで半分に切れるので、AM・MD・DN・NCは4cm。図に書きこむ。
  2. まわりの3つを出す。三角形ABMは 8×4÷2＝16。三角形BCNも 8×4÷2＝16。三角形DMNは8。
  3. 64−16−16−8＝24cm²。
  4. 落としやすい所: 三角形ABMの底辺をAMの4にする。高さはABの8。8×8÷2 にしない。
答え：24cm²

5 (2) BG：GM A・5点｜平行線と砂時計（相似）

👀 まず見るところ

【条件文】部品は「直線MNと直線BCの交わる点をE」。BCをのばした線にCEの長さを書きこむ（図に置く）→ AMとBEが平行な砂時計になり、BG：GM＝BE：AM で決まる。

📚 前提知識

  • 平行な2本の線を、交わる2本の線で結ぶと、砂時計の形ができる。上と下の三角形は同じ形。たとえば上の辺が4、下の辺が12なら、ほかの辺も 1：3 の比になる。
  • Nは真ん中の点。三角形NDMと三角形NCEは、DN＝CN・向かい合う角が同じ・どちらも直角。だから同じ形で同じ大きさ。

🔍 整理して解く

  1. CEを出す。三角形NCEは三角形NDMと同じ大きさ。だから CE＝DM＝4cm。BE＝8＋4＝12cm。
  2. Gのまわりの砂時計を見る。上の辺はAM＝4cm。下の辺はBE＝12cm。AMとBEは平行。
  3. 上の三角形AGMと、下の三角形EGBは同じ形。BG：GM＝BE：AM＝12：4。
  4. かんたんにして 3：1。
  5. 落としやすい所: Eが正方形の外にあることを見のがして、BEを8にする。CEの4をたす。
答え：3：1

5 (3) 三角形BFGの面積 B・6点｜砂時計で辺の比→面積を2回わける

👀 まず見るところ

【条件文】部品は(1)の「三角形BMN」の24と、(2)の BG：GM。足りないのは BF：FN。BNをのばして、ADをのばした線と交わる点Qを図に置く → AQとBEの砂時計で BF：FN が決まる。

📚 前提知識

  • 頂点が同じで、底辺が同じ直線の上にある2つの三角形は、高さが同じ。面積の比は底辺の比と同じ。
  • 三角形BMNの中の三角形BFGは、「BM上で何分のいくつ」「BN上で何分のいくつ」を2回かけて出せる。

🔍 整理して解く

  1. BNをのばし、ADをのばした線と交わる点をQとする。三角形NCBと三角形NDQは、(2)と同じ理由で同じ大きさ。だから DQ＝BC＝8cm、AQ＝16cm。BN＝NQ にもなる。
  2. Fのまわりの砂時計を見る。上の辺はAQ＝16cm。下の辺はBE＝12cm。 BF：FQ＝BE：AQ＝12：16＝3：4。
  3. 比をそろえる。BQ全体は 3＋4＝7。NはBQの真ん中。だから BN＝7÷2＝3.5。整数にするため全部2倍すると BQ＝14、BF＝6、BN＝7。だから BF：FN＝6：(7−6)＝6：1。
  4. 三角形BMNを、BM上でわける。BG：GM＝3：1 だから、三角形BGNは 24×3/4＝18cm²。
  5. 三角形BGNを、BN上でわける。BF：FN＝6：1 だから、三角形BFGは 18×6/7＝108/7＝15 3/7cm²。
  6. 落としやすい所: BF：FQ の 3：4 を、そのまま BF：FN にする。Nは BQ の真ん中なので、比をそろえてから使う。
答え：15 3/7cm²
コツ：「考え方も含めて」の問題。答案には、①CE＝4とAQ＝16 ②BG：GM＝3：1とBF：FN＝6：1 ③24×3/4×6/7 の式、の3つを順に書く。

5 まとめ

  • 「真ん中の点」を見たら、長さを半分ずつ図に書きこむ。同じ大きさの三角形が見つかる。
  • 正方形の外に点があるときは、辺をのばして平行線の砂時計を作る。
  • 三角形の中の三角形は、辺の比を1回ずつかけて面積をわける。
