1 (1) 4.71−(4 3/7−□)÷2 4/7＝3.21 A・4点｜□を求める逆算

👀 まず見るところ

【条件文】部品は「4.71−」と「＝3.21」。□をふくむかっこ全体を1つのかたまりと見て、外側から順にもどす → まずかっこ÷2 4/7 が 1.5と決まる。

📚 前提知識

  • A−B＝C なら、B＝A−C。たとえば 10−□＝3 なら、□＝10−3＝7。
  • B÷D＝E なら、B＝E×D。わり算はかけ算でもどす。
  • 小数と分数がまざったら、分数にそろえる。1.5＝3/2。

🔍 整理して解く

  1. 外側からもどす。かっこ÷2 4/7 の部分は、4.71−3.21＝1.5。
  2. かっこの中は、1.5×2 4/7。分数にすると 3/2×18/7＝27/7（＝3 6/7）。
  3. 4 3/7−□＝27/7。4 3/7＝31/7 なので、□＝31/7−27/7＝4/7。
  4. たしかめ。4 3/7−4/7＝3 6/7。3 6/7÷2 4/7＝27/7×7/18＝1.5。4.71−1.5＝3.21 で合う。
  5. 落としやすい所。2 4/7 を仮分数にするとき、2×7＋4＝18 をまちがえやすい。
答え：4/7

1 (3) (1−1/2)×(1＋1/2)×…×(1＋1/2025) A・4点｜分数のかけ算（消し合い）

👀 まず見るところ

【条件文】部品は「1−1/2」「1＋1/2」の形。かっこを 1/2、3/2、2/3、4/3 … と分数に直して書く → となりどうしで分子と分母が消し合い、はしだけ残る。

📚 前提知識

  • 1−1/3＝2/3、1＋1/3＝4/3。分母はそのままで、分子が1小さいか1大きいかになる。
  • 2/3×3/4＝2/4。前の分母と次の分子が同じなら、約分で消える。

🔍 整理して解く

  1. 「1−」の組と「1＋」の組に分けて、分数に直す。かけ算は順番を入れかえてよい。
    組分数に直す消し合ったあと
    1−1/○1/2×2/3×3/4×…×2024/20251/2025
    1＋1/○3/2×4/3×5/4×…×2026/20252026/2
  2. 「1−」の組は、最初の分子1と最後の分母2025だけが残る。
  3. 「1＋」の組は、最初の分母2と最後の分子2026だけが残る。2026/2＝1013。
  4. 2つをかける。1/2025×1013＝1013/2025。
  5. たしかめ。2までなら 1/2×3/2＝3/4。はしの式でも 1/2×3/2 で同じになる。
答え：1013/2025

2 (1) 走ったあと歩く（歩きが15分長い） A・4点｜速さ

👀 まず見るところ

【条件文】部品は「15分長く」と2つの速さ。歩いた時間から15分を切りはなして書く（直して書く）→ 残りは走る時間と歩く時間が同じになり、速さの和でわれば走った時間が出る。

📚 前提知識

  • 同じ時間だけ走って歩くと、1時間で進むのは 7.6＋4.8＝12.4km。2人が向かい合って進むときの「速さの和」と同じ考え方。
  • 15分は 1/4 時間。時速4.8kmで15分歩くと、4.8÷4＝1.2km。

🔍 整理して解く

  1. 時間の線分図を書く。歩く時間は、走る時間より15分長い。 
    走る  ├────□────┤
歩く  ├────□────┤15分┤
  2. 歩きのおまけの15分で進んだ道のりは 4.8÷4＝1.2km。10.5−1.2＝9.3km。
  3. 残りの9.3kmは、同じ時間□だけ走って歩いた道のり。9.3÷12.4＝0.75時間＝45分。これが走った時間。
  4. 歩いた時間は 45＋15＝60分。全体は 45＋60＝105分＝1時間45分。
  5. たしかめ。7.6×3/4＝5.7km。4.8×1＝4.8km。たすと10.5km で合う。落としやすい所は、答えが「全体」の時間であること。45分で止めない。

2 (2) 平行移動した直角三角形 B・4点｜相似と面積

👀 まず見るところ

【条件文】部品は「平行移動」と「三角形CGHの面積が6cm²」。平行移動だからDEとABは平行 → 三角形CGHは三角形CABの縮図。面積が1/9なので、辺は1/3になる。

📚 前提知識

  • 平行移動では、もとの辺と動かした辺が平行になる。だからDEとABは平行。
  • 縮図の面積は、辺の比を2回かけた比になる。辺が1/3なら、面積は 1/3×1/3＝1/9。
  • 平行四辺形の面積は、底辺×高さ。

🔍 整理して解く

  1. 三角形ABCの面積は 12×9÷2＝54cm²。三角形CGHは6cm²で、54の1/9。辺は1/3になる。CH＝9×1/3＝3cm。だから HB＝6cm。
  2. 求める2つの三角形は、平行四辺形ABEDから四角形ABHGをとった残り。図に書いて確かめる。
  3. 平行四辺形ABEDの底辺はAB＝12cm。高さはABとDEのあいだの長さ。HBはABに垂直なので、高さはHB＝6cm。面積は 12×6＝72cm²。
  4. 四角形ABHGは、三角形ABCから三角形CGHをとった形。54−6＝48cm²。
  5. 求める面積の和は 72−48＝24cm²。
答え：24cm²

2 (3) 軸の両側にある図形を回転 B・4点｜回転体

👀 まず見るところ

【条件文】部品は「lを軸として回転」と、図形が軸の左右両方にあること。左側を軸の右へ折り返して図に置く → 外側にはみ出した線だけが立体の形を決める。

📚 前提知識

  • 軸の左右にまたがる図形を回すと、左側と右側の立体が重なる。重なった所は1回だけ数える。だから左側を右へ折り返し、外側の線だけを使う。
  • 円すいの体積は、底面積×高さ×1/3。円周率は3で計算する。
  • 底面が同じ円すいを2つ上下にくっつけた立体は、高さをたして1つの円すいと同じ式で出せる。

🔍 整理して解く

  1. 左側の辺BAを軸の右へ折り返す。B'は軸から3cm、A'は軸から1cm。CDと交わる点をPとする。 赤い線が、立体の半分の切り口のふち。軸の右の大きな三角形と、Pより下でB'側にはみ出したオレンジの三角形CB'Pでできている。
  2. Pの高さを出す。いちばん下では、CDは軸の上、B'A'は軸から3cm。すき間は3cm。1cm上がるごとに、CDは右へ2cm、B'A'は左へ0.5cm動く。すき間は1cmで 2.5cm へる。3÷2.5＝1.2cm。Pの軸からの長さは 2×1.2＝2.4cm。
  3. 大きな三角形を回すと、半径8cm・高さ4cmの円すい。8×8×3×4×1/3＝256cm³。
  4. B'A'をのばすと、高さ6cmで軸にとどく（4cmで2cm寄るので、3cm寄るのは6cm）。半径3cm・高さ6cmの円すいは 3×3×3×6×1/3＝54cm³。
  5. 軸の上の点Cと、高さ6cmの点を、Pと結ぶ。この三角形を回すと、半径2.4cmの円すいが上下に2つできる。高さの合計は6cm。2.4×2.4×3×6×1/3＝34.56cm³。54cm³の円すいからこれをとると、オレンジの三角形を回した立体が残る。54−34.56＝19.44cm³。
  6. 合わせて 256＋19.44＝275.44cm³。分数にすると 275 11/25cm³。落としやすい所は、左側の立体をそのままたすこと。重なりを2回数えてしまう。
答え：275 11/25cm³

👀 まず見るところ

【条件文】部品は「6を宣言すると6000円」「77を宣言すると15000円」。6＝2×3、77＝7×11 に直して書き、金額を1000＋5000、5000＋10000に分ける → 5000円の2つの数字が決まる。

  1. 6000円＝1000円＋5000円。だから2と3は、1000円と5000円に1つずつ。
  2. 15000円＝5000円＋10000円。だから7と11は、5000円と10000円に1つずつ。
  3. 5000円には、2か3の1つと、7か11の1つが入る。これで5000円は満員。残りの5と9は、1000円と10000円に1つずつ入る。
    金額1000円5000円10000円
    入る数字2か3 ／ 5か92か3 ／ 7か117か11 ／ 5か9
  4. ①45＝5×9。5と9は1000円と10000円に1つずつ。どちらがどちらでも 11000円。
  5. ②21＝3×7。3は1000円か5000円。7は5000円か10000円。組み合わせを全部書く。
    3の金額7の金額もらえる金額

    1000円10000円11000円
    1000円5000円6000円
    5000円5000円10000円まで

  6. 落としやすい所は、②で「21を宣言したときの金額」を1つに決めようとすること。決まらないから「2番目に高い」と聞いている。
答え：①11000円　②11000円

4 (1)あ・い・う 6個の数の合計は、Aが何個・Bが何個分か A・2点×3｜和と差（消去算）

👀 まず見るところ

【条件文】部品は「3つの数から2つを選び、和と差」。6個を「A＋B、A＋C、B＋C、A−B、A−C、B−C」と式に直して書く → 全部たすとCが消えて、AとBの個数が決まる。

📚 前提知識

  • 大きい順にA、B、Cなので、差は「大きい方−小さい方」。A−B、A−C、B−C の3つになる。
  • たして0になる組は消える。たとえば「＋C」と「−C」が1つずつあれば、Cは無くなる。

🔍 整理して解く

  1. 6個の数をたす。 
    98＋76＋50＋48＋28＋22＝322
    これが あ＝322。
  2. 6個の式で、A・B・Cがそれぞれ何個あるかを表にする。＋は1個ふえる、−は1個へる。
    6個の式ABC
    A＋B＋1＋1
    A＋C＋1＋1
    B＋C＋1＋1
    A−B＋1−1
    A−C＋1−1
    B−C＋1−1
    合計4個2個0個
  3. Cは＋2個と−2個で消える。だから合計の322は、Aが い＝4 個、Bが う＝2 個分。
  4. 落としやすい所は、差の向き。B−C を C−B と書くと、Bの個数がずれる。
答え：あ 322　い 4　う 2

4 (1)え・お・か A＋Bを決めて、AとBを出す A・2点×3｜和と差（消去算）

👀 まず見るところ

【条件文】部品は「大きい順にA，B，C」。いちばん大きい2つの和が6個の中で最大 → A＋B＝98と決まる。322から（A＋B）2組分をひけば、Aが2個分だけ残る。

📚 前提知識

  • 差より和のほうが大きい。たとえば A＋C は A−C より、Cの2個分大きい。
  • 和の中では、大きい2つをたした A＋B がいちばん大きい。

🔍 整理して解く

  1. 6個のうちいちばん大きい98が A＋B。え＝98。
  2. 「Aが4個、Bが2個」を「（A＋B）が2組と、Aが2個」に分けて線分図にする。
  3. Aの2個分が126。だから A＝126÷2＝63。これが お。
  4. B＝98−63＝35。これが か。大きい順になっていて、どちらも2けたなので合う。
答え：え 98　お 63　か 35

4 (2) Cの数を出す A・4点｜和と差（確かめ）

👀 まず見るところ

【条件文】部品は(1)で出た「A＝63、B＝35」。A＋Bの次に大きいのはA＋C → 2番目の76＝A＋Cと決まり、Cが出る。

📚 前提知識

  • A＋C は、A＋B の次に大きい。B＋C より大きいのは A が B より大きいから。差の3つは、どれも A＋C より小さい。

🔍 整理して解く

  1. 98（A＋B）と28（A−B＝63−35）を消す。残りは 76、50、48、22。
  2. 残りでいちばん大きい76が A＋C。C＝76−63＝13。
  3. 確かめ。残りの3つの式に入れる。 
    B＋C＝35＋13＝48
A−C＝63−13＝50
B−C＝35−13＝22
    48・50・22がそろう。合っている。
答え：13

5 (1) 100秒後の帯A・B・C A・4点（完答）｜周期（あまり）

👀 まず見るところ

【条件文】部品は例の「2秒後」と「最後までいったら最初に戻る」。2秒後がAの△・Bの△・Cの○ → 「◯秒後＝◯番目のコマ」と直して書く。100をコマの数でわったあまりで決まる。

📚 前提知識

  • 同じ並びをくり返すときは、1周のコマ数でわったあまりを見る。Aは6コマで1周。8秒後は 8÷6＝1あまり2 で、2番目と同じ。
  • あまりが0のときは、1周の最後のコマ。

🔍 整理して解く

  1. 帯の下に、何秒後にそのコマが出るかを書く。2秒後は2番目になり、問題の例と合う。
  2. 1周のコマ数は、A＝6、B＝4、C＝5。
  3. 100をそれぞれでわる。
    帯わり算何番目出るもの
    A100÷6＝16あまり44番目×
    B100÷4＝25あまり0最後（4番目）×
    C100÷5＝20あまり0最後（5番目）△
  4. 落としやすい所は、あまり0を「1番目」としてしまうこと。わり切れたら、1周の最後のコマになる。
答え：A×・B×・C△

5 (2) Aが△・Bが○になる3回目 A・4点｜周期（共通の秒をさがす）

👀 まず見るところ

【条件文】部品は「A △ と B ○」と「3回目」。Aの△が出る秒、Bの○が出る秒をそれぞれ書き出す → 両方にある最初の秒と、そのくり返しの間かくで決まる。

📚 前提知識

  • Aは6秒、Bは4秒で同じ並びにもどる。両方がそろってもどるのは、6と4の最小公倍数の12秒ごと。

🔍 整理して解く

  1. Aの△は2番目と5番目。出る秒は 2, 5, 8, 11, 14, 17, … と3秒ごと。
  2. Bの○は1番目。出る秒は 1, 5, 9, 13, 17, … と4秒ごと。
    Aが△258111417
    Bが○1591317
  3. 両方にあるのは5秒後、17秒後。間は12秒で、6と4の最小公倍数と同じ。
  4. 3回目は 17＋12＝29秒後。
  5. 確かめ。29÷6＝4あまり5 → Aは5番目の△。29÷4＝7あまり1 → Bは1番目の○。合っている。
答え：29秒後

5 (3) A・B・Cが全部○になる2回目 A・4点｜周期（3つの周期をそろえる）

👀 まず見るところ

【条件文】部品は「A ○・B ○・C ○」と「2回目」。先にAとBだけそろう秒を書き出し、その中からCも○の秒をさがす → 3本の周期6・4・5の最小公倍数60秒ごとにくり返す。

📚 前提知識

  • 3本とも同じ並びにもどるのは、6・4・5の最小公倍数の60秒ごと。
  • Cの○は2番目。5でわって2あまる秒に出る（2, 7, 12, 17, …）。

🔍 整理して解く

  1. Aの○は1番目で、1, 7, 13, 19, 25, … と6秒ごと。Bの○も1番目で、1, 5, 9, 13, … と4秒ごと。
  2. AとBがそろって○になるのは 1秒後から12秒ごと。1, 13, 25, 37, 49, …
  3. この中から、5でわって2あまる数をさがす。
    AとBが○1132537
    5でわったあまり1302
  4. 1回目は37秒後。次は60秒後なので、2回目は 37＋60＝97秒後。
  5. 落としやすい所は、1回目の37秒後で答えてしまうこと。聞かれているのは「2回目」。
答え：97秒後

5 (4) Aが○・Bが△にならないわけ B・8点｜周期（偶数・奇数で示す）

👀 まず見るところ

【条件文】部品は「A ○ と B △」と「ならないことを示しなさい」。Aの○の秒とBの△の秒を書き出し、偶数か奇数かに丸 → いつも片方が奇数、片方が偶数なので、同じ秒にならないと決まる。

📚 前提知識

  • 奇数に偶数をたしても、奇数のまま。1に6をたし続けると 7, 13, 19 と奇数が続く。
  • ある秒は、偶数か奇数のどちらか一方。両方にはならない。

✍️ 答案の組み立て

  1. Aの○は1番目。出るのは 1, 7, 13, 19, … 秒後。1から6ずつふえるので、いつも奇数秒後。
  2. Bの△は2番目。出るのは 2, 6, 10, 14, … 秒後。2から4ずつふえるので、いつも偶数秒後。
  3. 奇数の秒と偶数の秒は同じにならない。だから、Aが○でBが△になる秒はない。
  4. 答案には「Aの○は奇数秒後」「Bの△は偶数秒後」「だから同じ秒にならない」の3つを書く。
模範解答：（例）帯Aの○が出てくるのは奇数秒後，帯Bの△が出てくるのは偶数秒後だから。

6 (1)② AB×ABの下2けたがABになる2けたの数 B・4点（完答）｜数の性質（十の位を決める）

👀 まず見るところ

【条件文】部品は「下2けたがAB」と、①の答え。一の位Bは0・1・5・6にしぼれる（①を使う）→ Bごとに十の位を計算して、Aと同じになるかを見る。

📚 前提知識

  • かけ算の答えの一の位は、かける数どうしの一の位だけで決まる。だから AB×AB の一の位がBになるには、①のBでないとだめ。
  • 十の位の数を変えても、一の位は変わらない。下の位から1けたずつ決められる。

🔍 整理して解く

  1. Bが0のとき。A0×A0 は下2けたが00になる。Aも0になり、2けたの数にならない。
  2. Bが1のとき。21×21＝441、31×31＝961。下2けたの十の位は、Aを2倍した数の一の位になる。Aと同じになるのはA＝0だけで、2けたにならない。
  3. Bが5のとき。15×15＝225、35×35＝1225。Aが何でも、下2けたは25。だからA＝2の25だけ。
  4. Bが6のとき。十の位を表にする。
    AB162636465666768696
    AB×AB2566761296211631364356577673969216
    下2けた567696163656769616
    下2けたがABと同じなのは76だけ。
  5. 確かめ。25×25＝625、76×76＝5776。どちらも下2けたがもとの数。
答え：25・76

6 (2) ABCD×ABCDの下4けたがABCDになる4けたの数 B・4点｜数の性質（下の位から決める）

👀 まず見るところ
