1 問1 コップの底面積 2点｜体積の計算

👀 まず見るところ

【条件文】部品は「最大で300cm³」と「高さが10cm」。円柱の体積＝底面積×高さ、に直して書く → 300÷10で底面積が決まる。

📚 前提知識

  • 円柱の体積＝底面積×高さ。底面積がわからないときは「体積÷高さ」で戻せる。

🔍 こう読み解く

  1. 底面積を□cm²とすると、□×10＝300。
  2. □＝300÷10＝30（cm²）。単位はcm²（面積）で答える。
答え：30cm²

1 問2 1円玉の密度 2点｜密度の計算

👀 まず見るところ

【条件文】部品は「直径は2cm」と「小数第2位を四捨五入」に丸。直径は÷2で半径1cmに直して書く → 底面積×厚み＝体積、1g÷体積で密度が決まる。

📚 前提知識

  • 密度＝1cm³あたりの質量＝質量÷体積（問題文の※にある決まり）。

🔍 こう読み解く

  1. 半径は2÷2＝1cm。底面積は1×1×3.14＝3.14cm²。
  2. 体積は3.14×0.12＝0.3768cm³。
  3. 1÷0.3768＝2.65…。小数第2位を四捨五入して2.7g。
答え：2.7g

1 問3 1円玉が沈んだ深さ 2点｜力のつり合い

👀 まず見るところ

【条件文】部品は「重さ（質量×10）」と、表面張力の力「7とします」。1円玉に下向き10・上向き7の矢印を図に置く → 残り3が浮力と決まり、押しのけた体積が出る。

📚 前提知識

  • 浮いて止まっている物体は、下向きの力＝上向きの力の合計。ここでは「重さ＝浮力＋表面張力の力」と問題文に書いてある。
  • 浮力＝（水の密度）×（押しのけた水の体積）×10。これも問題文の式をそのまま使う。

🔍 こう読み解く

  1. 1円玉の重さは1×10＝10。表面張力の力が7なので、浮力は10−7＝3。
  2. 押しのけた水の体積を□cm³とすると、1×□×10＝3 → □＝0.3cm³。
  3. 沈んだ深さ＝体積÷底面積＝0.3÷3.14＝0.0955…cm。mmに直すと×10で0.95…mm → 小数第2位を四捨五入して1.0mm。
  4. 落としやすい所: 答えの単位はmm。cmのまま「0.1」と書かないこと、問2の2.7はこの計算では使わないこと。
答え：1.0mm

1 問4 1円玉と同じ形の水がちょうど水面まで沈む理由 3点｜記述（40字程度）

👀 まず見るところ

【条件文】部品は「問3の結果を参考にして」と「40字程度」。問3と同じく下向き＝重さ、上向き＝浮力の2本を図に置く → 水の重さと浮力が同じ大きさになる位置で止まる、と決まる。

📚 前提知識

  • 浮力＝（水の密度1）×（沈んだ部分の体積）×10。全部沈むと、沈んだ体積＝その水の体積になる。

✍️ 答案の組み立て

  1. 要素A（下向き）: 1円玉と同じ形状の水の重さ＝1×（1円玉の体積）×10。
  2. 要素B（上向き）: 水面の高さまで沈むと、浮力も1×（1円玉の体積）×10。
  3. 要素C（結論）: AとBがつりあうから、そこで止まる。答案は「重さ」と「浮力」の2語を入れて「つりあうから」で結ぶ。
模範解答：1円玉と同じ形状の水の重さと，その水が受ける浮力の大きさがつりあうから。

1 問5 宇宙で球になった水の半径 2点｜体積の計算

👀 まず見るところ

【条件文】部品は「半径3cm，高さ4cm」と球の体積の式「×4÷3」。水の形が変わっても体積は同じ、と1行に直して書く → 円柱の体積＝球の体積の式で半径が決まる。

📚 前提知識

  • 形が変わっても、水の量（体積）は変わらない。

🔍 こう読み解く

  1. コップの水の体積は3×3×3.14×4＝36×3.14cm³。3.14はかけ算せずに残しておく。
  2. 球の半径を□cmとすると、□×□×□×3.14×4÷3＝36×3.14。
  3. □×□×□＝36÷4×3＝27。27＝3×3×3なので□＝3cm。
答え：3cm

1 問6 球とコップの水の表面積の比 2点｜表面積の計算

👀 まず見るところ

【条件文】部品は「コップに入っていたときの水の表面積」と「小数第3位を四捨五入」。コップの水は上の面・底の面・側面の3つに分けて図に置く → 3つの合計と球の表面積の比で決まる。

📚 前提知識

  • 円柱の表面積＝円2つ＋側面。側面は広げると長方形で、横＝円周（直径×3.14）、縦＝高さ。

🔍 こう読み解く

  1. 球の表面積は半径3cm（問5）なので3×3×3.14×4＝36×3.14cm²。
  2. コップの水の表面積は、円2つ3×3×3.14×2と、側面3×2×3.14×4の合計＝42×3.14cm²。
  3. （36×3.14）÷（42×3.14）＝36÷42＝0.857…。小数第3位を四捨五入して0.86倍。
  4. 落としやすい所: 上の面だけ（空気にふれている面だけ）で比べない。この問題はコップにふれている底と側面も水の表面に数える。
答え：0.86倍

2 問3 もやもやが出なかったビーカーの中身 2点｜実験の読み取り

👀 まず見るところ

【条件文】部品は「2つは10gの食塩」に丸＝食塩水Aと食塩水Bは同じもの、と直して書く → 同じ液どうしを足しても変化は出ない、と決まる。

📚 前提知識

  • もやもやは、ちがう液どうしが混ざるときに見える（水を加えたグループで、水どうしだけ変化が出なかったことと同じ考え方）。

🔍 こう読み解く

  1. どちらも100mLの水に10gの食塩 → 食塩水Aと食塩水Bは同じもの。
  2. 食塩水Bを、水・砂糖水・食塩水Aに加える。中身がちがう水と砂糖水ではもやもやが出て、同じ食塩水Aだけ出ない。
答え：食塩水A

2 問4 実験2までで分かること 4点｜記述

👀 まず見るところ

【資料問題】部品は【結果2−2】の「液の表面付近」と「液の底の方」。5％はうすく軽い、15％はこく重い、と直して書く → もやもやは密度のちがう液が混ざるときに出る、と決まる。

📚 前提知識

  • 同じ体積なら、こい食塩水ほど重い（密度が大きい）。重い液は下へ、軽い液は上へ動く。

✍️ 答案の組み立て

  1. 要素A（実験2−1）: とけているものがちがう液を加えると、もやもやが出る。
  2. 要素B（実験2−2）: こさがちがう食塩水を加えても出る。こい（重い）ものは底、うすい（軽い）ものは表面付近。
  3. 要素C（まとめ）: AとBに共通するのは「密度のちがうものどうしを混ぜた」こと。答案はこの言葉を入れて、「もやもやしたものが見えること」で結ぶ。
模範解答：密度のちがうものどうしを混ぜたときにもやもやしたものが見えること。
コツ：もやもやが見えるのは、光の曲がり方（屈折）が液の密度によってちがうから（声教の解説）。

2 問5 実験2と異なる現象 2点｜原因の見分け

👀 まず見るところ

📚 前提知識

3 問3 ヤゴやメダカにとっての水生植物 3点｜記述

3 問4 動物・理由 どちらから先に駆除するか 2点＋3点｜記述

👀 まず見るところ

【素材文】部品は「アメリカザリガニを捕食する」。「バス → ザリガニを食べる」と矢印で余白に書く（3語で書く）→ バスを先に消すと、ザリガニを食べる者がいなくなると決まる。

📚 前提知識

  • 食べる・食べられるの関係では、食べる側がいなくなると、食べられる側の数は増える。

🔍 こう読み解く

  1. ブラックバスから先に駆除すると、ザリガニは捕食されなくなって増え、そのあとの駆除が大変になる。
  2. ザリガニから先に駆除すると、バスはエサをとりにくくなって数が減り、駆除しやすくなる。
  3. だから先はアメリカザリガニ。理由は「バスを先に駆除すると、ザリガニが増える」の向きで書く。
答え：動物 アメリカザリガニ／理由 ブラックバスを先に駆除してしまうと，ブラックバスに捕食されなくなったアメリカザリガニが増えてしまうから。

4 問3 台風の断面図に風の流れをかく 3点｜作図

👀 まず見るところ

【まざり型→素材文】本文の部品「上昇気流」と問3の「らせん状」に丸。図2の上に「下から吹きこむ → 雲の中を上る → 上で外へ」の3本を置く。

📚 前提知識

  • 台風（低気圧）には、地表付近でまわりから中心へ風がふきこむ。北半球では上空から見て反時計回り。
  • ふきこんだ空気は上昇して積乱雲をつくり、上空で外へ流れ出す。

🔍 こう読み解く

  1. ① 地表付近に、外側から中心へ向かう矢印をかく。外側の積乱雲の中にも、下から上への矢印。
  2. ② 中心のまわりでは、風がアイウォール（雲の壁）にそってらせん状に上昇する。うずを巻きながら上へ向かう線をかく。
  3. ③ 上空まで上った空気は、雲の上で外へ向かってふき出す。この①→②→③が一つながりになっていれば、風の流れが表せる。
答え：右の図（地表付近で中心へふきこみ，雲の壁にそってらせん状に上昇し，上空で外へふき出す矢印）
コツ：声教の解説では、中心付近は空気が少なくなるので上空から空気が流れこみ（下降気流）、雲のほとんどない「目」ができると説明している。
