1 (1) 小数のかけ算とわり算の連続 A・5点｜計算のくふう

👀 まず見るところ

【条件文】部品は「÷0.01」「×0.001」のような、1の下に0がならぶ数。÷0.01は「100倍」、×0.001は「1000でわる」に直して書く → 小数点の移動だけで答えが出る。

📚 前提知識

  • 0.01でわるのは、100倍するのと同じ。たとえば 3÷0.01＝300。
  • 0.001をかけるのは、1000でわるのと同じ。たとえば 5×0.001＝0.005。

🔍 整理して解く

  1. 左から順に、2つずつ組にして計算する。
    組計算答え
    0.1÷0.010.1を100倍10
    ×0.001÷0.00011000でわって10000倍＝10倍100
    ×0.00001÷0.000001100000でわって1000000倍＝10倍1000
  2. たしかめ。「÷小さい数」の組はどれも10倍になる。0.1を10倍、10倍、10倍して1000。
答え：1000
コツ：小数を全部筆算すると、0の数を数えまちがえやすい。「×0.001÷0.0001」は、0の数の差だけを見ると10倍とすぐ分かる。

1 (2) 帯分数と小数のまじった計算 A・5点｜分数と小数の計算

👀 まず見るところ

【条件文】部品は「0.625」「0.125」「0.75」。5/8、1/8、3/4 に直して書く → 全部を分数にして計算すると、約分で数が小さくなる。

📚 前提知識

  • 1/8＝0.125。だから 5/8＝0.625、3/8＝0.375、7/8＝0.875。8分の○の小数はよく出る。
  • 1/8でわるのは、8をかけるのと同じ。

🔍 整理して解く

  1. 小さいかっこの中を出す。2 1/3＝7/3。7/3−3/7＝49/21−9/21＝40/21。
  2. 大きいかっこの中を、かけ算・わり算から計算する。 
    40/21×5/8＝25/21
1/7÷1/8＝8/7＝24/21
25/21＋24/21＝49/21＝7/3
  3. 最後に0.75＝3/4をかける。7/3×3/4＝7/4＝1 3/4。
答え：1 3/4
コツ：49/21 は7で約分して 7/3。約分を先にすると、次のかけ算で3が消える。

1 (3) □をふくむ逆算 A・5点｜逆算

👀 まず見るところ

【条件文】部品は「÷1/6」と、まわりの「1.875」「0.05」。÷1/6は「×6」、1.875は15/8に直して書く → 外側からひとつずつもどして□を出す。

📚 前提知識

  • 逆算は、いちばん最後にした計算からもどす。ひき算の「ひく数」は「ひく数＝ひかれる数−答え」で出す。
  • 1.875＝1と7/8＝15/8。0.75−1/5＝0.75−0.2＝0.55＝11/20。

🔍 整理して解く

  1. 大きいかっこの部分をAとおく。式は「15/8−A×6−7/16＝1/20」。
  2. A×6 を出す。15/8 から 7/16 と 1/20 をひいた残りになる。 
    15/8−7/16＝30/16−7/16＝23/16
23/16−1/20＝115/80−4/80＝111/80
  3. A＝111/80÷6＝111/480＝37/160。
  4. A＝11/20×□ なので、□＝37/160÷11/20＝37/160×20/11＝37/88。
  5. たしかめ。11/20×37/88＝37/160。これを6倍すると111/80。15/8−111/80−7/16 は 1/20＝0.05 になる。
答え：37/88
コツ：「−A÷1/6−7/16」のように、ひき算が2つ続く所は、まとめて「ひかれる数から両方ひく」と考えると向きをまちがえない。

1 (4) 縮尺25000分の1の地図の面積 A・5点｜縮尺と面積

👀 まず見るところ

【条件文】部品は「25000分の1」と答えの単位「km²」。地図の1cmは実際の250m＝0.25kmと直して書く → 地図の1cm²は 0.25×0.25 km²。面積は長さの比を2回かける。

📚 前提知識

  • 縮尺25000分の1では、地図の1cmが実際の25000cm＝250m＝0.25km。
  • 面積は「たて×横」なので、長さが25000倍なら面積は25000×25000倍。1cm²の正方形は、実際には 0.25km×0.25km の正方形になる。

🔍 整理して解く

  1. 地図の1cm²が、実際に何km²かを出す。0.25×0.25＝0.0625km²。
  2. 50cm²なので50倍する。0.0625×50＝3.125km²。
  3. たしかめ。50cm²は、たて5cm・横10cmの長方形と考えてもよい。実際はたて1.25km・横2.5km。1.25×2.5＝3.125km²。
答え：3.125
コツ：cm²のまま25000×25000倍すると、0がたくさんならぶ。先にkmに直してからかけると、けたをまちがえない。落としやすいのは、面積なのに25000倍を1回しかかけないこと。

1 (5) 1/13 の小数第2023位 A・5点｜周期

👀 まず見るところ

【条件文】部品は「1/13」と「小数第2023位」。1÷13をわり切れるまで進めず、同じ数字がくり返す所まで書く → 6けたの周期なので、2023を6でわったあまりで決まる。

📚 前提知識

  • わり算のあまりが前と同じになったら、そこから先は同じ数字がくり返す。1÷13では、あまりが1にもどった所で周期が終わる。
  • □番目が周期の何番目かは「□÷周期の長さ」のあまりで分かる。あまり0なら周期の最後。

🔍 整理して解く

  1. 1÷13を計算する。1/13＝0.076923 076923 …。あまりは 10、9、12、3、4、1 と進み、1にもどる。周期は「076923」の6けた。
  2. 2023÷6＝337 あまり 1。
    周期の何番目123456
    数字076923
  3. あまり1は周期の1番目。小数第2023位は0。
答え：0
コツ：小数第1位の「0」を周期に入れわすれると、1つずれて7と答えてしまう。周期は小数第1位から数える。

2 (1) Aの2/3とBの75%とCの4割が等しい A・5点｜連比

👀 まず見るところ

【条件文】部品は「2/3」「75%」「4割」が「等しい」。75%は3/4、4割は2/5に直して書く → 等しい量を6のような数に決めると、A・B・Cがそれぞれ出る。

📚 前提知識

  • 75%＝0.75＝3/4。4割＝0.4＝2/5。
  • 「Aの2/3が6」なら、A＝6÷2/3＝9。もとの数は「かけた分数でわる」ともどせる。

🔍 整理して解く

  1. 等しい量を、分子の2と3でわれる6とおく。
    ABC
    かける分数2/33/42/5
    等しい量666
    もとの数6÷2/3＝96÷3/4＝86÷2/5＝15
  2. A：B：C＝9：8：15。9・8・15に共通の約数は1だけなので、これがいちばん簡単な比。
  3. たしかめ。9×2/3＝6、8×0.75＝6、15×0.4＝6。3つとも同じ。
答え：9：8：15
コツ：等しい量を1とおくと、3/2・4/3・5/2の分数の比になって、通分がひと手間ふえる。分子（2と3）の最小公倍数の6にしておくと、全部整数で出る。

2 (2) 46歳と18歳、出会ったときは5倍 A・5点｜年齢算

👀 まず見るところ

【条件文】部品は「46歳」「18歳」と「5倍」。2人の差の28歳は何年前でも同じ → 5倍のときの差は「5−1＝4」にあたると直して書く。

📚 前提知識

  • 2人とも1年に1歳ずつ年をとる。だから年れいの差は、いつでも同じ。
  • 小川さんが石川さんの5倍なら、石川さんを①とすると小川さんは⑤。差は④。

🔍 整理して解く

  1. 今の差を出す。46−18＝28歳。
  2. 出会ったときの年れいを比で書く。
    石川さん小川さん差
    比①⑤④
    年れい7歳35歳28歳
    ④が28歳なので、①は 28÷4＝7歳。
  3. 石川さんは今18歳、出会ったとき7歳。18−7＝11年前。
  4. たしかめ。11年前の小川さんは 46−11＝35歳。35は7の5倍。
答え：11年前
コツ：「何年前」を□として 46−□＝(18−□)×5 の式を立ててもよい。比の差④を使うと、式を変形せずに出る。

2 (3) 2時から3時の間で長針と短針が反対向き A・5点｜時計算

👀 まず見るところ

【条件文】部品は「2時から3時の間」と「反対側に一直線」。一直線は「間の角が180度」と直して書く → 2時に60度前にいる短針を、長針が60＋180＝240度追いかける。

📚 前提知識

  • 長針は1時間で360度なので、1分で6度。短針は1時間で30度なので、1分で0.5度。
  • 長針は1分ごとに 6−0.5＝5.5度ずつ短針に近づく（追いこす）。

🔍 整理して解く

  1. 2時ちょうどの位置を書く。長針は12、短針は2。短針は長針の60度先にいる。
  2. 反対向きになるのは、長針が短針を追いこして、さらに180度先に出たとき。長針が多く回る角度は 60＋180＝240度。
  3. かかる時間は 240÷5.5＝480/11＝43 7/11分。答えは2時43 7/11分。
  4. たしかめ。長針は 6×480/11＝2880/11度＝約262度。短針は 60＋0.5×480/11＝約82度。差は180度。
答え：2時43 7/11分
コツ：「重なる」なら追いかける角度は60度、「一直線」なら60＋180度。落としやすいのは、180−60＝120度とひいてしまうこと。120÷5.5分後（約22分）は、長針が短針を追いこして60度先に出ただけで、まだ一直線になっていない。

2 (4) 黒くぬられた6つの角の和 A・5点｜角の和（くさび形）

👀 まず見るところ

【条件文】部品は「黒くぬられた部分の角の和」。1つずつの大きさは出ないので、2本の線が交わる点Xに印をつけて図に置く → くさび形と四角形に分けると、Xの角を通して和が決まる。

📚 前提知識

  • くさび形（へこみのある四角形）では、へこんだ所の外側から見た角＝残り3つの角の和。三角形の外角が2回使われるからこう言える。
  • 2本の直線が交わってできる、向かい合う角（対頂角）は等しい。
  • 四角形の4つの角の和は360度。

🔍 整理して解く

  1. 6つの角にア〜カの名前をつけ、線が交わる点をXとする。青のくさび形と、だいだいの四角形に分ける。
  2. くさび形を見る。へこみはX。Xの右側の赤い角＝ア＋イ＋ウ。
  3. 四角形を見る。エ＋オ＋カ＋（Xの左側の赤い角）＝360度。
  4. Xの右側と左側の赤い角は、向かい合う角なので同じ大きさ。だから ア＋イ＋ウ＋エ＋オ＋カ＝360度。
答え：360度
コツ：しるしの角が多い図では、まず線の交わる点をさがす。そこで図を2つに分けると、交わる点の角が「つなぎ役」になって消える。

3 (1) 10gずつ取りかえたあとのAの食塩 A・5点｜食塩水のやりとり

👀 まず見るところ

【条件文】部品は「10gの食塩水を同時に取り出し」と求めるもの「食塩の重さ」。濃さではなく食塩のgを聞いている → 食塩のgに直して表に書く。出ていく分をひき、入ってくる分をたすだけ。

📚 前提知識

  • 食塩の重さ＝食塩水の重さ×濃さ。12％の食塩水100gなら、100×0.12＝12gの食塩が入っている。
  • 食塩水を取り出すと、食塩も同じ濃さで出ていく。12％の食塩水10gには、食塩が1.2g入っている。

🔍 整理して解く

  1. はじめの食塩の重さを出す。Aは 100×0.12＝12g。Bは 200×0.03＝6g。
  2. Aから出ていく食塩は 10×0.12＝1.2g。Bから来る食塩は 10×0.03＝0.3g。表にする。
    食塩水食塩
    A はじめ100g12g
    Aから出る−10g−1.2g
    Bから来る＋10g＋0.3g
    A あと100g11.1g
  3. 12−1.2＋0.3＝11.1g。食塩水の重さは100gのまま。
  4. 落としやすい所: 取り出す10gをそのまま食塩の重さだと思わない。食塩は10gの中の一部だけ。
答え：11.1g

3 (2) 水100gを加えたBの濃さ A・5点｜食塩水のやりとり

👀 まず見るところ

【条件文】部品は「次に」と「水を100g加えました」。「次に」は(1)のあとのB、という合図 → (1)の表にBの行を書き足す。水を足しても食塩のgは変わらない。

📚 前提知識

  • 濃さ＝食塩の重さ÷食塩水の重さ。6gの食塩が300gの食塩水にあれば、6÷300＝0.02で2％。
  • 水を足すと、食塩水の重さだけがふえる。食塩の重さはそのまま。

🔍 整理して解く

  1. (1)のときのBを表にする。
    食塩水食塩
    B はじめ200g6g
    Bから出る−10g−0.3g
    Aから来る＋10g＋1.2g
    水を加える＋100g0g

  3. 濃さは 6.9÷300＝0.023。百分率にすると 2.3％。
  4. 落としやすい所: (1)の入れかえを忘れて、はじめの6gで計算すると2％になってしまう。
答え：2.3％

3 (3) Aの食塩をBの2倍にする移し方 B・5点｜食塩水のやりとり（全体の量は変わらない）

👀 まず見るところ

【条件文】部品は「食塩の量が容器Bに含まれる食塩の量の2倍」。食塩はAとBを行き来するだけで、2つの合計は変わらない → 合計を 2：1 に分けて、Aの目標のgを書く。足りない分が、移す食塩の量になる。

📚 前提知識

  • 容器どうしで移すだけなら、食塩の合計は変わらない。11.1gと6.9gなら、どう移しても合計は18g。
  • 2.3％の食塩水を1g移すと、食塩は0.023g動く。動かしたい食塩のg÷0.023で、移す食塩水のgが出る。

🔍 整理して解く

  1. (2)のあとの食塩は、Aが11.1g、Bが6.9g。合計は 11.1＋6.9＝18g。
  2. A：B＝2：1 に分ける。Aは 18÷3×2＝12g、Bは 6g にしたい。
    AB
    いまの食塩11.1g6.9g
    目標の食塩12g6g
    動かす食塩＋0.9g−0.9g
  3. Aの食塩をふやすから、BからAへ移す。Bの濃さは(2)の2.3％。
  4. 移す食塩水は 0.9÷0.023＝900/23＝39 3/23g。
  5. 確かめ。39 3/23gの中の食塩は 900/23×0.023＝0.9g。Aは12g、Bは6g。12は6の2倍で合っている。
答え：容器Bから容器Aへ39 3/23g移動すればよい

4 (1) 鉄橋とトンネルから電車Aの長さ A・5点｜通過算

👀 まず見るところ

【条件文】部品は「渡りはじめてから渡り終わるまで」と「完全に隠れている」。鉄橋は「540m＋電車の長さ」、トンネルは「3420m−電車の長さ」に直して書く → 2つをたすと電車の長さが消えて、速さが出る。

📚 前提知識

  • 鉄橋を渡りはじめてから渡り終わるまでに進むのは、鉄橋の長さ＋電車の長さ。電車の先頭が入ってから、最後尾が出るまで。
  • トンネルに完全に隠れている間に進むのは、トンネルの長さ−電車の長さ。最後尾が入ってから、先頭が出るまで。
  • 3.42kmは3420m。単位をmにそろえる。

🔍 整理して解く

  1. 2つの道のりを線分図に書く。
  2. 2本をたす。「＋電車の長さ」と「−電車の長さ」が消える。時間は 7＋29＝36秒、道のりは 540＋3420＝3960m。
  3. 速さは 3960÷36＝秒速110m。
  4. 鉄橋の7秒で 110×7＝770m 進む。電車の長さは 770−540＝230m。
  5. 確かめ。トンネルは (3420−230)÷110＝3190÷110＝29秒。合っている。
答え：230m

4 (2) すれ違いから電車Bの長さ B・5点｜通過算（すれ違い）

👀 まず見るところ

📚 前提知識

  2. すれ違う間の道のりを、2本の線分図にする。上は「長さの和」、下は「2.5秒で進んだ和」。2本は同じ長さ。

6 (1)① 売れたくつのサイズ A・5点｜代表値の選び方（記述）

👀 まず見るところ

【資料問題】部品は資料の正体「売れたくつのサイズ」と、9個のうち「26」が7個あること。同じ値が多い数に丸 → 「最も個数が多いデータの値」＝最頻値が合う。

📚 前提知識

  • 最頻値は「いちばん多く出てくる値」。売れたくつなら「いちばんよく売れたサイズ」になる。
  • 平均値は、売れたことの無いサイズになることもある。

✍️ 答案の組み立て

  1. 平均値を出してみる。合計は 26×7＋26.5＋27＝235.5。235.5÷9＝26.16…。26.16…というサイズは1足も売れていない。
  2. 要素A（特徴）: 9人中7人が同じ26を買っている。
  3. 要素B（平均値の弱点）: 平均値だと、その特徴を表していない。
  4. 適するもの: いちばん多い値をそのまま答える最頻値。最頻値は26になる。
模範解答：理由…（例）平均値だと，9人中7人が同じ値（26）であるというデータの特徴を表していないから。／適するもの…最頻値
コツ：お店が次に多く仕入れたいのは「いちばん売れたサイズ」。だれが使う代表値かを考えると選びやすい。

6 (1)② 9人の年齢 A・5点｜代表値の選び方（記述）

👀 まず見るところ

【資料問題】部品は「9人の年齢」の中で1つだけ飛びぬけた「100」。この1人に丸 → 平均値が大きく引っぱられる。真ん中の値＝中央値なら100の影響を受けない。

📚 前提知識

  • 中央値は「小さい順に並べたときの真ん中」。9個なら5番目。いちばん大きい値が100でも1000でも、5番目は変わらない。
  • 平均値は全部をたすので、1つだけ大きい値があると、そちらに引き上げられる。

✍️ 答案の組み立て

  1. 小さい順に並べ直す。2, 3, 3, 3, 4, 4, 5, 6, 100。データは並んでいないので、ここを先にやる。
  2. 平均値は 130÷9＝14.4…。9人中8人は6才以下なのに、平均は14才をこえている。
  3. 要素A（特徴）: 1人だけ100才。要素B（平均値の弱点）: その年齢が平均値を引き上げてしまう。
  4. 適するもの: 5番目の4才を答える中央値。
模範解答：理由…（例）1人だけ100才で，その年齢が平均値を引き上げてしまうから。／適するもの…中央値
コツ：「1つだけかけはなれた値」を見たら中央値。このデータは3才が3人で最頻値も考えられるが、解答は中央値。100才の1人が平均をゆがめる、という点を理由の中心にする。

6 (1)③ 2回のテストの比較 B・5点｜代表値の選び方（記述）

👀 まず見るところ

【資料問題】部品は聞かれ方「2回のテストの比較」と、どちらも5番目が「50」であること。中央値が同じなら差が出ない → 全員の点を使う平均値でくらべる。

📚 前提知識

  • 中央値は真ん中の1つしか見ない。真ん中より上の点が大きく変わっても、中央値は変わらない。
  • 平均値は全員の点を使う。全体の高い・低いをくらべるのに向いている。

✍️ 答案の組み立て

  1. 中央値を見る。どちらも9人で、5番目は1回目も2回目も50点。
  2. 平均値を出す。1回目は 402÷9＝44.6…点。2回目は 588÷9＝65.3…点。2回目のほうが20点ほど高い。
  3. 要素A（特徴）: 2回とも中央値は同じ50点。要素B: 2回目のほうが全体的に高得点なのに、中央値ではそれが表れない。
  4. 適するもの: 全員の点を使う平均値。
模範解答：理由…（例）2回とも中央値は同じ50点であり，2回目のテストの方が全体的に高得点となっているデータの特徴を表していないから。／適するもの…平均値
コツ：平均値の計算は理由に書かなくてよい。「中央値が同じ50点」と「2回目のほうが全体に高い」の2つが入れば答案になる。

6 (2) 平均値が中央値より高い10人の点数 B・3点｜平均値と中央値（記述）

👀 まず見るところ

【条件文】部品は「10人」と「中央値よりも平均値のほうが高い」。10人は上の5人・下の5人に分けられる → 平均値＝（上位5人の平均＋下位5人の平均）÷2 に直して書く。

📚 前提知識

  • 10人の中央値は、5番目と6番目の平均。中央値を境に、下の5人と上の5人に分かれる。
  • 5人ずつの2組の平均は、2組の平均をたして2でわった値。たとえば50点の組と70点の組なら、全体は60点。

✍️ 答案の組み立て

  1. 具体的な数で見る。40, 45, 50, 55, 60 ｜ 60, 65, 70, 90, 100 の10人。中央値は（60＋60）÷2＝60点。下位5人の平均は50点、上位5人の平均は77点。全体の平均は63.5点で、中央値より高い。
  2. 数直線に3つの値を置く。中央値から下位平均までは10点。上位平均までは17点。
  3. 全体の平均は、下位平均と上位平均のちょうど真ん中。だから平均値が中央値より上に来るのは、上の差（17点）が下の差（10点）より大きいとき。
  4. 答案の要素: 「上位5人の平均値と中央値との差」と「下位5人の平均値と中央値との差」をくらべ、上のほうが大きい、と書く。
模範解答：上位5人の点数の平均値と10人の点数の中央値との差が，下位5人の点数の平均値と10人の点数の中央値との差よりも大きい。
コツ：「高い点の人が一部だけ大きくはなれている」と言いかえてもよい。点数の答えは無いので、数の例を1つ作って数直線に置くと、何を書けばよいかが見える。
