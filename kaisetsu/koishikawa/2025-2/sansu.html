1 (3) 1/(1×3)＋1/(2×4)＋…＋1/(10×12) 4点｜分数の和（分けて消す）

👀 まず見るところ

【条件文】部品は分母の「1×3」「2×4」。かける2つの数の差がどれも2 → 1/1−1/3 のようなひき算に分けて、最後に×1/2。まん中がつぎつぎに消える。

📚 前提知識

  • 1/1−1/3＝3/3−1/3＝2/3。これは 1/(1×3) の2倍。だから 1/(1×3)＝(1/1−1/3)×1/2。
  • 差が2の2数なら、どれも同じ形にできる。1/(N×(N＋2))＝(1/N−1/(N＋2))×1/2。

🔍 整理して解く

  1. 1つずつひき算に分ける。×1/2 は最後にまとめてかける。 
    1/(1×3)  → 1/1 −1/3
1/(2×4)  → 1/2 −1/4
1/(3×5)  → 1/3 −1/5
  …
1/(9×11) → 1/9 −1/11
1/(10×12)→ 1/10−1/12
  2. −1/3 と ＋1/3 のように、2つ下の行と消し合う。残るのは ＋1/1、＋1/2、−1/11、−1/12 の4つ。
  3. 分母を132にそろえる。132/132＋66/132−12/132−11/132＝175/132。
  4. ×1/2 をかける。175/132×1/2＝175/264。
  5. 落としやすい所。差が2なので、消えるのは「となり」ではなく「2つ先」。だから最初の2つと最後の2つが残る。
答え：175/264

👀 まず見るところ

【条件文】部品は「ある星の時間の1分は、地球における75秒」。地球の60秒のあいだに星では 60÷75＝0.8分 → 星の時間＝地球の時間×0.8 に直して書く。

📚 前提知識

  • 星の1分のほうが長い。だから、同じ時間がたったとき、星の時間のほうが少なく数えられる。

👀 まず見るところ

【条件文】部品は「対角線で折って重ねた」と「対角線の長さは13cm」。重なりは EB＝ED の二等辺三角形 → 底辺13cm、Eから下ろした垂線は対角線のまん中に届く。あとは高さを相似で出す。

  • 折り返した角は、もとの角と同じ大きさ。辺ADと辺BCは平行なので、重なりの三角形は2つの角が等しくなる。
  • 二等辺三角形の頂点から底辺に下ろした垂線は、底辺をちょうど半分に分ける。

🔍 整理して解く

  1. 長方形ABCDを対角線BDで折る。Cが動いた先をC′、BC′とADが交わる点をEとする。重なりは三角形EBD。Eから対角線に垂線EFを下ろす。

【条件文】部品は「直角三角形」。正十二角形の頂点は1つの円の上にある。直角三角形は円の直径を1辺にもつと直して書く → 直径の本数×残りの頂点の数。

📚 前提知識

  • 円の直径を1辺にして、円の上にもう1点をとる。その点の角は、いつも90°になる。
  • 反対に、円の上の3点でできる直角三角形の長い辺（斜辺）は、いつも直径。

🔍 整理して解く

  1. 直径になる対角線を数える。AG、BH、CI、DJ、EK、FLの6本。
  2. AGを辺にする三角形は、残りの10個の頂点のどれを選んでもよい。10通り。
  3. ほかの直径も同じ。10×6＝60通り。
  4. 1つの直角三角形に直径は1本だけ。だから同じ三角形を2回数えていない。
答え：60通り

4 (3) 正十二角形の頂点でできる鋭角三角形 5点｜場合の数（辺の数で分ける）

👀 まず見るところ

【条件文】部品は「最も大きい角の大きさが90°未満」。頂点の間にある正十二角形の辺の数を3つ書く（直して書く）→ 辺6本分が直角だから、3つとも6より小さい組だけを数える。

📚 前提知識

  • 正十二角形の辺1本分の弧に向かい合う角は、180÷12＝15°。辺4本分なら60°、辺6本分なら90°。
  • 3つの辺の数をたすと、いつも12になる。12個の辺を3つに分けているから。

🔍 整理して解く

  1. 和が12で、どれも5以下の組を書き出す。（5,5,2）（5,4,3）（4,4,4）の3つ。（6をふくむと直角、7以上だと鈍角になる。）
  2. （5,2,5）はAFHの形。回すと頂点ごとに1つずつ、12通り。
  3. （3,4,5）はADHの形。うら返したAJFの形もあるので、12＋12＝24通り。
  4. （4,4,4）は正三角形。(1)より4通り。
  5. 全部で 12＋24＋4＝40通り。
  6. たしかめ。三角形は全部で220通り。直角60、鋭角40、鈍角120。60＋40＋120＝220。
答え：40通り
コツ：正多角形の頂点で作る三角形は、角度でなく「間の辺の数」で書く。角の大きさは、向かい合う辺の数×15°で出る。

5 (1) 三角すいOPBQと三角すいOABCの体積比 5点｜立体の体積比

👀 まず見るところ

【条件文】部品は「OP：PA＝3：1」と「OQ：QC＝1：1」。OAとOCを同じ長さ4にそろえて、OP＝3、OQ＝2と辺に書く（図に置く）→ Oから出る3本の辺の長さの比で体積の比が出る。

📚 前提知識

  • 頂点Oが共通で、Oから出る3本の辺が重なっている三角すいどうし。体積の比は（3本の辺の長さのかけ算）の比になる。
  • たとえば、3本とも半分にすると、体積は 1/2×1/2×1/2＝1/8。

🔍 整理して解く

  1. 正四角すいなので、OA＝OB＝OC。どれも4とする。OP＝3、OB＝4、OQ＝2。
  2. 体積の比を式にする。 
    OPBQ：OABC ＝ (3×4×2)：(4×4×4)
            ＝ 24：64 ＝ 3：8
  3. 三角すいOPBQは、三角すいOABCの3/8倍。
  4. 落としやすい所は、OBの長さ。OBは切っていないので、そのまま4を使う。
答え：3/8倍

5 (2)考え方・答え OE：EH（考え方も書く） 8点（考え方6点・答え2点）｜相似（平行線）

👀 まず見るところ

【条件文】部品は「直線OHと直線PQが交わる点をE」。O・P・Q・Hは全部、三角形OACの上にある。平面OACで切った三角形を平らに描く（図に置く）→ QとHがどちらも真ん中の点なので、QHがOAと平行になる。

📚 前提知識

  • Hは正方形ABCDの対角線の交点。だから対角線ACの真ん中。
  • 三角形の2つの辺の真ん中どうしを結ぶと、のこりの辺と平行で、長さは半分になる。
  • 平行な2本の線をはさむ「ちょうちょ形」の2つの三角形は相似。

🔍 整理して解く

  1. 三角形OACを描き、OA＝OC＝4として、OP＝3、PA＝1、OQ＝QC＝2を書きこむ。
  2. 三角形OACで、QはOCの真ん中、HはACの真ん中。だからQHはOAと平行。QH＝4×1/2＝2。
  3. OPとHQは平行。三角形OPEと三角形HQEは、ちょうちょ形の相似。
  4. 相似比は OP：HQ＝3：2。だから OE：EH＝3：2。
答え：3：2（考え方は解説を参照）
コツ：考え方らんには、①平面OACで切った図 ②QHがOAと平行で長さ2になる理由 ③相似な三角形OPEとHQE ④相似比3：2、の4つを順に書く。図に長さの比を書きこむと、説明が短くすむ。

5 (3) 平面PBQと辺ODの交点R 5点｜立体の切断（相似）

👀 まず見るところ

【条件文】部品は「3点P，B，Qを通る平面」と「辺ODとの交点をR」。平面PBQは直線PQの上の点E（(2)）も通る。平面OBDで切った三角形を描き、BからEを通る直線をのばす（図に置く）→ その線とODの交点がR。

  • 相似の組が見えないときは、平行な線を1本足して「ちょうちょ形」を作る。

🔍 整理して解く

  1. 三角形OBDを描く。HはBDの真ん中。OH上に、(2)のOE：EH＝3：2を書く。

  5. 三角形SROと三角形BRDも、ちょうちょ形の相似。相似比はSO：BD＝3：4。だから OR：RD＝3：4。

3〜5 まとめ

  • 仕切りの水そうは、部屋ごとの容積を書き、どの部屋から満水になるかを時間の表にする。こさは「物質の重さ」で追う。

6 (1) 旧暦の7月28日は新暦の何月何日 5点｜暦（通し番号）

👀 まず見るところ

【条件文】部品は「5日間で1週」と「4週で次の月」。5×4＝20を「新暦は1か月20日」に直して書く → 旧暦の日付を1月1日からの通し番号にして、20でわれば決まる。

📚 前提知識

  • 旧暦（今のカレンダー）の各月の日数。1年365日なので2月は28日。1・3・5・7・8・10・12月が31日、4・6・9・11月が30日。

🔍 整理して解く

  1. 旧暦の7月28日が、1月1日から数えて何日目かを出す。1〜6月の日数をたし、7月の28日をたす。 
    31＋28＋31＋30＋31＋30＋28＝209（日目）
  2. 209を20でわる。

  3. 10か月分（1〜10月）が終わって、9日目。だから新暦の11月9日。
  4. 落としやすい所は、あまりの9を見て「10月9日」としてしまうこと。わった答えの10は「終わった月の数」なので、その次の月になる。

6 (2) 新暦で月と日の積が90の日を旧暦に 5点（完答）｜暦（書き出し）

👀 まず見るところ

【条件文】部品は「月と日の積が90」と「すべて」。新暦の日は1〜20日、月は365÷20から19月まで、と範囲を書く → かけて90になる組をその範囲で全部書き出せば決まる。

📚 前提知識

    90 ＝ 5×18 ＝ 6×15 ＝ 9×10 ＝ 10×9 ＝ 15×6 ＝ 18×5
    1×90、2×45、3×30 は日が20をこえるので使えない。30×3、45×2、90×1 は月が19をこえる。全部で6回。
  2. それぞれを通し番号にする。新暦の5月18日なら 20×4＋18＝98日目。
  3. 通し番号から旧暦の月の日数を順に引いていく。98−31−28−31＝8。3月までを引いて8日残るので、旧暦の4月8日。

    新暦通し番号旧暦の月の日数を引く旧暦
    5月18日20×4＋18＝9898−31−28−31＝84月8日
    6月15日20×5＋15＝115115−31−28−31＝254月25日
    9月10日20×8＋10＝170170−31−28−31−30−31＝196月19日
    10月9日20×9＋9＝189189−31−28−31−30−31−30＝87月8日
    15月6日20×14＋6＝286286−31−28−31−30−31−30−31−31−30＝1310月13日
    18月5日20×17＋5＝345345−（1〜11月の日数334）＝1112月11日
    引いた残りが、次の月の日数より小さくなったら止める。
  5. 落としやすい所は、新暦に13月〜19月があることを忘れて、15月6日と18月5日を書き落とすこと。完答なので、1つ落とすと点にならない。

6 (3) どの月にも祝日がある「各位の数の和」 5点｜暦（いちばん苦しい月から決める）

👀 まず見るところ

【条件文】部品は「月と日の各位の数の和」と「月に1回以上」。19月は5日までしかない → 19月で作れる和から候補を出し、和が大きくなりにくい1月・10月で残りを消せば決まる。

📚 前提知識

  • 「各位の数の和」は、月と日を数字ごとにばらしてたしたもの。たとえば12月11日なら 1＋2＋1＋1＝5。
  • 「どの月にも」と言われたら、いちばん条件がきびしい月から調べる。そこで候補がぐっと少なくなる。

🔍 整理して解く

  1. 19月は1日〜5日だけ。作れる和を書き出す。
    19月の日1日2日3日4日5日
    各位の数の和1＋9＋1＝111＋9＋2＝121＋9＋3＝131＋9＋4＝141＋9＋5＝15
    19月に祝日があるには、決める数は11〜15のどれか。
  2. 次に、和が大きくなりにくい1月を見る。日は1〜20日なので、日の各位の数の和がいちばん大きいのは19日の 1＋9＝10。1月の和は最大で 1＋1＋9＝11。
  3. 10月も月の各位の数の和は 1＋0＝1 で、1月と同じ。最大は10月19日の11。
  4. 12〜15にすると、1月と10月に祝日が1回もない。だから決める数は11だけ。
  5. 確かめ。11にすると、どの月にもある。2月なら9日（2＋9＝11）、9月なら2日、18月なら2日、19月なら1日。落としやすい所は、19月が5日までしかないことを見落とすこと。
答え：11
