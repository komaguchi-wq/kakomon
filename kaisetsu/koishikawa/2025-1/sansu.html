1 (1) 45−2÷(125＋25/4)×(45×45＋15×15)＝10 5/□ A・4点｜四則計算

👀 まず見るところ

【条件文】部品は「(125＋25/4)」と答えの形「10 5/□」。かっこの中を先に出し、÷は「逆数をかける」に直して書く → 2250 と約分でき、□は分母と決まる。

📚 前提知識

  • 計算の順は「かっこの中 → ×と÷ → ＋と−」。45−2÷… は、45−2 を先にしない。
  • 分数でわるのは、逆数をかけるのと同じ。2÷525/4 は 2×4/525。

🔍 整理して解く

  1. 1つめのかっこ。125＋25/4＝500/4＋25/4＝525/4。
  2. 2つめのかっこ。45×45＝2025、15×15＝225。たして 2250。
  3. かけ算とわり算をまとめる。2×4/525×2250＝240/7。
  4. 45−240/7＝315/7−240/7＝75/7＝10 5/7。だから □＝7。
  5. 落としやすい所。答えは「10 5/7」でなく、□に入る 7 だけを書く。
答え：7

👀 まず見るところ

【条件文】部品は「500gの食塩水」「容器Cの食塩水300g」「5.75%」。最後の食塩水800gの食塩の重さを出す → Cの分をひけば、A・Bを混ぜた500gの濃さが決まる。

【条件文】部品は「直線ACと直線BDの交点をP」「直線CHと直線GDの交点をQ」。どちらも面の対角線の交点＝面のまん中と直して書く → 6つの面のまん中を結ぶと、PQを1辺とする正八面体になる。

📚 前提知識

  • 正八面体は、同じ四角すいを2つ、底どうしで重ねた形。

6 (2)考え方・答え 32段目に並ぶ1の個数 A/B・考え方6点＋答え2点｜数列（きまりを見つける）

👀 まず見るところ

【条件文】部品は「32段目」と「考え方も含めて」。9段目までの図で、1だけが並ぶ段（1・2・4・8段目）に丸をつける → 2倍ずつ出てくると分かり、32段目もその仲間と決まる。

📚 前提知識

  • 並べ方のきまり。両はしはいつも1。それ以外は、すぐ上の左と右の2つを見る。同じ数（1と1、0と0）なら0。ちがう数（1と0）なら1。
  • たとえば4段目「1 1 1 1」の下は、真ん中がどれも「1と1」なので0。5段目は「1 0 0 0 1」になる。

🔍 整理して解く

  1. 図から、1だけが並ぶ段を書き出す。
    1だけが並ぶ段1段目2段目4段目8段目
    1の個数1個2個4個8個
  2. 段の番号が、1→2→4→8と2倍ずつふえている。このあとも 8×2＝16段目、16×2＝32段目と続く。
  3. なぜ続くのか。8段目が全部1だと、9段目は両はしの1以外が0になる。そこから9〜16段目は、1〜8段目と同じ形が左右に2つ並ぶ。だから16段目は8段目が2つで、全部1になる。32段目も同じ。
  4. 32段目は全部1。並ぶ数の個数は段の番号と同じなので、1は32個。
  5. 落としやすい所は、考え方を答えだけで終えること。「1だけの段が1, 2, 4, 8段目と2倍ずつ現れる。だから32段目も1だけ」と書く。
考え方（解答一覧は「解説を参照」）：両はしは1、上の2つが同じなら0、ちがえば1になる。1だけが並ぶ段は1段目、2段目、4段目、8段目と2倍ずつ現れるので、16段目、32段目も1だけが並ぶ。32段目には数が32個並ぶので、1は32個。
答え：32個
