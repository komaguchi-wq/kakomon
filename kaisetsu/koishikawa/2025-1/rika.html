2 問1 0℃のまま温度が変わらない理由 A・3点｜記述・状態変化と熱

👀 まず見るところ

【条件文】部品は「「放出」「吸収」のうち」と書き出し「水が氷に変わるとき，」。冷やされて熱をうばわれているのに温度が下がらない → 水が氷になりながら熱を出している、と矢印で書く → 「放出」が決まる。

📚 前提知識

  • 水が氷に変わるときは、まわりに熱を放出する。氷が水に変わるときは、まわりから熱を吸収する。
  • そのため、水が氷に変化している間は、冷やし続けても温度がほとんど変わらない。

✍️ 答案の組み立て

  1. 要素1: 書き出し「水が氷に変わるとき，」に続けて、熱の向き＝まわりに熱を放出している。
  2. 要素2: 文末は「なぜですか」に合わせて「〜から。」で結ぶ。
模範解答：（水が氷に変わるとき，）まわりに熱を放出しているから。

2 問2 20℃の水に0℃の氷を入れたあとの温度 A・3点｜熱量の計算

👀 まず見るところ

【条件文】部品は「20℃の水100g」「0℃の氷20g」と「80カロリー」。水が0℃まで下がるときに出せる熱と、氷をとかすのに使う熱を、カロリーに直して並べて書く → 残りの熱で120gの水を温める計算が決まる。

📚 前提知識

  • 熱量（カロリー）＝重さ（g）×温度の変化（℃）。0℃の氷1gを0℃の水にするには80カロリー（問題文の条件）。

🔍 こう読み解く

  1. 20℃の水100gが持つ熱量（0℃を基準）: 100×20＝2000カロリー。
  2. 0℃の氷20gをすべて水にする熱量: 80×20＝1600カロリー。
  3. 残りは 2000−1600＝400カロリー。これで0℃の水 100＋20＝120gを温める。
  4. 400÷120＝3.333… → 小数第3位を四捨五入して3.33℃。落としやすい所: 400÷100として4℃にすること。とけた氷20gも水になって一緒に温まる。
答え：3.33℃

2 問3 状態変化で温度が変わる現象 B・2点（完答）｜状態変化と熱

👀 まず見るところ

【素材文】部品は「温度が変わる原因が物質の状態変化」と「すべて選び」。ア〜オそれぞれ「何が・何から・何に」を3語で書く → 液体→気体の変化があるイ・エだけが残る。

🔍 こう読み解く

  1. イ: 手についたアルコールが液体→気体になり、手から熱をうばう → ○。
  2. エ: 湿球のガーゼの水が液体→気体になり、熱をうばうので低い値になる → ○。
  3. ア: カイロの中の鉄粉が空気中の酸素と結びついて熱が出る → ×。ウ: 電流のはたらき → ×。オ: 手から鉄棒へ熱が移る → ×。落としやすい所: オの「冷たく感じる」をイと同じにすること。オは何も状態が変わっていない。

2 問4① 室内を冷やすときの冷媒の状態 B・2点｜資料（循環図）

👀 まず見るところ

【資料問題】部品は凡例の黒い矢印＝液体・白い矢印＝気体と本文「圧縮機…状態変化はさせないまま」。圧縮機・膨張弁の前後で矢印の色が変わるウ・エを先に消す → 残りは室内機で「液体→気体（熱を吸収）」のほうと決まる。

📚 前提知識

  • 水が水蒸気に変わるときと同じように、冷媒も液体から気体に変わるときにまわりから熱を吸収する。気体から液体のときは熱を放出する。

🔍 こう読み解く

  1. 本文より、圧縮機と膨張弁では状態が変わらない → 入る矢印と出る矢印は同じ色。ウ（圧縮機に白で入り黒で出る）とエ（圧縮機に黒で入り白で出る）は×。
  2. 室内を冷やすには、室内機で冷媒が部屋のあたたかい空気から熱を吸収する → 室内機に液体で入り、気体で出る。
  3. イ: 膨張弁→室内機が黒（液体）、室内機→圧縮機が白（気体）→ ○。アは室内機に白で入り黒で出る＝熱を放出するので、部屋があたたまる → ×。
答え：イ

2 問4② 膨張弁での冷媒の温度とその理由 B・4点（完答）｜記述・熱の移動

👀 まず見るところ

【条件文】部品は「圧縮機では…温度だけ変化」と「膨張弁ではその逆の反応」。圧縮で上がる温度の逆＝膨張で下がる、と書きかえる → Bの「熱が高温のものから低温のものへうつる」につなげれば理由が決まる。

📚 前提知識

  • ふつう液体や気体は、圧縮されると温度が上がり、膨張すると温度が下がる。
  • 熱は高温のものから低温のものへ移る。冷媒の温度が低いほど、部屋の空気から熱を吸収しやすい。

✍️ 答案の組み立て

  1. 記号: 膨張弁では冷媒を膨張させる → 温度が下がる → イ。
  2. 理由の要素1: 膨張弁で冷媒の温度を下げる。
  3. 理由の要素2: そのことで、室内機で部屋の空気からより効率よく熱を吸収できる。問題文の「より効率よく部屋を冷やす」に答える形で結ぶ。
模範解答：記号 イ　説明（例）膨張弁で冷媒の温度を下げることで，室内機においてより効率よく部屋の空気から熱を吸収できるから。

  4. アが新月（H）。ア→イ→ウ→エと進むと、形はH→A→B→C（右が大きく光り、左が少し欠けた形）。
