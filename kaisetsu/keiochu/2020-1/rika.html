1 (1)(2) ナツミカンにかける物質と、できる物質 A・2点×2｜穴うめ・中和

👀 まず見るところ

【素材文】部品は手がかりの言葉「すっぱい味の成分がそれと反応して少なくなる」と「泡が出る」に丸 → 酸性を打ち消し、しかも気体が出る物質＝重そう、気体＝二酸化炭素と決まる。

📚 前提知識

  • すっぱい味の成分は酸性（ナツミカンはクエン酸など）。アルカリ性のものを加えると、たがいの性質を打ち消し合う＝中和。
  • 重そう（炭酸水素ナトリウム）は弱いアルカリ性。酸性のものと反応すると二酸化炭素が出る。ふくらし粉にも使われる。

🔍 こう読み解く

  1. (1) 酸味をおさえる＝酸性を中和する → アルカリ性のものをさがす。クエン酸と酢は酸性、食塩は中性、片栗粉はデンプンなので外れる。
  2. 残るのは重そうと消石灰。あとの会話の「泡が出る」＝気体が出る、に合うのは重そう（3）。消石灰は酸性のものと中和しても気体は出ない。
  3. (2) シュワシュワの泡＝重そうが酸性の果汁と反応して出る気体 → 二酸化炭素（5）。
  4. 落としやすい所: (1)で「すっぱい」につられてクエン酸を選ぶこと。クエン酸はナツミカンの側に入っている成分。
答え：(1) 3　(2) 5

【まざり型→資料問題】部品は「60℃のときの方が水に溶ける量が少なくなる」と答え方「物質の数」。40℃と60℃のたて線をなぞり（図に置く）、その間で右下がりの線に印をつける → 3本と決まる。下がり方がわずかな線があるので、時間が無ければ後回し。

📚 前提知識

  • 固体は温度が高いほどよく溶けるものが多いが、温度が上がると溶ける量が減る物質もある。グラフが右下がりになっている所がそれにあたる。

🔍 こう読み解く

  1. 見るのは40℃と60℃の2点だけ。線の全体の形（0℃から100℃で上がったか）で決めない。
  2. はっきり下がっているのはH（40℃で約36g → 60℃で約32g）。
  3. D（約82g → 約81g）とG（約33g → 約32g）もわずかに下がっている。合わせてD・G・Hの3つ。
  4. 落としやすい所：Dは40℃と60℃の間に山のてっぺんがあり、ほぼ同じ高さに見える。2点の高さを方眼で比べて決める。
答え：3

4 (1)イ 20℃では溶かせないが80℃なら溶かせる物質の数 A・2点｜水の量をそろえる・数える

👀 まず見るところ

【まざり型→条件文】部品は「50gの水に30g以上」。グラフは100gの水の話なので、「100gの水に60g以上」に直して書く → 60gの横線より、20℃では下・80℃では上にある線を数えれば決まる。

📚 前提知識

  • 溶ける量は水の量に比例する。水が50g → 100gと2倍になれば、溶ける量も2倍になる。

🔍 こう読み解く

  1. グラフの60gの所に横線を引く。
  2. 20℃で60gより上にある線（BとD）は、20℃でも溶かせるので外れる。
  3. 残りのうち、80℃で60g以上になっているのはA（20℃で約7g → 80℃で約70g）とC（約37g → 約66g）の2つ。E・F・G・Hは80℃でも60gに届かない。
  4. 落としやすい所：30gの横線で数えてしまうこと。水50gの数字は、先に2倍してからグラフに当てる。
答え：2

4 (1)ウ 20℃と80℃の溶ける量の差が20gより小さい物質の数 B・2点｜グラフの読み取り・数える

👀 まず見るところ

【まざり型→条件文】部品は「20℃のときと80℃のとき」と「差が20gより小さい」。20gは縦軸の10の目盛り2つ分の高さに直して図に置く → 2点の高さのちがいがそれより小さい線を数える。イでA・Cが分かっていれば手を付ける。

📚 前提知識

  • 線のかたむきが急なほど、温度による溶ける量の変化が大きい。ほぼ横ばいの線は差が小さいので、数字を読まなくても決められる。

🔍 こう読み解く

  1. イで読んだ数字を使う。Aは70−7＝63g、Cは66−37＝29g。どちらも20gより大きいので外れる。
  2. きわどいのはF。20℃で約5g、80℃で約24g → 24−5＝19gで、20gより小さい。
  3. B・D・E・G・Hは、20℃と80℃の点の高さのちがいが目盛り2つ分（20g）にとどかない。
  4. 当てはまるのはA・C以外の6つ。
答え：6

4 (1)エ 60℃の溶ける量が0℃の2倍以上になる物質の数 B・2点｜グラフの読み取り・数える

👀 まず見るところ

【まざり型→条件文】部品は「0℃のときに溶ける量の2倍以上」。0℃の値を2倍した数を左はしに書き（直して書く）、60℃の値と比べる → 3本と決まる。「水の量が同じ」なのでグラフの数字のまま比べてよい。きわどいCとHだけ数字を読む。

📚 前提知識

  • このグラフはどの物質も水100gで調べた結果。水の量がそろっているので、0℃と60℃の点の高さをそのまま比べれば何倍かが分かる。

🔍 こう読み解く

  1. AとFは0℃でごくわずかしか溶けず、60℃ではその何倍にもなっている → 当てはまる。
  2. B・D・E・Gは0℃と60℃の高さが近く、2倍にはとどかない → 外れる。
  3. Cは0℃で約29g、60℃で約56g。29×2＝58gにとどかないので外れる。
  4. Hは0℃で約14g、60℃で約32g。14×2＝28g以上なので当てはまる。合わせてA・F・Hの3つ。
答え：3

4 (1)オ 80℃で溶かして20℃に冷やしても固体が出ない物質の数 B・2点｜水の量をそろえる・数える

👀 まず見るところ

【まざり型→条件文】部品は「50gの水」「物質10g」と「固体が出てこない」。水100gに20gの話に直して書く → 20℃のたて線の上で、20g以上の所を通る線を数えれば決まる。イと同じ直し方なので、イが解けたら手を付ける。

📚 前提知識

  • 冷やして固体が出てくるのは、溶かした量がその温度で溶ける量をこえたとき。こえなければ、冷やしても全部溶けたまま。

🔍 こう読み解く

  1. 水50gに10g ＝ 水100gに10×2＝20g。
  2. 見るのは冷やした後の20℃。20℃で溶ける量が20g以上なら固体は出ない。
  3. 20℃で20gにとどかないのはA（約7g）とF（約5g）だけ。
  4. 固体が出ないのはA・F以外の6つ。
答え：6

4 (2) アンモニアの溶ける量を示す印の位置 A・2点｜単位を直す計算

👀 まず見るところ

【まざり型→条件文】部品は「約70リットル」と、ただし書きの「1リットルで約0.7g」。グラフの縦軸はgなので、0.7×70でgに直して書く → その高さにある印が答え。

📚 前提知識

  • グラフに点を打つときは、軸の単位（ここではg）にそろえてから打つ。気体は体積（リットル）で表されることが多いので、重さに直す一歩が入る。

🔍 こう読み解く

  1. 余白に式を書く：0.7×70＝49g。
  2. 印はどれも20℃のたて線の上にある。高さが49g（50の少し下）の印は◆2。
  3. 落としやすい所：「70」をそのまま縦軸に当てて◆1を選ぶこと。70はリットルで、gではない。
答え：2

4 (3) グラフが100℃までしか無い理由 A・2点｜知識問題

水はふつうの気圧（1気圧）のもとでは100℃でふっとうして気体（水蒸気）に変わる。100℃より高い温度の液体の水は無いので、物質を溶かして量を調べることができない。漢字指定なので「気体」または「水蒸気」と漢字で書く。
答え：気体(水蒸気)

4 まとめ グラフの読み取り 7問

  • 水が50gの文（イ・オ）は、量を2倍して100gの水の話に直してからグラフに当てる。
  • 数える問題は、線の形で決まるものを先に片づけ、きわどい線だけ数字を読む（ア＝DとG、ウ＝F、エ＝CとH）。
  • リットルで書かれた量は、ただし書きの数字でgに直してから印を選ぶ。
