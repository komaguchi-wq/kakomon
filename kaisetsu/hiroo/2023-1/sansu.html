2 (3) 10人の円卓で「はい」の最小と最大 B・6点｜論理（最大・最小）

👀 まず見るところ

【条件文】部品は「【正直者】が7人，【嘘つき者】が3人」と質問「両隣に【正直者】と【嘘つき者】が1人ずついますか？」。「はい」と言う人を「両隣が正・嘘の正直者」と「両隣が正・正か嘘・嘘の嘘つき者」に直して書く → 嘘つき者3人を「まとめる／ばらす」で人数が変わる。(2)の表ができていれば手を付ける価値がある。

📚 前提知識

  • この質問で「はい」と言うのは2種類。正直者で両隣が正・嘘の人。嘘つき者で両隣が正・正か嘘・嘘の人（本当は「いいえ」だから）。

  4. ほかの分かれ方も確かめる。終わりの条件は「3通りの分かれ方×正直者1人だけの間があるかどうか」を全部書いたら終わり。

    3人まとまり123
    2人＋1人（間はどちらも2人以上）145
    2人＋1人（間に正直者1人だけの所がある）123
    1人ずつ（間はどれも2人以上）369

  • 「できる限り入れる」＝空きがちょうど埋まるまで入れる。小1個①で空き㊿なら50個。
  • 容器の中に残っている鉄球を数え忘れない。作業③で入れた小10個は、作業④でも中にある。

🔍 整理して解く

  1. 表に作業③④の行を足す。
    作業取り出してできた空き入れた体積あふれた水
    ③中15個＝㊺小10個＝⑩＋大10個⑮（①と同じ）
    ④大10個＝㊿小□個0（あふれない）
  2. 作業③: ⑩＋大10個−㊺＝⑮。大10個＝⑮＋㊺−⑩＝㊿。大1個＝⑤。
  3. 作業④: 空き㊿を小①で埋める。㊿÷①＝50個入る。
  4. 容器の中の小＝作業③の10個＋50個＝60個。
  5. 落としやすい所: 答えを50個にする。問いは「容器の中にある小の鉄球は全部で」。作業③で入れた10個が残っている。
答え：60個

3 (3) 作業⑤で入れた中と大の個数の組み合わせ B・6点｜整数の組を数える（表）

👀 まず見るところ

【条件文】部品は「作業②の1/3」と「それぞれ少なくとも1個」。作業⑤の行を「③×中＋⑤×大−60＝⑩」に直して書く → 3×中＋5×大＝70 の整数の組を表で数える問題に変わる。式が1本になれば数えるだけなので、手を付ける価値がある。

📚 前提知識

  • 3×中＋5×大＝70 の組は、大を1個ずつ増やして、残り（70−5×大）が3でわり切れるものを拾う。大2個なら残り60で中20個。
  • 大を3個増やすと 5×3＝15 減る。中は 15÷3＝5個減る。1組見つかれば「大＋3、中−5」でたどれる。

🔍 整理して解く

  1. 作業⑤: 小60個（60）を取り出す → 空き60。中a個と大b個を入れる。あふれ＝③×a＋⑤×b−60。
  2. あふれは作業②の㉚の1/3＝⑩。3×a＋5×b＝60＋10＝70。
  3. 大b を 1 から順に入れて、70−5×b が3でわり切れるものだけ残す。
    大 b12345…8…11…14
    70−5×b656055504530150
    中 a×20××151050 ×（中が0個）
    大は 2、5、8、11、14 と3個ずつ増える。大15個以上は 5×15＝75 で70をこえるので終わり。
  4. 大14個は中が0個で「少なくとも1個」に合わない。残りは（中, 大）＝(20, 2)(15, 5)(10, 8)(5, 11) の4通り。
  5. 落としやすい所: (0, 14) を数えて5通りにする。「それぞれ少なくとも1個」に丸をつけてから数える。
答え：4通り

👀 まず見るところ

  • 同じ形なら、短い辺：斜めの辺 がそろう。ED：EF＝FC：FB。

  1. (1) 図に数を置く。AD＝BC＝8cm なので AE＝AD−ED＝8−3＝5cm。EF＝AE＝5cm。BF＝AB＝10cm。

5 (2)① 2つの平面で切ったときの切断面の辺（作図） B・6点｜立体の切断（切り口の作図）

👀 まず見るところ

【条件文】部品は「3点D，I，Jを通る平面」と「点Hを含む立体」の切断面。決まり2つ（同じ面の2点は結ぶ／平行な面の切り口は平行）で D・I・J の切り口を図に置く → 四角形DIFJ。ACF の切り口と交わる線 P-F を足し、P-I 側を消せば完成。決まり通りに線を引くだけなので、手を付ける。

📚 前提知識

  • 同じ面にある2点は結ぶ。D と I は上の面、D と J は左の面（ADHE）。
  • 平行な面には平行な切り口。上の面の DI と平行な線を、下の面の J から引く。
  • 2つの平面で切るときは、両方の平面にある2点を結んだ線が、2つの切り口の交わる線になる。

🔍 整理して解く

  1. D と I（上の面）を結ぶ。J から DI と平行に引くと、ちょうど F に着く（I は BC の真ん中、J は EH の真ん中で、ずれ方が同じ）。D-J、I-F も結ぶ。切り口は四角形DIFJ（ひし形）。
  2. 三角形ACF の切り口と DIFJ は、上の面で AC と DI が交わる点 P と、共通の点 F の2か所で出会う。P-F を結ぶ。これが2つの切り口の交わる線。
  3. Hを含む立体に残る辺を実線にする: D-P、P-C、C-F、F-J、J-D、P-F。P-I の側（三角形PIF より B に近い側）は切り落とされる方なので、実線にしない。
答え：右の図（実線は D→P→C、C→F、F→J、J→D、P→F。P は上の面で AC と DI が交わる点）
