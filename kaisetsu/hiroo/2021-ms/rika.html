1 問1 単位[m/s²]がもつ意味 A・4点｜条件文・単位の読みかえ

👀 まず見るところ

【条件文】部品は「[m/s²]」と、本文の決まり「右上にある2という数字は『同じものをかけた回数』」。m÷(s×s)＝(m÷s)÷s に直して書く → 「速さ÷時間」と決まる。

📚 前提知識

  • 単位の「/」は割り算。本文のとおり、速さは移動距離を時間で割るので [m/s]＝距離÷時間。
  • 右上の2は、すぐ前の文字だけにつく。本文の [kg/m²] も「質量を面積で割って得られる量」で、[kg/m] 同士をかけたものではない、と書いてある。

🔍 こう読み解く

  1. [m/s²] の2は s だけについている → m÷(s×s)。
  2. 割り算を1回ずつに分ける: m÷s÷s。はじめの m÷s は速さなので、全体は速さ÷時間。
  3. 「速さ÷時間」＝単位時間（1秒）あたりに速さがどれだけ変わるか → ウ「時間経過で速さがどう変化するか」。
  4. ほかの選択肢を単位に直して確かめる。ア 速さ×速さ＝[m/s]×[m/s]で、mも2回かかる。イ 長さ÷時間＝[m/s]で、速さそのもの。エ 速さ×時間＝[m/s]×[s]＝[m]で、距離にもどる。
  5. 落としやすい所: 「2」を見てアの「2回かけた」に飛びつくこと。2回かかっているのは s だけで、m は1回。
答え：ウ

1 問2 電気の量を表す次元 B・4点｜条件文・次元の逆算

👀 まず見るところ

【条件文】部品は「単位時間あたりに導線の断面を通過する電気の量」と答え方「解答例と同じ形式」。「あたり」は ÷T に直して書く → 電流A＝電気の量÷T。式が1本で済むので手を付ける。逆算すれば電気の量が決まる。

📚 前提知識

  • 本文で、速さは「単位時間で移動できる距離」＝距離÷時間＝L/T。「単位時間あたり」は時間で割るという意味。
  • □÷T＝A なら □＝A×T（割り算の逆算）。距離＝速さ×時間 と同じ形。

🔍 こう読み解く

  1. 問題文の決め方を式にする: 電流＝電気の量÷時間 → A＝（電気の量）÷T。
  2. 逆算する: （電気の量）＝A×T。
  3. 解答例は「L×T，L/T」の形。同じように文字と×だけで A×T と書く。「必要な文字を用いて」なので、LとMは使わなくてよい。
  4. まちがえやすい形は A/T。「あたり」で割られるのは電気の量のほうで、電流ではない。式を書いてから逆算すれば防げる。
答え：A×T

1 問3 音の速さ・密度・圧力の次元 B・4点｜条件文・次元の約分

👀 まず見るところ

【条件文】部品は「密度[M/L³]」「圧力[M/(L×T²)]」と「速さ[L/T]」。3つとも分数に直して書く。速さにはMが無い → Mが消えるのは割り算だけ、と見えたら手を付ける。

📚 前提知識

  • 次元は文字の式と同じように約分できる（本文にも「単位同士が約分されるように打ち消し合う」とある）。分数の割り算は、割るほうをひっくり返してかける。
  • 問題の一文の「のみによって決まる」は、速さを密度と圧力だけの式で表せる、という意味。式の左と右で次元は同じになる。

🔍 こう読み解く

  1. 密度にも圧力にもMが1つずつある。かけるとM×Mが残るので、ウは合わない。割り算でMを消す。
  2. 圧力÷密度を計算する。L³＝L×L×L、T²＝T×T と書き直してから約分する。
  3. 残った (L×L)/(T×T) は L/T×L/T。L/T は速さなので、圧力÷密度＝速さ×速さ → オ。
  4. 5つを並べて確かめる。左と右の次元が同じになるのはオだけ。
    選択肢左の次元右の次元等しいか
    ア速さ L/T密度÷圧力 (T×T)/(L×L)×
    イ速さ L/T圧力÷密度 (L×L)/(T×T)×
    ウ速さ×速さ (L×L)/(T×T)密度×圧力（M×Mが残る）×
    エ速さ×速さ (L×L)/(T×T)密度÷圧力 (T×T)/(L×L)×
    オ速さ×速さ (L×L)/(T×T)圧力÷密度 (L×L)/(T×T)○
  5. イとオで迷いやすい。圧力÷密度はLもTも2回ずつ残るので、速さ1つ分ではなく速さ×速さになる。
答え：オ

1 問4 会話の中の科学的に不適切な推論 B・4点｜素材文・組み合わせを選ぶ

👀 まず見るところ

【素材文】設問は「科学的に不適切な推論」。①〜④の手がかりの言葉に丸: ①「15分」③「500[m]」は知っている事実、②「近い」④「時間がかかる」は相手と比べた推論。印をつけるだけなので手を付ける → 時間と距離を直接比べた発言が答え。

📚 前提知識

  • 本文の決まり: 「違う単位のもの同士の値を比べることに意味がない」。時間（T）と距離（L）は次元がちがうので、そのままでは比べられない。
  • 時間と距離をつなぐには歩く速さがいる。会話のあとの本文にあるとおり、Aさんは自分の歩く速さで換算しているが、速く歩く人も遅く歩く人もいるので、相手にはあてはまらない。

🔍 こう読み解く

  1. ①〜④を「何の量の話か」「事実か推論か」で分ける。
    番号発言量事実か推論か
    ①B「歩いてだいたい15分くらい」時間自分のことを言った事実
    ②A「私の家のほうが最寄り駅まで近い」距離Bの「時間」から距離を比べた推論
    ③A「家から駅まで500[m]くらい」距離自分で測った事実
    ④B「私よりも時間がかかる」時間Aの「距離」から時間を比べた推論
  2. ②: Bさんは「でも距離は知らない」と言っている。Aさんが知っているのはBさんの「15分」だけで、時間を聞いて距離の遠い近いを決めている → 不適切。
  3. ④: Bさんは「500[m]」という距離を聞いて、自分の「15分」という時間と比べている。②と同じ形 → 不適切。
  4. ①と③は推論ではなく、知っていること・測ったことを言っただけ。不適切なのは②と④ → ケ。
答え：ケ

2 問1 リチウムイオン電池は環境問題の解決にどう役立つか A・3点｜記述

👀 まず見るところ

【素材文】部品は設問の「環境問題の解決にどう貢献」と、本文のはじめの「繰り返し充電可能」に丸。充電できる＝電気をためておける。「何の電気をためると環境によいか」を1つ書けば答えになる。

📚 前提知識

  • 火力発電は化石燃料を燃やすので、大量の二酸化炭素が出る。風力発電や太陽光発電は自然エネルギーを使うので、環境をこわしにくい。
  • ただし自然エネルギーは、安定して電気を得ることが難しい。発電してあまった電気を電池にためておけば、安定して使えるようになる。

✍️ 答案の組み立て

  1. 要素A（何の電気か）: 自然エネルギー（風力・太陽光）から得た電気。
  2. 要素B（電池が何をするか）: その電気をためる。
  3. 「1つ簡潔に」なので、AとBを1文でつなぐだけでよい。解答一覧は（例）の形で、書き方は1つに決まっていない。落としやすい所は、「環境にやさしいから」のように電池のはたらき（ためる）が入っていない答え。設問は「どう貢献」と聞いている。
模範解答：自然エネルギーから得た電気をためる。

答え：カ

4 問2 空気のかたまりが上昇する場面 B・3点｜一言の記述

👀 まず見るところ

【素材文】部品は聞き方「空気のかたまりが上昇する」「状況を1つ」に丸 → 空気が上に動く場面を1つ、短い言葉で書けばよい。山・熱せられた地面のどれか1つを言えるなら手を付ける。

📚 前提知識

  • 空気は上昇すると、上空は気圧が低いので体積が大きくなり、温度が下がる。露点以下になると水蒸気が水の粒になる（父の説明）。だから雲ができるには上昇が条件になる。
  • 空気が上昇する代表的な場面は、風が山の斜面にぶつかる所、地面や海面が強く熱せられた所、暖かい空気が冷たい空気の上にはい上がる前線。

🔍 こう読み解く

  1. 下線部②は「色んな理由で」と書いている。理由は1つではないので、思いうかんだ場面を1つ選ぶ。
  2. 空気のかたまりが風となって山に当たると、斜面にそうように上昇する → 「山にぶつかる」（解答一覧の例）。
  3. 声教の解説はもう1つ、地面や海水面が強く熱せられる場面も挙げている。その上の空気がぼう張して周りより軽くなり、上昇する。
  4. 解答らんは1行。「何が・どうなる」を短く書く。
答え：（例）山にぶつかる

4 問3①②③④ お湯と線香の実験の考察（A・Bの語と色） B・2点×2／A・2点×2｜考察の穴うめ

👀 まず見るところ

【素材文】部品は考察の「になって上昇し」と、線香を近づけたあとの「湯気が出た」に丸 → 上昇するBは目に見えない気体、白く見える湯気は液体の粒。A＝水、B＝水蒸気と決まれば、色もそのまま決まる。2語を入れるだけなので手を付ける。

📚 前提知識

  • 水蒸気は気体で、無色のとても細かい粒なので目に見えない。湯気は水蒸気が冷えてできた液体の水の粒で、白く見える。
  • 雲も湯気と同じで、水や氷の粒（理華のせりふ）。だからこの実験は雲のでき方と似ている。

🔍 こう読み解く

  1. 小問の番号を確かめる。アプリの①②は (1) のA・B、③④は (2) の①・②にあたる。
  2. 考察は「AがBになって上昇し、BがAになった」という行って帰る形。最初のAはコップのお湯＝水、お湯の表面から出て上昇するBは水蒸気。
  3. 水蒸気は肉眼で見えない → (2)①は無。お湯から離れて温度が下がり、線香の煙の粒子を中心にして水蒸気が液体の水の粒にもどると、白い湯気として見える → (2)②は白。
  4. 検算: 1枚目の写真（線香なし）では湯気がほとんど見えず、2枚目（線香あり）で湯気が見える。見えなかったもの＝水蒸気、見えたもの＝水の粒で話が合う。
  5. 落としやすい所は「湯気＝水蒸気」と考えること。見えるものは液体。考察の文は「[　]色の」と続くので、(2) は色の字をつけず「無」「白」と書く。
答え：(1) A 水　B 水蒸気　(2) ① 無　② 白

4 問3⑤ 煙の粒子のはたらき（会話文から抜き出し） A・3点｜抜き出し

👀 まず見るところ

【素材文】部品は聞き方「会話文の中から抜き出して」と考察の「煙の粒子が」に丸 → 会話文で、小さな粒が何かの役目をしている所をさがす。父の「空気中のちりが凝結核となって」で決まる。

📚 前提知識

  • 水蒸気が水の粒になるには、くっつく中心になる小さな粒がいる。この中心になる粒が凝結核。空気中のちりや煙の粒子がその役目をする。

🔍 こう読み解く

  1. 小問の番号を確かめる。アプリの⑤は (3) の［あ］にあたる。
  2. 父は実験のあとに「温度を変えなくてもきっかけがあれば雲ができる」と言っている。線香の煙がその「きっかけ」。
  3. 「きっかけ」の中身を会話文でさがす → 「空気中のちりが凝結核となって水滴づくりの中心になって」。煙の粒子はこの「ちり」と同じ役目をしている。
  4. 落としやすい所は「きっかけ」「ちり」と書くこと。役目に名前がついた語は凝結核。抜き出しなので、漢字3字を会話文のとおりに写す。
答え：凝結核

4 問4 不安定な大気での自由対流高度と雲頂高度 B・3点｜図の選択

👀 まず見るところ

【資料問題】部品は図の正体「点線は安定な大気における」高さ、聞かれ方「雲が発達しやすいとき」→ 2本の高度が点線より上か下かを1本ずつ決める。会話の定義2つを図の横に書ければ、知識がなくても決まる。

📚 前提知識

  • 自由対流高度＝「周りの空気より雲の空気のほうが暖かい」という条件になる高さ。ここより上では雲は軽いので勝手に上昇する（父の説明）。
  • 雲頂高度＝高いところで温度がそろってきて、浮力が重力よりも小さくなる高さ。雲のてっぺんにあたる。
  • 大気が不安定＝「上空に寒気があったり，地上付近に暖かい空気が入り込む」状況（父の説明）。

🔍 こう読み解く

  1. 4つの図を、点線とくらべて整理する。
    図雲頂高度自由対流高度2本の間
    ア点線より上点線より上―
    イ点線より下点線より上せまくなる
    ウ点線より上点線より下広がる
    エ点線より下点線より下―
  2. 不安定な大気は、上空が冷たいか、地上付近の空気が暖かい状態。どちらでも、上がる空気と周りの空気の温度差が大きい。「雲の空気のほうが暖かい」という条件が低い所から成り立つ → 自由対流高度は下がる。
  3. 温度差が大きいと、高く上がってもなかなか温度がそろわない → 雲頂高度は上がる。
  4. 自由対流高度が下がり、雲頂高度が上がる図はウ。声教の解説も、2本の間が安定な大気のときより縦長になって大きな積乱雲へ発達する、としている。
答え：ウ
コツ：「雲が発達しやすい」＝雲が育つ範囲（2本の間）が広い、と言いかえる。イはせまくなっているので先に消せる。

4 問6 写真から読み取る土砂災害の前兆 B・3点｜写真・一言の記述

👀 まず見るところ

【資料問題】部品は聞かれ方「土砂災害が発生する前兆」と、写真の正体を1行＝がけの下の道路と、そこを流れる水 → がけと水に目をつけ、水のようすを一言で書く。「前ぶれ＝水のにごり」を知っていれば手を付ける。

📚 前提知識

  • 大雨のとき、がけや山から出てくる水がにごるのは土砂災害の前ぶれ。水にまじっているのは、がけの中からけずり出された土砂。

🔍 こう読み解く

  1. 写真で土砂災害に関係するのは、奥のがけと、その下を流れる水の2つ。
  2. 声教の解説では、がけの下を流れる水が茶色ににごっている。降った雨水で、がけの中を流れる地下水に新たな流れができ、土砂が運ばれて流れ出たと考えられる。
  3. 土砂が出ていくと、地面やがけはやわらかくなり、くずれるおそれがある。だから「水がにごっている」が前兆になる。
答え：（例）水がにごっている。
コツ：紙面の写真は白黒なので、水の色は読み取れない。「がけの下の水のようす」に目をつけて「にごっている」と書けるかどうかが分かれ目。

4 まとめ 大問4でくり返し出た入口

  • 会話文の長い大問は、設問を先に見て「何が決まれば答えられるか」を決めてから読む。問3の抜き出しと問4は、答えの材料が父のせりふの中にある。
  • 水蒸気＝気体で見えない。湯気・雲＝液体の水（や氷）の粒で白く見える。水蒸気が水の粒になるには凝結核がいる。
  • 一言の記述（問2・問6）は、「空気が上がる場面」「水のようす」を短く書けば点になる。空らんにしない。
