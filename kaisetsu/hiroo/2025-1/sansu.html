1 (1) 分母がとなりどうしの数のかけ算になっている分数のたし算 A・5点｜分数の計算（引き算に直す）

👀 まず見るところ

【条件文】部品は分母の「2020×2021」。となりどうしの数のかけ算は「1/2020−1/2021」（2020分の1 ひく 2021分の1）に直して書く → とちゅうが消えて、はしだけ残る。

📚 前提知識

  • 分母がとなりどうしの数のかけ算なら、2つの分数の引き算に直せる。小さい数でためす。1/2−1/3＝3/6−2/6＝1/6。分母の6は 2×3 になっている。
  • 分母は1つだけでも 2020×2021＝4082420 で、400万をこえる。通分してたすのは大変。直してからたすほうが速い。

🔍 整理して解く

  1. はじめの5つの分数を、引き算に直して書く。 
    1/(2020×2021) ＝ 1/2020 − 1/2021
1/(2021×2022) ＝ 1/2021 − 1/2022
1/(2022×2023) ＝ 1/2022 − 1/2023
1/(2023×2024) ＝ 1/2023 − 1/2024
1/(2024×2025) ＝ 1/2024 − 1/2025
  2. 5つをたす。「−1/2021」と「＋1/2021」のように、同じ分数を引いてたす所が消える。残るのは 1/2020−1/2025。
  3. 最後の 1/2025 をたす。「−1/2025」と「＋1/2025」も消える。残りは 1/2020 だけ。
  4. 落としやすい所は、最後の 1/2025。これだけ形がちがう。引き算に直さないで、そのままたす。
答え：1/2020（2020分の1）

1 (2) 3.14をふくむ式の□を出す A・5点｜□をふくむ計算

👀 まず見るところ

【条件文】部品は左の「3.14×2」と右の「15.7×0.8」。15.7を 3.14×5 に直して書く → 両がわの3.14が消えて、かっこの中は2と決まる。

📚 前提知識

  • 15.7 は 3.14×5。3.14のかけ算は、3.14を残したままほかの数を先に計算する。3.14×5×0.8 なら 3.14×4。
  • □を出すときは、最後にした計算から順にもどす。引いた数はたす。わった数はかける。

🔍 整理して解く

  1. 右がわを直す。15.7×0.8＝3.14×5×0.8＝3.14×4。
  2. 左がわは 3.14×2×（かっこ）。両がわを3.14でわる。2×（かっこ）＝4。だからかっこの中は2。
  3. かっこの中は「□÷7/32（32分の7）から 2 3/7（2と7分の3）を引く」計算。引く前にもどす。 
    □÷7/32 ＝ 2＋2 3/7 ＝ 4 3/7
  4. 4 3/7（4と7分の3）を仮分数にする。4×7＋3＝31 で 31/7。わる前にもどす。 
    □ ＝ 31/7×7/32 ＝ 31/32
    7が約分で消えて 31/32。
  5. 落としやすい所は、もどす向き。2 3/7 を引いて2になった。だから、もどすときは2にたす。
答え：31/32（32分の31）

1 (3) 大小2個のさいころの目の積が偶数 A・5点｜場合の数（全体から引く）

👀 まず見るところ

【条件文】部品は「大小2個」と「積が偶数」に丸。偶数になる出方は種類が多い → 積が奇数になるほうを数えて、全部の36通りから引く。

📚 前提知識

  • かけ算の答えが奇数になるのは、奇数×奇数のときだけ。3×5＝15 は奇数。3×4＝12 は偶数。偶数が1つでも入ると、積は偶数になる。
  • 大小2個のさいころは、区別して数える。大が2で小が3と、大が3で小が2は、別の出方。全部で 6×6＝36通り。

🔍 整理して解く

  1. 全部の出方を数える。6×6＝36通り。
  2. 積が奇数になる出方を数える。大も小も奇数の目（1、3、5）のとき。3×3＝9通り。
    小が奇数（1、3、5）小が偶数（2、4、6）
    大が奇数（1、3、5）積は奇数　9通り積は偶数　9通り
    大が偶数（2、4、6）積は偶数　9通り積は偶数　9通り
  3. 全部から引く。36−9＝27通り。
  4. 落としやすい所は、偶数×偶数。表で見ると、偶数になるマスは3つある。9×3＝27 でも同じ答えになる。
答え：27通り

1 (4) 各位の和の5倍と、位の入れかえから2桁の数を決める A・5点｜数の性質（位の入れかえ）

👀 まず見るところ

【条件文】部品は「入れかえると、もとの数より18だけ大きく」。「一の位は十の位より2大きい」に直して書く → 当てはまる数は7個だけ。もう1つの「和を5倍すると、もとの数より5だけ大きく」で確かめる。

📚 前提知識

  • 十の位と一の位を入れかえると、差は「数字の差×9」になる。13と31の差は18。数字の差は 3−1＝2 で、2×9＝18。
  • 5をかけた数は、一の位が0か5になる。

🔍 整理して解く

  1. 入れかえの条件から見る。18÷9＝2。一の位は、十の位より2大きい。
  2. 当てはまる数を書き出す。13、24、35、46、57、68、79。一の位は9までなので、79で終わり。
  3. 7個の数で「各位の和×5」と「もとの数＋5」をくらべる。
    もとの数13243546576879
    各位の和×520304050607080
    もとの数＋518294051627384
  4. 下の2行が同じになるのは35だけ。たしかめ。3＋5＝8。8×5＝40。35＋5＝40。53−35＝18。
  5. 落としやすい所は、入れかえの向き。入れかえると大きくなるので、一の位のほうが大きい。答えは53でなく35。
答え：35
コツ：表を書かなくても決まる。「各位の和×5」は5の倍数。そこから5を引いたもとの数も5の倍数。7個のうち、一の位が0か5なのは35だけ。

1 (5) 辺が3cm、4cm、5cmの直角三角形の内側に接する円 A・5点｜平面図形（内側に接する円）

👀 まず見るところ

【条件文】部品は「AB＝5cm、BC＝4cm、AC＝3cm」と「内側に円が接して」。長さは図の辺に書きこむ。円の中心と3つの頂点を結ぶ → 半径を高さにした三角形3つに分かれて、半径が決まる。

📚 前提知識

  • 円が辺に接しているとき、中心から接している点に引いた半径は、辺と直角に交わる。だから半径は、その辺を底辺にした三角形の高さになる。
  • 三角形の面積は、底辺×高さ÷2。同じ三角形の面積を2通りの出し方で書くと、分からない長さが出る。

🔍 整理して解く

  1. 三角形ABCの面積を出す。直角をはさむ辺は4cmと3cm。4×3÷2＝6cm²。
  2. 円の中心と、A、B、Cを結ぶ。三角形が3つできる。底辺は5cm、4cm、3cm。高さはどれも円の半径（□cm）。
  3. 3つの面積をたす。 
    5×□÷2 ＋ 4×□÷2 ＋ 3×□÷2
＝（5＋4＋3）×□÷2
＝ 6×□
  4. これが、手順1で出した6cm²と同じ。6×□＝6。□＝1cm。
  5. 円の面積を出す。1×1×3.14＝3.14cm²。
  6. 落としやすい所は、答えるもの。聞かれているのは半径でなく、円の面積。
答え：3.14cm²
コツ：別の見方もある。角Cの所に、半径を1辺にした正方形ができる。1つの点から円に引いた2本の接する線は、同じ長さ。Aからは 3−□、Bからは 4−□。この2つをたすと辺ABの5cm。7−□×2＝5 で、□＝1。

1 (6) 四隅から1辺5cmの正方形を切り取って作る箱 A・5点｜立体図形（容積からもどす）

👀 まず見るところ

【条件文】部品は「1辺の長さが5cmの正方形を切り取り」と「容積が720cm³」。5cmは「箱の高さ」に直して図に書く → 720÷5 で底面積が出て、底の1辺が決まる。

📚 前提知識

  • 四隅を切って折り上げると、切り取った正方形の1辺が箱の高さになる。底は、点線でかこまれたまん中の正方形。
  • 直方体の容積は、底面積×高さ。だから底面積は、容積÷高さ。
  • 同じ数を2回かけて144になる数は12。10×10＝100、12×12＝144。

🔍 整理して解く

  1. 図に書きこむ。高さは5cm。底は1辺□cmの正方形。
  2. 底面積を出す。720÷5＝144cm²。
  3. □×□＝144。12×12＝144 なので、底の1辺は12cm。
  4. もとの紙の1辺は、底の1辺の両がわに5cmずつたした長さ。5＋12＋5＝22cm。
  5. 落としやすい所は、最後のたし算。5cmは右と左の両方にある。12＋5＝17 で止めない。

2 (2) 3桁の整数で、各位の積が3桁の奇数 B・6点｜場合の数（使える数字を決める）

👀 まず見るところ

【条件文】部品は「積」「3桁の奇数」に丸。奇数は「3つとも奇数の数字」に直して書く。1が入ると積は81以下 → 使える数字は3、5、7、9だけ。ここまで見えたら数え切れるので、手をつけてよい。

📚 前提知識

  • 積が奇数になるのは、かける数が全部奇数のとき。偶数や0が1つでも入ると、積は偶数になる。
  • いちばん大きい積は 9×9×9＝729。4桁にはならない。だから「3桁」は「100以上」だけ調べればよい。
  • 3つの数字のならべ方。3つとも同じなら1通り。2つが同じなら3通り。3つともちがえば6通り。たとえば 3・3・5 は 335、353、533 の3通り。

🔍 整理して解く

  1. 使える数字を決める。奇数の数字は1、3、5、7、9。1が入ると、積は残り2つの数字の積と同じ。大きくても 9×9＝81 で、100にとどかない。使えるのは3、5、7、9の4つ。
  2. この4つの数字で作る3桁の数を、全部数える。4×4×4＝64個。
  3. このうち、積が100より小さいものを数える。小さい数字の3が入る組から調べる。
    数字の組積ならべ方
    3・3・3271通り
    3・3・5453通り
    3・3・7633通り
    3・3・9813通り
    3・5・5753通り
    次に小さい 3・5・7 は105。3が入らない組は、いちばん小さい 5・5・5 でも125。ここで終わり。合わせて 1＋3×4＝13個。
  4. 全部から引く。64−13＝51個。
答え：51個
コツ：「100以上のもの」をじかに数えると、組が15種類ある。「100より小さいもの」は5種類だけ。少ないほうを数えて引く。

3 (2) 4つの頂点でつくる、体積がいちばん大きい立体 B・6点｜立方体から角を切り落とす

👀 まず見るところ

【条件文】部品は「異なる4点」「体積が最も大きく」に丸。4点を結ぶと三角すい → 「3点が同じ面にある形」と「どの面にも2点ずつの形」に分けて図に置き、体積をくらべる。2つの形がかけたら手を付ける。

📚 前提知識

  • 三角すいの体積は「底面積×高さ÷3」。底面が立方体の面の半分で、高さが1辺の三角すいは、立方体の 1/6（6分の1）。1辺6cmなら 18×6÷3＝36cm³ で、216cm³の1/6。
  • 4点が同じ平面にあると、立体にならない。たとえば A・B・C・D や、A・C・G・E。

🔍 整理して解く

  1. 1辺を6cmと決める。立方体の体積は 6×6×6＝216cm³。
  2. 3点が同じ面にある形を調べる。たとえば A・B・C と F。底面は三角形ABCで 6×6÷2＝18cm²。高さは6cm。体積は 18×6÷3＝36cm³。4点目を下の面のどの頂点にしても、高さは6cmのままで、体積は同じ。
  3. 3点が同じ面に来ない形をさがす。上の面でAとC（ななめ）を選ぶ。下の面では、AやCの真下ではないFとHを選ぶ。どの面にも2点ずつになる。
  4. 立体A・C・F・Hは、立方体から4つの角（B・D・E・Gのところ）を切り落とした形。角1つは手順2と同じ36cm³。216−36×4＝72cm³。立方体の 1/3（3分の1）で、36cm³より大きい。
  5. 同じ形は、上でBとD、下でEとGを選んだ B・D・E・G だけ。上の2点をとなりどうし（AとBなど）にすると、3点が同じ面にのるか、平らになる。上がAとCのときも、下にE（Aの真下）やG（Cの真下）を入れると、3点が同じ面にのるか、平らになる。だから2個。
答え：2個
コツ：体積が大きい立体は、辺でつながる頂点を1組も選ばない。Aを選んだら、B・D・Eは選べない。

3 (3) 2つの立体に共通している部分の体積 B・6点｜面の真ん中を結ぶ立体（正八面体）

👀 まず見るところ

【条件文】部品は「(2)で求めたすべての立体」「共通している部分」に丸。2つの立体の辺を同じ立方体に置く → どの面でも対角線2本が面の真ん中で交わる → その6つの点を結んだ立体の体積を出す。(2)の図があるときに手を付ける。

📚 前提知識

  • 正方形の対角線2本は、真ん中の点で交わる。
  • 対角線の長さが分かる正方形の面積は「対角線×対角線÷2」。対角線が6cmと6cmなら 6×6÷2＝18cm²。
  • 四角すいの体積は「底面積×高さ÷3」。

🔍 整理して解く

  1. (2)の2つの立体の辺を、同じ立方体にかく。A・C・F・Hの立体の辺は、6つの面の対角線。B・D・E・Gの立体の辺は、同じ面のもう1本の対角線。どの面でも、2本は真ん中で交わる。
  2. 交わる点は6つ。この6つの点は、どちらの立体にも入っている。A・C・F・Hの立体は、4つの角を相手の立体の面で切り落とされる。たとえばAの角は、B・D・Eを通る面で切られる。切り口は、上・前・左の面の真ん中を結ぶ三角形。残るのは、6つの面の真ん中の点を結んだ立体。
  3. 1辺を6cmとして体積を出す。真ん中の高さの正方形で、上下2つの四角すいに分ける。正方形の面積は 6×6÷2＝18cm²。
  4. 四角すい1つの高さは、立方体の高さの半分で3cm。体積は 18×3÷3＝18cm³。2つで 36cm³。
  5. 立方体は216cm³。36÷216＝1/6（6分の1）。
  6. たしかめ。(2)の立体は72cm³。切り落とす角は、辺の長さが半分の小さい三角すい。辺が半分になると、体積は 1/2×1/2×1/2＝1/8（8分の1）になる。72÷8＝9cm³。72−9×4＝36cm³。合っている。
答え：1/6倍（6分の1倍）
コツ：「重なる部分がない場合は0」とあるが、6つの面の真ん中の点はどちらの立体にも入るので、0にはならない。

4 (1) Aを70g入れるとAとBが等しくなる A・6点｜比（変わらないものはそのまま）

👀 まず見るところ

【条件文】部品は「Aを70g入れた」「A，Bの割合が等しく」。ふえたのはAだけ → Aが①から③になった、と直して書く → ②＝70g で①が決まる。「最初の液体全体」に丸。

4 (2) Aを200g、Bを何gか加えて 5：3：2 にする A・6点｜比（変わらないCにそろえる）

4 (3) 同じ液体Dを2回入れる。Dの中のA：B：C B・6点｜比（同じ量を2回→ふえ方が同じ）

5 (1) 「この箱には石が入っている」と書かれた箱A A・5点｜論理（真実か嘘か決まらない）

👀 まず見るところ

【条件文】部品は決まりの言葉「真実か嘘のどちらか」に丸。箱Aの文が真実のときと嘘のときの2通りを書く → 石が入っている場合も、入っていない場合もある → どちらか決められない。

📚 前提知識

  • 嘘は「真実を否定した内容」。「石が入っている」が嘘なら、本当は「石が入っていない」。

🔍 整理して解く

  1. 2通りを表に書く。
    箱Aの文箱Aの中
    真実石が入っている
    嘘石が入っていない
  2. 真実か嘘かを決める手がかりは、ほかに何もない。2通りとも残る。
  3. だから「入っているかどうかわからない」のウ。「最も正しいもの」を選ぶので、アやイのように言い切ったものは選べない。
答え：ウ

5 (2) 箱B「真実が書かれた箱は1つだけ」 B・5点｜論理（場合に分けて、合わないものを消す）

👀 まず見るところ

【条件文】部品は箱Bの「真実が書かれた箱は1つだけ」と「すべて選び」に丸。箱Bの文が真実のとき・嘘のときの2通りを表に置く → どちらでも箱Aの文は嘘に決まる。表が2行で終わるので手を付ける。

📚 前提知識

  • 「1つだけ」が嘘なら、真実の箱は0個か2個。箱は2つなので、1個でなければ0個か2個になる。
  • 箱の文と、真実の箱の数が合わない場合は起こらない。そういう場合を消していく。

🔍 整理して解く

  1. 箱Bの文が真実のとき。真実の箱は1つだけで、それは箱B。だから箱Aの文は嘘。
  2. 箱Bの文が嘘のとき。真実の箱は0個か2個。箱Bが嘘なので、2個にはならない。0個に決まり、箱Aの文も嘘。
    箱Bの文真実の箱の数箱Aの文箱Aの石
    真実1個（箱B）嘘入っていない
    嘘0個嘘入っていない
  3. どちらでも、箱Aの文「石が入っている」は嘘。箱Aには石が入っていない。イが正しい。
  4. 箱Bの石については、どの箱にも書かれていない。だから、わからない。カが正しい。
  5. 箱Aについて1つ、箱Bについて1つ選ぶ。2つとも合って正解になる。
答え：イ・カ
コツ：(1)では「わからない」だった箱Aが、箱Bの文が加わると「石が入っていない」に決まる。情報がふえたら、前の答えを見直す。

5 (3) 箱C「箱Aには宝も石も入っていない」 C・6点｜論理（4通りを調べて理由を書く）

👀 まず見るところ

本番では後回し。【条件文】部品は箱Cの「箱Aには宝も石も入っていない」。箱Aの中身を4通りに分けて表に置く → 箱Bの文と合う場合だけが残る。

📚 前提知識

  • 箱が3つになったので、(2)の結果は使わずに調べ直す。箱AとCの片方だけが真実だと、箱Bは真実でも嘘でも合わない。箱Bが真実なら、真実の箱が2つになる。箱Bが嘘なら、真実の箱が1つだけになり、箱Bの文が本当になってしまう。

🔍 整理して解く

  1. 箱Aの中身を4通りに分ける。箱Aの文と箱Cの文が、真実か嘘かを書く。
    箱Aの中身箱A「石が入っている」箱C「宝も石も入っていない」箱B「真実は1つだけ」
    宝も石も入っていない嘘真実合わない
    石だけ入っている真実嘘合わない
    宝だけ入っている嘘嘘真実でも嘘でも合う
    宝も石も入っている真実嘘合わない
  2. 残るのは「宝が入っていて、石は入っていない」だけ。このとき箱AもCも嘘。箱Bが真実なら、真実の箱は箱Bの1つだけで合う。箱Bが嘘なら、真実の箱は0個で、これも合う。
  3. 答案は、結果を1文で書く。理由は、4通りそれぞれに「箱AとCが真実か嘘か」と「箱Bと合うか」を書く。
答え：考えられる結果…箱Aには宝が入っていて，石は入っていない。
模範解答：理由…（例）「箱Aには宝も石も入っていない」とき，Aは嘘でCは真実だからBに矛盾する。「箱Aには石が入っていて，宝は入っていない」とき，Aは真実でCは嘘だからBに矛盾する。「箱Aには宝が入っていて，石は入っていない」とき，AもCも嘘だからBはどちらでもよい。「箱Aには宝も石も入っている」とき，Aは真実でCは嘘だからBに矛盾する。

3〜5 まとめ

  • 立方体の頂点を選ぶ問題は、結び方を「辺・面の対角線・中を通る対角線」に分ける。体積が大きい立体は、辺でつながる頂点を選ばない。
  • 比の問題は、加えていない液体の数をそろえる。gが分かる所は、先に重さに直して表に書く。
  • 真実か嘘かの問題は、2通りを表に書く。文と合わない場合を消して、残ったものが答えになる。
