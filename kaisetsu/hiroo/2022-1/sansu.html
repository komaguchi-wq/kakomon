👀 まず見るところ

【条件文】部品は「対角線BDを3等分する点」と「面積が120cm²」。BE・EF・FD に①①①を図に置く → AD∥BC の砂時計の相似で G・H は辺のまん中と決まり、五角形は △BCD から小さい三角形2つをひく形になる。「3等分」と「平行」がそろえば手を付ける。

  • 平行な2本の線にはさまれた砂時計の形は相似。向かい合う辺の比が同じになる。AD∥BC なら、△AED と △GEB は ED：EB の比で相似。
  • 角を1つ共有する三角形の面積比は、その角をはさむ2辺の比のかけ算。BG が BC の 1/2、BE が BD の 1/3 なら、△BGE は △BCD の 1/2×1/3＝1/6。

  4. △BGE は △BCD の 1/2×1/3＝1/6 だから、60÷6＝10。△DHF も DH が DC の 1/2、DF が DB の 1/3 なので 10。
  5. 60−10−10＝40。

【条件文】部品は「その操作番号と同じ番号の電球は点灯しているはず」と「18個」。前の文は「忘れた番号は平方数」に直して書く → 忘れなければ14個なので、4個ふえる平方数をさがすと決まる。(2) で「点灯＝平方数」と分かっていれば、表を書くだけで進む。

📚 前提知識

  • 操作を1つ忘れると、その番号の倍数の電球だけ、押される回数が1回へる。その電球は点灯と消灯が入れかわる。
  • 平方数に平方数をかけると平方数になる。25×4＝100＝10×10。25の倍数のうち平方数は、25×1・25×4・25×9 … の形だけ見ればよい。

🔍 整理して解く

  1. 忘れなかった場合を先に出す。200までの平方数は 1×1 から 14×14＝196 まで。点灯は14個。
  2. 「点灯しているはず」の電球は平方数の番号。忘れた操作番号も平方数で、1・4・9・16・25・… のどれかになる。
  3. 忘れた番号の倍数だけが入れかわる。倍数のうち平方数の電球は消える。平方数でない電球はつく。14個が18個になったので、つく数が消える数より4個多い番号をさがす。
  4. 表にする。
    忘れた操作200までの倍数うち平方数（消える）平方数でない（つく）点灯の数
    1200個14個186個14−14＋186＝186
    450個7個（4・16・36・64・100・144・196）43個14−7＋43＝50
    922個4個（9・36・81・144）18個14−4＋18＝28
    1612個3個（16・64・144）9個14−3＋9＝20
    258個2個（25・100）6個14−2＋6＝18
    365個2個（36・144）3個14−2＋3＝15
    49以上の平方数は、200までの倍数が4個以下。そのうち1個は自分自身で、消える。つく数が消える数より4個多くなることはないので、ここで終わり。
  5. たしかめ。25の倍数は 25・50・75・100・125・150・175・200 の8個。25 と 100 が消えて、残りの6個がつく。14−2＋6＝18。合っている。
答え：操作番号25
コツ：「同じ番号の電球は点灯しているはず」の1文は、忘れた番号を平方数だけにしぼるためにある。条件の文は、候補をしぼる部品として先に直して書く。

4 (1) 約分すると5になる分数の分母 A・6点｜和が決まっている比（線分図）

👀 まず見るところ

【条件文】部品は「分子と分母の和が2022」と「約分すると5」。5は「分子：分母＝5：1」に直して線分図に置く → 和の⑥が2022に当たり、分母の①が決まる。

📚 前提知識

  • 約分して5になる分数は、5/1 と同じ大きさ。10/2 も 15/3 も、分子が分母の5倍。
  • 和が決まっている2つの数は、比の合計で和をわると①が出る。たとえば和が12で 2：1 なら、①＝12÷3＝4。

🔍 整理して解く

  1. 線分図をかく。分子は⑤、分母は①。
  2. ⑤＋①＝⑥ が 2022。①＝2022÷6＝337。
  3. 分母は①なので 337。分子は 337×5＝1685。
  4. たしかめ。1685＋337＝2022。1685÷337＝5。合っている。
  5. 落としやすい所: 2022÷5 としてしまう。和には分母の①も入っているので、6でわる。答えるのは分子の1685でなく分母。
答え：337

4 (2) 約分すると整数になる分数の個数 B・6点｜約数（和が決まっている分数）

👀 まず見るところ

【条件文】部品は「約分すると整数」。(1) の5を□に変えて「分子は分母の□倍」に直して書く → 和の2022は分母の（□＋1）倍になり、分母は2022の約数と決まる。(1) の線分図がかけていれば、同じ図で進める。

📚 前提知識

  • 2022 を素数のかけ算に分ける。2022÷2＝1011。1011÷3＝337。337 は 2・3・5・7・11・13・17 のどれでもわり切れない素数。だから 2022＝2×3×337。
  • 約数は、2・3・337 をそれぞれ使うか使わないかで 2×2×2＝8個ある。

🔍 整理して解く

  1. (1) では、2022 は分母337の6倍だった。分子が分母の□倍なら、和は分母の（□＋1）倍。分母は2022をわり切る数になる。
  2. 2022の約数を小さい順にならべて、表にする。
    分母（2022の約数）分子（2022−分母）約分すると
    120212021
    220201010
    32019673
    62016336
    33716855
    67413482
    101110111
    20220作れない
  3. 分母が2022だと分子が0になる。分子は1から2021までなので、これは外す。
  4. 8−1＝7個。1011/1011＝1 も整数なので数に入れる。
答え：7個

4 (3) 整数部分が1になる分数の個数 B・6点｜分数の大きさの境目

👀 まず見るところ

【条件文】部品は「整数部分が1」。「1以上で、2より小さい」に直して書く → ちょうど1になる分数とちょうど2になる分数を出せば、その間の個数で決まる。境目は (1) と同じ線分図で出せるので進める。

📚 前提知識

  • 整数部分が1の数は、1・1 1/2・1 2/3 など。ちょうど1は入る。ちょうど2は整数部分が2なので入らない。
  • 分子が1ふえると、分母は1へる。ならんだ分数は、右へ行くほど大きくなる。
  • ○から△までの整数の個数は △−○＋1。3から5までなら 5−3＋1＝3個。

🔍 整理して解く

  1. ちょうど1になるのは、分子と分母が同じとき。2022÷2＝1011 だから 1011/1011。
  2. ちょうど2になるのは、分子：分母＝2：1 のとき。③＝2022 で ①＝674。分数は 1348/674。
  3. 境目のまわりを表にする。
    分数大きさ整数部分
    1010/10121より小さい0
    1011/1011ちょうど11
    1012/10101 2/10101
    ……1
    1347/6751 672/6751
    1348/674ちょうど22
  4. 整数部分が1なのは、分子が1011から1347まで。1347−1011＋1＝337個。
答え：337個
コツ：はしの2つを確かめてから数える。1011/1011 は入れる。1348/674 は入れない。ひき算のあとの「＋1」も、はしを表に書いておけば落とさない。

5 (1) A・B・C を通る平面の切り口 B・6点｜立体の切断（切り口の作図）

👀 まず見るところ

【条件文】部品は「3つの頂点A，B，Cを通る平面」と「頂点以外を通る線の位置は正確でなくても構いません」。A・B・C がのっている面に丸 → 切り口の線は面の上だけに引け、平行な面には平行な線で6本と決まる。形だけでよいので、平行の決まりを知っていれば手を付ける。

📚 前提知識

  • 切り口の線は、立体の面の上にだけできる。同じ平面にある2点でも、結んだ線が立体の外を通るなら、その線は切り口にならない。
  • 平行な2つの面を1つの平面で切ると、切り口の線は平行になる。立方体なら、上の面の線と底の面の線が平行。

🔍 整理して解く

  1. AとBは、どちらも奥の面にある。ところがAとBを結ぶ線は、左上の立方体が無い所を通る。立体の外を通るこの線は、切り口にならない。図には入れずに進める。
  2. 線が引ける面を決める。Aからは「上の面」と「上の立方体の左の面」。Bからは「段の面（左下の立方体の上の面）」と「左の面」。Cからは「底の面」と「右の面」。合わせて6本。奥の面はAとBの2点、前の面はCの1点でしか平面にふれない。
  3. 平行な面の線を平行にそろえる。上の面・段の面・底の面の3本が平行。左の面・上の立方体の左の面・右の面の3本も平行。
  4. 線どうしは辺の上で出会う。上の面の線と右の面の線は、上の面の右の辺で出会う（点P）。底の面の線と左の面の線は、底の面の左の辺で出会う（点Q）。段の面の線と上の立方体の左の面の線は、段の内側のかどの辺で出会う（点R）。
  5. A→P→C→Q→B→R→A の順に結ぶと、六角形になる。P・Q・R はどれも奥寄りにとる。正確には奥から2cm の所で、(2) で出す。
答え：右の図（A→P→C→Q→B→R→A と結んだ六角形。上の図の赤い線。Pは上の面の右の辺、Qは底の面の左の辺、Rは段の内側のかどの辺の上で、どれも奥寄り）
コツ：「AとBは同じ面だから結ぶ」と直線を引くと、立体の外を通る線になる。L字の立体では、結ぶ前に、線が面からはみ出さないかを見る。

5 (2) 切ってできる大きい方の立体の体積 C・6点｜切断した立体の体積（高さの平均）

👀 まず見るところ

【条件文】本番では後回し。部品は「1辺が6cm」と「体積が大きい方」。切り口の点P・Q・R の位置を cm で図に置く → 下の直方体と上の立方体に分け、底面積×高さの平均で出す。

📚 前提知識

  • ななめに切った四角柱の体積は「底面積×4つの高さの平均」。同じ立体を逆さにして重ねると、直方体になる。高さが 4・0・2・6 なら、向かい合う 4＋2 と 0＋6 がどちらも6。重ねた直方体の高さは6で、平均は3。

🔍 整理して解く

  1. 点Pの位置を出す。奥の面で、BからAへは右に6cm、上に6cm。同じだけのばした点をTとする。Tは右の面を上にのばした所にあり、高さは18cm。TとCを結ぶ線は、奥に6cm進む間に18cm上がる。奥に1cmで3cm上がるので、高さ12cmの上の面とは手前から4cmの所で出会う。これがP。高さ6cmの所は手前から2cm。AからPへは、右に6cm進む間に手前へ2cm。平行な線も同じかたむきになる。Rは、Bから右に6cmで手前へ2cm。Qは、Cから左に12cmで奥へ4cm。QもRも手前から4cm。
  2. 前の面を底面にして、切り口までの長さを書きこむ。下の直方体（底面 12×6＝72）は 4・0・2・6 で平均3。72×3＝216。上の立方体（底面 6×6＝36）は 4・2・4・6 で平均4。36×4＝144。
  3. 手前側の立体は 216＋144＝360。全体は 6×6×6×3＝648。奥側は 648−360＝288。大きい方は手前側の 360。
答え：360cm³

3〜5 まとめ（大問3・4・5で繰り返し出た入口）

  • 「□の倍数を押す」は、電球の側から見ると「約数の個数だけ押される」。約数が奇数個になるのは平方数だけ。
  • 和が決まっている分数は、比の線分図で①を出す。「5になる」「整数になる」「1以上2未満」と条件が変わっても、同じ図を使い回す。
  • 切断は「線は面の上だけ」「平行な面には平行な線」。体積は四角柱に分けて、底面積×高さの平均。
