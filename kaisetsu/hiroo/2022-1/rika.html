1 問1①② 乾電池の数を変えたときの電流 A・4点｜グラフの形を選ぶ

👀 まず見るところ

【まざり型→条件文】部品は「電熱線Aを1本に固定して」と、①②で変わる「乾電池を直列に／並列に」。「直列＝力が増える、並列＝変わらない」に直して回路図の横に書く → グラフの形（右上がりか水平か）が決まる。

📚 前提知識

  • 乾電池を直列に増やすと、電流を押す力が個数に比例して大きくなる。電熱線が同じなら電流も個数に比例。
  • 乾電池を並列に増やしても、押す力は1個のときと同じ。電流は変わらない（長持ちするだけ）。

🔍 こう読み解く

  1. ①直列: 1個→2個→3個で電流も1→2→3。点が原点から一直線に右上がりのア。
  2. ②並列: 何個にしても電流は同じ。点が横に並ぶエ。
  3. 落としやすい所: ウも右上がりだが、増え方がだんだん大きくなる曲がった形。比例なら直線のアを選ぶ。
答え：① ア　② エ

1 問1③④ 電熱線の本数を変えたときの電流 A・4点｜グラフの形を選ぶ

👀 まず見るところ

【まざり型→条件文】部品は「乾電池を1個に固定して」と、③④で変わる「電熱線Aを直列に／並列に」。直列＝1本の長い電熱線、並列＝通り道が増える、に直して書く → 反比例か比例かが決まる。

📚 前提知識

  • 電熱線を直列につなぐと、1本の長い電熱線と同じ。長さが2倍・3倍なら電流は1/2・1/3（反比例）。
  • 電熱線を並列につなぐと、電池から見た通り道が2本・3本に増える。1本ごとに同じ電流が流れるので、電流計の電流は本数に比例。

🔍 こう読み解く

  1. ③直列: 本数が増えるほど電流は小さくなり、減り方はだんだんゆるやか（1、1/2、1/3…）。右下がりの曲線のイ。
  2. ④並列: 電流計は電池のすぐそばにあるので、全部の通り道の電流が合わさる。1本、2本、3本で電流も1、2、3 → 一直線に右上がりのア。
  3. 落としやすい所: ④で「並列だから変わらない（エ）」と答えないこと。変わらないのは電池を並列にしたとき（②）。
答え：③ イ　④ ア

👀 まず見るところ

1 問3 断面積が3倍の電熱線Cの長さ B・2点｜計算・何倍

👀 まず見るところ

【条件文】部品は「断面積が3倍」「(6)の電流計と同じ値」と、ただし書きの「断面積を2倍，3倍にすることは…並列に2本，3本とつなげるのと同じ」。「電流＝9/2」「Cの長さを□倍」と図4の横に書く → 3本並列の式を9/2に合わせれば□が出る。

1 問4 電熱線B＋乾電池2個の水温上昇 B・2点｜計算・何倍

👀 まず見るところ

📚 前提知識

🔍 こう読み解く

1 問5 接点Pを動かしたときの時間とPQの長さ C・2点｜グラフ選択＋理由の記述

👀 まず見るところ

【条件文】本番では後回し。合図は図5-4の「電熱線Aの途中に接続」＝電流が通るのはPからQまでだけ。「PQが短い＝電熱線が短い＝電流が多い」に直して書く → 時間がPQの長さに比例するかが決まる。

📚 前提知識

  • 乾電池は1個のまま。電流は電流が通る部分の長さ（PQ）に反比例し、発熱量は電流に比例する。

🔍 こう読み解く

  1. PQが2倍、3倍になると電流は1/2、1/3。乾電池は同じなので発熱量も1/2、1/3。
  2. 同じ水温上昇に必要な熱は同じ。発熱量が1/2なら時間は2倍 → 時間はPQの長さに比例。
  3. 比例＝原点に向かう一直線。曲がって増え方が大きくなるウ、増え方が小さくなるエではなく、一直線のア。理由は「電流が反比例→発熱量が反比例→時間は比例」の3段で書く。
答え：記号…ア　理由…（例）電池の数は同じなので，流れる電流の大きさはPQの長さに反比例する。よって，発熱量もPQの長さに反比例するので，同じ水温上昇までの時間はPQの長さに比例するから。

  • 酸素と二酸化炭素の交かんは、空気（水）と血液がふれる面でしか起きない。だから交かんの場所は表面積が大きいつくり（肺胞＝たくさんの小さな袋、えら＝たくさんのうすいひだ）になっていて、そこに毛細血管が集まる。

✍️ 答案の組み立て

  1. 要素A（形）: 小さな袋やひだがたくさんある → 表面積が大きくなる構造。「小さい」だけで止めず「表面積」まで書く。
  2. 要素B（血管）: 袋やひだを毛細血管が包んでいる → 毛細血管が集中している。
  3. 「構造的な」類似点を聞かれているので、「酸素を取り込む」などのはたらきの共通点は書かない。
模範解答：表面積が大きくなるような構造をしている。／毛細血管が集中している。

3 問5 筋肉に酸素を渡したヘモグロビンの割合 B・2点｜条件文・割合の計算

👀 まず見るところ

【条件文】部品は「肺では…97％」「筋肉では…30％」と、聞き方の「肺にある酸素と結合したヘモグロビンのうち」に丸。「のうち」＝もとにする量は97、に直して書く → (97−30)÷97。手を付ける価値: もとにする量を決めれば1行の割り算。

📚 前提知識

  • 割合は「比べる量÷もとにする量」。「〜のうち何％」と聞かれたら、「〜」がもとにする量。すべてのヘモグロビン（100）を1にしない。

🔍 こう読み解く

  1. ヘモグロビンが100個あるとすると、肺で酸素を持っているのは97個。筋肉を通ったあとも持っているのは30個。
  2. 筋肉で酸素を渡したのは 97−30＝67個。
  3. もとにする量は「肺で結合していた97個」なので、67÷97×100＝69.07… → 小数第1位を四捨五入して 69％。67％（100をもとにした値）と答えない。
答え：69％

4 問1 三原山と昭和新山の特徴 A・2点｜素材文・2つ選ぶ（完答）

👀 まず見るところ

【素材文】部品は本文の「三原山は…黒っぽい岩肌でなだらかな傾斜」「昭和新山は…白っぽい岩肌で溶岩ドーム」に丸。黒っぽい＝粘性が弱い＝ゲンブ岩、白っぽい＝粘性が強い＝リュウモン岩、に直して書く → 山ごとに1つずつ決まる。

📚 前提知識

  • マグマの粘性が弱い（さらさら）と、溶岩が遠くまで流れてなだらかな山になる。固まった岩は黒っぽいゲンブ岩。
  • 粘性が強い（ねばねば）と、溶岩が流れずに盛り上がって溶岩ドームになる。固まった岩は白っぽいリュウモン岩。

🔍 こう読み解く

  1. 三原山: 黒っぽい・なだらか → 粘性が弱く、ゲンブ岩 → イ。
  2. 昭和新山: 白っぽい・溶岩ドーム → 粘性が強く、リュウモン岩 → キ。
  3. 落としやすい所: 「粘性が弱い＝ねばりが弱い＝さらさら」の向きを逆に取らない。完答なので、本文の「黒っぽい／白っぽい」を2つとも確かめてから書く。
答え：イ・キ

4 問2 マグマがある高さまでしか上昇しない理由 B・2点｜素材文・最も適当なもの

👀 まず見るところ

【素材文】部品は下線部Aの「ある一定の場所でマグマだまりを形成」と選択肢全部に共通の「浮力が大きくなる」に丸。浮力＝周りより密度が小さいものが浮く力、に直して書く → 深いところは「周りの岩石の密度がマグマより大きい」が答えの形。手を付ける価値: 「木が水に浮く」と同じ、と気づけば取れる。

📚 前提知識

  • 浮力は密度の差で決まる。周りの物質より密度が小さいものは浮き上がり、密度が大きいものは沈む（木は水に浮く）。温度の差が直接浮力を生むのではない。

🔍 こう読み解く

  1. マグマが上昇する＝周りの岩石よりマグマの密度が小さいので浮力がはたらく。周りの岩石の密度がマグマより小さければ沈むはず → イは逆で×。
  2. 「ある高さで止まる」＝浅くなると浮力が小さくなる。つまり深いところほど周りの岩石の密度が大きく、浅くなると差が縮む → ア。
  3. ウ・エは温度の話。浮力は密度で決まるので、温度の高い低いでは説明にならない → ×。
答え：ア

4 問3② 水3％のマグマが発泡し始める深さ（図3・図4） B・2点｜資料問題・2つのグラフをたどる

👀 まず見るところ

【資料問題】資料の正体を1行＝図3は「ある圧力において，マグマに水がどれくらい溶けるか」（たて＝圧力・億Pa、横＝溶存水・％）、図4は圧力と深さ（km）。部品は「約3％の水を含む」と「整数で」に丸。3％ → 図3で圧力 → 図4で深さ、の順にたどる。手を付ける価値: 図3の交点が読めれば、図4は割り算1回。

📚 前提知識

  • 圧力が高いほど、マグマに溶けていられる水は多い（図3の曲線が右上がり）。マグマが上昇して圧力が下がり、溶けていられる量が3％を切った瞬間に、余った水が水蒸気のあわになる＝発泡。

🔍 こう読み解く

  1. 図3で 溶存水3％ のたて線をたどると、曲線と交わるのは 圧力1.0億Pa の横線の上（マス目の交点）。圧力がこれより下がると3％は溶けていられない → ここで発泡が始まる。
  2. 図4は原点を通る直線で、深さ10kmのとき2.5億Pa。1億Paあたりの深さは 10÷2.5＝4km。
  3. 1.0億Pa × 4km/億Pa ＝ 4km。図4で深さ4のたて線と直線の交点が圧力1.0であることも、同じ答えになる。
答え：4km
