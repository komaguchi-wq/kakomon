1 問1 日本の農業の土地生産性と労働生産性 A・1点｜素材文・組み合わせ

👀 まず見るところ

【素材文】部品は本文の「農地面積が非常に小さい」と、Ⅱの後ろの「価格面で競争することが難しく」に丸。かっこの定義（面積あたり／1人あたり）と結べば、Ⅰ・Ⅱの高低が決まる。

📚 前提知識

  • せまい農地を家族で手間をかけて耕すと、面積あたりの収穫は多いが、1人あたりの収穫は少なくなる。アメリカ合衆国は広い農地を大型機械で耕すので、その逆になる。

🔍 こう読み解く

  1. Ⅰ＝土地生産性（1ヘクタールあたり）。小さい農地に機械・農薬・化学肥料をつぎこむので、面積あたりの収穫は多い → 高く。

  3. Ⅰ高く・Ⅱ低く → イ。落としやすい所: どちらも「生産性」なので、かっこの定義を読まずに両方同じにしてしまうこと。
答え：イ

3 問1 世界の貿易 B・1点｜正しいもの

👀 まず見るところ

【素材文】部品は各文の言い切り「禁止されています」と機関名「国連貿易開発会議(UNCTAD)」に丸。言い切りは言いすぎ、機関名はすりかえを疑い、4つ全部に○×をつける。

📚 前提知識

  • 関税を下げ、貿易の争いを解決するのはWTO（世界貿易機関）。UNCTADは南北問題（先進国と発展途上国の経済格差）の是正などをめざして置かれた機関。
  • 国どうしの協定は禁止されていない。日本も東南アジアの国々と経済連携協定（EPA）を結び、環太平洋パートナーシップ協定（TPP）にも参加している。

🔍 こう読み解く

  1. ア「独自に協定を結ぶことは禁止」→ EPAやTPPがある。言いすぎ → ×。
  2. イ 関税・貿易の争いの解決はWTOの仕事。機関名のすりかえ → ×。
  3. ウ 発展途上国が「価格の低い工業製品を先進国に輸出し」「高品質の原材料を先進国から輸入する」→ 実際は安い原材料を輸出し、工業製品を輸入する国が多い。逆 → ×。
  4. エ 輸入が急に増えたとき、一定期間だけ関税を上げる対策（セーフガード）→ ○。「一定の条件」「一定期間だけ」のように限定がついた文は、言いすぎになりにくい。
答え：エ

3 問6①・問6② 耐久消費財の普及率 B・1+1点｜表の読み取り

👀 まず見るところ

【資料問題】正体は「全世帯における主要な耐久消費財の普及率(%)」・1958〜1990年。各列を「いつ数字が始まるか」「増え続けるか、減るか」で見る。始まりと増え方で5つが分かれる。

📚 前提知識

  • 1950年代後半からの「三種の神器」＝白黒テレビ・電気洗濯機・電気冷蔵庫。1960年代後半からの「3C（新三種の神器）」＝カラーテレビ・クーラー・乗用車。
  • カラーテレビが広まると、白黒テレビは置きかえられて減っていく。

🔍 こう読み解く

  1. 表の最初（1958年）から数字があるのはAとB＝三種の神器の白黒テレビと冷蔵庫。Aは1968年の96.4から減り、1982年の17.4で終わる＝置きかえられた白黒テレビ。減らずに1990年98.2まで伸びるB＝電気冷蔵庫。
  2. いちばん遅く1987年から始まるE＝パソコン。1966年0.3から1990年99.4まで一気に伸びるD＝白黒テレビと入れかわったカラーテレビ。
  3. 残るC＝乗用車。1961年2.8から伸びるが、1990年でも77.3で100%には届かない。
  4. 落としやすいのは、A（96.4まで高い）を冷蔵庫と思いこむこと。高さだけでなく、その後に減るかどうかまで見る。
答え：① 乗用車 C　② 電気冷蔵庫 B

4 Ⅰ 1820年代と1840年代の幕府の外交 B・4点｜変化と理由の記述

👀 まず見るところ

【資料問題】部品は「1820年代と1840年代」と「変化した理由を含めて」。年表の1825年と1842年のあいだにある1840年のアヘン戦争が理由。資料文①②の命令を1語ずつ比べて書く。

📚 前提知識

  • 資料文①＝1825年の外国船打払令。「直ちに打払い」「打ち殺してもかまわない」＝強硬。
  • 資料文②＝1842年の天保の薪水給与令。食料や薪や水が足りなければ与えて帰国させる＝緩和。
  • アヘン戦争で清がイギリスに敗れたことを知り、幕府は欧米の力をおそれて、争いを避けようとした。

✍️ 答案の組み立て

  1. 要素A（1820年代）：外国船打払令を出し、外国船に強硬な姿勢をとっていた。
  2. 要素B（理由）：アヘン戦争で清が敗れ、幕府が危機感をもった。
  3. 要素C（1840年代）：外国船に水や薪などを与えて帰国させるようにし、強硬な姿勢を緩和した。
  4. 書く順は A → B → C。「〜していたが、〜して、〜した」と時間の順につなぐと、変化と理由が1文に入る。
模範解答：1820年代は，外国船打払令を出すなど外国船に対して強硬な姿勢を示していたが，アヘン戦争が起こり，清が敗れて危機感を持った幕府は，1840年代になると，外国船に対して水や薪などを与えて帰国させるようにするなど強硬な姿勢を緩和した。
コツ：資料文②の最後は「上陸させてはならない」。国を開いたのではなく、打払いをやめて穏やかに帰す方針に変えただけ。「開国した」と書くと言いすぎになる。

4 Ⅱ ポリアーキー指標が上がった2つの時期 B・4点｜グラフと理由の記述

👀 まず見るところ

【資料問題】部品は「見方」の箱の「参政権を有する市民の割合」と「結社の自由や表現の自由」。物差しは選挙と自由の2本。A・Bそれぞれに、選挙の出来事と自由の出来事を1つずつ置く。

📚 前提知識

  • Aのころ：1889年に大日本帝国憲法が発布され、法律の範囲内という制限つきで臣民の自由権が認められた。1890年に初の衆議院議員選挙（直接国税15円以上を納める満25歳以上の男子だけ）。
  • Bのころ：1945年12月の選挙法改正で女性参政権がはじめて認められた。グラフの「日本(1945)」の注記がこれ。1947年に日本国憲法が施行され、基本的人権が広く保障された。

✍️ 答案の組み立て

  1. 要素A①（選挙）：国会開設にともない、制限はあるが初の選挙が行われた。
  2. 要素A②（自由）：大日本帝国憲法で、臣民としての自由権が認められた。
  3. 要素B①（選挙）：はじめて女性参政権が認められた。
  4. 要素B②（自由）：日本国憲法で、旧憲法より広く自由権が認められた。
  5. 「Aの時期は〜ため。Bの時期は〜ため。」と時期ごとに2文に分けると、要素の抜けに気づきやすい。
模範解答：Ａの時期は，国会開設にともない制限はあるものの初の選挙が実施され，大日本帝国憲法制定にともない臣民としての自由権が認められたため。Ｂの時期は，初めて女性参政権が認められ，さらに日本国憲法の制定により旧憲法よりも広く自由権が認められたため。
コツ：グラフの「カッコ内の数字＝女性参政権が初めて認められた年度」という注記は、Bの理由そのもの。注記や見方の箱は、読み飛ばさずに答えの部品として使う。

3〜4 まとめ

  • 正誤選択は「言いすぎ（禁止されている）」「すりかえ（機関名）」「逆（輸出と輸入）」で切る。
  • 普及率の表は、数字の始まる年と、その後に減るかどうかで製品が分かれる。
  • 記述は、資料文・年表・「見方」の箱の言葉がそのまま要素になる。比べる2つの時期を並べて書く。
