1 (1) 小数と分数のまじった計算 A・5点｜計算

👀 まず見るところ

1.25と0.75がある → 分数に直してから計算する。1.25は5/4、0.75は3/4。うしろのかっこは、分母を8にそろえる。

📚 前提知識

  • かっこの中は、ひき算より先にわり算をする。
  • 分数でわるときは、ひっくり返してかける。3/4÷5/8 は 3/4×8/5。

🔍 整理して解く

  1. 前のかっこの、わり算から計算する。 
    0.75÷5/8 ＝ 3/4×8/5 ＝ 6/5
1.25−6/5 ＝ 5/4−6/5 ＝ 25/20−24/20 ＝ 1/20
  2. うしろのかっこを、分母8にそろえてたす。 
    1/2＋1/4＋1/8 ＝ 4/8＋2/8＋1/8 ＝ 7/8
  3. 前÷うしろを計算する。1/20÷7/8 ＝ 1/20×8/7 ＝ 2/35。
  4. 落としやすい所は、前のかっこ。1.25−0.75 を先にひくと、答えがずれる。
答え：2/35

1 (2) 2つの容器で食塩水をやりとりする A・5点｜食塩水（全体の濃さ）

👀 まず見るところ

「何gか」移した量は、2回とも分からない → やりとりの前後で変わらないものを見る。食塩水は合わせて1000g、食塩は合わせて160g。全部まぜたら16%になる。

📚 前提知識

  • 2つの容器の間で移すだけなら、食塩水の合計も食塩の合計も変わらない。外に捨てていないから。
  • 2つの食塩水をまぜた濃さは、重いほうの濃さに近くなる。たとえば14%と18%を同じ重さずつまぜると、ちょうどまん中の16%になる。

🔍 整理して解く

  1. はじめの食塩を出す。Aは 400×0.1＝40g。Bは 600×0.2＝120g。合わせて160g。
  2. 食塩水は合わせて 400＋600＝1000g。全部まぜたときの濃さは 160÷1000＝0.16 で、16%。
  3. 最後のA（14%）とB（18%）を全部まぜても、16%になるはず。線分図に書く。 
    A 14% ├────┤16%├────┤ 18% B
         差2      差2
  4. 16%は、14%と18%のちょうどまん中。だからAとBは同じ重さ。1000÷2＝500g。
  5. たしかめ。500×0.14＝70g。500×0.18＝90g。70＋90＝160g で、はじめの食塩と同じ。
答え：500g
コツ：「何g移したか」を追いかけると、分からないものが2つになって進まない。移すだけの問題は、合計の重さと合計の食塩を先に書く。

1 (3) 3でわると1、5でわると2、7でわると3あまる数 A・5点｜あまりの数（書き出しと周期）

👀 まず見るところ

あまりが1・2・3でばらばら → いちばん小さい数を書き出しで見つける。そのあとは、3と5と7の最小公倍数の105ずつふえる。書き出しは、数が早くふえる7から始める。

📚 前提知識

  • 当てはまる数が1つ見つかったら、次は最小公倍数をたした数。105は3でも5でも7でもわり切れるので、たしてもあまりは変わらない。
  • 5でわると2あまる数は、一の位が2か7。たとえば 12、17、22、27。

🔍 整理して解く

  1. 7でわると3あまる数をならべる。一の位が2か7のものに印をつける。 
    3 10 17 24 31 38 45 52 …
  2. 印の数を3でわる。17÷3 は 5あまり2 で、ちがう。52÷3 は 17あまり1 で、当てはまる。いちばん小さい数は52。
  3. 当てはまる数は、52に105を何回かたした数。1000に近づける。1000−52＝948。948÷105 は 9あまり3。
  4. 52＋105×9＝997。次は 997＋105＝1102。
  5. 1000とのちがいをくらべる。997は3ちがい。1102は102ちがい。近いのは997。
答え：997
コツ：「1000に最も近い」は、1000より小さい数と大きい数の両方を出してからくらべる。1000をこえた数のほうが近いこともある。

1 (4) 行き時速4km・帰り時速6kmで往復3時間 A・5点｜速さ（往復）

👀 まず見るところ

同じ道を行きと帰りでちがう速さ → 道のりを、4と6の最小公倍数の12kmと決めてためす。そのときの往復の時間と、本当の3時間をくらべる。

📚 前提知識

  • 同じ速さで歩くなら、道のりが半分になると、かかる時間も半分になる。道のりと時間は同じ割合で変わる。
  • 往復の速さを「4と6のまん中の時速5km」にしてはいけない。おそい行きのほうが、長い時間歩いているから。

🔍 整理して解く

  1. 道のりを12kmと決める。行きは 12÷4＝3時間。帰りは 12÷6＝2時間。往復で5時間。
  2. 本当は3時間。5時間の 3/5 になっている。 
    道のり12km → 往復5時間
道のり□km → 往復3時間   （3/5倍）
  3. 道のりも 3/5 にする。12×3/5＝7.2km。
  4. たしかめ。行きは 7.2÷4＝1.8時間。帰りは 7.2÷6＝1.2時間。たすと3時間。
答え：7.2km

1 (5) へこみのある五角形を辺BCのまわりに回す B・5点｜回転体（円すい台）

👀 まず見るところ

ななめの辺AEをのばすと、軸の上の点Cに着く（AEは対角線ACの一部）→ 大きい円すいから小さい円すいを引く形で考える。図形は左右が同じ形なので、左半分を出して2倍する。図が見えたら手をつけてよい問題。

📚 前提知識

  • 円すいの体積は、底面積×高さ÷3。
  • ななめの線を軸まで回すと円すいになる。軸にとどかないななめの線は、とちゅうで切った円すい（円すい台）になる。大きい円すいから、先の小さい円すいを引いて出す。
  • Eは正方形のまん中。だからEは、辺BCから3cm、辺ABからも3cmの所にある。

🔍 整理して解く

  1. Eから辺BCにまっすぐ線を下ろす。着いた点をMとする。MはBCのまん中で、EM＝3cm。五角形は、左の台形ABMEと右の台形DCMEに分かれる。 
    A
│＼
│  ＼E          AB＝6cm  EM＝3cm
│  │＼         BM＝3cm  MC＝3cm
B──M──C   ← 軸
  2. 左の台形を回す。三角形ABCを回した大きい円すいから、三角形EMCを回した小さい円すいを引く。 
    大きい円すい  6×6×3.14×6÷3 ＝ 72×3.14
小さい円すい  3×3×3.14×3÷3 ＝  9×3.14
ひくと        63×3.14
  3. 右の台形も同じ形。2倍して 126×3.14。
  4. 3.14は最後に1回だけかける。126×3.14＝395.64。
答え：395.64cm³
コツ：別の見方もある。正方形を回した円柱は 216×3.14。そこから、三角形AEDを回した部分の 90×3.14 を引いても同じ 126×3.14 になる。ただし引く部分の形が出しにくいので、円すいの引き算のほうが速い。

1 (6) 半径1cmの円が八角形の辺の上を1周する B・5点｜円が通ったあとの面積

👀 まず見るところ

うでの幅も底の厚さも2cm＝円の直径 → 八角形の中は、ほとんど全部を円が通る。だから外側に1cm広げた大きい長方形から、通らない所を引く。数えるものが多いので、本番では後回しでよい。

📚 前提知識

  • 円の中心が辺の上を動くと、辺の両側に1cmずつ、幅2cmの帯ができる。
  • 角の所では、1辺1cmの正方形から、半径1cmの円の1/4を引いた形のすきまが残る。1個の面積は 1−0.785＝0.215cm²。
  • すきまは、外にとがった角の外側だけではない。中にへこんだ角では、八角形の内側にもできる。

🔍 整理して解く

  1. 八角形を外側に1cmずつ広げた長方形を書く。横は 10＋2＝12cm。たては 8＋2＝10cm。面積は 12×10＝120cm²。
  2. くぼみの中の、通らない長方形を引く。くぼみは横6cm。両側から1cmずつ帯が入るので、残る横は4cm。たては、くぼみの底の1cm上から、大きい長方形の上の辺までで 6−1＋1＝6cm。面積は 4×6＝24cm²。
  3. 角のすきまを数える。全部で8個。
    場所個数
    外まわりの4つの角の外側4
    うでの先の、くぼみ側の角の外側2
    くぼみの底の角の、八角形の内側（ななめ下）2
  4. すきま8個を合わせる。正方形8個から、円の1/4を8個引く。円の1/4が8個で、円2個分。8−2×3.14＝1.72cm²。
  5. 全部引く。120−24−1.72＝94.28。
  6. 落としやすい所は、表の3行目の2個。左下で見る。くぼみの底の角から、左に1cm、下に1cmの正方形を書く。この中は、左の辺からも下の辺からも1cmより遠い。いちばん近いのは、くぼみの底の角。その角から1cmより遠い所が、すきまとして残る。
答え：94.28cm²
コツ：へこんだ角（内側の角が270度）では、円はその角を中心に1/4だけ回る形で通る。だから内側に「正方形−円の1/4」のすきまが残る。とがった角では外側に残る。角ごとに、どちら側にすきまができるかを図に書きこむ。

2 (1) 〈m/n〉がm/nと同じになる組（1〜9） A・6点｜約束記号・倍数の数え上げ

👀 まず見るところ

〈 〉は「こえない整数」。それがもとの数と同じ → m÷nがわり切れるということ。つまりmがnの倍数になる組を、nごとに数える。

📚 前提知識

  • 〈29/10〉は、2.9をこえない整数でいちばん大きいものだから2。小数の部分を切り捨てるのと同じ。
  • 切り捨てても変わらない数は、もともと整数。5/1＝5 や 6/3＝2 がそう。

🔍 整理して解く

  1. nを1から9まで順に決めて、9以下のnの倍数を数える。
    n123456789
    mの個数943211111
  2. n＝2なら、mは2、4、6、8の4個。n＝5から9は、m＝nの1個だけ。
  3. たす。9＋4＋3＋2＋1×5＝23。
  4. 落としやすい所は、m＝nの組。1/1や7/7も、わり切れて1になるので数える。
答え：23通り

2 (2)(3) 〈m/n〉＝〈2×n/m〉になるm、nをさがす B・6点＋6点｜約束記号・小さい数でためす

👀 まず見るところ

2026のままでは手が出ない → n＝3のような小さい数で表を書いて、決まりを見つける。mが大きくなると、左はふえて右はへる。同じになるのは、どちらも1のときだけ。(2)が分かれば(3)まで続けて取れる。

📚 前提知識

  • 〈m/n〉が1になるのは、mがn以上で、nの2倍より小さいとき。n＝3なら、mは3、4、5。
  • 〈2×n/m〉が1になるのは、mがnより大きくて、nの2倍以下のとき。n＝3なら 6÷m を見る。mは4、5、6。
  • 両方に当てはまるのは、nより大きくて、nの2倍より小さいm。n＝3なら4と5の2個。個数は n−1個。

🔍 整理して解く

  1. n＝3でためす。左は〈m/3〉、右は〈6/m〉。
    m1234567
    左〈m/3〉0011122
    右〈6/m〉6321110
    同じになるのは、m＝4と5。どちらも1のとき。
  2. ほかの数で同じにならないわけを見る。左が0のとき、mはnより小さい。すると 2×n÷m は2より大きいので、右は2以上。左が2以上のとき、mはnの2倍以上。すると右は1以下。どちらも合わない。
  3. (2) n＝2026。mは2026より大きくて、4052より小さい数。2027から4051まで。4051−2027＋1＝2025個。
  4. (3) mも100以下。nが1から50のときは、nの2倍が100以下なので、mは n−1個。0＋1＋2＋…＋49 ＝ 49×50÷2 ＝ 1225。
  5. nが51から100のときは、mの上が100で止まる。mは n＋1 から100までで、100−n個。49＋48＋…＋1＋0 ＝ 1225。 
    n      1  2  3 … 50 | 51 52 … 99 100
mの個数 0  1  2 … 49 | 49 48 …  1   0
  6. たす。1225＋1225＝2450。
答え：(2) 2025個　(3) 2450通り
コツ：はしの数を入れて確かめる。m＝2026 のとき、左は1で右は2。m＝4052 のとき、左は2で右は1。どちらも合わないので、はしは入れない。(3)は、nが51以上でmが100をこえる分を数えないようにする。

3 (2) 各位の数字の和が15 B・6点｜組を書き出してから並べる

👀 まず見るところ

「各位の数字の和が15」→ 先に4つの数字の組を小さい順に書き出し、あとで1組につき24通りをかける。組が6つ前後で終わると見えたら、手を付ける価値がある。いきなり4けたの数を書き出すのは多すぎる。

📚 前提知識

  • ちがう4つの数字を並べる方法は 4×3×2×1＝24通り。どの組でも同じ。
  • 組を書き出すときは、小さい数字から決める。「1と2を使う→残り2つで12」のように、残りの和を書くと数え落としがへる。

🔍 整理して解く

  1. いちばん小さい2つを先に決める。残り2つの和を出す。残り2つは、先の2つより大きくて、ちがう数字。 
    1,2 → 残り12 → (3,9) (4,8) (5,7)
1,3 → 残り11 → (4,7) (5,6)
1,4 → 残り10 → なし（5と5は同じ数字）
2,3 → 残り10 → (4,6)
2,4 → 残り 9 → なし
  2. 組は 6つ。{1,2,3,9} {1,2,4,8} {1,2,5,7} {1,3,4,7} {1,3,5,6} {2,3,4,6}。
  3. 1組につき24通り並べられる。6×24＝144。
答え：144通り
コツ：「1,4」や「2,4」の行も書いて「なし」とたしかめる。ここを書かないと、6つで全部かどうかが分からない。

3 (3) 小さい方から2026番目の整数 A・6点｜辞書ならべ（かたまりでわる）

👀 まず見るところ

「小さい順に」「2026番目」→ 千の位が同じ数のかたまりが何個ずつあるかを出して、2026をわる。千の位が決まったら、百の位、十の位でも同じことをくり返す。

📚 前提知識

  • 千の位を1つ決めると、残りの3けたは 8×7×6＝336通り。百の位まで決めると 7×6＝42通り。十の位まで決めると6通り。
  • わり算のあまりが「そのかたまりの中で何番目か」を表す。あまりが10なら、次のかたまりの10番目。

🔍 整理して解く

  1. 千の位でわる。2026÷336＝6 あまり10。千の位が1〜6の数で 336×6＝2016個。だから千の位は 7。その中の10番目をさがす。 
    千の位 1  2  3  4  5  6 | 7
個数  336 ×6 ＝2016個   | ここの10番目
  2. 百の位は42個ずつ。10番目は最初のかたまりに入る。7はもう使ったので、いちばん小さい百の位は1。ここまでで「71□□」。
  3. 十の位は6個ずつ。残っている数字は 2,3,4,5,6,8,9。十の位が2の数が1〜6番目。十の位が3の数が7〜12番目。10番目は「713□」の 4番目。
  4. 一の位に使える数字を小さい順にならべる。2,4,5,6,8,9。4番目は6。だから7136。
答え：7136
コツ：位が下がるたびに「もう使った数字」を消してからならべる。ここでは7と1と3を消すのを忘れると、一の位がずれる。

4 (1) 4つの比がすべて1：2のときの四角形AEPH A・6点｜回しても同じ形（対称）

👀 まず見るところ

4つの比が全部1：2 → 図を90°回しても同じ図になる → 正方形は同じ形の四角形4つに分かれている。だから正方形の面積を4でわるだけ。

📚 前提知識

  • 正方形を90°回してぴったり重なる図では、交わる点Pは正方形の真ん中になる。4つの部分は同じ形で、面積も同じ。

🔍 整理して解く

  1. 図1を90°回すところを考える。EはFの場所へ、FはGの場所へ移る。どの点も辺を1：2に分けているので、回した図は元の図と同じになる。
  2. 直線EGは直線FHに重なる。だから四角形AEPHは、四角形BFPE、CGPF、DHPGと同じ形。
  3. 正方形の面積は 6×6＝36cm²。36÷4＝9。
答え：9cm²
コツ：Pの場所を計算しようとすると時間がかかる。「比が全部同じ」と見たら、まず回して同じ図になるかをたしかめる。

4 (2) 各辺の真ん中の点と点P、AEPHが7cm² A・6点｜頂点と結んで等しい三角形をつくる

👀 まず見るところ

E・F・G・Hが辺の真ん中 → PとA・B・C・Dを結ぶと、同じ面積の三角形が2つずつできる。AEPHとCGPFをたすと正方形の半分になる。Pの場所は分からないままでよい。

📚 前提知識

  • 底辺の長さが同じで、高さも同じ三角形は、面積が同じ。三角形PAEと三角形PEBは、底辺がどちらも3cm。高さはどちらも「Pから辺ABまで」。だから面積が同じ。

🔍 整理して解く

  1. PからA・B・C・Dに線を引く。三角形が8つできる。同じ面積どうしに同じ記号を書く。 
    ア＝PAE＝PEB   イ＝PBF＝PFC
ウ＝PCG＝PGD   エ＝PDH＝PHA
  2. 8つ全部で正方形。ア×2＋イ×2＋ウ×2＋エ×2＝36。だから ア＋イ＋ウ＋エ＝18。
  3. 四角形AEPHは ア＋エ で、これが7cm²。四角形CGPFは イ＋ウ。
  4. イ＋ウ＝18−7＝11。
答え：11cm²
コツ：向かい合う2つの四角形をたすと、いつも正方形の半分の18cm²になる。Pが中のどこにあっても同じ。

4 (3) 比が4：1と3：2のときの四角形AEPH B・6点｜交わる2本の線は面積の比で分ける

👀 まず見るところ

(1)とちがって比がそろっていない → Pの場所を出すしかない。EP：PGは、三角形HEFと三角形HGFの面積の比と同じ。小数の計算が4回ほど続くので、Aの問題を終えてから手を付ける。

📚 前提知識

  • 直線HFをはさんで、EとGが反対側にある。三角形HEFと三角形HGFは底辺HFが同じ。だから面積の比は高さの比になり、それが EP：PG と同じになる。
  • 辺の長さは、AE＝AH＝4.8cm、EB＝HD＝1.2cm、BF＝DG＝3.6cm、FC＝GC＝2.4cm。6cmを5つに分けた1つ分が1.2cm。

🔍 整理して解く

  1. 三角形HEFの面積を出す。正方形から、まわりの3つをひく。 
    三角形AEH  4.8×4.8÷2＝11.52
三角形EBF  1.2×3.6÷2＝ 2.16
台形HDCF  (1.2＋2.4)×6÷2＝10.8
三角形HEF  36−11.52−2.16−10.8＝11.52
  2. 三角形HGFの面積を出す。台形HDCFから、角の三角形2つをひく。 
    三角形HDG  1.2×3.6÷2＝2.16
三角形GCF  2.4×2.4÷2＝2.88
三角形HGF  10.8−2.16−2.88＝5.76
  3. 11.52：5.76＝2：1。だから EP：PG＝2：1。PはEからGへ2/3進んだところ。
  4. Pの場所を出す。横は、辺ABから 6×2/3＝4cm。たては、辺BCからの高さで見る。Eは1.2cm、Gは2.4cm。差の1.2cmの2/3は0.8cm。Pの高さは 1.2＋0.8＝2cm。だからPから辺ADまでは 6−2＝4cm。
  5. APで2つに分ける。三角形AEPは 4.8×4÷2＝9.6。三角形APHも 4.8×4÷2＝9.6。たして 19.2cm²。分数にすると 19と1/5。
答え：19{1/5}cm²
コツ：四角形の面積は「Pから辺までのきょり」が2つ分かれば出せる。(2)と同じで、Aと結んで三角形2つにする。

5 (1)①② 2両と7両で時間の差が10秒 B・5点＋5点｜速さが車両の数で変わる

👀 まず見るところ

「最後尾と駅を230cm」→ 先頭が進む長さは、230cmから列車の長さをひいたもの。速さが1/2倍なら時間は2倍。1両の速さを①として、2両と7両の時間を①で表せたら手を付ける。

📚 前提知識

  • □両編成の速さは、1両のときの 1/□ 倍。同じ長さを進む時間は □倍になる。たとえば1両で3秒の長さは、2両だと6秒かかる。
  • □両編成の列車の長さは 10×□ cm。先頭は、はじめから駅にそれだけ近い。

🔍 整理して解く

  1. 先頭が進む長さを出す。それを「1両の速さで進んだら何cm分か」に直す。□両なら□倍する。 
    2両  230−20＝210cm  → 210×2＝ 420cm分
7両  230−70＝160cm  → 160×7＝1120cm分
  2. 差は 1120−420＝700cm分。これが10秒。だから1両の速さは 毎秒70cm。
  3. ① 7両のとき。1120÷70＝16秒。
  4. ② □両で同じ16秒になるとき、(230−10×□)×□＝1120。両方を10でわる。(23−□)×□＝112。
  5. たして23、かけて112になる2つの数をさがす。112＝7×16 で、7＋16＝23。だから□は7か 16。7両以外なので16両。
  6. たしかめ。16両の先頭は 230−160＝70cm進む。速さは 70÷16。時間は 70÷(70÷16)＝16秒。合っている。
答え：① 16秒　② 16両編成
コツ：「(23−□)と□は、たすと23」に気づくと、112を2つの数のかけ算に分けるだけで出る。

5 (2) 向かい合う2つの列車、(1,2)と同じ時間になる組 C・6点｜出会いの時間を式にして調べ上げる

👀 まず見るところ

本番では後回し。「全て答えなさい」→ 車両の数の和と積の式にして、和を3から20まで調べる形になる。式づくりと調べ上げの両方に時間がかかる。

📚 前提知識

  • 出会うまでの時間は「先頭どうしのきょり÷速さの和」。1両の速さは(1)で出した毎秒70cm。(1,2)なら、きょりは 210−30＝180cm、速さの和は 70＋35＝105。時間は 180÷105＝12/7秒。

🔍 整理して解く

  1. Aの車両の数とBの車両の数の、和と積で式を書く。先頭どうしのきょりは 10×(21−和)。速さの和は 70×和÷積。(1,2)なら 70＋35＝105 で、70×3÷2 と同じになる。
  2. 時間が 12/7秒になるように式を書いて、整理する。 
    10×(21−和) ÷ (70×和÷積) ＝ 12/7
→ (21−和)×積÷和 ＝ 12
→ 積 ＝ 12×和÷(21−和)
  3. 和を3から20まで入れる。積が整数になるのは、和が 3,7,9,12,14,15,17,18,19,20 のとき。このうち、2つの整数に分けられるものだけ残す。 
    和 3 → 積 2 → (1,2)  ←はじめの組
和 7 → 積 6 → (1,6)
和14 → 積24 → (2,12)
和18 → 積72 → (6,12)
  4. 和が9で積が9、和が12で積が16 などは、合う整数の組がない。残るのは (1,6)・(2,12)・(6,12) の3組。
答え：（1，6）・（2，12）・（6，12）

3〜5 まとめ

  • 「□番目」は、上の位ごとのかたまりの個数でわる。あまりが、次のかたまりの中の順番になる。
  • 正方形の中の四角形は、Pと頂点を結んで三角形に分ける。底辺が正方形の辺の上にくるので、高さは「Pから辺まで」になる。
  • 列車の問題で「最後尾から」とあったら、先頭が進む長さは列車の長さの分だけ短い。
