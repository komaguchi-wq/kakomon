1 (1) 目盛り4個・長さ6のゴロム定規 A・5点｜条件の整理（書き出し）

👀 まず見るところ

【条件文】部品は「すべて異なる」と「目盛りが4個」「長さは6」。目盛り4個は、すきま3つに直して書く → たして6になる、ちがう3つの数は1・2・3だけ。あとは並べる順を決める。

📚 前提知識

  • 両はしの0と6も目盛りに数える。例の定規は 0・1・3 で3個。だから4個なら、中に入れるのは2個。
  • 測れる長さは、となりどうしだけではない。はなれた目盛りの間も測れる。0・1・3 なら、1と2と3の3つ。

🔍 整理して解く

  1. すきまは3つ。たして6。全部ちがう数。当てはまるのは 1＋2＋3 だけ。
  2. 並べる順をためす。となりの2つをたした数が、すきまの数と同じになったら消す。
    すきまの順となりの2つをたす結果
    1・2・31＋2＝3（すきまの3と同じ）×
    2・1・32＋1＝3（すきまの3と同じ）×
    1・3・21＋3＝4、3＋2＝5○
    3がはしにあると、残りの1と2がとなりになる。だから3はまん中に決まる。
  3. すきま 1・3・2 を目盛りに直す。0、1、4、6。
  4. 解答冊子の図1は、置けない場所に×をつける方法。まん中の3は、左右が3と3で同じになる。1に置くと、2と5にも置けない。残りは4。同じ答えになる。
  5. たしかめ。測れる長さは 1・3・2・4・5・6。全部ちがう。落としやすい所は、間違いの例のように、はなれた目盛りの間を調べ忘れること。
答え：解説の図1を参照のこと。（目盛りは 0・1・4・6。左右を逆にした 0・2・5・6 も同じ定規）

1 (2) 目盛り5個・長さ11のゴロム定規を2通り A・6点｜条件の整理（書き出し）

👀 まず見るところ

【条件文】部品は「目盛りが5個」「長さは11」と「2通り」。すきま4つに直して書く → たして11になる、ちがう4つの数は1・2・3・5だけ。となりに置けない組を先に消す。

📚 前提知識

  • ちがう4つの数をいちばん小さく選ぶと 1＋2＋3＋4＝10。11には1足りない。4を5に変えた 1・2・3・5 だけが当てはまる。
  • となりの2つをたした長さも測れる。その数がすきまの数と同じなら、同じ距離が2か所できる。たとえば 1 と 2 がとなりだと、3が2か所になる。

🔍 整理して解く

  1. すきま 1・2・3・5 で、となりに置けない組を表に書く。
    組たすととなりに置けるか
    1と23（すきまの3と同じ）×
    2と35（すきまの5と同じ）×
    1と3／1と5／2と5／3と54／6／7／8○
  2. 2のとなりに置けるのは5だけ。となりが1つしかないので、2ははしに決まる。そのとなりが5。
  3. 残りの1と3の順で2通り。「2・5・1・3」と「2・5・3・1」。
  4. 目盛りに直す。2・5・1・3 は 0、2、7、8、11。2・5・3・1 は右から読むと 1・3・5・2 で、0、1、4、9、11。
  5. たしかめ。3つ分をたした長さも書く。上の定規は 1・3・5・2・4・8・7・9・10・11。下の定規は 2・5・1・3・7・6・4・8・9・11。どちらも全部ちがう。
  6. 測れない長さがあってもよい（上は6、下は10が測れない）。落としやすい所は、左右を逆にしただけの定規を2通り目にしてしまうこと。
答え：解説の図2，図3を参照のこと。（目盛りは 0・1・4・9・11 と 0・2・7・8・11。左右を逆にかいても同じ定規）

2 (1) 三角形ABCを直線mのまわりに回す A・8点｜回転体（円すい−円すい）

👀 まず見るところ

【条件文】部品は「円周率は3として」に丸。「2cm」「3cm」は図に置く。Cから直線mに引いた点線の3cmが半径 → 大きい円すいから小さい円すいをひく形に決まる。高さの差がABの2cm。

📚 前提知識

  • 円すいの体積は、半径×半径×円周率×高さ×1/3。
  • 底面が同じ円すいどうしのひき算は、高さの差だけで計算できる。たとえば高さ5cmと高さ3cmなら、高さ2cmの円すい1つ分と同じ。

🔍 整理して解く

  1. 点線が直線mとぶつかる点をPと書く。CPの3cmが半径になる。
  2. 三角形ACPを回すと大きい円すい。三角形BCPを回すと小さい円すい。求める立体は、大きい円すいから小さい円すいを取りのぞいた形。
  3. BPを□cmとする。大きい円すいの高さは 2＋□。小さい円すいの高さは □。ひくと□が消える。高さの差は2cm。
  4. 3×3×3×2×1/3＝18。
  5. 落としやすい所はBPの長さ。図に書かれていないが、ひき算で消えるので出さなくてよい。
答え：18cm³

2 (2) 直角三角形DEFを斜辺のまわりに回す A・8点｜回転体（円すい＋円すい）

👀 まず見るところ

【条件文】部品は「直角三角形DEF」と「3cm」「4cm」「5cm」。Eから直線mに垂直な線を引いて図に置く → その長さが半径で、円すい2つを合わせた形に決まる。半径は面積から出す。

📚 前提知識

  • 直角三角形で、いちばん長い辺を底辺にしたときの高さは、面積を2通りに表して出す。3×4÷2＝6。底辺を5にすると、高さは 6×2÷5＝2.4。
  • 半径が同じ円すい2つは、高さをたしてまとめて計算できる。

🔍 整理して解く

  1. Eから直線mに垂直な線を引く。ぶつかる点をQと書く。EQが半径になる。
  2. 三角形DEFの面積は 3×4÷2＝6cm²。DFの5cmを底辺にする。高さEQは 6×2÷5＝2.4cm。
  3. 上は三角形DEQを回した円すい。下は三角形FEQを回した円すい。高さは□cmと△cmで、合わせて5cm。
  4. 2.4×2.4×3×5×1/3＝28.8。
  5. 落としやすい所は半径。3cmや4cmは軸に垂直ではないので、半径に使えない。
答え：28.8cm³

2 (3) 長方形GHIJを対角線のまわりに回す B・9点｜回転体（折り返し・相似）

👀 まず見るところ

【条件文】部品は「長方形GHIJ」と「12cm」「16cm」。Jを直線mの左側に折り返して図に置く → 重なった形の外側だけ回せばよい。12：16＝3：4 で図2と同じ形と見えたら手を付ける。

📚 前提知識

  • 軸の右側にある部分は、軸で左側に折り返して回しても、できる立体は同じ。1回転すると同じ場所を通る。
  • 形が同じで長さが4倍の立体は、体積が 4×4×4＝64倍。長さが2倍なら 2×2×2＝8倍。

🔍 整理して解く

  1. 三角形GIJを直線mで折り返す。Jの行き先をJ′と書く。HIとGJ′が交わる点をR、Rから直線mに垂直に下ろした点をSと書く。

  3. 四角形GHRSは、三角形GHIから三角形RISを取った形。「三角形GHIの回転体」から「三角形RISの円すい」をひく。

  5. 三角形GHIは、(2) の三角形DEFの4倍の大きさ（3cm→12cm）。回転体は 28.8×64＝1843.2cm³。
  6. 三角形RISの円すいは 7.5×7.5×3×10×1/3＝562.5cm³。
  7. (1843.2−562.5)×2＝2561.4。

コツ：「考え方も書きなさい」とある。答案には「折り返すので四角形GHRSの2倍」「(2) の64倍」「円すいRISをひく」の3つを式といっしょに書く。

3 (1) 3つの荷物A・B・Cの運び方 A・8点｜場合の数（前の結果を使う）

👀 まず見るところ

【まざり型→条件文】部品は博士の言葉「玄関に置いた荷物がはじめてなくなるタイミングで場合分け」。2つ目のAの場所に直して書く → AA○○○○、A△△A○○、A○○○○A の3つに分かれ、中身は2つの荷物の運び方で数えられる。

📚 前提知識

  • 書き方の決まり。同じ文字の1つ目が博士、2つ目が助手。AABB は「博士A→助手A→博士B→助手B」。
  • 助手は上からしか取れない。Aはいちばん下にある。助手がAを運ぶのは、Aの上に何もないとき。だから、2つのAの間に出てくる荷物は、その間に全部トラックに運ばれている。
  • 2つの荷物の運び方は2通り（AABB と ABBA）。会話文に書いてある。

🔍 整理して解く

  1. 3つの荷物は6文字。1文字目は博士のA。2つ目のAの場所で3つに分ける。
    形入るもの通り
    AA○○○○○○○○はBとCの運び方。BBCC・BCCB2
    A△△A○○△△はBB。○○はCC1
    A○○○○A○○○○はBとCの運び方。BBCC・BCCB2
  2. たす。2＋1＋2＝5通り。
  3. 全部書くと AABBCC・AABCCB・ABBACC・ABBCCA・ABCCBA。落としやすい所は ABACBC のような形。Bがまだ玄関にあるのに、助手は下のAを運べない。
答え：5通り

4 (1) 図1とは別の折り方で正方形を作る A・8点｜折って切る作図

👀 まず見るところ

【資料問題】部品は「図1とは別の方法」と、完成図の点線（たてと横の折り目）。正体を1行「半分に折って、また半分」と書く → 折った形は左上の小さい正方形に決まる。切り口は図1と同じで、紙の中心から同じ長さをとる。

📚 前提知識

  • 開いた図の点線は、折り目のあと。図1の完成図は点線がななめ（対角線）。この問題の完成図は点線がたてと横。折り目がちがうと、正方形の向きが変わる。
  • 2回折ると、紙は4枚重ねになる。紙の中心に集まる角は 360÷4＝90度。この角をはさむ2辺から同じ長さをとって切ると、開いたときに4つの辺が同じ長さになる。

🔍 整理して解く

  1. 問題の1つ目の図を見る。左半分の長方形を、横の点線で下から上へ折る。できる形は、紙の左上にある小さい正方形。これを太い線でかく。
  2. 紙の中心がどこに来たかをさがす。小さい正方形の右下のかどが、もとの紙の中心になる。
  3. 右下のかどから、下の辺と右の辺に同じ長さをとる。その2点を通るまっすぐな線が切り口。等しい長さの印も2か所につける。
  4. たしかめ。切り取った直角二等辺三角形を、横の折り目、たての折り目の順に開く。4つ集まって、かどが上下左右を向いた正方形になる。完成図と同じ。
  5. 落としやすい所は、切り口を左上のかどの側に入れてしまうこと。中心は右下のかどなので、そちら側を切る。
答え：解説の図Ⅰ㋑を参照のこと。（左上の小さい正方形を太線でかき、その右下のかどから同じ長さの所を結ぶ切り口をかく。同じ長さの印もつける）

4 (2) 正八角形・正六角形の折り方の角度①② A・8点｜折り紙と角度

👀 まず見るところ

【条件文】部品は「正八角形」「正六角形」。それぞれ 360÷8＝45度、360÷6＝60度に直して、図の紙の中心の角に書く。①は等しい長さの印がある二等辺三角形の底角で出る。②は60度がそのまま答えになる。

📚 前提知識

  • 正八角形は、中心から頂点に線を引くと、同じ二等辺三角形8つに分かれる。中心の角は 360÷8＝45度。正六角形なら 360÷6＝60度。
  • 二等辺三角形は、残りの2つの角が同じ大きさ。頂角が45度なら、(180−45)÷2 で出る。
  • 折って重なる角は、同じ大きさ。

🔍 整理して解く

  1. ①から。図2の3番目の図で、三角形の右はしのとがった点が紙の中心。ここに45度と書く。
  2. 切り口で切り取る三角形には、等しい長さの印が2つある。頂角45度の二等辺三角形になる。①はその底角。
    (180−45)÷2＝67.5度
  3. 次に②。図3の1番目の図で、紙の中心は長方形の右の辺のまん中。半分に折った紙では、中心のまわりは180度ある。
  4. 開くと正六角形になる。だから、この180度を60度ずつ3つに折り重ねている。赤い点線は、下から1つ目の60度の区切り。②は右の辺と赤い点線の間の角なので 60度。
  5. たしかめ。赤い点線で折ると、右下のかどは60度の2つ分だけ回る。中心から右下のかどまでは、紙の1辺の半分。回った先は、上から4分の1の点線の上にちょうど乗る。図の●の位置と合う。
  6. 落としやすい所は、①を45度と答えてしまうこと。45度は中心の角。①は切り口の側の角。
答え：①67.5度　②60度

4 (3) 開くと正三角形になる折り方をかく C・10点｜折って切る作図

👀 まず見るところ

本番では後回し。【資料問題】部品は「正三角形がかかれた折り紙の折り目」。点線の本数を図3の正六角形とくらべ、正体を1行「図3より折り目が1回分少ない」と書く → 図3の2番目の図で止めて切ると決まる。

📚 前提知識

  • 正三角形は、中心から3つの頂点に線を引くと、頂角 360÷3＝120度の二等辺三角形3つに分かれる。120度は、(2)の60度の2つ分。

🔍 整理して解く

  1. 図3の1番目、2番目の図をそのままかく。半分に折った長方形を、赤い点線で折り上げた形まで。3番目の折りはしない。
  2. この形で、紙の中心に集まる角は 60×2＝120度。中心から、右の辺の上向きと、折り上げた紙の下の辺に、同じ長さをとる。その2点を通る線が切り口。等しい長さの印もつける。
  3. たしかめ。切り取った形は頂角120度の二等辺三角形。開くと3つ集まって正三角形になる。折り目は、たての線と、ななめ下への2本。問題の完成図と同じ。
答え：解説の図Ⅳを参照のこと。（図3の1番目・2番目と同じ図をかき、3つ目の図で、紙の中心から右の辺と折り上げた紙の下の辺に同じ長さをとって切り口をかく）

4 まとめ

  • 折って切る問題は、まず紙の中心がどこに来たかに印をつける。
  • 中心の角は「360÷頂点の数」。正方形90度、正八角形45度、正六角形60度、正三角形120度。
  • 切り口は、中心の角をはさむ2辺から同じ長さをとる。完成図の点線の本数が、折る回数の手がかりになる。
