【資料問題】部品は「国債の発行（借金）による収入」と「国債費」。前者をグラフの凡例の「公債金」に直して書く → 歳入と歳出の棒の合計はほぼ同じなので、公債金が国債費より大きい年が赤字と決まる。知識がなくても決まる。

📚 前提知識（あれば答え合わせに使う）

  • プライマリーバランス＝借金を除いた収入と、借金の返済を除いた支出のつり合い。赤字＝その年の税などだけでは支出がまかなえていない（本文）。

🔍 こう読み解く

  1. 斜線の2本だけ見比べる。1990年 公債金5.6＜国債費14.3／2000年 32.6＞22／2010年 44.3＞20.6／2020年 36.9＞24.3。
  2. 声教の解説のように足し算でも確かめられる。公債金を除いた歳入と、国債費を除いた歳出（兆円）は次のとおり。
    年公債金を除いた歳入国債費を除いた歳出判定
    1990年60.651.9黒字
    2000年52.463赤字
    2010年47.971.7赤字
    2020年70.683.3赤字
  3. 赤字は2000年・2010年・2020年。1990年の歳入の「2.6」（その他収入）を足し忘れても、1990年は黒字のまま。
答え：イ・ウ・エ

👀 まず見るところ

  1. 表1：D 60件中58件成立、E 67件中13件成立。成立しやすいD＝内閣、E＝議員 → アかイ。
  2. 残りは国会法の数字。衆議院＝20人、参議院＝10人なので、B＝20、C＝10のイ。アのB＝10、C＝15は数字がちがう。

3 問6 国務大臣の資格や業務 B・2点｜正誤・すべて選ぶ（完答）

👀 まず見るところ

【素材文】聞かれ方「正しいもの」「すべて」に丸。部品は各文の決め手「全員」「衆議院議員」「官房長官」「兼任」「文民である必要はありません」に丸 → 憲法の決まりと1語ずつ照らして○×を決める。

📚 前提知識

  • 憲法第68条：国務大臣は内閣総理大臣が任命し、そのうち過半数は国会議員でなければならない。
  • 憲法第66条：国務大臣は防衛大臣もふくめて全員が文民でなければならない。

🔍 こう読み解く

  1. ア 全員を内閣総理大臣が任命 → ○。ウ 内閣官房長官も国家公安委員会委員長も国務大臣 → ○。
  2. イ「過半数は衆議院議員」→ 正しくは国会議員（参議院議員でもよい）。せまく言いすぎ → ×。
  3. エ「兼任が許されていません」→ そのような決まりはなく、首相が国務大臣を兼任した例もある → ×。オ「全員が文民である必要はありません」→ 第66条と逆 → ×。
答え：ア・ウ

4 Ⅰ 新井白石が天皇家と結びついた意図 B・4点｜意図の記述・資料1

👀 まず見るところ

【資料問題】部品は資料1の6代家宣の在任「約3年」と7代家継の就任時の年齢「3歳」。直前の3〜5代（在任約28〜29年）とくらべてずばぬけて短く、就任の年齢もいちばん若いので「将軍がすぐ亡くなり、次は幼い→将軍の権威が弱まる」と1行に直して書く → 天皇家と結びついた意図が決まる。

📚 前提知識（あれば答え合わせに使う）

  • 将軍（征夷大将軍）は天皇によって任命される。だから天皇家が安定していることは、将軍家の安定にもつながる（声教の解説）。
  • 政策の文：財政難の天皇家のために幕府が費用を献上して閑院宮家を創立し、満5歳の将軍家継と2歳の皇女の婚礼を発表した。

✍️ 答案の組み立て

  1. 要素A（困りごと・資料1）：6代将軍はすぐ亡くなり、7代将軍は幼い → 将軍の権威が落ちることを心配した。
  2. 要素B（したこと・政策の文）：費用を出して宮家をつくり、幼い将軍と皇女を婚約させた → 天皇家との結びつきを強めた。
  3. 要素C（ねらい）：天皇家を後ろだてにして、将軍（幕府）の権威を高めようとした。
模範解答：6代将軍はすぐ亡くなり，7代将軍は幼少だったため，将軍の権威が落ちることを心配した新井白石は，天皇家との結びつきを強くして将軍（幕府）の権威を高めようとした。
コツ：「資料1を参考にして」とある記述は、資料の中でずばぬけた数字を1つ見つけ、それが「何が困るのか」を書くと要素Aになる。

4Ⅱ 問1 相続税で2人の相続額の差はどうなるか A・2点｜計算・解答らんに合わせる

👀 まず見るところ

【条件文】部品は「3000万円＋(600万円×相続人の数)」に収まれば「課税の対象とはなりません」と、Bさんの「3,000万円」。1人で相続なので3600万円以下＝Bさんは税が0円と直して書く → Aさんは本文の計算例そのままで決まる。

📚 前提知識（あれば答え合わせに使う）

  • 計算に使うのは本文の「相続税の計算方法」だけ。Aさんは例と同じ「1人で1億円」なので、相続税は例の1,920万円。

🔍 こう読み解く

  1. 相続税がないとき：1億円−3000万円＝7000万円の差。
  2. 相続税があるとき：Aさん 1億円−1920万円＝8080万円。Bさん 3000万円は3600万円以下なので税はなく3000万円のまま。差は8080万円−3000万円＝5080万円。
  3. 7000万円−5080万円＝1920万円。差は1920万円小さくなる。
  4. 落としやすい所：Bさんにも30％をかけてしまうこと。解答らんの「2人が相続する額の差は」に続くので、「小さくなる」まで書く。
答え：1920万円小さくなる。

4Ⅱ 問2 相続税があることの社会での利点 B・3点｜説明記述・指定語句

👀 まず見るところ

【条件文】部品は「問1の計算の結果を踏まえた上で」と指定語句「固定」。問1の「差が小さくなる」を「財産の多い家と少ない家の格差が縮む」と直して書く → 「格差の固定化を防ぐ」で利点の文が決まる。

📚 前提知識（あれば答え合わせに使う）

  • 本文：相続税には累進課税制度が組み込まれ、相続する額が多いほど税率が高い。財産の少ない家の相続では税を払わなくてよい。
  • 相続税がなければ、親から受け継ぐ財産の差が、そのまま子どもの世代の差として続いていく。

✍️ 答案の組み立て

  1. 要素A（何の差か）：生まれた家庭の環境によって、多くの財産を相続する人と、相続する財産を持たない人がいる。
  2. 要素B（利点）：相続税で差が縮まり、格差の固定化を防ぐことができる。指定語句「固定」はここで使う。
模範解答：相続税があることで，生まれた家庭の環境により，多くの財産を相続する人と相続する財産を持たない人との格差の固定化を防止することができるという利点がある。
コツ：指定語句は、何が「固定」されるのかを考えると使う場所が決まる。ここでは「格差」が固定される。

  • 正誤の文は文の最後の部分ですりかえられていることが多い（3 問3の後半、3 問6の「衆議院議員」）。
  • グラフの計算は、本文の言葉を凡例の言葉に直して書いてから（3 問4 国債の発行による収入＝公債金）。
  • 4Ⅱは本文の計算例をなぞる問題。課税されない人がいないかを先に確かめる。
