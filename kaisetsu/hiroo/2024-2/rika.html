2 問2 水の高さをそろえてから測る理由 B・2点｜記述

👀 まず見るところ

【条件文】部品は下線部①の「ビーカー内外で水の高さが同じになるようにしてから」。同じ言葉が実験の最初にもあることに丸 → 測る前に毎回そろえる条件。「高さがちがうと中の空気がどうなるか」に直して書く。

📚 前提知識

  • 空気はおされるとちぢみ、引かれるとふくらむ。同じ量の空気でも、おされ方がちがうと体積（気体部分の高さ）が変わる。
  • ビーカーの中と外で水面の高さが同じとき、中の空気をおす力は外の空気と同じになる。

✍️ 答案の組み立て

  1. 要素A（どんなとき）: ビーカー内外で水の高さがちがうと。
  2. 要素B（何が起こる）: 中の空気が圧縮されたりぼう張したりして、高さを正しくくらべられない。
  3. この実験は気体の体積を「気体部分の高さ」で測っている。燃やす前の10cmと同じ条件にそろえて、はじめてへった分が分かる。
答え：ビーカー内外で水の高さが違うと，ビーカーの中の空気が圧縮されたりぼう張したりするから。

3 問3 同じ場所でくらす鳥と渡る鳥のちがい B・4点｜記述（空らん2つ）

👀 まず見るところ

【素材文】部品はお父さんの言葉「渡る一番の理由はエサを確保するため」に丸。空らんの後ろの「けど」「から他の場所に移動する」から、ⅠとⅡはエサについて反対の内容と決まる。丸の言葉「エサ」をそのまま使って書く。

📚 前提知識

  • 季節が変わると、その場所で手に入るエサ（虫・木の実・草など）の種類と量が変わる。

✍️ 答案の組み立て

  1. Ⅰ（同じ場所でくらせる鳥）: 1年中そこにいてもエサに困らない理由を書く。そのときにあるエサを何でも食べられるから、季節でエサが変わっても平気。
  2. Ⅱ（渡る鳥）: Ⅰの反対。特定のエサしか食べられないので、季節でそのエサがなくなると、ある場所へ移動するしかない。
  3. 文の形をそろえる。Ⅰは「〜けど」に、Ⅱは「〜から」につながるように書き、「エサ」の語を両方に入れる。
模範解答：Ⅰ そのときにあるエサを何でも食べることができる　Ⅱ 特定のエサしか食べられない
コツ：声の教育社の解説は、Ⅰに「エサが豊富にある」、Ⅱに「季節によってエサがなくなってしまう」という内容も理由として挙げている。エサについて反対の内容になっていることが大事。

3 問4 ホシムクドリの飛行衝動の実験 B・4点｜実験の図＋条件を1つだけ変える

👀 まず見るところ

【まざり型→資料問題】部品は図の正体「細いオレンジ色の矢印は太陽光の向き」「太い黒い矢印は黒丸の示す向きの平均的な方向」。図2〜4それぞれで、鳥に当たる光の矢印と黒い矢印の角度を見比べる → 3つとも同じずれ方なら、それが答え。時間が残っていれば取り組む。

📚 前提知識

  • 実験で何かを証明するときは、変える条件は1つだけにして、ほかは全部そろえる。2つ同時に変えると、どちらが原因か分からない。
  • 1羽だけの結果では、その鳥だけのくせかもしれない。数を増やして同じ結果になれば確かになる。

🔍 こう読み解く

  1. (1) 図3・図4は鏡で光の向きを変えている。鳥に当たる光は、鏡ではね返って窓から入る短い矢印のほう。この矢印と黒い矢印を見比べる。
  2. 図2は光が左上へ進み、黒い矢印はそれより少し左にたおれた左上。図3は光が左下へ、黒い矢印は真下。図4は光が右上へ、黒い矢印は真上。どれも、光の進む向きから反時計回りに少しずれた向き。
  3. 同じ午前9時なのに、黒い矢印は左上・下・上と変わった → 時刻で向きが決まるアは×。光と同じ向きでも反対向きでもない → イ・ウも×。ずれは窓の間かく60°より小さいので、反時計回りに30°のオ。
  4. (2) 証明したいのは「太陽の位置を確認し」「春に」の2つ。太陽を確かめるには光だけをなくす → オ（窓をふさぐと飛行衝動をしない）。春を確かめるには季節だけを変える → ア（違う季節の同じ時間）。1羽だけでは足りないので数を増やす → エ。
  5. 残りを消す。イ・キ・クは季節と時間など2つ以上を同時に変えている。ウは、問4の最初の説明「太陽が出ているどの時間帯でも」北西を向く、と合わない。カは鳥かごの大きさで、太陽とも春とも関係がない。
答え：(1)オ　(2)ア・エ・オ
コツ：(2)は3つそろって正解（完答）。選択肢の先頭の「同じ季節／違う季節」「同じ時間／違う時間」に丸をつけ、変えたものが1つだけの選択肢を残す。

3 問6 ハクチョウがV字で飛ぶ理由 B・2点｜記述

👀 まず見るところ

【資料問題】部品は図5の正体「決まったフォーメーション＝V字のならび」と「黒い矢印は，進む方向」に丸。先頭は1羽だけで、ほかの鳥は全部だれかのななめ後ろにいる → 「前の鳥のおかげで後ろの鳥が楽になる」形で書くと決まる。

📚 前提知識

  • 鳥が羽ばたいて進むと、その後ろに空気の流れができる。ななめ後ろの鳥はその流れに乗れるので、使う力が少なくてすむ。
  • 渡り鳥は長い距離を飛ぶ（会話文に「飲まず食わずで何日も飛び続ける鳥もいる」）。エネルギーの節約が大切になる。

✍️ 答案の組み立て

  1. 要素1（原因）: 前を飛ぶ鳥が起こす空気の流れ。
  2. 要素2（結果）: 後ろの鳥は少ないエネルギーで飛べる。
  3. 「なぜ」と聞かれているので、文末は「〜から。」で終える。「迷子にならないため」は下線部⑤の「群れ」の理由で、V字の形の理由にはならない。
模範解答：前を飛ぶ鳥が起こす空気の流れのおかげで，後ろの鳥は少ないエネルギーで飛ぶことができるから。

4 問2 西の空を見るときの持ち方 A・2点｜図の読み取り

👀 まず見るところ

【資料問題】部品は図1の「北」のラベルと、図2のメモ「自分が向いている方角が書いてある側を手前に持ち」。北の向かいのB＝南と図に書きこむ（図に置く）→ 残るAとCのどちらが西かを決めれば答えになる。

📚 前提知識

  • 星座早見盤は頭の上にかざして見上げて使う。そのため、地面に置いて見下ろす地図とは東西が反対になる。

🔍 こう読み解く

  1. 上が北なので、下のBは南。
  2. 地図なら北を上にすると右が東。星座早見盤は東西が反対なので、右のAが西、左のCが東。
  3. 西の空を見たいので、西と書いてある側＝Aを手前にして持つ。
  4. 落としやすい所: 地図と同じつもりで左のCを西にしない。
答え：A

4 問3 早見盤の②の目盛り B・2点｜図の読み取り・短い説明

👀 まず見るところ

【資料問題】部品は「②の目盛り」の正体を1行: ①の北極星のところから、窓のふちへ向かってのびる線についた目盛り。方位はふちの東西南北で読むので、残る「空のどの高さか」を読む目盛り → 高度と答える。図から正体が書けたら手を付ける。

📚 前提知識

  • 星の位置は「方位」と「高度（地平線から何度上か）」の2つで表す。方位は早見盤のふちの東西南北で分かるので、残る目盛りは高度。

🔍 こう読み解く

  2. ②の目盛りは、北極星のある中心から窓のふちに向かってのびている。星座の位置をこの目盛りで読むと、その星座が見える高さ（高度）の目安になる、と答える。

4 問4 2か月後・2時間後の冬の大三角 A・2点｜星の動きの計算

👀 まず見るところ

【条件文】部品は「2か月後」と「22時」（1月は20時）。そのままでは使えないので角度に直して書く: 2か月→30°×2、2時間→15°×2。南東から西へ合計何度動くかで方角が決まる。

📚 前提知識

  • 同じ時刻に見ると、星は1か月に約30°ずつ東から西へ動く（地球の公転。12か月で360°）。
  • 同じ日のうちでは、星は1時間に15°ずつ東から西へ動く（地球の自転。24時間で360°）。

🔍 こう読み解く

  1. 余白に式を書く。2か月後の同じ20時: 30×2＝60（度）西へ。
  2. さらに20時から22時まで2時間: 15×2＝30（度）西へ。
  3. 合わせて 60＋30＝90（度）西へ動く。
  4. 8方位はとなりどうしが45°。南東から45°で南、もう45°で南西。
  5. 落としやすい所: 「2時間晴れるのを待ち」の分を足し忘れると60°で止まり、南と南西の間になって選べない。
答え：カ

4 問5 天の川銀河の見え方と公転軌道面 B・4点｜説明文＋図の読み取り

👀 まず見るところ

【まざり型→素材文】(1)の部品は「天球を1周するように存在」と「Xが天の川銀河の中心部分」に丸 → 1周＝360°、中心ならどの向きにも星が同じ。(2)の部品は「図5を参考にして」→ 図5で星座の並びと天の川の帯が交わる形を見る。材料は全部問題文にあるので手を付ける。

📚 前提知識

  • やぎ座・いて座・さそり座・てんびん座は、黄道（天球上の太陽の通り道）にならぶ星座。黄道は地球の公転軌道面を天球にうつしたものにあたる。

🔍 こう読み解く

  1. (1)① 今のYの位置でも、天の川は図4のIのように天球を1周している。うずまきの円ばんの中にいるからで、中心のXに移っても円ばんの中にいるのは同じ → 360°。
  2. (1)② 今は中心からはなれたYにいるので、中心（いて座・さそり座の方向）とその反対側で星の集まり方がちがう。中心のXにいれば、まわりに星がかたよりなく集まる → 明るさは「どの方向でも同じ」。組み合わせはア。
  3. (2) 図5では、やぎ座・いて座・さそり座・てんびん座が左右にならぶ。この並びが公転軌道面。天の川の帯は、その並びをななめに横切っている。
  4. 選択肢で、2つの輪がななめに交わるのはイ。アは直角に交わる、ウは重なる、エは交わらないので、図5と合わない。
答え：(1)ア　(2)イ
