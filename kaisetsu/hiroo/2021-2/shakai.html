1 問1①② C班・D班の発電 A・2点×2｜語句記述

👀 まず見るところ

【素材文】部品は【ア】の説明「動植物などから生まれた生物資源の総称」と、【イ】の「蒸気タービンを【イ】を利用して回す」に丸。1文に手がかり1語で、それぞれの発電の名前が決まる。

📚 前提知識

  • バイオマス＝動植物など生物に由来するエネルギー資源。直接燃やすか、発酵させてガスを取り出して燃やし、熱や電気を得る。
  • 地熱発電＝火山や温泉のある地域の地中深くから得られる高温・高圧の水蒸気でタービンを回す。天候や季節に左右されない。

🔍 こう読み解く

  1. 【ア】：「生物資源の総称」「廃棄されていたものを燃料とする」→ 生物由来の資源＝バイオマス。
  2. 【イ】：蒸気タービンを回す熱の出どころで、「天候や季節に左右されることなく」安定し、八丁原（大分県九重町）が例 → 地熱。
  3. 落としやすい所：【イ】は「太陽光発電や風力発電とは異なり」とあるので、天気まかせの発電は入らない。
答え：① バイオマス　② 地熱

1 問3 原子力発電の原料 A・2点｜知識問題

ウラン。原子力発電はウランを濃縮して燃料にし、原子炉の中で核分裂させた熱で発電する。発電時に二酸化炭素をほとんど出さない一方、放射性物質がもれないよう厳しい管理が要る。カタカナ3字。

1 問4 総エネルギー供給の割合 A・2点｜資料問題・帯グラフ

👀 まず見るところ

【資料問題】正体を1行「日本の総エネルギー供給・割合・1970〜2017年度」。部品は1970年度の帯で、いちばん長いⅡとほとんど無いⅢ。この2つが決まれば残りも決まる。

📚 前提知識

  • 日本のエネルギーの中心は石油。1973年の石油危機（オイルショック）のあと、少しずつ割合が下がった。
  • 液化天然ガス（ガス）は1969年に輸入が始まった。燃やしたときの二酸化炭素が化石燃料の中で最も少なく、近年は石炭と並ぶほどになった。

🔍 こう読み解く

  1. Ⅱはどの年度でもいちばん長く、年ごとに短くなる → 石油危機で減っていった石油。
  2. Ⅲは1970年度にはほとんど無く、あとで大きく伸びる → 輸入が始まったばかりのガス。
  3. 残ったⅠが石炭。Ⅰ石炭・Ⅱ石油・Ⅲガスの組み合わせはエ。
  4. 落としやすい所：近年はⅠとⅢが同じくらいの長さなので、2017年度から見ると迷う。1970年度の帯から見る。
答え：エ

1 問5 六ヶ所村の地形図と写真 B・2点｜資料問題・地形図

👀 まず見るところ

【資料問題】部品は地図の「戸鎖川」の線と、写真に川が写っているか。川の写っていない写真が、川の線の上にないbと決まる。時間がかかる問題なので、他を終えてから手を付ける。

📚 前提知識（あれば答え合わせに使う）

  • 知識がなくても決まる。矢印はすべて東向きなので、地図で矢印の先に何があるかを写真と比べるだけ。

🔍 こう読み解く

  1. aは「戸鎖川」の字のすぐ左、cは川の線をまたぐ道路の上。bだけが川の線の上になく、道路のカーブの上にある。写真Ⅲは道路と左手の山だけで川が写っていない → Ⅲ＝b。
  2. 残るⅠ・Ⅱは川の写真。aは「戸鎖川」の上流側で、川ぞいの低い土地の両側に等高線（山）がある。前方に山が見える写真Ⅱ → Ⅱ＝a。
  3. cは川をまたぐ道路の上で、矢印の先は地図で何もかかれていない白い広がり（水面）。すぐ手前に橋の手すりがあり、前方の視界が開けている写真Ⅰ → Ⅰ＝c。Ⅰc・Ⅱa・Ⅲbはオ。
答え：オ

👀 まず見るところ

【素材文】聞かれ方「誤っているもの」に線。各文の人物名に丸をつけ、出来事と組み合わせが合うかだけを見る。オの「平将門」が兵庫の港と結びつかない時点で決まる。

📚 前提知識

2 問6① 明治の外交史料の並べかえ B・2点｜史料の並べかえ（完答）

👀 まず見るところ

答え：2番目…D　4番目…E

3 問3 年齢階層別のジニ係数 B・1点｜資料問題・正しいもの

👀 まず見るところ

【資料問題】正体を1行「年齢階層別の当初所得と再分配所得のジニ係数」、決まり「1に近づくほど格差が大きく」。濃い棒と斜線の棒の差がどの年齢で大きいかを見れば、ア〜ウは知識がなくても消せる。読むのは棒の差だけなので手を付ける価値がある。

📚 前提知識（あれば答え合わせに使う）

  • 当初所得＝給与など。再分配所得＝税金・社会保険料をはらい、社会保障の給付を受けたあと。2本の棒の差＝再分配で格差がどれだけ縮んだか。
  • 高齢者は働いて得る収入の差が大きいが、年金や医療・介護保険などの給付で差が縮む。

🔍 こう読み解く

  1. グラフ全体: 60歳より右（高齢）へ行くほど濃い棒が高くなり、斜線の棒との差が開く。29歳以下は2本がほぼ同じ高さで、30代も差は小さい。
  2. ア 75歳以上は「当初所得の段階では格差が小さい」→ 濃い棒は75歳以上がいちばん高い → ×（逆）。イ 現役世代の差が「65歳以上の高齢者よりも大きく」→ 差が大きいのは高齢者側 → ×（逆）。ウ 20代や30代の差が「他の世代に比べて大きく」→ 差は小さい → ×。
  3. エ 65歳以上で2本の棒の差が大きく、再分配後に格差が縮んでいる → グラフと合い、背景（年金・医療・生活保護・介護保険）も正しい → ○。
答え：エ

3 問6 解職請求の署名を提出する機関 A・2点｜知識問題

4 Ⅰ 着色された国の「ある共通点」 B・2点｜地図＋理由の記述

👀 まず見るところ

【資料問題】部品は「第二次世界大戦後」と「理由を含めて」。着色の正体を1行（ヨーロッパ中央・東アジアの半島・インドシナ半島の東岸＝ドイツ・朝鮮半島・ベトナム）→ 共通点は「分断」、理由は冷戦と決まる。

📚 前提知識

  • 第二次世界大戦後、アメリカ中心の西側（資本主義）とソ連中心の東側（社会主義）が対立した。直接戦火を交えなかったので冷戦という。
  • ドイツは東西に、朝鮮半島とベトナムは南北に分かれた。ドイツは1990年、ベトナムは1976年に統一。朝鮮半島は1950〜53年の朝鮮戦争のあとも分かれたまま。

✍️ 答案の組み立て

  1. 部品A（理由）：冷戦の影響で（西側と東側の対立）。

  3. 出力の形: 「（冷戦の影響で）、（東西もしくは南北に分断された）国家。」 共通点を聞かれているので文末は体言止めでよい。
模範解答：冷戦の影響で，東西もしくは南北に分断された国家。
コツ：理由を答える部分に「戦争があったから」だけを書くと、第二次世界大戦そのものと区別できない。「冷戦」の2字を入れる。

4 Ⅱ ボルダルールで選ばれるリーダー B・2点｜計算＋指定語句の記述（完答）

👀 まず見るところ

【条件文】部品は「24票で1位」（ふさわしくない）と「計40名」。40−16＝24 に直して書く → A君を1位にしなかった24人全員がA君を3位にした、と決まり、全員の順位表が作れる。

📚 前提知識（あれば答え合わせに使う）

  • ボルダルール：1位3点・2位2点・3位1点を全員分たす。だれの1票でも 3＋2＋1＝6点が配られるので、3人の合計は 40×6＝240点になる（検算に使える）。

🔍 こう読み解く

  1. B支持の14人とC支持の10人、合わせて24人が「A君が最もふさわしくない」＝A君を3位。だからB支持はA君3位・Cさん2位、C支持はA君3位・Bさん2位。
  2. 順位表にまとめる（図2のA支持16人の内わけ7人・9人も入れる）。
    投票した人人数1位2位3位
    A支持その17ABC
    A支持その29ACB
    B支持14BCA
    C支持10CBA
  3. A君＝16×3＋24×1＝72点。Bさん＝14×3＋(7＋10)×2＋9×1＝85点。Cさん＝10×3＋(9＋14)×2＋7×1＝83点。72＋85＋83＝240 で検算も合う。多数決1位のA君は3位になる。

✍️ 長所の説明の組み立て

  1. 部品A（多数決の弱点）：一部の人たちから高い支持を集めた人が選ばれてしまう（A君は16人に1位、24人に3位）。
  2. 部品B（ボルダルールの長所）：広く全体から支持を集めた人を代表に選べる（Bさんは3位が9人だけ）。
  3. 出力の形: 「（一部の人たちから高い支持を集めている人）ではなく、（広く全体から支持を集めている人）を選べるところ。」 指定語句「一部」「全体」をそのまま入れ、長所を聞かれているので「〜ところ。」で終える。
模範解答：B（さん），85（点）／（例）　ボルダルールだと，一部の人たちから高い支持を集めている人ではなく，広く全体から支持を集めている人を代表として選ぶことができるところ。
コツ：「1人6点ずつ配られる」と気づけば、3人の合計240点で計算ミスを見つけられる。
