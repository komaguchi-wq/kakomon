3 問1 条件Bと条件Cを比べてわかること A・2点｜対照実験・最も適当なもの

👀 まず見るところ

【まざり型→資料問題】部品は「条件Bと条件C」の2行と、結果の「条件A〜C」が発芽。BとCでちがう言葉に丸（だっし綿／土）→ ちがうのは土だけで結果は同じ → 土は関係ないと決まる。

📚 前提知識

  • 2つの実験を比べてわかるのは、ちがえた条件1つについてだけ。結果が同じなら「その条件は必要ではない」、結果がちがえば「その条件が必要」。

🔍 こう読み解く

  1. B「水と肥料を含んだだっし綿の上に置く」、C「水と肥料を含んだ土にうめる」。水・肥料・25℃・明るさは同じで、ちがうのは土があるかないかだけ。
  2. 結果はどちらも発芽。土が無いBでも発芽した → 土は発芽に必要な条件ではない → カ。
  3. 落としやすい所: オ「肥料が必要な条件ではない」は内容としては正しいが、BもCも肥料ありなので、この2つからは言えない（肥料はAとBを比べるとわかる）。設問の「条件Bと条件Cの実験結果を比べたときに」に丸をつけてから選ぶ。
答え：カ

3 問2 「空気」が必要かを調べる組み合わせ A・2点｜対照実験・組み合わせ

👀 まず見るところ

【まざり型→資料問題】部品は「空気」と、条件G・Hの「水に沈める」。「水に沈める」を「空気なし」に直して書く → 空気だけがちがい、肥料は同じ組をさがすと A と H に決まる。

📚 前提知識

  • 水の中に沈めた種子は空気にふれない。だっし綿の上に置いた種子は空気にふれている。
  • ちがう条件が2つある組では、結果の原因がどちらなのか決められない。

🔍 こう読み解く

  1. 空気なしは G と H。G は「肥料をとかした」水、H は「肥料をとかさない」水。
  2. A は「水を含んだだっし綿」で肥料なし。A と H は、水あり・肥料なし・25℃ が同じで、ちがうのは空気だけ → ウ。
  3. イ（AとG）は空気と肥料の2つがちがう。ア（AとD）は水、エ（DとE）とキ（GとH）は肥料を調べる組。オ（DとG）とカ（DとH）は、空気のほかに水の有無もちがう。
  4. 落としやすい所: 「沈める」だけを見て G を選ぶ。G の「肥料をとかした」に丸をつけると、A と肥料がそろわないことに気づける。
答え：ウ

3 問3 「光が必要」という仮定を証明する実験 A・2点｜対照実験・仮定と結果

👀 まず見るところ

【まざり型→条件文】部品は「条件Aの実験を、どのように変えた条件で」と「必要な条件であると仮定」。変えるのは光1つだけ、「必要」は「無いと発芽しない」に直して書く → 暗くして発芽しない、が証明になる。

📚 前提知識

  • 「○○が必要」を証明するには、○○だけを無くした実験で発芽しないことを見せる。ほかの条件まで変えると、発芽しない原因が分けられない。

🔍 こう読み解く

  1. 条件Aは、明るい・25℃・水ありで発芽した。ここから光だけを無くす＝室内を暗くする。
  2. 仮定が正しければ、暗くしたときは発芽しないはず → イ「室内を暗くすると、発芽が見られない」。
  3. ウ・エは室温も5℃に下げている。5℃で明るい条件 I は発芽しなかったので、暗くて5℃で発芽しなくても、光のせいか温度のせいか分けられない。
  4. 落としやすい所: ア「暗くすると、発芽が見られる」は、光が必要ではないことを示す結果。仮定の証明とは逆になる。
答え：イ
コツ：実際のインゲンマメは暗い所でも発芽する。この問は事実ではなく「仮定が正しいなら、どんな結果になるはずか」を聞いている。

3 問4 インゲンマメとトウモロコシの種子で子葉となる場所 A・2点｜図の読み取り・組み合わせ

👀 まず見るところ

【資料問題】部品は聞かれ方「子葉となる場所」に線。図の正体は図2「インゲンマメの種子」と図3「トウモロコシの種子」の断面。a〜f の名前を図に書きこむ → 子葉は b、トウモロコシで子葉になるのは胚の d。

📚 前提知識

  • インゲンマメは発芽のための栄養分を子葉にたくわえる。トウモロコシは胚乳にたくわえ、子葉は胚の一部として小さく入っている。

🔍 こう読み解く

  1. 名前を図に書きこむ。
    記号名前はたらき
    a種皮外側の皮
    b子葉栄養分をたくわえている
    c胚の一部（bとcで胚）発芽後に根・くき・本葉になる
    d胚発芽後に子葉などからだになる
    e胚乳栄養分をたくわえている
    f種皮外側の皮
  2. 図2で種子の大部分をしめる b が子葉。図3で大きい e は胚乳で、下の小さい d が胚。子葉になるのは d のほう → b と d＝イ。
  3. 落としやすい所: ウ（b と e）。e は「栄養分をたくわえる」点が b と同じなので選びたくなるが、胚乳は子葉にならない。聞かれているのは栄養分の場所ではなく子葉となる場所。
答え：イ

3 問6①② 水耕栽培の説明として適当なものを2つ B・4点｜素材文・2つ選ぶ

👀 まず見るところ

【素材文】部品は本文の「土を使わなくても」「水に養分をとかした液体」に丸。「土が原因の困りごとが無い」「入れる養分を自分で決められる」に直して書く → 合う選択肢は2つだけ。選択肢の形が2組と気づけたら手を付ける。

📚 前提知識

  • 土にはもともといろいろな養分がまじっている。同じ場所で同じ作物を作り続けると、土の養分がかたよるなどして育ちが悪くなる（連作障害）。

🔍 こう読み解く

  1. 選択肢を2組に分ける。ア・イ・ウは「土壌栽培では困難だが、水耕栽培なら〜調べることができる」、エ〜キは「土壌栽培よりも水耕栽培のほうが〜」。
  2. ア・イ・ウ: 水耕栽培は入れる養分とその割合を自由に変えられるので、生育に必要な最低限の栄養素を調べられる → イ。光の色（ア）や蒸散のしくみ（ウ）は土で育てていても調べられるので、「土壌栽培では困難」が合わない。
  3. エ〜キ: 土を使わないので、同じ場所で作り続けることによる栄養の障害が起こらず、収穫量が落ちにくい → カ。エの根菜類は、一般に土壌栽培のほうが適している。
  4. オとキは本文の言葉から考えて切る。オ: 「水に浮くパネルなどになえを固定」するだけなので、背の高い植物は支えにくいと考えられる。キ: 土が無く「施設内」なので雑草は生えにくく、除草の手間はむしろ少ないと考えられる。
答え：イ・カ

4 問1 P波・S波の文章の空らん①〜③ A・2点｜素材文・空らんの組み合わせ

👀 まず見るところ

【まざり型→素材文】部品は空らんの前の言葉「P波を最初に感じるのは」「地震の規模の大きさは」に丸。②は直前の「ほとんど同時に到達する。しかし」に丸 → ①速い ②大きく ③マグニチュード とその場で決まる。

📚 前提知識

  • P波とS波は震源を同時に出発する。先に着くP波のほうが速い。遠い地点ほど、着く時刻の差（PS時間）は開く。
  • マグニチュード＝地震そのものの規模。震度＝それぞれの場所でのゆれの大きさ。

🔍 こう読み解く

  1. ①: 同時に出て先に着く → P波のほうが「速い」。オ〜クにしぼる。
  2. ②: 近い地点は「ほとんど同時」、そのあと「しかし」で逆の内容 → 遠くなるほど差は「大きく」。カ・クにしぼる。
  3. ③: 「地震の規模の大きさ」→ マグニチュード → カ。
  4. 落としやすい所: ③で震度を選ぶ。本文の最初にある「到達時刻や震度を予想し」は、各地のゆれの話。規模と書いてあればマグニチュード。
答え：カ

4 問2 断層についての説明 B・2点｜素材文・最も適当なもの

👀 まず見るところ

【素材文】聞かれ方「もっとも適当なもの」に線。部品は選択肢の言い切り「発生しない」「現れることはない」に丸 → 言い切りは例が1つあれば×。残るウとエを「断層は地震の原因」で比べる。手を付ける目安: ア・イがすぐ切れたら2択まで進める。

📚 前提知識

  • 断層＝地層や岩石に大きな力がかかり、割れめができてずれたもの。このずれが地震の原因になる。

🔍 こう読み解く

  1. ア「海底では発生しない」: 岩石が割れてずれるのは海底の下でも同じ。海底の断層がずれて津波が起こることもある → ×。
  2. イ「地表面に現れることはない」: ずれが地表まで届くと、地面の段差やずれとして見える → ×。
  3. ウ: 力のかかる場所や向きは決まっていないので、断層はどこでもどの向きにも現れる可能性がある → ○。
  4. エ「断層が生じなくても地震が起こる」: 断層のずれが地震の原因、という習った内容と合わない。迷うのはここだが、「もっとも適当」なので、はっきり正しいウを選ぶ。
答え：ウ

4 問3① 震源から300kmの地点のPS時間（紙面の(1)） A・2点｜条件文・比例の計算

👀 まず見るところ

【まざり型→条件文】部品は「300km」と、表1でS波の時刻が書いてあるただ1つの行「A　150km」。AのPS時間（S波−P波）を表の右に書く → 「それぞれ一定の速さ」だからPS時間は距離に比例し、300kmは2倍。

📚 前提知識

  • P波もS波も速さが一定なら、震源から着くまでの時間はどちらも距離に比例する。だから、その差のPS時間も震源からの距離に比例する。

🔍 こう読み解く

  1. S波の時刻があるのはAだけ。AのPS時間＝9時50分20秒−9時49分52秒。49分52秒から50分ちょうどまで8秒、そこから20秒 → 8＋20＝28秒。
  2. 300km は 150km の 300÷150＝2倍 → PS時間も2倍 → 28×2＝56秒。
  3. 落としやすい所: 分をまたぐ引き算。20から52が引けないからと、52−20＝32秒にしない。「50分ちょうどまで」と「そこから」に分けて数える。
答え：56秒

4 問3② 地震の発生時刻（紙面の(2)） A・2点｜条件文・差で速さを出す

👀 まず見るところ

【まざり型→条件文】部品は表1のP波到達時刻の2行、B「30km・9時49分36秒」とC「90km・9時49分44秒」。差に直して書く（60kmで8秒）→ P波が震源からAまでにかかる時間が決まり、発生時刻までさかのぼれる。

📚 前提知識

  • 発生時刻＝P波が着いた時刻 −（震源からそこまでP波がかかった時間）。かかった時間は表に無いので、2地点の距離の差と時刻の差から作る。

🔍 こう読み解く

  1. BとCの差をとる。距離 90−30＝60km、時刻 44秒−36秒＝8秒。P波は60km進むのに8秒かかる。
  2. Aは震源から150km。150÷60＝2.5倍 → 8×2.5＝20秒。
  3. AにP波が着いたのは9時49分52秒。その20秒前が発生時刻 → 9時49分32秒。
  4. 図にすると、P波の直線をBから左下へのばして、距離0km（震源）にぶつかる所が発生時刻になる。
  5. 確かめ: Bは30kmで、60kmの半分 → 4秒。36秒−4秒＝32秒で合う。落としやすい所: 距離と時刻の組を取りちがえること。「60kmで8秒」のように、距離の差と時刻の差を1組にして表の横に書く。「何時何分何秒」なので時と分も書く。
答え：9時49分32秒

4 問3③ P波の速さはS波の速さの何倍か（紙面の(3)） B・2点｜条件文・速さの比

👀 まず見るところ

【まざり型→条件文】部品は「P波の速さはS波の速さの何倍」に丸。同じ150km（A）にかかった時間に直して書く（P波20秒・S波48秒）→ 時間の比の逆が速さの比。②が出ていれば引き算と割り算1回ずつ。

📚 前提知識

  • 同じ距離を進むとき、速さの比はかかった時間の比の逆になる。時間が短いほうが速い。

🔍 こう読み解く

  1. ②より発生時刻は9時49分32秒。AまでのP波は 52秒−32秒＝20秒。
  2. AまでのS波は 9時50分20秒−9時49分32秒。50分ちょうどまで28秒、そこから20秒 → 48秒。
  3. 同じ150kmに、P波20秒・S波48秒。P波の速さはS波の 48÷20＝2.4倍。割り切れるので四捨五入はいらない。
  4. 速さで確かめると、P波 150÷20＝7.5km/秒、S波 150÷48＝3.125km/秒、7.5÷3.125＝2.4 で同じ（速さの比は 12：5）。20÷48 と逆に割ると1より小さくなるので、「P波のほうが速い」と合わないと気づける。
答え：2.4倍

5 問1 ななめに生えている植物の生育条件を2つ B・2点｜記述・2つで完答

👀 まず見るところ

【資料問題】部品は「地面に対してこのように生えている」と「考えられることを2つ」に丸。図の正体を1行（地面は水平、幹だけが右へななめ）→「幹をかたむける力」と「かたむいているのは地面」の2方向で1つずつ書く。

📚 前提知識

  • 植物の地上の部分は、本来、重力と反対の向き（真上）に幹がのび、光のある方に枝をのばす。図はこの「本来」と合っていないので、その理由を外にさがす。

✍️ 答案の組み立て

  1. 要素A（幹をかたむける力）: 幹は右へかたむいている → 左から右へおす力 ＝ 図の左側からの強い風がふき続けた。風の向きまで書く。
  2. 要素B（見方を変える）: 幹が本来どおり真上にのびているとすると、かたむいているのは地面のほう ＝ 山のしゃ面。「地面に対して」という聞き方がこの見方の合図。
  3. 光で説明しにくいわけ: 図の植物は、幹に対して枝がかたよりなくのびている。光が一方からだけ当たったのなら枝がかたよるはずなので、光のえいきょうは少ないと読める。
模範解答：図の左側から強い風を受け続けた。／山のしゃ面のように，地面がかたむいている場所で植物が真上にのびている。
コツ：答えが1つに決まらない問なので、短く2つ書いて次へ進む。模範解答は例。2つは「別の原因」になるように書く（風の話を言いかえて2つにしない）。

3〜5 まとめ この回で繰り返し出た入口

  • 実験の文は表に直す（大問3）。比べる2つは「ちがう所が1つだけ」。2つちがう組（AとG）は選ばない。
  • 地震の表は差を1組にして書く（大問4）。「60kmで8秒」「150kmでPS時間28秒」と書けば、発生時刻・PS時間・速さの比は比例で出る。
  • 選ぶ前に聞かれ方に丸。「条件Bと条件Cの実験結果を比べたときに」「子葉となる場所」「もっとも適当なもの」が、ひっかけの選択肢を切る合図になった。
