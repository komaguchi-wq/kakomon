2 問1 状態図の文章の穴うめ A・5点｜状態変化・語句選択

👀 まず見るところ

【まざり型→素材文】1つの空らんにつき手がかり1語に丸。①②は「温度を上昇させていく」、④は「圧力が低いほど（④）が高く」。図1の点線の矢印と境界の線に置いてたどる → 変化の向きと語が決まる。

📚 前提知識

  • 温度を上げる向き: 固体→液体が融解（その温度が融点）、液体→気体が沸騰（その温度が沸点）。凝固・凝縮は温度を下げる向きの変化。

🔍 こう読み解く

  1. ①② 点線の矢印は左から右（温度を上げる）。0℃で固体→液体＝融解（エ）、100℃で液体→気体＝沸騰（オ）。
  2. ③ 液体と気体の境界の線の温度＝その圧力での沸点（イ）。線は右上がりなので、圧力が低いほど沸点は低い。文と合う。
  3. ④ 固体と液体の境界の線は左上がり。圧力が低いほど境界の温度が高い → 文の「圧力が低いほど」「高くなります」と合うのは融点（ア）。
  4. ⑤ 二酸化炭素は「1気圧で液体を形成することはできません」→ 圧力を上げる＝高圧（ク）。落としやすい所は①。同じ0℃の変化でも、上げる向きなら融解、下げる向きなら凝固。
答え：①エ　②オ　③イ　④ア　⑤ク
今回：5点中4点。①カ ×、②オ ○、③イ ○、④ア ○、⑤ク ○。①のカ（凝固）は温度を下げる向きの変化。部品を拾えなかった可能性＝「温度を上昇させていく」に丸をつけ、矢印の向きを先に見る。

3 問4 つるで巻きついて成長する理由 A・2点｜記述

今回：「小さな虫がよって来た際においはらうため。」 ×。知識。模範解答は水分の話。「様々な植物に共通」と聞かれたら、まず水・光・温度のどれかで考える。

3 問6 グリーンカーテンで温度が下がる理由 B・2点｜すべて選ぶ・完答

4 問1 空気の塊が上昇する要因 A・2点｜適切でないもの

👀 まず見るところ

【素材文】部品は問いの「適切でないもの」に丸。もう1つはウの「冷たい空気が上に押し上げられる」に丸 → 上がるのは軽いほうの空気、で○×が決まる。

📚 前提知識

  • あたたかい空気は同じ体積で軽く、冷たい空気は重い。ぶつかると冷たい空気が下にもぐり、あたたかい空気が上に押し上げられる（前線）。
  • 上昇気流ができる場所: 地面があたためられた所／山の斜面／前線／低気圧の中心。

🔍 こう読み解く

  1. ア（地表であたためられる）・エ（対流）はあたたまった空気が上がる話 → 正しい。イ（山にぶつかる）は斜面をのぼる → 正しい。オ（低気圧の中心）は風がふきこんで上にのぼる → 正しい。
  2. ウだけ、上がる空気が逆。押し上げられるのはあたたかい空気 → これが適切でない。
  3. 落としやすい所は、正しいものを選んでしまうこと。問いの太字に丸をつけてから選択肢に入る。
答え：ウ
今回：ウ ○。

4 問2 ペットボトルで雲をつくる実験 A・4点｜記述＋番号

👀 まず見るところ

【まざり型→素材文】部品は先生の言葉「空気の体積が膨張」→「温度が下がっていき水蒸気が水滴に変わって」と、実験の「水を少し入れて」。水蒸気はもうある → 足りないのは水滴のしんになるもの。膨張する瞬間＝ふたを開けたとき。

📚 前提知識

  • 水蒸気が水滴になるには、くっつくしん（核）がいる。実験では線こうのけむりを少し入れる。自然の雲では空気中のちりなど。
  • 空気はおしちぢめると温度が上がり、急にふくらむと温度が下がる。

🔍 こう読み解く

  1. (1) 実験にあるのは「水」「密閉」「空気を入れる」「ふたを開ける」。雲に必要な 水蒸気・温度を下げる操作 はそろっている → 無いのは核。「ちりなど、雲の核になるものを入れる」と操作の形で書く。
  2. (2) ④は密閉しただけ。⑤は空気をおしこむので、中の空気はちぢめられて温度が上がる → くもらない。
  3. ⑥でふたを開けると、中の空気が一気にふくらむ → 温度が下がる → 水蒸気が水滴になり白くくもる。先生の説明の「膨張」と同じ向きの変化は⑥だけ。
  4. 落としやすい所は、空気を入れている最中の⑤を選ぶこと。「膨張」は体積が大きくなるほう、と言葉を確かめる。
答え：(1)（例）細かいちりなどの，雲の核になるものを入れる。　(2)⑥
今回：(1)「ちりやほこりなどのきっかけが必要。」 ○。(2)は赤の○×が付いていない（解答らんの字に赤で「字きたない」の書きこみ）。数字と記号は、だれが見ても1つに読める形で書く。

4 問3 雲が浮いているように見える理由 A・3点｜空らん補充

👀 まず見るところ

【素材文】空らんの前後に丸。アは「支えられて浮いている」→ 下から支える空気の流れ。イ・ウは「落下途中で見えなくなり」→ 水滴が消える＝蒸発する条件を、温度と湿度で書く。

📚 前提知識

  • 雲は上昇気流のある所にできる（先生の言葉「空気の塊が上昇すること」）。細かい水滴は、この上昇気流に支えられて落ちにくい。
  • 水滴が蒸発しやすいのは、気温が高く、湿度が低い（空気がかわいている）とき。

🔍 こう読み解く

  1. ア: 「空気」だけでは、上向きに支える理由にならない。上向きの流れを表す言葉＝上昇気流。
  2. イ: 地表に近づくほど気温は高い → 「高」。
  3. ウ: 結果が「見えなくなり」＝水滴が水蒸気にもどる。蒸発するのは空気がかわいているとき → 湿度は「低」。
  4. 落としやすい所はウ。空らんだけ見ずに、文の終わりの結果（見えなくなる）から逆にたどって決める。
答え：ア 上昇気流　イ 高　ウ 低
今回：ア「空気」 ×／イ「高」 ○／ウ「高」 ×。アは知識（上向きの流れの名前まで書く）。ウは部品を拾えなかった可能性＝後ろの「見えなくなり」とつなぐと、蒸発しやすい「低」に決まる。

4 問4 逆転層のグラフと雲海の条件 B・6点｜グラフ選択＋選択＋記述

👀 まず見るところ

【まざり型→資料問題】部品は「地上から高度200mまで」と「上空に行くほど気温が高くなっている」。グラフの正体は「横＝気温・たて＝高度」→ 0mから200mの間だけ、線が右上がりの図をさがす。ここが見えたら(1)は取れる。

📚 前提知識

  • ふつうは上空ほど気温が低い（グラフは左上へのびる線）。逆転層はその逆で、地面近くの空気のほうが冷たい。
  • 晴れた夜は地面の熱がにげ、地面近くの空気がよく冷える。昼と夜の気温差が大きい日ほど、朝に逆転層ができやすい。
  • 雲（水滴）ができるには水蒸気がたくさん必要＝湿度が高い。

🔍 こう読み解く

  1. (1) 0mの点と200mの点をくらべる。イは200mの点のほうが右（気温が高い）にあり、200mより上は左上へ下がっていく → 説明どおり。
  2. ウは0mから200mまで気温が変わらない。エは0mに横線があるだけ。アは0mから始まる線が無く、右上がりの部分は200mより上にある → 「地上から200mまで」に合わない。
  3. (2) まず湿度。雲ができるのだから「高い」→ ア・ウ・オ・キ。次に、地面近くが強く冷える日＝昼夜の気温差が大きい → オ。
  4. (3) 問いは「温度や湿度以外」の条件。風があると上下の空気がまざって逆転層がくずれ、雲も流される → 「風が吹いていない」。
答え：(1)イ　(2)オ　(3)（例）風が吹いていないということ。
今回：(1)「ア」 ×／(2) 空らん ×／(3) 空らん ×。(1)は部品を拾えなかった可能性＝右上がりの線はあるが、アはそれが200mより上。「地上から200mまで」に丸をつけ、0mの点から指でたどる。
コツ：たて軸が高度のグラフは、下（0m）から上へ読む。横軸から読むと、線の向きを取りちがえやすい。
