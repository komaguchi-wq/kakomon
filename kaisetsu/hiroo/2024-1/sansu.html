1 (2) 分数が何段も重なった式のア・イ A・5点｜もどして考える計算

👀 まず見るところ

【条件文】部品は「3/5」と「当てはまる整数」。1÷□＝3/5 の形だから、3/5 を逆数 5/3 に直して書く → 外側から1枚ずつはがすと、最後は「整数＋1/整数」に分けるだけ。

📚 前提知識

  • 1÷□＝3/5 なら、□は 3/5 の逆数の 5/3。たとえば 1÷2＝1/2 で、1÷(1/2)＝2。

📚 前提知識

【条件文】部品は「6人の並び方」と「AからFまで名前をつけ」。6つの場所は全部ちがう場所 → 6人を1列に並べるのと同じ。Aから順に、入れる人数を図の場所に書いてかける。

📚 前提知識

  • ちがう場所に1人ずつ入れるときは、入れる人数を順にかける。3人を3つの場所なら 3×2×1＝6通り。1人入るたびに、残りの人が1人ずつへる。

🔍 整理して解く

  1. Aに入れるのは6人のだれか。6通り。
  2. Bは残りの5人。そのあと 4人、3人、2人、1人とへる。
  3. かける。6×5×4×3×2×1＝720。
  4. 落としやすい所は三角形の形。回すと同じに見えるが、Aが先頭と決まっている。回した並びも別のものとして数える。
答え：720通り
今回：720 ○。

4 (2) ブルーとグリーンがAかDかF A・6点｜条件つきの順列

👀 まず見るところ

【条件文】部品は「2人をAかDかFに配置」。2人はブルーとグリーン。配置図のA・D・Fに丸 → 先にこの2人の場所を決める。残りの4人は、あいた4か所に自由に入る。

📚 前提知識

  • 条件のある人から先に置く。条件のある人の置き方 × 残りの人の並び方 で出る。

🔍 整理して解く

  1. ブルーの場所はA・D・Fの3通り。グリーンは残りの2通り。3×2＝6通り。
  2. 残りの4人を、あいた4か所に入れる。4×3×2×1＝24通り。
  3. かける。6×24＝144。
  4. 落としやすい所は1つ目の式。「3か所から2か所をえらぶ3通り」で止めると、ブルーとグリーンの入れかえが抜ける。
答え：144通り
今回：144 ○。

4 (3) ピンクの隣にレッドとブルー B・6点｜隣の場所で場合分け

👀 まず見るところ

【条件文】部品は「ピンクの隣に」と「隣というのは1m離れている位置」。隣を配置図に直して書く → ブルーはかどにいる。かどの隣は2か所だけ。ピンクの場所が2通りに決まる。ここまで見えたら手を付ける。

📚 前提知識

  • 場所ごとに、隣の場所を書き出しておく。かど（A・D・F）の隣は2か所。まん中（B・C・E）の隣は4か所。
  • 3つのかどは、三角形を回すと重なる。1つのかどで数えて3倍すればよい。

🔍 整理して解く

  1. ブルーをAに置く。Aの隣はBとC。ピンクはBかCに入る。まずピンクをBに置く。
  2. Bの隣は A・C・D・E。Aはブルーが使っている。レッドは C・D・E のどこかに入る。
  3. グリーンはかどのDかF。グリーンがDのときは、レッドがDに入れない。表にする。
    グリーンレッドが入れる場所何通り
    DC、E2通り
    FC、D、E3通り
    合わせて5通り
  4. 残りの2人（イエローとブラック）は、あいた2か所に入る。2通り。5×2＝10通り。
  5. ピンクがCのときも、左右を入れかえただけで10通り。ブルーがAのときは 10＋10＝20通り。
  6. ブルーがD、Fのときも同じ数になる。20×3＝60。
答え：60通り
今回：24 ×（答案）。途中の式が残っていないので、原因は答案からは決められない。次は「ブルーをAに置く → ピンクはBかC」と場所を図に書いてから数える。
コツ：「隣」の条件は、いちばん隣が少ない場所（かど）にいる人から置くと、場合分けが少なくなる。

5 (1)① 平行なロープで 5：3：1 に分ける A・6点｜面積比＝辺の比

👀 まず見るところ

【条件文】部品は「長方形の辺と平行」と「5mごとにくい」。平行に切ると、たてが同じ長方形にならぶ → 面積の比を「よこの長さの比」に直して書く。90mを 5：3：1 に分ける。

📚 前提知識

  • たてが同じ長方形は、よこの長さの比がそのまま面積の比になる。たて70mで、よこ50mとよこ10mなら、面積は5倍。
  • ロープはくいに結ぶ。分ける長さは5の倍数になる。

🔍 整理して解く

  1. 比をたす。5＋3＋1＝9。
  2. よこ90mを9つに分ける。90÷9＝10m。5つ分は50m、3つ分は30m、1つ分は10m。どれも5の倍数。くいがある。
  3. たて70mは9でわり切れない。たてを分ける向きには作れない。よこを分ける。
  4. 落としやすい所は解答らんの書き方。ロープの線だけでなく、かどからの長さ（50m・30m・10m）を3つとも書き入れる。たして90mになるかも見る。
答え：下の図1（よこ90mを、かどから50m・30m・10mに分ける。たての線2本。解答は例）
今回：×。よこを3つに分ける線が2本かいてあり、上に「10m」と「50m」、その下に「40m」と読める。まん中の長さは字がうすくて読めない。原因は答案からは決められない。次は3つの長さを全部はっきり書き、たして90mになるか確かめる。

5 (2) ロープ3本で 6：5：4：3：2：1 に分ける C・6点｜和が同じ組＋ななめの線

👀 まず見るところ

【条件文】本番では後回し。部品は「6：5：4：3：2：1」と「1本以上は長方形の辺と平行」。6＋1、5＋2、4＋3 がどれも7 → 「たて2本で3等分、ななめ1本で切る」に直して書く。

📚 前提知識

  • 比の合計は21。土地は 70×90＝6300m²。比の1は 6300÷21＝300m²。

🔍 整理して解く

  1. よこを30mずつ、たての線2本で3等分する。1つ分は比の7（2100m²）。
  2. ななめの線1本で、下側を左から 1、2、3 にする。下側は台形。面積は 300、600、900m²。
  3. 左はしの高さを5mにする。30m進むごとに10m上がる線にする。高さは 5m、15m、25m、35m。たとえば左の台形は (5＋15)×30÷2＝300m²。両はしの5mと35mは5の倍数。くいがある。
答え：下の図3（よこを30mずつに分けるたての線2本と、左の辺の上から65mの点と右の辺の上から35mの点を結ぶ線1本。解答は例）
今回：空らん ×。C問題。先に 3 (1) と 5 (1)① を取り直す。

3〜5 まとめ この回で繰り返し出た入口

  • 約数の個数は、素数のかけ算に直してから「個数＋1」をかける。逆に個数から数をもどすときも同じ決まりを使う。
  • 並べ方は、条件のある人を先に図に置く。「隣」は場所ごとに書き出す。
  • 辺と平行に切った土地は、面積の比を長さの比に直す。長さが5の倍数かを最後に見る。
