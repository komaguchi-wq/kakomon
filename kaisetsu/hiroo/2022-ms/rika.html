1 問1①② 流れと同じ速さで動く観測者から見た船 A・3点＋B・3点｜条件文・速さの合成

👀 まず見るところ

【まざり型→条件文】部品は「川の流れの速さと同じ速さで川下へ動く観測者」と、図1の矢印「岸からみた船の速さ2.5」「川の流れの速さ1.5」。観測者は流れといっしょに動くので横向きの1.5は見えない → 2.5を対角線とする長方形の2辺に直して図に置く。残る縦の辺が①、その向きが②。①が出れば②は矢印を書くだけなので、セットで取る。

📚 前提知識

  • 流れと同じ速さで動く人から見ると、川の水は止まって見える。船は「流れがなかったとき」と同じ、こぐ速さだけで進むように見える。
  • 問題文の決まり: 2つの速さを2辺とする長方形の対角線が、合わせた速さ。逆に対角線を2辺に分けてもよい。直角をはさむ2辺が3:4なら残りの辺は5。

🔍 こう読み解く

  1. 図1で「岸からみた船の速さ」2.5が長方形の対角線、「川の流れの速さ」1.5が横の辺。残る縦の辺が、流れの分を除いた船自身の速さ＝観測者から見た船の速さ。
  2. 横1.5と対角線2.5の比は 1.5:2.5＝3:5。3:4:5の直角三角形なので、縦の辺は4にあたる → 1.5×4/3＝2.0 → 2m/秒（①）。
  3. 向き（②）: 観測者には流れが見えないので、船は向こう岸へまっすぐ、岸に垂直に進んで見える。解答らんの図の船から、向こう岸へ垂直な矢印を書く。
  4. 落としやすい所: 2.5をそのまま答える／矢印をななめ（岸から見た向き）に書く。「観測者が動いている」の1語で横向きの1.5を消すのが決め手。
答え：① 2m/秒　② 右の図（船から向こう岸へ、岸に垂直な向きの矢印）

1 問2 伸びるゴムの上の2点の速さ A・3点｜条件文・比

👀 まず見るところ

【条件文】部品は「釘からゴム上の2点AとBまでの距離はそれぞれ1cmと3cm」と、聞かれ方「点Bの速さは点Aの速さの何倍」。「2.75倍」はAにもBにも同じにかかる数なので、速さの比＝釘からの距離の比 1:3 と置ける。

📚 前提知識

  2. 動いた長さは A 2.75−1＝1.75cm、B 8.25−3＝5.25cm。同じ時間で動いたので、速さの比は 1.75:5.25＝1:3。
  3. ゴムが何倍に伸びても、釘からの距離の比1:3は変わらないので、速さの比もいつも1:3 → 3倍。
  4. 落としやすい所: 「四捨五入が必要な場合は」の一文につられて、2.75を使った割り算を作ること。答えは整数3で、四捨五入は要らない。

1 問3 岸壁で反射する汽笛が聞こえる時間 B・3点｜条件文・音の速さ

👀 まず見るところ

【条件文】部品は「17m/秒」「3.4km」「10秒間、汽笛を鳴らし続けました」「323m/秒」。3.4kmは3400mに直して書く。鳴らし始めの音と鳴らし終わりの音を別々に追い、聞こえる時刻の差を出す、と決める。「音と船が向かい合って近づく」の式が立つなら手を付ける価値がある。

📚 前提知識

  • 岸壁ではね返った音と船は、向かい合って近づく。出会うまでの時間＝（2つの間の道のり）÷（速さの和）。音は岸壁まで行って戻るので、道のりは「岸壁までの距離×2」。
  • 船は近づきながら鳴らすので、鳴らし終わりの音は岸壁に近い所から出る。だから往復の道のりが短く、早く戻ってくる。

🔍 こう読み解く

  1. 鳴らし始めの音（0秒後に出る）: 岸壁まで3400m。往復の道のり 3400×2＝6800m を、音323と船17が向かい合って縮める → 6800÷(323＋17)＝20秒後に聞こえ始める。
  2. 鳴らし終わりの音（10秒後に出る）: 船は 3400−17×10＝3230m の地点にいる → 10＋3230×2÷340＝10＋19＝29秒後に聞こえ終わる。
  3. 整理すると次の表。聞こえるのは20秒後から29秒後まで → 29−20＝9秒間。
    音出た時刻出た地点の岸壁までの距離聞こえる時刻
    鳴らし始め0秒後3400m3400×2÷340＝20秒後
    鳴らし終わり10秒後3400−17×10＝3230m10＋3230×2÷340＝29秒後
  4. 10秒間鳴らした音が9秒間に縮んで聞こえる。これが問4の「音が高くなった」の正体で、問4の文にもそう書いてある。
答え：9秒間

3 問2 図12のア〜カで左（光の側）に曲がるもの B・3点｜まざり型→素材文・すべて選ぶ

👀 まず見るところ

📚 前提知識

  • 曲がるには、先端で作られたオーキシンが右（光の反対）側に寄ってから下へ流れ、右側だけが早くのびることが必要。先端が無い・右へ寄れない・右側を下れない、のどれか1つでも起これば曲がらない。
  • 寒天片はオーキシンを通す（図9のa）ので、切った先端をもどしても流れはつながる。

🔍 こう読み解く

  1. ア: 先端に光を通さない黒いキャップ。先端に光が当たらないので右へ寄らず、まっすぐ下へ流れる → 曲がらない。

答え：イ・エ・オ

3 問5 茎は上へ・根は下へ曲がる理由 B・3点｜記述・まざり型→素材文

👀 まず見るところ

【まざり型→素材文】部品は本文の「オーキシンはその重力の方向に沿って図の下側へ移動します」（茎の先端も根冠も）と、《特徴》④の「茎が成長できるオーキシンの量では，根の成長は抑制される」。茎と根で「下側にオーキシンが多い」は同じ、ちがうのは「その量で成長が進むか止まるか」→ 曲がる向きが逆になる理由が決まる。

📚 前提知識

  • 曲がる向き＝よくのびる側の反対。下側がよくのびれば上へ曲がり、上側がよくのびれば下へ曲がる（本文の冒頭にある「成長速度に差が生じた結果として曲がる」と同じ）。
  • 図11: 根の成長が最も進むオーキシンの量は茎より少なく、茎がよくのびる量では根は抑制側（0より下）にある。

✍️ 答案の組み立て

  1. 要素A（共通）: 水平にねかせると、茎の先端でも根冠でも、オーキシンは重力の方向＝下側に移動する。
  2. 要素B（茎）: 茎は下側のオーキシンで成長が進む → 下側が長くのびて、重力と反対（上）へ曲がる。
  3. 要素C（根）: 根は同じ量のオーキシンでは成長が抑制される → 下側がのびず上側がのびて、重力の方向（下）へ曲がる。
  4. 「茎は下側のオーキシンで下側が成長して上に曲がるが、根は同じ量では成長が抑えられて下に曲がる」の形でB・Cを対比させる。落としやすい所: 「根ではオーキシンが上側に移動する」と書くのはまちがい。移動の向きは茎と同じで、ちがうのは量への反応。
模範解答：茎は下側にオーキシンがあることで，その部分の成長が進むが，根は同じオーキシン量では成長が抑制されるため。

3 まとめ この大問で繰り返し使った入口

  • 流れをふさぐものを1か所ずつ探す: 雲母片の位置（問2）、出口P・入口Aの有無（問3）。ふさがれた先には届かない。
  • 茎と根のちがいは「移動の向き」でなく「同じ量への反応」（問5・図11）。

  3. 落としやすい所: 「550：5」と「5：550」をひっくり返すと 42350000km という月より大きい数になる。月の直径は月までの距離よりずっと小さい、で向きを確かめる。
答え：3500km

4 問3 月が近づいたり遠ざかったりする根拠になる事例 B・3点｜素材文・2つ選ぶ（完答）

👀 まず見るところ

【素材文】設問は「月が地球へ近づいたり遠ざかったりしている根拠」を「2つ選び」。部品は各選択肢の中の「大きさ」「2種類ある」のような、月の遠近で変わることを言っている言葉に丸。形や色や沈む角度の話は、距離とは別の理由で起こるので外す。手を付ける価値: 「スーパームーン」を聞いたことがあればオは決まり、もう1つは日食の2種類。

📚 前提知識

  • 月が近いと大きく見え、遠いと小さく見える。同じ満月でも大きさがちがい、最も大きいものがスーパームーンと呼ばれる。
  • 日食では、月が近い（大きく見える）と太陽を全部かくして皆既日食、月が遠い（小さく見える）とふちが残って金環日食になる。日食に2種類あること自体が「月の距離は一定でない」証拠。

🔍 こう読み解く

  1. オ「満月の大きさは一定ではなく」→ 見かけの大きさが変わる＝距離が変わる → ○。
  2. イ「皆既日食と金環日食が存在する」→ 月が太陽を全部かくせるときと、かくしきれないときがある＝月が近いときと遠いときがある → ○。
  3. ウの満ち欠けは太陽・月・地球の位置関係で形が変わる話、アは月食のときの色の話、エは月が沈むときの角度の話で、どれも月までの距離が変わらなくても起こる → ×。
答え：イ・オ

4 問5 表2の木星の公転周期（D） B・3点｜まざり型→条件文・式に当てはめる

👀 まず見るところ

【まざり型→条件文】部品は式の形「（公転周期）×（公転周期）＝（平均距離）×（平均距離）×（平均距離）」と、表2の木星「5.2」。求めるのは公転周期なので、5.2を3回かけた数を「□×□」の形に直して、□に近い整数をさがす。手を付ける価値: 小数のかけ算2回と、11×11・12×12 の比べっこだけ。選択肢が4年おきなので、ぴったり出なくてよい。

📚 前提知識

  • 式は「公転周期を2回かけた数＝太陽からの距離を3回かけた数」（AUと年の単位で）。地球で確かめると 1×1＝1×1×1 で成り立つ。
  • 「もっとも近いもの」を選ぶ問題は、□×□ が 121（11×11）と 144（12×12）のどちらに近いかで決める。

🔍 こう読み解く

  1. 余白に「□×□＝5.2×5.2×5.2」と書く。5.2×5.2＝27.04、27.04×5.2＝140.608。
  2. 11×11＝121、12×12＝144。140.608は144のすぐ下なので、□は12より少し小さい数。選択肢で最も近いのはウの12年。
  3. 念のため土星でも式を確かめられる: 29×29＝841、9.5×9.5×9.5＝857.375 で、ほぼ等しい。式の読み方が合っている印になる。
答え：ウ
コツ：□を2回かけるのか3回かけるのかを取りちがえやすい。式の左（周期）は2回、右（距離）は3回、と式の上に「2」「3」と書きこんでから計算する。

4 問6①②③ 水星の昼と夜で温度差が大きい理由（穴うめ） A・1点×2／B・1点｜素材文・空らん

👀 まず見るところ

【素材文】設問は3つの空らん。部品は空らんの前後の言葉「質量が小さいために表面の（ア）が弱くて」「（イ）を留めておくことができず」「（ウ）の移動が起こりにくい」に丸 → 質量が小さい→弱くなるもの＝重力、留めておけないもの＝表3で水星だけ「ほぼ無し」の大気、大気が運ぶもの＝熱、の順に決まる。

📚 前提知識

  • 質量が大きい天体ほど重力が強い。重力が弱いと、大気を表面にとどめておけない。
  • 地球では大気や海があたたまった空気や水を昼側から夜側へ運ぶ（対流する）ので、昼夜の温度差が小さい。運ぶものが無い水星は、昼は熱くなり、夜は冷えきる。

🔍 こう読み解く

  1. ア: 「質量が小さいために弱い」もの → 重力。
  2. イ: 表3の「大気の主成分」で水星だけ「ほぼ無し」。重力が弱くて留めておけないもの → 大気。
  3. ウ: 大気が無いと「移動が起こりにくい」もの → 熱。昼側の熱が夜側に運ばれないから温度差が大きい、と文がつながる。落としやすい所: ウに「空気」「風」と書かない。問われているのは移動するもの＝熱。
答え：ア 重力　イ 大気　ウ 熱

4 問7 金星が昼夜を問わず高温である原因 A・4点｜記述・資料問題（表3）

👀 まず見るところ

【資料問題】部品は設問の「水星よりも大きい（太陽から遠い）のに高温」と、表3の金星の行「大気の主成分 二酸化炭素」「470」。太陽の近さでは説明できないので、原因は大気に直して書く → 二酸化炭素の温室効果、と決まる。

📚 前提知識

  • 二酸化炭素は温室効果のある気体。地球温暖化の原因として習う気体と同じで、地面から出ていく熱をにがしにくくする。
  • 金星はその二酸化炭素が大気の主成分なので、温室効果が地球よりはるかに強く、夜側も冷えない。

✍️ 答案の組み立て

  1. 要素A（表3から）: 金星の大気の主成分が二酸化炭素で、その濃度が高い。
  2. 要素B（理由）: 二酸化炭素の温室効果が強くはたらき、熱がにげにくいから。
  3. 落としやすい所: 「太陽に近いから」は設問が否定している。「大気が厚いから」だけでは成分の名前が無く、要素Aが抜ける。表3の「二酸化炭素」の語を答案に入れる。
模範解答：二酸化炭素の濃度が高いため，温室効果が強くなるから。
