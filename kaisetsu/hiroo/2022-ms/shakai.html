2 問2 各時代の農村と農民の生活 B・1点｜正誤・誤っているもの

👀 まず見るところ

【素材文】聞かれ方「誤っているもの」に線。1文につき時代と結びつく言葉に丸 → エの「蔵屋敷」は江戸時代の倉庫で、室町時代の文に入っているすりかえ。ア〜ウで迷ったらエから確かめる。

📚 前提知識

  • 室町時代、高利貸しをしていたのは酒屋・土倉。1428年の正長の土一揆では、近江国の馬借らが徳政を求めて酒屋・土倉をおそった。
  • 蔵屋敷は、江戸時代に各藩が大坂などに置いた、年貢米を保管・取り引きする倉庫。

🔍 こう読み解く

  1. エ「徳政を求めて蔵屋敷や土倉などをおそったり」→ 蔵屋敷は江戸時代のもの。室町時代におそわれたのは酒屋・土倉 → 時代ちがいのすりかえ。
  2. さらに「加賀国の馬借を襲いました」→ 正長の土一揆は近江国の馬借らがおそった側。場所も、おそう側・おそわれる側も逆。エが誤り。
  3. ア（奈良時代の租・調・庸と運脚）、イ（平安時代の国司と武装する者）、ウ（鎌倉時代の荘園領主と地頭の二重の負担）は、それぞれの時代の説明として合っている。
答え：エ

2 問3①② 江戸幕府の組織図の誤り B・2+2点｜資料問題・誤りを正す

👀 まず見るところ

【資料問題】部品は「誤りが2か所」と※の「□の語句」。役職名を1つずつ見て、ほかの時代の名前・江戸幕府に無い名前に丸 → 「管領」（室町幕府）と「大蔵奉行」の2つが決まる。説明文は正しいので、説明から正しい名前を引き出す。

📚 前提知識

  • 江戸幕府で老中を補佐したのは若年寄。管領は室町幕府で将軍を補佐した役職。
  • 幕府領（天領）の財政や監督を受けもったのは勘定奉行（寺社奉行・町奉行と合わせて三奉行）。

  1. 図の「管領」の説明は「老中補佐」。目付（旗本などの監視）を下に置く老中補佐の役職は若年寄 → ① 管領→若年寄。

2 問4 日明貿易のカード B・2点｜正誤・正しい組み合わせ

👀 まず見るところ

【素材文】聞かれ方「正しい説明」の組み合わせ。1枚につき手がかり1語に丸 → bの「まったく」は言いすぎ、dの「銀でできた」は材料のすりかえ。b・dが消えれば残りはア。

📚 前提知識

  • 日明貿易は、日本が明に貢ぎ物を出し、返礼品を受け取る朝貢形式。日本の利益は大きかった。
  • 倭寇と正式な貿易船を区別するために勘合（符）という合い札を使ったので、勘合貿易ともよぶ。日本は明から銅銭（明銭）を多く輸入した。

🔍 こう読み解く

  1. a 明は、元（モンゴル民族）の支配に対する漢民族の反乱をきっかけに14世紀中ごろに成立 → ○。c 勘合符で倭寇と区別 → ○。
  2. b「利益はまったくありませんでした」→ 返礼品で利益は大きかった → ×（言いすぎ・逆）。d「銀でできた明銭」→ 明銭は銅銭 → ×。
  3. 正しいのは a・c → ア。選択肢は「a・c」「a・d」「b・c」「b・d」なので、bとdのどちらか1つを×と決めるだけでも2択までしぼれる。
答え：ア

3 問5 マスク不足のときの需要と供給のグラフ B・2点｜資料問題・グラフ選択

👀 まず見るところ

【資料問題】部品は「マスクを欲しいと思う人が増え」と「生産がそれ以前と変わらずに」。動くのは需要の線だけ、供給の線は動かない、と直して書く → 需要の線が右へ動き、交点が上がるグラフに決まる。

📚 前提知識（あれば答え合わせに使う）

  • 縦軸＝価格、横軸＝数量のグラフでは、右下がりの線＝需要（安いほど欲しい人が多い）、右上がりの線＝供給（高いほど作りたい）。
  • 欲しい人が増える＝どの価格でも需要量が増える＝需要の線が右へ動く。

🔍 こう読み解く

  1. 点線（影響後の線）がどちらの線と平行かを見る。ア・イは右下がりの線が動く＝需要。ウ・エは右上がりの線が動く＝供給 → 生産は変わらないのでウ・エは×。
  2. アは矢印が左向き（需要が減る）→ ×。イは矢印が右向き（需要が増える）で、新しい交点●が元より上＝価格が上がった → イ。

4Ⅰ 問1 木簡が書写に使われた理由と、官人が書写にはげんだ理由 B・4点｜記述・理由2つ

※ デジタル版では、この大問の木簡の写真と資料文が黒くぬられていて読めない。解説は解答例と声の教育社の解説から書いている。

👀 まず見るところ

【素材文】問いは2つ。「なぜ木簡が書写の材料として」と「官人を目指すものは書写を熱心に」に丸 → 答えも2文に分け、1文目は木簡の特徴（写真）、2文目は律令制（資料文）から書く。

📚 前提知識

  • 古代の紙は手間と材料がかかる貴重品。木簡は木を削って形を整えれば作れ、手に入れやすい。
  • 木簡は墨で書いた部分を削れば再利用できる。声教の解説によると、写真からもこの点が分かる。
  • 律令制の役人にとって、声教の解説が資料文から引いている言葉では「文字による記録や命令」が「不可欠」だった。

✍️ 答案の組み立て

  1. 要素A（木簡の特徴）：練習したあと削って何度も使える → だから書写（文字の練習）の材料になった。
  2. 要素B（律令制）：律令政治は記録や命令を文字で残した → 官人には文字を書けることが必要だった。
  3. 2つの問いに1文ずつ。2文目は「〜から。」で終える。
模範解答：木は文字を練習したあとに，削って再利用できるため，書写の材料として利用された。また，律令政治は，文字で記録や命令を残したため，官人にとって文字を習得することが必要だったから。
コツ：資料が見えないときも、問いの文に「木簡の特徴や写真」「資料文」と書いてあれば、どの文をどこから書くかは決まる。紙と比べた木の良さ（手に入れやすい・削って使い直せる）を1つ入れる。

👀 まず見るところ

【素材文】部品は本文の「時間がたっても簡単に過去のものを見つける」と「簡単には消すことができません」に丸。この2つをつなぎ、「だから本人がいつまでも困る」と結べば答えになる。

📚 前提知識

  • 刑に服して反省やつぐないをした人でも、ネット上に記録が残れば、その後の行動にかかわらず過去だけが注目されることがある。
