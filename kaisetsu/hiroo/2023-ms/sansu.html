1 (1) 1〜9を入れて たて・よこ・ななめの和が15 A・6点｜魔方陣（3×3）

👀 まず見るところ

【条件文】部品は「その数の和が15」と、もう入っている「1・7・9」。1と9は同じたての列 → まん中は 15−1−9 で決まる（図に置く）。まん中が決まれば、7の行の右はしも引き算で出る。

  • 魔方陣は「数が2つ入っている列」から手をつける。残り1マスは 15−（2つの和）で出る。たとえば 1 と 9 の列なら 15−10＝5。

  1. たてのまん中の列は 1・□・9。まん中のマスは 15−（1＋9）＝5。

    8（ア＋オ）（2，6）だけ
    どちらにも入っている数は 6。だから ア＝6、イ＝8、オ＝2。
  4. カは 15−（2＋9）＝4。ななめ 6＋5＋4＝15、8＋5＋2＝15 も合っている。
  5. 落としやすい所: 解答らんに書いたあと、8本（たて3・よこ3・ななめ2）を全部たして15か確かめる。1本でも15にならなければどこかが入れちがい。
答え：解説の図❸を参照のこと。（上の段 6・1・8、まん中の段 7・5・3、下の段 2・9・4）

1 (2) 1〜16を入れて たて・よこ・ななめの和が34 A・6点｜魔方陣（4×4）

👀 まず見るところ

【条件文】部品は「その数の和が34」と、3つうまっている「5・□・2・11」の行。あいた1マスは 34−（5＋2＋11）で決まる（図に置く）。あとは使える数の一覧を書き、和が2通りに決まるマスをさがす。

📚 前提知識

  • 4×4でも入口は同じ。「3つ入っている列」の残り1マスは 34−（3つの和）で出る。たとえば 5・2・11 の行なら 34−18＝16。
  • 2マスあいている列は「2マスの和」だけ分かる。1つのマスが2本の列に入っていれば、2つの和の両方に合う数をさがせる。

🔍 整理して解く

  1. 2段目は 5・□・2・11。あいたマスは 34−（5＋2＋11）＝16。あいているマスに ア〜ケ をつける。
  2. 残っている数は 4・6・7・8・10・13・14・15。アは「左上から右下のななめ」と「左はしのたて」の2本に入っている。
    ななめ ア・16・3・ケ → ア＋ケ＝34−（16＋3）＝15。
    たて ア・5・12・キ → ア＋キ＝34−（5＋12）＝17。
    和残りの数で作れる組
    15（ア＋ケ）（7，8）だけ
    17（ア＋キ）（4，13）または（7，10）
    両方に入っている数は 7。だから ア＝7、ケ＝8、キ＝10。
  3. 決まったマスから、引き算で順に出す。
    下の段 10・1・ク・8 → ク＝34−19＝15。
    右から2列目 ウ・2・3・15 → ウ＝34−20＝14。
    上の段 7・イ・14・9 → イ＝34−30＝4。
    左から2列目 4・16・オ・1 → オ＝34−21＝13。
    3段目 12・13・3・カ → カ＝34−28＝6。
  4. たしかめ。右上から左下のななめ 9＋2＋13＋10＝34。右はしのたて 9＋11＋6＋8＝34。
  5. 落としやすい所: ア＋キ＝17 には（4，13）もある。ア＋ケ＝15 の組が1つしかないことで決める。片方の和だけで決めると、4を入れてしまう。
答え：解説の図❻を参照のこと。（上から 7・4・14・9 ／ 5・16・2・11 ／ 12・13・3・6 ／ 10・1・15・8）

1 (3)①② 正三角形の3頂点の和が同じになる理由（A・B） A・6点×2｜理由の穴うめ（重なりの数え方）

👀 まず見るところ

【条件文】部品は「各辺上に並ぶ4個の数の和も…すべて26」と理由文の「それぞれ頂点は2回足している」。「3辺の和＝26×3」と直して書く → これが A。A から六角形の 26 を引いて 2 でわる → B。

📚 前提知識

  • 正三角形の3つの辺をたすと、頂点の数だけ2回たしてしまう。たとえば頂点が 1・2・3 の小さい三角形なら、辺の和3本をたすと 1・2・3 が2回ずつ入る。
  • 1つの正三角形の上にある数は、頂点3個＋辺のとちゅう6個（＝六角形の頂点）の9個。

🔍 整理して解く

  1. 1つの正三角形の3つの辺を全部たす。1辺が26だから 26×3＝78。これが A。
  2. 78 の中身を書き分ける。頂点3個は2回ずつ、辺のとちゅうの6個は1回ずつ。だから「頂点の和×2＋とちゅう6個の和＝78」。
  3. とちゅうの6個は、ちょうど中央の六角形の頂点。その和は 26。だから 頂点の和×2＝78−26＝52。頂点の和は 52÷2＝26。これが B。
  4. もう1つの正三角形も同じ計算になる。だからどちらの頂点の和も 26。
  5. 落としやすい所: Bを「78−26＝52」で止めない。52 は頂点を2回たした数なので、2でわるのが最後の一歩。
答え：A…78，B…26

1 (3)③ 残りの数を正方形に入れる B・6点｜数の配置（調べ）

👀 まず見るところ

【条件文】部品は①で出た「頂点の和はどちらも26」と、もう入っている 12 と 11。12のなかま2つの和＝14、11のなかま2つの和＝15 と直して図のそばに置く → 辺のとちゅうのマスの和が決まり、1と2の場所がしぼれる。①が解けていれば、引き算だけで進む。

📚 前提知識

  • 12 と同じ正三角形の頂点は、図の左と右下。11 と同じ正三角形の頂点は、図の左上と右。頂点の和26から、残りの2頂点の和が出る。
  • 六角形の6個の和も26。ほかの4個の和が分かれば、残り2個の和が出る。

🔍 整理して解く

  1. マスに名前をつける。外の6個は 12・11 と a・b・c・d。中の六角形は 上・左上・左下・下・右下・右上。 11 の正三角形の頂点は a・b・11 → a＋b＝26−11＝15。12 の正三角形の頂点は 12・c・d → c＋d＝26−12＝14。
  2. 辺 a→上→右上→b の和は26。a＋b＝15 だから、上＋右上＝26−15＝11。
    辺 c→左下→下→d の和は26。c＋d＝14 だから、左下＋下＝26−14＝12。
  3. 六角形の6個の和は26。上＋右上＝11、左下＋下＝12 だから、残りの 左上＋右下＝26−11−12＝3。つまり左上と右下は 1 と 2。ここでは 左上＝2、右下＝1 とする。
  4. a を1つ決めて、引き算で順に出す。たとえば a＝6 なら b＝15−6＝9。
    辺 11→左下→左上→a：左下＝26−11−2−6＝7。
    辺 b→右下→下→11：下＝26−9−1−11＝5。左下＋下＝12 に合っている。
  5. 残った数は 3・4・8・10。c＋d＝14 になる組は（4，10）。c＝4、d＝10 とする。
    辺 12→上→左上→c：上＝26−12−2−4＝8。右上＝11−8＝3。
    たしかめ。辺 d→右下→右上→12：10＋1＋3＋12＝26。六角形 8＋2＋7＋5＋1＋3＝26。
    使った条件決まった数
    a＋b＝15a＝6，b＝9
    左上＋右下＝3左上＝2，右下＝1
    11の辺・bの辺左下＝7，下＝5
    c＋d＝14（残り 3・4・8・10）c＝4，d＝10
    12の辺・上＋右上＝11上＝8，右上＝3
答え：解説の図❽を参照のこと。（例: 上の図の入れ方。a＝6，b＝9，c＝4，d＝10，六角形は上から時計回りに 8・3・1・5・7・2。ほかの入れ方もある）
コツ：「頂点の和26」が分かったら、まず「2つの頂点の和」と「辺のとちゅう2マスの和」を図のそばに書く。六角形の条件で 1 と 2 の場所が決まれば、あとは引き算が続く。答えは1つではないので、6本の辺と六角形の7本がすべて26になれば正解。

2 (1) 512671を超えるものの個数 A・7点｜個数（はんい）

👀 まず見るところ

【条件文】部品は「同じ3けたの数を2つ並べて」と「512671を超える」。6けたの前半3けたを「A」と直して書く → 512512 と 513513 を 512671 とくらべる。Aは 513 から 999 まで。

📚 前提知識

  • 6けたの大小は、上の3けたでほぼ決まる。上3けたが同じなら、下3けたでくらべる。たとえば 512512 と 512671 は上3けたが同じで、下は 512＜671。
  • 「513 から 999 まで」の個数は 999−513＋1。「＋1」は両はしを数えるため（1から3までは 3−1＋1＝3個）。

🔍 整理して解く

  1. 3けたの数を A とする。6けたの数は「A A」の形。
  2. A＝512 のとき 512512。これは 512671 より小さい。A＝513 のとき 513513。これは 512671 より大きい。
  3. だから A は 513 以上 999 以下。個数は 999−513＋1＝487。
  4. 落としやすい所: 「超える」なので 512671 と同じ数は入らないが、そもそも 512512 は小さいので関係ない。「＋1」を忘れて 486 にしない。
答え：487個

2 (2) すべての6けたの数を割り切る1けたの素数 A・7点｜整数の性質（1001の分解）

👀 まず見るところ

【条件文】部品は「同じ1けたの素数で割り切れます」と、例の「123123」。123123＝123000＋123＝123×1001 と直して書く → 1001 を素数の積に分ければ決まる。

📚 前提知識

  • 「A A」の形の6けたの数は、A×1000＋A＝A×1001。たとえば 123123＝123×1001。
  • 1001＝7×11×13。この分解はよく出るので、7で割ってみる（1001÷7＝143、143＝11×13）。

🔍 整理して解く

  1. A を2つ並べた数は、A×1000＋A×1＝A×（1000＋1）＝A×1001。
  2. 1001 を素数に分ける。1001＝7×11×13。
  3. だからどの6けたの数も A×7×11×13 と書ける。7・11・13 のどれでも割り切れる。1けたの素数は 7。
  4. 落としやすい所: 2・3・5 で割り切れるかは A によって変わる（123123 は奇数。909909 は3の倍数でも、100100 は各位の和が 2 で3の倍数ではない）。A によらず割り切れるのは 1001 の約数だけ。
答え：7

2 (3) 2023を引くと12の倍数になる数（150150以下で2番目に大きいもの） B・8点｜余りの整理（記述）

👀 まず見るところ

【条件文】部品は「2023を引いて12の倍数」「150150以下の数で2番目に大きい」。「A×1001−2023 が12の倍数」と直して書き、12でわった余りだけを追う。1001 と 2023 に共通の 7 が見えたら、手を付ける価値がある。

📚 前提知識

  • 2023＝7×17×17。2023 を 7 で割ると 289、289＝17×17。
  • 共通の 7 でくくる。7×□ が12の倍数になるのは、7 と 12 が1以外に同じ約数を持たないので、□ が12の倍数のとき。
  • 12で割った余りだけ見る。A×143＝A×144−A と書き直す。A×144 は12で割り切れるので、余りは「A を引いた分」で決まる。たとえば A＝11 なら 11×143＝1573、1573÷12＝131 余り 1。

🔍 整理して解く

  1. 6けたの数は A×1001＝A×7×11×13。ひく数は 2023＝7×17×17。どちらにも 7 があるので、7 でくくる。
    A×7×11×13−7×17×17＝7×（A×143−289）。
  2. これが12の倍数になるには、かっこの中 A×143−289 が12の倍数になればよい。
  3. 289÷12＝24 余り 1。だから A×143 も、12で割って 1 余る数でないと差が12の倍数にならない。
  4. A×143＝A×144−A。A×144 は12で割り切れる。だから A×143 の余りは「12−（Aの余り）」の形。これが 1 になるのは、A を12で割った余りが 11 のとき。
  5. A は 150 以下で、12で割ると11余る数。（150−11）÷12＝11 余り 7 → 1番大きい A は 12×11＋11＝143。2番目は 12×10＋11＝131。6けたの数は 131131。
    A（150以下・余り11）6けたの数順位
    1431431431番目
    1311311312番目
    1191191193番目
  6. たしかめ。131131−2023＝129108。129108÷12＝10759 で割り切れる。
答え：131131
コツ：記述らんには「7でくくる → かっこの中が12の倍数 → 289は余り1 → A×143は余り1 → Aは余り11 → 150以下で2番目」の流れを、1行ずつ書く。A×1001 を12で割った余りは A×5 の余りと同じ（1001＝12×83＋5）なので、A×5−7 が12の倍数と置いても A の余り11 に着く。

1〜2 まとめ この2大問で繰り返し出た入口

  • 「同じ3けたを2つ並べる」と見たら A×1001、1001＝7×11×13 をすぐ書く。
  • 記述問題は「12で割った余り」のように、見るものを1つにしぼって1行ずつ進める。
