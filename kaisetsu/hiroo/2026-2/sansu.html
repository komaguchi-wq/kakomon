1 (1) 8.5×14＋4.25×28＋2.125×56 A・5点｜計算のくふう

👀 まず見るところ

【条件文】部品は式の数字「8.5、4.25、2.125」と「14、28、56」。左は半分ずつ、右は2倍ずつ → 3つとも「8.5×14」に直して書く。小数の筆算3回をしなくてすむ。

📚 前提知識

  • かけ算は、片方を半分にして、もう片方を2倍にしても、答えが同じ。たとえば 4×6＝24。2×12＝24。

🔍 整理して解く

  1. 2つ目を書きかえる。4.25×28 は、4.25×2×14 と同じ。4.25×2＝8.5。だから 8.5×14 になる。
  2. 3つ目を書きかえる。2.125×56 は、2.125×4×14 と同じ。2.125×4＝8.5。これも 8.5×14 になる。
  3. 8.5×14 が3つ。まとめてかける。 
    8.5×14×3＝8.5×42＝357
  4. 落としやすい所は最後の 8.5×42。8×42＝336 と 0.5×42＝21 に分けて、たす。
答え：357

1 (2) 分数の中に分数がある式の□ A・5点｜もどして考える計算

👀 まず見るところ

【条件文】部品は、どの段にもある分子の「1」と右の「4/7」。「1÷（分母ぜんぶ）＝4/7」に直して書く → 外側から、上下をひっくり返して1を引く。2回で□が出る。

📚 前提知識

  • 「1÷ある数」が 4/7 なら、「ある数」は 4/7 の上下をひっくり返した 7/4。たとえば 1÷2＝1/2。1÷(1/2)＝2。

🔍 整理して解く

  1. いちばん外側を見る。「1÷（分母ぜんぶ）＝4/7」。分母ぜんぶは、ひっくり返して 7/4。
  2. 分母は「1＋（中の分数）」。1を引く。中の分数は 7/4−1＝3/4。
  3. 中の分数も同じ形。「1÷（その分母）＝3/4」。その分母は、ひっくり返して 4/3。
  4. その分母は「1＋1/□」。1を引く。1/□＝4/3−1＝1/3。□は3。 
    4/7 →(ひっくり返す) 7/4 →(1を引く) 3/4
3/4 →(ひっくり返す) 4/3 →(1を引く) 1/3 → □＝3
  5. たしかめ。1＋1/3＝4/3。1÷4/3＝3/4。1＋3/4＝7/4。1÷7/4＝4/7。合っている。
答え：3

1 (3) 値上がりして3個ずつ減らしたクッキーとチョコ A・6点｜つるかめ算

👀 まず見るところ

【条件文】部品は「合わせて20個」「3個ずつ少なく」「150円安く」と、求めるもの「何個買ったか」に丸。「値上がり後も20個なら予定より何円高いか」に直して書く → 値上がり分50円と70円のつるかめ算になる。

📚 前提知識

  • つるかめ算は、「1個あたりの数が2種類」「合わせた個数」「合計」の3つがそろえば解ける。全部を片方にして、ずれを1個ごとの差でわる。
  • 値上がり後の値段は、クッキーが 150＋50＝200円。チョコが 200＋70＝270円。

🔍 整理して解く

  1. 値上がり後も20個買ったとする。実際よりクッキー3個とチョコ3個が多い。その分は (200＋270)×3＝1410円。
  2. 実際の代金は、予定より150円安い。だから「値上がり後に20個」は、予定より 1410−150＝1260円高い。 
    予定の代金 ──(150円安い)── 実際の代金
実際の代金 ──(1410円高い)── 値上がり後に20個
→ 値上がり後に20個 は 予定より 1260円高い
  3. この1260円は、20個の値上がり分の合計。クッキーは1個50円、チョコは1個70円で、合わせて20個。
  4. 20個が全部チョコなら 70×20＝1400円。1260円より140円多い。チョコ1個をクッキーにかえると 70−50＝20円へる。140÷20＝7個。これが予定のクッキーの個数。
  5. 落としやすい所はここ。聞かれているのは買った個数。3個少なくしたから 7−3＝4個。
  6. たしかめ。予定はクッキー7個とチョコ13個。150×7＋200×13＝3650円。実際は 200×4＋270×10＝3500円。差は150円で合っている。
答え：4個

1 (4) 8日のロボットAと10日のロボットB A・6点｜仕事算

👀 まず見るところ

【条件文】部品は「8日」「10日」と、求めるもの「何日かかるか」に丸。仕事全体を8と10の最小公倍数の40に直して書く → 1日分が5と4で出る。「何日目」ではないので、答えは分数のまま。

📚 前提知識

  • 仕事全体を40とすると、8日で終わる人は1日に 40÷8＝5 だけ進む。10日で終わる人は1日に 40÷10＝4 だけ進む。

🔍 整理して解く

  1. 仕事全体を40とする。Aは1日に5。Bは1日に4。
  2. 一緒にやると、1日に 5＋4＝9 進む。
  3. かかる日数は 40÷9＝40/9＝4 4/9日（4と9分の4）。
  4. 落としやすい所は「5日」と答えてしまうこと。聞かれているのは「何日目に終わるか」ではなく「何日かかるか」。ロボットは休まず動くので、分数のまま答える。
答え：4 4/9日

1 (5) 直角が2つで CD＝DA の四角形の面積 A・6点｜合同な図形を組み合わせる

👀 まず見るところ

【条件文】部品は「CD＝DA」と「角ABCと角CDAはともに直角」。図の辺に同じ印、角に直角の印を置く → Dのまわりに同じ四角形を4つならべると正方形になる。CDの長さは出さなくてすむ。

📚 前提知識

  • 四角形の4つの角の和は360度。角Bと角Dが90度だから、角Aと角Cの和は 360−90×2＝180度。180度は一直線。
  • Dを中心に90度回すと、辺DAは辺DCにぴったり重なる。長さが同じで、間の角が90度だから。

🔍 整理して解く

  1. 同じ四角形を、Dを中心に90度ずつ回して4つならべる。角Dが4つ集まって 90×4＝360度。すき間なくうまる。
  2. となりどうしの境目では、角Aと角Cがとなり合う。和が180度だから、外側の辺はまっすぐつながる。外側の1辺は、4cm と 6cm をつないだ 10cm。
  3. 正方形の面積は 10×10＝100cm²。
  4. 同じ四角形4つ分だから、4でわる。100÷4＝25cm²。
答え：25cm²
コツ：「となり合う2辺が同じ長さで、間が直角」の図形は、その頂点を中心に90度回すと重なる。4つならべて正方形にする手が使える。

1 (6) 円すいの側面に一巻きさせた糸 A・6点｜円すいの展開図

👀 まず見るところ

【条件文】部品は「最も短くなるように」と「半径が2cm」「母線の長さが12cm」。「最も短い糸」を「展開図のまっすぐな線」に直して書く → おうぎ形をかいてAとA′を結ぶ。先に中心角を出す。3.14は使わずにすむ。

2 (1) 3秒後の角ASP A・6点｜点の移動と中心角

👀 まず見るところ

【条件文】部品は「毎秒3.14cm」「半径10cm」と、求めるもの「角ASP」に丸。速さを「AからCまで何秒か」に直して書く → 角ASPが1秒に何度ふえるかが出る。3.14はわり算で消える。

📚 前提知識

  • 半円の上を同じ速さで動くと、中心から見た角も同じ調子でふえる。端から端までで180度。10秒かかるなら、1秒に18度。

2 (2) PSとQTがはじめて平行になるとき B・6点｜点の移動・角の和が180度

👀 まず見るところ

【条件文】部品は「はじめて平行になる」と「1.2倍」。Pは直線ACの上側、Qは下側を動く。「平行」を「角ASPと角ATQの和が180度」に直して書く → Qも「1秒に何度」にすれば、わり算1回で出る。ここまで見えたら手を付ける。

  • 2本の直線が平行なとき、錯角（Zの形にならぶ角）は同じ大きさ。ここでは角ASPと角BTQが錯角になる。

  1. QがAからBまで動く時間を出す。弧ABは 6×3.14 cm。速さは 3.14×1.2。わると 6÷1.2＝5秒。角ATQは1秒に 180÷5＝36度ふえる。

  3. 角BTQは「180度−角ATQ」。これが角ASPと同じ。つまり 角ASP＋角ATQ＝180度。
  4. 2つの角は合わせて1秒に 18＋36＝54度ふえる。180÷54＝10/3＝3 1/3秒後（3と3分の1）。

  6. たしかめ。1＋1＋1＋2＋5＝10。1＋1＋1＋3＋3＝9。1＋1＋2＋2＋2＝8。どれも、かけた数と同じ。3つとも書けて正解になる。

4 (1) 白玉1個と黒玉3個の取り出し方 B・6点｜場合の数（順番×選び方）

👀 まず見るところ

【条件文】部品は「取り出す順番が異なる取り出し方は、別の取り出し方」と例の「3通り」。作業を「白と黒（黒が1個へる）」「黒と黒（黒が2個へる）」に直して書く → へり方の順番 × どの黒玉を取るかで数える。例の3通りが自分で出せたら手を付ける。

  • 白玉は1個だけ。1回の作業で出る2個は、「白と黒」か「黒と黒」のどちらか。白玉は箱にもどすので、へるのは黒玉だけ。

🔍 整理して解く

  1. 「白と黒」の作業をA、「黒と黒」の作業をBと書く。Aは黒が1個へる。Bは黒が2個へる。黒3個を0個にする順番は、A→A→A、A→B、B→A の3つ。

    順番箱の中（○白 ●黒）どの黒玉を取るか取り方
    A→A→A○●●● → ○●● → ○● → ○3×2×16通り
    A→B○●●● → ○●● → ○3×13通り
    B→A○●●● → ○● → ○3×13通り
  3. 全部たす。6＋3＋3＝12通り。
  4. 落としやすい所は B→A の1回目。「3×2＝6通り」と数えると多すぎる。「黒玉1と2」「黒玉2と1」は同じ取り方。
  5. 別の見方でたしかめ。1回目で分ける。1回目がAなら、取る黒玉は3通り。残りは白1個と黒2個で、例の3通り。3×3＝9通り。1回目がBなら3通り。残りは白1個と黒1個で1通り。3×1＝3通り。9＋3＝12通りで同じ。

5 (1) 5人の順位と合格した2人 A・6点｜条件の整理（順位の表）

👀 まず見るところ

【条件文】部品は「半分」「100点満点」「2人だけが合格」に丸。「半分」は「AはCより下、BはDより下、AもBも50点以下」に直して書く → 91点のEはAとBより上。順位の表に×を置くと、1位と2位はCとEに決まる。

📚 前提知識

  • 基準点以上の人が合格。だから合格者は、点数の高い人から順に決まる。2人だけ合格なら、合格は1位と2位。
  • CはAの2倍の点数。Cは100点以下だから、Aは50点以下。同じように、Bも50点以下。

🔍 整理して解く

  1. ②から、AはCより下。Aは1位ではない。Cは5位ではない。③から、BはDより下。Dは3位だから、Bは4位か5位。
  2. AとBは50点以下。Eは91点だから、AとBより上。Eより下に2人以上いるので、Eは3位までに入る。3位はDだから、Eは1位か2位。ここまでを表に書く。
    1位2位3位4位5位
    A×
    B×××
    C×
    D××○××
    E×××
  3. 1位と2位のうち、1人はE。もう1人はAかC。Aは1位ではないので、Aが入るなら2位。すると1位はEで、CはAより下になる。②に合わない。だから、もう1人はC。
  4. 合格したのは1位と2位の2人。CとE。落としやすい所は、⑥を「合格＝上から2人」に直さずに進めること。
答え：CとE

5 (2) 基準点の最も高い点数・最も低い点数と理由 B・6点｜条件の整理（理由を書く）

👀 まず見るところ

【条件文】部品は「合計は316点」と「最も高い点数と最も低い点数」に丸。「半分」を「CはAの2倍、DはBの2倍」に直して書く → C＋D＝150点。基準点は3位のDより上、2位の点数以下。この両はしをさがす。(1)が出ていれば手を付ける。

📚 前提知識

  • 合格が1位と2位だけになるのは、基準点が「2位の点数以下」で「3位の点数より上」のとき。たとえば2位が80点、3位が60点なら、基準点は61点から80点まで。
  • CはAの2倍、DはBの2倍。A、B、C、Dの合計は、「AとBの合計」の3つ分になる。

🔍 整理して解く

  1. E以外の4人の合計を出す。316−91＝225点。これが「AとBの合計」の3つ分。AとBの合計は 225÷3＝75点。CとDの合計は 75×2＝150点。
  2. 最も高い基準点をさがす。基準点は2位の点数以下。Eが2位なら、2位は91点。Eが1位なら、2位のCは91点より下。だから2位の点数は、高くても91点。Cが92点のとき、Dは 150−92＝58点、Aは46点、Bは29点。Dは3位で、条件に全部合う。基準点は91点にできる。
  3. 最も低い基準点をさがす。基準点は3位のDより上。Dが低いほど、基準点も下げられる。CとDの合計は150点。Cは高くても100点。Dは低くても 150−100＝50点。このとき、Aは50点、Bは25点。AとDが同じ50点で、2人とも3位になる。基準点は51点まで下げられる。
  4. 理由を書く。入れるのは3つ。「CとDの合計は150点」「基準点はDより上で、2位の点数以下」「両はしになるときの点数の例」。計算の式もそのまま書いてよい。
答え：最も高い点数…91点，最も低い点数…51点
理由（例・解答一覧は「解説を参照のこと」。声の教育社の解説をもとにした書き方）：A、B、C、Dの合計は 316−91＝225点。CはAの2倍、DはBの2倍だから、AとBの合計は 225÷3＝75点、CとDの合計は150点。合格はCとEで、3位のDは不合格。だから基準点は、Dの点数より上で、CとEの低いほうの点数以下。Eは91点なので、基準点は91点より高くできない。Cが92点、Dが58点、Aが46点、Bが29点のとき、基準点を91点にできる。また、Cは100点以下なので、Dは 150−100＝50点以上。Cが100点、Dが50点、Aが50点、Bが25点のとき（AとDは同じ点数で、どちらも3位）、基準点を51点まで下げられる。
コツ：「考えられる点数のうち最も高い・最も低い」は、まず「基準点が入るはば」を言葉で書く。次に、そのはばの両はしが動くかどうかを調べる。最も低いときは、AとDが同じ50点で2人とも3位になる（声の教育社の解説の図もこの形）。
