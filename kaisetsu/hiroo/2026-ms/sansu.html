1 (1) 大きな立方体の2つの頂点を通る棒 A・8点｜立体図形（つき通す個数）

👀 まず見るところ

【条件文】部品は「2つの頂点を通る」と、決まりの「1つの頂点だけを通る場合」は数えない、に丸。棒を正面から見た図と真上から見た図に直して書く → 段ごとに、棒が通るますをぬる。どの段も1個で、3個。

📚 前提知識

  • 立体の中の棒は、正面から見た図と真上から見た図の2枚に分けて調べる。正面の図で「どの段の、左右のどこを通るか」が分かる。真上の図で「その段のどのますを通るか」が分かる。
  • 棒が小さな立方体の頂点にふれるだけなら、つき通したことにならない。中を通った立方体だけを数える。

🔍 整理して解く

  1. 正面から見た図をかく。棒は左上の角から右下の角へ進む。上の段では左の列を通る。中の段ではまん中の列、下の段では右の列を通る。
  2. 真上から見た図を、段ごとに3枚かく。棒は手前の左の角から、奥の右の角へ進む。正面の図で分かった列の中で、棒が通るますをぬる。
  3. ぬったますは、どの段も1個。1＋1＋1＝3個。
  4. 落としやすい所は、段が変わる所。棒は小さな立方体の頂点を通って、次の段へ入る。頂点でふれるだけのまわりの立方体は数えない。
答え：3個

2 (2) 1から5を、となりの和が素数になるように1列に並べる B・8点｜条件の整理（書き出し）

👀 まず見るところ

【条件文】部品は「隣り合っている数の和がどれも素数」と「以外のものを解答欄にすべて」に丸。(1)の図1の表を使う → 5のとなりに置けるのは2だけなので、5は列のはし。そこから順に決める。(1)の図1ができていれば手を付ける。

📚 前提知識

  • (1)の表から、となりに置ける相手をまとめる。1は2と4。2は1と3と5。3は2と4。4は1と3。5は2だけ。
  • 列のまん中にある数は、両どなりに相手が1つずつ要る。相手が1つしかない数は、はしにしか置けない。

🔍 整理して解く

  1. 5の相手は2だけ。5をまん中に置くと、両どなりに2が2個要る。だから5は左はしか右はし。そのとなりは2。
  2. 5を左はしに置く。「5，2，□，□，□」。2の次は1か3。
  3. 2の次が1のとき。1の相手で残っているのは4。4の次は3。「5，2，1，4，3」。2の次が3のとき。3の次は4。4の次は1。「5，2，3，4，1」。
  4. 5を右はしに置く。左はしのときの2つを、逆から読めばよい。「3，4，1，2，5」と「1，4，3，2，5」。
  5. 並べ方は全部で4つ。「1，4，3，2，5」は例なので、のぞく。答えは3つ。
  6. 落としやすい所は、逆から読んだ列。「5，2，1，4，3」と「3，4，1，2，5」は別の並べ方として書く。解答らんは5つあるが、使うのは3つ。3つとも合って8点（完答）。
答え：「3，4，1，2，5」，「5，2，1，4，3」，「5，2，3，4，1」
コツ：声の教育社の解説は、(1)の図1の答えを線にそってたどっている。左上→左下→右下→右上→まん中の順に読むと「1，4，3，2，5」。たどり始める丸を変えると、ほかの3つが出る。

3 (1) 静水時の船の速さ B・9点｜流水算・旅人算（流れが消える）

👀 まず見るところ

【条件文】部品は「静水時に同じ速さ」と「川の流れと同じ速さで流れた」に丸。時刻は「出発から10分・38分」に直して書く → 向かい合う2つの速さをたすと、流れの分が消えて静水時の速さだけになる。10分のときの線分図がかけたら手を付ける。

📚 前提知識

  • 下りの速さ＝静水時の速さ＋流れの速さ。上りの速さ＝静水時の速さ−流れの速さ。ボールは流れの速さで下る。
  • 向かい合って進む2つは、速さの和で近づく。AとBなら（静水＋流れ）＋（静水−流れ）。静水時の速さの2つ分になる。Bとボールなら（静水−流れ）＋流れ。静水時の速さの1つ分になる。

🔍 整理して解く

  1. 12km＝12000m。静水時の速さを毎分□mと書く。時刻は出発からの時間に直す。ボールを落としたのが10分。Bがボールの横を通ったのが38分。
  2. はじめの10分。AとBは向かい合っている。近づく速さは毎分 □×2 m。10分で □×20 m 近づく。
  3. 10分のとき、ボールはAと同じ場所にある。ここから38分までの28分間は、ボールとBが向かい合う。近づく速さは毎分□m。28分で □×28 m 近づいて、出会う。
  4. 線分図にまとめる。
  5. 全体をたす。□×20＋□×28＝□×48。これが12000m。□＝12000÷48＝250。
  6. 解答らんには式や考え方も書く。入れるのは3つ。「AとBは毎分□×2mで近づく」「ボールとBは毎分□mで近づく」「□×48＝12000」。
答え：毎分250m
式や考え方（例・解答一覧は答えだけ。声の教育社の解説をもとにした書き方）：12km＝12000m。静水時の速さを毎分□m、流れの速さを毎分△mとする。出発から10分までは、AとBが毎分（□＋△）＋（□−△）＝□×2（m）ずつ近づく。10分から38分までは、ボールとBが毎分（□−△）＋△＝□（m）ずつ近づく。□×2×10＋□×28＝□×48 が12000mだから、□＝12000÷48＝250。

3 (2) 川の流れの速さ A・8点｜流水算（はなれる時間＝近づく時間）

👀 まず見るところ

【条件文】部品は「すぐ引き返した」と「11時5分にボールを拾う」に丸。11時5分は65分に直して書く。Aとボールの間は、下りでは毎分250mで広がり、上りでは毎分250mでちぢまる → 時間が同じなので、折り返しは10分と65分のまん中。

📚 前提知識

  • 同じ向きに進む2つは、速さの差ではなれる。下りのAとボールなら（250＋流れ）−流れ＝250。
  • 向かい合う2つは、速さの和で近づく。上りのAとボールなら（250−流れ）＋流れ＝250。流れの速さが分からなくても、どちらも毎分250mになる。

🔍 整理して解く

  1. 10分にボールを落とす。Aは下りを続ける。Aとボールの間は、毎分250mずつ広がる。
  2. Aが下流のはしに着いて、すぐ引き返す。ここからAとボールの間は、毎分250mずつちぢまる。65分に0mになる。
  3. 広がる速さとちぢまる速さが同じ。広がった時間とちぢまった時間も同じになる。10分から65分までは55分。半分ずつで27.5分。折り返したのは 10＋27.5＝37.5分。
  4. Aは12000mを37.5分で下った。下りの速さは 12000÷37.5＝320。毎分320m。
  5. 流れの速さは、下りの速さ−静水時の速さ。320−250＝70。
  6. たしかめ。ボールを落とした場所は、上流から 320×10＝3200m。65分には 3200＋70×55＝7050m。Aは毎分 250−70＝180m で27.5分上る。180×27.5＝4950m。上流からは 12000−4950＝7050m。同じ場所になる。
  7. 落としやすい所は 12000÷37.5 の計算。両方を2倍して 24000÷75＝320 とすると、小数のわり算をしなくてすむ。
答え：毎分70m

3 (3) Bがボールの横を通ったときの、AとBの間の距離 A・8点｜流水算（同じ速さで同じ向き）

👀 まず見るところ

【条件文】部品は「船Bがボールの横を通り過ぎた時刻」に丸。38分に直して書く。Aの折り返しは37.5分 → 38分にはAもBも上り。同じ毎分180mなので、37.5分のときの間の距離がそのまま答えになる。

📚 前提知識

  • 同じ向きに同じ速さで進む2つは、間の距離が変わらない。AとBは静水時の速さが同じ。だから上りの速さも同じ毎分180mになる。

🔍 整理して解く

  1. 上りの速さを出す。250−70＝180。毎分180m。
  2. 37.5分のとき。Aは下流のはしにいる。Bは下流のはしから 180×37.5＝6750m の所にいる。間は6750m。
  3. ここからAも上りになる。AもBも毎分180m。間の距離は6750mのまま変わらない。38分のときも6750m。
  4. たしかめ。38分の場所を別々に出して、ひく。
    37.5分38分
    Aの場所（下流のはしから）0m180×0.5＝90m
    Bの場所（下流のはしから）6750m180×38＝6840m
    間の距離6750m6840−90＝6750m
  5. 落としやすい所は、38分のAの向き。Aを下りのまま計算すると合わない。(2)で出した37.5分と見くらべて、Aがもう折り返していることを図に書く。
答え：6750m

1〜3 まとめ

  • 立体の中の棒は、正面と真上の2枚の図に分ける。つき通す個数は「1＋こえた境目の面の数」。同時にこえる所は辺や頂点。
  • 「和が素数」は、組を全部書き出す。相手が少ない数・多い数から場所が決まる。並べる問題も同じ表で解ける。
  • 流水算で向かい合う2つは、流れの分が消える。船と流れるボールの間は、下りでも上りでも静水時の速さで変わる。

大問4（3×3のマスに6個の数字・列の合計から入れ方を決める）

4 全体像 A 8点／C 17点

小問図と合計難易度・配点入口の合図
(1)図1（横 7・4・16／縦 6・10・11）A・8点4 と 16 は、ちがう2つの数の和が1通りだけ
(2)図2（横 9・6・15／縦 7・10・13）C・9点15 は 6＋9 か 7＋8。入れ方が何通りもある
(3)図3（横 3・ア・14／縦 4・ア・13）C・8点3＝1＋2 と 4＝1＋3 で、1 の場所が決まる

どの列も、入る数字は2個だけ。だから列の合計は「ちがう2つの数の和」になる。この言いかえが3問とも入口になる。

取り方: (1)を確実に取る。(2)(3)は後回しでよい。時間が残ったら、決まるマスが多い(3)から見る。(2)は入れ方を全部そろえて9点なので、最後にする。

この解説では、横の列を「上の段・中の段・下の段」、縦の列を「左・まん中・右」とよぶ。

4 (1) 図1のマスに数字を入れる A・8点｜条件の整理（2つの数の和）

👀 まず見るところ

【条件文】部品は「それぞれ2個ずつ」と「異なる」に丸。合計を「ちがう2つの数の和」に直して書く → 4＝1＋3、16＝7＋9 と1通りに決まる列から埋める。

📚 前提知識

  • 1つの列に入る数字は2個。だから列の合計は「ちがう2つの数の和」。4 なら 1＋3 だけ。2＋2 は同じ数字なので使えない。
  • 小さい合計と大きい合計は、組が少ない。16 は 7＋9 だけ。7 は 1＋6、2＋5、3＋4 の3通りある。組が少ない列から決める。

🔍 整理して解く

  1. 合計の横に、たして合計になる2つの数を書く。組が少ない列から書く。中の段は 4＝1＋3。下の段は 16＝7＋9。
  2. 上の段の 7 は、1＋6、2＋5、3＋4 の3通り。1 と 3 は中の段で使った。残るのは 2＋5。使う6個は 1・2・3・5・7・9 に決まった。
  3. 縦の列も、この6個から2個ずつ使う。左の 6 は 1＋5。右の 11 は 2＋9。残った 3 と 7 で、まん中の 10 になる。
  4. 数字を1個ずつマスに置く。5 は「上の段」と「左の列」の両方にある。だから左上のマス。同じように、2 は右上、1 は中の段の左、3 はまん中、7 は下の段のまん中、9 は右下。
  5. たしかめ。横は 5＋2＝7、1＋3＝4、7＋9＝16。縦は 5＋1＝6、3＋7＝10、2＋9＝11。上の段を 3＋4 や 1＋6 にすると、中の段の 1 や 3 と重なる。ここが落としやすい。
答え：上の図の赤い数字（上の段は左5・右2、中の段は左1・まん中3、下の段はまん中7・右9。解答一覧では「解説の図②を参照のこと。」）

4 (3) 図3のイに入る数字を全部 C・8点｜条件の整理（1 の場所を決める）

👀 まず見るところ

【条件文】本番では後回し。部品は「同じ数が入ります」と、合計の 3 と 4。3＝1＋2、4＝1＋3 に直して書く → 1 は左上に決まる。ここまで見えたら、(2)より先に手を付けてよい。

📚 前提知識

  • 同じ数字は2回使えない。3＝1＋2 と 4＝1＋3 の両方に 1 がある。1 は1個だけ。だから、上の段と左の列が重なる左上のマスに入る。

🔍 整理して解く

  1. 1 を左上に書く。2 を右の列に置くと、もう1個が 13−2＝11 になってしまう。だから 2 は上の段のまん中。3 を下の段に置くと、もう1個が 14−3＝11 になってしまう。だから 3 は中の段の左。
  2. 上の段と左の列は、もう2個入った。右上と左下は空き。下の段は、まん中と右に入る。まん中の列は 2 と下のマスで2個。だから、まん中のマスも空き。残りの3マスを ○・△・イ とする。 下の段は △＋イ＝14。使える組は 5＋9 と 6＋8 だけ。7＋7 は同じ数字なので使えない。イは 5・6・8・9 のどれか。
  3. 4つとも表でたしかめる。△は 14−イ。○は 13−イ。横のアは 3＋○。縦のアは 2＋△。
    イ△（14−イ）○（13−イ）横のア（3＋○）縦のア（2＋△）
    5981111
    6871010
    86588
    95477
    4つとも、横のアと縦のアが同じ数になった。6個の数字も全部ちがう。イは4つとも当てはまる。
答え：5，6，8，9
