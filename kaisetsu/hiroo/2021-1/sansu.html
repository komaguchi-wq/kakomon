1 (1)② 11からの奇数の和が600 A・5点｜奇数の和（平方数）

【条件文】部品は「11＋13＋15＋17＋19＋…」と「＝600」。前に 1＋3＋5＋7＋9＝25 をたして「1から始まる奇数の和＝625」に直して書く → 625＝25×25 なので、奇数は25個。□は25番目の奇数。

📚 前提知識

  • 1から順に奇数をたすと、「個数×個数」になる。1＋3＝4＝2×2。1＋3＋5＝9＝3×3。1＋3＋5＋7＝16＝4×4。

  2. 両方に25をたす。1から□までの奇数の和は 600＋25＝625。

👀 まず見るところ

【条件文】部品は「水を蒸発させる」と「8％」。蒸発で減るのは水だけなので、「食塩10gが8％にあたる」に直して書く → あとの食塩水の重さが出る。200gとの差が蒸発させた水。

1 (4) 半径1cmの円に入った正八角形と三角形CDF B・6点｜等積変形

👀 まず見るところ

【条件文】部品は「半径1cmの円O」と「三角形CDF」。図が無いので、円・正八角形・中心Oを自分で図に置く → DFと平行な直径CGが見えたら、CをOに動かして半径2本の三角形にできる。見えないときは後回し。

📚 前提知識

  • 正八角形の頂点は、円周を8等分する。中心Oのまわりの角は 360÷8＝45度ずつ。DからFまでは2つ分で90度。
  • 三角形の頂点を、底辺と平行な線の上で動かしても、面積は変わらない。底辺も高さも同じままだから。

🔍 整理して解く

  1. 円に正八角形をかく。頂点に、Aから順にHまで記号をつける。向きはどうかいても、答えは変わらない。三角形CDFをぬる。CとGを結ぶ。Cから4つ先がGなので、CGは中心Oを通る直径になる。
  2. 直線OEで折ると、DとF、CとGがそれぞれ重なる。だからDFもCGもOEと垂直。2本は平行になる。
  3. Cを、直径CGの上でOまで動かす。底辺DFはそのまま。高さも同じ。だから三角形CDFの面積は、三角形ODFと同じ。
  4. 三角形ODFを見る。ODとOFは半径で1cm。Oの角は 45×2＝90度。直角をはさむ2辺が1cmの直角三角形になる。
  5. 面積は 1×1÷2＝1/2cm²。
答え：1/2cm²
コツ：円の中の正多角形は、中心Oと頂点を結ぶと「半径」と「中心の角」が使える。辺の長さが分からない三角形は、頂点を平行に動かしてOに集める。

👀 まず見るところ

【条件文】部品は「BP＝4cm」「AQ＝3cm」と、聞かれている「頂点Eを含む方」。下の面からの高さ PF＝1cm・QE＝2cm に直して図に書く → 切り口の4つ目の点の高さが決まれば、底面積×高さの平均で出る。

📚 前提知識

  • 立体を平面で切ると、向かい合う面にできる切り口の線は平行になる。前の面で「横に4cm進むと1cm下がる」なら、うしろの面でも同じ下がり方をする。
  • 底面が長方形で上がななめの立体は、体積＝底面積×高さの平均。同じ立体をさかさまにして上に重ねると、直方体になる。その半分と考える。

  2. 4つ目の点をさがす。前の面のQPは、横に4cm進むと 2−1＝1cm下がる。うしろの面でも、Dから横に4cm進むと1cm下がる。その点をRとする（Rは問題文に無い名前。この解説でつけた）。Rは辺CGの上で、Cから1cm下。RG＝5−1＝4cm。

  5. たしかめ。上の立体の高さは、上の面から測って 3cm・4cm・1cm・0cm。平均は2cm。体積は 12×2＝24cm³。36＋24＝60。直方体全体の 4×3×5＝60 と合う。

コツ：高さの平均が使えるわけ。向かい合うかどの高さをたすと、2＋4＝6、1＋5＝6 で同じになる。同じ立体をさかさまにして重ねると、高さ6cmの直方体（4×3×6＝72cm³）になる。その半分が36cm³。

👀 まず見るところ

【条件文】部品は「《n》＝777」と例の「《211》＝112＋121＋211＝444」。777を 111×7 に直して書く → 同じ数字が何個あるかで分けた表で数える。例の 444＝111×(2＋1＋1) に気づけたら手を付ける。

📚 前提知識

  • 同じ数字があると、並べ替えの個数がへる。211は 112、121、211 の3個。11は1個だけ。
  • 2つだけ同じ数字の3けた（211など）は、並べ替えが3個。たてに並べると、どの位にも3つの数字が1回ずつ出る。和は 111×(数字の和)。《211》＝111×4＝444。
  • 3つともちがう3けたは、(1)と同じ。和は 222×(数字の和)。《123》＝222×6＝1332。

🔍 整理して解く

  1. n のけた数を決める。《n》には n 自身が入っている。4けた以上だと和は1000より大きい。2けたは、いちばん大きくても 98＋89＝187。1けたは n そのもので、9まで。だから n は3けた。
  2. 777＝111×7 と書く。3けたの数を、同じ数字の個数で3つに分けて表にする。
    数字の形並べ替えの個数《n》777になるのはn の個数
    3つとも同じ1個n そのものn＝7771個
    2つだけ同じ3個111×(数字の和)数字の和が73組×3個＝9個

4 (1) 三角形ABEと面積の等しい三角形 A・6点｜長方形の対角線と等積（底辺が同じ・高さが同じ）

👀 まず見るところ

【条件文】部品は「長方形ABCDの対角線AC上に点E」と「三角形ABEと面積の等しい三角形」。BとDから対角線ACまでの高さを図に置く → 底辺AEが同じで高さも同じ、三角形AEDに決まる。

📚 前提知識

  • 長方形を対角線で切ると、同じ形で同じ大きさの三角形が2つできる。三角形ABCと三角形CDA。だから、BからACまでの高さと、DからACまでの高さは同じ長さ。
  • 底辺が同じで高さが同じ三角形は、形がちがっても面積が同じ。

🔍 整理して解く

  1. BEを引く。三角形ABEの底辺をAEと見る。高さは、BからACにおろした線。 大問4の図は、(2)(3)で分かる長さの比に合わせてかき直してある。問題の図とは、E・F・Gの位置が少しちがって見える。どの線の上にあるかは、問題の図と同じ。
  2. ACの反対側で、同じ底辺AEを使う三角形をさがす。三角形AEDが見つかる。高さは、DからACにおろした線。
  3. 2つの高さは同じ長さ。だから 三角形ABE＝三角形AED＝63cm²。
  4. 落としやすい所: 見た目の形がちがうので、等しいと思えない。底辺AEに色をつけて、高さだけをくらべる。
答え：三角形AED

4 (2) AE：EG を求める B・6点｜高さが同じ三角形（面積の比＝底辺の比）

👀 まず見るところ

【条件文】部品は「三角形AEDの面積は63cm²」「三角形ABGの面積は105cm²」。(1)で分かった 三角形ABE＝63 を図に置く → 105−63 で三角形EBGが出て、面積の比がそのまま AE：EG に決まる。引き算1回なので手を付ける。

📚 前提知識

  • 頂点が同じで、底辺が同じ直線の上にある2つの三角形は、高さが同じ。面積の比は底辺の比と同じになる。底辺が3cmと2cmなら、面積も 3：2。

🔍 整理して解く

  1. 図に面積を書きこむ。三角形ABEは(1)から63。三角形ABGは105。
  2. 三角形EBG＝105−63＝42cm²。
  3. 三角形ABEと三角形EBGは、頂点Bが同じ。底辺のAEとEGは、どちらもACの上にある。高さが同じ。
  4. AE：EG＝63：42＝3：2。
答え：3：2

4 (3) 三角形FBDの面積 B・6点｜面積の比と底辺の比（2回使う）

👀 まず見るところ

【条件文】部品は「三角形EGFの面積は12cm²」と、求める「三角形FBD」。12と(2)の42を図に置く → 三角形EGDから EF：FD が出て、三角形EBFの何倍かで決まる。面積を図に書きこめたら手を付ける。

📚 前提知識

  • (1)と同じ考え方。BとDは、ACまでの高さが同じ。底辺EGが同じなので、三角形EGD＝三角形EBG。
  • 高さが同じ三角形は、面積の比＝底辺の比。逆に、面積の比から底辺の比も出せる。

🔍 整理して解く

  1. GとDを結ぶ。三角形EGD＝三角形EBG＝42cm²。底辺EGが同じで、高さも同じ。
  2. 三角形EGDは、GFで2つに分かれている。三角形FGD＝42−12＝30cm²。
  3. 三角形EGFと三角形FGDは、頂点Gが同じ。底辺のEFとFDは、どちらもEDの上にある。EF：FD＝12：30＝2：5。
  4. 次は頂点Bから見る。BとDを結ぶ。三角形EBF＝三角形EBG＋三角形EGF＝42＋12＝54cm²。
  5. 三角形EBFと三角形FBDは、頂点Bが同じ。底辺はEFとFD。面積の比も 2：5 になる。
  6. 三角形FBD＝54×5/2＝135cm²。
  7. 別の道でたしかめ。三角形EGFと三角形EBGは、頂点Eが同じ。底辺の比は FG：GB＝12：42＝2：7。頂点Dから見ると、三角形FGDと三角形GBDも 2：7。三角形GBD＝30×7/2＝105。30＋105＝135。合っている。
答え：135cm²

5 (1) 面アと点も辺もふれない面 A・6点｜正八面体の展開図（頂点の記号を書きこむ）

👀 まず見るところ

【資料問題】部品は資料の正体「正八面体の展開図と見取り図」と聞かれ方「点も辺もふれない面」。展開図の頂点に見取り図の A〜F を書きこむ → 面アと同じ記号を1つも持たない面が答えに決まる。

📚 前提知識

  • 正八面体の頂点は6個。向かい合う頂点が3組ある。見取り図では AとF、BとD、CとE。向かい合う頂点どうしは、辺でつながっていない。
  • 展開図で、辺でくっついた三角形2枚（ひし形）を見る。ひし形のはなれた2つの頂点は、向かい合う頂点になる。面ABCと面ACDのひし形なら、はなれているのはBとD。

🔍 整理して解く

  1. 面アを見取り図の面ABCと決める。上の頂点にA、左下にB、右下にCと書く。どの面に決めても、同じように進められる。
  2. アと②のひし形を見る。はなれた頂点は、Bと②の右上。②の右上は、Bの向かいのD。
  3. ②と③のひし形では、Aと③の右下がはなれている。③の右下はF。③と④のひし形では、Cと④の右上がはなれている。④の右上はE。
  4. ④の頂点は D・F・E。A・B・C が1つも無い。④は面アと点も辺もふれない。
  5. 残りも同じやり方で書きこんで確かめる。⑤は F・E・B、⑥は E・A・B、①は E・A・D、⑦は B・C・F。どれも A・B・C のどれかを持っている。
  6. 落としやすい所: 展開図でアから遠くに見える①や⑥を選ぶ。組み立てると、⑥は辺ABで面アとくっつく。記号を書いて確かめる。
答え：④
コツ：三角形が一列に並んだ帯では、3つ先の面が「ふれない面」になる（ア→②→③→④）。

5 (2) 面DEFを地面に置いて真上から見た図 B・6点｜正八面体を面で置いた見え方（上下の正三角形を重ねる）

👀 まず見るところ

【まざり型→条件文】部品は「面DEFが地面とぴったり重なる」と「枠だけかきなさい」。真上に来る面ABCを見取り図に置く → 上の正三角形と下の正三角形を重ねてかくと、外側の枠が決まる。(1)の「ふれない面」が使えるので手を付ける。

📚 前提知識

  • (1)と同じ考え方。面DEFと点も辺もふれない面は、D・E・F を持たない面ABC。この2つの面は平行。面DEFを地面に置くと、面ABCが真上で水平になる。会話の広子さんの考え（面アを地面に置くと、真上からは面イも見える）は、このこと。
  • 正八面体にはへこんだ所がない。真上から見た枠は、6つの頂点をいちばん外側で結んだ形になる。

🔍 整理して解く

  1. 真上から見ると、上の面ABCも下の面DEFも、同じ大きさの正三角形に見える。2つの三角形の中心は重なる。
  2. 向きを決める。AはDとEに辺でつながっている。Fにはつながっていない。ADとAEは同じ長さなので、真上から見たAは、DとEのちょうど間に来る。
  3. 同じように、BはEとFの間。CはDとFの間。上の三角形は、下の三角形をさかさまにした向きになる。
  4. 6つの頂点を外側で順に結ぶ。A−D、D−C、C−F、F−B、B−E、E−A。どれも正八面体の辺。星形のへこみに見える所は、横の面（面ACDなど）がうめている。
  5. 6つの頂点は、中心から同じ長さの所に、同じ間かくで並ぶ。枠は正六角形。重なっている頂点は無い。
  6. 回る向きを確かめる。見取り図の面ABCを外から見ると、A→B→C は左回り。かいた図でも A→B→C は左回りになっている。
答え：右の図（上でかいた正六角形。頂点は時計回りに A・D・C・F・B・E）
コツ：図ウは上の面だけを見た形。図エは上の面と下の面だけを重ねた形。図オは頂点を真上にして置いたときの形。横の面まで考えると正六角形になる。

3〜5 まとめ この回で繰り返し出た入口

  • 新しい記号の問題は、例を自分で計算し直して決まりを見つける。《211》＝444＝111×4 が(2)(3)の入口。
  • 面積の問題は、分かった面積を図に書きこむ。高さが同じ三角形は、面積の比＝底辺の比。
  • 立体の展開図は、頂点の記号を書きこんで確かめる。同じ記号を持たない面どうしが、ふれない面。
