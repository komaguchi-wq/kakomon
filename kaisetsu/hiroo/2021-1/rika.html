1 問1 地球を磁石として見た図 A・2点｜図を選ぶ

👀 まず見るところ

【資料問題】部品は本文の「磁針のN極が北を向く」と、図の決まり「矢印は磁力線の向き」。「N極を引きつけるのはS極」と図の北極の横に書く → 北極側の磁極と矢印の向きの2つで1つにしぼれる。

📚 前提知識

  • 磁石のN極とS極は引き合う。方位磁針のN極が北に引かれるのは、地球の北極側がS極だから。
  • 磁力線の矢印は、磁石の外側ではN極から出てS極に入る向きにかく。

🔍 こう読み解く

  1. 北極側がS極、南極側がN極になっている図はウとエ。ア・イ・オ・カは北極側がN極なので消える。

1 問2 導線のまわりに置いた方位磁針A〜D B・2点｜電流のまわりの磁界

👀 まず見るところ

1 問5 電流を流す範囲 B・2点｜簡易モーター

👀 まず見るところ

【まざり型→条件文】部品は「反時計回りに回転させるように働く間だけ」と「P側から見て」。問4の力（abは右、cdは左）を、abが上半分のときと下半分のときの図に矢印で置く → 反時計回りになる半分が決まる。問4が解けていれば矢印を2組かくだけ。

🔍 こう読み解く

  2. abが下半分（カ・キ・クの側）にあるとき。下のabが右へ、上のcdが左へ押される → 反時計回り。ここで流す。

2 問1 氷から水になる現象と同じもの A・2点｜状態変化

👀 まず見るところ

【素材文】部品は「氷から水になる」と、答え方の「ひらがなで」。「固体→液体」と3語で書く → ア〜オも「何から何へ」に直せば、同じものが1つ残る。

📚 前提知識

🔍 こう読み解く

  1. ア 霜柱は、土の中の水がこおったもの（液体→固体）。
  2. イ コップの水滴とオ 湯気は、水蒸気が冷えて水のつぶになったもの（気体→液体）。

2 問2 氷と水のあたたまりやすさ B・2点｜計算・何倍

👀 まず見るところ

【条件文】部品は「同じ時間，同じ重さ」と、実験の「20秒」「21秒」。時間がそろっていないので「1秒あたり何℃」に直して書く（÷秒）→ 氷と水をそのまま比べられる。割り算2つで終わるので先に取る。

📚 前提知識

  • 氷も水も同じ200gで、熱は「常に一定の割合」で加えている。だから1秒あたりの温度上昇が大きいほうが、あたたまりやすい。

🔍 こう読み解く

  1. 氷: マイナス20℃から0℃まで20℃上がるのに20秒。20÷20＝1秒あたり1℃。
  2. 水: 0℃から10.5℃まで10.5℃上がるのに21秒。10.5÷21＝1秒あたり0.5℃。
  3. 1÷0.5＝2。氷のほうが2倍あたたまりやすい → ア。
  4. 160秒は氷がとけている間で、温度は0℃のまま。この計算には使わない。
答え：ア

2 問3 氷から水になるまでのグラフ A・2点｜グラフを選ぶ

👀 まず見るところ

【資料問題】資料の正体は「横軸は熱を加えた時間，縦軸は温度」。部品は実験の「20秒」「160秒」「21秒」。3つの時間を横はばとして図に置く → 平らな部分が長く、両はしのかたむいた部分の横はばがほぼ同じグラフに決まる。

📚 前提知識

  • 氷がとけている間は、加えた熱がとけることに使われる。温度は0℃のままで、グラフは平らになる。
  • グラフのかたむきが急なほど、あたたまりやすい（問2）。

🔍 こう読み解く

  1. アは線が真上に立っている。時間がたたないのに温度が変わることになるので消す。
  2. 横はばを比べる。氷の温度が上がる20秒と、水の温度が上がる21秒はほぼ同じ。平らな160秒は、20秒の8倍（160÷20）。
  3. イ・ウは、氷の部分の横はばが水の部分より広いので合わない。両はしの横はばがほぼ同じなのはエ。
  4. 確かめ: エは氷の線のほうが急。問2の「氷は水の2倍あたたまりやすい」と合う。
  5. 落としやすい所: 上がる温度（20℃と10.5℃）だけを見て選ぶこと。横軸は時間なので、秒数を横はばに直して比べる。
答え：エ

2 問4 1.5gのプロパンで同じ実験をしたとき B・2点｜計算・大小の判断

👀 まず見るところ

【条件文】部品は「45gのプロパン…16gのメタン…の2.5倍」と、問4の「1.5gのプロパン」。重さがそろっていないので「同じ45gどうし」に直して書く → 同じ重さで出る熱の大小が決まる。45÷16を計算して2.5と比べるだけなので手を付ける。

📚 前提知識

  • 燃やす重さが2倍、3倍になれば、出る熱も2倍、3倍になる。
  • 加える熱が少なければ、同じ200gの氷の最終的な温度は低くなる。

🔍 こう読み解く

  1. メタン16gの熱を1とする。メタンを45g燃やすと、45÷16＝2.8125。
  2. プロパン45gの熱は2.5。同じ45gで比べるとプロパンのほうが少ない（2.5÷2.8125＝8/9）。
  3. 同じ1.5gでも、プロパンの熱はメタンの8/9。熱が足りないので10.5℃まで上がらない → ア。
  4. くわしく確かめる。メタンのときは 20＋160＋21＝201秒ぶんの熱。その8/9は 201×8÷9＝178.66…秒ぶん。氷がとけ終わるのは 20＋160＝180秒ぶんなので、氷が少し残って0℃のままになる。
答え：ア

3 問3 4つの部屋が縮む順番 A・2点｜素材文・心臓の動き

👀 まず見るところ

【素材文】部品は部屋の名前「A：左心室　B：右心室」「C：左心房　D：右心房」。記号の横に「室」「房」と書く → 同じ種類の部屋どうしが同時に縮む、で選択肢を見る。

📚 前提知識

  • 心臓は「心房が縮む → 心室が縮む」の2段で動く。心房は血液を心室へ送る部屋、心室は血液を心臓の外へ送り出す部屋だから、順番にしないと血液が流れない。
  • 左右の心房どうし、左右の心室どうしは同時に縮む。

🔍 こう読み解く

  1. 記号に書きこむ: A・B＝心室、C・D＝心房。
