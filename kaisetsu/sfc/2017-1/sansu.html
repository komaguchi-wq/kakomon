1 (1) アが式の先頭にある逆算 A・5点｜逆算

👀 まず見るところ

【条件文】部品は式「8×ア÷4−14−6＝4」。アは式の先頭にある → 後ろの計算から順にもどして書く。「8×ア÷4」のかたまりが24と決まる。

📚 前提知識

  • 逆算は、最後にした計算からもどす。ひき算はたし算でもどす。□−6＝4 なら、□は 4＋6＝10。
  • わり算はかけ算でもどす。かけ算はわり算でもどす。□÷4＝24 なら、□は 24×4＝96。

🔍 整理して解く

  1. 計算の順番を書く。×8、÷4、−14、−6 の順。もどすときは逆の順になる。
  2. −6 をもどす。4＋6＝10。−14 をもどす。10＋14＝24。式は 8×ア÷4＝24 になった。
  3. ÷4 をもどす。24×4＝96。×8 をもどす。96÷8＝12。
  4. たしかめ。8×12÷4＝24。24−14−6＝4。合っている。落としやすいのは、もどすときに14や6をひいてしまう所。ひき算をもどすときはたす。
答え：12

【条件文】部品は「AはBより3列左」と「4個の文字がななめに一列にならぶことはない」。列は4つしかない → Aをア列、Bをエ列と図に置く。列を全部決めてから段を決めると、2通りまでしぼれる。

👀 まず見るところ

【資料問題】資料の正体は「ある立体の展開図」で、方眼は「1cm」。点線（折り目）で面に分けて正体を1行書く → ます4個の同じ形が2枚あるので、それが底面、高さ1cmの柱と決まる。

📚 前提知識

  • 展開図に同じ形の面が2枚あれば、それが柱の底面。残りの細い帯は側面になる。柱の体積は「底面積×高さ」。

🔍 整理して解く

  1. 点線で面に分けて、色をぬる。ます4個でできた段ちがいの形が、上と下に1枚ずつある。残りは、はば1cmの帯。
  2. 底面は、ます4個で4cm²。高さは帯のはばで1cm。
  3. 体積は 4×1＝4。1辺1cmの立方体を4個、段ちがいにつないだ形と同じ。
  4. 落としやすい所は、面を1枚ずつ組み立てようとして時間を使うこと。同じ形の2枚を先にさがす。
答え：4cm³

5 (2) 6個ですきまなく作る直方体の表面積 B・6点｜体積から3辺を決める

👀 まず見るところ

【条件文】部品は「6個」と「すきまなく」。体積 4×6＝24cm³ に直して書く → かけて24になる3辺をさがす。直方体の形が決まれば、表面積は式1本で出る。(1)が出ていれば手を付ける。

📚 前提知識

  • すきまなく組むと、体積は変わらない。4cm³が6個なら24cm³。
  • 直方体の表面積は「（たて×横＋横×高さ＋高さ×たて）×2」。同じ面が2枚ずつ3組ある。

🔍 整理して解く

  1. かけて24になる3つの整数を書き出す。
    3辺この立体で作れるか
    1×1×24、1×2×12、1×3×8、1×4×6× 厚さ1cmの板になる。段ちがいの形は、平らにならべるとすきまができる
    2×2×6× どう組んでもすきまが残る（声の教育社の解説も「作ることはできない」）
    2×3×4○
  2. 3辺は2cm、3cm、4cm。面を3種類書く。
  3. （2×3＋3×4＋4×2）×2＝26×2＝52。
答え：52cm²
コツ：本番では、組み方を全部たしかめなくてよい。24を「2×3×4」と分けて、表面積の式に進む。

5 (3) 直方体をならべて作る最小の立方体 B・6点｜最小公倍数

👀 まず見るところ

【条件文】部品は「同じ向き」と「最も小さい」立方体。立方体は3辺が同じ長さなので、2・3・4の最小公倍数に直して書く → 1辺12cmと決まり、各方向の個数をかける。

📚 前提知識

  • 同じ向きにならべると、たての長さは3cmの倍数、横は4cmの倍数、高さは2cmの倍数になる。3つが同じ長さになるのは公倍数のとき。

🔍 整理して解く

  1. 2と3と4の最小公倍数は12。立方体の1辺は12cm。
  2. 方向ごとに、ならべる個数を出す。
    方向直方体の辺個数
    たて3cm12÷3＝4個
    横4cm12÷4＝3個
    高さ2cm12÷2＝6個
  3. 4×3×6＝72。
  4. たしかめ。体積でくらべると 12×12×12＝1728、24×72＝1728。合っている。
答え：72個

6 (1) Bさんが出発したのは何分後か A・6点｜旅人算（時間の線分図）

👀 まず見るところ

【条件文】部品は「全長3.6km」「全長1.3km」と「9分早く」。kmはmに直して分速でわり、1周の時間120分と65分を線分図に置く → 「9分早く」は終わりの時刻の差なので、Bさんの出発が図から出る。

📚 前提知識

  • 時間＝道のり÷速さ。単位をそろえてからわる。3.6kmは3600m。
  • 出発がずれている2人は、時間の線分図を上下にならべる。左はしがA君の出発、右はしが着いた時刻。

🔍 整理して解く

  1. A君の1周は 3600÷30＝120分。Bさんの1周は 1300÷20＝65分。
  2. 線分図を書く。A君は0分から120分まで。Bさんが着くのは、その9分あとの129分。
  3. Bさんは129分に着いて、65分歩いた。出発は 120＋9−65＝64分後。
  4. 落としやすい所は、9分をひいてしまうこと。早く着いたのはA君なので、Bさんの着く時刻は120分に9分をたす。
答え：64分後

6 (2) C君が忘れ物に気がついたのは何分後か B・6点｜速さと比（往復）

👀 まず見るところ

【条件文】部品は「Bさんより21分遅れて」と「分速45m」。21分は「C君が着くのは150分後」に直して(1)の線分図に置く → 1周ぶんの80分をひいた残りが、気がつくまでの行き帰りの時間。(1)の図があれば手を付ける。

📚 前提知識

  • 同じ道のりを行って帰ると、かかる時間の比は速さの比の逆。分速30mと45mは2：3。時間は3：2。たとえば90mなら、行き3分、帰り2分。

🔍 整理して解く

  1. Bさんが着くのは129分。C君が着くのは 120＋9＋21＝150分後。
  2. C君の動きを3つに分けて、表に書く。
    区間速さ時間
    K→気がついた地点（行き）分速30m③
    気がついた地点→K（帰り）分速45m②
    長いコース1周分速45m3600÷45＝80分
  3. 行き帰りの合計は 150−80＝70分。これが③＋②＝⑤。
  4. 行きは 70÷5×3＝42分。気がついたのは出発から42分後。
  5. たしかめ。行きは 30×42＝1260m。帰りは 1260÷45＝28分。42＋28＝70分で合っている。
答え：42分後

6 (3) 短いコースのEからOまでの道のり B・6点｜旅人算（追いつき＋速さと比）

👀 まず見るところ

【条件文】部品は「2度目に出会ったところが地点E」と、はじめの文の「地点Oで出会った」。短いコースをまっすぐにのばした図に置く → KE と OK が別々に出て、1300mからひけば EO が残る。手順が長いので、本番では最後に回す。

📚 前提知識

  • 追いつくまでの時間は「はじめの差÷速さの差」。120m先の人を、1分に25mずつ近づいて追うと 120÷25＝4.8分。
  • 同じ道のりを進む時間の比は、速さの比の逆。分速30mと20mなら、時間は2：3。

🔍 整理して解く

  1. 短いコースを1本の線にのばして、K・E・O・Kを書く。求めるのはまん中のEO。
  2. 左のKEを出す。C君がKにもどるのは 42＋28＝70分後。Bさんは64分後に出発したので、そのとき 20×（70−64）＝120m先にいる。
  3. ここからC君がBさんを追う。1分に 45−20＝25m ずつ近づく。120÷25＝4.8分で追いつく。C君が進んだ道のりは 45×4.8＝216m。これがKE。声の教育社は道のりの比 4：9 を使い、120÷（9−4）×9＝216 と出している。
  4. 右のOKを出す。Oで出会ってからKまで、A君とBさんは同じ道を進む。時間の比は2：3。差の①が9分。A君は 9×2＝18分かかる。OKは 30×18＝540m。
  5. EOは 1300−（216＋540）＝544。
  6. たしかめ。BさんがOに着くのは、出発から（216＋544）÷20＝38分後で、64＋38＝102分。A君がOに着くのは 120−18＝102分。同じ時刻で合っている。
答え：544m
コツ：1度目の出会いは、C君がKへ引き返すとちゅうのすれちがい。2度目は、C君がKを出直してからの追いつき。だから「差÷速さの差」で考える。

4〜6 まとめ

  • ふえながらくり返す列は、区切り線を入れて組の表にする。「何枚目」は「何組目の何枚目」に直す。
  • 展開図は、同じ形の2枚を先にさがす。組み合わせの問題は、体積から3辺を決める。
  • 出発がずれる旅人算は、1周の時間を先に出して時間の線分図に置く。同じ道のりなら、時間の比は速さの比の逆。
