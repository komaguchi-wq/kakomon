二 問2Ⅰ・問2Ⅱ 空らんⅠ・Ⅱに入る語句 A・2点×2｜空欄型（語句・記号）

👀 ① 聞き方

問いは「あてはまる語句を次の中から選び」→ 読解の設計カードの空欄型（前後を見る → 入れて読み返す）。部品はⅠが「敵から逃れるための」、Ⅱが直前の文の「鳥から身を守る」に丸 → 丸の言葉を熟語に直したものが入ると決まる。

📚 ② 空欄の前後を切る

  • 空欄の前後にヒントがある（塾技70）。Ⅰは二か所にある。「天敵の鳥の攻撃から身を守るための[Ⅰ]である」と「優雅に見えるチョウの飛翔は、敵から逃れるための[Ⅰ]だったのである」。両方に入る語を選ぶ。
  • Ⅱの文は「さなぎになってもアゲハチョウの[Ⅱ]は手を抜くことはない」。「なっても」の「も」は、前の幼虫の話と同じことが続く合図。前の段落の終わりは「こうして、あの手この手で鳥から身を守るのである」。

🔍 ③ 入れて読み返す

  1. Ⅰ: 主語は「飛び方」「飛翔」＝チョウの動き。中身は「敵から逃れる」。逃れる＝逃避、動き＝行動なので ウ「逃避行動」。一つ目の空らんだけ見るとエ「防御手段」も入りそうに見えるが、二つ目の「逃れるための」に合うのはウ。
  2. Ⅱ: さなぎは「保護色」と「枝のトゲに似せた形」で身を守る。幼虫の「あの手この手」から続く「鳥から身を守る」方法の全体を指すので エ「防御手段」。
  3. 迷いやすいところ: Ⅱはア「偽装工作」やオ「模倣行為」も入りそうに見える。声教の解説は正解の理由だけを示している。アとオは私が「幼虫の臭角は、何かに似せる方法ではない。『さなぎになっても』で受ける中身は、似せることだけではなく身を守ること全体」という点で切った。イ「先制攻撃」は、鳥を先に攻める話が本文に無い。
  4. 落としやすい所: Ⅰを一つ目の空らんだけで決めてエにすると、Ⅱに入れる語がなくなる。二か所ある空らんは両方に入れて読み返す。
答え：Ⅰ＝ウ　Ⅱ＝エ

二 問3a・問3b・問3c 空らんa〜cに入るひらがな一字 A・2点（a）／B・2点×2（b・c）｜空欄型（ひらがな一字）

👀 ① 聞き方

問いは「ひらがな一字を書きなさい」→ 読解の設計カードの空欄型（前後を見る → 入れて読み返す）。部品はbの前の「のに対して」とcの前の「また」に丸 → 比べている、つけ加えている、という文のつながりで一字が決まる。丸が見えたらb・cも手を付ける。

📚 ② 空欄の前後を切る

  • 空欄の前後にヒントがある（塾技70）。a「羽を閉じてふわっと落ちる[a]、羽をはばたかせて、舞い上がるという動きを繰り返している」＝二つの動作が順に続く。
  • b「羽が大きいので、激しく上下運動をして敵をまどわすのに対して、意外にも体の方は大きく[b]上下しない」＝羽と体を比べている。
  • c「羽根を揚げるという意味で揚羽と呼ばれるようになったのである。また、…大きくて美しい羽で舞うようすからつけられたと[c]言われている」＝名前の由来の二つ目。

🔍 ③ 入れて読み返す

  1. a: 「落ちる」のあとに次の動作「舞い上がる」が続く。同じものの動作が続けて起こるときの「と」。「落ちると、…舞い上がる」。
  2. b: 羽は「激しく」上下する。体は少ししか上下しない。「大きくは上下しない」と「は」を入れると、羽と比べた言い方になる。
  3. c: 一つ目の由来に「また」で二つ目を足している。同じ種類のものをつけ加える「も」。「つけられたとも言われている」。
  4. 落としやすい所: 一字を入れたら、空らんの前後だけでなく文の頭から声に出すつもりで読み返す。bを空らんの前後だけで見ると、比べている相手（羽）に気づけない。
答え：a＝と　b＝は　c＝も

二 問4 ──線1「身をやつして」と同じ意味の語句 B・2点｜抜き出し型（同じ意味の語句＝対応語）

👀 ① 聞き方

問いは「同じ意味の語句を本文中から抜き出しなさい」→ 読解の設計カードの抜き出し型（その中の「同じ意味の語句」を探す形。形の合う語を探す → 同じ言い方の場所で確かめる）。部品は線の前の「糞の姿に」に丸 →「糞に〜して」の形がもう一度出る所を探せば、言葉の意味を知らなくても決まる。

📚 ② 形の合う語を探す

  • 答えを探す前の条件整理がカギ（塾技61）。形＝「〜して」で終わる語句。範囲＝幼虫が糞のふりをする話の中（線1のある段落）。
  • 「身をやつす」は、身なりを変えて、みすぼらしく目立たないような姿になること。ここでは幼虫が鳥の糞の姿になっていること。

✍️ ③ 同じ言い方の場所で確かめる

  1. ──線部を含む一文にも注目（塾技65）。線1の文は「糞の姿に身をやつして身を守っているのである」。
  2. 二つあとの文に「体が大きくなると鳥の糞に成りすましていたのでは巨大な糞になってしまう」。「糞に＋〜して」の形が同じ。
  3. 入れかえて確かめる。「糞の姿に成りすまして身を守っている」→ 意味が通る。答えの形式をそろえる（塾技63）ので、「成りすまして」と「て」まで写す。
  4. 迷いやすいところ: 同じ段落の「姿を似せて」も候補に見える。入れかえると「糞の姿に姿を似せて」となり、「姿」が重なって通らないので、私はここで切った（声教の解説は正解だけを示している）。
答え：成りすまして

👀 ① 聞き方

問いは「いくつの『手』があげられているか、算用数字で」→ 読解の設計カードの抜き出し型の仲間（条件を書く → 範囲を決める → 数えて確かめる）。部品は線の前の「こうして」に丸 → 前にもどって、幼虫の身の守り方を文の頭のつなぐ言葉で区切って数えると決まる。

📚 ② 条件を書き出す

  • 「あの手この手」は、さまざまな手段という意味。主語は「アゲハチョウの幼虫」、目的は「鳥から身を守る」。

二 問6(1)・問6(2)・問6(3)・問6(4) 空らん1〜4の接続語 A・2点×4｜空欄型（接続語）

👀 ① 聞き方

📚 ② 空欄の前後を切る

二 まとめ この大問で繰り返し出た入口

  • 空らんは前後の言葉に丸をつけてから選ぶ。二か所ある空らん（問2Ⅰ）は両方に入れて読み返す。
  • 段落や文の頭のつなぐ言葉（そこで・そして・また・さらに）に印をつけて読む。問5の数え方も問6の接続語も、この印で決まる。
  • 「同じ意味の語句」は、意味を考える前に同じ形の言い方（「糞の姿に〜して」と「鳥の糞に〜して」）を探し、入れかえて確かめる。

三 問11 「その音は、［Ⅴ］が［Ⅵ］音だよ」 B・2点｜抜き出し

👀 ① 聞き方

問いは「語句を本文中からぬき出し」→ 読解の設計カードの抜き出し型。やることは 条件を書き出す → 候補を数えて確かめる。部品は空らんの前の「その音は」と、空らんの後ろの私の言葉「奏でてるなんて言い方」に丸 → Ⅵは後ろ、Ⅴは海の場面にある。後ろの一言が見えたら取りにいく。

📚 ② 条件を書き出す

  • 答えを探す前の条件整理がカギ（塾技61）。形＝本文中の語句をそのまま／Ⅴは「〜が」の前＝音を出しているもの／Ⅵは「音」の前＝音をどうしているか。字数の指定は無い。
  • 範囲をしぼり込む（塾技62）。「その音は――」は、最初の海の場面でうみかが言いかけた言葉。Ⅴは、その直前のうみかの説明から探す。
  • 空欄の前後にヒントがある（塾技70）。空らんのせりふを聞いた私は「うみか、きちんと言葉にできてるよ。奏でてるなんて言い方、私もできないよ」と答えている。

✍️ ③ 候補を数えて確かめる

  1. Ⅵ: 私が「奏でてるなんて言い方」とほめている → うみかが今言った言葉の中に「奏でてる」がある。「音だよ」の前に入れると「奏でてる音だよ」とつながる。
  2. Ⅴ: 海の場面のうみかのせりふ「貝殻から海の音が聞こえるっていうけど、それを出してるのはお姉ちゃん自身。」→ 音を出しているもの＝「お姉ちゃん自身」。
  3. 入れて読み返す:「その音は、お姉ちゃん自身が奏でてる音だよ」。海の場面の「海の音じゃなくて、自分の耳の音なんだよ」と同じ中身になっている。

声教も、Ⅴは最初の場面の「それを出してるのはお姉ちゃん自身」、Ⅵはすぐ後の「奏でてるなんて言い方、私もできないよ」を根拠にしている。迷いやすいのはⅤ。「自分の耳」「蝸牛の体液」も音のもとだが、後ろに「が奏でてる」と続けて、妹が姉に言うせりふになるのは「お姉ちゃん自身」。「自身」まで写す。

答え：Ⅴ お姉ちゃん自身　Ⅵ 奏でてる

👀 ① 聞き方

🔍 ③ 気持ちで選択肢を切る

  1. ア がまん強い:「嫌なことがあった時、いつも大好きな宇宙のことを思い出して、きっと耐えている。」エ 強がり:「本音の声を聞かせないで突っぱね続けるのも、本当にうみからしい。」

四 じゃんけんをしたことがない人に、やり方とルールを説明する A・8点｜条件作文（四のC説明型・百八十字以内）

👀 ① 聞き方

問いは「説明する文章を…書きなさい」→ SFCの四の型カードのC説明型（全体 → 部品 → 手順 → 例外の順で書く）。傍線を言いかえる読解の設計カードの説明型とは別で、本文が無いので部品は自分で作る。設問の「したことがない人に」「やり方やルール」に丸 → 手の形・勝ち負け・進め方を言葉だけで書くと決まる。

📚 ② 条件を書き出す

  • 答えを探す前の条件整理がカギ（塾技61）。書き始める前に、設問の言葉を一つずつ丸で囲む。下が条件のチェック表。
設問の言葉（紙面のまま）答案ですること
「『じゃんけん』をしたことがない人に、」読む人は何も知らない。「グー」と書くだけでは伝わらないので、手の形を言葉で書く。声教の解説も、図や映像で示せないので、手の形をどう伝えるかがポイントとしている

✍️ ③ 部品を集める

  1. 先に材料を出す。知らない人が聞きたい順に、余白に名詞でメモする（手の種類→形と勝ち負け→進め方→同じ手のとき）。全体から細かい所へ進む順にすると、読む人が迷わない。
  2. 部品A（全体）: 模範解答は「グー，チョキ，パーの三種類の手の形があります」。はじめに数を言うので、あとの説明が三つあると分かる。
  3. 部品B（手の形）: 模範解答は、グー＝「こぶしをにぎった形」、チョキ＝「人差し指と中指をのばした形」、パー＝「手を開いた形」。石・はさみ・紙のたとえは使わず、手そのものの形を書いている。
  4. 部品C（勝ち負け）: 模範解答は「グーは…チョキに勝ち，パーに負けます」のように、一つの手につき勝つ相手と負ける相手の両方を書いている。三つの手を同じ形の文でそろえているので、読む人がくらべやすい。
  5. 部品D（進め方）: 模範解答は「かけ声をかけて同時に手を出し，勝敗を決めます」。「同時に」が無いと、後から出した人が勝てる遊びになってしまう。
  6. 部品E（同じ手のとき）: 模範解答は「二人が同じ手を出す『あいこ』の時には，じゃんけんをやり直します」。勝ち負けが決まらない場合まで書くと、ルールの説明がそろう。
  7. 出力の形: 「じゃんけんには（三種類の手）があります。（手①の形）で（勝つ相手）に勝ち、（負ける相手）に負けます。…（進め方）。（同じ手のとき）。」 模範解答は177字で、手の説明に116字（31＋28＋32＋25字）、進め方とあいこに61字（29＋32字）。字数指定のある記述は、コアを決めて要素を足し、8〜9割は書く（塾技87）。手の説明が6行をこえたら、進め方とあいこが入らなくなる。

模範解答とちがう書き方でもよい。声教の解答には「（例）」と付いている。学校の採点基準は分からないが、設問の条件から、答案に要るのは次の四つと考えられる。①三つの手の形が言葉で分かる ②どの手がどの手に勝つかが三つとも分かる ③同時に手を出すことが書いてある ④同じ手のときにどうするかが書いてある。落としやすいのは①で、ふだん使っている「グー」「チョキ」「パー」の名前だけを書いて、形の説明をぬかしやすい。

模範解答：じゃんけんには，グー，チョキ，パーの三種類の手の形があります。グーはこぶしをにぎった形でチョキに勝ち，パーに負けます。チョキは人差し指と中指をのばした形でパーに勝ち，グーに負けます。パーは手を開いた形でグーに勝ち，チョキに負けます。遊ぶ時には，かけ声をかけて同時に手を出し，勝敗を決めます。二人が同じ手を出す「あいこ」の時には，じゃんけんをやり直します。
コツ：自分で解くときのチェックは5つ。三つの手の形を言葉で書いた／勝ち負けが三つとも分かる／「同時に」出すと書いた／同じ手のときを書いた／百八十字以内で、原稿用紙の使い方を守った。書き終えたら、じゃんけんを知らない人になったつもりで読み返し、この文章だけで遊べるかを確かめる。
