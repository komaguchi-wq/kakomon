1 (1) 63と126と2100の最大公約数・最小公倍数 A・5点｜連除法（3つの数）

👀 まず見るところ

「最大公約数」と「最小公倍数」を3つの数で聞いている → 3つ並べて連除法を書く。最大公約数は「3つとも割れる数」だけ、最小公倍数は「2つ以上が割れる数」まで続ける。この2つの止めどころのちがいが、この問題の全部になる。

📚 前提知識

  • 最大公約数は、3つとも割れる数をかけ合わせた数。3で割り、7で割ったら、残りの3・6・100 はもう3つ同時には割れない。だから 3×7＝21。
  • 最小公倍数は、2つだけでも割れるうちは続ける。割れない数はそのまま下におろす。たとえば 3・6・100 を2で割ると、3はそのまま、6→3、100→50。

🔍 整理して解く

  1. 連除法を書く。3つとも割れる数で割る。 
    3 ) 63  126  2100
7 ) 21   42   700
     3    6   100   ← 3つ同時にはもう割れない
最大公約数＝3×7＝21
  2. そのまま続けて、2つ以上が割れる数で割る。割れない数はおろす。 
    2 )  3    6   100   ← 6と100が割れる。3はそのまま
3 )  3    3    50   ← 3と3が割れる。50はそのまま
     1    1    50
最小公倍数＝3×7×2×3×1×1×50＝6300
  3. たしかめ。6300÷63＝100、6300÷126＝50、6300÷2100＝3。どれも割り切れる。
答え：ア…21，イ…6300
コツ：3つの数の最小公倍数は「2つ割れれば続ける」。ここで止めてしまうと 21×3×6×100 のように大きくなりすぎる。

1 (2) □のある四則計算（逆算） A・5点｜逆算

👀 まず見るところ

□は「3 3/5÷□/25」のかたまりの中だけにある → □のないかたまりを先に計算して、式を「28/3−■−5/6＝1」の形に短くする。小数はすべて分数に直す（1.75＝7/4、1.4＝7/5）。

📚 前提知識

  • たし算・ひき算の間にある かけ算・わり算のかたまりは、それぞれ1つの数と同じ。先に計算して1つの数にしてしまう。
  • ひき算の逆算。「A−■−B＝1」なら、■＝A−B−1。順番を一つずつもどす。
  • わり算の逆算。「C÷■＝D」なら、■＝C÷D。たとえば 6÷■＝2 なら ■＝6÷2＝3。

🔍 整理して解く

  1. 左のかたまりを計算する。5 1/3×1.75＝16/3×7/4＝28/3。
  2. 右のかたまりを計算する。2 1/10÷1.4÷9/5＝21/10×5/7×5/9＝5/6。
  3. 式が短くなる。 
    28/3 − (3 3/5 ÷ □/25) − 5/6 ＝ 1
かっこの中 ＝ 28/3 − 5/6 − 1 ＝ 28/3 − 1 5/6 ＝ 56/6 − 11/6 ＝ 45/6 ＝ 15/2
  4. わり算をもどす。3 3/5÷□/25＝15/2 だから、□/25＝18/5÷15/2＝18/5×2/15＝12/25。
  5. 分母が25でそろった。□＝12。
答え：12
コツ：□/25 は「25分の□」という1つの分数として最後まで運ぶ。□だけを先に取り出そうとすると、途中で分母をなくしてしまう。

1 (3) 大小2つのサイコロで2けたの数が3の倍数 A・5点｜場合の数（3の倍数）

👀 まず見るところ

「2けたの数が3の倍数」→ 十の位＋一の位が3の倍数になる組を書き出す。和は3・6・9・12の4種類しかない。1から6の目で、たして3・6・9・12になる2つの数を組で書き、あとで大小の入れかえを数える。

📚 前提知識

  • 3の倍数の見分け方。各位の数の和が3の倍数なら、その数も3の倍数。たとえば 45 は 4＋5＝9 で3の倍数。
  • 大小2つのサイコロは区別がある。「大1・小2」と「大2・小1」は別の出方になる。同じ目どうし（3・3）は1通りだけ。

🔍 整理して解く

  1. 和が3の倍数になる組を、小さい数から書き出す。 
    和が3 ：(1,2)
和が6 ：(1,5) (2,4) (3,3)
和が9 ：(3,6) (4,5)
和が12：(6,6)
全部で7組
  2. ちがう数の組は5組。それぞれ大小を入れかえて2通りずつ。5×2＝10通り。
  3. 同じ数の組は (3,3) と (6,6) の2組。1通りずつで2通り。
  4. たす。10＋2＝12通り。
答え：12通り
コツ：別の見方。大きいサイコロの目を決めると、小さいサイコロの目は6つのうちちょうど2つで3の倍数になる。6×2＝12 で確かめられる。

2 (1) 駅と学校を2往復半するバスの速さ A・5点｜速さ（停車時間をのぞく）

👀 まず見るところ

「2往復半」「学校と駅でそれぞれ3分間停車」→ 全体の時間から停車の時間を引いて、走った時間だけを取り出す。2往復半は片道5回。停車は片道と片道の間だから4回。

📚 前提知識

  • 速さ＝道のり÷時間。分速を聞かれたら、道のりはm、時間は分にそろえる。4.2km＝4200m。
  • 「2往復半」は、行って帰ってを2回と、もう1回行く。だから片道は5回。

🔍 整理して解く

  1. 動きを順に書く。停車の回数を数える。 
    走る：駅→学校→駅→学校→駅→学校   片道5回
停車：学校・駅・学校・駅          4回（3分ずつ）
  2. 全体の時間。7時13分から8時までで 47分。
  3. 停車の合計は 3×4＝12分。走った時間は 47−12＝35分。
  4. 片道は 35÷5＝7分。速さは 4200÷7＝分速600m。
答え：分速600m
コツ：停車の回数は「最後の学校では止まらない」に気をつける。着いた時刻が8時。8時に着いてからの停車は数えない。

2 (2) 4時台に長針と短針が90°になる時刻 A・5点｜時計算

👀 まず見るところ

「4時から5時の間」「90°」→ 4時ちょうどの角120°から、長針が短針に1分5.5°ずつ追いつくと考える。90°になるのは2回。1回目は追いつく前（120−90）、2回目は追いこしたあと（120＋90）。

📚 前提知識

  • 長針は1分に 360÷60＝6°。短針は1分に 360÷12÷60＝0.5°。1分で差が 6−0.5＝5.5° 開く。
  • 4時ちょうどの長針と短針の角は、1目もり30°の4つぶんで 30×4＝120°。
  • 時計の角の問題は「1分に5.5°ちぢまる（開く）」という旅人算と同じ。

🔍 整理して解く

  1. 4時ちょうどの図をかく。長針は12、短針は4。差は120°。
  2. 1回目。長針が短針より30°多く動いたとき、差が 120−30＝90° になる。 
    1回目：長針が 120−90＝30° 多く動く → 30÷5.5＝5 5/11分
2回目：長針が 120＋90＝210° 多く動く → 210÷5.5＝38 2/11分
  3. 2回目。長針が短針を追いこして、さらに90°先に行く。多く動いた角は 120＋90＝210°。
  4. たしかめ。38 2/11分 は5時より前。どちらも4時台に入っている。
答え：イ…5 5/11分，ウ…38 2/11分
コツ：わり算 30÷5.5 は 30÷11/2＝60/11 と分数にして計算する。小数で割ろうとすると割り切れない。

2 (3) 同じ印の角がある直角三角形の x と y B・5点｜角度（印の角の和）

👀 まず見るところ

●●・○○・△△の2個ずつの印と直角がある → 1個ぶんを出そうとせず、「●＋○」「△−●」のような和・差で使う。x は●と○をふくむ三角形の残りの角。y は○と△の外角。●1個の大きさは決まらないが、決めなくてよい。

📚 前提知識

  • 三角形の3つの角の和は180°。直角があれば、残り2つの和は90°。
  • 外角の決まり。三角形のとなり合わない2つの角の和は、外角と同じ。たとえば 30°と40°の三角形なら、外角は70°。

🔍 整理して解く

  1. 点に名前をつける。直角の頂点をA、左下をB、右下をC。66°の点をD、下の辺の△の点をE、右の辺の点をF。x の点をG、y の点をH。
  2. 大きい三角形ABCを見る。●2個＋○2個＋90°＝180°。だから ●＋○＝45°。 
    三角形ABC：●●＋○○＝90° → ●＋○＝45°
三角形GBC：x＝180°−（●＋○）＝180°−45°＝135°
  3. x の三角形GBCは、角が●・○・x。x＝180−45＝135°。
  4. y のために、三角形DBEを見る。Eの外角が△2個。外角の決まりで △△＝●●＋66°。だから △−●＝33°。 
    三角形DBE の外角：△△＝●●＋66° → △−●＝33°
三角形HEC の外角：y＝○＋△
   ○＋△＝（●＋○）＋（△−●）＝45°＋33°＝78°
  5. y は三角形HECの外角。y＝○＋△。○＋△ は「●＋○」と「△−●」をたすと出る。45＋33＝78°。
答え：エ…135度，オ…78度
コツ：●の1個ぶんが出ないと止まってしまう問題。「たして45」「ひいて33」の2本の式ができたら、そのままたし算する。時間をかける価値は、x が出た時点で「和で使う」と見えたかどうかで決める。

3 (1) 戸が全開になるまでに開いた角度 A・5点｜図形（正三角形の半分）

👀 まず見るところ

戸の長さ6m、Aから角まで3m、戸の先は右のかべに当たる → 6mと3mの直角三角形は正三角形の半分。Aのところの角が60°で、閉まった向きからは 180−60 になる。

📚 前提知識

  • 直角三角形で、いちばん長い辺がもう一つの辺の2倍なら、正三角形を半分にした形。角は30°・60°・90°。短い辺のとなりの角が60°。
  • 閉まった戸はかべにそって左向き。開いた戸はAから右上へのびる。開いた角は、この2つの向きの間の角。

🔍 整理して解く

  1. Aと右下の角と戸の先で直角三角形をかく。戸6m、Aから角3m。 
    戸（斜め）：6m
Aから角　：3m   → 2：1 → 正三角形の半分
Aの角　　：60°
  2. 閉まった戸は左向き、開いた戸は右上向き。間の角は 180−60＝120°。
答え：120度
コツ：戸の先がかべに当たる高さは書かれていない。「6mと3m」の2つの数だけで角が決まる。

4 (2) 3点 A・P・Q を通る切り口と RF の長さ A・6点｜立体の切断（平行と相似）

👀 まず見るところ

A と Q は同じ面 ABED にある → まっすぐ結ぶ。上の面の切り口 AP と、下の面の切り口 QR は平行になる。すると三角形 ABP と三角形 QER が同じ形になり、ER が出る。

📚 前提知識

  • 切り口の線は「同じ面にある2点を結ぶ」でかく。A と P は上の面、A と Q は面 ABED、Q と R は下の面。
  • 向かい合う面（上の面と下の面）についた切り口の線は平行になる。たとえば直方体を斜めに切ると、上と下の切り口の線は平行。
  • 2つの直角三角形で、直角をはさむ辺の向きがそろっていれば同じ形（相似）。辺の比はどこも同じ。

🔍 整理して解く

  1. まず、図に切り口を書く。A→P（上の面）、A→Q（面 ABED）、Q→R（下の面）、R→P（面 BCFE）。切り口は台形 AQRP。 
    切り口の4本の線
A→P：上の面 ABC の上
A→Q：面 ABED の上
Q→R：下の面 DEF の上（AP と平行）
R→P：面 BCFE の上
  2. QR は AP と平行。だから三角形 ABP と三角形 QER は同じ形になる。直角は B と E。
  3. 対応する辺の長さをならべる。AB＝8cm、QE＝8−6＝2cm。比は 8：2＝4：1。
  4. ER は BP の 1/4。BP＝4cm だから、ER＝4×1/4＝1（cm）。
  5. 聞かれているのは RF。RF＝6−1＝5（cm）。
  6. 落としやすい所: ER＝1cm を答えにしてしまう。設問の「RF」を最後にもう一度見る。
答え：5cm

4 (3) 3点 A・P・S を通る切り口の面積 A・6点｜三角すいの展開図

👀 まず見るところ

切り口は三角形 APS。B に BA・BP・BS の3本が直角に集まる → 切り取られる三角すい A-BSP を展開図にすると 1辺 8cm の正方形になる。正方形から角の直角三角形3つをひく。三角形 APS の高さを直接はかろうとしても出ない。

📚 前提知識

  • 切り口は、同じ面にある2点を結ぶ。A と P は上の面、A と S は面 ABED、P と S は面 BCFE。だから切り口は三角形 APS で、頂点 B のまわりが切り取られる。

🔍 整理して解く

  1. B に集まる3本の辺の長さを書き出す。 
    B に集まる3本の辺（どれも直角に交わる）
BA＝8cm（上の面の辺）
BP＝4cm（上の面の辺 BC の上）
BS＝4cm（たての辺 BE の上）
  2. 展開図を余白にかく。1辺 8cm の正方形。左上を A。右の辺のまん中を P、下の辺のまん中を S。残りの3つの角は全部 B。
  3. 角の直角三角形3つの面積を出す。 
    正方形の角にある3つの直角三角形

三角形 ABS：8×4÷2＝16
三角形 BPS：4×4÷2＝8
  4. 正方形全体からひく。64−（8＋16×2）＝24（cm²）。
  5. 落としやすい所: 三角形 BPS を 8×4÷2 としない。BPS は 4cm と 4cm の直角三角形。

5 (1) 初めての黒い 7 は何番目 A・6点｜数列（けた数と周期）

👀 まず見るところ

数字だけ見ると 0, 1, 2, …の整数を1けたずつ並べたもの。色だけ見ると黒白白のくり返し → 3 でわって 1 あまる番目が黒。「何番目か」と「色」を分けて調べる。

📚 前提知識

  • 0〜9 は1けたで 10枚。10 からは1つの数に2枚使う。10〜17 なら 8個で 2×8＝16枚。
  • 2けたの数 n の一の位のカードは、10＋2×（n−9）番目。たとえば 17 の 7 は 10＋16＝26番目。
  • 黒は 1, 4, 7, 10, …番目。3 でわったあまりが 1 なら黒。あまりが 2 か 0 なら白。

🔍 整理して解く

  1. 7 が出てくる場所を小さい順に書き出す。7、17 の 7、27 の 7、…。
  2. それぞれ何番目かを出し、3 でわったあまりを見る。
    どの 7何番目3 でわったあまり色
    78番目2白
    17 の 710＋2×8＝26番目2白
    27 の 710＋2×18＝46番目1黒
  3. 初めて黒になるのは 27 の 7。46番目。
  4. 落としやすい所: 10〜27 の枚数を 18枚と数えない。2けたは1つの数に2枚で、2×18＝36枚。
答え：46番目

5 (2) 黒1 白8 白2 黒8 と並ぶ場所 B・6点｜数列（区切りを見つける）

👀 まず見るところ

「1 8 2 8」を 2けたの数の区切りで切る → 「□1｜8 2｜8□」で 81, 82, 83 の並び。あとは 81 の 1 が何番目かを出して、色が黒かを確かめる。区切り方が1つに決まったら、時間をかける価値がある。

📚 前提知識

  • 2けたの数 n の一の位のカードは、10＋2×（n−9）番目。81 の 1 なら 10＋2×72＝154番目。
  • 黒は3枚ごと。ある1枚が黒なら、そのあとは白・白・黒と自動的に決まる。

🔍 整理して解く

  1. 「1 8 2 8」に区切りを入れる。 
    区切り方
8｜1 → 81 の一の位
8 2  → 82
8｜3 → 83 の十の位
  2. 81 の 1 は何番目か。10〜81 で使う枚数は 2×（81−9）＝144枚。10＋144＝154番目。
  3. 色を確かめる。154÷3＝51 あまり 1 → 黒。合っている。
  4. 残りの3枚は 155, 156, 157番目。黒は3枚ごとだから白・白・黒になり、問題の並びと同じ。
  5. 落としやすい所: 「18」と「28」の組は、間に 19〜27 がはさまる。だから並ばない。となり合う数で区切る。
答え：154番目
コツ：もし 154 が黒でなかったら、次の候補（3けたの 1828 など）にうつる。まず一番小さい候補から色を確かめる。

5 (3) 白8 白8 黒8 白9 で止めたときの黒の数字の合計 C・6点｜数列（周期で集計）

👀 まず見るところ

本番では後回し。合図は「8 8 8 9」→ 88, 89 の並び。だから 0〜89 まで置いて止める。あとは黒のカードの数字を 30個ずつのかたまりで足す。

📚 前提知識

  • 黒は3枚ごと。2けたの数 30個は 60枚で、60 は 3 でわり切れる。だから 10〜39 と 40〜69 では、黒になる位置が同じになる。

  1. 止まる場所を確かめる。87 の 7 は 10＋2×78＝166番目。3 でわると 1 あまる → 黒。88, 89 の4枚（167〜170番目）は白・白・黒・白で、問題の並びと同じ。だから 0〜89 まで置いてやめる。
  2. 黒の数字を、かたまりごとに足す。10〜39 は書き出すと、一の位の黒は 0〜9 が1回ずつ、十の位の黒は 1 が3回・2 が4回・3 が3回。

  3. 全部足す。18＋65＋95＋80＝258。

6 (1) 工場 A の生産数は工場 B の何倍 A・6点｜比の消去算

工場 A の 1：2 と工場 B の 3：2 は単位のちがう比 → A を ①②、B を □3 □2 と表に書く。合わせた比 2：3 を式にすると、① と □ の関係が出る。

6 (2) プリンの価格はケーキの何倍 A・6点｜売上の比（消去算）

👀 まず見るところ

売上は「個数×値段」。プリン1個を □ 円、ケーキ1個を △ 円とおく → (1) の表の個数を使って、A と B の売上を式にする。売上の比 10：3 から □ と △ の関係が出る。

📚 前提知識

  • A の売上は □×5＋△×10。B の売上は □×3＋△×2。個数は (1) で出した 5・10・3・2 を使う。
  • 比の式は「内項の積＝外項の積」で等式にする。

🔍 整理して解く

  1. 式にする。（□×5＋△×10）：（□×3＋△×2）＝10：3。
  2. 内項の積＝外項の積。（□×3＋△×2）×10＝（□×5＋△×10）×3。 
    展開
左：□×30＋△×20
右：□×15＋△×30
  3. □ を左、△ を右に集める。□×30−□×15＝△×30−△×20。□×15＝△×10。
  4. 5 でわる。□×3＝△×2。だから □：△＝2：3。
  5. プリンはケーキの 2÷3＝2/3（倍）。
  6. 落としやすい所: 3/2 倍と逆にしない。「プリンはケーキの何倍」だから、プリン÷ケーキ。
答え：2/3倍

6 (3) 工場 C を建てて売上を3等分する B・6点｜比の文章題（逆算）

👀 まず見るところ

A で減らした分を B と C が作る → プリンとケーキの合計個数は変わらない。だから全体の売上も変わらず、1工場分＝全体÷3。C はケーキだけを作るから、C から順にもどして A の個数を出す。ここに気づけたら、手を付ける価値がある。

📚 前提知識

  • (1)(2) の結果を使う。個数はプリン 8・ケーキ 12（A が 5・10、B が 3・2）。値段はプリン 2、ケーキ 3 とおける。
  • 全体の売上は 2×8＋3×12＝52。3等分すると 52/3。

🔍 整理して解く

  1. C から出す。C はケーキだけで売上 52/3。ケーキ1個は 3 だから、C のケーキは 52/3÷3＝52/9（個）。
  2. A のケーキは、もとの 10 から C の分がへる。10−52/9＝38/9（個）。
  3. A のプリンを出す。A のケーキの売上は 3×38/9＝38/3。A の売上 52/3 からひくと、プリンの売上は 52/3−38/3＝14/3。プリン1個は 2 だから、A のプリンは 14/3÷2＝7/3（個）。
  4. B のプリンは 8−7/3＝17/3（個）。確かめ: B の売上は 2×17/3＋3×2＝52/3 で合っている。
    プリンケーキ売上
    A7/338/952/3
    B17/3252/3
    C—52/952/3
    合計81252
  5. ウ: A のプリンは 5 から 7/3 になった。減らした分は 5−7/3＝8/3。8/3÷5＝8/15（倍）。
  6. エ: A のケーキは 10 から 38/9 になった。減らした分は 10−38/9＝52/9。52/9÷10＝26/45（倍）。
  7. 落としやすい所: ウ・エは「減らした分÷もとの個数」。新しい個数÷もとの個数（7/15 や 19/45）にしない。

コツ：「3つの売上が等しい」と見たら、まず全体の売上を出して 3 でわる。分数のまま進めてよい。通分は最後だけ。

4〜6 まとめ この回で繰り返し出た入口

  • 数列は「何番目か」（けた数で数える）と「色」（3 でわったあまり）を分ける。
  • 単位のちがう比は ① と □ で表に書き、「内項の積＝外項の積」で消去算。前の小問の表を次でも使う。
