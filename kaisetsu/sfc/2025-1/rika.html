2 問1 食塩水に青色の溶液を加えた色 A・2点｜表の読み取り

👀 まず見るところ

📚 前提知識

🔍 こう読み解く

  2. 食塩水は中性で、酸でもアルカリでもない → 溶液の色は変わらず青。解答らんの末尾に「色」が印刷されているので「青」だけ書く。

2 問3 赤色の溶液を緑色にする溶液 B・2点｜中和・すべて選ぶ

👀 まず見るところ

手順4の結果の終わり「赤色」＝強い酸性。緑色は手順3の並びで青（中性）よりアルカリ側。つまり「アルカリ性の溶液を足す」問題。「加える量に制限はない」という一言が、選ぶ範囲を広げる合図。

📚 前提知識

  • 酸性の溶液にアルカリ性の溶液を加えると中和が進み、酸性が弱まって中性になり、さらに加えるとアルカリ性になる。
  • 表のアルカリ性は重そう水（b）とアンモニア水（f）の2つ。手順1でどちらも緑系（緑・黄緑）になっている。

🔍 こう読み解く

  1. 手順3の色の並び「赤→赤むらさき→むらさき→青→緑→黄緑」を、酸性が強い→アルカリ性が強い、のものさしとして余白に書く。
  2. 赤（強い酸性）を緑まで動かすには、アルカリ性の溶液で青（中性）を通りこすところまで中和する。酸性（a・c・e）や中性（d）を加えてもアルカリ性にはならないので、緑にはならない。
  3. 重そう水は手順1で「緑」止まりの弱いアルカリ性。だから多めに加えれば緑になり、黄緑まで行きすぎる心配もない。アンモニア水は緑を通って黄緑まで行くので、緑になったところで止める。よってbとf。「量に制限はない」は、弱い重そう水も外さないための一言。
答え：b・f

👀 まず見るところ

🔍 こう読み解く

👀 まず見るところ

会話文の「気温が下がりにくくなる」から出発する。夜や冬の気温が下がらない → 3 蚊が冬を越せる。都市だけ周囲より熱い → 上昇気流 → 積乱雲 → 4 局地的な集中豪雨。この2つが説明できれば手を付ける価値がある。

📚 前提知識

  • ヒートアイランド現象は、最高気温よりも最低気温（夜・冬）の上昇に大きく影響する。だから冬の夜に虫が死なずに越冬したり、春の花の開花時期が変わったりする。
  • 地面が周囲より熱いと空気が温められて上昇気流ができ、積乱雲が発生しやすい → 都市部だけに降る局地的な豪雨（いわゆるゲリラ豪雨）。

🔍 こう読み解く

  1. 3：冬の夜の気温が下がりにくい → 感染症のもとになる蚊が冬を越す → ○。
  2. 4：都市部の熱で上昇気流 → 積乱雲 → 局地的な集中豪雨が増える → ○。
  3. 5：雨が増える方向なので「河川水量の減少」は逆 → ×。2：地磁気は熱と関係がない → ×。1：レールの変形は暑さで起こるが、「都市部だけ気温が下がりにくい」から矢印でたどれない。声教の解説も3・4の理由だけを挙げているので、入れない → ×。
答え：3・4
コツ：「すべて選ぶ」は、会話文の1文（熱がこもって下がりにくい）から矢印でたどれるものだけ○にする。たどれない選択肢は入れない。

3 問6 バイオマス発電の排熱を処理する工夫 B・2点｜2つ選ぶ・完答

👀 まず見るところ

ゴールは「大気中に出る熱を減らす」こと。熱をよそへ移す（1 河川の水→海）か、熱を使い切る（3 暖房や給湯に再利用）が対策。2は「大気に直接」なのでそのまま、4の冷房（エアコン）は会話文で「利用をひかえる」側にある。

📚 前提知識

  • 会話文の対策は「エアコンや自動車の利用をひかえ、人工排熱を減らす」。冷房（エアコン）は、対策ではなく原因の側に書かれている。
  • 排熱を暖房や給湯に再利用すると、その分だけ大気に捨てる熱が減る。河川の水に熱を吸収させて海へ流せば、熱が都市部から移動する（ただし川の水温が上がるので生態系への影響は別に考える必要がある）。

🔍 こう読み解く

  1. 下線部②「バイオマス発電による人工排熱は、工夫して処理する」＝都市部の大気に熱を出さない工夫を2つ選ぶ。
  2. 1：河川の水で冷やして海へ → 熱が都市部から出ていく → ○。3：暖房・給湯に再利用 → 捨てる熱が減る → ○。
  3. 2：大気中に直接排出 → 工夫していない → ×。4：冷房で冷やす → エアコンの利用は会話文で減らす側 → ×。
答え：1・3

4 問1 皿の重さ A・2点｜てこの計算

👀 まず見るところ

「均一な棒の中央を支え」→ 棒の重さは考えなくてよい。図1の数字は皿が左50cm、おもり100gが右20cm。余白に皿×50＝100×20と書く。

📚 前提知識

  • てこのつり合い：支点の左側の（重さ×支点からの距離）＝右側の（重さ×支点からの距離）。
  • 均一な棒はその中央に重さが集まっていると考える。中央で支えていれば、棒の重さは支点の真上なので式に入れない。

🔍 こう読み解く

  1. 左：皿の重さ×50cm。右：100g×20cm＝2000。
  2. 皿の重さ＝2000÷50＝40g。
  3. 落としやすい所: 皿は「固定」されているので、このあとの問2・問3でも左側にはいつも「皿40g」が乗っている。
答え：40g

4 問2 皿にのせた物体の重さ A・2点｜てこの計算

👀 まず見るところ

おもりの位置が20cm→32.5cmに変わっただけ。左側は「皿40g＋物体」の合計。式は（□＋40）×50＝100×32.5。

📚 前提知識

  • 皿の上に物体をのせると、皿の位置（左50cm）に「皿の重さ＋物体の重さ」がかかる。距離は同じ50cmのまま。

🔍 こう読み解く

  1. 右側：100×32.5＝3250。
  2. 左側：（□＋40）×50＝3250 → □＋40＝3250÷50＝65。
  3. □＝65−40＝25g。皿の40gを引き忘れて「65g」と答えるのがいちばん多いミス。
答え：25g

4 問3 計ることができる最大の重さ A・2点｜てこの計算

👀 まず見るところ

「最大」＝おもりをいちばん遠くまで動かしたとき。棒は1mで中央支持なので、おもりは右端の50cmまで。式は（△＋40）×50＝100×50。

📚 前提知識

  • おもりが支点から遠いほど右側の「重さ×距離」が大きくなり、皿側に重いものをのせられる。棒の端がおもりの限界。

🔍 こう読み解く

  1. 右側：100×50＝5000。
  2. 左側：（△＋40）×50＝5000 → △＋40＝100。
  3. △＝100−40＝60g。ここでも皿の40gを引く。
答え：60g

4 問4 計れる最大の重さを大きくする方法 B・3点｜すべて選ぶ・完答

👀 まず見るところ

問3の式を言葉にする。物体の重さ＝おもり×（支点〜おもり）÷（支点〜皿）−皿の重さ。この式の「大きくなる向き」を7つの選択肢に当てはめるだけ。式を書ければ時間をかける価値がある。

📚 前提知識

  • 問3では 100×50÷50＝100、100−40＝60g。かける数（おもり・おもりまでの距離）が大きいほど、割る数（皿までの距離）と引く数（皿の重さ）が小さいほど、計れる重さは大きくなる。
  • 支点を中央からずらすと、棒の重さも効いてくる。棒の重心（中央）が支点より右にあれば、棒はおもりと同じ「右に傾ける側」にはたらく。

🔍 こう読み解く

  1. 1 皿を支点に近づける → 割る数（支点〜皿）が小さくなる → 大きくなる → ○。
  2. 2 支点を左（皿側）へ → おもりまでの距離が長く、皿までの距離が短くなる。さらに棒の中央が支点より右に来るので、棒の重さもおもりの側にはたらく → 大きくなる → ○。3はその逆 → ×。
  3. 4 おもりを重く → かける数が大きい → ○。5 → ×。6 皿を重く → 引く数が大きい → ×。7 皿を軽く → 引く数が小さい → ○。
  4. 落としやすい所: 7を「皿を軽くしても関係ない」と思って外すこと。皿の重さは最後に引く数なので、軽いほど物体に回せる分が増える。
答え：1・2・4・7

4 問5 てこの3つの点の名前 A・3点｜知識問題

A（荷物をのせた点）＝作用点、B（棒を支えている点）＝支点、C（棒を押す点）＝力点。「力を加える点が力点、力がはたらく相手が作用点、支えるのが支点」と役割で覚える。漢字指定なので「作用点・支点・力点」を正確に。解答用紙の推定配点では3つ完答で3点。
答え：A…作用点・B…支点・C…力点

4 問6 より小さな力で動かすには点Bをどうするか A・3点｜記述（10字以内）

👀 まず見るところ

「点A、Cの位置は変えない」ので、動かせるのは支点Bだけ。てこは支点から力点までが長く、支点から作用点までが短いほど小さな力ですむ。だからBを作用点Aに近づける。

📚 前提知識

  • てこのつり合い：荷物の重さ×（支点〜作用点）＝加える力×（支点〜力点）。支点〜力点が長いほど、同じ荷物を小さな力で動かせる。

✍️ 答案の組み立て

  1. 「点Bを」に続く形で、動かす向きを書く：「点Aに近づける」。「荷物に近づける」「作用点に近づける」も同じ意味で、解答一覧も「（例）」付き。
  2. 10字以内なので理由は書かない。解答用紙のマスは「点Bを」のあと10マス。
模範解答：（点Bを）点Aに近づける。
コツ：くぎぬき・バールを思い出す。支点を釘のすぐそばにして、長い柄の端を持つほど軽く抜ける。
