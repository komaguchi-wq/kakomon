1 問1 方位磁針の使い方 A・2点｜器具の使い方・正しいもの

1 問6 河口での川の水と海の水 B・2点｜正しいものの選択

👀 まず見るところ

📚 前提知識

🔍 こう読み解く

  2. 2は「えいきょうを受けにくい」が逆。水が蒸発すれば塩分はこくなり、雨が降ればうすくなる。
  3. 3は「大きく」が言いすぎ。4は、蒸発するのは川の水だけではないので、海の水の割合が高くなる理由にならない。
  4. 落としやすいのは、1の前半だけ読んで迷うこと。「真水は軽い」の1点で判断する。

2 問3 1往復の時間を長くする方法 B・2点｜すべて選ぶ

👀 まず見るところ

📚 前提知識

  • ふりこの長さは、支点からおもりの重心までの長さ。人が乗ったブランコでは、支点から人の重心までと考えてよい。

3 問3 気体Aの名前 A・2点｜矢印の向き・漢字指定

👀 まず見るところ

気体Aにつながる矢印の向き。生物ア・生物イからは気体Aへ（放出）、気体Aからは植物へ（吸収）。動物が出して、植物が取り入れる気体は1つしかない。

📚 前提知識

  • 動物は呼吸で二酸化炭素を放出する。植物は光合成をするために二酸化炭素を吸収する。

🔍 こう読み解く

  1. リード文の例で矢印の読み方を確かめる。「生物ア→気体A」＝放出、「気体A→植物」＝吸収。
  2. 動物が放出し、植物が吸収する → 二酸化炭素。酸素なら矢印の向きが全部逆になる。
  3. 「漢字で」の指定。「炭」の字を正しく書く。
答え：二酸化炭素

3 問4 足りない矢印をかき入れる B・2点｜作図

👀 まず見るところ

設問の「すべてが示されているわけではありません」。図1で気体Aへ矢印を出していない箱を数えると、植物と生物ウの2つ。この2つから気体Aへ矢印をかく。

📚 前提知識

  • 呼吸は生きているものすべてがしている。植物も、分解者の生物ウも、呼吸で二酸化炭素を放出する。植物は「吸収する（光合成）」と「放出する（呼吸）」の両方をしている。

🔍 こう読み解く

  1. 図1にある矢印は、生物ア→気体A、生物イ→気体A、気体A→植物の3本。
  2. 足りないのは植物→気体Aと生物ウ→気体Aの2本。植物の矢印は、もとからある気体A→植物の矢印のとなりに、向きを逆にしてかく。
  3. 矢印の先（とがった方）を気体A側にする。向きが逆だと「吸収」の意味になってしまう。
  4. 「排出物や死がい」の箱は生きていないので、矢印はかかない。
答え：右の図（植物→気体A、生物ウ→気体A の矢印を2本かき入れる）
コツ：植物の1本だけで終わらせやすい問題。「気体Aへ矢印が出ていない箱はどれか」を、箱を1つずつ指でさして確かめる。

3 問5 アカネズミの総数を求める比の式 A・2点｜比・標識再捕獲法

👀 まず見るところ

式の左がわ「N：(ア)」。Nは森林全体の数なので、右がわの先頭(イ)も「全体」にあたる数が来る。全体：印つき＝全体：印つきの形にそろえる。

📚 前提知識

  • 印をつけたネズミが森林全体にまんべんなく散らばれば、2回目につかまえた中の印つきの割合は、森林全体の中の印つきの割合と同じと考えられる。この調べ方を標識再捕獲法という。

🔍 こう読み解く

  1. 余白に数を整理する。森林全体＝N ひき、そのうち印つき＝32ひき。2回目につかまえた数＝29ひき、そのうち印つき＝4ひき。
  2. 森林全体で「全体：印つき」＝N：32。2回目で「全体：印つき」＝29：4。
  3. よって N：32＝29：4。ア＝32（D）、イ＝29（C）、ウ＝4（A）。
  4. 落としやすい所：答えるのは数字ではなく記号。また、イとウを逆（4：29）にしない。左がわが「多い方：少ない方」なので、右がわも29：4の順。
答え：ア D　イ C　ウ A
コツ：式を解くと N＝32×29÷4＝232。2回目の29ひき中4ひき（約7分の1）が印つきなので、全体は32ひきの約7倍、と見ても同じくらいの数になる。

3 問6 調査をより正確にするための注意 B・2点｜調査の条件・すべて選ぶ

👀 まず見るところ

問5の式が成り立つ条件は「2回目の29ひきが、森林全体の縮図になっている」こと。各文が、この縮図を守るか、くずすかで分ける。知識ではなく問5の考え方で決まるので、問5が解けたら続けて手を付ける。

📚 前提知識

  • 調査は、1回目と2回目の条件をそろえる（時刻・場所）。つかまえるときに体の大きさなどで選ばない。つけた印は2回目まで失われないようにする。

🔍 こう読み解く

  1. 1（同じ時間帯）・2（同じ場所）は、2回の調査の条件をそろえる文 → 正しい。
  2. 3（大きなものを選ぶ）・4（小さなものを選ぶ）は、どちらも選んでつかまえる文。かたよった集まりになり、縮図ではなくなる → 誤り。
  3. 5（外れやすい印）は逆。印が外れると、2回目に印つきとして数えられる数が本当より少なくなり、式から出るNが大きくなりすぎる → 誤り。
答え：1・2

3 まとめ 入口の確認

  • 図1は矢印の向きと点線のつながりだけで問1・問3が決まる。問4は「矢印が出ていない箱」を数える。
  • 「すべて」「2つずつ」の問は、設問の条件（森林・すべて）に線を引いてから選び、最後の選択肢まで読む。
  • 比の式は「全体：印つき＝全体：印つき」と、左右で同じ順にそろえる。

4 問3 A・B・C・D・G・Hは何の水溶液か A・1点×6｜実験結果から決める

👀 まず見るところ

実験1の「AとDだけ」と、実験2の「DとGのみ」。両方に出てくるDから決める。Dが決まると、AとGも続けて決まる。

📚 前提知識

  • 青色リトマス紙を赤くするのは酸性。8種類のうち酸性は炭酸水と塩酸の2つ。
  • アルミニウムをとかして気体（水素）を出すのは、塩酸と水酸化ナトリウム水溶液の2つ。
  • 鼻がツンとするにおいは塩酸とアンモニア水。さとう水は電気を通さない。フェノールフタレイン溶液はアルカリ性のときだけ赤むらさき色になる。

🔍 こう読み解く

  1. 実験1：AとDは酸性 → 炭酸水か塩酸。実験2：DとGは塩酸か水酸化ナトリウム水溶液。両方に当てはまるのは塩酸だけ → D＝⑤塩酸。残りから A＝①炭酸水、G＝⑦水酸化ナトリウム水溶液。
  2. 実験3：においがあるのはCとD。Dは塩酸と決まっているので C＝⑥アンモニア水。実験4：豆電球がつかないHは ⑧さとう水。
  3. 残ったB・E・Fは、食塩水・石灰水・重そう水のどれか。実験5でBは色が変わらない → アルカリ性ではない → B＝②食塩水（中性）。
  4. 落としやすい所：答えは①〜⑧の数字で書く。聞かれているのは A・B・C・D・G・H の6つで、EとFはここでは決めない（問4で決める）。
答え：A ①　B ②　C ⑥　D ⑤　G ⑦　H ⑧

4 問1 赤色リトマス紙を青くするもの A・2点｜性質で選ぶ・すべて選ぶ

👀 まず見るところ

設問の「A〜Eのうち」。赤色リトマス紙を青くする＝アルカリ性なので、問3の表のA〜Eからアルカリ性を拾う。Gはアルカリ性でも、選ぶ範囲の外にある。

📚 前提知識

  • 8種類を性質で分けると、酸性＝炭酸水・塩酸、中性＝食塩水・さとう水、アルカリ性＝石灰水・重そう水・アンモニア水・水酸化ナトリウム水溶液。

🔍 こう読み解く

  1. A炭酸水（酸性）、B食塩水（中性）、Dは塩酸（酸性）→ 選ばない。Cアンモニア水はアルカリ性 → 選ぶ。
  2. Eは石灰水か重そう水のどちらかで、まだ決まっていない。しかしどちらでもアルカリ性（実験5で赤むらさき色になっている）なので、決まらないまま選べる。
  3. 落としやすい所：「すべて選び」で、2つそろって2点。Eを「まだ分からないから」と外さない。
答え：C・E

4 問2 気体がとけている水溶液 B・2点｜とけているものの知識・すべて選ぶ

👀 まず見るところ

問3の表の横に、それぞれ「何が水にとけているか」を書きたす。気体は3つ。3つそろって2点なので、炭酸水とアンモニア水のあと、塩酸まで思い出せるかで決まる。ここは知っていれば短時間で取れる。

📚 前提知識

  • 気体がとけている：炭酸水（二酸化炭素）・アンモニア水（アンモニア）・塩酸（塩化水素）。
  • 固体がとけている：食塩水・石灰水・重そう水・水酸化ナトリウム水溶液・さとう水。水を蒸発させると固体が残るのはこちら。

🔍 こう読み解く

  1. 範囲は「A〜Hのうち」。問3の表から、A＝炭酸水、C＝アンモニア水、D＝塩酸の3つを選ぶ。
  2. E・Fは石灰水と重そう水で、どちらも固体がとけた水溶液。決まっていなくても、選ばないと判断できる。
  3. 落としやすい所：実験3でにおいがあったCとDは、どちらも気体がとけた水溶液。においのある2つに、においのない炭酸水を足して3つ、と数えると塩酸を落とさない。
答え：A・C・D

4 問4 EとFを決める実験 A・2点×3｜見分ける実験を選ぶ

👀 まず見るところ

EとFは石灰水か重そう水。石灰水といえば「二酸化炭素で白くにごる」。二酸化炭素がとけているのは炭酸水＝A。問3の表があれば、アはすぐに決まる。

📚 前提知識

  • 石灰水は二酸化炭素と反応して白くにごる。炭酸水には二酸化炭素がとけているので、石灰水に炭酸水を加えても白くにごる。
  • 重そう水に炭酸水を加えても、白くにごらない。

🔍 こう読み解く

  1. ア：選べるのは A炭酸水・B食塩水・Cアンモニア水。石灰水だけに変化を起こせるのは炭酸水 → A。
  2. イ：文は「Eでは〔イ〕が、Fでは変化が見られなかった」。変化があったのはEなので、Eのようすを10字以内で書く →「白くにごった」（6字）。
  3. ウ：白くにごったEが石灰水 → ③。変化のないFが重そう水（④）。
  4. 落としやすい所：アはA〜Cの記号、ウは①〜⑧の数字で答える。アに「①」、ウに「石灰水」と書かない。
答え：ア A　イ 白くにごった　ウ ③
コツ：実験5でEもFも赤むらさき色になったが、そこから分かるのは「どちらもアルカリ性」までで、石灰水か重そう水かは決まらない。だから問4で別の実験をして「はっきり決める」ことになる。

4 まとめ 水溶液の見分け

  • 見分けの問題は、2つの実験に共通して出てくる記号から決める（今回はD＝塩酸）。
  • 対応表を先に作り、「何性か」「何がとけているか」を横に書きたすと、あとの問いは表を見るだけになる。
  • 「A〜Eのうち」「A〜Cから」「①〜⑧の数字で」のように、問いごとに選ぶ範囲と答え方がちがう。答える前にそこへ線を引く。
