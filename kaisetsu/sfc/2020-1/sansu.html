1 (1) 分母が49の分数3つのかけ算 A・5点｜計算のくふう

👀 まず見るところ

3つの分数の分母が全部49で、分子は22・11・33。どれも11の倍数 → 11/49 でくくって、かっこの中だけ先に計算する。1つずつかけ算してからたすと、数が大きくなって約分で手間がかかる。

📚 前提知識

  • 同じ数をかけているものは、かっこでまとめられる。たとえば 3×4＋3×6 は 3×(4＋6)＝30。別々に計算しても 12＋18＝30 で同じ。
  • 22/49 は 11/49×2、33/49 は 11/49×3。余った2と3は、うしろの帯分数にかけておく。

🔍 整理して解く

  1. 帯分数を仮分数に直す。2と1/3＝7/3、3と5/6＝23/6、1と2/3＝5/3。
  2. 11/49 を外に出す。余った2と3を、うしろの数にかける。 
    22/49×7/3  → 11/49×(2×7/3) ＝ 11/49×14/3
11/49×23/6 → そのまま
33/49×5/3  → 11/49×(3×5/3) ＝ 11/49×5
  3. かっこの中を6で通分する。14/3＋23/6−5 ＝ 28/6＋23/6−30/6 ＝ 21/6。
  4. 11/49×21/6 を約分する。21と49を7でわると 3 と 7。3と6を3でわると 1 と 2。残りは 11/(7×2)＝11/14。落としやすいのは、ひく数の 33/49 のほうに3をかけわすれる所。
答え：11/14

1 (2) かっこの中の分数に□がある計算 A・5点｜□をもどして出す

👀 まず見るところ

□はかっこの中の分数の分子にある → 外側から1枚ずつはがす。順番は「−0.375」→「2÷」→「3−」→「÷34」→「＋41」。小数の0.375と1.75は、先に分数の 3/8 と 7/4 に直しておく。

📚 前提知識

  • 0.375＝3/8、1.75＝7/4。0.125＝1/8 の3つ分が0.375。
  • 「2÷○＝△」の○は、2÷△で出る。たとえば 2÷○＝4 なら、○は 2÷4＝0.5。「3−○＝△」の○も同じで、3−△で出る。わる数とひく数は、かけ算やたし算でもどさない。

🔍 整理して解く

  1. 「□＋41」をひとまとめにして△と書く。式は「2÷(3−△/34)−0.375＝1.75」。
  2. いちばん外の「−0.375」をもどす。1.75＋0.375＝7/4＋3/8＝14/8＋3/8＝17/8。
  3. 「2÷(かっこ)＝17/8」だから、かっこは 2÷17/8＝2×8/17＝16/17。
  4. 「3−△/34＝16/17」だから、△/34＝3−16/17＝51/17−16/17＝35/17。分母を34にそろえると 70/34。△は70。
  5. □＋41＝70 だから、□＝70−41＝29。たしかめ。(29＋41)÷34＝35/17。3−35/17＝16/17。2÷16/17＝17/8。17/8−3/8＝14/8＝1.75。合っている。
答え：29

2 (1) 入れる水の量を1.2倍にしたときの時間 A・5点｜逆比（反比例）

👀 まず見るところ

水そうの大きさは同じで、「1.2倍」になるのは1分あたりの水の量 → 時間は逆の比。1.2＝6/5 だから、時間は5/6倍。1時間30分は先に90分に直す。90×1.2 とかけると時間がふえてしまう。

📚 前提知識

  • いっぱいにする水の量が同じとき、入れる速さの比と時間の比は逆になる。たとえば速さが2倍なら、時間は半分。速さが 5：6 なら、時間は 6：5。

🔍 整理して解く

  1. 1分あたりの水の量の比を書く。はじめ：あと＝1：1.2＝5：6。
  2. 時間の比は逆にする。はじめ：あと＝6：5。

時間    はじめ 6 ： あと 5
        90分        □分
  3. 1時間30分＝90分。90分が6にあたる。あとの時間は 90×5/6＝75分。

2 (2) 表で5歩・裏で3歩、15回で63歩 A・5点｜つるかめ算

👀 まず見るところ

「15回」と「合わせて63歩」。回数の合計と歩数の合計が両方ある → つるかめ算。全部が裏だったとして、足りない歩数を2歩ずつうめる。聞かれているのは表の回数だから、裏にそろえると、わり算の答えがそのまま表の回数になる。

📚 前提知識

  • 裏1回を表1回に取りかえると、回数は15回のまま、歩数だけ 5−3＝2歩 ふえる。たとえば裏15回なら45歩。表1回・裏14回なら47歩。

🔍 整理して解く

  1. 全部が裏だったとする。3×15＝45歩。
  2. 実際は63歩。足りないのは 63−45＝18歩。
  3. 裏を表に1回取りかえるごとに2歩ふえる。18÷2＝9回が表。 
    裏15回       → 45歩
表1回 裏14回 → 47歩（＋2）
  …
表9回 裏6回  → 63歩

2 (3) 36人のクラスで金魚と犬の両方を飼っている人数 A・5点｜集まり

👀 まず見るところ

①②③は全部「飼っていない者」の人数。聞かれているのは「両方を飼っている者」 → 先に36からひいて、「飼っている人数」に直す。金魚は23人、犬は21人、どちらかを飼っている者は30人。直さずに13と15をたすと、何の人数か分からなくなる。

📚 前提知識

  • 金魚の人数と犬の人数をたすと、両方を飼っている者を2回数えている。だから「金魚＋犬−どちらかを飼っている者」で、両方の人数が出る。たとえば金魚3人、犬2人で、どちらかを飼っている者が4人なら、両方は 3＋2−4＝1人。

  2. どちらかを飼っている者は 36−6＝30人。

├──── 金魚23人 ────┤

👀 まず見るところ

聞かれているのは段ごとの「和」 → 図の1段目から5段目の和を横に書きならべる。1, 2, 4, 8, 16。1段下がるごとに2倍になっている。7段目まで2倍を続ける。7段目の数を1つずつ作ってからたしてもよいが、(3)では使えない。

👀 まず見るところ

こんどは数の和ではなく「個数」。図では1段目に1個、2段目に2個、5段目に5個 → □段目には□個。「1から73までの和」から「1から34までの和」をひく。ひくのは35段目までではなく、その手前の34段目まで。

5 (1) 折った紙の角㋐の大きさ B・6点｜折り返しと角度

👀 まず見るところ

「BEとEFの長さが等しい」→ 図2の三角形E・B(D)・F が正三角形だと見ぬく。3つの角が60度と分かれば、角㋐は60度2つ分で出る。ここが見えたら(2)(3)まで手を付ける価値がある。

📚 前提知識

  • 紙を折ると、重なる辺と角は同じ大きさ。BがDに重なるから、図1でEとDを結んだ線はEBと同じ長さ。FとDの間も、FBと同じ長さ。
  • 長方形の左の辺ABと右の辺DCは平行。折り目EFがこの2本を横切る。だから、図1でEの下側の角（EBとEFの間）と、Fの上側の角（FEとFDの間）は同じ大きさ（さっ角）。

🔍 整理して解く

  1. 図1に、EとDを結ぶ線をかき足す。三角形DEFができる。
  2. Eの下側の角（EBとEFの間）は、折るとEDとEFの間の角に重なる。だから同じ大きさ。この角は、Fの上側の角（FEとFDの間）とも同じ大きさ。

  4. DEはBEと同じ長さ。BEはEFと同じ長さ。3つの辺が全部同じになった。三角形DEFは正三角形で、角は全部60度。図2では三角形E・B(D)・F がこれにあたる。
  5. 図2で角㋐を2つに分ける。左側は正三角形の角で60度。右側は三角形B(D)・C・F の角。 
    角E・B(D)・C は折る前のBのかどで90度 → 90−60＝30度が三角形B(D)・C・Fの角
角B(D)・C・F も折る前のCのかどで90度 → Fの角は 180−90−30＝60度
角㋐＝60＋60＝120度
  6. たしかめ。図1でFの下側の角（FEとFCの間）は 180−60＝120度。折ってもこの角は変わらない。
答え：120度

5 (2) AGとGDの長さの比 B・6点｜折り返しと辺の比

👀 まず見るところ

「頂点Aが直線BEに重なった」→ 折り目EGは、図2のEの角（EAとEBの間）をちょうど半分に分ける。この角は60度だから30度ずつ。30度と60度が出たら、正三角形の半分の三角形をさがす。

📚 前提知識

  • 角が90度・60度・30度の三角形は、正三角形を半分にした形。いちばん短い辺といちばん長い辺の比は 1：2。図2の三角形AEGでは、短い辺がAG、長い辺がEG。
  • 2つの角が同じ三角形は二等辺三角形。図2の三角形G・E・B(D) は、EとB(D)の角がどちらも30度になる。

🔍 整理して解く

  1. 図2の左上の三角形A・E・B(D) の角を出す。Aは紙のかどで90度。Eの角は図1で考える。左の辺ABは一直線で、Eのところは180度。そこから(1)の60度を2つ（EDとEFの間、EFとEBの間）引く。残りは60度。B(D)の角は 180−90−60＝30度。
  2. 折り目EGが、Eの60度を半分にする。図2に30度を2つ書きこむ。 
    三角形AEG      ：A＝90度  E＝30度  G＝60度 → 正三角形の半分
三角形G・E・B(D)：E＝30度  B(D)＝30度      → 二等辺三角形
  3. 三角形AEGで、AGを1とする。EGは2。
  4. 三角形G・E・B(D) は二等辺三角形。だからGB(D)もEGと同じ2。GB(D)はGDのこと。
  5. AG：GD＝1：2。
答え：1：2
コツ：声の教育社の解説は、図3で三角形AEGと三角形A・B(D)・G が合同（ぴったり重なる形）だとして、GB(D)＝2 を出している。数は同じになる。

5 (3) かげの部分が20cm²のときの長方形の面積 B・6点｜辺の比と面積

👀 まず見るところ

図3のかげの三角形は、図2の三角形AEGを折り返したもの → 三角形AEGも20cm²。(2)の 1：2 を使って、図2の左上の三角形A・E・B(D) の面積に広げる。そこから長方形全体に広げる。

📚 前提知識

  • 高さが同じ三角形は、面積の比が底辺の比と同じ。図2の三角形AEGと三角形G・E・B(D) は、どちらも高さがAE。底辺はAGとGDで 1：2。だから面積も 1：2。
  • 直角三角形の面積は、長方形の半分。図1でAE×ADの長方形は、三角形AEDの2倍。

🔍 整理して解く

  1. 三角形AEGは20cm²。三角形G・E・B(D) はその2倍で40cm²。
  2. 合わせると、図2の左上の三角形A・E・B(D) は 20×3＝60（cm²）。
  3. 図1にもどす。この三角形は三角形AED。たてAE・横ADの長方形は 60×2＝120（cm²）。
  4. たての長さをくらべる。三角形AEDも正三角形の半分で、AE：ED＝1：2。EDはEBと同じ長さ。だから AE：EB＝1：2。ABはAEの3つ分。 
    図1の左の辺  A ├─1─┤E├───2───┤ B
たてAEの長方形が120cm² → 3つ分で 120×3＝360cm²
  5. 長方形ABCDは 120×3＝360（cm²）。
答え：360cm²

6 (1) K君が橋Aをわたって店に着く時刻 A・6点｜速さと条件の整理

👀 まず見るところ

「9時と9時30分になると橋が上がる」→ 橋の入り口に着く時刻を先に出す。9時〜9時10分に当たったら、9時10分まで待つ。道のりを全部たしてからわると、待つ時間をぬかしてしまう。

📚 前提知識

  • かかる時間は「道のり÷速さ」。K君は分速20m。家から橋Aまで240mなら 240÷20＝12分。
  • 橋が通れないのは 9時〜9時10分と、9時30分〜9時40分。入り口に着いたとき上がっていたら、入り口で待つ。橋の上にいたら、その場で止まる。

🔍 整理して解く

  1. 時刻を上から順に書いていく。 
    8:50 家を出る
      240÷20＝12分
9:02 橋Aの入り口  ← 橋は上がっている。9:10まで待つ
9:10 歩き出す
      (300＋540)÷20＝42分
9:52 店に着く
  2. 橋Aの入り口から店までは 300＋540＝840m。840÷20＝42分。
  3. 9時10分＋42分＝9時52分。
  4. 落としやすい所。9時2分から歩き続けたことにしない。橋の入り口で8分待っている。
答え：9時52分

6 (2) O君はどちらの橋が何分早いか A・6点｜速さと条件の整理

👀 まず見るところ

「どちらの橋をわたったほうが」→ 橋Aの場合と橋Bの場合を、時刻の表で2本ならべる。O君は分速15m。橋Aでは橋の上で9時になる。橋Bでは9時10分ちょうどに入り口に着く。

📚 前提知識

  • 橋の上で止まっても、残りの道のりは変わらない。止まった場所から店までの道のりを出して、9時10分から歩き直す。
  • 橋は10分で元にもどる。9時10分ちょうどに入り口に着いたら、待たずにわたれる。

🔍 整理して解く

  1. 橋Aの場合。入り口まで 240÷15＝16分。8時46分に橋に入る。
  2. 9時まであと14分。橋の上を 15×14＝210m 進んだ所で止まる。9時10分にまた歩き出す。
  3. 残りは (300−210)＋540＝630m。630÷15＝42分。店に着くのは9時52分。
  4. 橋Bの場合。入り口まで 600÷15＝40分。9時10分に着く。橋はちょうど元にもどった所なので、待たずにわたる。橋の上は 300÷15＝20分で、出口に着くのは9時30分ちょうど。上がりはじめる時刻と同じだが、そのときにはわたり終えているので止まらない。 
    橋A  8:30 家 →16分→ 8:46 橋に入る →14分→ 9:00 止まる
     9:10 歩き出す →42分→ 9:52 店
橋B  8:30 家 →40分→ 9:10 橋に入る（待たない）
     →20分→ 9:30 橋を出る →20分→ 9:50 店
  5. 橋を出てから店までは300m。300÷15＝20分。店に着くのは9時50分。入り口から店まで 600÷15＝40分 とまとめて出しても同じ。
  6. 9時52分−9時50分＝2分。橋Bのほうが早い。
答え：橋Bをわたったほうが2分早く着く
コツ：道のりだけなら橋Aは1080m、橋Bは1200mで、橋Aのほうが短い。橋の上で10分止まる分で、順番が入れかわる。

6 (3) O君がK君より早く着くための出発時刻 A・6点｜速さと条件の整理

👀 まず見るところ

「K君より早く店に着きたい」→ 先にK君が着く時刻（9時40分）を出す。次に、O君が止まらずに歩いた場合の出発時刻を出す。その時刻で橋Aの上で9時にならないかを確かめる。

📚 前提知識

  • 着く時刻から、かかる時間を引くと出発の時刻にもどせる。9時40分に着きたくて72分かかるなら、8時28分。
  • 橋の上で9時になると10分止まる。止まると間に合わなくなるときは、9時より前に橋をわたり終えるのが条件になる。

🔍 整理して解く

  1. K君は橋Bへ。入り口まで 600÷20＝30分。9時ちょうどに着く。橋が上がりはじめるから、9時10分まで待つ。
  2. 橋Bの入り口から店まで 600÷20＝30分。K君が着くのは9時40分。
  3. O君は橋Aへ。家から店まで 240＋300＋540＝1080m。止まらなければ 1080÷15＝72分。9時40分−72分＝8時28分。
  4. 8時28分に出た場合を確かめる。橋に入るのは8時44分。橋をわたるのに 300÷15＝20分かかる。出るのは9時4分。橋の上で9時になって、10分止まる。K君より早くは着けない。 
    8:28 家 →16分→ 8:44 橋に入る →20分→ 9:04 出るはず
                          ↑ 9:00に橋の上 → 10分止まる
  5. だから、9時より前に橋Aをわたり終える。家から橋Aの出口まで 240＋300＝540m。540÷15＝36分。
  6. 9時−36分＝8時24分。これより前に家を出る。このとき店に着くのは9時36分より前で、9時40分より早い。
答え：8時24分

4〜6 まとめ

  • 数が書かれていない仕事算は、全員で1分にぬる面積を1とおく。1分にぬった面積が、そのまま人数の割合になる。
  • 折り返しは、重なる辺と角に同じ印をつける。60度や30度が出たら、正三角形と、その半分の三角形（辺の比 1：2）をさがす。
  • 通れない時間がある速さの問題は、道のりを全部たす前に、橋に着く時刻を先に出す。時刻を上から順に書く。
