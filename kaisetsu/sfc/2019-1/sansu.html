1 (1) 360と756の最大公約数 A・6点｜最大公約数（連除法）

👀 まず見るところ

【条件文】部品は「最大公約数」に丸。360と756を横にならべて、連除法の形に直して書く → 左にならんだ数だけをかけると決まる。下の数までかけると、最小公倍数になる。

📚 前提知識

  • 連除法は、2つの数を同じ数でわり続ける書き方。たとえば12と18。2でわると6と9。3でわると2と3。左の数をかけた 2×3＝6 が最大公約数。
  • わり終わりの合図は、下の2つの数に、1以外の同じ約数がなくなったとき。

🔍 整理して解く

  1. 360と756を横にならべて、両方をわれる数でわっていく。どちらも偶数なので、2から始める。 
    2 ) 360  756
2 ) 180  378
3 )  90  189
3 )  30   63
     10   21
  2. 10と21を見る。10の約数は 1, 2, 5, 10。21の約数は 1, 3, 7, 21。同じなのは1だけ。ここで終わり。
  3. 左の数をかける。2×2×3×3＝36。
  4. たしかめ。360÷36＝10。756÷36＝21。どちらもわり切れる。落としやすいのは、30と63をもう一度3でわるのをわすれて、12で止める所。
答え：36

1 (2) 分母が3×5、5×7、7×9の分数のたし算 A・6点｜計算のくふう（ひき算に分ける）

👀 まず見るところ

【条件文】部品は分母の「3×5、5×7、7×9」。となりどうしで同じ数がつながっている → 1つずつ「ひき算の半分」に直して書くと、とちゅうが消えて 1/3 と 1/9 だけが残る。

📚 前提知識

  • 1/3−1/5 を計算すると 5/15−3/15＝2/15。これは 1/(3×5) の2倍。だから 1/(3×5) は「1/3−1/5」の半分。3と5の差が2なので、半分にする。
  • かけ算とわり算だけの式は、わる数を先に使ってよい。125×8÷25 は、125÷25＝5 を先にすると 5×8＝40。

🔍 整理して解く

  1. かっこの中の3つを、ひき算の半分に書きかえる。
    もとの分数書きかえた形
    1/(3×5)(1/3−1/5)×1/2
    1/(5×7)(1/5−1/7)×1/2
    1/(7×9)(1/7−1/9)×1/2
  2. 3つをたす。通分はしない。「−1/5」と「＋1/5」が消える。「−1/7」と「＋1/7」も消える。残るのは (1/3−1/9)×1/2。
  3. 1/3−1/9＝3/9−1/9＝2/9。半分にして 1/9。かっこの中は 1/9 になった。
  4. 式は 125×8×1/9÷25。先に 125÷25＝5。5×8＝40。40×1/9＝40/9＝4 4/9。
  5. 落としやすいのは「×1/2」をわすれる所。かっこの中が 2/9 のままになり、答えが2倍になる。
答え：4 4/9

2 (1) 1辺18cmの正方形の折り紙を折ったときのDG A・6点｜折り返しと相似（3：4：5）

👀 まず見るところ

【条件文】部品は「1辺の長さが18cm」と図の「8cm」「6cm」。折った紙は折る前と同じ長さ → AEに 18−8＝10 と図に置く。6・8・10 で 3：4：5 の直角三角形と決まり、同じ形を右へたどる。

📚 前提知識

  • 紙を折ると、折る前の形と折ったあとの形は合同（ぴったり重なる）。長さも角も同じ。正方形の角を折った所は、折ったあとも90度。
  • 3辺が 6cm・8cm・10cm の直角三角形は、辺の比が 3：4：5。2でわると 3・4・5 になる。
  • 直角三角形の直角でない2つの角は、たすと90度。一直線は180度。直角のとなりにできる角は、この2つを使って出せる。

🔍 整理して解く

  1. 点線の正方形の左上をH、右上をIと書く。折り目はAD。HはEに、IはFに重なった。HAは 18−8＝10cm。折って重なるから EAも10cm。三角形ABEは 6：8：10＝3：4：5。
  2. 角に印をつける。三角形ABEで、Aの角を○、Eの角を●とする。○＋●＝90度。Eの所は一直線で、●と直角（折る前のHの角）と角CEGをたすと180度。角CEGは 90度−● で、○と同じ。三角形ECGは、三角形ABEと同じ形になる。Gでは向かい合う角が同じ大きさ。Fは直角（折る前のIの角）。三角形DFGも同じ形になる。
  3. 三角形ECGを見る。ECは 18−6＝12cm。ECは○と直角にはさまれた辺で、比の「4」にあたる。EGは「5」にあたる。EG＝12×5/4＝15cm。
  4. EFは、折る前のHIと同じ18cm。GF＝18−15＝3cm。
  5. 三角形DFGを見る。GFは●と直角にはさまれた辺で、比の「3」にあたる。DGは「5」にあたる。DG＝3×5/3＝5cm。
  6. たしかめ。CGは 12×3/4＝9cm。DFは 3×4/3＝4cm で、折る前のDIも4cm。右の辺は 4＋5＋9＝18cm。正方形の1辺と合っている。落としやすいのは、比の3・4・5をどの辺に当てるか。「○と直角の間が4、●と直角の間が3」と図に書いてから式にする。
答え：5cm

【条件文】部品は「高さが8cm」と「水の深さが4cm」。水は下がわにあって、三角すいの形ではない → 上の空気を「高さ 8−4＝4cm の小さい三角すい」と図に置く。全体からこの小さい三角すいをひくと決まる。

4 (3) 21回おしたら全部ついていた。□に入るランプ B・6点｜条件の整理（2回で打ち消し）

👀 まず見るところ

【条件文】部品は「すべてのランプがついていた」＝最初と同じ。21回をたどる問題ではない。①〜⑤をおした回数を数えて書く → 同じランプ2回は消せるので、残りは数個になる。(1)の「②→②」を思い出せたら手を付ける。

📚 前提知識

  • 同じランプを2回おすと、両どなりが2回変わってもとどおり。おさないのと同じ。間にほかのランプをはさんでも同じ（(1)の②→②）。
  • ①〜⑤を1回ずつおすと、どのランプも両どなりから1回ずつ、合わせて2回変わる。全部もとどおり（(2)の5回目）。

🔍 整理して解く

  1. □以外の20回で、①〜⑤をそれぞれ何回おしたか数える。数えた丸数字に線を引くと、数え落としがない。
    ランプ①②③④⑤
    おした回数（合わせて20回）55523
    2回ずつ消した残り11101
  2. 残りは「①・②・③・⑤を1回ずつ」と□だけ。21回が5回に減った。
  3. □が④なら、「①〜⑤を1回ずつ」になる。これは全部もとどおり。つまり全部ついたまま。□は④。
  4. 確かめ。①・②・③・⑤を1回ずつおすと、消えているのは③と⑤。この2つを同時に変えられるのは、間にある④だけ。
答え：④
コツ：長い手順の問題は、(1)(2)が決まりを見つけるための練習になっている。(1)の「②→②」と、(2)の「5回目で全部つく」が、そのまま(3)の道具。

5 (1) エンジンを止めた船がAからBまで流れる時間 A・5点｜流水算（川の長さ＝半円の弧）

👀 まず見るところ

【条件文】部品は「半径が5.4kmの半円」と「エンジンを停止」。川のA〜Bは弧の16.2kmと図に置く。エンジン停止は「船の速さ＝流れの時速1.8km」に直して書く → 16.2÷1.8 で決まる。

📚 前提知識

  • 半円の弧の長さ＝直径×円周率÷2。ここでは 5.4×2×3÷2＝16.2km。
  • エンジンを止めた船は、川の流れと同じ速さで進む。水にうかべた葉っぱと同じ。

🔍 整理して解く

  1. 図に、川の長さと道の長さを分けて書きこむ。船が進むのは川（弧）のほう。
  2. A〜Bの川の長さ。5.4×2×3÷2＝16.2km。
  3. 船の速さは、流れと同じ時速1.8km。
  4. 16.2÷1.8＝9時間。
  5. 落としやすい所。円周率は3.14ではなく3。問題文の太字に丸をつけておく。
答え：9時間

5 (2) AとEから同時に出て3時間後に出会う船の、静水時の速さ A・5点｜流水算（出会い・速さの和）

👀 まず見るところ

【条件文】部品は「AとEから同時に」「3時間後にPで出会った」。出会いは「2そうの道のりの和＝川の全長」に直して書く → 速さの和が出る。下り＋上りで流れの1.8は消える。

📚 前提知識

  • 下りの速さ＝静水時の速さ＋流れの速さ。上りの速さ＝静水時の速さ−流れの速さ。
  • 下りと上りをたすと、＋1.8と−1.8が消える。和は静水時の速さの2つ分。たとえば静水時が時速10kmなら、11.8＋8.2＝20。

🔍 整理して解く

  1. 川をまっすぐにのばした線を描く。Aからの船は下り。Eからの船は上り。
  2. 川の全長。16.2×4＝64.8km。
  3. 2そうは3時間で、合わせて64.8km進んだ。速さの和は 64.8÷3＝時速21.6km。
  4. 和は静水時の速さの2つ分。21.6÷2＝時速10.8km。
  5. 確かめ。下りは時速12.6km、上りは時速9km。3時間で 37.8＋27＝64.8km。合っている。
  6. 落としやすい所。全長を道の 10.8×4＝43.2km にしない。船が進むのは川（弧）のほう。
答え：時速10.8km

5 (3) Qで真横に出会いを見た慶太君の、自転車の速さ B・6点｜流水算＋円（弧から角度）

👀 まず見るところ

【条件文】部品は「Qで…90度の向きに見る」。「3時間後に慶太君はQ。PQは道に垂直」に直して図に置く → 求めるのはA〜Qの道のり÷3。CからPの弧が5.4kmと出せたら手を付ける。

📚 前提知識

  • 弧の長さと中心の角は比例する。半円（180度）の弧が16.2kmなら、弧5.4kmは 1/3 で60度。
  • 2つの辺が半径で、間の角が60度の三角形は正三角形。上の頂点からまっすぐ下ろした線は、底辺を半分に分ける。

🔍 整理して解く

  1. 下りの船がPまでに進んだ長さを出す。下りの速さは 10.8＋1.8＝時速12.6km。3時間で 12.6×3＝37.8km。
  2. A〜Cの川は 16.2×2＝32.4km。CからPまでの川は 37.8−32.4＝5.4km。
  3. 5.4kmは、半円CDの弧16.2kmの 1/3。半円の中心をOとする。角COPは 180×1/3＝60度。
  4. OCもOPも半径で5.4km。三角形OPCは正三角形。QはCOの真ん中に来る。CQ＝5.4÷2＝2.7km。
  5. 慶太君は道をAからQまで走った。A〜Cが 5.4×2×2＝21.6km。21.6＋2.7＝24.3km。
  6. 24.3÷3＝時速8.1km。
答え：時速8.1km
コツ：円周率を3とする問題で「弧の長さ＝半径の長さ」になったら、中心の角は60度。正三角形が出てくる合図。

6 (1) 原料Aの、薬品全体に対する割合 A・5点｜割合（本数の比）

👀 まず見るところ

【条件文】部品は「どのパイプも時間当たりに入れられる量はすべて同じ」と「1時間」。3つとも同じ1時間だから、本数がそのまま量になる。A6本・B5本・C3本を帯の図に置く → Aは全体14のうちの6。

📚 前提知識

  • 割合＝くらべる量÷もとにする量。「全体に対する」だから、もとにする量は3つの合計。
  • パイプ1本が1時間に入れる量を1とする。Aは6、Bは5、Cは3。

🔍 整理して解く

  1. 14ますの帯を描いて、A・B・Cに分ける。
  2. 全体は 6＋5＋3＝14。
  3. Aは6。6÷14＝6/14＝3/7。
  4. 落としやすい所。6/14 のままにしない。BとCの合計8でわった 6/8 も別のもの。
答え：3/7

6 (2)① Aのパイプが4本に減ったときの入れ方（ア・イ） A・5点｜反比例（本数と時間）

👀 まず見るところ

【条件文】部品は、はじめと変わった言葉「Aを入れるパイプ4本」に丸。BとCは5本・3本のまま。Aだけ本数が 4/6 に減ったぶん、時間を6/4倍に直して書く → Aは90分、BとCは60分のまま。

📚 前提知識

  • 入れる量＝本数×時間。量が同じなら、本数が減ったぶん時間がふえる（反比例）。6本で60分の量は、4本だと 6×60÷4＝90分。
  • 1日分の薬品に必要な量は決まっている。Aは「6本で60分」、Bは「5本で60分」、Cは「3本で60分」の量。

🔍 整理して解く

  1. 原料ごとに、かかる時間を表にする。
    原料はじめ今の本数かかる時間
    A6本で60分4本60×6/4＝90分
    B5本で60分5本60分のまま
    C3本で60分3本60分のまま
  2. 時間の帯を描く。3つとも同時に始める。
  3. はじめの60分は、A・B・Cを同時に入れる。アは60。ここでBとCは入れ終わる。
  4. Aはまだ足りない。90−60＝30分、Aだけを入れる。〔A〕に○、イは30。
  5. 落としやすい所。Aの時間を 60×4/6＝40分 にしない。本数が減ると、時間はふえる。
答え：ア…60・A・イ…30

6 (2)② A5本・B4本に変えたときの入れ方（ウ・エ・オ） A・5点｜反比例（止める順番）

👀 まず見るところ

【条件文】部品は、はじめと変わった「Aを入れるパイプ5本」「Bを入れるパイプ4本」に丸。「〔 〕を止めて」にも丸。①と同じ表に直して書く → A72分・B75分・C60分。短い順にC、Aと止める。

📚 前提知識

  • 本数が 5/6 になると、時間は 6/5倍。本数が 4/5 になると、時間は 5/4倍。分子と分母を入れかえる。
  • 3つを同時に始めると、かかる時間が短い原料から先に入れ終わる。入れ終わった原料から止める。

🔍 整理して解く

  1. 原料ごとに、かかる時間を表にする。
    原料はじめ今の本数かかる時間
    A6本で60分5本60×6/5＝72分
    B5本で60分4本60×5/4＝75分
    C3本で60分3本60分のまま
  2. 時間の帯を描いて、短い順に区切る（図の帯の長さは、見やすいように少し変えてある）。
  3. はじめの60分は3つ同時。ウは60。ここでCが入れ終わる。〔C〕を止める。
  4. AとBを、あと 72−60＝12分。エは12。ここでAが入れ終わる。〔A〕を止める。
  5. 残りはBだけ。75−72＝3分。オは3。
  6. 落としやすい所。①は「〔 〕だけを入れる」、②は「〔 〕を止める」。○をつける原料の意味が逆になる。
答え：ウ…60・C・エ…12・A・オ…3

6 (3) パイプ23本を自由に分けたときの最短の時間 C・5点｜反比例（本数の分け方をさがす）

👀 まず見るところ

【条件文】本番では後回し。部品は「23本」と「最短」。終わる時間は、いちばん長くかかる原料で決まる → 本数を 6：5：3 に近く分けて、いちばん長い時間を小さくする。

📚 前提知識

  • 23本を 6：5：3 に分けると、Aは9本と10本の間、Bは8本くらい、Cは4本と5本の間。ぴったりには分けられないから、近い本数で試す。

🔍 整理して解く

  1. Aを9本、Bを8本にして試す。Cは 23−9−8＝6本。Aが 60×6/9＝40分、Bが37.5分、Cが30分。Aがいちばん長い。
  2. 長いAを1本ふやし、短いCを1本へらす。
    原料本数かかる時間
    A10本60×6/10＝36分
    B8本60×5/8＝37.5分
    C5本60×3/5＝36分
  3. いちばん長いのはBの37.5分。Bを1本ふやすと、AかCが1本減って37.5分より長くなる。これが最短。
答え：37.5分

4〜6 まとめ
