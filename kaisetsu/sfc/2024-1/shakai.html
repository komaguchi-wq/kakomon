2 問2 1990〜2020年の石炭 B・2点｜正誤選択・統計

👀 まず見るところ

4つのうち「増えた」と言っているのは4だけ。1〜3は思いこみを突く文なので、先に切りにいく。中国＝石炭の最多消費国、残っている炭鉱＝北海道の2つが出れば手を付ける価値がある。

📚 前提知識

  • 中国は世界最大の石炭産出国であり、輸入量も多い世界一の消費国。2020年の世界の石炭消費量のうち中国が約50%、インドは約10%ほど。
  • 世界の石炭産出量は1990年の約46.45億tから2020年は約75.75億tへ、1.5倍以上に増えている。
  • 日本の石炭輸入量は1990年の約1.08億tから2020年は約1.74億tへ増えた。

🔍 こう読み解く

  1. 1…最多消費国は今も中国で、インドはその5分の1ほど → ×。
  2. 2…世界の産出量は増えている → ×。「一貫して」という言い切りも危ない。

2 問4 石勝線の駅名の由来 A・1点｜写真の読み取り

👀 まず見るところ

駅名標に並ぶ3つの駅名。「トマム」「しむかっぷ」「しんとく」は、どれも日本語としては意味の取りにくいひびきをしている。北海道でこの形ならアイヌ語を疑う。

📚 前提知識

  • 北海道の地名の多くは先住民族アイヌの言葉に由来し、あとから漢字を当てている。
  • 写真の「トマム」は占冠村のトマム地区のことで、アイヌ語で「湿地」を意味する。占冠（しむかっぷ）・新得（しんとく）も同じくアイヌ語に由来する。

🔍 こう読み解く

  1. 設問は「3駅に共通する由来」。1駅だけの事情では答えにならない、と先に押さえる。
  2. 沿線のリゾート施設（3）や語呂合わせ（4）が3駅そろって当てはまるとは考えにくい → ×。開拓者の出身地名（1）なら本州の地名がそのまま残るはずで、3つとも当てはまらない → ×。
  3. 残った2（先住民族が呼んだ地名）。トマム＝湿地、という意味まで言えると確実になる。
答え：2

3 問1 鎌倉仏教の語句補充 B・2点｜空らん補充

👀 まず見るところ

📚 前提知識

  • 念仏＝「南無阿弥陀仏」。阿弥陀仏の力にすがれば救われる、という浄土の教え（他力本願）。
  • 題目＝「南無妙法蓮華経」。妙法蓮華経（法華経）を信じれば人も国も救われる、という日蓮の教え。

  • 選択肢の建長寺・円覚寺はどちらも神奈川県鎌倉市にある臨済宗の寺。盧舎那仏は東大寺の大仏のこと。

🔍 こう読み解く

  3. C「南無（う）という題目」→ 「南無」に続くのは妙法蓮華経（3）。
答え：あ 6・い 4・う 3

3 問2 A〜Cの「私」は誰か A・2点｜人物の判別

👀 まず見るところ

本文にキーワードが1つずつ置かれている。A＝悪人こそが救われる、B＝時宗、C＝題目と鎌倉幕府への批判。宗派と人物を組で覚えていれば、ここで3つとも決まる。

📚 前提知識

  • 親鸞…浄土宗を開いた法然に学び、念仏を唱えれば阿弥陀仏の力によって救われると説いて浄土真宗を開いた。「罪を自覚した悪人こそ救われる」＝悪人正機説。
  • 一遍…時宗を開いた僧。諸国を遊行して踊念仏を広めた。総本山の遊行寺ができるのは一遍の死後である。
  • 日蓮…題目を唱えることを説いて法華（日蓮）宗を開いた。法華経を信じなければ国難が来るとして他宗を攻撃し、鎌倉幕府から迫害を受けた。
  • まぎらわしい選択肢：道元＝曹洞宗、法然＝浄土宗、栄西＝臨済宗の開祖。空也と最澄は平安時代の僧で、空也は庶民に布教して「市聖」と呼ばれ、最澄は天台宗を開いた。

🔍 こう読み解く

  1. A…悪人正機を説いたのは親鸞（4）。師の法然（5）と取りちがえない。
  2. B…「時宗と呼ばれるようになる自らの教え」と本文に書いてある → 一遍（6）。
  3. C…題目を唱え、幕府を激しく批判した → 日蓮（2）。
  4. 落としやすいのは、鎌倉仏教のつもりで空也（3）や最澄（8）を選んでしまう形。この2人は平安時代の僧である。

  1. 設問は「適当でないもの」。答えは1つなので、言葉のずれがはっきり見える文から探す。
  2. 2は、内閣総理大臣の決まり方（国会が指名・天皇が任命）と混ざった形になっている。国務大臣を任命するのは内閣総理大臣で、天皇が行うのは任命ではなく認証 → これが答え。

7 問2 法律案と予算案の議決 A・2点｜正誤選択（適当でないもの）

👀 まず見るところ

7 問4 庁はどの府省に属するか A・2点｜組み合わせ（完答）
