1 Ⅰ(2) ストローと台風の気圧 A・6点｜会話文の穴うめ（語句の選択）

👀 まず見るところ

【まざり型→素材文】部品はB先生の「空気の量が多いほど大きくなる」「容器内の空気が減って気圧が小さくなる」に丸。空らんごとに「そこの空気は減ったか」を見る → 減った所は下がり、減っていない所は変わらない。

📚 前提知識

  • 気圧＝空気が物を押す強さ。同じ体積の中の空気が減ると小さくなる（会話文の決まり）。
  • あたためられた空気はふくらみ、同じ体積で比べると周りより軽くなるので上昇する。

🔍 こう読み解く

  1. ア・イ：吸うとストロー内の空気が減る → ア「下がり」。ストローの外側の空気は吸っていないので減らない → イ「変わらない」。外の気圧のほうが大きくなり、ジュースがストローの中へ押し上げられる。
  2. ウ・エ：台風が生まれるのは熱帯の海。海面の水温が「高く」なると、海面上の空気があたためられて軽くなり「上昇」する。水蒸気を多くふくむので、上空で雲ができる。
  3. オ・カ：この段落の初めに「これに似た現象」とある。台風の中心は、吸われたストローの中と同じで気圧が低い → オ「低気圧」。ストロー内のジュースと同じで、海面は「上昇」する。
  4. 落としやすいのはイ。「外の気圧が上がるからジュースが上がる」のではない。外は変わらず、中だけが下がる。
答え：ア…下がり・イ…変わらない・ウ…高く・エ…上昇・オ…低気圧・カ…上昇

1 Ⅰ(3) 台風の中心で海面が上昇する現象 A・2点｜知識問題

高潮（たかしお）。台風の中心は気圧が低いので、ストローで吸われたジュースと同じように海面が高くなる。これに満潮や、強い風による海水の吹き寄せが重なると、海岸の潮位が異常に高くなる。地震で起こる「津波」とは別の現象。
答え：高潮

1 Ⅰ(4) 図3でストローを吸うとビン内の気圧はどうなるか B・3点｜記述（結果と理由）

👀 まず見るところ

【まざり型→素材文】部品はAさんの「すき間がないように」と「ストロー内の液面が少しだけ上昇」。図3の「空気」の横に「出入りできない」と書く（直して書く）→ ビンの液面が下がった分、空気の体積が増えると決まる。会話文の決まりで書けるので手を付ける。

📚 前提知識

  • 気圧は「1cm³あたりに含まれる空気の量」で決まる（会話文）。空気の量が同じまま体積が増えると、1cm³あたりの空気は減り、気圧は下がる。

✍️ 答案の組み立て

  1. 結果：ビン内の気圧は「下がる」。
  2. 理由：吸うとジュースが少しストローに上がり、ビンの中の液面が下がる。すき間がないので空気は入ってこない。閉じこめられた空気の体積が増えるので、気圧が下がる。
  3. 答案には「空気の体積が増える」と「気圧が下がる」の2つを入れる。
  4. ビン内の気圧が下がると、ストロー内の気圧との差がなくなる。だから、そのあとはいくら吸ってもジュースが上がらない。
模範解答：ビン内に閉じこめられた空気の体積が増えることで気圧が下がる。

1 Ⅰ(5) 紙パックがつぶれる理由 B・3点｜記述（理由）

👀 まず見るところ

【まざり型→素材文】部品は「手を触れずにストローを吸うだけで」と、ただし書きの「すき間がない」。紙パックの外側に内向きの矢印を置く → 押しているのは手ではなく外の空気と決まる。(4)の続きなので手を付ける。

📚 前提知識

  • 空気はいつも物を押している。中と外の気圧が同じなら、押す力がつり合って形は変わらない。
  • ガラスのビンはかたいので、気圧の差があっても形が変わらない。紙パックは差にたえられずへこむ。

✍️ 答案の組み立て

  1. (4)と同じで、吸うと紙パックの中の気圧が下がる。外の気圧は変わらない → 内と外に気圧の差ができる。
  2. 外の空気が紙パックを内向きに押す力のほうが大きくなる。紙パックはその力にたえられる強さがないので、へこむ。
  3. 答案に入れる言葉は「内と外の気圧差」「外の空気が押す」「紙パックはたえられない」の3つ。聞かれているのは理由なので、文末は「〜から。」
  4. 紙パックがへこむと、ジュースが出た分だけ中がせまくなり、中の空気は広がらずにすむ。ビンとちがって中の気圧が下がり続けないので、ジュースを飲める。
模範解答：紙パックの内と外に気圧差が生じたとき、外の空気が押す力に紙パックはたえられずにへこむから。

1 Ⅱ(1) ふたを固定せずに真空にすると起きる現象 B・3点｜記述（現象と理由）

👀 まず見るところ

【まざり型→条件文】部品は設問の「ふたを固定せずに」と、会話文の「真空では気圧もなくなる」。図3のふたの上に「気圧0」、下に「二酸化炭素」と書きこむ（図に置く）→ ふたは下から上へ動くと決まる。書きこめば答えが出るので手を付ける。

📚 前提知識

  • ふたは、上と下から押す力が同じときだけ止まっている。差があると、気圧の大きい側から小さい側へ動く。
  • 図1のシリンダーの上の面には「外部につながる穴」がある。ふたより上は容器Aの中とつながっていて、同じ真空になる。

✍️ 答案の組み立て

  1. 場面の確認：下線部①のとき、シリンダーの中身は400℃の気体の二酸化炭素。
  2. 理由：ふたの下には二酸化炭素の気圧がある。ふたの上（容器A内）は真空で気圧が0。押し返すものがない。
  3. 現象：ふたが上に動き、二酸化炭素がシリンダー全体に広がる。
  4. 「理由とともに」なので、「外は真空で気圧が0」→「ふたが上に動く」の順に、理由と現象の両方を書く。
模範解答：シリンダー内には二酸化炭素があり、外（容器A内）は真空で気圧が0なので、ふたが上に動き、シリンダー全体に二酸化炭素が広がる。

1 Ⅱ(2) 二酸化炭素を確かめる方法 A・2点｜知識問題

石灰水を使う。気体を石灰水に通す（または気体を入れた容器に石灰水を加えてよく振る）と、二酸化炭素なら石灰水が白くにごる。「薬品名がわかるように方法と結果を」とあるので、「石灰水」と「白くにごる」の2つを書く。
答え：気体を石灰水に通すと、白くにごる。

1 Ⅱ(3) ドライアイスの密度は400℃の二酸化炭素の何倍か A・2点｜密度の計算（整数）

👀 まず見るところ

【まざり型→条件文】部品は「体積は1cm³」「2Lになりました」と、ただし書きの「密度とは一定体積あたりの重さ」。2Lは2000cm³に直して書く。重さはどちらも1.56gで同じ → 密度の倍率は体積の倍率だけで決まる。

📚 前提知識

  • 密度＝重さ÷体積。同じ重さなら、体積が小さいほど密度は大きい。
  • 1L＝1000mL＝1000cm³。

🔍 こう読み解く

  1. 余白に「密度＝重さ÷体積」と書く。
  2. ドライアイスは 1.56g で 1cm³。400℃の二酸化炭素は 1.56g で 2L＝2000cm³。
  3. 重さが同じで、体積は気体のほうが2000倍。密度は逆にドライアイスのほうが 2000÷1＝2000倍。
  4. 落としやすい所：2Lを「2」のまま使うと2倍になってしまう。単位をcm³にそろえてから比べる。
答え：2000倍

1 Ⅱ(4) 400℃のろうの密度は400℃の二酸化炭素の何倍か B・2点｜密度の計算（小数第1位）

👀 まず見るところ

【まざり型→条件文】部品は「気体の体積は150mL」「重さは0.8g」と、答え方の「小数第1位まで」に丸。150mLは150cm³に直して書く。今度は重さも体積もちがう → 密度を2つ作ってから割る。式の形は(3)と同じなので手を付ける。

📚 前提知識

  • 密度＝重さ÷体積。「AはBの何倍」は A÷B。
  • 問題の最初の注意：小数第1位まで答えるときは、小数第2位を四捨五入する。

🔍 こう読み解く

  1. 400℃のろうの密度：0.8÷150（g/cm³）。400℃の二酸化炭素の密度：1.56÷2000（g/cm³）。
  2. ここで割り算をすると小数が続く。式のまま「ろう÷二酸化炭素」を作る。
    (0.8÷150)÷(1.56÷2000)＝(0.8×2000)÷(150×1.56)＝1600÷234
  3. 1600÷234＝6.83… → 小数第2位を四捨五入して 6.8倍。
  4. 落としやすい所：割る向き。聞かれているのは「ろうは二酸化炭素の何倍か」なので、ろうを先に書く。
答え：6.8倍

1 Ⅱ(6) 状態変化と粒子についての正しい文 B・2点｜正しいものをすべて選ぶ

👀 まず見るところ

【まざり型→素材文】部品は聞かれ方の「すべて」と、本文の「粒子自体は大きさも重さも変化しない」に丸。この1文だけでオとカが消える。残り4つは1つずつ○×をつける。本文の言葉で切れる文が多いので手を付ける。

📚 前提知識

  • 気体の二酸化炭素は無色で目に見えない。空気中に置いたドライアイスの白いけむりは、冷やされた空気中の水蒸気が水滴になったもの。
  • 雲は、水蒸気が冷やされてできた小さな水滴や氷の粒の集まり。
  • 立体は、長さを2倍にすると体積は 2×2×2＝8倍 になる。

🔍 こう読み解く

  1. オ・カ：本文に「粒子自体は大きさも重さも変化しない」とある。温めても軽くも大きくもならない → どちらも×。
  2. イ：ろうは固体で1cm³、気体で150mL。下線部②のとおり液体はその間。粒子の数は同じなので、体積がいちばん小さい固体が、1cm³あたりの粒子の数はいちばん多い → ○。

  4. ア：シリンダーの中は二酸化炭素だけで、水蒸気がない。気体の二酸化炭素は見えないので、白い気体は見られない → ×。
  5. エ：粒子間の距離が2倍になると、たて・横・高さがどれも2倍。体積は8倍 → ×。
答え：イ・ウ

1 Ⅱ(7) 水の状態と体積の順・水の粒子の特別な点 C・3点｜順番＋記述

👀 まず見るところ

【まざり型→素材文】本番では後回しでよい小問。部品は「下線部②とは異なります」と「図4の粒子モデルをもとに」に丸 → 氷が水にうくことから順番を先に書き、説明は粒子の「距離」という言葉で書く。

📚 前提知識

  • 水は液体のときに体積がいちばん小さい（密度が最大）。こおると体積がふえるので、氷は水にうく。

🔍 こう読み解く

  1. 順番：氷は水にうく＝同じ重さなら固体のほうが体積が大きい。気体はさらに大きい → 小さい方から 液体、固体、気体。

1 まとめ この大問で繰り返し出た入口

  • 密度の倍率は、単位をcm³にそろえて「重さ÷体積」を2つ作る。割り算は最後に1回だけにする。
  • 記述と正誤の根拠は本文にある。「真空では気圧もなくなる」「粒子自体は大きさも重さも変化しない」に丸をつけてから設問に進む。

2 (1) 計量器の表示から手の力・遠心力を出す B・6点｜会話文のあなうめ（数値と向き）

👀 まず見るところ

【まざり型→条件文】部品は先生の言葉「計量皿の重さと計量皿にはたらく遠心力の合計」。皿の重さを、上向きなら＋100、逆さなら「[−100g]」に直して書く → 表示との差が力の大きさ、表示が増えていれば押し付ける向きと決まる。6点あり(5)(6)の土台なので、時間をかける価値がある。

📚 前提知識

  • 計量器の数値は、測定部を押す力。押し付ける向きはプラス、引き離す向きはマイナスで出る（注1と図6-a）。
  • 会話の例で確かめる: 図5-cは100→300で200g増えた＝200gで押し付け。図5-dは100→30で70g減った＝70gで引き離し。図6-bは−100→−40で60g増えた＝60gで押し付け。「何もしないときの表示から、いくつ増えたか減ったか」が加えた力。

🔍 こう読み解く

  1. 3つの場面を表にする。「何もしないときの表示」は、計量器が上向きなら100、逆さなら−100。
    場面計量器の向き何もしないとき実際の表示増えた分＝加わった力
    ①② 図6-c逆さ−10040140（手が押し付けて）
    ③④ 最も低い位置上向き（図5）100300200（遠心力が押し付ける）
    ⑤⑥ 最も高い位置逆さ（図6）−100100200（遠心力が押し付ける）
  2. ①②: −100から40までは 100＋40＝140 増えている → 手は140gで押し付けて。

👀 まず見るところ

【まざり型→素材文】部品は本文の「血圧が高くなるほどろ過される量が増えます」と、文の最後の「うすい尿ができる」に丸 → ①②③は前から順に決まり、④⑤は「うすい尿」から逆にたどって決まる。
