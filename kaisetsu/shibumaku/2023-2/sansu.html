1 (2) 4回の操作で1になる整数の個数 A・6点｜1からもどす樹形図

👀 まず見るところ

【条件文】部品は「4回の操作で1になる」と、求めるもの「何個」に丸。「1から4回もどす」に直して書く → 3の倍数は3本、それ以外は1本に枝分かれする樹形図になる。整数を1つずつ試すと終わりが見えない。

📚 前提知識

  • もどすときは操作を逆にする。「3で割る」の逆は「3をかける」。「2を加える」の逆は「2をひく」。「1を加える」の逆は「1をひく」。
  • 2や1をたしたあとの数は、3の倍数になっている。だから「ひく」でもどせるのは、今の数が3の倍数のときだけ。たとえば9の前は 9−2＝7、9−1＝8、9×3＝27 の3つ。8は3の倍数ではない。8の前は 8×3＝24 だけ。

🔍 整理して解く

  1. 左はしにゴールの1を書く。1は3の倍数ではない。1の前は 1×3＝3 だけ。
  2. 3は3の倍数。前の数は 3−1＝2 と 3×3＝9。3−2＝1 はゴールの数だから入れない。
  3. 同じようにもどす。3の倍数（色つき）からは「2をひく・1をひく・3をかける」の3本。それ以外の数からは「3をかける」の1本。
  4. 4回の列を数える。4, 5, 18, 21, 24, 25, 26, 81 の8個。
  5. たしかめ。5は 5→6→2→3→1 で4回。合っている。
  6. 落としやすい所は、3の倍数でない数から「ひく」の枝を出すこと。枝を出す前に、3の倍数かどうかを見る。
答え：8個

1 (3)いちばん大きい はじめて50個以上になる回数と、いちばん大きい数 B・5点｜回数と個数の表

👀 まず見るところ

【条件文】部品は「はじめて50個以上」。(2)の樹形図を「回数と個数の表」に直して書く → 個数は 1, 2, 4, 8 と2倍ずつ → 7回で64個。2倍ずつと見えたら手を付ける。いちばん大きい数は、3をかけ続けた数。

📚 前提知識

  • どの数からも「3をかける」で前の数が1つ出る。出た数は3の倍数。だから、ある回数の「3の倍数」の個数は、1つ前の回数の全部の個数と同じ。たとえば3回の数は4個。4回の3の倍数も 18, 21, 24, 81 の4個。
  • 3の倍数からは「2をひく」「1をひく」でも1つずつ出る。「2をひく」で出るのは3で割って1あまる数。「1をひく」で出るのは3で割って2あまる数。

🔍 整理して解く

  1. (2)の樹形図の数を、回数ごとに3種類に分けて数える。4回までを表に書く。
  2. 5回から先は樹形図を書かずにうめる。「3で割りきれる数」は、左どなりの合計と同じ。あまり1とあまり2は、左どなりの「3で割りきれる数」と同じ。
    1になるまでの回数1234567
    3で割りきれる数（個）112481632
    3で割ると1あまる数（個）00124816
    3で割ると2あまる数（個）01124816
    合計（個）1248163264
  3. 6回は32個で、まだ50個に足りない。はじめて50個以上になるのは7回で、64個。
  4. いちばん大きい数をさがす。もどし方のうち、数が大きくなるのは「3をかける」だけ。4回のいちばん大きい数は81。ここから毎回3をかける。81×3＝243。243×3＝729。729×3＝2187。
  5. たしかめ。2187は3を7回かけた数。3で7回割ると1になる。
答え：2187

  5. 距離が出たら、表の最短距離と見くらべる。B駅の300mは計算では出る。でも、最短距離の400mより近い。ここには作れない。見落とすと、B駅と答えてしまう。
答え：C駅から100m

4 (1)①② 三角形APQの3辺の和が最小のときの BP：PC と DQ：QE B・6点＋6点｜折り返して一直線・平行線と相似

👀 まず見るところ

【条件文】部品は「3辺の長さの和が最も小さく」→「折り返して一直線」に直して書く。正六角形をBCとDEで折り返し、うつったAどうしを直線で結ぶ → BC・DEと交わる点がP・Qに決まる。折り返しの図がかけたら手を付ける。

📚 前提知識

  • 折り返しても、長さは変わらない。BCで折り返すと、APはA′Pと同じ長さになる。折れ線は、まっすぐな1本の線になったときがいちばん短い。
  • 正六角形の1つの角は120°。向かい合う頂点を結ぶ線（BEやAD）は、辺の2倍の長さ。この線は、角を60°と60°に分ける。
  • 平行な2本の線の間に、ちょうちょの形の三角形が2つできる。2つは同じ形（相似）。たとえば上の辺が1、下の辺が3なら、ななめの線も 1：3 に分かれる。

🔍 整理して解く

  1. 正六角形を、BCで左に折り返す。DEで右下に折り返す。うつったAを、A′とA″と書く。AP＝A′P、AQ＝A″Q。 図1: 3辺の和「AP＋PQ＋QA」は、「A′P＋PQ＋QA″」と同じ長さ。
  2. A′とA″を直線で結ぶ。このときが、いちばん短い。直線がBCと交わる点がP、DEと交わる点がQ。
  3. 長さの分かる線をさがす。A′・B・Eは一直線にならぶ。角A′BCが120°、角CBEが60°で、合わせて180°になるから。A″・D・Cも一直線（60°＋120°）。六角形の1辺を1とする。A′B＝1、BE＝2、A″D＝2、DC＝1。BEとCDは平行。だからこの2本の直線も平行。 図2: 青い2本の直線が平行。色をつけた2つの三角形が、①で使うちょうちょの形。
  4. ①を出す。三角形A′BPと三角形A″CPは相似。A′B：A″C＝1：(2＋1)＝1：3。だから BP：PC＝1：3。
  5. ②を出す。こんどは、Qをはさむちょうちょの形を見る。 図3: 三角形A′EQと三角形A″DQは相似。A′E：A″D＝(1＋2)：2＝3：2。だから EQ：QD＝3：2。
  6. 聞かれているのは DQ：QE。EQ：QD＝3：2 を逆から読んで、DQ：QE＝2：3。3：2 のまま書かない。
答え：① 1：3　② 2：3
コツ：「2つの辺に1回ずつ寄って、もとの点にもどる」ときは、2つの辺でそれぞれ折り返す。折り返した図では、六角形の辺や対角線が一直線にならぶ所をさがすと、相似の辺の長さが出る。

4 (2) 三角形APQは正六角形の何倍 B・6点｜辺をのばして正三角形・面積の比

👀 まず見るところ

【条件文】部品は「正六角形ABCDEFの面積の何倍」と、(1)で出した 1：3 と 2：3。三角形APQは「六角形−まわりの3つ」に直して書く → 辺をのばして正三角形を作ると、まわりの3つが出る。(1)の比が2つとも出ていれば進む。

📚 前提知識

  • 正六角形の辺を1つおきにのばすと、大きい正三角形になる。外にできる小さい正三角形は、六角形と同じ辺の長さ。正六角形は、この小さい正三角形の6つ分。
  • 高さが同じ三角形は、底辺の比が面積の比になる。底辺が1/4なら、面積も1/4。
  • 1つの角が同じ2つの三角形は、その角をはさむ2辺の倍をかけると、面積の倍が出る。たとえば2辺が2倍と3倍なら、面積は 2×3＝6倍。

🔍 整理して解く

  1. 辺BC、DE、FAを両側にのばす。大きい正三角形GHIができる。小さい正三角形GBA、HDC、IFEの面積を、どれも1とする。正六角形は6。 図4: 四角の数字はBCを4つに分けた目もり。丸の数字はDEを5つに分けた目もり。まわりの3つをア・イ・ウとする。
  2. (1)の比を書きこむ。BP：PC＝1：3。BCは 1＋3＝4。GBとCHも4。DQ：QE＝2：3。DEは 2＋3＝5。HDとEIも5。
  3. まわりの3つを、小さい正三角形とくらべて出す。
    部分くらべ方面積
    ア 三角形ABP三角形GBAと高さが同じ。底辺は BP：GB＝1：41×1/4＝1/4
    イ 四角形PCDQ三角形HPQは、三角形HDCの (4＋3)/4×(5＋2)/5＝49/20倍。ここからHDCの1をひく49/20−1＝29/20
    ウ 四角形AQEF三角形IAQは、三角形IFEの (1＋1)/1×(5＋3)/5＝16/5倍。ここからIFEの1をひく16/5−1＝11/5
  4. 六角形から、まわりの3つをひく。6−(1/4＋29/20＋11/5)＝6−78/20＝21/10。これが三角形APQ。
  5. 六角形の6でわる。21/10÷6＝7/20倍。
  6. 確かめ。4つをたすと 5/20＋29/20＋44/20＋42/20＝120/20＝6。六角形の6と同じになる。
答え：7/20倍

5 (1) 直方体を3点P・Q・Rで切る。点Fを含む方の体積 A・6点｜直方体の切断・大きい三角すいからひく

👀 まず見るところ

【条件文】部品は「BP＝BQ＝ER＝2cm」と「角すいの体積は，(底面積)×(高さ)÷3」。2cmは図に書きこむ。ただし書きは、三角すいを使う合図 → 切り口の線をのばして大きい三角すいを作り、かどの小さい三角すい3つをひく。

📚 前提知識

  • 同じ面の上にある2点は、直線で結べる。PとQは、どちらも上の面にある。
  • 向かい合う面は平行。そこにできる切り口の線も、平行になる。上の面のPQと、底の面のRを通る線は平行。
  • 同じ形で大きさがちがう立体（相似）は、辺が2倍なら体積は 2×2×2＝8倍。辺が6倍なら 6×6×6＝216倍。

🔍 整理して解く

  1. 上の面で、PとQを結ぶ。BPとBQは、どちらも2cm。三角形BPQは直角二等辺三角形になる。PQは45°のななめの線。
  2. 底の面を真上から見た図をかく。Rを通って、PQと平行な線を引く。HGと交わる点をSとする。HRは 5−2＝3cm。HSも同じ3cm。SGは 4−3＝1cm。この線を両側にのばす。FEをのばした線と交わる点をI、FGをのばした線と交わる点をJとする。EI＝2cm、GJ＝1cm。 図1: 45°の線で、直角二等辺三角形が3つできる（IER、RHS、SGJ）。どれも、直角をはさむ2辺が同じ長さ。
  3. Iは、前の面をのばした平面の上にもある。だからIとPを結べる。AEと交わる点をTとする。三角形APTと三角形EITは合同（AP＝EI＝2cm）。だから AT＝TE＝4cm。
  4. Jは、右の面をのばした平面の上にもある。JとQを結ぶ。CGと交わる点をUとする。三角形QCUと三角形JGUは 3：1 の相似（QC＝3cm、GJ＝1cm）。だから CU＝6cm、UG＝2cm。
  5. IP、JQ、FBを上にのばすと、1点Kで交わる。IからTまで、横に2cm進んで4cm上がる。IからFまでは、横に6cm進む。2cmの3倍。上がる高さも3倍で、12cm。KF＝12cm、KB＝4cm。切り口は六角形PTRSUQ。 図2: 点Fを含む方は、三角すいK-FJIから、かどの三角すいを3つひいた形。
  6. 4つの三角すいは、どれも同じ形（相似）。辺の比を表にする。
    三角すい直角に集まる3辺（cm）辺の比体積の比
    K-FJI（全体）6・6・1266×6×6＝216
    K-BQP（上のかど）2・2・422×2×2＝8
    T-ERI（左のかど）2・2・428
    U-GJS（右おくのかど）1・1・211
  7. 点Fを含む方は、216−(8＋8＋1)＝199 にあたる。いちばん小さいU-GJSの体積は、1×1÷2×2÷3＝1/3cm³。だから 1/3×199＝199/3＝66 1/3cm³。
  8. 確かめ。全体は 6×6÷2×12÷3＝72cm³。72−8/3−8/3−1/3＝66 1/3cm³ で同じ。ひく三角すいは3つ。Gのかどの小さい三角すいを忘れると、66 2/3cm³ になってしまう。
答え：66 1/3cm³

5 (2) 切断面（六角形PTRSUQ）の面積 B・6点｜三角すいの展開図は正方形・面積の比

👀 まず見るところ

【条件文】部品は「切断面の面積」。六角形のままでは出せない →「三角形KIJ−かどの三角形3つ」に直して書く。三角形KIJは、(1)の三角すいを開いた正方形から出る。(1)で 6：2：2：1 が出ていれば進む。

📚 前提知識

  • 同じ形の図形（相似）は、辺が2倍なら面積は 2×2＝4倍。辺の比が 6：2：2：1 なら、面積の比は 36：4：4：1。
  • 直角が3つ集まる三角すいで、辺が 6cm・6cm・12cm のもの。これを開くと、1辺12cmの正方形になる。正方形の紙を、となり合う2辺の真ん中で折って作る三角すいと同じ形。

🔍 整理して解く

  1. 切り口の六角形は、三角形KIJの中にある。三角形KIJから、かどの三角形を3つひいた形。かどは、三角形KPQ、三角形ITR、三角形JSU。
  2. かどの三角形は、(1)の小さい三角すいの面。三角形KIJと同じ形で、辺の比は 6：2：2：1。面積の比は 36：4：4：1。
  3. 切り口は 36−(4＋4＋1)＝27 にあたる。三角形KIJの 27/36＝3/4倍。
  4. 三角形KIJの面積を出す。三角すいK-FJIを開く。1辺が 8＋4＝12cm の正方形になる。 図3: 正方形の3つのかどがF。三角形KIJの外側に、直角三角形が3つある。
  5. 正方形は 12×12＝144cm²。外側の3つは 6×6÷2＋12×6÷2×2＝90cm²。三角形KIJは 144−90＝54cm²。
  6. 54×3/4＝40.5cm²。
答え：40.5cm²
コツ：ななめの面の面積は、底辺と高さでは出しにくい。「同じ形の大きい三角形の何倍か」と「その大きい三角形を開いた図」の2つに分けると、たし算・ひき算だけで出る。

5 (3) 切断面を下にして置いたときの点Dの高さ B・6点｜体積と底面積から高さ

👀 まず見るところ

【条件文】部品は「切断面を下にして」「点Dの平面からの高さ」→「切り口を底面、Dを頂点にした六角すいの高さ」に直して書く。高さ＝体積×3÷底面積。底面積は(2)の40.5cm²。(1)(2)が合っているときだけ進む。

📚 前提知識

  • 角すいの体積は「底面積×高さ÷3」。もどして考えると、高さ＝体積×3÷底面積。たとえば体積10cm³、底面積6cm²なら、高さは 10×3÷6＝5cm。
  • 平面の上に置いた立体の頂点の高さは、頂点から平面まで、まっすぐ下ろした長さ。その平面を底面にした角すいの高さと同じ。

🔍 整理して解く

  1. 点Dを含む方の立体を見る。Dがのっていない面は4つ。三角形APT、三角形CQU、三角形HRS、切り口の六角形。Dとそれぞれの面を結ぶと、4つの角すいに分かれる。 図4: 色をつけた3つの三角形とDで、かどの三角すいが3つ。残りが、切り口を底面にした六角すい。
  2. 点Dを含む方の体積を出す。直方体は 5×4×8＝160cm³。(1)をひく。160−199/3＝281/3cm³。
  3. かどの三角すい3つを出す。
    三角すい使う長さ（cm）体積（cm³）
    T-APD（Aのかど）AD＝5、AP＝2、AT＝45×2÷2×4÷3＝20/3
    U-CDQ（Cのかど）CD＝4、CQ＝3、CU＝64×3÷2×6÷3＝12
    D-HRS（Hのかど）HR＝3、HS＝3、DH＝83×3÷2×8÷3＝12
  4. 六角すいの体積は、281/3−(20/3＋12＋12)＝63cm³。
  5. 高さを□cmとする。40.5×□÷3＝63。□＝63×3÷40.5＝14/3＝4 2/3cm。
  6. 確かめ。40.5×14/3÷3＝63。合っている。
答え：4 2/3cm

3〜5 まとめ

  • ふえる・へるの決まりが2つあるときは、基準を1つ決めて、ちがいを表に書く（大問3）。
  • 「長さの和が最も小さく」は、折り返して一直線に直す（大問4）。
  • 直方体の切断は、切り口の線をのばして大きい三角すいを作る。体積も切り口の面積も、同じ辺の比から出る（大問5）。
