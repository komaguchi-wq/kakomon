1 (1) 6番目の正方形の中の「3」の個数 A・7点｜規則性（わくの個数）

👀 まず見るところ

【資料問題】図の正体を1行で書く＝「外のわくが全部1。内へ1つ入るごとに1ふえる」。部品は「6番目」と「数字の3」に丸 → 3は外から3つ目のわくにならぶ、と決まる。

📚 前提知識

  • わく1周の個数は「外の正方形−内の正方形」で出す。3番目の図の2は、3×3−1×1＝8個。数えても8個。
  • 1辺のますの数は、1番目が1、2番目が3、3番目が5。1つ進むと2ますふえる。

🔍 整理して解く

  1. 6番目の1辺を出す。1、3、5、7、9、11とふえる。6番目は1辺11ます。
  2. 外から順にわくを書く。1のわくは1辺11。2のわくは1辺9。3のわくは1辺7。
  3. 3のわくの内がわは、1辺5の正方形。ここには4、5、6が入る。
  4. 7×7−5×5＝49−25＝24。
  5. 確かめ。まん中の6から外へ数える。5が8個、4が16個、3が24個。1周ごとに8個ふえる。
  6. 落としやすい所は、7×7＝49で止めること。内がわの25を引くところまでが1セット。
答え：24個

1 (2) 偶数が337個ある正方形は何番目か A・7点｜規則性（1つおきのわく）

👀 まず見るところ

【条件文】部品は「偶数が337個」と、例の「3番目の正方形の中には偶数が8個」。337は「奇数」に直して書く → わくの個数は8の倍数だから、まん中の1ますが偶数＝偶数番目と決まる。

📚 前提知識

  • わく1周の個数は、まん中から1周目が8個、2周目が16個、3周目が24個。8ずつふえる（3×3−1×1＝8、5×5−3×3＝16、7×7−5×5＝24）。
  • わくの個数はどれも偶数。合計が奇数になるのは、まん中の1ますを数えるときだけ。

  4. 2周目は16個。4周目は32個。16ずつふえる。合計が336になるまで表に書く。336になったら終わり。
    まん中から何周目24681012

3 (1) はじめて管Bから水を入れ始める時間 A・7点｜濃度（てんびんの図）

👀 まず見るところ

【条件文】部品は「水が300g」と「濃度が12%の食塩水を毎分100g」。水は「0%の食塩水」に直して書く → 0%と12%をまぜて8%にするてんびんの図で、入れた重さが決まる。

📚 前提知識

  • てんびんの図では、濃さの差の比と重さの比が逆になる。差が 2：1 なら、重さは 1：2。
  • 管Aは毎分100g。入れた重さを100でわると、かかった分が出る。

🔍 整理して解く

  1. てんびんの図をかく。左のはしが0%の水300g。右のはしが12%の食塩水□g。支点が8%。
  2. 差を出す。8−0＝8。12−8＝4。差の比は 8：4＝2：1。
  3. 重さの比は逆の 1：2。水300gが1にあたる。□は 300×2＝600g。
  4. 600÷100＝6。

5 (1) 円の中で4回まわるともどる正三角形の作図 B・8点｜図形の移動・作図

👀 まず見るところ

【条件文】部品は「4回回転させたとき」「最初の位置にもどりました」。「円周を4等分」に直して図に置く → 正三角形の1辺は、円にぴったり入る正方形の1辺と決まる。垂直二等分線がかければ手を付ける。

📚 前提知識

  • 回転の中心は、円周上の頂点。次に円周にくる頂点は、中心から1辺分はなれた所に着く。1辺の長さは変わらない。だから円周上の点は、同じはばでならぶ。
  • 円にぴったり入る正方形は、直角に交わる2本の直径でかける。直角は、垂直二等分線の作図で作る。
  • 正三角形は、1辺の両はしにコンパスの針をさしてかく。半径はその1辺と同じ長さ。2つの弧が交わる点が3つ目の頂点。

🔍 整理して解く

  1. かく前に、円周上の頂点の動きを考える。1回まわるごとに、1辺分だけ先の点へ進む。4回でもとにもどる。だから4つの点は円周を4等分する。4つの点を結ぶと正方形になる。 図1: 正三角形の1辺は、円にぴったり入る正方形の1辺と同じ長さ。
  2. Oを通る直線をひく。円と交わる点をP、Qとする。PQは直径。
  3. P、Qにコンパスの針をさす。同じ半径で、PQの上側と下側に弧をかく。弧が交わる2つの点を直線で結ぶ。これがPQの垂直二等分線。円と交わる点をR、Sとする。
  4. P、S、Q、Rは円周を4等分する点。PSが正方形の1辺になる。
  5. P、Sにコンパスの針をさす。半径をPSの長さにして、円の内側に弧をかく。交わる点をTとする。PとS、SとT、TとPを直線で結ぶ。正三角形PSTができる。作図に使った線は消さない。 図2: 青い線が作図に使う線。赤が答えの正三角形PST。
答え：解説の図を参照のこと。（正三角形PST。直径PQ・垂直二等分線RS・Tを決める弧を残す）
コツ：「何回かでもどる」は、円周を同じはばで分ける合図。4回なら4等分で、正方形の1辺が出発点になる。

5 (2) 正三角形が通らなかった部分の面積 A・7点｜円と正方形の面積

👀 まず見るところ

【条件文】部品は「一辺の長さが10cm」と「通らなかった部分」に丸。10cmは(1)の正方形の1辺として図に置く → 正三角形は正方形の中だけを通る。求めるのは「円−正方形」と決まる。

📚 前提知識

  • 円の面積は、半径×半径×3.14。半径そのものが出なくても、「半径×半径」が分かれば計算できる。
  • 円にぴったり入る正方形を対角線で切ると、直角二等辺三角形が4つできる。直角をはさむ2辺は、どちらも円の半径。1つの面積は、半径×半径÷2。

🔍 整理して解く

  1. 正三角形が通る所を図にかく。正三角形は、正方形の4つの辺に順につく。回転の中心は、いつも正方形の角。1つの辺についた形から、となりの辺についた形まで回る。2つの辺の間だけで動く。正方形の外には出ない。4つの角で順に回ると、正方形の中はすべて通る。 図1: 上は1回目〜4回目の動き。下は通った所をまとめた図。通らなかった部分は円−正方形。
  2. 正方形の面積を出す。10×10＝100cm²。
  3. 正方形を対角線で4つに切る。三角形1つは 100÷4＝25cm²。これが「半径×半径÷2」と同じ。だから半径×半径＝25×2＝50。 図2: 色をつけた三角形は、半径を2辺とする直角二等辺三角形。
  4. 円の面積は 50×3.14＝157cm²。
  5. 通らなかった部分は 157−100＝57cm²。
  6. 落としやすい所は、半径を出そうとして手が止まること。半径は整数にならない。「半径×半径＝50」のまま3.14をかける。
答え：57cm²

6 (1) 1辺8cmの立方体・赤い面をもつ小さな立方体の個数 B・7点｜色ぬり立方体・場合分け

👀 まず見るところ

【条件文】部品は「3つの面」と「考えられる個数をすべて」に丸。「3つの面」を「1つの角に集まる3面／向かい合う2面＋1面」に直して書く → ぬり方が2通りで、答えも2つと決まる。

📚 前提知識

  • 立方体の3つの面のえらび方は2種類だけ。ア＝1つの角に集まる3面（左・下・後ろ）。イ＝向かい合う2面と、その間の1面（上・下・左）。
  • 赤い面をもつ個数は「全部−白いまま」で出せる。面ごとに数えるときは、2つの面にまたがる列を2回数えない。

🔍 整理して解く

  1. ぬり方ア（左・下・後ろ）。白いままの部分は、右・上・手前によせた1辺7cmの立方体。全部は 8×8×8＝512個。白いままは 7×7×7＝343個。赤ありは 512−343＝169個。 図1: ぬり方ア。
  2. ぬり方イ（左・上・下）。左の面は 8×8＝64個。上の面は、左の1列をのぞいて 8×7＝56個。下の面も56個。赤ありは 64＋56＋56＝176個。 図2: ぬり方イ。
  3. 答えは2つとも書く。推定配点では(1)は完答。2つそろって7点になる。
答え：169個・176個
コツ：「3つの面をぬる」と見たら、角に集まる3面か、向かい合う面が入るかで分ける。

6 (2) 赤ありが408個のとき、すべての面が白い立方体の個数 B・7点｜偶数・奇数で場合を消す

👀 まず見るところ

【条件文】部品は「408個」と「すべての面が白い」に丸。408は「偶数」に直して書く → ぬり方アの赤ありは、169のようにいつも奇数。ぬり方はイと決まる。あとは408になる1辺をさがす。

📚 前提知識

  • ぬり方アの赤ありは「1辺を3回かけた数」どうしのひき算。1辺8なら 512−343＝169。1辺9なら 729−512＝217。となり合う整数は、片方が偶数で片方が奇数。3回かけても偶数は偶数、奇数は奇数のまま。偶数と奇数の差は奇数になる。
  • ぬり方イの赤ありは、(1)と同じ数え方。1辺8なら 8×8＋8×7×2。「1辺×1辺」の3つ分より少しだけ少ない。

🔍 整理して解く

  1. 408は偶数。ぬり方アは奇数にしかならない。ぬり方はイ。
  2. 1辺の見当をつける。408÷3＝136。「1辺×1辺」が136に近い数をさがす。12×12＝144 が近い。
  3. 表で確かめる。408をこえたら終わり。
