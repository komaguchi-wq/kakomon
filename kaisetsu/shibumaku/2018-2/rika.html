1 (1) 球状で生活する不都合 A・3点｜記述（1行・本文の裏返し）

👀 まず見るところ

【素材文】部品は設問の「最低限必要な光の強さ」と本文の「中心まで緑色の糸状体がぎっしり」に丸。光がいるのに、中心の糸状体は外側の糸状体に囲まれている → 「内部に光がとどきにくい」の1行が決まる。

📚 前提知識

  • 光合成には光が必要。マリモの糸状体は水中で光合成をする藻（説明ボックスの1つ目）。
  • 「個々の糸状体で生活する場合と比べて」＝1本ずつなら全部が光を受けられる。集まると光の当たらない内側ができる、が比べる点。

✍️ 答案の組み立て

  1. どこの糸状体か：球の内部（中心部）の糸状体。
  2. 何が起きるか：外側の糸状体にさえぎられて光がとどきにくい。
  3. 「不都合なこと」を聞かれているので「〜にくい。」で止める。解答らんは1行なので理由は書かない。
模範解答：球の内部の糸状体に光がとどきにくい。
コツ：声教の解説は「球の中心部や下部」の両方を挙げている。内部・中心・下側のどれかが書けていればよい。

1 (2) ゆれたり回転したりする利点 B・3点｜記述（1行）

👀 まず見るところ

【素材文】部品は下線部の「その場で回転する」と直前の「放射状に伸びて表面に達する」に丸。回れば光を受ける側の糸状体が入れかわる → (1)の反対を書けば決まる。(1)が書けたら手を付ける。

📚 前提知識

  • 湖底にとどく光は湖面の側（上）から。動かない球なら、横や下側の糸状体には光が当たりにくい。
  • 放射状マリモは中心から表面まで糸状体が伸びている（図3）。表面のどこにも糸状体の先があるので、光の当たる面が変われば光を受ける糸状体も変わる。

✍️ 答案の組み立て

  1. 主語：多くの糸状体（球の表面全体の糸状体）。
  2. 何が起きるか：順番に光の当たる側に来るので、多くの糸状体に光が当たる。
  3. 「都合が良いのはどのようなことですか」→「〜こと。」で終える。
模範解答：多くの糸状体に光が当たること。
コツ：声教の解説は「たとえ一方向からしか光がとどいていない場合でも」と条件を添えている。余白があれば「光が一方向からでも」を頭に付けると伝わりやすい。

👀 まず見るところ

【まざり型→素材文】穴うめの小問。部品は「湖底が深くなるほど」と「湖面に風が吹くと」に丸。深いほど光は弱、流れのもとは湖面なので深いほど遅 → 表の左（深い側）にア＝弱・ウ＝遅が決まる。

📚 前提知識

  • 光は水の粒に吸収されたり散らされたりするので、深くなるほど弱くなる（声教の解説）。
  • 風で湖面がゆれて水の流れが起きる。深い所ほどその影響を受けにくい。

🔍 こう読み解く

  1. ア：深いほど光は弱。イは反対側（浅い）なので強。
  2. ウ：深い湖底ほど流れは遅。エは速。
  3. 落としやすい所：表の左右を確かめてから書く。1行目「深い ←→ 浅い」と同じ向きで、左が深い側。
答え：ア…弱・イ…強／ウ…遅・エ…速

1 (3)オカキ 流れの速さと粒の大きさ A・2点｜表の穴うめ（レキ・砂・泥）

👀 まず見るところ

【まざり型→資料問題】表の小問。部品は表の1行目「深い ←→ 浅い」と文の「水の流れの速さに応じて」。ウ・エを表に書きこむと左＝遅い・右＝速い → 速い側ほど大きい粒で、オ泥・カ砂・キレキと決まる。

📚 前提知識

  • 粒は大きい順にレキ＞砂＞泥。大きな粒ほど水の流れで運ばれにくく、先に沈む。
  • 流れの速い所には大きなレキが運ばれてきてたまり、遅い所には砂、さらに遅い所には泥がたまる（流水のはたらきのたい積）。

🔍 こう読み解く

  1. 右端（浅い・流れが速い）＝いちばん大きいレキ＝キ。
  2. 左端（深い・流れが遅い）＝いちばん小さい泥＝オ。まん中の砂＝カ。
  3. 落としやすい所：「深い所＝大きな石」と思いこまない。粒の大きさは深さでなく流れの速さで決まる。
答え：オ…泥・カ…砂・キ…レキ

1 (4)①② 着生型・浮遊型がすむ場所 A・2点＋2点｜語句の選択（本文で決まる）

👀 まず見るところ

3 (1) 最も温度が高い部分とその理由 A・4点｜炎の構造・空らん記述（10字程度）

👀 まず見るところ

【素材文】部品は説明文の「空気を十分に混ぜることで、青色の高温の炎」と「外炎は、下の方は青色」に丸。空気とよくふれる所ほど高温 → 外炎。理由は丸の言葉を使って「空気と十分ふれ合って」と決まる。

📚 前提知識

  • ロウソクの炎は内側から炎心・内炎・外炎。炎心は気体のロウがまだ燃えていない暗い部分、内炎は最も明るい黄色、外炎は空気にふれて完全に燃えているので最も温度が高い。
  • 明るさと温度は別。内炎が明るいのは燃え切っていない部分が光っているためとされる。

🔍 こう読み解く

  1. いちばん外側＝空気にふれる部分。ガスバーナーの文と同じ理屈で、外炎が最高温。
  2. 理由の空らんは「気体のロウが（　）燃えているから」。ガスバーナーの文を言いかえて「空気と十分ふれ合って」（10字）。
  3. 落としやすい所: 「最も明るい＝最も熱い」と思って内炎と書くこと。説明文は明るさしか書いておらず、温度は空気の量で決まる。
答え：外炎／説明…空気と十分ふれ合って

3 (2)A・B 試験管の口を下に傾ける理由 A・4点｜実験操作の理由・空らん記述

👀 まず見るところ

【素材文】部品は実験の結果「茶色の液体がたまりました」と空らんの「試験管が（B）」に丸。液体が出る実験 → 口が上向きなら液体は熱い加熱部分へ流れる。試験管に起きる事故から逆算するとA・Bが決まる。

📚 前提知識

  • 蒸し焼き（乾留）では、出てきた気体の一部が試験管の口付近で冷やされて液体になる。
  • 熱くなったガラスが液体で急に冷やされると割れるおそれがある。口を下に傾けるのは、液体を加熱部分に戻さないため。

🔍 こう読み解く

  1. 白い煙（気体）が口の近くで冷えて茶色の液体になる。これが「発生した液体」。
  2. 口を下に傾けないと、その液体が加熱部分に逆流する → A。
  3. 熱いガラスに液体がつくと急に冷えてわれる → B。空らんの前が「試験管が（　）」なので「われることがある」と結ぶ。
  4. 落としやすい所: Aに「液体が出ない」「煙が出ない」など別の不都合を書くこと。Bが「試験管が〜」なので、試験管に起きる事故から逆算する。
答え：A 発生した液体が加熱部分に逆流し　B われることがある

3 (3) ガラス管の口の青白い炎の正体 B・2点｜2つ選ぶ・完答

👀 まず見るところ

【素材文】部品は説明文の「気体が燃えると炎になります」と設問の「2つ選び」に丸。炎が見えた＝燃えたのは気体 → 固体・液体の選択肢が切れる。この1文に気づけば手を付ける価値がある。

3 (4) 木炭が燃えても炎が出ない理由 A・3点｜説明文の応用・空らん記述

👀 まず見るところ

【素材文】部品は設問の「炎のでき方を読み取った上で」→ 説明文の「気体が燃えると炎」に丸。蒸し焼きで燃える気体は煙として出ていった → 木炭には気体が残っていない、と丸の言葉で書けば決まる。

📚 前提知識

  • 蒸し焼きで木片から気体成分・液体成分が出ていき、あとに残る黒い固体が木炭（主成分は炭素）。
  • 炭素は固体のまま酸素と結びつくので、炎は出ず赤く光るだけ。木片が最初に黄色い炎を出すのは、気体成分が燃えているから。

🔍 こう読み解く

  1. 炎ができるのは気体が燃えるとき。
  2. 蒸し焼きで燃える気体成分は煙となって出ていき、(3)でその気体が燃えたのを確かめている。
  3. だから木炭には「燃える気体成分が残っていない」→ 炎が出ない。空らんの後が「から。」なので、「残っていない」で止める。
  4. 落としやすい所: 「酸素が足りないから」と書くこと。フラスコは酸素で満たしてあるので、理由にならない。
答え：燃える気体成分が残っていない

3 (5) ゴム風船がふくらんでいた理由 A・3点｜記述（20字程度）

3 (6)あ・い BTB溶液の色（残った気体と白い固体） A・4点｜指示薬の色・漢字

👀 まず見るところ

📚 前提知識

🔍 こう読み解く
