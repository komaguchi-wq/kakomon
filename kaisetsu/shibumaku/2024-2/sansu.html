1 (1) 1から10マス右上の数 A・7点｜数表（平方数）

👀 まず見るところ

右上に並ぶ数は 9、25。9＝3×3、25＝5×5 → 奇数を2回かけた数が並ぶ。10マス目が「何番目の奇数か」だけ数える。

📚 前提知識

  • うずまきは、1を真ん中にした正方形を1周ずつ大きくしていく。3×3の正方形が書き終わる所が9。5×5が書き終わる所が25。だから右上の角は平方数（同じ数を2回かけた数）になる。
  • □番目の奇数は 2×□−1。たとえば3番目の奇数は 2×3−1＝5。

🔍 整理して解く

  1. 右上の数を表に書く。 
    右上へ  1マス  2マス  3マス … 10マス
数      3×3   5×5   7×7  …  ？
奇数    3     5     7    …  ？
  2. 3から数えて10番目の奇数を出す。1から数えると11番目。2×11−1＝21。
  3. 21×21＝441。
  4. 落としやすい所は「10番目の奇数＝19」とする数えちがい。1マス目が3で始まることを表で確かめる。
答え：441

1 (2) 441をふくむ枠のマスの個数 A・7点｜数表（等差数列）

👀 まず見るところ

例の「2個空けた枠は26個」が手がかり → 内側の枠から個数を順に書いて、増え方を見る。10、18、26 と8個ずつ増える。あとは441が何番目の枠かを決める。

📚 前提知識

  • 枠は1まわり外へ出ると、たてが2マス、横が2マス長くなる。上下左右の4辺で、合わせて8個増える。
  • 同じ数ずつ増える列は「はじめの数＋増える数×回数」で出せる。

🔍 整理して解く

  1. 枠ごとの個数を書く。 
    1 2 そのもの     … 2個
1まわり外（3〜12）  … 10個
2まわり外（13〜30） … 18個
3まわり外（31〜56） … 26個   ←8個ずつ増える
  2. 9は1まわり外の枠にある。25は2まわり外の枠にある。だから、10マス右上の441は10まわり外の枠にある。
  3. 2＋8×10＝82。
  4. 落としやすい所は、例の「2個空けて26個」を2まわり目と数えること。2個空けた枠は3まわり外になる。
答え：82個

1 (3) 2から20マス右下の数 A・7点｜数表（平方数の利用）

👀 まず見るところ

右下の 12、30 を (1) の 9、25 とくらべる → 12＝9＋3、30＝25＋5。右上の平方数に、同じ奇数をたした数になっている。

🔍 整理して解く

  4. そこに41をたす。1681＋41＝1722。

2 (1)① L字型の図形の面積 B・7点｜点の移動（速さの比と面積）

👀 まず見るところ

「E、F、Pが一直線」→ PはCから2cm上にいる。このときの図を自分でかき、PとQが進んだ長さを□と△で書いて 1：2 にする。手を付けるのは、この図がすぐかけたとき。

📚 前提知識

  • 同時に出発して同じ時間動くと、進んだ長さの比は速さの比と同じになる。Pは毎秒1cm、Qは毎秒2cm。だから進んだ長さは 1：2。
  • 台形の面積は（上底＋下底）×高さ÷2。高さが同じ2つの台形は、「上底＋下底」が同じなら面積も同じ。

🔍 整理して解く

  1. E、F、Pが一直線のときの図をかく。BPを□cm、Fの真下からQまでを△cmとする。 
    B─A             AB＝2cm
│ア│            BP＝AF＝□cm
P─F─────E      ←P、F、Eが横に一直線
│イ＼  ウ  │     PC＝ED＝2cm
C─┴──Q──D      C〜Fの真下＝2cm、Fの真下〜Q＝△cm
※アは長方形ABPF、イは四角形PFQC、ウは四角形FEDQ
  2. 進んだ長さを書く。Pは 2＋□。Qは □＋2＋2＋△。
  3. 比は 1：2。Pの長さを2倍するとQと同じ。（2＋□）×2＝4＋□＋△。だから □と△は同じ長さ。
  4. アとイの面積をくらべる。どちらも高さ2cmの台形と見る。アの「上底＋下底」は □＋□。イは 2＋（2＋□）。これが同じだから □＝4。
  5. アは 4×2＝8cm²。ア、イ、ウは同じ面積。8×3＝24。
  6. あとで使う長さも出しておく。BC＝6cm。イとウは同じ形の台形だから、FE＝2＋4＝6cm。CD＝8cm。
答え：24cm²
コツ：「PがCに着くのと同時にQはEに着く」は、長さが出たあとのたしかめに使える。Pは 2＋6＝8cm で8秒。Qは 6＋8＋2＝16cm で8秒。合っている。

2 (1)② イの面積の変化のグラフ B・7点｜点の移動（グラフをかく）

👀 まず見るところ

グラフは点が角に着く時刻で折れる → 0、2、3、7、8秒後のイの面積だけ出して、直線で結ぶ。①で長さが全部決まっていれば手を付ける。

📚 前提知識

  • 点が同じ辺の上を動いている間、面積は同じ調子で変わる。だからグラフは直線になる。向きが変わる時刻だけ調べれば足りる。
  • 角に着く時刻。PはBに2秒後、Cに8秒後。QはCに3秒後、Dに7秒後、Eに8秒後。

🔍 整理して解く

  1. はじめ（0秒後）のイは三角形ABF。2×4÷2＝4cm²。
  2. それぞれの時刻の図をかいて、イの面積を出す。 
    2秒後  PはB、QはBから4cm下   4×2÷2＝4
3秒後  PはBから1cm下、QはC   (6−1)×2÷2＝5
7秒後  PはCから1cm上、QはD   (6−5)×2÷2＋8×2÷2＝9
8秒後  PはC、QはE            (6＋8)×2÷2＝14
  3. 点をとって結ぶ。(0,4)→(2,4)→(3,5)→(7,9)→(8,14)。
  4. たしかめ。0〜2秒は横にまっすぐ。2〜7秒は1秒に1cm²ずつ増える1本の直線で、3秒後の点もこの上にある。7〜8秒は急に上がる。
答え：解説の図Ⅲを参照のこと。
コツ：図Ⅲは、(0,4)・(2,4)・(7,9)・(8,14) を順に結んだ折れ線。0〜2秒で面積が変わらないのは、三角形FPBが減る分と三角形FBQが増える分が同じだから。

2 (2) イとウとエの面積が等しくなるRの速さと時刻 B・7点｜点の移動（グラフの利用）

👀 まず見るところ

アの面積も調べると、2秒後から7秒後はアとイが同じ → イ＝ウ＝エ なら4つとも 24÷4＝6cm²。イが6になる時刻を②のグラフから読む。

📚 前提知識

  • ア、イ、ウ、エを合わせると、いつもL字型全体の24cm²。
  • 三角形FERは、底辺をER、高さをFE＝6cmと見る。

🔍 整理して解く

  1. アの面積を出す。0秒後は0。2秒後は三角形ABFで 2×4÷2＝4。8秒後は台形で (4＋6)×2÷2＝10。
  2. イのグラフとくらべる。 
    秒後   0   2   7   8
ア     0   4   9   10
イ     4   4   9   14    ←2〜7秒はアとイが同じ
  3. 2〜7秒の間で考える。ア＝イ、イ＝ウ＝エ。だから4つとも同じ。1つ分は 24÷4＝6cm²。
  4. イが6になる時刻を読む。2秒後に4で、1秒に1ずつ増える。6になるのは4秒後。これが②。
  5. 4秒後にエも6。エは三角形FER。ER×6÷2＝6。ER＝2cm。RはちょうどDにいる。
  6. Rは4秒で2cm進んだ。2÷4＝0.5。これが①。
  7. たしかめ。4秒後のQはCから2cm右。RはD。まだ重なっていないので、3点は動いている。
答え：① 0.5・② 4

3 (1) 8枚のカードの置き方 A・7点｜場合の数（積の法則）

👀 まず見るところ

真一さんは自分の4枚をA〜Dに、智子さんは自分の4枚をア〜エに置く → 1人分の並べ方を出して、2人分をかける。8枚をまぜて並べるのではない。

  4. 落としやすい所は、24＋24 とたしてしまうこと。「真一さんの1通りごとに智子さんが24通り」と声に出して確かめる。

3 (2) 真一さんが1度も勝たない置き方 B・7点｜場合の数（条件から決まる）

👀 まず見るところ

真一さんの4は、相手が1、2、3だと勝ってしまう → 4の相手は4に決まる。同じ考えを3、2、1の順に使う。短く解けるので手を付ける。

📚 前提知識

  • 「1度も勝たない」は、4回とも負けか引き分けということ。いちばん強いカードから相手を決めると、1通りずつにしぼれる。

🔍 整理して解く

  1. 真一さんの4の相手を決める。勝たないためには、相手は4だけ。
  2. 真一さんの3の相手を決める。智子さんの残りは1、2、3。勝たないためには、相手は3だけ。

    真一  4  3  2  1
智子  4  3  2  1   ←4回とも引き分け
  4. 真一さんの置き方を1つ決めると、智子さんの置き方は1通りに決まる。
  5. 真一さんの置き方は24通り。24×1＝24。

4 (1) 折り目BEと直線CFの交点GからEまでの長さ A・8点｜折り返し・相似

👀 まず見るところ

📚 前提知識

  • 紙を折ると、折り目をはさんで左右が同じ形になる。重なる2点（CとF）を結んだ線は、折り目と直角に交わる。
  • 直角三角形の直角の角から、向かいの辺に垂直な線を引く。分かれた2つの三角形は、どちらももとの三角形と同じ形（相似）になる。
  • 三角形BCEの辺は、CEが3cm、BCが4cm、BEが5cm。3：4：5の直角三角形。

🔍 整理して解く

  1. 図のGに直角の印を書く。四角形BCEFは、BEをじくにして左右が同じ形。だからBEとCFは直角に交わる。
  2. 三角形BCEと三角形CGEをくらべる。どちらも直角が1つある。角Eは2つの三角形で共通。だから2つは同じ形。 
    三角形BCE  短い辺CE：長い辺BC：ななめBE ＝ 3：4：5
三角形CGE  短い辺EG：長い辺CG：ななめCE ＝ 3：4：5
  3. 三角形CGEのななめの辺はCEで3cm。CE：EG＝5：3 になる。
  4. EG＝3×3/5＝1.8（cm）。
  5. 落としやすい所。小さい三角形の「5」にあたる辺は、BEではなくCE。対応する辺を図に書いてから式にする。
答え：1.8cm

4 (2) ABとAFの長さの比 A・8点｜相似・消去算

👀 まず見るところ

折った後は BF＝4cm、FE＝3cm、角BFEは直角。辺ADの上のFに直角がのっている → 左上の三角形ABFと右上の三角形DFEは同じ形（相似）。長さが出ないので、○と□でおく。

📚 前提知識

  • 一直線の上に直角が立つと、残りの2つの角はたして90度。左右にできる2つの直角三角形は、同じ形になる。
  • 相似の比は、対応するななめの辺でくらべる。BF：FE＝4：3。
  • ○と□の2種類が入った式が2つあるときは、片方をそろえてたす（消去算）。みかんとりんごの代金の問題と同じやり方。

🔍 整理して解く

  1. 図にBF＝4cm、FE＝3cm、角BFEの直角を書きこむ。角AFBと角DFEは、たして90度。だから三角形ABFと三角形DFEは同じ形で、比は4：3。
  2. 対応する辺を○と□でおく。大きい三角形が4、小さい三角形が3。 
    三角形ABF（4）  AB＝④   AF＝□4
三角形DFE（3）  DF＝③   DE＝□3      ※□4は「□の4つ分」
  3. 長方形のたてと横で式を2つ作る。たてはAB＝DE＋EC。横はAF＋FD＝4cm。 
    ア  ④−□3＝3（cm）
イ  ③＋□4＝4（cm）
  4. □の数を12（□12）にそろえる。アを4倍、イを3倍して、2つの式をたす。 
    ア×4  ⑯−□12＝12
イ×3  ⑨＋□12＝12
たすと  ㉕＝24  →  ①＝24/25（cm）
  5. アにもどす。□3＝24/25×4−3＝21/25（cm）。□1＝21/25÷3＝7/25（cm）。
  6. AB：AF＝④：□4＝①：□1＝24/25：7/25＝24：7。
答え：24：7
コツ：○と□は別の大きさなので、④：□4を1：1にしない。①と□1の長さを両方出してから比にする。

5 (1) 立方体を3つの平面で切った立体(ア)の面の数 B・7点｜立体の切断・構成

👀 まず見るところ

切る平面が3枚ある → 1枚ずつ順に切って、Eのある側だけ残す。3枚とも立方体の真ん中の点を通る。1枚目の後の三角柱が描けたら(3)まで進む。描けないときは後回し。

📚 前提知識

  • 向かい合う2本の辺を通る平面で切ると、立方体は同じ形の三角柱2つに分かれる。
  • 立方体の対角線（AGやBH）は、どれも立方体の真ん中の点で交わる。この点をPとする。Pの高さは2÷2＝1（cm）。

🔍 整理して解く

  1. 1枚目。A、B、G、Hを通る平面で切る。Eのある側は三角柱AEH−BFG。
  2. 2枚目。B、F、H、Dを通る平面で切る。残るのは四角すいH−ABFE。
  3. 3枚目。A、F、G、Dを通る平面で切る。この平面は対角線AGをふくむので、Pを通る。PはBHの上の点。四角すいからBのある側が切り落とされる。
  4. 残った立体の頂点は E、A、F、H、P の5つ。面を書き出す。 
    立方体の面にのる面   EAF  EFH  EHA
切り口の面（Pが頂点） PAF  PFH  PHA
  5. 合わせて 3＋3＝6（個）。
答え：6個
コツ：Eに集まる3つの正方形の面に、切り口の線が1本ずつ入る。AF、FH、HAの3本で、どれも正方形の対角線。この3本を見取図にかくと形がつかめる。

5 (2) 立体(ア)の面の図形の種類 B・7点｜合同な面を見分ける

👀 まず見るところ

(1)で書き出した6個の面を、Eが頂点の3個とPが頂点の3個に分けて見る → 同じグループの面は、辺の長さが3本とも同じ。(1)ができていれば、時間をかけずに取れる。

📚 前提知識

  • 3つの辺の長さがそれぞれ同じ三角形は、ぴったり重なる（合同）。合同な図形はまとめて1種類と数える。

🔍 整理して解く

  1. 三角形EAF、EFH、EHAを見る。どれも正方形の面を対角線で半分にした形。2cmの辺が2本ある直角二等辺三角形で、3個とも合同。
  2. 三角形PAF、PFH、PHAを見る。PA、PF、PHは、どれも立方体の対角線の半分で同じ長さ。AF、FH、HAは、どれも正方形の対角線で同じ長さ。だから3個とも合同な二等辺三角形。
  3. Eのグループには直角がある。Pのグループとは別の形。合わせて2種類。
答え：2種類

5 (3) 立体(ア)の体積 B・7点｜角すいの引き算

👀 まず見るところ

立体(ア)はそのままでは体積の式に当てはまらない → 大きい角すいから小さい角すいを引く。Aを通る2枚の平面で切ると、四角すいA−EFGHが残る。(1)の形が分かっていれば取りにいく。

📚 前提知識

  • 角すいの体積は、底面積×高さ÷3。問題文に書いてある。
  • Pは立方体の真ん中の点。底の面EFGHからの高さは 2÷2＝1cm。

🔍 整理して解く

  1. 切る順番を変えても、残る立体は同じ。先に、Aを通る2枚（A、B、G、Hの平面と、A、F、G、Dの平面）で切る。残るのは四角すいA−EFGH。
  2. 四角すいA−EFGHの体積を出す。底面は1辺2cmの正方形、高さはAEの2cm。 
    2×2×2÷3＝8/3（cm³）
  3. 最後に、B、F、H、Dを通る平面で切る。底の面の対角線FHから真上に切るので、Gのある側が落ちる。落ちるのは三角すいP−FGH。
  4. 三角すいP−FGHの体積を出す。底面は三角形FGH、高さは1cm。 
    2×2÷2×1÷3＝2/3（cm³）
  5. 引く。8/3−2/3＝2（cm³）。
答え：2cm³
コツ：へこんだ立体は、分けてたすより「大きい角すい−小さい角すい」のほうが式が少ない。

4〜5 まとめ この2題で出た入口

  • 「折った」と見たら、同じ長さと直角を図に書きこむ。重なる2点を結ぶ線は、折り目と直角に交わる。
  • 長さが出ない相似は、○と□でおく。長方形のたてと横で式を2つ作り、片方をそろえてたす。
  • 平面が何枚もある切断は、1枚ずつ切る。立方体の真ん中の点を通るかどうかを先に見る。
