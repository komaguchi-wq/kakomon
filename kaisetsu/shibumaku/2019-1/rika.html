2 (3)① 図3の気導の結果 B・2点｜グラフ読み取り・3つ選ぶ

👀 まず見るところ

【資料問題】部品は図3の正体「やっと聞こえる音の大きさ・dB・下に行くほど聞こえにくい」と、基準の「20dB以内…正常」。図の20dBに横線を引く → 気導の○（右）と×（左）が線の上か下かだけで決まる。

📚 前提知識（あれば答え合わせに使う）

  • 知識がなくても決まる。本文の決まりは「デシベルの値が大きくなるほど，やっと聞こえる音の大きさが大きい」＝値が大きいほど聞こえにくい。

🔍 こう読み解く

  1. 記号を確かめる。気導は 右耳＝○（実線）、左耳＝×（破線）。
  2. 右耳の○は、どの高さでもほぼ10dBあたり。20dBより小さい音で聞こえ始めるので、1000Hzで20dBの音は聞こえる → ア。
  3. 左耳の×は、どの高さでも60dBから85dBの範囲。20dBの音ではまだ聞こえない → エ。全部の高さで20dBをこえているので「どの高さの音でも，左耳が聞こえにくく，正常と言えない」→ カ。
  4. 3つ選ぶ問題なので、オ・キ・クが図と合わないことも確かめて終える（右耳は全部の高さで正常）。

2 (3)② 図3の骨導の結果 B・2点｜グラフ読み取り・3つ選ぶ

👀 まず見るところ

【資料問題】①と変わった言葉は「骨導」。部品は記号の説明「右耳の骨導は ⊏ 」「左耳の骨導は ⊐ 」と、図の中の「20dBを示す」。⊏ と ⊐ だけに丸をつけ、20dBの線とくらべる → ×の破線は見ない。

📚 前提知識（あれば答え合わせに使う）

🔍 こう読み解く

  1. 右耳の ⊏ は○とほぼ同じ高さにあり、5つとも20dBの線より上（値が小さい側）→ 1000Hzで20dBの音は聞こえる → ア。

2 (4) あくびや水を飲むと聞こえ方がもどる理由 A・3点｜記述（20字程度）

👀 まず見るところ

【素材文】空らんの後ろ「結果，外耳道と鼓室の気圧が等しくなり」が合図。その前に入るのは鼓室に空気が通る話 → 直前の段落の「耳管が開くと，空気が鼓室まで通じます」に丸をつけ、その言葉で書く。

📚 前提知識

  • 耳管は中耳（鼓室）と、鼻のおくとのどをつなぐ空間とを結ぶ細い管。本文のとおり「普段は閉じて」いる。
  • 鼓膜の外側（外耳道）と内側（鼓室）で気圧がちがうと、鼓膜が内か外に引っ張られて振動しにくくなる。

✍️ 答案の組み立て

  1. 要素A「耳管が開く」。口を大きくあけたり水を飲みこんだりすると、閉じていた耳管が開く。
  2. 要素B「鼓室が外気とつながる」。耳管を通って鼓室に外の空気が通じるので、鼓室の気圧が外の気圧と同じになる。
  3. A→Bの順につなぎ、空らんの後ろの「結果，外耳道と鼓室の気圧が等しくなり」に続くか読んで確かめる。
  4. 落としやすい所: 「気圧が等しくなる」は空らんの後ろにもう書いてあるので、それだけを書いても理由にならない。「耳管」の語を入れる。
模範解答：耳管が開き，鼓室が外気とつながる

📚 前提知識

🔍 こう読み解く
