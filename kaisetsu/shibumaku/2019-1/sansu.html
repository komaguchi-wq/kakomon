1 (1) AさんとBさんの20番目の数 A・7点｜場合の数（小さい順）

👀 まず見るところ

【条件文】部品は「4枚の異なる数のカード」と「20番目」に丸。千の位が1の数は24個 → 20番目は千の位が1の後ろのほう。24番目からもどって数える。

📚 前提知識

  • 千の位を1に決める。百の位は残りの4通り。十の位は3通り。一の位は2通り。4×3×2＝24個できる。
  • Aさんのカードを小さい順にならべると 1, 4, 6, 7, 9。Bさんは 2, 3, 4, 8, 9。同じ順番のカードどうしを入れかえると、Aさんの数がBさんの同じ番目の数になる。

🔍 整理して解く

  1. Aさんの千の位が1の数は24個。20番目は24番目から4つもどるほうが早い。
  2. 千の位が1でいちばん大きい数は1976。これが24番目。大きいほうから順に書く。
    番目2423222120
    Aさんの数19761974196719641947
    百の位が9の数は6個ある。1976, 1974, 1967, 1964, 1947, 1946 の順に小さくなる。5つ目の1947が20番目。
  3. Bさんは、カードを小さい順にならべて、Aさんのカードと上下に結ぶ。 図：1と2、4と3、6と4、7と8、9と9が同じ順番。
  4. 1947のカードを1枚ずつ入れかえる。1→2、9→9、4→3、7→8。Bさんの20番目は2938。
  5. 落としやすい所。小さいほうから20個書くと時間がかかり、数え落としやすい。24番目からもどる。
答え：Aさん…1947，Bさん…2938

1 (2) Bさんの数のほうが大きくなる番目の個数 B・7点｜場合の数（千の位ごとに比べる）

👀 まず見るところ

👀 まず見るところ

【条件文】部品は「その差がもっとも大きい」と「すべて答えなさい」に丸。結んだカードの差を書くと、6と4の差2がいちばん大きい → 千の位を6と4に決めて、上の位から順に差を大きくする。(1)(2)の図と表が残っていれば手を付ける。

2 (1) 4段目にはじめて色がぬられる列 A・7点｜きまりを数字で読む（3でくり上がる）

👀 まず見るところ

【資料問題】図1の正体は「あるきまりにしたがって」ぬった列のならび。ぬり方を 0・1・2 の数字に直して書く → 1段目は1列ごと、2段目は3列目、3段目は9列目から始まる。3倍ずつだから、4段目は9×3。

📚 前提知識

  • ますのぬり方は3種類。ぬらない、三角1つ、三角2つ（ます全部）。これを 0, 1, 2 と読む。
  • 2の次は、0にもどって上の段が1ふえる。10でくり上がるふつうの数と同じしくみで、3でくり上がる（3進法）。

🔍 整理して解く

  1. ぬり方を数字に直す決まりを書く。 図：左から 0、1、2 と読む。
  2. 図1の1列目から9列目までを、数字の表に書きかえる。
    列123456789
    3段目000000001
    2段目001112220
    1段目120120120
  3. はじめてぬられる列を見る。1段目は1列目。2段目は3列目。3段目は9列目。3倍ずつになっている。
  4. 4段目は 9×3＝27列目。
  5. 落としやすい所。9列目は2段目と1段目が0にもどる。ここを図1で確かめてから3倍する。
答え：27列目

👀 まず見るところ

4 (1)① ●が2つならんだ直角三角形・三角形ACDの面積 B・6点｜折り返しの合同と相似

👀 まず見るところ

【条件文】部品は「●印がついた2つの角の大きさは等しい」「辺ABの長さは2cmで，辺BCの長さは1cm」。●が2つは「ACで折り返す」に直して図に置く。CからAEに垂直な線を引くと、底辺ADと高さ1cmが決まる。この線が引けたら手を付ける。

📚 前提知識

  • 角を半分に分ける線で折ると、両がわはぴったり重なる。三角形ABCをACで折ると、辺ABは直線AEの上に重なる。
  • 直角三角形どうしは、直角のほかにもう1つ同じ角があれば、同じ形（相似）になる。三角形ABCは、直角をはさむ辺が 1cm と 2cm。同じ形の三角形は、どれも「短い辺：長い辺＝1：2」。

🔍 整理して解く

  1. 図に AB＝2cm、BC＝1cm を書く。CからAEに垂直な線を引く。AEと交わる点をFとする。Fは問題の図に無い点。自分で書き足す。
  2. 三角形ACFは、三角形ACBをACで折り返した形。だから AF＝2cm、CF＝1cm。
  3. 次に角を調べる。角ACBを○とする。●と○をたすと90度。折り返したから、角ACFも○。角ACDは直角。だから角FCDは 90度−○＝●。

答え：1.25cm²
コツ：「同じ大きさの角が2つならぶ」と見たら、その線で折り返した三角形を書き足す。高さになる線（CF）が同時に手に入る。

📚 前提知識

  • 平行な線で切ってできる小さい三角形は、もとの三角形と同じ形。辺の比がそのまま使える。たとえば底辺が 1：4 なら、高さも 1：4。
  • 直角三角形どうしで、ななめの辺が同じ線で、角も1つ同じなら、ぴったり重なる（合同）。

🔍 整理して解く

  1. ①の図を使う。角DCEを調べる。B・C・Eは一直線。180度から、角ACBの○と、角ACDの90度を引く。残りは 90度−○＝●。角FCDも●だった。
  2. DからEBに垂直な線を引く。EBと交わる点をGとする。三角形CDGは、三角形CDFをCDで折り返した形。だから CG＝1cm、DG＝0.5cm。
  3. DGもABも、EBに垂直。だからDGとABは平行。三角形EDGと三角形EABは同じ形。DG：AB＝0.5：2＝1：4。
  4. EG：EB も 1：4。だから EG：GB＝1：3。GBは 1＋1＝2cm。EG＝2×1/3＝2/3cm。
  5. CE＝EG＋GC＝2/3＋1＝1 2/3cm。
  6. 確かめ。EB＝2/3＋2＝2 2/3cm。EG：EB＝2/3：2 2/3＝1：4。合っている。
答え：1 2/3cm

4 (2) 対角線が直角に交わる四角形・角xと角yの和 B・7点｜角の和（方眼で直角二等辺三角形）

👀 まず見るところ

【条件文】部品は「AOの長さは6cm」「BOとDOの長さはどちらも2cm」「COの長さは4cm」。長さを1cmの方眼に直して図に置く。xもyも1つずつは出せない → 半分の角どうしを1つの点に集めると45度と決まる。方眼がかけたら手を付ける。

📚 前提知識

  • 方眼の上で「右へ3・上へ1」進む線と、「右へ1・下へ3」進む線は、同じ長さで、直角に交わる。同じ直角三角形を90度回した形になっている。
  • 直角二等辺三角形は、直角のほかの2つの角がどちらも45度。

🔍 整理して解く

  1. 1cmの方眼に四角形ABCDをかく。ACの上と下は同じ形。だからACは、角xも角yも半分に分ける。xの半分を×、yの半分を●とする。
  2. ×は「横6・たて2」の直角三角形の角。「横3・たて1」と同じかたむき。●は「横4・たて2」の直角三角形の角。
  3. 方眼の点Qに、×を上、●を下にしてならべる。Qから右へ3・上へ1の点をP、Qから右へ4・下へ2の点をRとする。P・Q・Rは説明のために足した点。
  4. PからRへは、右へ1・下へ3。QPは「3と1」、PRは「1と3」。同じ長さで、直角に交わる。三角形PQRは直角二等辺三角形。
  5. 角PQRは45度。つまり ×＋●＝45度。xとyの和はその2倍。45×2＝90度。
答え：90度
コツ：長さは分かるのに角度が出せないときは、方眼にかく。2つの角を1つの点にならべて、直角二等辺三角形（45度）をさがす。

5 (1) 3点C・D・Fを通る平面で切った体積の比 C・8点｜四角すい台の切断・体積比

👀 まず見るところ

本番では後回し。【条件文】部品は「辺ABと辺EFは平行」「3つの点C，D，Fを通る平面」。CDもEFと平行 → 切り口はEも通る台形DEFCと決まる。高さを□として、体積を「◯×□」の形で図の横に置く。

📚 前提知識

  • 上の長方形は6×8、下の長方形は9×12。6：9＝8：12＝2：3 で同じ形。この立体は、大きい四角すいから小さい四角すいを切り取った形。相似比が2：3なら、体積の比は 2×2×2：3×3×3＝8：27。

🔍 整理して解く

  1. 全体の体積。EA・FB・GC・HDを上へのばす。4本は1点で交わる。その点をOとする（Oは書き足す点）。上の面と下の面の間の長さを□とする。小さい四角すいO-ABCDの高さは □×2。体積は 6×8×(□×2)÷3＝32×□。全体はその (27−8)/8 倍。32×□×19/8＝76×□。 図：赤い線が切り口の台形DEFC。DEは裏がわの面の上なので点線。
  2. Aを含まない側（C・D・E・F・G・H）。下の面に、FGと平行な線IJとKLを引く。IJはCの真下、KLはDの真下を通る。この2本で切り分ける。まん中が三角柱、両はしが四角すい2つ。I・J・K・Lは書き足す点。
    部分式体積
    三角柱（まん中）12×□÷2×636×□
    四角すい2つ（両はし）底面を合わせると (9−6)×12＝36。36×□÷312×□
    Aを含まない側36＋1248×□
  3. Aを含む側は 76−48＝28（×□）。比は 28：48＝7：12。
答え：7：12

5 (2)① 3点P・Q・Fを通る平面とAEの交点R・AR：RE C・6点｜切り口の作図（のばして交点）と相似

👀 まず見るところ

本番では後回し。【条件文】部品は「CPの長さが2cm」「DQの長さが4cm」。BP＝6cm、AQ＝4cmに直して図に置く。PQとBAをのばして交わる点をMとする。MとFを結ぶ → AEと交わる点がRと決まる。

📚 前提知識

  • 切り口の線は、同じ面の上にある2点を結んでかく。QとRは結ぶ相手がまだ無い。こういうときは、切り口の線PQをのばして、となりの面の辺ののばした線と交わらせる。交わった点は、となりの面と同じ平面の上にある。

🔍 整理して解く

  1. 上の面を真上から見た図をかく。AQ＝8−4＝4cm、BP＝8−2＝6cm。PQとBAをのばして交わる点をMとする。三角形MAQと三角形MBPは同じ形。AQ：BP＝4：6＝2：3。だから MA：AB＝2：1。MA＝6×2＝12cm。
  2. MはBAをのばした線の上。だからMとFは、どちらも面ABFEと同じ平面の上にある。MとFを結ぶ。AEと交わる点がR。
  3. MAとFEは平行。三角形MRAと三角形FREは同じ形。MA：FE＝12：9＝4：3。だから AR：RE＝4：3。
答え：4：3

5 (2)② 3点P・Q・Fを通る平面で切った体積の比 C・6点｜三角すいの差・体積比

👀 まず見るところ

本番では後回し。【条件文】部品は「Aを含む立体」と、①の AR：RE＝4：3。Rの深さは「上の面から □×4/7」に直して書く → Aを含む側は、三角すいF-MBPから三角すいR-MAQを引いた形と決まる。

📚 前提知識

  • 角すいの体積は 底面積×高さ÷3（問題文に書いてある）。切り口のある立体は、①でのばした点Mまでふくめた大きい三角すいから、はみ出した小さい三角すいを引く。

🔍 整理して解く

  1. 2つの三角すいの体積を、□を使って表にする。底面はどちらも上の面と同じ平面の上。高さは上の面からの深さ。①の2つの図を使う。
    三角すい底面積高さ体積
    F-MBP（大）三角形MBP＝6×(6＋12)÷2＝54□54×□÷3＝18×□
    R-MAQ（小）三角形MAQ＝4×12÷2＝24□×4/724×(□×4/7)÷3＝32/7×□
  2. Aを含む側は 18−32/7＝94/7（×□）。全体は (1) で出した 76×□。Aを含まない側は 76−94/7＝438/7（×□）。
  3. 比は 94/7：438/7＝94：438＝47：219。

4〜5 まとめ この回で繰り返し出た入口

  • 同じ大きさの角が2つならぶ → その線で折り返した三角形を書き足す（大問4 (1)）。
  • 長さは分かるが角度が出せない → 方眼にかいて、45度の三角形をさがす（大問4 (2)）。
  • 上と下が同じ形の立体 → 高さを□として、体積を「◯×□」でそろえる。切り口が面のはしで止まったら、のばして交わらせる（大問5）。
