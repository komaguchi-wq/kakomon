1 (1) 体積が半分になる力 A・2点｜グラフの読み取り

👀 まず見るところ

1 (2) 関係式1の①②（大気の力） A・4点｜グラフ＋式の当てはめ

👀 まず見るところ

問題文の「①は大気がピストンを押す力」。(1)で、手が4000g押すと体積が半分になった。体積が半分＝押す力の合計が2倍。つまり手を加える前から大気が4000g分押していた。これが①。

📚 前提知識

  • 閉じ込めた気体は「押す力の合計×体積＝一定」（ボイルの法則）。押す力は「手＋大気」の合計で考える。②がその一定の値。

🔍 こう読み解く

  1. ①を□とおき、グラフの2点（0g, 40mL）と（4000g, 20mL）を関係式1に入れる。
  2. （0＋□）×40＝（4000＋□）×20 → 40×□＝80000＋20×□ → 20×□＝80000 → □＝4000。
  3. ②＝（0＋4000）×40＝160000。念のため（4000＋4000）×20＝160000 で一致。
答え：①4000・②160000
コツ：余白に「合計の力×体積＝160000」と書いておく。(3)(4)はこの1行に当てはめるだけになる。

2 (2) どちらが余っているか（A〜E） B・3点｜表の頭打ちと沈殿

2 (4) クエン酸2.0gと過不足なく反応する重曹 A・3点｜比で求める

👀 まず見るところ

🔍 こう読み解く

2 (5) 表4の条件で下がる温度 K〜N B・4点｜「反応した量」と「水の量」

👀 まず見るところ

基準はG（2.00・2.00・20mL）で7.3℃。表3で水を増やすほど下がり方が小さい。だから見るのは2つ、反応した量（＝出た二酸化炭素の量）と水の量。K〜Nを「Gと比べて多いか少ないか」で判断できれば手を付ける価値がある。

📚 前提知識

  • クエン酸と重曹の反応はまわりから熱を吸収する。吸収する熱は反応した量に比例し、同じ熱でも水が多いと温度は下がりにくい。
  • 反応した量は(4)の「クエン酸2.0g ↔ 重曹2.7g」で、どちらが使い切られるかを決めてから読む。

🔍 こう読み解く

  1. K（1.00・1.00・10mL）：重曹1.00が全部反応して二酸化炭素0.52g＝Gの半分。水も半分。割合が同じなので約7.3℃ → イ。
  2. L（3.00・3.00・20mL）：クエン酸3.00なら重曹は約4.0gまで反応できるので重曹3.00が全部反応 → 1.56g＝Gの1.5倍。水は同じ → 大きく下がる → ウ。
  3. M（1.00・3.00・20mL）：クエン酸1.00が先になくなる → 1.38gの半分＝約0.69g、Gより少ない。水は同じ → 下がり方は小さい → ア。
  4. N（3.00・2.00・20mL）：重曹2.00が全部反応 → 1.04g、Gとまったく同じ（クエン酸が余るだけ）。水も同じ → 7.3℃ → イ。
答え：K…イ・L…ウ・M…ア・N…イ
コツ：Nで「クエン酸が多いから大きく下がる」と考えると間違う。余った分は反応していないので熱に関係しない。

2 (6) 温度が下がる操作 B・3点｜吸熱と発熱の分類

👀 まず見るところ

下線部の温度が「下がる」ものをすべて選ぶ。まず「熱が出る」と分かるもの（金属と酸の反応、電球、カイロ）を消し、残りを「溶ける・蒸発する」で見る。

📚 前提知識

  • 温度が下がる（吸熱）：ものが水に溶けるとき（食塩・砂糖など）、液体が蒸発するとき（アルコール、汗）。
  • 温度が上がる（発熱）：塩酸＋アルミニウム（水素が出る）、電流を流したフィラメント、鉄粉がさびる（カイロと同じ）。

🔍 こう読み解く

  1. ア 塩酸にアルミニウム → 発熱 ×。ウ 豆電球 → フィラメントが発熱 ×。オ 鉄粉＋食塩水＋空気 → さびて発熱（カイロ）×。
  2. イ 食塩が水に溶ける → 溶けるときにまわりから熱を吸う ○。エ 消毒用アルコールが机で蒸発 → 蒸発するとき熱をうばう ○。
答え：イ・エ

1〜2 まとめ この2大問で繰り返し出た入口

  • 「合計の力×体積＝一定」の1行を余白に書けば、大問1は(2)〜(6)まで同じ式で進める。引く力はマイナス、大気が80%なら定数も80%。
  • 表で頭打ちになった列と沈殿の有無を見れば、どちらが余ったかは知識なしで決まる。折れ目の位置＝過不足なく反応する量。
  • 温度低下は「反応した量÷水の量」。余った分は反応していないので数えない。

3 (1) 光合成の材料 A・2点｜知識問題

光合成の材料は二酸化炭素と水。二酸化炭素は葉の気孔から、水は根から取り入れ、光のエネルギーでデンプンをつくる。あ・いの2つの空らんにこの2つを書く。
答え：あ…二酸化炭素・い…水

3 (2) 呼吸で使う気体・出る気体 A・2点｜知識問題

呼吸は酸素を使って栄養分を分解し、エネルギーを取り出すはたらき。出てくる気体は二酸化炭素。光合成（二酸化炭素を取りこみ酸素を出す）の逆向き、と結びつけると取りちがえない。文中の「（う）を使って」が酸素、「（え）が発生」が二酸化炭素。
答え：う…酸素・え…二酸化炭素

3 (3) 草丈のグラフから成長の仕方を読む A・3点｜グラフ読み取り・語句選択

👀 まず見るところ

3 (4) 葉を大きくすることの不利な点 B・3点｜記述（30字程度・指定語）

👀 まず見るところ

📚 前提知識

  • 光合成でつくった栄養分の使い道は2つ（呼吸の材料・成長の材料）。体が大きいほど呼吸で使う分、つまり維持のための栄養分が増える。

✍️ 答案の組み立て

  1. 要素A：葉が大きくなると（それを支える茎なども丈夫にする必要があり）体を維持するための栄養分が
  2. 要素B：多く必要になる。「葉が大きくなったことで」に自然につながる形にし、字数は30字前後で止める。
模範解答：植物の体を維持するための栄養分が多く必要となる。
コツ：指定語が本文にあるときは、その文をさがして言いかえる。「光合成量が増える」は良い点なので、不利な点として書かない。

3 (5) 転流率と分配率の計算 B・3点｜割合の計算

👀 まず見るところ

2つの割合の「もと」がちがう。転流率は光合成量がもと、分配率は転流した量がもと（文中の定義）。ここを言い直してから式にする。

📚 前提知識

  • 割合＝比べる量÷もとにする量×100。もとにする量が何かを先に決める。

🔍 こう読み解く

  1. 光合成量を100とおく。転流した量は 100×0.4＝40。
  2. 第一花房へ行った量は光合成量の2%なので 100×0.02＝2。
  3. 分配率は転流した量がもとなので 2÷40×100＝5(%)。
答え：5%
コツ：「2%」をそのまま答えに書きたくなる問題。もとが40に変わったので、2%より大きい数になる、と見当をつける。

3 (6) 図6の分配率の比べ方 A・3点｜グラフ読み取り・語句選択

👀 まず見るところ

図6は横線（普通葉8の高さ）の上が上の部位、下が下の部位。4つの時期すべてで、XとYの黒（根）の長さと、横線より上の長さを比べる。

📚 前提知識

  • 凡例：白＝第一花房、灰＝第二花房、たて線＝茎、ななめ線＝葉、黒＝根。X＝無処理株、Y＝処理株。

🔍 こう読み解く

  1. ①：黒（根）は1週間後 X 約45%・Y 約28%、3週間後 X 約15%・Y 約6%と、どの時期もYが短い → 根。茎は逆にYの方が長い時期があるので、茎は選べない。

  3. ③：上のうち白（第一花房）がほとんどで、これもYの方が長い → 第一花房。

3 (7) 転流率・分配率の正誤 B・3点｜すべて選ぶ・グラフで検証

👀 まず見るところ

4つの文はどれも図6だけで確かめられる。知識がなくても決まる。転流率は表の8つの数字、分配率は棒の長さで、「すべて」「上がり続ける」「行われない」の言い切りを反例1つでつぶす。

📚 前提知識（あれば答え合わせに使う）

  • 時間がたつと、実ができる第一花房への分配が増える。1週間後は約30%、2週間後以降は80%以上。

🔍 こう読み解く

  1. ア：Xの転流率は 47.2→71.9→61.0→48.2%。2週間後を山に下がっている → ×。
  2. イ：XとYを時期ごとに比べる。47.2＞40.7、71.9＞69.5、61.0＞50.8、48.2＞42.2。4つともYが低い → ○。
  3. ウ：白（第一花房）は1週間後 XもYも20〜30%、4週間後はどちらも80%をこえる → ○。
  4. エ：ななめ線（葉）の部分がXにもYにもある。葉への分配が行われているので、「行われない」は× 。

4 (1) 皆既月食の1週間後・2週間後の月 A・2点｜月の満ち欠け

👀 まず見るところ

図1で、月が地球の影に入るのは太陽―地球―月が一直線のとき、つまり月食＝満月。満月から1週間後が下弦、2週間後が新月、と数える。

📚 前提知識

  • 満月→（約7日）→下弦の月→（約7日）→新月。下弦の月は南の空で左半分が明るい。新月は太陽と同じ方向にあり観察できない。

🔍 こう読み解く

  1. 約1週間後＝下弦。左が白、右が黒の半月 → ウ（カは左右が逆で上弦）。
  2. 約2週間後＝新月。「観察できない」のア。
答え：約1週間後…ウ・約2週間後…ア

4 (2) 月食の月でクレーターのかげが見えにくい理由 B・3点｜記述（空らん補充）

👀 まず見るところ

解答らんの型「部分月食のときの月では（　）のに対して、一般的な欠けている月では（　）ため。」。2つの月でちがうのは太陽の光が当たる向き。ふつうの欠けた月の境目は、太陽の光が横から当たる場所。

📚 前提知識

  • 月食は満月のとき。満月は太陽の光が月の正面（真上）から当たるので、クレーターのかげができにくい。ふつうの欠けた月は、明暗の境目に光が横から当たり、でこぼこのかげが長く出る。

✍️ 答案の組み立て

  1. 前半（部分月食）：太陽の光がクレーターの真上方向から当たる。
  2. 後半（一般的な欠けている月）：太陽の光がななめ方向や横方向から当たる。2つの空らんを「真上／ななめ・横」の対比にそろえる。
模範解答：太陽の光がクレーターの真上方向から当たる／太陽の光がななめ方向や横方向から当たる
コツ：「地球の影で欠けている」と「太陽の光が当たらなくて欠けている」のちがいを、光の向きの言葉で書く。

4 (3) 地球の影の直径 A・3点｜比例の計算

👀 まず見るところ

図4の2つの長さ、月8.0cmと地球の影23.5cm。スケッチ上の比が、そのまま実際の直径の比。月の直径3200kmを8.0cmに対応させる。

📚 前提知識

  • 同じ図に描かれたものは縮尺が同じなので、（月の直径）：（影の直径）＝8.0：23.5。

🔍 こう読み解く

  1. 余白に「8.0cm ↔ 3200km」と書く。1cmあたり 3200÷8.0＝400km。
  2. 影の直径は 400×23.5＝9400km。式は 3200×23.5÷8.0 でも同じ。
答え：9400km

4 (4) 地球と月の距離 A・3点｜相似の比例計算

👀 まず見るところ

「五円玉の穴（5mm）が、目から60cmで月と同じ大きさに見える」。目を頂点にした2つの三角形が相似。単位をmmかcmにそろえてから比にする。

📚 前提知識

  • 見かけの大きさが同じ＝（大きさ）：（距離）の比が同じ。5mm＝0.5cm。

🔍 こう読み解く

  1. 穴：60cm÷0.5cm＝距離は大きさの120倍。
  2. 月も同じ倍率なので 3200km×120＝384000km。
答え：384000km
コツ：mmとcmを混ぜたまま計算すると10倍ずれる。先に「5mm＝0.5cm」と書きかえる。

4 (5) 皆既月食が続く時間 B・4点｜速さの計算＋図の読み取り

👀 まず見るところ

数値は全部そろっている。(4)の384000km、27日、円周率3、(3)の9400km、月の直径3200km。①は「軌道1周の長さ÷27日（秒）」、③④は「動いた距離÷①の速さ」。③④で動く距離を図5で決めるのがこの問題の核。B判定だが式は3本なので、時間があれば取る。

📚 前提知識

  • 月は地球のまわりを西から東へ（図1で反時計回り）動く。南の空では東が左なので、月は影に対して左へ進み、左側から欠け始める。

🔍 こう読み解く

  1. ①：軌道の長さ＝384000×2×3＝2304000km。27日＝27×24×60×60＝2332800秒。2304000÷2332800＝0.98… → 1秒あたり約1km。
  2. ②：影に対して左へ進むので、図5で左下へ向かう矢印のB。図5の白い月は影に入る前と出た後の月で、暗い月2つが皆既の始まりと終わり。
  3. ③：道Xでは、皆既の始まりと終わりの月（暗い部分）が接している。中心が動いた距離は月の直径1つ分＝3200km。3200÷1÷60＝53.3… → 約53分。
  4. ④：道Yは影の中心を通るので最大。影の直径から月の半径2つ分（＝直径1つ分）を引いた 9400−3200＝6200kmを動く。6200÷1÷60＝103.3… → 約103分。
答え：①1・②B・③53・④103
コツ：③と④のちがいは「暗い月2つが接している（直径1つ分）」か「影の端から端（影の直径−月の直径）」か。図5に線を引いて距離を確かめる。

4 (6) 月食が毎月起きない理由 A・3点｜選択

👀 まず見るところ

「満月のたびに月食が起きてもよさそうなのに、年2回ほど」。満月でも地球の影に入らないことがある理由を選ぶ。影の上や下を通り過ぎる、という絵を思いうかべる。

📚 前提知識

  • 月の公転面は地球の公転面に対して少しかたむいている（約5度とされる）。だから太陽―地球―月がちょうど一直線に並ぶのは、満月のうち年に2回ほど。

🔍 こう読み解く

  1. 「一直線に並ばない」を言っているのはオ（公転面が平行でない）だけ。
  2. ウは満月の回数の話で、「満月なのに影に入らない」理由にはならない。エ（円でない）は距離の変化の話で、影に入るかどうかは決めない。カ（自転＝公転）は月の同じ面が見える理由。キ（大気）は月食の月が赤く見える理由。
答え：オ
