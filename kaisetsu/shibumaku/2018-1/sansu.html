1 (1) 合わせて10個を、いちばん安く受けとる A・7点｜条件の整理（○●の書き出し）

👀 まず見るところ

「もらったお菓子にもシールが1枚つく」→ 買ったお菓子を○、もらったお菓子を●と書いて、4枚か6枚たまるたびに引きかえる。合わせて10個になったら止める。○の数がいちばん少ない引きかえ方が、いちばん安い。

📚 前提知識

  • 4枚で1個。○○○○ をわたすと ● が1個もどる。その ● にもシールがある。次は ●○○○ で4枚になる。
  • 6枚で2個。○○○○○○ をわたすと ●● が2個もどる。次は ●●○○○○ で6枚になる。
  • お金は ○の数×30円。●はただ。シールをわたしたお菓子も、受けとった数に入る。

🔍 整理して解く

  1. 4枚ずつ引きかえる場合を書く。1回目の4枚、2回目の4枚、と1行ずつ。 
    1回目 ○○○○   → ●が1個もどる
2回目 ●○○○   → ●が1個もどる
残り  ●○      （ここで合わせて10個）
  2. ○を数える。4＋3＋1＝8個。●は2個。
  3. 6枚で引きかえる場合も書く。 
    1回目 ○○○○○○ → ●が2個もどる
残り  ●●○○     （ここで合わせて10個）
  4. ○は 6＋2＝8個。こちらも8個。
  5. 4枚を1回だけ引きかえる場合は、○が9個になる。8個より多い。
  6. いちばん少ない○は8個。30×8＝240。
  7. 落としやすい所。「10個」は買った○ともらった●をたした数。○だけで10個にすると300円になってしまう。
答え：240円

1 (2) 360円で受けとれる個数の最大 A・7点｜条件の整理（引きかえの順番）

👀 まず見るところ

360円 → 買えるのは 360÷30＝12個。○が12個と決まっている → ●がいちばん多くなる引きかえ方をさがす。6枚で2個のほうが、シール1枚あたりのもどりが多い。シールが多いうちに、6枚で引きかえる。

📚 前提知識

  • 4枚で1個は、4枚がへって1枚もどる。つまり3枚へって1個。6枚で2個は、6枚がへって2枚もどる。つまり4枚へって2個。1個あたり2枚。6枚のほうが得。
  • ただし6枚で引きかえるには、手元に6枚いる。4枚や5枚しか残らないと、4枚のほうしか使えない。

🔍 整理して解く

  1. 12個の○を、6枚ずつ引きかえる。1行に、そのとき手元にあるシールを書く。 
    1回目 ○○○○○○ → ●●がもどる（残りの○は6個）
2回目 ●●○○○○ → ●●がもどる（残りの○は2個）
3回目 ●●○○    → 4枚。●が1個もどる
残り  ●        → 1枚。もう引きかえられない
  2. ●を数える。2＋2＋1＝5個。
  3. 4枚ずつだけで引きかえると、●は3個。6枚を1回しか使わないと4個。5個がいちばん多い。
  4. 受けとる個数は、○12個＋●5個＝17個。
  5. 落としやすい所。○○○○→● から始めると、6枚がそろう前にシールが足りなくなる。先に6枚で引きかえる。
答え：17個
コツ：「何個受けとれるか」は、買う○ともらう●をたした数。○の12個だけを答えにしない。

1 (3) 合わせて101個を、いちばん安く受けとる A・7点｜条件の整理（規則を見つける）

👀 まず見るところ

101個は1つずつ書けない → 6枚の引きかえを「1行6個」の形にして、行の数で数える。1行目は○6個。2行目からは ●●○○○○（もどった2個＋新しく買う4個）が続く。(2)で、6枚のほうが得だと分かっている。

📚 前提知識

  • 6枚で引きかえたあと、手元には●●の2枚がある。あと4個買えば、また6枚になる。4個買うごとに2個もらえる。
  • 1行6個でならべると、行が1つふえるごとに受けとる数が6ふえる。101÷6＝16 あまり 5。16行と、あと5個。

🔍 整理して解く

    1行目   ○○○○○○ （○6個）
2行目   ●●○○○○ （○4個）
3行目   ●●○○○○ （○4個）
…
16行目  ●●○○○○ （○4個）
17行目  ●●○○    （4枚 → ●が1個もどる）
18行目  ●       （ここで合わせて101個）
  2. 16行目までで96個。16行目の引きかえで、●●がもどる。残りは 101−96＝5個。
  3. 残り5個を作る。○を2個買って4枚にする。引きかえて●を1個もらう。●●○○と●で5個。
  4. ●を数える。2行目から16行目までが 2×15＝30個。17行目に2個、18行目に1個。合わせて 30＋3＝33個。
  5. ○は 101−33＝68個。30×68＝2040。
  6. 落としやすい所。残り5個を○○○で買い足すと、○が69個になる。最後に4枚で1個をはさむと、1個安くなる。

コツ：大きな数は、1回の引きかえを「1行」にして、行の数で数える。1行目だけ形がちがう（○6個）ことに気をつける。

「得点＝1回目＋2回目×2＋3回目×4」→ 先にA君の得点を出す。2＋6×2＋3×4＝26。Bさんに残るカードは 1・4・5の3枚と決まる。ならべ方は6通りしかない。全部計算して、26より大きいものを選ぶ。

  • 3枚のならべ方は 3×2×1＝6通り。1回目を1・4・5で分けて書くと、数え落とさない。

    (1, 4, 5) → 1＋8＋20＝29  ○
(1, 5, 4) → 1＋10＋16＝27 ○

2 (2) A君の得点が29点になるひき方の数 B・7点｜整数の性質（偶数・奇数で場合分け）

👀 まず見るところ

「X＋Y×2＋Z×4＝29」→ Y×2もZ×4も偶数。29は奇数。だから Xは奇数（1・3・5）に決まる。「29が奇数」に気づけたら、表は9本で終わる。手を付ける価値がある。1〜6から3枚を全部ためすのは長すぎる。

📚 前提知識

  • 偶数＋偶数＝偶数。奇数にするには、奇数を1つたす。29は「X＋偶数」。だからXが奇数。
  • Xを引いた残りは偶数。両方を2でわると「Y＋Z×2」の形になる。28なら14、26なら13、24なら12。
  • ひいたカードはもどさない。X・Y・Zは全部ちがう数。同じ数が出た組は消す。

🔍 整理して解く

  1. Xで分ける。X＝1なら Y＋Z×2＝14。X＝3なら13。X＝5なら12。
  2. Zを6・5・4・3と下げて、Yを出す。Yが1〜6からはみ出したら止める。 
    X＝1 → Y＋Z×2＝14
  Z=6 → Y=2 ○
  Z=5 → Y=4 ○
  Z=4 → Y=6 ○
  Z=3 → Y=8 ×（6より大きい）
X＝3 → Y＋Z×2＝13
  Z=6 → Y=1 ○
  Z=5 → Y=3 ×（Xと同じ）
  Z=4 → Y=5 ○
  Z=3 → Y=7 ×
X＝5 → Y＋Z×2＝12
  Z=6 → Y=0 ×
  Z=5 → Y=2 ×（Zが Xと同じ）
  Z=4 → Y=4 ×（YとZが同じ）
  Z=3 → Y=6 ○
  3. 同じ数を使う組を消す。(3, 3, 5)、(5, 2, 5)、(5, 4, 4) の3つ。
  4. 残った○を数える。X＝1で3通り、X＝3で2通り、X＝5で1通り。6通り。
  5. たしかめ。(5, 6, 3) は 5＋12＋12＝29。合っている。
答え：6通り
コツ：「×2」「×4」がついた数の和が奇数なら、何もついていない数が奇数。この1行で候補が半分になる。同じ数を2回使った組を消し忘れると9通りになる。

3 (1) A君の速さと小さな円の1周 A・5点×2｜グラフ（山のてっぺん＝半周）

👀 まず見るところ

A君のグラフの山のてっぺんが1500mで、そこが7.5分 → コースの半分1500mを7.5分で走った。Cさんの山のてっぺんは1000m。これが大きな円の半分。

📚 前提知識

  • 「P地点との道のり」は、進んだ道のりと残りの道のりのうち小さいほう。だから山のてっぺんは、ちょうどコースの半分になる。たとえば3000mのコースなら、てっぺんは1500m。
  • 一定の速さで走るグラフはまっすぐな線。速さは、道のり÷時間で出せる。

🔍 整理して解く

  1. A君の山を読む。0分から7.5分で、0mから1500mまで上がる。ここまでがコースの半分（図Ⅰの太線: P→Q→R）。
  2. A君の速さは 1500÷7.5＝200。毎分200m。15分で1周3000mと考えても、3000÷15＝200で同じ。
  3. Cさんは大きな円だけを歩く。山のてっぺん1000mが大きな円の半分。大きな円1周は2000m。
  4. 小さな円の半分は 1500−1000＝500。1周は 500×2＝1000m。 
    コース1周   3000m（A君は15分で1周）
大きな円    半分1000m → 1周2000m
小さな円    半分 500m → 1周1000m
答え：A君の走る速さ 毎分200m／小さな円のコース1周 1000m
コツ：7.5分は目盛りにない。「15分の半分」とグラフの形から読む。Cさんの山のてっぺんの時間は分からなくてよい。使うのは高さ1000mだけ。

3 (2)① B君がいちばん速いときの速さと、3人が出会う時間 C・5点×2｜出会いの回数→和差算

👀 まず見るところ

本番では後回しでよい。合図は「Q地点で3人が同時に出会った」と「それまでにA君とB君は4回出会った」 → Qでの出会いが5回目。2人の道のりの和は3000×5。あとは差を出して和差算。

📚 前提知識

  • 同じコースを反対向きに走る2人は、道のりの和が1周（3000m）になるたびに出会う。5回目に出会ったとき、和は 3000×5＝15000m。

🔍 整理して解く

  1. 和を出す。3000×5＝15000m。
  2. 差を出す。2人ともQ地点にいる。Qを通るのは、1周のうち「1000m進んだとき」と「2000m進んだとき」の2回。差がいちばん小さいのは、A君が2000m、B君が1000m進んだところで同じ周回にいる形（声教の図Ⅲのウ）。差は 2000−1000＝1000m。差が小さいほどB君は速い。
  3. 和差算。A君は (15000+1000)÷2＝8000m。B君は 8000−1000＝7000m。時間は 8000÷200＝40分。B君の速さは 7000÷40＝175。 
    和    15000m（5回目の出会い）
差     1000m（2人ともQにいる組み合わせで最小）
A君   (15000+1000)÷2＝8000m → 8000÷200＝40分
B君   8000−1000＝7000m → 7000÷40＝毎分175m
答え：B君の走る速さ 毎分175m／3人がはじめて同時に出会ったのは 40分後
コツ：「もっとも速い場合」は「差がもっとも小さい場合」と読みかえる。声教の図Ⅲはア〜エの4つの形を比べて、差1000mのウを選んでいる。

4 (1)① DE：EF A・7点｜砂時計形の相似を2組

👀 まず見るところ

平行四辺形だからBCとDEが平行。AはCBをのばした線の上 → Hを中心にした砂時計形の相似を2組さがす。三角形ABHとDEH、三角形BCHとEFH。

  • 平行な2本の線にはさまれた砂時計形（ちょうちょ形）の三角形は相似。上の辺と下の辺の比が、真ん中で交わる線の分かれ方と同じになる。たとえば上が2、下が3なら、交わる線も2：3に分かれる。

  1. 三角形ABHと三角形DEH（ABとDEが平行の砂時計）。AB：DE＝2：3。だから BH：HE＝2：3。
  2. 三角形BCHと三角形EFH（BCとEFが平行の砂時計）。BH：HE＝2：3。だから BC：EF＝2：3。EFは ③×3/2＝4.5。
  3. DE：EF＝3：4.5＝2：3。 
    AB ＝ ②        DE ＝ BC ＝ ③
BH：HE ＝ 2：3  （三角形ABH と DEH）
BC：EF ＝ 2：3  （三角形BCH と EFH）→ EF ＝ 4.5

コツ：FはDEをのばした線の上にある。聞かれているのはDE：EFで、DF：EFではない。図にDE＝③、EF＝4.5と書いてから答える。

4 (1)② 三角形CDHは三角形EGHの何倍 B・7点｜底辺の比×高さの比

👀 まず見るところ

三角形CDHの底辺CDと、三角形EGHの底辺HEは平行 → 面積の比＝底辺の比×高さの比で出す。底辺の比は砂時計（FCDとFHE）、高さの比は線CFの上の長さ（CHとHG）。①でEF＝4.5が出ていれば手を付ける価値がある。比を2段に分けて出す問題。

📚 前提知識

  • 面積の比は、底辺の比と高さの比をかけたもの。たとえば底辺5：3、高さ19：6なら 95：18。
  • Cは辺CDの上にある。だから線CFの上の点は、Cからの長さがそのまま「CDからの高さ」の比になる。HはBEの上にある。だからGの「HEからの高さ」は、HからGまでの長さの比。

🔍 整理して解く

  1. 底辺の比。三角形FCDと三角形FHE（HEとCDが平行）。①より DE：EF＝2：3。だから FD：FE＝(2+3)：3＝5：3。CD：HE＝5：3。
  2. 線CFを2通りに分ける。三角形BCHとEFHから CH：HF＝2：3。三角形ACGとEFGから CG：GF＝(②+③)：4.5＝10：9。
  3. CFを 5 と 19 の最小公倍数 95 にそろえる。CH＝38、CG＝50。HG＝50−38＝12。 
    CF ＝ 95 にそろえる
CからHまで   38  （CH：HF＝2：3 → 95×2/5）
CからGまで   50  （CG：GF＝10：9 → 95×10/19）
HからGまで   50−38＝12
  4. 高さの比は HC：GH＝38：12＝19：6。

5 (1) 直方体を切って、Aを含む側の体積 A・7点｜立体の切断・相似なすい体の差

👀 まず見るところ

切り口の4点が、上の面はBのまわり2cm、下の面はFのまわり6cm → 切り取られる小さい側は、上が細く下が太い「三角すい台」。RP・FB・SQをのばして1点Oに集め、大きい三角すいから小さい三角すいを引く。求める立体あは、直方体からその分を引いた残り。

📚 前提知識

  • すい台は、そのままでは体積の公式がない。のばして大きなすい体にして、小さなすい体を引く。
  • 相似な立体の体積の比は、相似比を3回かける。相似比が1：3なら、体積の比は 1×1×1：3×3×3＝1：27。
  • 三角すいの体積は、底面積×高さ÷3（問題文に書いてある）。

🔍 整理して解く

  1. まず、辺の長さを図に書きこもう。AB＝12、BC＝10、高さBF＝8。Bのまわりが2、Fのまわりが6。 
    上の面  PB＝2  QB＝2  （三角形PBQ）
下の面  RF＝6  SF＝6  （三角形RFS）
高さ    BF＝8
  2. RP・FB・SQを上へのばす。3本は1点Oで交わる。三角すいO-PBQと三角すいO-RFSは相似。相似比は PB：RF＝2：6＝1：3。

    小さい三角すい O-PBQ  底面 2×2÷2＝2   高さ OB＝4
大きい三角すい O-RFS  底面 6×6÷2＝18  高さ OF＝12
