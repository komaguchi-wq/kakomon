1 (1)① フタモンアシナガバチの写真を選ぶ B・3点｜写真の見分け

👀 まず見るところ

名前の「アシナガ」が合図。脚が長く、胸と腹の間が細くくびれたハチを探す。長く垂れた脚と細長い腹をもつのはエだけ。縮尺がちがうので大きさでは決められない。名前を手がかりにすれば短時間で決まるので、手を付けてよい。

📚 前提知識

  • アシナガバチはスズメバチ科のなかま（本文）。飛ぶときに長い後ろ脚を垂らして飛ぶのが名前の由来とされる。
  • 昆虫の翅は左右2枚ずつの4枚。翅が左右1枚ずつしか見えないものはハチではない。

🔍 こう読み解く

  1. アとウは腹が太くて大きく、がっしりした体。イとカは体が丸く毛が多い。オは翅が左右1枚ずつしか見えず、ハチの4枚とちがう。
  2. 残ったエは脚が細長く、胸と腹の間がくびれ、腹に横じまがある → エ。
  3. 落としやすい所：「しまがあるからア」と決めないこと。しまや大きさではなく、脚の長さと腰のくびれで見る。
答え：エ

1 (3)記号・理由 各巣室の幼虫の令の分布 A・3点＋B・3点｜本文から図を選ぶ・理由の記述

👀 まず見るところ

本文「初めの巣室の周りに巣室を作り足し、各巣室に1個の卵を産む」。つまり真ん中ほど古い。数字（令）が中央で大きく、外へ行くほど小さく、いちばん外側が卵、になっている図を探す。

📚 前提知識

  • 令＝脱皮の回数の目安。1令→2令→…→5令→蛹（本文）。早く産まれた卵ほど成長が進んでいるので、令の数字が大きい。
  • 「まだ羽化したハチはいない」は、成虫がいない段階という条件。5令や蛹があってもよい。

🔍 こう読み解く

  1. 「卵がいちばん外側にある」図をさがす。イ・エは卵が真ん中にあり、オは卵が右端の1列、カは同じ数字がかたまっているだけで、どれも「中央から外へ」の形ではない。ウは卵が内側にも混じり、5が外側・1が内側で逆。
  2. アは中央が5、そのまわりが4・3、外側が2・1、いちばん外が卵。中央ほど大きく、外ほど小さい形になっている → ア。
  3. 理由は本文の1文をそのまま使う：中央の巣室から周りへ順に卵を産みつけるから（中央ほど早く産まれて成長が進んでいる）。
  4. 落としやすい所：エは卵のとなりに5がある。最初の卵から順に産むなら、卵のとなりが5令になることはない。
答え：記号 ア／理由 中央の巣室から周りへ順に卵を産みつけるから。

1 (6) イの場合の効率をア・ウと比べる A・3点｜グラフの直線の傾き

👀 まず見るところ

本文の言いかえ：効率＝集めた水量÷時間＝原点と結んだ直線の傾き。図4に原点からイの点へ直線を引く。傾きが急なほど効率が高い。本文が「集めた水量はウが多いが効率はアが高い」と例まで示しているので、同じことをイでやる。

📚 前提知識

  • 直線の傾き＝縦÷横＝水量÷時間＝効率。曲線は最初が急で、だんだんゆるやか（長くいても水はあまり増えない）。

🔍 こう読み解く

  1. 原点から、曲線上のア・イ・ウの点へ直線を3本引く（声教の図i）。
  2. 曲線が上にふくらんでいるので、原点に近い点ほど直線が急。傾きはア＞イ＞ウ。
  3. だからイの効率は、アより低く、ウより高い。（　）に入れる文なので「〜より低く、〜より高い」と両方を書く。
  4. 落としやすい所：「水量が多い＝効率がよい」と混同すること。水量はウが最大でも、効率はアが最大。
答え：アの場合より低く，ウの場合より高い

1 (7)① 往復の時間カとキ、効率が高いのはどちらか A・3点｜直線の出発点を移す

👀 まず見るところ

往復の時間が入ると、直線の出発点が原点から左のカやキに移る。巣を離れていた時間＝往復＋水場なので、横軸で0より左に往復の時間をとった図5に、カからイの点へ、キからイの点へ直線を引く。

📚 前提知識

  • 効率＝水量÷（往復の時間＋水場の時間）。図5では、カ（またはキ）からイまでの横の長さが分母、イの点の高さが分子。

🔍 こう読み解く

  1. カ→イの点、キ→イの点に直線を引く（声教の図ii）。
  2. 分子（高さ）は同じで、分母（横の長さ）はキのほうが長い → キの直線のほうがゆるい。
  3. 傾きが急なカのほうが効率が高い。「水場が近いほど効率がよい」という当たり前の結論と合う。
答え：カ

1 (7)② 往復がカのとき、ア〜ウで効率が最も高いのは B・3点｜出発点を固定して3本引く

👀 まず見るところ

出発点をカに固定して、ア・イ・ウの3点へ直線を3本引く。いちばん急な直線を探す。定規を当てて3本引くだけなので、(6) ができたなら手を付ける。

📚 前提知識

  • (6) では原点から引いてアが最も急だった。出発点が左に動くと、近い点ほど横の長さ（カ＋ア）が相対的に長くなり、不利になる。順位が変わることがある。

🔍 こう読み解く

  1. カ→ア、カ→イ、カ→ウの3本（声教の図iii）。
  2. カ→アは高さが低いのに横は（カ＋ア）で長い → ゆるい。カ→ウは高さは最大だが横も最長 → 中くらい。カ→イが最も急。
  3. 落としやすい所：(6) の結果「アが最大」をそのまま答えること。出発点がずれると順位が変わるので、3本引いて確かめる。
答え：イ

1 (8) 往復がキのとき、最適な水場の時間サを作図で求める C・3点｜接線の作図

👀 まず見るところ

本番では後回し。合図は「効率が最も高い＝傾きが最大の直線」。キから引いた直線のうち最も急なのは、曲線に1点でふれる直線（接線）。

📚 前提知識

  • 出発点キから曲線上の点へ引ける直線のうち、傾きが最大なのは曲線とちょうど接するもの。それより急だと曲線に届かず、ゆるいと2点で交わる。

🔍 こう読み解く

  1. 定規をキの点に当てたまま角度を変え、曲線と1点だけで当たるところで直線を引く（声教の図iv）。
  2. 接点から横軸に垂直な線をおろし、横軸と交わった点がサ。図ivではイとウの間になる。
  3. 直線と垂線を消さずに残す（「作図したようすを残すこと」が条件）。
答え：解説の図ivを参照のこと。（キから曲線に接する直線を引き、接点の真下がサ）

2 (2) 太陽光を平行とみなせる理由 A・3点｜記述（穴埋め）

👀 まず見るところ

📚 前提知識

  • 光は広がって進むが、遠くまで来た光のごく一部（地球の幅ぶん）だけを見ると、広がりはほとんど無視できて平行に見える。
  • 声教の解説の値では、地球の直径は約12700km、太陽との距離は約1億5000万km。

🔍 こう読み解く

  2. 「太陽が大きいから」では理由にならない。比べる相手は直径と距離なので、距離を主語にする。
答え：地球と太陽の間の距離がはるかに大きい

「夏至」「北緯50°」「自転軸は23°傾く」の3つの数字。板が一番熱くなるのは太陽光に垂直なとき、と(1)で確かめたばかり。だから角B＝90°−（南中高度）。

📚 前提知識

  • 南中高度：春分・秋分は 90−緯度。夏至はそれより自転軸の傾きぶん高く、90−緯度＋23（この問題では23°）。冬至は 90−緯度−23。
  • 板が光に垂直だと、同じ面積で受け取る光線が最も多い（図3・図①の考え方）。

🔍 こう読み解く

  1. 余白に「南中高度＝90−緯度＋23」と書く。夏至のPでは 90−50＋23＝63°。
  2. 図10で、板を太陽光に垂直にする。太陽光と地面の角が63°なので、板と地面の角Bは 90−63＝27°（声教の図②の直角三角形）。
  3. 落としやすい所：63°をそのまま答えにしない。聞かれているのは「板と地面の角」。整数指定なので「27」とだけ書く。
答え：27度

2 (4) 夏が暑い理由と低緯度が暑い理由の共通点 B・3点｜記述（穴埋め）

👀 まず見るところ

空らんの後ろの「が多いから」と、この大問がずっと数えてきた「同じ面積が受け止める太陽光の量」。1（夏）も2（低緯度）も「南中高度が高い」場面なので、共通の理由はこれ。何を主語にするかが見えたら書く。

📚 前提知識

  • 夏は自転軸の傾きで南中高度が高い。緯度が低い地域も南中高度が高い。どちらも「太陽が高い→地面に光が垂直に近く当たる→同じ面積に当たる光が多い」。
  • 天候・海水・大気の影響は無視する、と設問にある。「日照時間が長い」は夏には言えても低緯度には言えないので、共通の理由にならない。

🔍 こう読み解く

  1. 「（　）が多いから」に入るのは名詞。主語を「夏や緯度の低い地域は」と立て、「同じ面積あたりの地面が受け止める太陽光の量」で受ける。
  2. 「太陽光が多い」だけだと弱い。「同じ面積あたり」を入れて、(1)の板の実験と同じ理屈だと示す。
答え：夏や緯度の低い地域は，同じ面積あたりの地面が受け止める太陽光の量

3 (1) スーパーボールBの密度 A・3点｜計算（密度）

👀 まず見るところ

🔍 こう読み解く

  2. 密度＝8.0÷8.8＝0.909…→ 小数第2位までで 0.91。
  3. 落としやすい所：50.0mLの水を引いてしまう（それは鉄の体積3.1cm³）。「鉄だけ」の目盛り53.1を引く。

3 (2) 体積と重さの点をグラフに記す A・3点｜作図（グラフ）

3 (4)①② 浮き上がる濃度の予想と実際 A・3点×2｜グラフの読み取り

👀 まず見るところ

図1で縦軸0.91（ボールの密度）の高さに横線を引く。点線（予想）と実線（実際）それぞれとぶつかる所の横軸を読む。①は点線で約42%、②は実線で約48%。

📚 前提知識

  • 混合液の密度がボールの密度より大きくなると浮く。水を加えるとエタノールの濃度は下がり、密度は上がる。だから答えは「〜%以下」。
  • 凡例：点線＝てつお君の予想（水とエタノールを結んだ直線）、実線＝実際。実線は点線より上にあるので、同じ密度になる濃度は実線の方が高い（＝加える水が少なくてすむ。紙面の「予想より少ない水の量で浮き上がった」と合う）。

🔍 こう読み解く

  1. 横軸1目盛り10%、縦軸1目盛り0.01。0.91は0.900の1目盛り上。定規で横線を引く。
  2. 点線との交点：40と50の間のやや40寄り → 42。実線との交点：50の少し手前 → 48。
  3. ［以上・以下］は、水を足す方向（濃度が下がる方向）で浮くので、両方「以下」を○で囲む。
答え：① 42%以下　② 48%以下
コツ：読み取り値は「整数」と指定。目盛りの中間は迷わず近い整数にする。42・48から数%ずれても、考え方が合っていれば(5)は「(4)で答えた値を用いる」ので計算は続けられる。

3 (5) 浮き上がったときに加えた水の体積 B・3点｜計算（濃度）

👀 まず見るところ

設問の「(4)で答えた値を用いる」と「エタノールの密度は0.8とする」。エタノール50.0mL→重さ40.0g。この40.0gが混合液の48%にあたる、と読みかえる。ここまで見えたら3ステップで終わる。

📚 前提知識

  • 紙面の定義：濃度＝エタノールの重さ÷混合液全体の重さ×100。重さの割合であって体積の割合ではない。
  • 混合液の重さ＝エタノールの重さ＋水の重さ（重さは混ぜても変わらない）。水は1.0g/cm³なので、水の重さ〔g〕＝体積〔mL〕。

🔍 こう読み解く

  1. エタノールの重さ＝0.8×50.0＝40.0g。
  2. 濃度48%のとき、混合液全体の重さ＝40.0÷0.48＝83.3…→ 約83g。
  3. 水の重さ＝83−40.0＝43g → 体積 43÷1.0＝43mL。
答え：43mL

3 (6)① 50%混合液の密度と、2つの密度の平均 B・3点｜グラフの読み取り

👀 まず見るところ

図1の50%の縦線で、実線と点線のどちらが上か。点線は「水とエタノールを直線で結んだ線」なので、50%での点線の高さがそのまま2つの密度の平均。実線はその上にある。知識がなくてもグラフだけで決まる。

📚 前提知識（あれば答え合わせに使う）

  • 声教の計算では、平均は (1.0＋0.8)÷2＝0.90g/cm³（紙面の0.788を使えば約0.89）。50%の実線の値は約0.907g/cm³で、どちらで計算しても実線のほうが上。

🔍 こう読み解く

  1. 50%の縦線を上にたどる。先に点線（＝平均、約0.89〜0.90）、その上に実線（約0.907）。
  2. 実線＝実際の密度が平均より大きい → ＞。
答え：＞

3 (6)②③ 混ぜたときの重さと体積 A・3点／B・3点｜考察（重さと体積）

👀 まず見るところ

直前の説明文「それぞれの液体の重さの合計と、混合した後の液体の重さは等しくなります。したがって、直線にならない原因は重さではありません」。②はこの文で「＝」。③は「重さが変わらないのに密度が大きい」なら体積が減っている、と考える。

📚 前提知識

  • 密度＝重さ÷体積。重さが同じで密度が大きいなら、体積が小さい。
  • 水とエタノールは混ぜると全体の体積が単純な和より小さくなる。グラフの実線が点線より上にあるのはこのため。

🔍 こう読み解く

  1. ②：重さは混ぜても増えも減りもしない。100g＋100g＝200g → ＝。
  2. ③：水100mL＝100g、エタノール100mL＝0.8×100＝80g。合計180g。濃度は 80÷180×100＝44.4…%。図1の実線で44%あたりの密度を読むと約0.92（声教の値）。
  3. 体積＝180÷0.92＝195.6…cm³。200mLより小さい → ＜。
答え：② ＝　③ ＜
コツ：③は計算しなくても決まる。①で「実際の密度は直線の予想より大きい」と分かったので、重さが同じなら体積は予想（200mL）より小さい。計算は確かめに使う。

  • 大問3は「密度＝重さ÷体積」と「体積＝目盛りの差（鉄だけの53.1を引く）」の2本だけ。(4)は0.91の高さに横線、(5)は(4)の値を濃度の式に入れる。
  • 答えの形の指定（小数第2位・小数第1位・整数・以上以下の○・点の名前）が多い。解く前に○を付けておく。
