1 (1)〈8〉 8の約数の逆数の和 A・4点｜約数と逆数

👀 まず見るところ

【条件文】部品は「すべての約数」と「逆数」。約数を小さい順に全部書き、1つずつ分子と分母をひっくり返す（直して書く）→ あとは通分してたすだけ。

📚 前提知識

  • 逆数は、分子と分母をひっくり返した数。2の逆数は 1/2。1の逆数は1のまま。
  • 例の〈6〉は、6の約数 1, 2, 3, 6 の逆数をたしている。1 も 6 も約数に入る。

  1. 8の約数を書く。1, 2, 4, 8 の4つ。
  2. 逆数にしてたす。1 ＋ 1/2 ＋ 1/4 ＋ 1/8。
  3. 分母を8にそろえる。(8＋4＋2＋1)/8 ＝ 15/8。帯分数に直すと 1 7/8。
  4. 落としやすい所は、1と8そのものを約数に入れ忘れること。

1 (2) 〈3240〉を求める B・7点｜約数の和（素数の積）

👀 まず見るところ

【条件文】部品は「〈3240〉」。約数が多すぎて書き出せない → (1)と同じ「約数の和÷3240」に直して書く。約数の和は、3240を素数のかけ算に分けてから出す。(1)で 15×13 に気づいていれば手を付ける。

📚 前提知識

  • 72＝8×9 のとき、約数の和は (1＋2＋4＋8)×(1＋3＋9)。素数ごとにかたまりを作って、和どうしをかける。
  • 素数が3種類になっても同じ。かたまりが3つになるだけ。

🔍 整理して解く

  1. 3240を素数でわっていく。3240＝2×2×2×3×3×3×3×5。つまり 8×81×5。
  2. かたまりごとに約数の和を出す。
    かたまり約数和
    81, 2, 4, 815
    811, 3, 9, 27, 81121
    51, 56
  3. 3つの和をかける。15×121×6＝10890。これが3240の約数の和。
  4. 3240でわる。10890/3240 を約分する。10でわって 1089/324。9でわって 121/36。帯分数に直すと 3 13/36。
答え：3 13/36
コツ：約分は先にしておくと楽になる。15×121×6 と 8×81×5 を見くらべる。15と5をわると、上に3が残る。6と8をわると、上に3、下に4が残る。上の 3×3＝9 と下の81をわると、下に9が残る。121/(4×9)＝121/36。

2 (1) 番くるわせなしで準優勝できるチーム A・7点｜トーナメントの条件整理

👀 まず見るところ

【条件文】部品は「番くるわせがない」と「準優勝」。準優勝＝決勝戦で負けたチーム → 「Aがいない方の山でいちばん強いチーム」に直して書く。その山の残り3チームは、自分より弱いチームになる。

📚 前提知識

  • トーナメント表は、左の4わく（ア〜エ）と右の4わく（オ〜ク）の2つの山に分かれる。それぞれの山で勝ち残った1チームどうしが決勝戦をする。
  • 番くるわせがなければ、強いチームが勝つ。山の中でいちばん強いチームが決勝戦に出る。

🔍 整理して解く

  1. 優勝はいつもA。だからAは準優勝にならない。
  2. 準優勝は、Aがいない方の山でいちばん強いチーム。同じ山に、自分より弱いチームが3つ入る。
  3. 自分より弱いチームの数を表にする。
    チームBCDEFGH
    自分より弱いチーム6543210
    3つ以上ある○○○○×××
  4. Eはぎりぎり。F, G, H と同じ山に入れば準優勝になる。
  5. Fは、自分より弱いチームがGとHの2つだけ。同じ山に強いチームが1つは入るので、決勝戦まで行けない。G, H も同じ。答えは B, C, D, E の4チーム。
  6. 落としやすい所は、Aを数に入れてしまうこと。Aは優勝するので準優勝ではない。
答え：4チーム

2 (2) 番くるわせが1回だけのとき準優勝できるチーム A・7点｜トーナメントの条件整理

👀 まず見るところ

【条件文】部品は (1) と変わった「1回だけ起きる」に丸。(1)の4チームに、番くるわせ1回で新しく準優勝になれるチームを足す。A, F, G, H を1チームずつ調べる。

📚 前提知識

  • 番くるわせは「どれかの試合」で1回。決勝戦で起きてもよい。
  • 決勝戦に出るには、1回戦と2回戦の2回勝つ。弱いチームは、強い相手に当たるたびに番くるわせが1回いる。

🔍 整理して解く

  1. B, C, D, E は (1) のままでよい。関係のない試合（たとえばG対H）で番くるわせが起きても、準優勝は変わらない。
  2. A。決勝戦で番くるわせが起きると、Aが負けて準優勝になる。
  3. F。1回戦でGに勝つ。2回戦でAに番くるわせで勝つ。決勝戦でBに負ける。これで準優勝。
  4. G。1回戦でHに勝つ。2回戦で強いチームに番くるわせで勝つ。決勝戦で負ければ準優勝。
  5. H。1回戦の相手はHより強い。2回戦の相手もHより強い。番くるわせが2回いるので、決勝戦に出られない。
  6. 準優勝になれるのは A, B, C, D, E, F, G の7チーム。落としやすい所は、Aを足し忘れること。
答え：7チーム

2 (3)① トーナメント表の割りふり方は何通りか B・5点｜場合の数（組分け）

👀 まず見るところ

【条件文】部品は「1回戦の対戦の組み合わせ」と「2回戦で考えられる対戦の組み合わせ」が同じなら同じもの、という決まり。左右を入れかえても同じ → Aの場所を1つに決めて数える（直して書く）。図2〜図6で決まりが飲みこめたら手を付ける。

📚 前提知識

  • 6チームから2チームを選ぶ選び方は、6×5÷2＝15通り。順番を区別しないので2でわる。
  • 図2と図5は、左の山と右の山を入れかえただけ。だから同じもの。図6は、Aの山に入るチームがちがうので別のもの。

🔍 整理して解く

  1. 1回戦の4試合を、左から Ⅰ, Ⅱ, Ⅲ, Ⅳ とする。AはⅠに入れると決める。入れかえても同じものになるので、こう決めてよい。
  2. Ⅰに入る、Aの相手を選ぶ。残り7チームから1つで 7通り。
  3. Ⅱに入る2チームを選ぶ。残り6チームから2つで 6×5÷2＝15通り。
  4. 残った4チームを、ⅢとⅣに2チームずつ分ける。Ⅲの選び方は 4×3÷2＝6通り。ⅢとⅣは入れかえても同じなので、6÷2＝3通り。
  5. かけ算する。7×15×3＝315。
答え：315通り
コツ：最後の「÷2」が決め手。たとえば残りが E, F, G, H のとき、「ⅢがE対F、ⅣがG対H」と「ⅢがG対H、ⅣがE対F」は同じもの。

4 (1) ひし形に入った円とAH：HD A・8点｜30°・60°・90°の三角形

👀 まず見るところ

【条件文】部品は「ひし形」と図の「60°」。対角線をひいて円の中心Oを図に置き、角に30°と60°を書く → 正三角形を半分にした形が2つ見えて、辺の比1：2が使える。

📚 前提知識

  • 30°・60°・90°の直角三角形は、正三角形を半分にした形。いちばん短い辺といちばん長い辺の比は1：2。1辺4cmの正三角形を半分にすると、短い辺は2cm、長い辺は4cm。
  • ひし形の対角線は、角を半分に分ける。2本は直角に交わる。
  • 円と辺がくっつく点と中心を結ぶと、辺と直角に交わる。

🔍 整理して解く

  1. 対角線ACとBDをひく。交わる点が円の中心O。OとHも結ぶ。OHは辺ADと直角に交わる。
  2. 角に度数を書く。角Aは60°で、対角線ACが半分に分ける。角OADは30°。となりの角Dは 180−60＝120°で、対角線BDが半分に分ける。角ODAは60°。
  3. 三角形ODHを見る。角Hが90°、角Dが60°。正三角形を半分にした形。HDを①とすると、ODは②。
  4. 三角形AODを見る。角Oが90°、角Aが30°。これも正三角形を半分にした形。いちばん短い辺がOD、いちばん長い辺がAD。ODが②だから、ADは④。
  5. AHは ④−①＝③。AH：HD＝3：1。落としやすい所は最後の比。AH：AD の3：4を書かない。聞かれているのはAHとHD。
答え：3：1

5 角Bを1：2に分ける直線BDの作図 C・9点｜作図（15°を作る）

👀 まず見るところ

【条件文】本番では後回し。部品は「辺BCと辺ACの長さが等しい直角三角形」と「1：2」。角Bの45°を1：2に分け、15°と30°に直して書く → BCから15°の線を作図する問題と決まる。

📚 前提知識

  • 正三角形はコンパスだけでかける。角は60°。直角のとなりにかくと 90＋60＝150°。二等辺三角形のてっぺんが150°なら、残りの角は (180−150)÷2＝15°ずつ。

🔍 整理して解く

  1. ACを1辺とする正三角形を、三角形ABCの外側にかく。Aを中心に、半径ACの円の一部をかく。Cを中心に、同じ半径の円の一部をかく。交わった点をEとする。
  2. BとEを定規で結ぶ。この直線がBD（ACと交わる点がD）。直線の近くに「P」と書く。
  3. 確かめ。角BCEは 90＋60＝150°。CBとCEは同じ長さだから、三角形CEBは二等辺三角形。角CBEは (180−150)÷2＝15°。残りの角DBAは 45−15＝30°で、1：2になっている。
答え：解説の図を参照のこと。（ACを1辺とする正三角形ACEを外側にかき、BとEを結んだ直線）

6 (1) 側面の三角形に入った正方形の1辺FG A・8点｜三角形の中の正方形（相似）

👀 まず見るところ

【条件文】部品は「四角形FHIGが正方形」と図2の「12cm」「10cm」。面ACDを正面から見た図をかき、数字を置く → すみの直角三角形の辺の比12：5で、正方形の1辺が決まる。

📚 前提知識

  • 同じ形の直角三角形は、直角をはさむ2つの辺の比が同じ。大きい三角形が12：5なら、小さい三角形も12：5。

🔍 整理して解く

  1. 面ACDを正面から見た図をかく。CDの真ん中をLとする。ALは12cm。LDは 10÷2＝5cm。
  2. 三角形ALDと三角形GIDを見くらべる。どちらも直角三角形で、角Dが同じ。同じ形。AL：LD＝12：5だから、GI：ID＝12：5。
  3. 正方形の1辺GIを⑫とする。IDは⑤。左のCHも⑤。CDは ⑤＋⑫＋⑤＝㉒。
  4. ㉒が10cm。FGは⑫だから 10×12/22＝60/11＝5 5/11cm。落としやすい所はCDの長さ。⑤は左右に2つあるので、⑫＋⑤＝⑰にしない。
答え：5 5/11cm

6 (2) 三角柱FJH-GKIは四角すいの何倍か B・8点｜真横から見た図・高さを□とおく

👀 まず見るところ

【条件文】部品は「三角柱FJH-GKI」と「何倍」。CからDの向きに真横から見た図をかき、四角すいの高さを□cmに直して書く → 三角形FJHの高さが□の5/11と分かり、□は最後に消える。(1)が出ていれば手を付ける。

📚 前提知識

  • 三角柱の体積は 底面積×高さ。この三角柱は、三角形FJHが底面で、FGが高さ。
  • 分からない長さは□と書いて進める。「何倍」のわり算で□は消える。たとえば (6×□)÷(2×□)＝3。

🔍 整理して解く

  1. 立体を、CからDの向きに真横から見た図をかく。四角すいは底辺10cmの三角形に見える。HとIは重なる。CDの真ん中のLも同じ点に重なる。JとKも重なる。右のななめの辺は(1)のALで12cm。Fは、その辺の上でHから60/11cmの所。
  2. Aの真下の点をO、Fの真下の点をPとする。AOを□cmとする。この図の上で、Aのある大きい直角三角形と、Fのある小さい直角三角形は同じ形。ななめの辺は12cmと60/11cm。比は 12：60/11＝11：5。だからFPは □×5/11（cm）。
  3. 三角形FJHの面積を出す。底辺JHは10cm。高さはFP。
    10×□×5/11÷2＝□×25/11（cm²）
  4. 三角柱の体積を出す。高さはFGの60/11cm。
    □×25/11×60/11＝□×1500/121（cm³）
  5. 四角すいの体積を出す。
    10×10×□÷3＝□×100/3（cm³）
  6. 三角柱を四角すいでわる。□は消える。
    1500/121÷100/3＝1500/121×3/100＝45/121（倍）
答え：45/121倍

4〜6 まとめ 図形の入口

  • 60°や30°が見えたら、正三角形を半分にした形をさがす。辺の比1：2が使える（4）。
  • 立体は、面を1つ正面から見た図にかき直す。三角形の中の正方形は、すみの直角三角形の比で決まる（6(1)）。
  • 高さが出ない立体の「何倍」は、高さを□と書いて進める。最後のわり算で消える（6(2)）。
