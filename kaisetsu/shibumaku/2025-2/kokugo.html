一 この回の全体像（大問一） A 30点／B 19点／C 0点｜説明文

宮内泰介『社会学をはじめる　複雑さを生きる技法』

話題は「社会の複雑さは二重になっている」。一つ目は外形的な複雑さ（制度・グローバルとローカル・価値観が入り組み、時代とともにふくらんできた）で、牛乳が例。二つ目は「意味」の複雑さ（人それぞれの意味世界が折り重なり、次の瞬間には変わる）で、二〇メートル先の十人・ジーンズ・近寄って聞く二人の会話が例。問3は一つ目、問4〜問6は二つ目から出ている。

キーワードは「意味」。この文章では「意味」＝人間どうしの「関係」（仲がよい・上司と部下）のことで、「高さ」「服の色」のような物理的なものと対比されている。この対比を押さえると問4・問5が一気に決まる。

取り方: Aの問1・問2・問4・問5・問7（30点）を先に確実に。記号は本文で「意味＝関係」「多義性の定義」を決めてから選択肢を見ると迷わない。問6は傍線の直前に定義の文があるので、Bでも取りにいく。問3の13点は指示語「このような」の中身を第3段落と傍線直前の段落から集めれば書ける。受験者平均61.5点、合格者平均68.6点（100点満点）。

一 問1 一戸・汚濁・粗・謝 A・12点｜知識問題

(a)「一戸あたりの牛の数」は「いっこ」。一世帯の家、という意味。「ひとと」とは読まない。(b)「水質オダク」＝汚濁。よごれてにごること。「濁」は「にごる」で、さんずいを忘れやすい。(c)「意味はアラくしか読み取れません」＝粗。音読みは「ソ」で「粗悪」「粗大」。きめがあらく細かくない、の意味なので「荒（あれる）」ではない、と私は区別した。(d)「ちゃんとアヤマったほうがいい」＝謝。音読みは「シャ」で「感謝」「謝罪」。「誤（まちがえる）」と取りちがえない。相手が「ありがとう」と返す会話なので、あやまる＝謝罪の場面と読める。
答え：(a)いっこ・(b)汚濁・(c)粗・(d)謝

一 問2 「話に耳をそばだてる」の意味 A・3点｜知識問題

「耳をそばだてる」＝聞き取ろうとして、注意して耳をかたむける。本文でも「近寄って、話に耳をそばだてる」→「そうやって近づいて、言葉が耳に入ってくると」と続き、自分から聞こうとする動作になっている。だからイ「よく聞こうとして話に注意を向ける」。アの「関心を持って熱心に」は「熱心さ」が語の意味に含まれない余分な要素、ウ「聞いていると装う」・エ「かくれてこっそり」・オ「たまたま耳に入る」は「注意して聞こうとする」動作そのものから外れる、と私は切った（声教は正解の意味だけを示している）。
答え：イ

一 問3 「外形的な、時代とともにふくらんできた複雑さ」とは B・13点｜説明型（記述・5行）

👀 ① 聞き方

問いの最後は「どのような『複雑さ』か。説明しなさい」→ 説明型。文末は「〜複雑さ。」または「〜ということ。」。傍線の「このような」が指す中身は第3段落と傍線の直前の段落にまとめの形で書いてあるので、そこを写して組めば5行を埋められる。時間をかける価値がある問題。13点なので部品は3〜4個。

📚 ② 傍線を切る

  • 「このような複雑さ」／「外形的な」／「時代とともにふくらんできた」の3つに切る。
  • 「このような」は指示語。指示語は直後をヒントにして前を見る（塾技12）。直後に「もう一つの複雑さは」…「『意味』の世界（意味世界）が一つでない、という複雑さです」と対になっているので、指すのは「社会の複雑さの一つ目」。第3段落の「いろいろな制度やしくみが入り組んでいる」「グローバルな問題とローカルな問題がからまりあっている」「人びとの価値観が多様」が中身になる。
  • 「時代とともにふくらんできた」は傍線の直前の段落の言いかえ。「昔より今のほうが、その度合いが増大している」「小さな共同体で生きていた人類が、巨大なグローバル社会を生みだすに至り」「お金を介するつながり方、モノを介するつながり方、制度や情報を介するつながり方などが複層的に重なり合っています」。
  • 牛乳の話（酪農家・飼料・糞尿・流通）は具体例。具体例が出てきたらその前後の「まとめ」に着目（塾技16）し、答案にはまとめの言葉を使う。

✍️ ③ 部品を集める

  1. 部品A（何が）: 社会のいろいろな制度やしくみ、グローバルな問題とローカルな問題、多様な価値観といった入り組んだ関係（第3段落）。
  2. 部品B（いつ・どう変わる）: グローバル化の進行とともに（「巨大なグローバル社会を生みだすに至り」の言いかえ）。
  3. 部品C（どのように）: お金、モノ、情報などを介して世界中で複層的に重なり合い（傍線直前の段落）。
  4. 部品D（結び）: ますますこみいったものになっている、ということ。字数の多い記述はコアを決めてから肉付けする（塾技88）。コアは「入り組んだ関係が、複層的に重なり合っている」で、A→B→C→Dの順に並べる。
模範解答：社会のいろいろな制度やしくみ，グローバルな問題とローカルな問題，多様な価値観といった入り組んだ関係が，グローバル化の進行とともに，お金，モノ，情報などを介して世界中で複層的に重なり合い，ますますこみいったものになっているということ。
迷いやすいところ：「外形的な」を「外から見える」と説明したくなるが、模範解答はこの語を言いかえず、中身（制度・問題・価値観）と変化（グローバル化・複層的に重なる）で答えている。もう一つ、牛乳の例を書き始めると具体例で欄が埋まる。酪農家や糞尿の話は入れず、第3段落のまとめの言葉に置きかえる。

一 問4 「社会は『意味』で構成されています」の説明 A・5点｜説明型（記号）

👀 ① 聞き方

問いの最後は「その説明として最も適当なもの」→ 説明型。傍線の直後（同じ段落）に「それが社会です」で終わる定義の一文があるので、選択肢を見る前にそこで部品を決める。

📚 ② 傍線を切る

  • 「社会は」／「『意味』で」／「構成されています」。「意味」は抽象語なので本文の言いかえで置きかえる（塾技77）。
  • 傍線の直後。否定側＝「物理的なモノや物理的な人間が存在するだけでは『社会』にはなりません」。定義側＝「物理的なモノや、モノとモノの関係について、言語を媒介に何らかの『意味』でとらえる人間という存在がいて、その意味や言語を媒介にお互いに関係をもちあうようなしくみ、それが社会です」。
  • 部品は3つ。(1)人間が言語を媒介にモノやモノとモノの関係を「意味」でとらえる (2)その意味や言語を媒介にお互いに関係をもちあう (3)そのしくみが社会。

🔍 ③ 部品で選択肢を切る

選択肢をパーツに分けて部分ごとにチェックする（塾技52）。3つの部品がそろっているものを残す。

選択肢切り方
ア「物理的なモノや、モノとモノの関係に言語を媒介にして『意味』を見出し」＝部品(1)、「互いに関係をもちあうことで」＝部品(2)、「社会は構築される」＝部品(3)。3つそろう → 答え
イ「二重の複雑さを解消する」が本文に無い。筆者は意味の世界を「もっと複雑」と言っていて、解消するとは言わない（言いすぎ・本文に書かれていない（塾技55））
ウ「一致した場合に限って」が本文と逆。AさんとBさんの意味の世界は「共通する部分もありますが、相違する部分もあり」、それでも社会（言いすぎ（塾技55））
エ「社会という抽象的な言葉ではなく」「具体的な言葉によって考えた方がよい」は、傍線の「意味で構成されている」の説明になっていない（問いにきちんと答えていない（塾技57））
オ「物理的な人間や物理的なモノとは徐々に関係を失っていく」が本文に無い。本文は物理的なモノやその関係を「意味」でとらえる、と言っていて、物理から切れるとは言わない（本文に書かれていない（塾技55））
答え：ア
コツ：声教はアの根拠（直後の定義の文）だけを示している。イ〜オは私が「解消」「一致した場合に限って」「関係を失っていく」を本文に無い言葉として切った。傍線の直後に「それが〜です」の定義があるときは、そこが正解の設計図になる。

一 問5 「社会」に注目している例として適当でないもの A・5点｜説明型・適当でないもの（記号）

👀 ① 聞き方

問いは「例として適当でないものを一つ」。設問の「でない」に印を付ける（塾技49）。傍線③「『社会』に注目している」とは何かを直後の段落で決め、「関係まで読んでいるか／見た目で止まっているか」のものさしを作ってから選択肢を見る。

📚 ② 傍線を切る

  • 傍線を含む一文は「それはまだ『社会』に注目しているとは言えません。ただ『高さ』という物理的なものに注目しているにすぎません」。つまり物理的なもの（高さ）に注目＝社会に注目していない。
  • 次の段落で反対側。「お互いに向き合っている」「話しているふう」「喧嘩しているふう」に注目したら「『意味』に注目した、つまりは、『社会』に注目した」。この「意味」は「人間としての関係、たとえば、仲がよいのか悪いのかとか、上司と部下なのかとか」。
  • さらに、ジーンズの例のように「彼らの生活習慣が似通っている」と読み取るのも「意味」に入る。ものさし＝見たものから人間どうしの関係や背景を読み取っているか。

🔍 ③ 部品で選択肢を切る

本文の内容をもとに解くのが大原則（塾技50）。各選択肢を「見たもの → 読み取ったこと」に分け、読み取りが「関係・背景」なら社会に注目、「色・形」で止まれば注目していない。

選択肢見たもの → 読み取ったこと
ア同じ色のユニフォーム → 同じチームの選手。チームという「関係」を読んでいる → 社会に注目
イ人びとの服 → 様々な色がある。「色」という物理的なもので止まっていて、「高さ」と同じ → 社会に注目していない → 答え
ウ手をつなぐ大人と子ども → 親子。「関係」を読んでいる → 社会に注目
エ長々と噂話をしている二人 → 仲が良い。近寄って言葉を聞き「二人の間の信頼関係」が見えてくる、という本文の例と同じ → 社会に注目
オ友人が美術に詳しい → 親子でよく美術館に行ったから。ジーンズから「生活習慣が似通っている」と読むのと同じ型で、背景を「意味」として読んでいる → 社会に注目
答え：イ
コツ：声教はイが「単なる視覚的な情報であって、『関係』をとらえることにまでふみこんでいない」と切る根拠だけを示している。ア・ウ・エ・オが社会に注目している側だという仕分けは私が本文の例（向き合う・話す・ジーンズ・会話を聞く）に当てはめて確かめた。

一 問6 「世界は多義性に満ち満ちています」と言える理由（二つ） B・6点｜理由型・二つ（記号）

👀 ① 聞き方

問いの最後は「なぜ…と言えるのか。その理由の説明として適当なものを二つ」→ 理由型。傍線の直前に「〜を『多義性』と呼ぶならば」という定義の一文があり、その定義が二つの中身でできている。この二つがそのまま二つの理由になるので、Bでも取りにいく価値がある。

📚 ② 合図を探す

  • 「原因・理由」と「結果」はペアで読む（塾技17）。傍線の直前「同じものごとが人びとの間で違った意味をもつこと、あるいは、一人の個人の中でも違った意味をもつことを『多義性』と呼ぶならば」→ 結果が「世界は多義性に満ち満ちています」。
  • 理由(1)＝人びとの間で意味が違う。一つ前の段落「意味の世界は、一人ひとりがそれぞれで意味をもっている、多重な世界」「Aさんが見ている意味の世界（意味世界）とBさんが見ている意味の世界とは、共通する部分もありますが、相違する部分もあり」。
  • 理由(2)＝同じ人の中でも意味が変わる。傍線を含む段落「その複雑に入り組んだ多重な『意味』は、次の瞬間には変化しています」「意味は、空間的にも時間的にも多重性をもっていて」。

🔍 ③ 理由で選択肢を切る

本文で決めた理由(1)(2)を物差しに、選択肢をパーツに分けて部分ごとにチェックする（塾技52）。

選択肢切り方
ウ「言葉を媒介にして見ている世界は一つではなく」「共通する部分もあれば相違する部分もある」＝理由(1)そのまま → 答え
オ「当初とらえた『意味』は一瞬一瞬の時間の経過とともに変化していく」＝理由(2)「次の瞬間には変化」「時間的にも多重性」 → 答え
ア「多様な背景を持つ存在だから」「関係には様々なあり方が存在する」が本文に無い。多義性は関係の種類の多さではなく、同じものごとの意味が違うこと（本文に書かれていない（塾技55））
イ「事実に基づく必要がない」「勝手に生み出せる」が本文と逆。筆者は「観察しているあなたが勝手に作り出そうとしている『意味』ではなく、彼ら自身が認識している『意味』」と言う（言いすぎ（塾技55））
エ「様々なものごとは複雑なしかたでつながって」は一つ目の外形的な複雑さの話で、多義性（二つ目の複雑さ）の理由になっていない（問いにきちんと答えていない（塾技57））
答え：ウ・オ
コツ：声教はウ・オの根拠（人びとの間で違う意味／個人の中でも時間とともに変わる）だけを示している。ア・イ・エは私が切った。二つ選ぶ問題は、先に本文で理由を二つ決めてから選択肢に当てはめると、選ぶ数を数えながら迷わずにすむ。

一 問7 本文の構成 A・5点｜本文の構成（記号）

👀 ① 聞き方

問いは「本文の構成について説明したものとして最も適当なもの」→ 表現の特色を問う問題（塾技59）。構成＝主張と例の並び方。この文章は「筆者の考えを言う → 身近な例で説明する」を二回くり返している。この骨組みに合う選択肢を残す。

📚 ② 本文の流れを先に決める

  • 一回目: 主張「社会は複雑で、複雑さが二重になっている」→ 例＝牛乳（酪農家・飼料・糞尿・流通・食文化）→ まとめ「外形的な、時代とともにふくらんできた複雑さ」。

一 まとめ この回で繰り返し出た入口

  • キーワード「意味」は人間どうしの「関係」のことで、「高さ」「色」のような物理的なものと対比されている（問4・問5）。抽象語は本文の言いかえで置きかえてから選択肢を見る。
  • 「このような」「〜と呼ぶならば」のように、指示語と定義の一文が答えの材料になっている（問3・問6）。指示語は直後をヒントにして前を見る（塾技12）。
  • 記号は、声教が正解の根拠しか書いていない問が多い。誤答は「本文に無い言葉（解消・一致した場合に限って・勝手に）」を見つけて切る（塾技55）。この回は言いすぎ・本文外のパターンがほとんどだった。

問8知識（文学史）A・4点島木健作1903年生まれ → それより前の作家

取り方: Aの問1・2・3・8（24点）を先に確実に。Bの記号（問4・問7）は「〜とは異なって」「それ」を切ってから選択肢へ。記述2問は根拠が傍線のすぐそばにあるので、部品を3つそろえて8割の行数を埋める。受験者平均61.5点・合格者平均68.6点。

二 問1 漢字の読み書き（a）〜（d） A・12点｜知識問題

(a)「漁り」は訓読みで「あさ（り）」。ゴミためを探しまわる、の意味。音読みはリョウ・ギョ（漁師・漁業）。(b)「ユズらなかった」は「譲」。音読みはジョウ（譲歩）。(c)「値する」は「あたい（する）」。音読みはチ（価値）。訓読みには「ね」もある。(d)「タガヤして」は「耕」。音読みはコウ（農耕）。
答え：(a)あさ・(b)譲・(c)あたい・(d)耕

二 問2 「尾羽うち枯らしている」の意味 A・3点｜知識問題

「尾羽うち枯らす」は、鳥の尾と羽がぼろぼろになる様子から、落ちぶれてみすぼらしい姿になること。知らなくても本文が助けてくれる。直後に「かつて主人持ちであったものがことにひどい」「落ちぶれ方がみじめなのである」と続くので、「落ちぶれ」を含むアが決まる。イ「品行がいやしく」は行いの話で姿の話ではなく、ウ「地味」・エ「じっとしている」・オ「意気消沈」は、毎日根気よく庭先をうろうろする犬猫の様子と合わない（別紙は正解の根拠だけを示している。イ〜オは私が本文の様子と照らして切った）。
答え：ア

二 問3 母が犬猫を一番憎んでいる理由 A・5点｜理由型・記号

👀 ① 聞き方

問いの最後は「それはなぜか」→ 理由型。傍線①の直後に「畑を踏み荒すからである」と理由が書いてある。ただし「なぜ畑がそこまで大事か」は後半の「病人の息子に新鮮な野菜を与えたいだけの一心」まで読まないと決まらない。

📚 ② 合図を探す

  • 「原因・理由」と「結果」はペアで読む（塾技17）。傍線①「彼等を一番憎んでいるのは母であった」の直後、「庭の畑作りは母の為事であり、彼等は畑を踏み荒すからである」の「〜からである」が第一の合図。
  • 畑作りの目的は二つ目の（中略）の前の段落にある。母が立木を刈ったのは「自分が作っている菜園に陽光を恵まなければならない」から、そして「病人の息子に新鮮な野菜を与えたいだけの一心だった」。畑＝息子の療養のため、と決まる。

🔍 ③ 理由で選択肢を切る

  1. 本文で決めた要素は二つ。「畑を踏み荒らす」＋「畑は病気の息子のため」。この二つが入った選択肢だけ残す。
  2. 選択肢をパーツに分けて部分ごとにチェック（塾技52）。ア「母が畑で育てた野菜だけ」「家族が飢える」→ 配給物も塩鮭もあるので言いすぎ・本文に書かれていない（塾技55）。イ「販売」→ 本文に無い。ウ「趣味」→ 「為事」「一心」と正反対。オ「台所に侵入しては食べ物を奪っていく」→ 傍線①のあとの場面でも「何も取られたことはないかい？」「いいえ、まだ何も。」とあるうえ、憎む理由は畑の話なので理由がずれている。
  3. エ「病気の息子の健康のために新鮮な野菜を食べさせようと母は畑を作っており、犬猫に野菜を踏まれると困るから」→ 二つの要素がそろう。別紙は正解の根拠だけを示している。ア〜ウ・オの切り方は私が本文と照らして書いた。
答え：エ
コツ：理由が「〜からである」で直後にあっても、その理由の背景（なぜ畑が大事か）まで問うのが渋幕。合図を見つけたら、同じ話題がもう一度出る場所を探す。

二 問4 「世が世なら、飼ってやってもいい」と思った理由（二つ） B・6点｜理由型・記号・複数選択

👀 ① 聞き方

「それはなぜか…適当なものを二つ」→ 理由型・二つ選ぶ。傍線②の前2段落が根拠で、「犬とちがって」と「病気の私とちがって」の二つの対比から黒猫の魅力が語られている。選択肢はどれも「〜とは異なって、『黒猫』は…」の形なので、後半の黒猫の描写が本文どおりかだけ先に見れば時間はかからない。手を付ける価値がある。

📚 ② 合図を探す

  • きっかけの出来事→気持ち→行動の順（塾技22）。傍線②の直前は「いやに堂々とした奴だなあ。」と私は感心した → 「たまには何か食わせてやれよ」→ 飼ってもいいとさえ思った。気持ちは「感心」。
  • 感心の中身は前の段落。「人間と真正面に視線が逢っても逃げなかった」「家のなかに這入って来はしなかった」「がつがつしている風も見えない」「台所のものなども狙わぬらしい」。その前の段落では体の大きさと「いかにも男性の象徴という感じ」。対比の相手は「尾など振って近づいてくる」「よろけるように逃げてゆく」犬と、「一日に十五分ぐらいは庭に出られる」病気の私。

🔍 ③ 理由で選択肢を切る

  1. 「二つ」に印（塾技49）。残す数を先に決めてから消去法（塾技54）。
  2. ア「平気で家の中に侵入して食べ物を狙い、座蒲団の上で寝る」→ これは他の猫の様子（「コソ泥以上に図々しく」の段落）。黒猫は「家のなかに這入って来はしなかった」ので人物の取り違え → ×。
  3. エ「可哀想だったから」→ 毛の色を見て「野良猫に成り下る運命にしかなかったかと思わせる」とあるだけで、あわれんではいない。気持ちの向きが合わない → ×。オ「殺される前に保護してやりたい」→ この時点で黒猫の死は考えていない → 本文に無い ×。カ「生命力の強さを分け与えてもらいたい」→ 描かれていない ×。さらに「餓えもせずに」は本文の「餓えているにちがいなかろうが」と逆（この点は別紙に無く、私が切った）。
  4. 残ったイ（犬との対比・こびない・おそれない・勝手に入らない）とウ（私との対比・立派な肉体・目が合っても見返す・悠然と歩く）は本文どおり → 答え。
答え：イ・ウ

二 問5 黒猫に嫌疑をかける者がいなかった理由 B・8点｜理由型・記述

👀 ① 聞き方

「それはなぜか。説明しなさい」→ 理由型の記述、文末は「〜から。」。傍線③は否定形「誰もなかった」なので、「本当は黒猫が犯人なのに、そう思えなかったのはなぜか」と裏返す。根拠は事件の前、黒猫を紹介した段落の「台所のものなども狙わぬらしい」。8点なので部品は3つ。

📚 ② 合図を探す

  • 「原因・理由」と「結果」はペアで読む（塾技17）。傍線③の直前「うろついている猫は多かったからどれともきめることはできなかった」は「誰か分からない」理由。「黒猫だけは疑わない」理由は別の場所、黒猫の日ごろの様子にある。
  • その様子は「餓えているにちがいなかろうが、がつがつしている風も見えない。台所のものなども狙わぬらしい」と「いつでも重々しくゆっくりと歩く」。しかも見ていたのは私だけではなく、家のものが「いいえ、まだ何も。」と答えている＝家族みんなが同じ印象を持っていた。

✍️ ③ 原因→結果の向きを確かめる

  1. 部品A: 黒猫は台所のものを狙うそぶりも見せなかった（本文「台所のものなども狙わぬらしい」）。
  2. 部品B: 堂々としていて、がつがつした様子がなかった（「いやに堂々とした奴だなあ」「がつがつしている風も見えない」）。
  3. 部品C: それを家族全員が見ていて、家に入りこむはずがないと思いこんでいた（「誰も」に対応する部品。「まだ何も」と答えたのは家のもの）。
  4. 見つけた理由が傍線とつながるか確認し、文末は「〜から」（塾技76）。「〜そぶりもなかった黒猫の堂々たる様子を家族全員が見ており、家に入りこんでくるはずがないと思いこんでいたから。」
模範解答：台所のものをねらうそぶりもなかった黒猫の堂々たるようすを家族全員が見ており，家に入りこんでくるはずがないと思いこんでいたから。
コツ：「猫は多かったから」だけを書くと、「誰も黒猫を疑わなかった」理由になっていない（問いに答えていない）。黒猫の側の事情を書く。

二 問6 「私はすぐには眠れなかった」理由 B・8点｜理由型・記述

👀 ① 聞き方

「それはなぜか。説明しなさい」→ 理由型の記述。傍線④の直後（同じ段落）に「痛快」「歎称」「鳴声ひとつ立てなかった」と理由が並ぶ。落とし穴は「意外」「裏切られた」で、本文が「そういう気はしなかった」と打ち消している方を書かないこと。部品は3〜4つ。

📚 ② 合図を探す

  • 「原因・理由」と「結果」はペアで読む（塾技17）。直後「やはりあいつであったということが私を眠らせなかった」が結果側の言いかえ。そのあと「そう意外だったという気もしなかったし、裏切られたという気もしなかった」で否定し、「何だか痛快なような笑いのこみあげてくるような気持だった。それは彼の大胆不敵さに対する歎称であったかもしれない」で本当の気持ちを言う。
  • さらに「そういえばあいつははじめから終りまで鳴声ひとつ立てなかったじゃないか」。捕まるときも鳴かなかったことへの感心が加わる。
  • 「常々好ましく思っていた」は、前の場面の「私は感心した」「たまには何か食わせてやれよ」「飼ってやってもいいとさえ思った」から。

✍️ ③ 原因→結果の向きを確かめる

  1. 部品A: 日ごろから好ましく思っていた黒猫が（前提）。
  2. 部品B: 大胆にも家に押し入った（「大胆不敵」）。
  3. 部品C: 捕まるときも鳴き声ひとつ立てなかった。
  4. 部品D: それに感心し、痛快で目がさえた（「痛快」「歎称」→ 眠れない、へ向きをそろえる。塾技76）。
模範解答：常々，好ましく思っていた黒猫が，大胆にも家に押し入り，捕まるときも鳴き声ひとつ立てなかったことに感心し，痛快で目がさえてしまったから。
コツ：心情語は本文の「痛快」「歎称（感心）」をそのまま使う。「意外で眠れなかった」「裏切られてくやしかった」は本文が否定しているので0点に近い。

二 問7 「私の病気のように退屈で愚劣だった」の説明 B・5点｜説明型・記号

👀 ① 聞き方

「どういうことか」→ 説明型。傍線⑤には指示語「それ」と比喩「私の病気のように」がある。「それ」＝直前の「卑屈な奴等だけがのそのそ這いまわっていた」、比喩は「いつになったらなおるかわからぬ」病気の自分に重ねている。この「犬猫の様子＝病気の私」の重なりが入った選択肢を探す。

📚 ② 傍線を切る

  • 「それは／いつになったらなおるかわからぬ私の病気のように／退屈で愚劣だった」。指示語は直後をヒントにして前を見る（塾技12）→ 「黒猫はいなくなって、卑屈な奴等だけがのそのそ這いまわっていた」。
  • 比喩は別の言葉に言いかえる（塾技77）。「なおるかわからぬ病気のよう」＝先の見えないまま、だらだらと続く。直後の「私は今まで以上に彼等を憎みはじめた」が、自分の姿を重ねたからこその感情。
  • 対比の両側を書く（塾技80）。黒猫＝「一国一城のあるじ」「落ちぶれても決して卑屈にならない」／犬猫＝「諂い虫の仲間」。黒猫が死んだ今、残ったのは卑屈な側だけ。

🔍 ③ 部品で選択肢を切る

  1. 要素は三つ。①卑屈な犬猫の様子 ②病気で先の見えない私と重なる ③黒猫の死後、いっそう見苦しい（憎み始めた）。
  2. ア「勇敢な母に比べて」→ 傍線が比べているのは母ではなく私の病気。比べる相手が本文に無い（塾技55）。イ「無駄な努力をしていてばからしい」「太く短く生きた」→ 本文に無い評価。ウ「世の中の象徴」→ 傍線は犬猫の様子を言っているのに、世の中の話にすりかわっていて問いに答えていない（塾技57）。エ「老人の母と」「小心者の妻と」「『私』ばかりがだらだらと生き残っている」→ 傍線の「それ」は犬猫の様子で、母や妻のことではない。指す相手の取り違え。
  3. オ「こびへつらって命をつなごうとする野良犬たちの様子は、病が治る見込みもないままに母に養われて…『私』と似通っており…『黒猫』が死んだ今となっては一層見苦しく情けない」→ 三つの要素がそろう。別紙は正解の根拠だけを示している。ア〜エの切り方は私が本文と照らして書いた。
答え：オ

二 問8 島木健作より前の時代の作家と作品 A・4点｜知識問題

島木健作は1903年生まれ・1934年デビュー。それより前に活動したのは明治の作家二人。樋口一葉（1872〜1896年）『たけくらべ』と、夏目漱石（1867〜1916年）『吾輩は猫である』。残りは戦後の作家で、三島由紀夫『金閣寺』、大江健三郎『万延元年のフットボール』、村上春樹『ねじまき鳥クロニクル』。作家と作品の組み合わせで答える。
答え：（作家，作品の順で）ウ，D／オ，A

二 まとめ この大問で繰り返し出た入口

  • 理由型が4問（問3〜6）。合図は傍線の直後の「〜からである」「〜が私を眠らせなかった」と、その理由の背景（畑は病人の息子のため／黒猫は台所を狙わない）がもう一度出る場所。
  • 記号は「〜とは異なって」「それ」の人物の取り違えで切れる（問4ア＝他の猫、問7ア・エ＝母や妻）。選択肢の後半だけ先に本文と照らす。
  • 記述は本文が否定している気持ち（「意外」「裏切られた」）を書かず、「痛快」「歎称」など本文の心情語をそのまま使う。
