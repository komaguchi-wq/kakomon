3 (1) 固体が析出し始めるまでに蒸発した水 A・3点｜溶解度の計算

👀 まず見るところ

表1の40℃の列。塩化ナトリウム36g、硫酸マグネシウム45g。混合液Aの18gと12gをそれぞれ「溶かしきるのに水が何g要るか」に言いかえると、先に足りなくなる方が析出し始める。

📚 前提知識

  • 溶解度は「水100gに溶ける限界」。溶けている量が同じなら、水が減るほど飽和に近づく。飽和をこえた分が固体として出る。
  • 問題文の指示どおり、2つの物質は互いに影響しない。1つずつ別々に計算してよい。

🔍 こう読み解く

  1. 塩化ナトリウム18gを40℃で溶かしておくのに必要な水 ＝ 100×18/36 ＝ 50g。
  2. 硫酸マグネシウム12gに必要な水 ＝ 100×12/45 ＝ 26.6… ＝ 約27g。
  3. 水を減らしていくと、先に50gで塩化ナトリウムが限界になる。だから析出し始めた時点の水は50g → 蒸発した水は 100−50＝50g。このとき先に出る固体は塩化ナトリウム。

3 (3)(4) 飽和水溶液の濃度と、水和物が出たあとの濃度 A・3点＋3点｜濃度の計算（水和物）

📚 前提知識

4 (1) 物体や虫めがねを変えたときの像の位置 A・8点｜作図の考え方（2本の光）

👀 まず見るところ

図4の2本の線。上の線が(i)平行→焦点、下の線が(ii)中心→直進で、いま交わっている点(キ)が像。変えたときに「どちらの線が動かないか」を決めれば、像は動かない方の線の上を移動する。

📚 前提知識

  • (i)の線は「物体の高さ」と「焦点の位置」だけで決まる。(ii)の線は「物体と中心を結ぶ向き」だけで決まる。
  • 問題文より、虫めがねが薄いと焦点距離は長く、厚いと短くなる。像は物体と上下逆に動く。

🔍 こう読み解く

  1. ① 物体を遠ざける（高さは同じ）→ (i)は変わらない。(ii)は中心から見た傾きがゆるくなる → 交点は(i)の線上で虫めがね側へ → カ。
  2. ② 物体を上へ → 像は逆に下へ動く。キの真下 → エ。
  3. ③ 薄くする → 焦点距離が長くなり右の焦点が右へ → (i)の傾きがゆるくなる。(ii)は変わらない → 交点は(ii)の線上でキより右 → イ。
  4. ④ 厚くする → ③の逆。(ii)の線上で虫めがねに近い → オ。落としやすいのは③④で「(ii)の線上」を選ぶこと。イとウ、オとカのどちらが(ii)の線か、図4で線を指でたどって確かめる。
答え：① カ　② エ　③ イ　④ オ

4 (2) 物体を近づけてもはっきり見える理由 A・3点｜水晶体の調節

👀 まず見るところ

「人がものを見る仕組み」の3つ目の●。「遠くの物体→水晶体が薄く調整される」。近づけるのはその逆なので、水晶体は厚くなる。厚い虫めがねは焦点距離が短い（大問4の冒頭の説明）。

📚 前提知識

  • 目は網膜の位置を動かせない。かわりに水晶体の厚みを変えて、光が網膜上で1点に集まるようにする。
  • 近い物体からの光は広がって入る → 強く曲げないと網膜に届く前に集まらない → 厚くして焦点距離を短くする。

🔍 こう読み解く

  1. ①：アイは「網膜が動く」なので×。近づける→厚くなる → ウ。
  2. ②：厚くなる → 焦点距離は短くなった → キ。
答え：① ウ　② キ

4 (3) 虫めがねの像を目で見る（作図・見え方・集まる位置） B・11点｜作図＋目のしくみ

👀 まず見るところ

図11と図12のちがいは目の位置。図11は像より外側に目がある＝像から広がった光が目に入る（図5と同じ、はっきり）。図12は虫めがねと焦点の間に目がある＝集まる途中の光が目に入る（図7と同じ、ぼやける）。時間をかける価値があるのは①②まで。③〜⑤は「図7の型」と決めてから。

📚 前提知識

  • 点Aから出た光は、虫めがねで曲がったあとすべて像の頂点を通る。だから目に入る光の道すじは「B（またはC）と像の頂点を結んだ直線」を面Sまで逆にたどり、そこからAへ結べばよい。
  • 広がって入る光は水晶体の調節で網膜に集まる（はっきり）。集まりながら入る光は調節しきれず水晶体と網膜の間で集まる（ぼやける）。像は上下左右が逆。

🔍 こう読み解く

  1. ①作図：Bと像の頂点（下向き矢印の先）を直線で結び、虫めがねの点線（面S）まで延ばす。その交点とAを直線で結ぶ。Cについても同じ。像の頂点を通る2本の折れ線になる（答えの図Ⅱ）。
  2. ②：図11の目には像から広がる光が入る → はっきり見える。像は上下左右が逆なので、りんごが左下に来たえ。
  3. ③：図12の目には集まる途中の光が入る → 図7のとおり水晶体と網膜の間で1点に集まる → 図13で網膜より手前のア。
  4. ④：点Dは物体の下端。像は逆さなので、Dからの光は像の上端へ向かう。水晶体の中心を通る光はそのまま上向きに直進し、③と同じく網膜の手前で集まる → 上側で手前のエ。
  5. ⑤：ぼやけて見える（図7）。像は逆さだが、目はふだんも網膜に逆さに映った像を正しい向きに感じている（図5）。だから見え方は物体を直接見たときと同じ向き → お。
答え：① 下の図Ⅱ　② え　③ ア　④ エ　⑤ お
コツ：①は「像の頂点を通す」の一言で決まる。定規で B→像の頂点→面S、C→像の頂点→面S の順に引く。
