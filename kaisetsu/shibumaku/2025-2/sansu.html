1 (1) 07を入力したときの出力 A・6点｜条件の整理

👀 まず見るところ

「07 → 十の位0、一の位7」と紙に書く → ①②③の順に手で計算する。問題文の例（15→64）で、自分の計算のしかたが合っているかを先に確かめる。

📚 前提知識

  • ①の「10でわった余り」は、和が10以上のときだけ10をひく。15なら 1＋5＝6 で6のまま。73なら 7＋3＝10 で余り0。
  • ②の「差」は、大きいほうから小さいほうをひく。15なら 5－1＝4。73なら 7－3＝4。

🔍 整理して解く

  1. ① 和は 0＋7＝7。10より小さいので、余りは7。十の位は7。
  2. ② 差は 7－0＝7。一の位は7。
  3. ③ 十の位7、一の位7をならべて 77。
  4. 確かめ。例の 15 は 6 と 4 で 64。同じやり方で合っている。
答え：77

1 (2) 2回入力して40になる最初の数 A・6点｜出力からもどす

👀 まず見るところ

「もう一度入力したら40」→ 40から2回もどす。出力の一の位は「差」だから、40の一の位0 ＝ 差が0 ＝ ぞろ目。ここから直前の数がしぼれる。100個を順に試すのは、時間がもたない。

📚 前提知識

  • 出力の十の位は「和を10でわった余り」。だから、もとの和はその数か、その数＋10のどちらか。十の位が4なら、和は4か14。
  • 出力の一の位は「差」そのもの。一の位が2なら、2つの数字の差は2。

🔍 整理して解く

  1. 40の直前の数を書く。差0でぞろ目、和が4か14。当てはまるのは 22 と 77。 
    40 の直前：差0（ぞろ目）・和4か14 → 22, 77
  2. 22の直前の数を書く。和が2か12、差が2。和2なら 0と2、和12なら 5と7。ならべ方は2通りずつ。 
    22 の直前：和2 → 02, 20
　　　　　　和12 → 57, 75
  3. 77の直前の数を書く。和が7か17、差が7。和7なら 0と7。和17で差7の数字の組はない（12と5になってしまう）。 
    77 の直前：和7 → 07, 70
　　　　　　和17 → なし
  4. 全部で6個。確かめ。57 → 和12で余り2、差2 → 22 → 和4、差0 → 40。合っている。
答え：02, 07, 20, 57, 70, 75
コツ：「出力からもどす」ときは、一の位（差）から先に決める。差が決まれば、2つの数字の組は和ごとに1つずつしかない。

1 (3) くり返しても記録がすべて同じになる最初の数 B・6点｜変わらない数をさがす

👀 まず見るところ

「記録された数はすべて同じ」→ 入力しても変わらない数をさがす。次に、記録に入らない「最初の入力」を(2)のやり方で1回もどす。(2)ができていれば5分で取れる問題で、時間をかける価値がある。

📚 前提知識

  • 入力しても変わらない数は、「十の位＝和の余り」「一の位＝差」がもとの数と同じ数。まず ぞろ目 や 一の位0 の数で試すと見つけやすい。
  • 記録されるのは「出力された数」。最初に入力した数そのものは記録に入らない。ここで答えが1個ふえる。

🔍 整理して解く

  1. 変わらない数をさがす。十の位は「十の位＋一の位」を10でわった余り。一の位が0でないと、十の位が変わってしまう。だから一の位は0。
  2. 一の位が0なら、差は十の位そのもの。出力の一の位は差だから、一の位0のままにするには十の位も0。変わらない数は 00 だけ。
  3. 最初の入力は記録に入らないので、1回目の出力が00ならよい。00の直前の数を(2)のやり方で書く。差0でぞろ目、和が0か10。 
    00 の直前：和0 → 00
　　　　　　和10 → 55
  4. 確かめ。55 → 和10で余り0、差0 → 00 → 00 → …。記録はすべて00で同じ。
答え：00, 55
コツ：「00だけ」で止まらない。記録に入るのは出力だけ、と設問の言葉を読み直すと55が出てくる。

1 (4) 2回出力した数の十の位に表れない数字 B・6点｜偶数・奇数で分ける

👀 まず見るところ

「100個の数すべて」→ 全部は計算しない。十の位と一の位を「偶数か奇数か」だけで分ける。和も差も、偶数か奇数かは同じ組み合わせで決まる → 4通りの表を2回たどる。表が4行で終わると見えたら手を付ける。

📚 前提知識

  • 偶＋偶＝偶、奇＋奇＝偶、偶＋奇＝奇。差も同じ決まり。たとえば 7 と 5 は和12・差2でどちらも偶数。
  • 10でわった余りをとっても、偶数か奇数かは変わらない。10は偶数だから。和12の余り2は偶数のまま。0は偶数として扱う。

🔍 整理して解く

  1. 十の位・一の位の偶奇の組を4通り書く。1回入力すると、十の位は「和の偶奇」、一の位は「差の偶奇」になる。和と差の偶奇は同じだから、出力はいつも同じ偶奇どうしの組になる。
  2. 4通りをそれぞれ2回たどる。 
    偶・偶 → 偶・偶 → 偶・偶
偶・奇 → 奇・奇 → 偶・偶
奇・偶 → 奇・奇 → 偶・偶
奇・奇 → 偶・偶 → 偶・偶
  3. 2回目の出力は、どれも十の位が偶数。だから十の位に奇数は表れない。
  4. 確かめ。(1)の 07（偶・奇）→ 77（奇・奇）→ 和14で余り4、差0 → 40（偶・偶）。表のとおり。
答え：1, 3, 5, 7, 9
コツ：「すべての数に対して」と言われたら、数そのものでなく「偶数か奇数か」「何でわった余りか」で仲間分けする。

2 (1)A・B 3個並べたときの(A)と(B)の数 A・3点×2｜1つ前に積み上げる

👀 まず見るところ

条件は「△が奇数個か偶数個か」だけ → 記号を「△」と「△以外（○か×の2通り）」の2種類で考える。図1・図2の2個の並べ方（4通り・5通り）に3個目を1つ足す。3個目に△を足すと、(A)と(B)が入れかわる。

📚 前提知識

  • △を1個足すと、△の個数が1ふえる。奇数個は偶数個に、偶数個は奇数個に変わる。○か×を足しても△の個数は変わらない。
  • (A)と(B)を合わせると、並べ方の全部になる。△の個数は奇数か偶数のどちらかだから。2個なら 4＋5＝9＝3×3。

🔍 整理して解く

  1. 2個の結果を書く。(A)は4通り、(B)は5通り。
  2. 3個目を足したときの行き先を4行で書く。 
    (A)4通り に ○か× → (A)のまま  4×2＝8
(A)4通り に △    → (B)になる   4×1＝4
(B)5通り に ○か× → (B)のまま  5×2＝10
(B)5通り に △    → (A)になる   5×1＝5
  3. (A)は 8＋5＝13通り。(B)は 10＋4＝14通り。
  4. 確かめ。13＋14＝27＝3×3×3。全部の並べ方と合う。
答え：(A) 13通り、(B) 14通り
コツ：樹形図を27本ぜんぶかいても数えられるが、○と×はまとめて「2通り」と数えると図が3分の1になる。

2 (2) 4個並べたときの(A)の数 B・7点｜1つ前に積み上げる

👀 まず見るところ

箱の中の考え方は「3個の並べ方に4個目を足す」→ (1)の13通りと14通りをそのまま使う。(A)に○か×、(B)に△を足すと(A)になる。(1)が合っていれば、かけ算とたし算だけで取れる。

3 (1) グラフの あ・い A・7点｜点の移動とグラフ

👀 まず見るところ

グラフの折れ目は、Pが頂点に着いた時刻 → 図1の辺に「BC 37cm→18.5秒、CD 20cm→10秒、DA 16cm→8秒」と書きこむ。頂点に着いた瞬間の三角形ABPが、あ・い・96のそれぞれに当たる。

📚 前提知識

  • 時間＝道のり÷速さ。BCの37cmを毎秒2cmで進むと 37÷2＝18.5秒。
  • 台形ABCDの中の三角形ABCと三角形ABDは、高さが同じ（台形の高さ）。だから面積の比は底辺の比 BC：AD＝37：16 と同じ。

🔍 整理して解く

  1. Pが動く順に、着く時刻を書く。 
    出発 B     0秒
C に着く   37÷2＝18.5秒   ← 面積がいちばん大きい（い）
D に着く   18.5＋10＝28.5秒 ← 面積96
A に着く   28.5＋8＝36.5秒  ← 面積0
  2. あ は Pが Cに着く時刻。あ＝37÷2＝18.5。
  3. い は三角形ABC。96は三角形ABD。高さが同じだから、面積の比は 37：16。
  4. い＝96×37÷16＝222。
  5. 確かめ。96÷16＝6 で、1cmあたり6cm²。37×6＝222 で合う。
答え：あ…18.5・い…222

3 (2) 面積が2回目に105cm²になる時刻 A・7点｜グラフの読み取り

👀 まず見るところ

「2回目」＝グラフの下り坂 → 105は222と96の間だから、PがCD上にいる 18.5秒〜28.5秒の間。この10秒で面積は222から96まで、一定の速さで減る。「1秒で何cm²減るか」を出す。

📚 前提知識

  • グラフがまっすぐな区間は、面積が毎秒同じだけ変わる。減った量÷かかった秒数＝1秒あたりの減り方。
  • 時間の答えは分数のまま。18.5は 18 1/2 と書いてから 分母をそろえる。

🔍 整理して解く

  1. CD上の10秒で減る量を出す。222－96＝126。1秒あたり 126÷10＝12.6cm²減る。
  2. 222から105まで減るのに必要な量は 222－105＝117。
  3. かかる秒数は 117÷12.6＝9 2/7 秒。（117÷12.6＝1170÷126＝65÷7）
  4. Cに着いた18.5秒に足す。18 1/2＋9 2/7＝27 11/14。 
    18.5秒(C・222) ─ 9 2/7秒 → 105 ─ → 28.5秒(D・96)
答え 18 7/14＋9 4/14＝27 11/14 秒後
  5. 確かめ。12.6×9 2/7＝12.6×65÷7＝117。222－117＝105 で合う。
答え：27 11/14秒後
コツ：「1回目」は上り坂（BC上）、「2回目」は下り坂。どの辺の上にいるかを先に決めてから計算に入る。

👀 まず見るところ

コツ：「ある点が辺の真ん中」＋「同じ長さのペア」が見えたら、その点のまわりに半回転させて図をつなぐ。

5 (1) 三角すいあの体積 A・7点｜正方形を折る三角すい

👀 まず見るところ

CE・EF・FCで折ると、A・B・Dの3つの角が1点に集まる → その点から E・F・Cへ出る3本の辺（6cm・6cm・12cm）は、正方形の角だからどれも直角。底面を三角形AEF、高さをDC＝12cmにして体積を出す。

📚 前提知識

  • 正方形の角を1点に集めた三角すいは、その点で3本の辺が互いに垂直。三角形AEFを底面にすると、12cmの辺がそのまま高さになる。
  • 角すいの体積＝底面積×高さ÷3（問題文に書いてある）。

🔍 整理して解く

  1. 集まる点を「ABD」と書き、そこから出る3本の辺を書く。 
    ABD → E   6cm（AE）
ABD → F   6cm（AF）
ABD → C  12cm（BC＝DC）  3本とも直角に交わる
  2. 底面 三角形AEF＝6×6÷2＝18cm²。高さ 12cm。
  3. 18×12÷3＝72。
答え：72cm³

5 (2) 点Sの位置（AT・AU） B・7点｜三角すいの切り口と展開図

👀 まず見るところ

Rは面CDFの中で、辺DFから4cm・辺CDから2cmの点。「面CDFに垂直な直線」は、折ると面CDFと直角になる辺DE（AE・BEが重なる辺）と平行。DCを縦に立て、Dから4cmの高さの切り口の三角形で考える。切り口の図が描けたら手を付ける。

📚 前提知識

  • 三角すいを底面と平行に切ると、切り口は底面と同じ形の小さい三角形。頂点Cからの高さの比で縮む。今回は Cから8cm（Dから4cm）で切るから、8：12＝2：3。
  • 三角形の2辺の真ん中どうしを結んだ線は、残りの辺と平行。逆に、1辺の真ん中から平行に引くと、向かいの辺の真ん中に着く。

🔍 整理して解く

  1. Dを下、Cを上にして三角すいを立てる（底面はDEF、DC＝12cmが高さ）。Dから4cmの高さで底面と平行に切り、切り口を三角形GHIとする（G はDC上、H はCE上、I はCF上）。 
    G：DC上、DG＝4cm
H：CE上、CH：HE＝2：1
I：CF上、CI：IF＝2：1
切り口の辺 GH＝DE×2/3＝4cm、GI＝DF×2/3＝4cm
  2. Rは面CDFの中で高さ4cm・CDから2cm → GI上で、Gから2cm。GIは4cmだからRはGIの真ん中。
  3. Rを通り面CDFに垂直な直線は、GH（＝DEと平行）と平行。真ん中のRから平行に引くから、HIの真ん中に着く。これがS。RS＝GH÷2＝2cm。
  4. 展開図（正方形）にもどす。HはCE上でCから2/3、IはCF上でCから2/3。Aから右（AD方向）・下（AB方向）に何cmかを表にする。
    点Aから右（AD方向）Aから下（AB方向）
    C1212
    E06
    F60
    H（C→E の 2/3）12－12×2/3＝412－6×2/3＝8
    I（C→F の 2/3）12－6×2/3＝812－12×2/3＝4
    S（HとIの真ん中）(4＋8)÷2＝6(8＋4)÷2＝6
  5. Sは正方形のちょうど真ん中。AT＝6cm、AU＝6cm（TはEに、UはFに重なる）。
答え：AT＝6cm・AU＝6cm
コツ：「面に垂直な直線」は、折ったときにその面と直角になる辺（今回はDE）と平行に引く。底面と平行な切り口で考えると、平面図形の問題になる。

5 (3) 穴をあけた木片の体積 B・7点｜ななめに切った円柱

👀 まず見るところ

穴はRS（2cm）を軸にした半径1cmの円柱 → R側の面CDFは棒に垂直で切り口は平らな円、S側の面CEFはななめの切り口。ななめに切った円柱を2つ合わせると、まっすぐな円柱。(2)のRS＝2cmが出ていれば取れる。

📚 前提知識

  • 円柱を軸の上の点を通る平面でななめに切ると、高い側と低い側が同じだけある。同じものを2つ合わせると、高さが2倍のまっすぐな円柱になる。だから体積は「軸の長さを高さにした円柱」と同じ。

🔍 整理して解く

  1. 穴の形を書く。半径1cm、軸はRからSまで2cm。R側は平ら、S側はななめ（Sはななめの切り口の真ん中）。 
    R（平らな円）──2cm──S（ななめの切り口の真ん中）
  2. 同じ形を2つ、ななめの面で合わせる。高さ 2×2＝4cm のまっすぐな円柱になる。
  3. 穴の体積＝1×1×3.14×4÷2＝6.28cm³。
  4. 木片いは三角すいあと同じ72cm³。72－6.28＝65.72。
答え：65.72cm³
コツ：ななめに切った円柱の体積は「底面積×軸の長さ（円の中心での高さ）」。切り口の形（だ円）の面積は出さなくてよい。

3〜5 まとめ（この3題でくり返し出た入口）

  • 台形の中の三角形は「高さが同じ → 面積の比＝底辺の比」。対角線で作る三角形（DBC・ACD）を、底辺の比で縮めて使う（大問3・4）。
  • 辺の真ん中の点があれば、そこを中心に半回転して図をつなぐ（大問4）。
  • 正方形を折る三角すいは、集まった角から3本の辺が直角に出る。空間の問題は「底面と平行な切り口」で平面にして考える（大問5）。
