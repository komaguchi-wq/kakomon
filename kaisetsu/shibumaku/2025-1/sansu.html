1 (1)① 5×12の長方形を対角線1本で切る A・8点｜格子と対角線（通るタイルの数え方）

👀 まず見るところ

「対角線で切られていないタイル」→ 先に対角線が通るタイルの枚数を出して、全部の枚数から引く。通る枚数はまたぐマス目の線の本数＋1で出せる。60枚を1枚ずつ数えるのは、見落としが出やすい。

📚 前提知識

  • 線がマス目の線を1本またぐたびに、新しいタイルに入る。だから通るタイルは「またぐ本数＋1」。縦3・横5で試すと、横の線を2本、縦の線を4本またぐ。2＋4＋1＝7枚。
  • 5と12は、1以外に同じ約数がない。だから対角線は、途中でマス目の角（線と線が交わる点）を通らない。角を通ると1回で2本またぐことがあり、数がずれる。

🔍 整理して解く

  1. 小さい長方形で数え方をたしかめる。 
    縦3・横5の長方形に対角線1本
またぐ横の線: 3−1＝2本
またぐ縦の線: 5−1＝4本
通るタイル  : 2＋4＋1＝7枚
  2. 縦5・横12にあてはめる。またぐ横の線は5−1＝4本、縦の線は12−1＝11本。通るタイルは 4＋11＋1＝16枚（5＋12−1 と同じ）。
  3. タイルは全部で 5×12＝60枚。切られていないのは 60−16＝44枚。
答え：44枚
コツ：縦と横が「1以外に同じ約数を持たない」長方形なら、対角線が通るタイルは（縦＋横−1）枚。角を通る長方形は、(2)のように小さい長方形に分ける。

1 (1)② 対角線2本で切る B・8点｜2本の線の重なりを引く

👀 まず見るところ

対角線が2本 → 16枚＋16枚から、両方に切られたタイルを引く。両方に切られるのは2本が交わる真ん中のまわりだけ。そこだけ拡大して見る。①が出ていれば、真ん中の数枚を落ち着いて数えるだけで取れる。

📚 前提知識

  • 2本の対角線は長方形の真ん中で交わる。真ん中は 横6cm・縦2.5cm の点。横6cmはマス目の線の上、縦2.5cmはタイルのちょうど半分の高さ。
  • 対角線は、縦5に対して横12進む。だから縦に0.5cm進む間に、横には 0.5×12÷5＝1.2cm進む。1.2cmは1マス（1cm）より長い。

🔍 整理して解く

  1. 真ん中のまわりを図にする。交点は、下から3段目の行の中、横5〜6cmと6〜7cmのタイルの境目。この2枚は、2本とも通る。 
    下から3段目の行（高さ2〜3cm）のタイル
横 4〜5 ｜ 5〜6 ｜ 6〜7 ｜ 7〜8
交点は 5〜6 と 6〜7 の境目（高さ2.5cm）
行の上の線(3cm)で: 線ACは横4.8cm, 線DBは横7.2cm
行の下の線(2cm)で: 線ACは横7.2cm, 線DBは横4.8cm
  2. 交点から行の上の線まで0.5cm。その間に線は横に1.2cm進むから、上の線では交点から左右に1.2cmずつ離れる。下の線でも同じ。だから 4〜5cm のタイルには片方の線が上から、もう片方が下から入る。7〜8cm も同じ。
  3. 両方に切られるタイルは、4〜5・5〜6・6〜7・7〜8 の4枚。切られるタイルは 16×2−4＝28枚。
  4. 切られていないのは 60−28＝32枚。
答え：32枚

1 (2) 7×21の長方形を4本の直線で切る B・8点｜4本の線の重なりを引く

👀 まず見るところ

直線が4本 → 1本ずつ通る枚数を出して、重なりを引く（①②と同じ）。ただし対角線SQは、縦7・横21 で7でわり切れる。途中でマス目の角を通るから、ここだけ「縦1・横3の長方形が7個」に分けて数える。①②の数え方が思い出せるなら、時間はかかるが取れる問題。

📚 前提知識

  • 縦と横に同じ約数があるとき、対角線はマス目の角を通る。7×21なら、角で7つの小さい長方形（1×3）に分かれる。1×3 の対角線が通るタイルは 1＋3−1＝3枚。
  • TQは、縦7・横2の長方形の対角線。TUは、縦7・横17（21−2×2）の長方形の対角線。どちらも縦と横に同じ約数がないから（縦＋横−1）で出せる。

🔍 整理して解く

  1. 4本それぞれの通る枚数を表に書く。 
    SQ: 1×3 の長方形が7個 → 3×7＝21枚
TQ: 縦7・横2  → 7＋2−1＝8枚
SU: 縦7・横2  → 7＋2−1＝8枚
TU: 縦7・横17 → 7＋17−1＝23枚
合計 21＋8＋8＋23＝60枚
  2. SQとTUの重なりを見る。2本は長方形の真ん中（横10.5cm・縦3.5cm）で交わる。ここはタイルのど真ん中。交点から行の上の線まで0.5cm進む間に、SQは横に 1.5cm、TUは横に 1/2×17/7＝17/14cm（約1.2cm）進む。どちらも1マスをこえて、左右のとなりのタイルにも入る。両方に切られるのは、真ん中とその左右の3枚。
  3. TQとSQはQで交わる。Qの角のタイル1枚は両方に切られる。SUとSQも同じで、Sの角のタイル1枚。TQとTUはTで分かれる。Tはマス目の線の上にあるから、2本は左のタイルと右のタイルに別々に入る。ここに重なりはない。SUとTUのUも同じ。
  4. 切られるタイルは 60−(3＋1＋1)＝55枚。切られていないのは 7×21−55＝147−55＝92枚。
答え：92枚
コツ：線が3本以上のときは「1本ずつの枚数の表」と「2本ずつの重なりの表」を分けて書く。重なりは、線が交わる点のまわりだけ拡大して数える。

2 (1) ウ＝ア−イ のいちばん大きい数 A・8点｜条件の整理（最大を作る）

👀 まず見るところ

「ア−イ をいちばん大きく」→ アをいちばん大きく、イをいちばん小さくする。アの千の位はAだから A＝9。イは小さい順にならべた数だから、いちばん小さい数字3を入れて B＝3。あとは 9773−3779 を計算するだけ。

📚 前提知識

  • 差をいちばん大きくするには、引かれる数をいちばん大きく、引く数をいちばん小さくする。問題文の例では A＝6、B＝5 で 6775−5677＝1098。千の位の差で大きさがほぼ決まる。
  • イは「アの4つの数字を小さい順にならべた数」。数字は3・4・5・6・8・9のどれかで、7は無い。

🔍 整理して解く

  1. A＝9、B＝3 とする。ア＝9773。数字を小さい順にならべて イ＝3779。
  2. 筆算する。 
      9773
− 3779
  5994
  3. たしかめ。Aを8にしても、Bを4にしても、千の位の差が1小さくなる。だから9773−3779がいちばん大きい。
答え：5994

2 (2)(3) ウが2けた・3けたになる組 B・8点＋8点｜場合分け（けた数）

👀 まず見るところ

「2けた」「3けた」→ 先に、AとBが7より大きいか小さいかで場合分けの表を書く。イ（小さい順）の形はそれで6つに分かれる。6つの形ごとに ア−イ の筆算を書けば、けた数が見える。例の A＝6、B＝5 で イ＝5677 になった理由（7が真ん中に入る）がつかめれば手を付ける。

📚 前提知識

  • 使える数字は 3・4・5・6・8・9。7は無い。だからAもBも、7より小さい（3〜6）か、7より大きい（8か9）かのどちらか。
  • イは、7・7 の前後にAとBがどう入るかで形が決まる。たとえば A＝3、B＝8 なら イ＝3778。A＝8、B＝9 なら イ＝7789。

🔍 整理して解く

  1. イの6つの形を書き出す。 
    A＜B のとき
 ① A・Bとも7より小 : イ＝AB77
 ② Aが小・Bが大    : イ＝A77B（アと同じ）
 ③ A・Bとも7より大 : イ＝7789（A＝8, B＝9）
B＜A のとき
 ④ A・Bとも7より小 : イ＝BA77
 ⑤ Bが小・Aが大    : イ＝B77A
 ⑥ A・Bとも7より大 : イ＝7789（B＝8, A＝9）
  2. 形ごとに ア−イ を筆算して、けた数を見る。
    形ア−イけた数
    ①A77B−AB77。千の位と十の位は同じ数。百の位の 7−B で決まる。B＝6なら2けた（例: 3776−3677＝99）、B＝4か5なら3けたB＝6→2けた／B＝4,5→3けた
    ②アとイが同じ。ウ＝0—
    ③8779−7789＝9903けた
    ④A77B−BA77。Aは6以下だから百の位 7−A は0にならず、千の位からくり下がらない。千の位の差 A−B が残る4けた
    ⑤A77B−B77A。Aは8か9、Bは6以下。千の位の差が2以上4けた
    ⑥9778−7789＝19894けた
  3. (2) 2けたになるのは ①でB＝6のときだけ。A＜B だから A は 3・4・5。(A, B)＝(3, 6)(4, 6)(5, 6) の3通り。
  4. (3) 3けたになるのは、①で B＝4か5 のとき (3, 4)(3, 5)(4, 5) の3通りと、③の (8, 9) の1通り。①の3通り＋③の1通りで4通り。
答え：(2) 3通り　(3) 4通り
コツ：「小さい順にならべる」問題は、真ん中の数字（ここでは7）より大きいか小さいかで形が決まる。形ごとに筆算を1つ書くと、くり下がりの有無でけた数が見える。

3 (1) グラフの(ア)＝太郎が5%になる時間 A・8点｜グラフ（残量の減り方）

👀 まず見るところ

グラフは「3台のうちいちばん少ないカメラ」の残量。(ア)は、折れ線がはじめて5%まで落ちた時間。最初に落ちていく線は、0分から撮影している太郎（60%から1分に5/12%）。だから (ア)＝(60−5)÷5/12。

📚 前提知識

  • 1分に□%減るなら、△%減るのにかかる時間は △÷□。たとえば真一は 80÷2/5＝200分で0%になる。
  • 花子の最初の残量は書かれていない。「このままだと150分しか撮影できない」から、1/3×150＝50%と分かる。
  • 撮影も充電もしていない間は、残量は変わらない。真一は15分まで80%のまま、花子は25分まで50%のまま。

🔍 整理して解く

  1. 3人の線を表に書く。 
    真一: 15分から80%、1分に2/5%減 → 0%は 15＋200＝215分
太郎:  0分から60%、1分に5/12%減 → 5%は (60−5)÷5/12＝132分
花子: 25分から50%、1分に1/3%減  → 5%は 25＋(50−5)÷1/3＝25＋135＝160分
  2. 太郎は 132分で5%になり、ここで充電に入る。132分の時点で真一と花子はまだ5%より多い。だからグラフの最初の谷（5%）は太郎で、(ア)＝132。
  3. 続きも書いておく。太郎は 132＋12＝144分に30%で再開。花子は160分に5%、170分に26%で再開。(2)でこの数を使う。
答え：132

3 (2) グラフの(イ)＝上がる線と下がる線が出会う時間 A・8点｜旅人算（出会い）

👀 まず見るところ

(イ)は、132分のあと折れ線が上がって、折れる所。充電中の太郎（上がる線）と撮影中の花子（下がる線）が同じ残量になる時間。132分の時点の2人の差を、1分に縮まる量でわる。向かい合って進む旅人算と同じ。

📚 前提知識

  • 太郎の充電は 12分で 5%→30%。1分に 25÷12＝25/12%ふえる。
  • 花子は撮影中で、1分に 1/3%減る。2人の差は1分に 25/12＋1/3＝29/12% 縮まる。
  • 132分の時点の花子の残量: 50−1/3×(132−25)＝50−107/3＝43/3%。

🔍 整理して解く

  1. 132分の時点の差を出す。花子 43/3%、太郎 5%。差は 43/3−5＝28/3%。 
    132分: 花子 43/3% ─┐ 1分に1/3%減
                    │ 差 28/3%   → 1分に 1/3＋25/12＝29/12% 縮まる
132分: 太郎  5%   ─┘ 1分に25/12%増
  2. 差がなくなるまでの時間: 28/3÷29/12＝28/3×12/29＝112/29＝3 25/29分。
  3. (イ)＝132＋3 25/29＝135 25/29。
  4. たしかめ。太郎の充電が終わるのは144分。135 25/29分はそれより前。だから太郎はまだ充電中（上がる線）でよい。
答え：135 25/29
コツ：残量のグラフで「上がる線」と「下がる線」が交わる所は、旅人算の出会いと同じ。「差÷(ふえる量＋減る量)」で出せる。

4 (1) 直角二等辺三角形の中のしきつめ、BD：DC B・9点｜しきつめ・比（①と□1）

👀 まず見るところ

正方形と直角二等辺三角形のしきつめ → 小さい正方形の1辺を①、大きい正方形の1辺を□1 とおいて、辺を全部この2つで図に書きこむ。そのうえで、BCの長さを「左から足す」と「高さの2倍」の2通りで書けば、①と□1の比が出る。図のどこが直角二等辺三角形か（Aの下・左はし・右上・右はし）が見えたら手を付ける。

📚 前提知識

  • 直角二等辺三角形は、直角をはさむ2辺が同じ長さ。だから正方形にくっついた三角形の辺は、正方形の1辺と同じになる。
  • 直角二等辺三角形ABCの底辺BCは、Aからの高さの2倍。Aから垂線を引くと、2つの小さい直角二等辺三角形に分かれるから。
  • ①と□の式が2つできたら、同じものどうしを見くらべる。たとえば □9−③＝□6＋② なら、□3＝⑤。

🔍 整理して解く

  1. 図に名前と長さを書きこむ。小さい正方形をア、大きい正方形（縦に2つ）をイ、右下の正方形（横に2つ）をウ、三角形はAの下をエ、左はしをオ、右上をカ、右はしをキとする。 
    ア（小さい正方形）＝①
イ（大きい正方形2つ）＝□1 ずつ → 左のオの辺は □2
エ（Aの下）の辺＝イの上＋アの上＝□1＋①
ウ（右下の正方形2つ）＝□2−①（イ2つの高さ＝ウ＋ア）
キ（右はし）の辺＝ウと同じ □2−①
  2. BCを左から足す。オの辺、イの辺、ウが2つ、キの辺。□2＋□1＋(□2−①)×3＝□9−③。
  3. Aからの高さを上から足す。エの辺、アの辺、ウの辺。(□1＋①)＋①＋(□2−①)＝□3＋①。BCはこの2倍で □6＋②。
  4. 2つを見くらべる。□9−③＝□6＋②。だから □3＝⑤。□1：①＝5：3。□1＝5、①＝3 とおく。
  5. BDはオの辺＋イの辺で □3＝15。DCはウ2つ＋キで (□2−①)×3＝(10−3)×3＝21。BD：DC＝15：21＝5：7。
  6. たしかめ。カ（右上の三角形）の縦の辺は、高さ18からウの7を引いて11。横の辺は、ウ2つの14からアの3を引いて11。同じ長さになった。
答え：5：7
コツ：正方形が2種類あるしきつめは、①と□1の2文字でおく。「長い1本の辺を2通りに書く」と式が1つできる。

4 (2) 長方形PQRSの中のしきつめ、PQ：QR B・9点｜45°回転・斜辺の比

👀 まず見るところ

図2をななめに見る → 45°回すと、上半分に図1と同じならび（大きい正方形2つ・小さい正方形・右下の正方形2つ）が出てくる。だから(1)の 5：3 がそのまま使える。PQとQRは、直角二等辺三角形のななめの辺（斜辺）を足して出す。(1)が出ていて、図2の中に図1の形が見えたら手を付ける。

📚 前提知識

  • 直角二等辺三角形は、大きさがちがっても全部同じ形（相似）。だから斜辺の長さの比は、直角をはさむ辺の比と同じ。辺5の三角形と辺8の三角形なら、斜辺も 5：8。
  • (1)から ア＝3、イ＝5。エ（Aの下）の辺は 5＋3＝8、カ（右上）の辺は 5＋3＋3＝11。

🔍 整理して解く

  1. 図2の頂点Pを図1のAに重ねて、時計回りに45°回す。すると辺PQは辺ABの上に、辺PSは辺ACの上に重なる。
  2. 辺PQを2つに分ける。イ（大きい正方形）の左上の角がPQに当たる点をTとする。Qから右へ5でイの角、そこから上へ5でT。この辺5の直角二等辺三角形の斜辺がQT。TPはエ（辺8）の斜辺。
  3. 辺PSはカ（辺11）の斜辺。QRは長方形だからPSと同じ長さ。 
    QT: 辺5の三角形の斜辺  → 5
TP: エ（辺8）の斜辺    → 8
PS: カ（辺11）の斜辺   → 11
PQ＝QT＋TP＝5＋8＝13,  QR＝PS＝11
  4. 斜辺の比は辺の比と同じで 5：8：11。PQ：QR＝(5＋8)：11＝13：11。
答え：13：11
コツ：ななめにしきつめた図は、45°回して「まっすぐな図」に直す。前の小問の図と同じ形が見えたら、その比をそのまま使う。

  • 格子と直線: 通るタイルは「またぐ線の本数＋1」。線が2本以上なら、1本ずつの表と重なりの表を分けて書き、重なりは交わる点のまわりだけ拡大して数える。
  • 条件の整理: 「小さい順にならべる」は、真ん中の数字より大きいか小さいかで形が決まる。形ごとに筆算を1つ書く。
  • グラフとしきつめ: 「同じになる時間」は差÷1分に縮まる量。しきつめは①と□1の2文字でおき、長い1本の辺を2通りに書く。

大問題材難易度・配点入口の合図
5すべての辺が4cmの四角すいを、3つの真ん中の点L・M・Nで切る。(1)切り口が辺OBを分ける比 (2)O側の立体の体積B 9＋9Nだけ底面から浮いている → 底面の直線LMをのばして、面OBCの平面図に持ちこむ

5 (1) 3点L・M・Nを通る平面が辺OBを分ける比 B・9点｜立体の切断（切り口を平面図で）

👀 まず見るところ

切る3点のうちNだけ底面から浮いている → 底面の直線LMをのばして、辺CBの延長との交点Eをつくる。EとNは同じ面OBCにあるから、結べばOBと交わる。その点がP。面OBCを正三角形の平面図に取り出せれば、手を付ける価値がある。

📚 前提知識

  • 切り口の線は、同じ面にある2点を結んでつくる。同じ面に2点がないときは、底面の線を面の外までのばして交点をつくる。
  • 三角形の2つの辺の真ん中を結んだ線は、残りの辺と平行で、長さは半分。1辺4cmの正三角形なら、真ん中どうしを結ぶと2cm。
  • 平行な2本の線にはさまれた「ちょうちょ」の形は相似。上の線が2cm、下の線も2cmなら相似比は1：1で、同じ大きさになる。

🔍 整理して解く

  1. 底面ABCDを上から見た図を描く。LとMを結んで、両側にのばす。 
    底面を上から見る（正方形ABCD・1辺4cm）
直線LM : L（ADの真ん中）とM（ABの真ん中）を結び、両側にのばす
点E    : 直線LMと、辺CBをBの先へのばした線が交わる点
点F    : 直線LMと、辺CDをDの先へのばした線が交わる点
  2. 三角形AMLは、直角をはさむ2辺が2cmの直角二等辺三角形。三角形BMEも同じ形になるから、BE＝2cm。同じようにDF＝2cm。
  3. 面OBCを取り出して、平面図に描く。NとEを結んだ線がOBと交わる点がP。 
    面OBCを取り出す（正三角形・1辺4cm）
上の点  : O
まん中  : G──N     GはOBの真ん中、NはOCの真ん中。GN＝2cm（BCと平行）
下の線  : E──B────C   BE＝2cm、BC＝4cm
線NE    : NとEを結ぶ。OBと交わる点がP（GとBの間）
  4. GNとBEは平行で、どちらも2cm。三角形GPNと三角形BPEは「ちょうちょ」の形で、相似比は1：1。だからGP＝PB。
  5. OG＝GB＝2cm。GBの真ん中がPだから、PB＝1とするとOG＝GB＝2。OP＝2＋1＝3。OP：PB＝3：1。
答え：3：1
コツ：切る点が「浮いている」ときは、底面にある線を面の外までのばして交点をつくる。あとは1つの面を平面図に取り出して、ちょうちょ型をさがす。

5 (2) 点Oを含む立体ⓐの体積は四角すいの何倍か B・9点｜切断と体積（三角すいの引き算）

👀 まず見るところ

切り口は五角形NQLMPで、O側の立体ⓐは形が複雑 → 反対側（B・C・D側）を「大きい三角すい−はみ出した三角すい2つ」で出して、1から引く。大きい三角すいは、(1)でつくったE・Fと頂点Nの三角すいN-CFE。(1)の3：1が出ていれば手順は決まっている。手を付ける価値がある。

📚 前提知識

  • すい体の体積は「底面積×高さ÷3」。÷3はどのすい体にも共通だから、体積の比は「底面積の比×高さの比」で出せる。底面積が2倍で高さが半分なら、体積は同じ。
  • 辺OCの真ん中の点Nは、底面からの高さがOの半分。辺OBをO側から3：1に分ける点Pは、高さがOの1/4。
  • 切り口の線を面の外までのばすと、切り取られる側は「1つの大きい三角すい」から「はみ出した小さい三角すい」を引いた形になる。

🔍 整理して解く

  1. B・C・D側の立体をⓘとする。ⓘは、三角すいN-CFEから、はみ出した2つの三角すいP-BMEとQ-DFLを取りのぞいた形。ⓐ＝四角すい全体−ⓘ。CE＝CF＝4＋2＝6cm。
  2. それぞれのすい体の「底面積」と「高さ」を表にする。四角すいO-ABCDの高さを1とする。 
    四角すいO-ABCD : 底面積 4×4＝16    高さ 1
三角すいN-CFE  : 底面積 6×6÷2＝18  高さ 1/2（NはOCの真ん中）
三角すいP-BME  : 底面積 2×2÷2＝2   高さ 1/4（PB：OB＝1：4）
三角すいQ-DFL  : P-BMEと同じ
  3. 四角すいとN-CFEを比べる。底面積の比は 16：18＝8：9、高さの比は 2：1。体積の比は (8×2)：(9×1)＝16：9。四角すいを1とすると、N-CFEは 9/16。
  4. 四角すいとP-BMEを比べる。底面積の比は 16：2＝8：1、高さの比は 4：1。体積の比は (8×4)：(1×1)＝32：1。P-BMEは 1/32。Q-DFLも同じ 1/32。
  5. ⓘ＝9/16−1/32×2＝9/16−1/16＝1/2。
  6. ⓐ＝1−1/2＝1/2。たしかめ。ⓘはN-CFEの9/16より少し小さいはずで、1/2＝8/16はそれに合う。
答え：1/2倍
コツ：切り口が五角形になったら、O側を直接は求めない。線をのばしてできる「大きい三角すい−はみ出した三角すい」で反対側を先に出す。高さの比は、切り口が辺を分ける比（(1)の答え）をそのまま使う。
