👀 まず見るところ

本文の最初の定義「進化とは、世代を経る過程で、生物の集団がもっている特徴が変化すること」。→ 選択肢を「世代をまたいでいるか／1匹の一生の話か」で分ける。知識がなくても決まる。

📚 前提知識（あれば答え合わせに使う）

  • 自然選択：偶然生まれた個体差のうち、環境に合う特徴をもつ個体が生き残って子を残し、世代を重ねて集団の特徴が変わる。練習や成長で身についたものは進化ではない。

2 (3) Bのグループ（長さを変えないのに切って貼る）の理由 A・4点｜対照実験の記述

👀 まず見るところ

処理A・B・Cの文に共通する語「切り出し…接着剤で貼り付け」。Bは長さが同じなのに、AやCと同じ「切って貼る」をしている。→ 変えたいのは尾羽の長さだけ、それ以外をそろえる。

📚 前提知識

  • 対照実験：調べたい条件（ここでは尾羽の長さ）だけを変え、それ以外の条件はすべてそろえる。そろえないと、結果の差が「長さのせい」か「切って貼ったせい」か分からない。

✍️ 答案の組み立て

  1. 要素A：AやCでは接着剤を使っている（切って貼っている）。
  2. 要素B：その影響を同じにするため、Bも接着剤を使って条件をそろえる。
  3. 設問は「明確に説明」なので、「条件をそろえるため」だけでなく「接着剤を使ったという条件」まで具体的に書く。
模範解答：接着剤を使ったという条件をそろえるため。

3 (2) 10往復を測る工夫で減る「値のずれ」 B・3点｜実験の工夫の理由・2つ選ぶ

👀 まず見るところ

「10往復を測って÷10」で小さくなるのは、測るたびに入るずれ。押すタイミング（ア）や空気の動き（キ）のずれは、10往復ぶんまとめて測って÷10すると1往復あたり10分の1になる。おもりや定規のずれは10往復にしても同じ。選択肢を「測り方で変わるもの／装置に固定されたもの」に分けられれば、取りにいく価値がある。

📚 前提知識

  • ずれには2種類ある。そのつど不規則に出るもの（反応時間・空気の動き）と、装置に固定されたもの（おもりの重さや形・ひもの長さ）。長く測って割ると減るのは前者だけ。

🔍 こう読み解く

  1. ア：押すタイミングのずれは、10往復を測っても押した瞬間の分しか入らない → ÷10で1/10になる → ○。
  2. キ：空気の動きによるずれも、10往復ぶんまとめて測って÷10すると1往復あたりでは1/10になる（声の教育社）→ ○。
  3. ウ・エ・カ：おもりの形や重さ、ひもの長さは10往復しても同じ値のまま → 減らない → ×。オ：ひもが伸びていくずれは、長く測るほど大きくなる → ×。
  4. イも反応時間のずれだが、「繰り返すたびに短くなる」一方向のずれ。声教の解説は「繰り返し実験をして慣れた結果を使う方が大きく減らせる」として選ばない。
答え：ア・キ

👀 まず見るところ

📚 前提知識

  • 振り子の長さが長いほど周期は長い（結果1-A）。おもりの重さを変えても周期は同じ（結果1-B）。
  • 間違った測り方をしても「重さで周期は変わらない」ことは同じ。だから結果Bは水平線のまま上下にずれるだけ。右上がりのクは出てこない。

🔍 こう読み解く

  1. ①班：正しい線よりいつも上にある曲線 → 結果Aはイ（長さ0の所でも、おもりの分だけ周期が残るので線が高い所から始まる）。エは途中で交わるので×。結果Bは水平線が上にずれたカ。
  2. ②班：10往復のつもりが9往復なので、計算した周期は正しい値の0.9倍。いつも下 → 結果Aはウ、結果Bは下にずれたキ。
  3. 解答らんは「結果A・結果B」が①②それぞれに2つずつ。書く場所を取り違えないように、①の2つを書いてから②へ進む。
答え：① 結果A…イ，結果B…カ　② 結果A…ウ，結果B…キ

3 (4) ブランコのモデル化（何をそろえ、どう吊るすか） B・3点｜モデル化・完答

👀 まず見るところ

図5の3つの定義を見比べる。ブランコは座板までの長さが同じなので、そろえるのは「全体の長さ」。体重は変わらないので、立つ／座るともおもりの数は同じ。ちがいは重心の高さだけ、と言い直してから選ぶ。

📚 前提知識

  • 振り子の長さ＝吊るした点から重心まで。全体の長さが同じなら、重心が上にある方が「振り子の長さ」は短い。
  • 2個直列：重心は2個の真ん中（上寄り）。2個並列：重心は最下点のすぐ上（下寄り）。

🔍 こう読み解く

  1. ①：立つ場合も座る場合もブランコの長さは変わらない → 同じにするのは全体の長さ。
  2. 人の体重は同じなので、おもりの個数も同じ。「1個」は候補から外れる。
  3. 立つ場合は重心が高い → 全体の長さが同じで重心が上にくる2個直列。座る場合は重心が低い → 2個並列。
答え：① 全体　② 2個直列　③ 2個並列

3 (5) 立つ場合と座る場合、周期が短いのは B・5点｜選択＋理由の記述

👀 まず見るところ

設問は「周期が短い方」と「そう考えた理由」。(4)で組んだモデルをそのまま使う。立つ＝2個直列＝重心が高い＝振り子の長さが短い。結果1-Aで、長さが短いほど周期は短い。

📚 前提知識

  • 周期を決めるのは振り子の長さ（吊るした点から重心まで）。短いほど周期は短い。体重（おもりの重さ）は関係しない（結果1-B）。

✍️ 答案の組み立て

  1. 要素A：立つ場合は座る場合に比べて、人の重心の位置が高い。
  2. 要素B：重心が高い＝振り子の長さが短い場合に当たる。
  3. 結び：振り子の長さが短いほど周期は短いので、立つ場合。「重心」と「振り子の長さ」の2語をつなぐ。
模範解答：立つ場合／理由…（例）立つ場合は座る場合に比べて人の重心の位置が高く，振り子の長さが短い場合に当たるから。
コツ：「体重が重いから」「勢いがつくから」は結果1-Bで否定される書き方。理由は長さ（重心の高さ）だけで書く。

4 (1) 過炭酸ソーダの用途・性質 B・3点｜性質の正誤・すべて選ぶ

👀 まず見るところ

選択肢を実験の文に当てる。ア／イは実験1の赤色リトマス紙→青で決まる。オ／カは実験1の「水10mLに1.00gがすべて溶けた」を100mLに直す。ウ・エは酸素を出す薬品という知識＋実験2の様子。実験文だけで4つ決まるので、取りにいく。

📚 前提知識

  • 赤色リトマス紙を青に変える＝アルカリ性。
  • 過炭酸ソーダは酸素を出す。そのはたらきで漂白剤・洗浄剤（酸素系漂白剤）に使われる。実験2で塩酸を加えて出たのは泡（二酸化炭素）だけで、実験は安全に行えている。

🔍 こう読み解く

  1. 実験1より、水溶液はアルカリ性 → ア×、イ○。
  2. 水10mLに1.00g → 水100mLなら10.0gが溶ける計算 → 限界は10g以上 → オ×、カ○。
  3. ウ：酸素を出す薬品＝漂白剤・洗浄剤 → ○。エ：酸性の塩酸と混ぜても、刺激臭のある有毒な気体は出ていない → ×。
答え：イ・ウ・カ
コツ：「すべて選ぶ」は、×にする根拠も1つずつ実験文に戻して確かめる。

4 (2) 気体A・Bの正体 A・4点｜気体の見分け

👀 まず見るところ

気体を見分ける合図は2つ。線香がポッと明るく光る＝酸素、石灰水が白くにごる＝二酸化炭素。実験1・2の文にこの2つがそのまま書いてある。

📚 前提知識

  • 酸素はものを燃やすはたらきがあるので、火のついた線香が明るく燃える。
  • 二酸化炭素は石灰水を白くにごらせる。

🔍 こう読み解く

  1. A：湯せんや二酸化マンガンで出た気体 → 線香が明るく光り、石灰水は変化なし → 酸素。
  2. B：塩酸を加えて出た気体 → 石灰水が白濁 → 二酸化炭素。
答え：A 酸素　B 二酸化炭素

4 (3) ビーカーの中をうちわであおぐ理由 A・4点｜操作の理由・記述

👀 まず見るところ

下線①は「気体を発生させた後、重さをはかる前」の操作。この実験は減った重さを出ていった気体の重さとして使う。ビーカーの中に気体が残っていると、減り方が小さく出る。

📚 前提知識

  • 発生した気体はすぐには全部出ていかず、ビーカーの中に残る。空気より重い二酸化炭素はとくにたまりやすい。
  • 重さの変化から気体の量を求める実験は、はかる時点で「気体は全部外へ出た」がそろっていないと、実験どうしを比べられない。

✍️ 答案の組み立て

  1. 要素A：ビーカー内に残った気体を追い出す（空気と入れかえる）。
  2. 要素B：そのうえで重さの変化を正確にはかるため。「何のために」と聞かれているので「〜ため」で結ぶ。
模範解答：ビーカー内に残った気体を空気と入れかえて重さの変化を正確にはかるため。
コツ：「かき混ぜるため」「冷ますため」は、この実験で減った重さを何に使うかを見ていない答え。

4 (4) 美浜さんの予想 X・Y B・4点｜表の足し算

👀 まず見るところ

美浜さんの文の「もし〜としたら」を見る。実験5と同量のA（0.07g）を塩酸でも出したとしたら → X＝0.30＋0.07。続く二酸化マンガンは実験3の3-2と同じ → Y＝0.17。実験3・5の3つの数（0.07／0.17／0.30）の足し算だけで決まるので、取りにいく。

📚 前提知識

  • 実験3の流れ：水に溶かす→A 0.07g（実験5より）、二酸化マンガン→A 0.17g、塩酸→B 0.30g。
  • 実験4の実際：塩酸に溶かす→0.30g、水＋二酸化マンガン→0.24g。

🔍 こう読み解く

  1. X：塩酸でB 0.30g、そこに水に溶けて出るA 0.07gも足す → 0.30＋0.07＝0.37。
  2. Y：続けて二酸化マンガン → 実験3の3-2と同じA 0.17g → 0.17。
  3. 実際は0.30と0.24。0.24＝0.07＋0.17なので、「酸性ではAが出ず、あとでまとめて出た」という先生の仮説につながる。ここが(5)の入口。

4 (5) 表の空らんⅠ〜Ⅲ（仮説を当てはめる） A・3点｜表の空らん

👀 まず見るところ

仮説「酸性の水溶液ではAは発生しない」を表に当てる。Ⅰは水に溶かしただけ → Aだけ。Ⅱは塩酸に溶かした → 仮説でAなし → Bだけ。Ⅲは水と二酸化マンガン → Bのもとは4-1で出し切っている（実験2：さらに塩酸を加えても泡は出ない）→ Aだけ。

📚 前提知識

  • A（酸素）は温める・二酸化マンガンで、B（二酸化炭素）は塩酸で出る。

🔍 こう読み解く

  1. Ⅰ：0.07g＝実験5の酸素 → ア。
  2. Ⅱ：0.30g＝実験3で塩酸を加えたときの二酸化炭素と同じ → イ。仮説どおりAはゼロ。
  3. Ⅲ：0.24g＝0.07＋0.17＝Ⅱで出なかった酸素がまとめて出た → ア。重さを表どうしで見比べると確かめられる。

4 (6) 体積の比 Z と大きい方 C・3点｜体積の比・小数第2位

👀 まず見るところ

本番では後回し。合図は先生の「同じ体積でBはAの1.4倍の重さ」→ 重さを体積に直すには÷1.4。

📚 前提知識

  • 過炭酸ソーダ1.00gから出る気体の合計：酸素は0.07＋0.17＝0.24g、二酸化炭素は0.30g（実験3〜5のまとめの表）。

🔍 こう読み解く

  1. Bの重さ0.30gを「Aの重さ」に換算 → 0.30÷1.4。
  2. Aの重さ0.24gで割る → 0.30÷1.4÷0.24＝0.892… → 0.89倍。
  3. 1より小さいので、体積はA（酸素）の方が大きい。
答え：Z 0.89　A

3〜4 まとめ この回で繰り返し出た入口

  • 振り子は「周期は長さ（重心まで）だけで決まる」の1本。重さ・振れ幅・数え間違いは、グラフを上下にずらすだけで形は変えない。
  • 気体の重さの実験は「減った重さ＝出た気体」。表の数を足して合うか（0.07＋0.17＝0.24）を見れば、仮説の問題も空らんも決まる。
  • 2つ選ぶ・すべて選ぶ問題は、実験文に戻って○×の根拠を1つずつ言えるものから決める。
