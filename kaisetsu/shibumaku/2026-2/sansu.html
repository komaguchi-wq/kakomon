1 (1) カレーとラーメンが好きな生徒の人数 集まり（線分図）

👀 まず見るところ

「クラス全体の1/2」「1/3」と、「どちらも好き5人」「どちらも好きではない12人」 → 全体を1とした線分図を書く。カレーの線とラーメンの線が重なった分が5人。重なりをなくすように線をずらすと、右にあまる人数が 12−5＝7人になる。

📚 前提知識

  • カレーが好きな人とラーメンが好きな人をそのままたすと、どちらも好きな5人を2回数える。だから、たした分は5人だけ本当より多い。
  • 全体1から 1/2 と 1/3 をひくと 1/6。この1/6にあたる人数が分かれば、全体は「人数÷1/6」で出る。たとえば1/6が3人なら、全体は18人。

🔍 整理して解く

  1. 全体を1として線分図を書く。左からカレー1/2、その右にラーメン1/3。重なりが5人、右のあまりが12人。 
    全体（1）     ├─────────────────────────┤
カレー 1/2    ├───────────┤
ラーメン 1/3          ├──────────┤   ← 左はし5人分がカレーと重なる
どちらも×                          ├12人┤
  2. ラーメンの線を右にずらして、重なりをなくす。右のあまりは 12−5＝7人になる。 
    全体（1）     ├─────────────────────────┤
カレー 1/2    ├───────────┤
ラーメン 1/3              ├──────────┤   ← 右にずらして重なりなし
残り 1/6                             ├7人┤
  3. 全体から 1/2 と 1/3 をひく。1−1/2−1/3＝1/6。この 1/6 が7人。
  4. 全体は 7÷1/6＝42人。
  5. たしかめ。42人の1/2は21人、1/3は14人。21＋14−5＝30人がどちらか好き。42−30＝12人。合っている。
答え：42人
コツ：「どちらも好き」と「どちらも好きではない」が両方あるときは、線分図で重なりをずらす。ベン図でも同じ。「全体−（1/2＋1/3−5人）＝12人」の1本の式にしてもよい。

1 (2) 仕入れ値が2段階のカレーとラーメン100食分 つるかめ算＋倍数で場合をしぼる

👀 まず見るところ

仕入れ値が「40食分以上なら120円」「30食分以上なら160円」と2段階 → 先に、どの値段の組み合わせかを決める。合計15660円が40でわり切れるかどうかで、組がしぼれる。値段が決まれば、ふつうのつるかめ算。3通り全部でつるかめ算をすると、時間がかかる。

📚 前提知識

  • カレーは150円か120円、ラーメンは200円か160円。表にすると値段は4つ。組み合わせは3通り（150円と200円の組は、40食分未満＋30食分未満で100食分にならない）。
  • 40の倍数をいくつ集めても、合計は40の倍数。120円と160円と200円はどれも40の倍数。たとえば120×3＋160×2＝680は40でわり切れる。
  • つるかめ算は、全部片方だとしたときの金額と本当の金額の差を、1食分の差でわる。

🔍 整理して解く

  1. 値段の表を書く。
    少量大量
    カレーア 150円（40食分未満）ウ 120円（40食分以上）
    ラーメンイ 200円（30食分未満）エ 160円（30食分以上）
  2. 組み合わせを確かめる。ア＋イは 40＋30 より少なくて、100食分にならない。イ＋ウは200円と120円で、どちらも40の倍数。ウ＋エも120円と160円で、どちらも40の倍数。
  3. 15660÷40＝391あまり20。わり切れない。だからイ＋ウとウ＋エは合わない。残るのはア（150円）＋エ（160円）。
  4. つるかめ算。全部エなら 160×100＝16000円。本当より 16000−15660＝340円高い。 
    ア 150円 ┐ 合わせて100食分
エ 160円 ┘ 15660円
  5. エをアに1食分かえると 160−150＝10円安くなる。340÷10＝34食分がア（カレー）。ラーメンは 100−34＝66食分。
  6. たしかめ。カレー34食分は40食分未満で150円、ラーメン66食分は30食分以上で160円。値段の条件に合う。150×34＋160×66＝5100＋10560＝15660円。
答え：34食分
コツ：値段が「〜以上なら安い」と段階になっている問題は、つるかめ算の前に「どの段階の組か」を決める。倍数（ここでは40）でわり切れるかが、組をしぼる道具になる。答えが出たら、その値段でよい食数かをもう一度見る。

1 (3) 食券35枚で12650円・カレーの枚数 3種類のつるかめ（式に当てはめる）

👀 まず見るところ

3種類の食券で「35枚」「12650円」 → 3種類に共通の70円を先にひいて、2種類にする。残るのはカレー320円とラーメン380円の上乗せ分だけ。あとは「16×□＋19×△＝510」に当てはまる組をさがす。「1枚または□枚」と、1つは問題文が教えてくれている。

📚 前提知識

  • 面積図の土台: 35枚全部に70円分がある。70×35＝2450円をひくと、残り10200円はカレーとラーメンの上乗せ分だけになる。サラダの上乗せは0円。
  • 320と380は両方20でわれる。式全体を20でわると、数が小さくなって当てはめやすい。320×□＋380×△＝10200 → 16×□＋19×△＝510。
  • 「□を19ふやして△を16へらす」と、16×19 と 19×16 で同じ304ずつ増えて減る。だから合計はかわらない。

🔍 整理して解く

  1. 面積図を書く。横に□枚・△枚・○枚、たてに390円・450円・70円。下の70円の土台が35枚分。 
    面積図（横＝枚数、たて＝1枚の値段）
上の段（上乗せ）: カレー 320円×□枚 ＋ ラーメン 380円×△枚 ＋ サラダ 0円×○枚 ＝ 白い部分
下の段（土台）  : 70円×35枚 ＝ 2450円（3種類に共通）
全体            : □＋△＋○＝35枚、合計 12650円
  2. 白い部分の金額は 12650−2450＝10200円。式は 320×□＋380×△＝10200。20でわって 16×□＋19×△＝510。
  3. 問題文にある □＝1 を入れる。19×△＝510−16＝494。△＝26。サラダ○は 35−1−26＝8枚。35枚以内で合う。
  4. □を19ふやし、△を16へらす。□＝1＋19＝20、△＝26−16＝10。合計は304ふえて304へるので510のまま。○は 35−20−10＝5枚。合う。
  5. もう一度□を19ふやすと39。16×39＝624 で510をこえる。ここで終わり。
  6. たしかめ。390×20＋450×10＋70×5＝7800＋4500＋350＝12650円。
答え：20
コツ：3種類のつるかめ算は「共通の分を先にひく」か「1種類を消す」で2種類にする。□と△の式になったら、1つ見つけたあとは「□を△の係数だけふやし、△を□の係数だけへらす」で次の組が出る。

2 (1) 和が10になる3つの数の組 書き出し（大きい数から固定）

👀 まず見るところ

「1〜5が2個ずつ」で「和が10」 → いちばん大きい数を5から順に決めて書き出す。残り2つの和が決まるので、もれがない。同じ数は2回までしか使えない所が落とし穴。

📚 前提知識

  • 書き出しは、いちばん大きい数を先に固定する。5を使うなら残り2つの和は5。4が最大なら残り2つの和は6で、どちらも4以下。
  • 玉は2個ずつ。(3,3,3)のように同じ数を3回は使えない。0の玉も無いので(5,5,0)も無い。

🔍 整理して解く

  1. いちばん大きい数を5にする。残り2つの和は5。(1,4)と(2,3)。→ (1,4,5) (2,3,5)。
  2. いちばん大きい数を4にする（5は使わない）。残り2つの和は6で、4以下。(2,4)と(3,3)。→ (2,4,4) (3,3,4)。(1,5)は5が入るのでだめ。
  3. いちばん大きい数を3にする。3個たしても 3＋3＋3＝9 で10に足りない。ここで終わり。 
    最大5: (1,4,5) (2,3,5)
最大4: (2,4,4) (3,3,4)
最大3: 9まで → なし
  4. 全部で 4通り。
答え：4通り

2 (2) 積が10の倍数になる3つの数の組 5×偶数

👀 まず見るところ

「積が10の倍数」 → 10＝2×5。3つの中に5と偶数（2か4）が入っていればよい。「5, 偶数, あと1つ」の形で数えて、同じ組を2回数えていないか最後に見る。

📚 前提知識

  • かけ算の答えが10の倍数になるのは、かける数の中に5の倍数と2の倍数があるとき。1〜5なら、5と、2または4。たとえば 5×2×3＝30、5×4×1＝20。
  • 残りの1つは1〜5のどれでもよい。玉は2個ずつあるので、5や2や4がもう一度出てもよい。
  • (5,2,4)と(5,4,2)は同じ組。数えたあとで重複をひく。

🔍 整理して解く

  1. 「5, 偶数, □」の形で書く。偶数は2か4の2通り。□は1〜5の5通り。2×5＝10通り。
  2. 書き出して確かめる。 
    偶数2: (5,2,1) (5,2,2) (5,2,3) (5,2,4) (5,2,5)
偶数4: (5,4,1) (5,4,2) (5,4,3) (5,4,4) (5,4,5)
  3. (5,2,4)と(5,4,2)は同じ組。1つへらして 10−1＝9通り。
答え：9通り
コツ：「積が○の倍数」は、○を素数に分けて「どの数が入っていればよいか」に直す。決めた数を先に置いて、残りを数えると速い。

2 (3) （2つの和）×（1つの数）が10の倍数 場合分けの表

👀 まず見るところ

「2つの数の和」×「1つの数」が10の倍数 → 「1つの数」○が5かどうかで分ける。○が5なら、和が偶数ならよい。○が1〜4なら、和が5の倍数（5か10）。表を書いて数え、最後に同じ組をひく。頭の中だけで数えると、重複に気づけない。

📚 前提知識

  • 2つの数の和は2〜10。10の倍数になる和は10（5＋5）だけ。和が5になるのは 1＋4 と 2＋3。
  • ○が5のとき、5×（和）が10の倍数になるには、和が偶数ならよい。たとえば 5×6＝30。
  • ○が1〜4のとき、○に5の倍数はない。だから和が5か10。和が5なら○は偶数（2か4）。和が10なら○は1〜4のどれでもよい（5は2個しかないので○にできない）。

🔍 整理して解く

  1. 表を書く。左が「2つの和」、右が「1つの数」○。
    2つの和○数
    ア5（1＋4, 2＋3）2, 42×2＝4
    イ10（5＋5）1, 2, 3, 41×4＝4
    ウ2（1＋1）51
    エ4（1＋3, 2＋2）52
    オ6（1＋5, 2＋4, 3＋3）53
    カ8（3＋5, 4＋4）52
  2. ア〜カをたす。4＋4＋（1＋2＋3＋2）＝16通り。
  3. 同じ組をさがす。イの(5,5,1)とオの(1,5,5)は同じ。イの(5,5,3)とカの(3,5,5)も同じ。16−2＝14通り。
  4. 落としやすい所。○＝5で和が10（5＋5）は5が3個になるので入れない。○＝5で和が偶数の組に5が入るもの（1＋5、3＋5）は、イと重なる。
答え：14通り
コツ：「AとBの積が○の倍数」は、片方に○の約数（ここでは5）があるかどうかで場合を分ける。表の右に「数」の列を作ってから合計し、最後に「同じ組」をひく。

1〜2 まとめ

  • 大問1は「線分図」「値段の表」「面積図」と、図を書けば式が見える。段階つきの値段は、つるかめ算の前に組を決める。
  • 3種類のつるかめ算は、共通の分を先にひいて2種類にする。□と△の式は、1つ見つけたら「係数を入れかえてふやす・へらす」で次が出る。
  • 場合の数は「同じ数は2個まで」と「同じ組の重複」で数がずれる。表を書いて、最後に重複をひく。

3 (1) BSの長さ 台形の面積から長さをもどす

👀 まず見るところ

P・Rは上の辺AD、Q・Sは下の辺BCにある → Kはいつも「上底PR・下底QS・高さ10cm」の台形。面積÷5＝PR＋QSに直して、グラフの数を長さで読む。0秒はP＝A、R＝D、Q＝Bだから、台形ABSD。

📚 前提知識

  • 台形の面積＝（上底＋下底）×高さ÷2。高さが10cmなら、面積＝（上底＋下底）×5。たとえば上底48・下底16なら 64×5＝320。
  • 2点が重なると上底か下底が0になる。そのときは三角形で、式は同じまま使える。

🔍 整理して解く

  1. 0秒の図をかく。上底AD＝48cm、下底BS＝□cm、高さ10cm。 
    上底 AD : A ├──────48──────┤ D
高さ    : 10cm（辺AB）
下底 BS : B ├──□──┤ S　　　　　C
  2. 面積320÷5＝64。これが上底＋下底。48＋□＝64。
  3. □＝64−48＝16。
答え：16cm
コツ：この大問は最後まで「面積÷5＝PR＋QS」で読む。グラフの320・80・あ・最小値を、先に全部5で割っておくと速い。

3 (2) 点Qの速さ グラフの折れ点＝2点が重なる瞬間

👀 まず見るところ

グラフは2秒のところで折れて、そのあとも減り続ける → 2秒で「2点が重なって三角形になった」。重なったのはQとS。Qは2秒でB→Sの16cmを進んだ。

📚 前提知識

  • Kが三角形になるのは、PとRが重なるか、QとSが重なるとき。上底か下底が0になる。
  • 2秒の面積80÷5＝16。これは「PR＋QS」。どちらかが0で、もう片方が16。

🔍 整理して解く

  1. 2秒で重なったのがPとRだとする。すると PR＝0、QS＝16。QSは最初から16なので、Qが動いていないことになる。おかしい。
  2. だから2秒で重なったのはQとS。QS＝0、PR＝16。 
    2秒後の上の辺 : P→├──16──┤←R
2秒後の下の辺 : Q＝S（下底は0）
  3. Qは2秒で16cm進んだ。16÷2＝8。
答え：毎秒8cm

3 (3)い 最初の最小値の時刻 出会い（速さの和）

👀 まず見るところ

2秒からい秒までグラフはまだ減り、い秒で底につく → 今度はPとRが重なる。2秒の時点でPRは16cm。PとRの速さの和が分かれば、あと何秒で出会うかが出る。

📚 前提知識

  • 向かい合って進む2点は、速さの和で近づく。48cmはなれた2点が2秒で16cmまで近づいたら、2秒で32cm縮んだ。

🔍 整理して解く

  1. PRは0秒で48cm、2秒で16cm。2秒で 48−16＝32cm 縮んだ。
  2. PとRの速さの和は 32÷2＝毎秒16cm。
  3. 残り16cmを毎秒16cmで縮める。16÷16＝1秒。い＝2＋1＝3。
  4. たしかめ。3秒のQSは 8×3−16＝8cm、PR＝0。面積 8×5＝40。グラフの底がここ。
答え：3

3 (3)あ 平らな部分の面積 速さの和と差

👀 まず見るところ

3秒のあと面積が増え、そのあとしばらく平らになる → 平ら＝「QSがのびる分だけPRが縮む」。Qは毎秒8cmでSからはなれる。だからPRは毎秒8cmで縮む。3秒で出会ったPとRがまた近づくのは、速いほうが端で折り返したから。

📚 前提知識

  • 同じ向きに進む2点の間は、速さの差で変わる。PとRの和は16（前の問）、差が8なら、速いほうは（16＋8）÷2＝12、おそいほうは4。
  • 速いほうをPとしても、Rとしても同じ図になる。ここではPを速いほうにする。

🔍 整理して解く

  1. 速さを出す。和16・差8 → P＝毎秒12cm、R＝毎秒4cm。
  2. Pが端Dに着く時刻は 48÷12＝4秒。ここから平らになる。
  3. 4秒の長さを書く。PR＝出会ってから1秒はなれた分＝16×1＝16cm。QS＝8×4−16＝16cm。 
    4秒後の上の辺 : ←R├──16──┤P（Dに着いた）
4秒後の下の辺 : S├──16──┤Q→
  4. あ＝（16＋16）×5＝160。
答え：160

3 (3)う 2回目の最小値の時刻 時刻ごとの表

👀 まず見るところ

う秒でグラフはまた底につく（面積40） → QがSにもどった瞬間。Qは B→C→S と 48＋32＝80cm を毎秒8cmで進む。まずう＝80÷8＝10と見当をつけ、途中の時刻を表で確かめる。

📚 前提知識

  • Pは4秒でDに着き、8秒でAにもどって止まる。Qは6秒でCに着き、12秒でBにもどって止まる。Rは12秒でAに着き、24秒でDにもどる。
  • 面積÷5＝PR＋QS。この2つの長さを時刻ごとに書けば、グラフの形が全部分かる。

🔍 整理して解く

  1. 時刻ごとにPR・QSを表にする。
    時刻PRQS面積できごと
    4秒1616160PがDで折り返す
    6秒032160PとRが重なる／QがCで折り返す
    8秒1616160PがAで止まる
    10秒8040QがSにもどる（底）
    12秒01680RがA、QがBに着く
    24秒4816320RがDにもどる
  2. 4〜8秒はPR＋QSが32のまま。平らな部分がここ。
  3. 8秒からPが止まる。PRは毎秒4cm縮み、QSは毎秒8cm縮む。面積は減る。
  4. QSが0になるのは10秒。う＝10。このときPR＝8で面積40。い秒の底と同じ高さ。
答え：10
コツ：10秒より後は、PR＋QSが毎秒4cmずつ増え続ける（10〜12秒はQSが8増えPRが4減る。12秒からはPRだけ4増える）。だからグラフは一直線で320までのぼる。

4 (1) 折り目㋐の作図 作図（折り返しと正三角形）

👀 まず見るところ

折ると弧が中心Oを通る → Oは折り目をはさんで、円周上の点Qに重なる。折り目はOとQのちょうど真ん中を通る。QはPから4cm（PO＝PQ）なので、Pを中心に半径POの弧をかけば見つかる。

📚 前提知識

  • 折り返すと、折り目をはさんで長さは変わらない。Pは折り目の上にあるので、PO＝PQ＝4cm。
  • OP＝OQ＝PQ＝4cm → 三角形OPQは正三角形。同じことをもう1回やると、正六角形の辺が2つ分できる。
  • 2点O・Qから同じ距離にある点を2つ結ぶと、OQの垂直二等分線。これが折り目。

🔍 整理して解く

  1. Pを中心に、半径PO（4cm）の弧をかく。円周と交わった点をQとする。
  2. Qを中心に、半径QO（4cm）の弧をかく。円周と交わった点（Pでないほう）をRとする。
  3. PとRを定規で結ぶ。これが直線㋐。線のそばに㋐と書く。 
    円周上に P → Q → R と、半径の長さで弧をうつす
P・R はどちらも O からも Q からも 4cm → PR が OQ の真ん中を垂直に通る
  4. たしかめ。㋐で折ると、QはOにぴったり重なる。弧はOを通る。
答え：解説の図①を参照のこと。（P→Q→Rと半径の長さで弧をうつし、PとRを結んだ直線が㋐）
コツ：作図の線（2つの弧）は消さない。QはPの左右どちらにとってもよい。

4 (2) 2回折った図形の斜線部 折り返しと面積の移動

👀 まず見るところ

折り目㋐・㋑はどちらもOから2cm（Oと重なる点までが4cmで、その半分）。斜線部は㋑で折り返した部分だから、開いてもどせば「点線の弧・㋐・㋑で囲まれた形」と同じ大きさ。この形は、円から1辺4cmの正方形を取った残りの4分の1。

📚 前提知識

  • 折った部分は、折る前と同じ大きさ。面積は折り返す前の位置で考えてよい。
  • Oを中心に、㋐と㋑を2辺にもつ1辺4cmの正方形がかける（Oから各辺まで2cm）。円からこの正方形を取ると、同じ形が4つ残る。

🔍 整理して解く

  1. 斜線部を㋑で開いてもどす。㋑が円周と交わる左下の点をUとする。点線の弧（もとの円周）と㋐・㋑で囲まれた形になる。 
    ㋐の線  : P から角（㋐と㋑の交点）まで
㋑の線  : 角から U まで
点線の弧: U から P まで（もとの円周）
この3本で囲んだ形 ＝ 斜線部を開いてもどした形
  2. Oを中心に1辺4cmの正方形をかく。上の2辺が㋐・㋑。円からこの正方形を取り、㋐・㋑をのばした線で切ると、風車のように同じ形が4つ（声教の図③）。その1つが、1でもどした形。
  3. 円 4×4×3.14＝50.24。正方形 4×4＝16。残り 50.24−16＝34.24。
  4. 4等分。34.24÷4＝8.56。
答え：8.56cm²
別の見方：斜線部を切って動かすと、Oを中心とする半径4cmの四分円から、1辺2cmの正方形を取った形になる（声教の図②）。12.56−4＝8.56。

5 (1) 辺BFの長さ 内接円の半径

👀 まず見るところ

球が三角柱の上下の面にも横の3面にもくっつく → 真上から見ると「三角形ABCに内側からぴったりの円」。BF＝球の直径＝円の半径×2。まず真上から見た図をかく。

📚 前提知識

  • 3・4・5の三角形は直角三角形（角B＝90°）。面積は 4×3÷2＝6。
  • 内側の円の中心Oと3つの頂点を結ぶと、3つの三角形に分かれる。どれも高さが半径。

🔍 整理して解く

  1. 真上から見た図をかく。直角三角形ABCと、3辺にくっつく円。中心O、半径△cm。 
    真上から見た図 ＝ 直角三角形ABC（角Bが直角）
辺   : AB＝3（たて）、BC＝4（横）、CA＝5（ななめ）
円   : 3辺すべてにくっつく。中心O、半径△cm
  2. 三角形OAB・OBC・OCAの面積をたす。（3＋4＋5）×△÷2＝6。
  3. 12×△÷2＝6 → △＝1cm。
  4. BFは球の直径。1×2＝2。
答え：2cm
コツ：直角三角形なら「（3＋4−5）÷2＝1」でも半径が出る。声教の図②の a・b・c（頂点から円にさわる点までの長さ）で、a＋b＝3、b＋c＝4、c＋a＝5。全部たして2でわると6。6−5＝1 が b、これが半径。

5 (2) B・F・Oを通る面で切った、Aを含む立体 切断（三角柱の体積）

👀 まず見るところ

BFはたての辺 → 切り口はたてにまっすぐな面。真上から見た図で、BからOを通る直線をひくだけ。Oは辺BA・BCからどちらも1cm。だからこの直線はBから45°で、辺ADに当たる。

📚 前提知識

  • OはBAから1cm、BCから1cm。BからOへの直線は、たてと横に同じだけ進む（45°）。
  • たてにまっすぐ切った立体は柱。体積＝底面積×高さ。

🔍 整理して解く

  1. 真上から見た図に、BからOを通る直線をひく。辺ADと交わる点をIとする。 
    真上から見た図（横4・たて3）
上の辺 AD : A ├─3─┤ I ├1┤ D
ななめの線: B → O → I（横に1・たてに1ずつ進む45°）
下の辺 BC : B ├───4───┤ C
  2. 三角形ABIは直角二等辺三角形。AB＝3だから AI＝3cm。
  3. Aを含む立体は、底面が三角形ABI、高さBF＝2cmの三角柱。
  4. 3×3÷2×2＝9。
答え：9cm³

5 (3) 断面の円の中心Pの位置 相似（3:4:5）

👀 まず見るところ

B・F・H・Dを通る面もたてにまっすぐ → 真上から見ると対角線BD。断面の円の中心Pは、OからBDへ垂線を下ろした足。□はBからPまでの長さ。真上の図で、3:4:5の直角三角形を2つさがす。

📚 前提知識

  • OはBCから1cm、BAから1cm。Oから辺BCへ下ろした足をJとすると BJ＝1、OJ＝1。
  • 対角線BDは、横4・たて3の長方形の対角線。BDと、たて・横の線でできる直角三角形は全部3:4:5。たとえばBJ＝1なら、JからBDまでの高さは3/4、BDに沿った長さは5/4。

🔍 整理して解く

  1. 真上の図をかく。B、対角線BD、O（Bから横1・たて1）、Oからまっすぐ下ろした足J。OJをのばしてBDと交わる点をS。OからBDへの垂線の足をP。 
    真上から見た図（Bが左下、Dが右上）
対角線BD : B から D へ（横4・たて3の向き）
点O      : B から横に1・たてに1（円の中心）
点J      : O のまっすぐ下、辺BC の上（BJ＝1、OJ＝1）
点S      : OJ と BD が交わる点（O と J の間）
点P      : O から BD へ垂線を下ろした足（S のすぐ右上）
  2. 三角形BJSは3:4:5（BJ＝1が「4」の辺）。SJ＝1×3/4＝3/4、BS＝1×5/4＝5/4。
  3. OS＝OJ−SJ＝1−3/4＝1/4。
  4. 三角形OSPも3:4:5（OSが「5」の辺。角OSPと角BSJは対頂角で等しい）。SP＝1/4×3/5＝3/20。
  5. □＝BP＝BS＋SP＝5/4＋3/20＝25/20＋3/20＝28/20＝7/5＝1 2/5。
答え：1 2/5cm
コツ：「球をたての面で切った円の中心」は、真上から見ると「Oから切り口の線へ下ろした垂線の足」。立体のまま考えず、真上の図に落とす。

3〜5 まとめ この回で繰り返し出た入口

  • グラフ問題は、面積を「上底＋下底」に直してから読む。折れ点は「誰かが重なった／端で折り返した」。
  • 折り返しは「折る前と同じ大きさ」。開いてもどしてから面積を考える。
  • 立体の中の球は、真上から見た図にする。内接円の半径と3:4:5で全部つながる。
