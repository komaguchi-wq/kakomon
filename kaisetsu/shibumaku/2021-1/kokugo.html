一（説明文・湯川秀樹「具象以前」）

一 この回の全体像（担当の大問） A 19点／B 29点／C 0点

出典は湯川秀樹『詩と科学』所収の「具象以前」。説明的な随筆。研究者の喜びは、着想・構想が理論体系の形にまとまった時にあるが、そういう瞬間はごくまれで、人生のほとんどは同じ平面の上でのゆきつもどりつに費やされる。若いころの筆者は「百日の労苦は一日の成功のためにある」と考えていたが、近年は反対の方向に傾いてきた。形になる前の、他人には見えない苦心のほうに意味がある、という考えである。

軸は「具象化されたもの」と「具象以前の世界」の対比。具象化されたもの＝すでに形になって外から見えるもの（理論体系・業績・マスメディアの情報・機械が扱う知識）。具象以前の世界＝まだ形になっていない、その人の内にあるもの（着想・イメージ・苦心）。筆者が重く見るのは後ろの側。どの問も、この二つのどちら側の話かを先に決めると解ける。

一 問1(a)・問1(b)・問1(c) 漢字の読みと書き A・3点×3｜知識問題

(a)「ゆきつもどりつのために費やされてしまう」→ つい（費やす）。設問は「漢字をひらがなに」なので、傍線のついた「費」の部分だけ「つい」と答える。音読みは「ヒ」で「費用」。(b)「カッキ的な発見」→ 画期。「画期的」＝これまでとは時代を区切るほど目覚ましいようす。「画」は「区切る」の意味で、「活気」と書かない。(c)「大きな成功をオサめた」→ 収。成功・勝利・利益を手に入れるときは「収める」。音読みは「シュウ」で「回収」。国を「治める」、学問を「修める」、税を「納める」と文の意味で書き分ける。
答え：(a)つい・(b)画期・(c)収

一 問2 空らんXに入る十字の言葉 B・5点｜抜き出し型

👀 ① 聞き方

  • 自分で範囲をしぼり込む（塾技62）: 「まれ」と同じ意味の言葉がもう一度出る所を探す。五つ目の段落に「滅多に来ない」がある。

一 問3 ①「同じ平面の上の少し離れたところにきているに過ぎない」の具体例 A・5点｜説明型・記号

👀 ① 聞き方

問いは「その具体例として最も適当なもの」→ 読解の設計カードの説明型（記号）。やることは 1 傍線を切る → 2 使えない言葉に印 → 3 本文の言葉で言いかえ → 選択肢を切る、の順。使えない言葉は比喩の「平面」。これを研究の話に直せば、具体例が決まる。

📚 ② 傍線を切る

  • 「同じ平面の上の／少し離れたところに／きているに過ぎない」。比喩は別の言葉に言いかえる（塾技77）。直後の文が「一つの段階からもう一つ上の段階に飛びあがれるのは…まれ」なので、平面＝段階。
  • 上の段階とは何か。同じ段落の前半に、研究者の喜びは「着想・構想が、一つの具体的な理論体系の形にまとまった時」とある。上の段階＝理論の形にまとまること。同じ平面＝着想・構想のまま。
  • 「少し離れたところ」＝「相当前進したつもり」の中身。動いてはいるが、上には上がっていない。

🔍 ③ 部品で選択肢を切る

物差しは二つ: ①着想・構想の段階のまま ②理論の形になる段階へは上がっていない。選択肢を／で前半・後半に切って照らす（選択肢の部分チェック（塾技52））。

選択肢切り方
ア 明確な形をもった研究の構想や計画が／結局は無意味なものであった事実が発覚した本文に書かれていない。傍線は「上がっていない」と気づく話で、無意味だと分かる話ではない
イ 進歩・飛躍をすることができず／無駄なエネルギーを消費してしまっていた言いすぎ。「エネルギーの消費に終始している」という見方は、次の段落で筆者が「決してそうではないように思われる」と打ち消している
ウ 着想・構想段階にあった研究内容が／少ししか近づくことができなかった向きがちがう。「少し近づく」は上の段階に向かって少し上がっている。傍線の「少し離れた」は同じ平面の中での動き
エ 理論化できていない部分と理論体系化された部分とが／同じ段階にある本文に書かれていない。二つの部分が並んでいる話で、「前進したつもりが上がっていない」話ではない
オ 着想・構想という段階から／新しい理論が形になる段階への移行は行われないような進展物差し①②とも合う → ○

声教の解説は正解の根拠だけを示している（まとまった形になっておらず「着想・構想」から進んでいないことになるので、オ）。ア〜エは私が本文と照らして切ったもの。落としやすい所: ウとオの二択。選択肢同士を比較する（塾技53）と、ちがいは「少し近づいた」か「移行は行われない」か。傍線の「同じ平面」に合うのは、上がっていないほう。

答え：オ

一 問4 ②「情報伝達の方法が急激に変化してきた」ことについての筆者の考え A・5点｜説明型・記号

👀 ① 聞き方

問いは「このことについての筆者の考えを、本文全体の内容をふまえて説明したもの」→ 読解の設計カードの説明型（記号）。やることは 1 傍線を切る → 3 本文の言葉で言いかえ → 選択肢を切る、の順。傍線は事実だけなので、筆者の考えは同じ段落の最後の二文から取る。

📚 ② 傍線を切る

  • 「情報伝達の方法が／急激に変化してきた」。これは出来事で、良い・悪いは入っていない。筆者の考えは段落の終わりにある: 与えられる情報は「既に具象化されたものの中からの選択」で、「具象以前の世界は初めから問題になっていない」。
  • 「本文全体」の合図 → 「対比」の発見（塾技9）。具象化されたもの⇔具象以前の世界。前半で筆者は、業績で人を評価するのは「外から見た時の」評価だとし、「何のために努力しているか、何を苦労しているかという面を、もっと重要視しなければならない」と考えるようになった。マスメディアの情報は、業績と同じ「具象化されたもの」の側。

🔍 ③ 部品で選択肢を切る

物差しは二つ: ①マスメディアの情報＝既に具象化されたもの ②形になる前の世界（努力・苦心）は問題にされない。選択肢を／で切って1パーツずつ照らす（選択肢の部分チェック（塾技52））。誤りの四つは、どれも後半が本文に書かれていない（塾技55）。

選択肢切り方（声教の解説どおり）
ア 遠くの出来事を知ることのできる情報技術は／科学が具象化の努力により実現したものとして評価できる情報技術をそのように評価する記述は無い
イ 万人に瞬時に同じ情報を与えることは／他人の正しい評価を可能とする「他人の正しい評価を可能とする」とは述べられていない
ウ 既に具象化された情報を得る事は／科学者を研究成果で評価するのと同様に、形になる前の努力を無視する事につながる物差し①②とも合う → ○
エ テレビなどの情報伝達は／いまだに理論化されていない世界のことを…理解させるそのような記述は無い
オ 直接関係のない人々の情報を知ることで／具象化以前の世界に対する努力について想像することができる想像できるとは述べられていない。本文の「初めから問題になっていない」と照らすと向きも逆（この一言は私の補足）

落としやすい所: ウの「科学者を研究成果で評価するのと同様に」は、傍線の段落だけ読んでも出てこない。設問の「本文全体」に丸をつけ、前半の「業績で評価する」話と同じ側だとつないでから選ぶ。

答え：ウ

一 問5 ③「混沌に目鼻をつけようとする努力」とはどのようなものか B・7点｜説明型・記述

👀 ① 聞き方

問いは「とはどのようなものか説明しなさい」→ 読解の設計カードの説明型。やることは 1 傍線を切る → 2 使えない言葉に印 → 3 本文の言葉で言いかえ → 5 出力の形、の順。部品の数は7点÷3〜4＝2個。傍線の直前に「いわば」があり、前の文の言い直しだと見えたら手を付ける。

📚 ② 傍線を切る

  • 「混沌に／目鼻をつけようとする／努力」。「混沌」と「目鼻をつける」が比喩で、そのままでは答えに使えない言葉。比喩は別の言葉に言いかえ、指示語は指す中身を書き直す（塾技77）。
  • 直前の「いわば」は、前の内容をたとえで言い直す合図。その前の文は「科学も芸術もそういう努力のあらわれである」。指示語は直後をヒントにして前を見る（塾技12）→「そういう努力」の中身は、さらに前の二文にある。

✍️ ③ 部品を集める

  1. 部品A（混沌＝）: 最後の段落「人間は具象以前の世界を内蔵している」。「内蔵している」は「自分の内にある」と直す。
  2. 部品B（目鼻をつけようとする＝）: 続く文「そこから何か具象化されたものを取り出そうとする」。
  3. 「努力」も傍線の言葉なので、「力をつくす」に言いかえる。
  4. 出力の形: 「（自分の内にある具象以前の世界から）＋（何か具象化されたものを取り出そうと）力をつくすこと。」

問いは「どのようなものか」だが、声教の解答例は「〜こと。」で結んでいる。迷いやすいところ: 「混沌」「目鼻」を残したまま「混沌に形をあたえる努力」とだけ書くと、部品Aの「具象以前の世界」が入らない。中心の語は本文のまま使う。

模範解答：自分の内にある具象以前の世界から、何か具象化されたものを取り出そうと力をつくすこと。

一 問6 (Y)「外から見て、離れて見て、ある人の評価をするだけではいけない」といえる理由 B・7点｜理由型・記述

👀 ① 聞き方

問いは「なぜそういえるのか。本文全体の内容をふまえて説明しなさい」→ 読解の設計カードの理由型。やることは 1 合図を探す → 2 理由の文を見つける → 4 向きを確かめる → 5「〜から。」の順。「本文全体」は、結論の段落まで見る合図。問5が書けていれば、その答えを部品に使えるので手を付ける。

📚 ② 合図を探す

  • 傍線の「〜だけではいけない」は、比較のカタチ「AだけではなくB」（塾技8）。A＝外から見た評価。二つ前の段落に、科学者を「業績によって評価する」のは「外から見た時の、やや離れて見た時の評価でもある」とある。A＝業績での評価。
  • Bは傍線の直後: 「ある人が何のために努力しているか、何を苦労しているかという面を、もっと重要視しなければならない」。同じ段落の終わりには「『どんな風に』苦心したかが重要であったかも知れない」。
  • 「原因・理由」と「結果」はペアで読む（塾技17）。なぜBが大事なのかは、最後の段落に書かれている: 「人生の意義の少なくとも一つは、ここに見出し得るのではなかろうか」。「ここ」が指すのは、直前の「混沌に目鼻をつけようとする努力」。

✍️ ③ 原因→結果の向きを確かめる

  1. 部品A（外からの評価の物差し）: 「業績」→「人に評価される業績より」。
  2. 部品B（筆者が重く見るもの）: 「混沌に目鼻をつけようとする努力」＋「どんな風に」→「自分の内の混沌に形を与えるため、どんな風に努力したのか」。
  3. 部品C（結論の語）: 最後の段落「人生の意義」。これを主語にする。
  4. 出力の形: 「人生の意義は、（A）より、（B）にあるから。」見つけた理由が傍線とつながるか確かめ、文末は「〜から」（塾技76）。「人生の意義は努力のしかたにある → だから、業績を外から見るだけの評価ではいけない」とつながる。

声教の解説も同じ組み立て（外からの評価＝業績で行う評価／筆者は「生まれようとしている世界」の重要性をくり返し説明し、最後の段落でそこに人生の意義があると述べている）。迷いやすいところ: 傍線の直後だけで「何を苦労しているかが大事だから」と書くと、部品Cの「人生の意義」が入らない。「本文全体」とあれば最後の段落まで見る。

模範解答：人生の意義は、人に評価される業績より、自分の内の混沌に形を与えるため、どんな風に努力したのかにあるから。

一 問7 (1)〜(6)の語を二つのグループに分ける B・5点｜記号・語の分類

👀 ① 聞き方

問いは「本文の内容に従って二つのグループに分けたとき、どのような分け方になるか」→ 読解の設計カードの記号。やることは 1 分ける軸を本文の対比で決める → 2 語を一つずつどちら側か決める → 3 選択肢と照らす、の順。軸が「具象化されたもの／具象以前」だと見えていれば手を付ける。

📚 ② 対比の軸を決める

  • 「対比」の発見（塾技9）。題名は「具象以前」。本文はずっと、すでに形になったもの（具象化されたもの）と、まだ形になっていないもの（具象以前の世界）を比べている。二つのグループはこの二つの側。
  • 語だけを見て決めない。それぞれの語の前後の言葉で、どちら側かを決める。

🔍 ③ 語を一つずつ分けて選択肢を切る

語前後の言葉側
(1)理論体系「一つの具体的な理論体系の形にまとまった」形になった
(2)着想「基本的に新しい着想から出発した」。一つ目の段落では「長い間、心の中で暖めていた着想・構想」形になる前
(3)業績「そこから独創的な業績が生まれなかったら」。同じ段落に「科学者をその業績によって評価する」＝外から見えるもの形になった
(4)「何か」「他人は知らなくても、その人自身は何かについて苦心をしつづけていたかも知れない」形になる前
(5)イメージ「絵になる以前のイメージを自分の中で暖ため育ててきた」形になる前
(6)知識「既に具象化された知識」形になった

→ (1)(3)(6) と (2)(4)(5)。この組み合わせはエ。選択肢同士を比較する（塾技53）と早い: (6)「知識」は「既に具象化された」と本文に書いてあり、(5)「イメージ」は「絵になる以前」と書いてある。(1)と(6)が同じ側で、(5)が反対側にある選択肢はア・イ・エ・オ・キ。次に(3)「業績」が(1)の側にあるのはイ・エ・キ。(2)「着想」が(5)の側にあるのはエ・キ。最後に(4)「何か」が(5)の側にあるのはエだけ。迷いやすいところ: (4)「何か」。苦心の相手なので、他人には見えない側に入れる。声教の解説も同じ分け方（「着想」「何か」「イメージ」が具象以前の世界、「理論体系」「業績」「知識」が具象化されたもの）。

答え：エ

一 問8 本文の主張に沿った文章を選ぶ B・5点｜記号・本文の主張

👀 ① 聞き方

問いは「本文が主に主張しようとしている考え方に沿った文章」→ 読解の設計カードの記号。やることは 1 筆者の主張を1行で書く → 2 選択肢を／で前半・後半に切る → 3 主張と同じ向きかを照らす、の順。選択肢は本文に出てこない人物の話なので、主張を1行で書けたら手を付ける。決め手は選択肢の文末。

📚 ② 主張を1行で書く

  • 「筆者の主張」の発見（塾技2）。(Y)の一文と最後の段落から: 業績を外から見て評価するだけではいけない。形になる前に、その人が内で何を考え、どう苦心したかに目を向ける。
  • だから正解は「形になったもの（作品・賞・評判）」で終わる文ではなく、形になる前の、その人の内側に目を向けている文。

🔍 ③ 主張で選択肢を切る

  2. 部品B（すること）: 「まだ見た事のない『地獄』」「想像力を、極度に働かせて」「いろいろに話し合った」→ 見たことのない地獄を想像し、同じく退屈している宗兵衛に話す。
  3. 部品C（結び）: 「ただ一つの退屈紛らし」→ それが退屈を紛らすただ一つの方法だったから。出力の形: 「（背景A）おかんにとって、（B）ことが、（C）だったから。」理由が傍線とつながるか確かめ、文末は「〜から」（塾技76）。
模範解答：何の変化もない日が永遠に続く極楽に飽きて退屈しきっているおかんにとって、見たことのない「地獄」についていろいろ想像をめぐらし、同じく退屈しきっている宗兵衛にその話をすることが、退屈を紛らすただ一つの方法だったから。

二 問8 菊池寛が書いた作品 B・4点｜知識問題

  • 記述2問（問3・問7）は設問の条件の言葉が部品を増やす合図。問3「原因も分かるように」→ 安らかな点と原因を2組、問7「本文全体の内容をふまえて」→ 極楽に飽きるまでの流れを背景に入れる。
