1 (1) 5△10、5△30、5△60 を計算する A・2点×3｜約束記号（商と余り）

👀 まず見るところ

【条件文】部品は「割ったときの商をa△b」と「余りをa▼b」。△の横に「商」、▼の横に「余り」と直して書く → 「かけた数÷たした数」の商を3回出すと決まる。

📚 前提知識

  • 例は「24を10で割った商は2で余りは4」。6△4＝2 と 6▼4＝4 はここから出ている。わられる数はかけ算、わる数はたし算。
  • 商は「わる数が何回入るか」。余りは「入りきらずに残った数」。余りはわる数より小さい。

🔍 整理して解く

  1. 問題文の記号の横にメモを書く。△＝商。▼＝余り。
  2. わり算を表にならべる。列は「b」「5×b（わられる数）」「5＋b（わる数）」「わり算」「5△b（商）」。
    b5×b（わられる数）5＋b（わる数）わり算5△b（商）
    10501550÷15＝3 余り53
    3015035150÷35＝4 余り104
    6030065300÷65＝4 余り404
  3. 確かめ。15×3＋5＝50。35×4＋10＝150。65×4＋40＝300。
  4. 落としやすい所は、△と▼の取りちがえ。答えに書くのは商の 3, 4, 4。余りの 5, 10, 40 は書かない。
答え：5△10＝3、5△30＝4、5△60＝4
コツ：bを30から60に大きくしても、商は4のまま。「どこまで大きくなるか」が (2) の入口になる。

1 (2) 8△c のうち、もっとも大きいもの B・7点｜約束記号（商はどこまで大きくなるか）

👀 まず見るところ

【条件文】部品は「いろいろな整数にかえて」と「もっとも大きいもの」。8△cを「8×c÷（8＋c）の商」に直して書く → cを大きくした表を置くと、商は7で止まると決まる。(1)で 5△30 も 5△60 も4のまま、と気づけたら手を付ける。

📚 前提知識

  • 商が8になるのは、わる数の8個分が、わられる数の中に入るとき。たとえば 40÷5 は、5の8個分がちょうど40。だから商が8。
  • わる数（8＋c）の8個分は、8×8 と 8×c の合計。つまり 8×c より64大きい。c＝100 なら 108×8＝864。8×100＝800 より64大きい。

🔍 整理して解く

  1. cを大きくしながら表を書く。列は「c」「8×c」「8＋c」「わり算」「8△c」。
    c8×c（わられる数）8＋c（わる数）わり算8△c（商）
    1898÷9＝0 余り80
    8641664÷16＝44
    2419232192÷32＝66
    5644864448÷64＝77
    100800108800÷108＝7 余り447
    1000800010088000÷1008＝7 余り9447
  2. 商は7で止まっている。8になることがあるかを、図で確かめる。 図：c＝100 のとき。上がわられる数。下がわる数108の8個分。8個分のほうが64長い。
  3. cがいくつでも、わる数の8個分は 8×c より64大きい。わられる数の中に8回は入らない。だから商は8にならない。
  4. 声教の解説は、同じことを逆数で確かめている。8×c÷（8＋c）をひっくり返すと 1/c＋1/8。これは 1/8 より大きい。だから、もとの数は8より小さい。
  5. 7は、表の c＝56 で実際に出ている。いちばん大きいのは 7。
答え：7
コツ：「わる数の□個分」をわられる数とくらべると、商がどこで止まるかが分かる。5△b は4まで。3△d は2まで。

1 (3) 3▼d＝3 となる d を3つ B・7点｜約束記号（商で場合分け）

👀 まず見るところ

【条件文】部品は「3▼d＝3」と「全部で3つ」。▼を余りに直して「3×d＝（3＋d）×商＋3」と書く → 商は (2) と同じ考えで 0, 1, 2 の3つだけ。商ごとにdが1つ決まる。(2)が解けていれば続けて取れる。

📚 前提知識

  • わり算の確かめの式は「わられる数＝わる数×商＋余り」。例の 24÷10＝2 余り4 なら、24＝10×2＋4。
  • わる数（3＋d）の3個分は、9 と 3×d の合計。3×d より9大きい。だから商は3にならない。商は 0, 1, 2 のどれか。
  • 余りはわる数より小さい。わる数の 3＋d は4以上。余り3は、どのdでも当てはまる。

🔍 整理して解く

  1. 「3▼d＝3」を確かめの式に直す。3×d＝（3＋d）×商＋3。
  2. 商は 0, 1, 2 の3通り。「全部で3つ」と数が合う。商ごとに表を書く。
    商確かめの式dの個数でくらべるdもとのわり算
    03×d＝3dの3個分＝313÷4＝0 余り3
    13×d＝（3＋d）×1＋3dの2個分＝639÷6＝1 余り3
    23×d＝（3＋d）×2＋3dの1個分＝9927÷12＝2 余り3
  3. 商が1と2のときは、線分図を書く。上と下で同じ長さのdを消す。残りがdの大きさになる。 図：上が 3×d。下が「わる数×商＋余り3」。青い破線の左は、上下で同じ長さ。
  4. 3つとも、もとのわり算で余りが3になった。dは 1, 3, 9。
答え：1、3、9
コツ：余りの問題は「わられる数＝わる数×商＋余り」に直す。商が何通りあるかを先に決めると、場合分けの数が決まる。

2 (3) 1分後にライトがもっとも多く増える時刻 B・7点｜条件の整理（進み方ごとの増える本数）

👀 まず見るところ

【条件文】部品は「1分後」と「もっとも多く増える」。「1分後」を「数字が1つ進む」に直して、増える本数を表に置く → ＋3は「1→2」「7→8」だけ。59分で2か所が同時に増える時刻と決まる。表が書ければ手を付ける。

📚 前提知識

  • 1分たつと、分の一の位が1つ進む。9のときは0にもどる。そのとき、となりの位が1つ進む（くり上がり）。
  • 分の十の位は、5の次が0。59分の次は00分。このとき時も1つ進む。
  • 増える本数は「あとの本数−前の本数」。1→2 は 5−2＝3本。7→8 は 7−4＝3本。3本増えるのはこの2つだけ。

🔍 整理して解く

  1. 進み方ごとに、増える本数を表にする。右はしの 5→0 は、分の十の位（59分→00分）で使う。
    進み方0→11→22→33→44→55→66→77→88→99→05→0
    本数6→22→55→55→44→55→66→44→77→66→65→6
    増える本数−4＋30−1＋1＋1−2＋3−10＋1
  2. いくつの位が進むかで場合を分ける。進む位ごとに、増える本数を下に書く。 図：上の段が今の時刻。下の段が1分後。赤い数字が変わった位。
  3. 場合ごとに、いちばん多く増えるときを表にまとめる。
    場合進む位いちばん多く増えるとき
    ① 分の一の位が9以外分の一の位だけ＋3（1→2、7→8）
    ② 分の一の位が9（59分以外）分の十の位。一の位は 9→0＋3＋0＝＋3（19分→20分）
    ③ 59分で、時の一の位が9以外（23:59 は⑤）分は 5→0 と 9→0。時の一の位＋1＋0＋3＝＋4（時の一の位が1か7）
    ④ 09:59 と 19:59時の十の位も進む09:59 は ＋1−4＝−3。19:59 は ＋1＋3＝＋4
    ⑤ 23:59 → 00:004つとも変わる2→0 で＋1、3→0 で＋1、分で＋1。合わせて＋3
  4. いちばん多いのは＋4。③は時の一の位が1か7。時は 01, 07, 11, 17, 21。27時はない。④は 19:59。全部で6つ。
  5. 確かめ。01:59 は 6＋2＋5＋6＝19本。02:00 は 6＋5＋6＋6＝23本。4本増えている。
答え：01：59、07：59、11：59、17：59、19：59、21：59
コツ：「すべて答えなさい」は、19:59 のように時の十の位が進む場合まで調べる合図。くり上がる位が多いほど、増える場所も多い。

1〜2 まとめ

  • 新しい記号や図が出たら、横に意味を書く。△の横に「商」。図3の数字の下に本数。
  • 「もっとも大きい」「もっとも多い」は、小さい表を書いて、どこで止まるかを見る。
  • 時刻の問題は、位ごとに入る数字を先に図に書く。数えすぎと数え落としを防げる。

👀 まず見るところ

【まざり型→資料問題】グラフの正体を1行書く＝「時間と、2つの三角形の面積の和S」。部品は折れ目の「60」「12.8」と、条件「PのほうがQより速く」。折れ目は点がかどに着いた合図 → 60の所で、先に着いたのがPかQかが決まる。(2)(3)もここから続く。時間をかける価値がある。

📚 前提知識

  • 三角形の面積と底辺が分かれば、高さは「面積×2÷底辺」で出る。たとえば面積60cm²・底辺20cmなら、60×2÷20＝6cm。
  • グラフの折れ目は、点がかどに着いた時。かどを曲がると、面積の増え方・へり方が変わる。
  • 同じ時間に動いた長さの比は、速さの比と同じ。

🔍 整理して解く

  1. グラフの正体を書く。Sは、三角形BCQと三角形CDPの面積の和。はじめはPもQもAにいる。どちらの三角形も 24×20÷2＝240cm²。はじめのSは480。
  2. 最初の折れ目は S＝60。PかQのどちらかが、かどに着いた。2つの場合を図と表でくらべる。
    Qが先にBに着いた場合Pが先にDに着いた場合
    0になった三角形BCQCDP
    60の三角形CDP。PD＝60×2÷20＝6cmBCQ。QB＝60×2÷24＝5cm
    Pが動いた長さ24−6＝18cm24cm
    Qが動いた長さ20cm20−5＝15cm
    「PのほうがQより速く」合わない合う
    先に着いたのはP。速さの比は 24：15＝8：5。
  3. 次に「12.8」の正体を決める。Sがはじめの480にもどった時。480になるのは、2つの三角形がどちらも240の時。三角形CDPは、PがBに着いたあと240。三角形BCQは、QがDに着いたあと240。Pが1周（88cm）してAで止まる時でも、Qは 88×5/8＝55cm しか進んでいない。55cmは、C（44cm）とD（64cm）の間。あとでそろうのはQのほう。だから12.8秒は、QがDに着いた時。

  5. PがDに着くのは 24÷8＝3秒後。QがBに着くのは 20÷5＝4秒後。4−3＝1。Pのほうが1秒早い。
答え：1秒早い
コツ：折れ目の数（60）は「どちらが先に着いたか」を決める材料。両方の場合を書いて、条件に合わないほうを消す。速さの比が出たら、もう1つの数（12.8）で本当の速さにする。

4 (1) 転がすのを止めたときのQOの長さ B・7点｜おうぎ形の転がり（弧の長さが同じ）
