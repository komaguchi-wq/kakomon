1 (1) 先生のコメントの空らん1・2 A・4点｜まざり型→資料問題（表の列くらべ）

👀 まず見るところ

【まざり型→資料問題】部品は表1の正体「A〜Dの おもりの数・角度X・長さ」と、コメントの「明らかにできるが／明らかにできない」。表の4列を2列ずつ見比べ、「1つだけちがう組」があれば明らかにできる、無ければできない、と決まる。

📚 前提知識

  • ある条件の影響を調べるには、その条件だけを変え、ほかはそろえる（対照実験）。2つ同時に変えると、どちらが原因か分からない。

🔍 こう読み解く

  1. ①は問題文が「角度X」と言っている。表1でBとCは角度だけがちがう（2個・25cm は同じ）→ 角度の実験はできる。

  3. おもりの数だけがちがう組は無い（Dは1個だが、Aとは角度も、Cとは長さもちがう）→ 2 ＝おもりの数（ア）。
  4. 落としやすい所: 1 と 2 を逆に入れること。「できる→できない」の順にコメントが並んでいるのを見てから書く。
答え：1 イ　2 ア

1 (3) おもりの数を調べるための変え方 7〜9 A・4点｜まざり型→条件文

👀 まず見るところ

【まざり型→条件文】部品は「下線部①，②が明らかになっている実験条件を変えずに」。A・B・Cは使用中なので、変えてよいのはDだけと直して書く → 選択肢はキ・クの2つにしぼれる。

📚 前提知識

  • おもりの数の実験には「数だけがちがう組」が要る。Dは1個なので、Dを 2個の列（A か C）と数以外が同じ になるように変える。

🔍 こう読み解く

  1. 条件を守る選択肢はキ（Dの長さを25cm）とク（Dの数を2個）だけ。ア〜カはA・B・Cを変えるので除外。
  2. キ: Dが 1個・5度・25cm になる → C（2個・5度・25cm）と数だけちがう → 比べられる。
  3. ク: Dが 2個・5度・50cm になる → 数が全部2個になり、数の実験ができない → ×。
  4. 落としやすい所: オ（Cの角度を10度）。Dの角度を10度にしてAと比べる手もあるが、選択肢のオは「Cを変える」なので条件に反する。主語（どの列か）を確かめる。
答え：キ

1 (4) おもり2個のつけ方（作図） B・4点｜まざり型→条件文（作図）

👀 まず見るところ

【まざり型→条件文】部品はノートの「ふりこの長さは，糸の長さではなく，支点からおもりの重心までの長さ」と、実験計画の「糸とおもりはすべての実験条件で同じものを使う」。2個にしても重心の高さが変わらない形＝横に並べる、と1行に直してから描く。

📚 前提知識

  • おもりを縦に2個つなぐと、全体の重心は2個のまん中＝1個のときより下に移る → ふりこの長さが長くなり、数の実験でなく長さの実験になってしまう。

🔍 こう読み解く

  1. 解答らんの図（糸と、糸の先の輪）をそのまま使う。
  2. 輪の下に、おもり2個を左右に並べて描き、どちらも同じ輪にかける。
  3. 2個の中心を同じ高さにそろえる（重心の高さが1個のときと同じになる）。
  4. 各おもりの下に小さなフックを描き足す（図3と同じ形）。
答え：解説の図を参照のこと。（声教の解答図は、糸の先の輪に、おもり2個を左右に並べて同じ輪にかけた形。2個の中心は同じ高さで、それぞれの下に小さなフックがある。）
コツ：B問題だが、ノートの「重心」の説明を読み直せば描ける。手を付ける合図は「ふりこの長さ＝支点から重心まで」を思い出せたとき。縦につないだ図は、重心が下がってふりこの長さが変わるので答えにならない。

1 (6) 水銀補正ふりこで調整がいらない理由 B・4点｜まざり型→素材文

👀 まず見るところ

【まざり型→素材文】設問は下線部④の理由。部品はまとめの「金属は温度の変化で伸びたり縮んだり」と、選択肢のちがい「重さ／体積」「上がり／下がり」の2か所に丸 → 温度で変わるのは体積、金属棒が伸びた分を打ち消す向きは上がり、で1つに決まる。

📚 前提知識

  • 温度が上がると、ものは体積がふえる（ぼう張）。重さは変わらない。液体の水銀も同じ。
  • 金属棒が伸びるとおもりが下がり、ふりこの長さが長くなる → 1往復が長くなって時計が遅れる。

🔍 こう読み解く

  1. 「重さが大きくなる」（ア・イ）は×。温度で重さは変わらない。
  2. 水銀の体積がふえると、入れ物の中で液面が上がる → 入れ物全体の重心が上がる（入れ物の大きさは変わらないという条件に注意）。
  3. 金属棒が伸びて重心が下がる分と、水銀の重心が上がる分が打ち消し合い、ふりこの長さはほぼ一定 → ウ。エは向きが逆。
答え：ウ
コツ：B問題。手を付ける合図は「2つの変化が打ち消し合う」と読めたとき。選択肢は4つとも後半が同じなので、前半の2語（体積・上がり）だけで切る。

2 (1) 水素が発生する実験 A・3点｜まざり型→素材文（すべて選ぶ）

👀 まず見るところ

【まざり型→素材文】部品は「アルミニウム粉末に20cm³の塩酸を加えると…気体が発生」と設問の「すべて選びなさい」に丸。発生する気体の正体を「水素」と1行書いてから、ア〜カの気体を1つずつ書く。

📚 前提知識

  • 水素: 金属（アルミニウム・亜鉛・鉄・マグネシウム）＋塩酸。アルミニウムは水酸化ナトリウム水溶液にも溶けて水素を出す。
  • 二酸化炭素: 石灰石・卵のから（炭酸カルシウム）＋酸、重そう＋酸。酸素: 過酸化水素水＋二酸化マンガン。

🔍 こう読み解く

  1. ア 石灰石＋塩酸 → 二酸化炭素。ウ 卵のから＋食酢 → 二酸化炭素。エ 重そう＋食酢 → 二酸化炭素。
  2. オ 過酸化水素水＋二酸化マンガン → 酸素。
  3. イ 亜鉛＋塩酸 → 水素。カ アルミニウム＋水酸化ナトリウム水溶液 → 水素。答えはイとカ。
  4. 落としやすい所: カを落とすこと。アルミニウムは酸にもアルカリにも溶ける金属。
答え：イ・カ

2 (2) 水素の集め方 A・3点｜まざり型→素材文

👀 まず見るところ

【まざり型→素材文】部品は「発生した気体の集め方としてもっとも適する」。気体の正体（水素）を「水に溶けにくい・空気より軽い」の2語で書けば、水上置換の図アに決まる。

📚 前提知識

  • 水に溶けにくい気体は水上置換（ア）。空気より軽く水に溶ける気体は上方置換（イ・口を下に向けて管を上へ）、重い気体は下方置換（ウ）。

🔍 こう読み解く

  1. 水素は水に溶けにくい → まず水上置換を選ぶ。空気と混ざらず、集まった量も見える。
  2. 落としやすい所: 「軽いから上方置換（イ）」と考えること。上方置換は、水に溶けやすくて水上置換が使えない気体（アンモニア）のための方法。
答え：ア

2 (4) アルミニウム0.63gをちょうど溶かす塩酸 A・4点｜まざり型→資料問題（限界の行）

👀 まず見るところ

【まざり型→資料問題】部品は表1で気体が「468cm³で一定」になっている所と、塩酸は全部「20cm³」。468＝塩酸20cm³を使い切ったときの気体、と正体を1行書けば、塩酸20cm³が溶かせるアルミニウムの重さが出せる。

📚 前提知識

  • 気体の量が増えなくなった＝塩酸が足りなくなった。そこから先はアルミニウムが余る。
  • ちょうど溶かす量は比例で求める（塩酸の体積とアルミニウムの重さは比例）。

🔍 こう読み解く

  1. 塩酸20cm³で気体468cm³。この気体を出すアルミニウムは 0.1×468÷130＝0.36g。つまり「塩酸20cm³ ⇔ アルミニウム0.36g」。
  2. 0.63gをちょうど溶かす塩酸は 20×0.63÷0.36＝35（cm³）。
  3. 落としやすい所: 0.4gと468を対応させること。0.4gのときは塩酸が先に無くなり、アルミニウムが0.04g余っている。
答え：35cm³

👀 まず見るところ

  1. 要素A（何を変えるか）: 息のかわりに「まわりの空気（吸う空気）」を袋に入れる。
