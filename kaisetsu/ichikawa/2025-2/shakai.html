【資料問題】部品は導入の年「2012年」「2013年」と、写真4の見出し「南気仙沼駅の駅舎（2011年7月12日撮影）」。写真4の正体を1行（震災直後にこわれた駅）→ 2003年の地図2にあった鉄道の代わり、と決まる。

📚 前提知識

  • 2011年3月11日の東北地方太平洋沖地震による東日本大震災で、JR線の線路や駅舎が津波でこわされた。
  • JR東日本は線路をバス専用道路にして、BRT（バス・ラピッド・トランジット）を導入した。のちに自治体も鉄道での復旧を断念し、BRTを本復旧として受け入れた。

✍️ 答案の組み立て

  1. 要素A（原因）：2011年の東日本大震災の津波（写真4の撮影日と、こわれた駅舎）。
  2. 要素B（何が起きたか）：JR線の駅舎や線路が破壊された（地図2にあった気仙沼港ぞいの鉄道が、地図1では一部を除いてなくなり、BRTになっている）。
  3. 要素C（だからBRT）：鉄道の代わりの手段として使われた。写真3「専用道路を走るBRT車両」が、線路のあとを道路にしたことを示す。
  4. 落としやすい所: 「震災があったから」で止めない。駅舎・線路がこわれた→その代わり、までつなげて「〜ため。」で終える。
模範解答：2011年の東日本大震災のときに発生した津波により，JR線の駅舎や線路が破壊され，その代替手段として用いられたため。

3 問4 気仙沼・駒ノ湯・酒田の気温と日照時間 B・4点｜資料問題・グラフ3つ

👀 まず見るところ

【資料問題】正体を1行「平均気温（℃）と日照時間（時間）」。日本海側の酒田は冬の日照時間が短いグラフ、内陸の高い所の駒ノ湯は気温がいちばん低いグラフ、と1つずつ決めれば残りが気仙沼。

📚 前提知識

  • 酒田は日本海側の気候。冬は雪の日が多く、冬の日照時間が短い。
  • 気仙沼は太平洋側の気候で、夏は雨が多く、夏の日照時間が短くなる。夏に北東から吹く冷たいやませの影響も受ける。駒ノ湯は内陸の標高の高い場所にあり、1年を通じて気温が低い。

🔍 こう読み解く

  1. 日照時間（▲の点線）が冬の1月・12月に大きく下がるのはc → 酒田。
  2. a・bのうち、1月の気温が0℃より下で、どの月もaより低いのはb → 駒ノ湯。
  3. 残るaは日照時間が1年中あまり変わらず、夏も伸びない → 気仙沼。a 気仙沼・b 駒ノ湯・c 酒田の組み合わせはア。
答え：ア

4 問1 日本の税制度 A・3点｜素材文・正誤の組み合わせ

👀 まず見るところ

【素材文】aの定義を3語で書く（納める義務の人≠納入する人＝直接税）。これは間接税の定義なのでaは誤。bは「所得の高い人たちから低い人たちへ」に丸 → 累進課税の話と決まる。

📚 前提知識

  • 直接税＝税を負担する人と納める人が同じ（相続税・所得税・法人税）。間接税＝負担する人と納める人がちがう（消費税）。
  • 所得税は、所得が高い人ほど税率が高い累進課税。経済格差を調整し、富を再分配するはたらきがある。

🔍 こう読み解く

  1. a：「異なる税を直接税」は直接と間接のすりかえ。相続税が直接税なのは正しいが、定義が逆 → 誤。
  2. b：累進課税で高所得者から多く集め、再分配する → 正。a誤・b正でウ。
  3. 落としやすい所: aは後半の「相続税」が正しいので、前半の定義で切る。
答え：ウ

4 問2 GNIと識字率・オーバー・エイジ・スチューデント C・4点｜資料問題・グラフ2つ・a〜cの正誤

👀 まず見るところ

【資料問題】本番では後回し。部品は数の言葉「10,000ドルを上回る国はすべて」「30%を上回る国もある」。aは10,000〜20,000ドルの点、bは30%の線より上の点をグラフで探す。cは2つのグラフを結べるかで決まる。

📚 前提知識（あれば答え合わせに使う）

  • 「すべて」は1つでも例外があれば誤。「〜もある」は1つあれば正。

🔍 こう読み解く

  1. a：グラフ1で、一人あたりGNIが10,000〜20,000ドルの間に90%に届かない点がある。すべて90%を上回るのは20,000ドルを上回る国 → 誤。
  2. b：グラフ2で、20,000ドルより左に30%の線を超える点がある → 正。
  3. c：2つのグラフからは「GNIが低い国ほど識字率が低く、オーバー・エイジ・スチューデントの割合が高い」までは読めるが、識字率と割合を直接結ぶことはできない → 誤。a誤・b正・c誤でカ。
答え：カ

4 問3 現代日本の政治 B・3点｜素材文・正誤の組み合わせ

4 問4 参政権にかかわる裁判と憲法の条文 A・6点｜素材文・条文の選択

👀 まず見るところ

【素材文】1文につき手がかり1語に丸。aは「最高裁判所裁判官がふさわしいかどうか」→ 国民審査＝公務員を辞めさせる権利、bは「一票の格差」→ 平等。それぞれ条文の中の同じ意味の言葉と結ぶ。

📚 前提知識

  • 最高裁判所裁判官（長官をふくめて15名）は国民審査を受ける。これは第15条の公務員の選定・罷免権にかかわる。
  • 一票の格差は、選挙区によって一票の重さがちがう問題で、第14条の法の下の平等にかかわる。

🔍 こう読み解く

  1. a：国民審査は、ふさわしくない裁判官を国民が辞めさせられるしくみ → 「公務員を選定し、及びこれを罷免する」のイ。
  2. b：一票の重さが選挙区でちがう＝平等の問題 → 「法の下に平等」のア。
  3. 残りはウ＝思想及び良心の自由（第19条）、エ＝信教の自由（第20条）、オ＝国籍離脱の自由（第22条）で、どちらとも結びつかない。
  4. 落としやすい所: aを「投票に参加できない＝平等」と読んでアにしない。投票の中身が「裁判官を辞めさせるかどうか」である点で結ぶ。
答え：a イ　b ア

4 問6 投票コストを下げる工夫 B・3点｜素材文・提案の判断

👀 まず見るところ

【素材文】部品は「投票コストを下げる」。千葉さんの提案は「小さな投票所を統合」に丸 → 駅から遠くに住む車を使えない人には投票所が遠くなる、と決まる。※3の定義があるので手を付ける価値がある。

📚 前提知識（あれば答え合わせに使う）

  • 投票コスト＝投票を妨げたり、ためらわせたりするしくみやしかけ（本文の※3）。

🔍 こう読み解く

  1. 千葉さん：小さな投票所の統合は、行政には効率がよく費用も減らせる。しかしターミナル駅から離れた所に住む、運転免許を持たない人や返納した高齢者には投票所が遠くなり、かえって投票コストを上げる → ふさわしくない。
  2. 市川さん：インターネットをよく使う若者が自宅や外出先から投票できれば、投票所へ行く手間が減る → 投票コストを下げる工夫。市川さんのみふさわしいのでウ。
答え：ウ
