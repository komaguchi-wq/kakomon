1 (1) 6.28×7−1.57×32/3＋3.14÷3 A・6点｜計算のくふう

👀 まず見るところ

【条件文】部品は「6.28」「1.57」「3.14÷3」。どれも 3.14×□ に直して書く（6.28＝3.14×2、1.57＝3.14×1/2、÷3＝×1/3）→ 3.14でくくれば、かっこの中の計算だけで決まる。

📚 前提知識

  • A×B＋A×C＝A×(B＋C)。同じ数をかけた式は、まとめて1回のかけ算にできる。たとえば 3×7＋3×3＝3×10。
  • ÷3 は ×1/3 と同じ。わり算は分数のかけ算に直せる。

🔍 整理して解く

  1. 3つの部分を、全部 3.14×□ の形に書き直す。 
    6.28×7      ＝3.14×2×7    ＝3.14×14
1.57×32/3   ＝3.14×1/2×32/3＝3.14×16/3
3.14÷3      ＝3.14×1/3
  2. 3.14でくくる。3.14×(14−16/3＋1/3)。
  3. かっこの中を計算する。14＝42/3 だから、42/3−16/3＋1/3＝27/3＝9。
  4. 3.14×9＝28.26。
  5. 落としやすい所: 1.57 を「3.14の半分」と見ぬくこと。ここを見落とすと 1.57×32/3 の筆算に入ってしまう。
答え：28.26

1 (2) 空らんア・イに入る記号 A・6点｜記号の穴うめ

👀 まず見るところ

【条件文】部品は右の「20 2/5」と、記号が決まっている「6÷(7＋8)」。20.4 と 0.4 に直して書く → 式は (1＋2ア3)×4＋0.4イ9＝15.4 になり、アの4通りを試すだけで決まる。

📚 前提知識

  • 計算できる所は先に計算して、式を短くする。6÷(7＋8)＝6÷15＝0.4。
  • 「−5」と「＋10」は右へ移せる。左から −5＋10 を消すかわりに、右の 20.4 に ＋5−10 をする。

🔍 整理して解く

  1. 右を小数にする。20 2/5＝20.4。−5＋10 を右へ移して、20.4＋5−10＝15.4。式は (1＋2ア3)×4＋0.4イ9＝15.4 になる。
  2. (1＋2ア3)×4 を4通り書き出す。
    ア(1＋2ア3)×4
    ＋(1＋2＋3)×4＝24
    −(1＋2−3)×4＝0
    ×(1＋2×3)×4＝28
    ÷(1＋2÷3)×4＝20/3
  3. 24 に 0.4 と 9 を組み合わせて 15.4 にできるか見る。24＋0.4−9＝15.4。合う。
  4. 0・28・20/3 では、0.4と9をどう組んでも 15.4 にならない。だから アは＋、イは−。
  5. 落としやすい所: ÷のときは (1＋2÷3)×4＝20/3 で、6.66…と割り切れない。15.4 との差 8.73… は 0.4 と 9 から作れないので、÷は先に消してよい。
答え：ア ＋ イ －

1 (3) 3種類の商品の売り上げから、Aの値段 A・6点｜和差算（売り上げ）

👀 まず見るところ

【条件文】部品は「総売り上げが50000円」と、売り上げの差「300円多かった」「1000円少なかった」。お金だけの線分図に置く → 和差算でAの売り上げが先に出る。個数は別の図にする。

📚 前提知識

  • 和差算。3本の線分図で、いちばん長いものにそろえる。合計に差をたして3でわれば、いちばん長いものが出る。
  • 売り上げ＝値段×個数。だから 値段＝売り上げ÷個数。

🔍 整理して解く

  1. 売り上げ（お金）の線分図を描く。Aがいちばん長い。BはAより300円短く、CはAより1000円短い。
  2. 全部をAの長さにそろえる。合計に差をたす。(50000＋300＋1000)÷3＝17100円。これがAの売り上げ。
  3. Cの売り上げは 17100−1000＝16100円。Cの値段は230円だから、Cの個数は 16100÷230＝70個。
  4. 個数の線分図を描く。AはBより50個少ない。Cは70個。
  5. AとBの個数の和は 300−70＝230個。Aの個数は (230−50)÷2＝90個。
  6. Aの値段は 17100÷90＝190円。
  7. 落としやすい所: 「値段が70円高い」は答えを出すのに使わない。確かめに回す（Bの値段 16800÷140＝120円、190−120＝70円で合う）。
答え：190円

1 (4) 円の周を12等分した図の角⑦ A・6点｜角度（円の12等分）

👀 まず見るところ

【条件文】部品は「円の周を12等分」。中心Oを打ち、Oと点を結んで「1つ分＝30度」を図に置く → 半径2本でできる二等辺三角形の底角と、中心の角60度の外角で⑦が出る。

📚 前提知識

  • 円の周を12等分すると、となりどうしの点と中心がつくる角は 360÷12＝30度。
  • 半径2本と弦でできる三角形は二等辺三角形。底角は (180−頂角)÷2。
  • 三角形の外角は、となり合わない2つの内角の和。

🔍 整理して解く

  1. 中心Oを打ち、OとA、OとBを結ぶ。横の直径の左はしをC、ななめの線と直径の交わる点をDとする。
  2. AからBまで、周の点は5つ分。角AOB＝30×5＝150度。
  3. OA＝OB（半径）だから三角形OABは二等辺三角形。角OAB＝(180−150)÷2＝15度。
  4. AからCまでは2つ分。角AOC＝30×2＝60度。
  5. ⑦は三角形OADの外角。⑦＝角OAD＋角AOD＝15＋60＝75度。
  6. 落としやすい所: 5つ分を数えまちがえない。Aから下のBまで、点を1つずつ指で数える。
答え：75度

2 (1) 50秒後にXを「通過中」の電車Aの速さのはんい B・6点｜通過算（はんい）

👀 まず見るところ

【条件文】部品は「50秒後のとき地点Xを通過中」とAの長さ「160m」。「通過中」を「先頭がXに着いてから、最後尾がXを出るまで」に直して図に置く → 50秒で進む道のりは600m以上760m以下。この幅が見えれば手を付けてよい。

📚 前提知識

  • 通過算は、電車の先頭（または最後尾）1点の動きで考える。地点を「通過し終わる」までに、電車は自分の長さぶん多く進む。
  • 秒速をm、時速をkmに直すには ×60×60÷1000（＝×3.6）。秒速10m なら時速36km。

🔍 整理して解く

  1. X・Yと電車Aの箱を描く。Aは YからXへ進む。いちばん手前は「先頭がちょうどXに着いた」①、いちばん先は「最後尾がちょうどXを出る」②。
  2. 50秒で進んだ道のりは、600m以上 760m以下。
  3. 秒速に直す。600÷50＝12m以上、760÷50＝15.2m以下。
  4. 時速に直す。12×60×60÷1000＝43.2km、15.2×60×60÷1000＝54.72km。
  5. 確かめ: 12×3.6＝43.2、15.2×3.6＝54.72。合う。
答え：ア 43.2 イ 54.72
コツ：「通過中」は1つの時刻ではなく、はんい。「着いた瞬間」と「出る瞬間」の2つの箱を描くと、以上・以下の2つの数が自然に出る。

2 (2) 18秒後にすれ違う電車A・B、Aの最後尾がXを通過する時刻 A・6点｜通過算（出会い）

👀 まず見るところ

【条件文】部品は「同時に通過」と「18秒後に…先頭がすれ違い」。向かい合って進む出会い算に直して書く → 速さの和＝600÷18。Bの時速72kmを秒速20mに直せば、Aの秒速が出る。

📚 前提知識

  • 出会い算。向かい合って進む2つが出会うまでに進んだ道のりの和＝はじめの間の道のり。600mを18秒で分け合った。
  • 時速72km は 72×1000÷60÷60＝秒速20m。

🔍 整理して解く

  1. AはYからX、BはXからYへ、先頭どうしが向かい合って進む。18秒後に先頭がすれ違う。
  2. 速さの和は 600÷18＝100/3 m（秒速）。
  3. Bの秒速は 72×1000÷60÷60＝20m。Aの秒速は 100/3−20＝40/3 m。
  4. Aの最後尾がXを通過するのは、先頭がYを通過してから 600＋160＝760m 進んだとき。
  5. 760÷40/3＝760×3/40＝57秒後。
  6. 落としやすい所: 「最後尾がXを通過」には、600mにAの長さ160mをたす。先頭だけで 600÷40/3＝45秒 としない。
答え：57秒後

2 (3) 先頭も最後尾も並んで通過した電車B・C、Cの長さと速さ B・6点｜通過算（追いつき）

👀 まず見るところ

【条件文】部品は「最後尾が並んで地点Yを通過」と「その60秒後にCの先頭とBの最後尾が並び」。並んだ時刻を図に置く → Bの最後尾がYを通過するまでの秒数は、Bの数字だけで出る。そこから速さの差へ。

📚 前提知識

  • 追いつき算。同じ向きに進む2つの差は、（速さの差）×時間 で開く。100秒で200m開いたなら、速さの差は秒速2m。
  • 電車の最後尾が地点を通過するまでに進む道のり＝地点までの道のり＋電車の長さ。

🔍 整理して解く

  1. Bの秒速は20m（(2)で出した）。Bの最後尾がYを通過するのは、600＋200＝800m 進んだとき。800÷20＝40秒。
  2. Cの最後尾も同じ40秒でYを通過した。だからCも40秒で「600m＋Cの長さ」を進んだ。
  3. 先頭をそろえてXを出てから、40＋60＝100秒後にCの先頭がBの最後尾に並ぶ。
  4. このときBの先頭は、Cの先頭よりBの長さ200mだけ前にいる。100秒で200mの差 → 速さの差は 200÷100＝秒速2m。
  5. Cの秒速は 20−2＝18m。時速に直すと 18×60×60÷1000＝64.8km。
  6. Cは40秒で 18×40＝720m 進んだ。Cの長さは 720−600＝120m。
  7. 確かめ: Cの最後尾は (600＋120)÷18＝40秒でYを通過。Bと同じ。合う。
答え：長さ…120m 時速…64.8km
コツ：「並んだ」が2回出てくる問題は、2回目の並びまでの合計時間（40＋60＝100秒）と、そのときの差（Bの長さ200m）を先に決める。

1〜2 まとめ この回の入口

  • 計算は「同じ数でくくる」「右を先に小数に」。3.14・1.57・6.28 は全部 3.14×□。
  • 条件が多い文章題は、お金の図と個数の図を分ける。使わない条件（70円）は確かめに回す。
  • 通過算は X・Y の線と電車の箱を描き、「最後尾が通過」なら電車の長さをたす。

3 (1)(i) (1, 1)(2, 1)(2, 2)に加える1つ A・6点｜条件の整理（両端から決める）

👀 まず見るところ

【条件文】部品は「左端に(0, 0)の棒磁石が、右端に(1, 0)」と「N極に書かれた数字とS極に書かれた数字がそれぞれ同じ」。6つの箱を描き、左から2番目はN極が0、右から2番目はS極が1、と図に置く → 残る1つの入る場所が決まる。

📚 前提知識

  • くっつく所は、左の磁石のS極と右の磁石のN極。だから「左のS極の数字＝右のN極の数字」が5か所続く。(0, 0)のとなりはN極が0の磁石、(1, 0)のとなりはS極が1の磁石に決まる。
  • 残った7つのうち、N極が0なのは(0, 1)と(0, 2)の2つだけ。S極が1なのは(1, 1)と(2, 1)の2つだけ。この4つが両端のとなりの候補。

🔍 整理して解く

  1. 6つの箱を描く。左から2番目（ア）はN極が0、右から2番目（エ）はS極が1。間は「前のS極＝次のN極」でつなぐ。
  2. わかっている3つ (1, 1)(2, 1)(2, 2) に、N極が0のものはない。だから残る1つがアで、(0, 1)か(0, 2)。3つはイ・ウ・エに入る。
  3. エはS極が1だから、3つの中では(1, 1)か(2, 1)。(1, 1)のS極は1なので、右どなりはN極が1の磁石。3つの中にN極が1のものはないので、右どなりは右端の(1, 0)。つまり(1, 1)はいちばん右のエ。

    決まり方N極が0S極が2（ウのN極）S極が1 → (2, 1)(1, 1)

  4. ウはS極が1だから(2, 1)。イはS極が2だから(2, 2)。イのN極が2なので、アのS極は2。アは(0, 2)。
  5. たしかめ。(0, 0)(0, 2)(2, 2)(2, 1)(1, 1)(1, 0)。くっつく所は 0＝0、2＝2、2＝2、1＝1、1＝1。合う。
  6. 落としやすい所: 答えは「残る1つ」の(0, 2)。並べ終えた安心感で、イの(2, 2)を書かないように、問題文の「残る1つの棒磁石を答えなさい」に丸をつけておく。

コツ：一列にくっつける問題は、両端からせめる。「左端のとなりはN極が0」「右端のとなりはS極が1」の2つで、候補が2つずつにしぼれる。

👀 まず見るところ

【条件文】部品は(i)の図と、変わった3つ「(1, 1), (1, 2), (2, 0)」、それに「くっつけられない場合は(×, ×)」。3つを(i)の箱に置く → 右から2番目に入るものが1つしかなく、その左が空く。行きづまったら、そこで手を止めてよい。

3 (1)(iii) (0, 1)(2, 1)(2, 2)に加える1つ A・6点｜条件の整理（2通りを試す）

👀 まず見るところ

【条件文】部品は(i)の図と、変わった3つ「(0, 1), (2, 1), (2, 2)」。今度はN極が0の(0, 1)が3つの中にある → アが(0, 1)か、それとも残る1つの(0, 2)か、の2通りを箱に置いて試す。

📚 前提知識

  • 両端のとなりの決まりは(i)と同じ。アはN極が0、エはS極が1。
  • 候補が2つあるときは、片方を入れてみて行きづまるかを見る。(ii)で「入れるものがなくなる」形を見ているので、同じ形が出たらその候補を消す。

🔍 整理して解く

  1. まず、アを残る1つの(0, 2)にしてみる。すると3つ (0, 1)(2, 1)(2, 2) がイ・ウ・エ。エはS極が1だから(2, 1)。ウはS極が2だから(2, 2)。イはS極が2のはずだが、残りの(0, 1)はS極が1。イに入れるものがない。この道は(ii)と同じで行きどまり。
  2. だからアは(0, 1)。アのS極が1なので、イのN極は1。(2, 1)と(2, 2)はN極が2だから、イに入るのは残る1つ。未使用の中でN極が1なのは(1, 1)か(1, 2)。

4 (1) 三角形GDHと四角形EBFHの面積比 B・7点｜相似（辺をのばして外に作る）・面積比

👀 まず見るところ

4 (2) コンパス2回で正方形にぴったり入る円 C・7点｜作図（辺の真ん中をコンパス1回で）

  • 正方形にぴったり入る円は、中心が対角線の交点、半径が1辺の半分。半径を作るには、どれか1辺の真ん中の点があればよい。(1)で、BI＝ABのときFがBCの真ん中になった。これを逆に使う。

5 (1) ふたつきの容器Xを沈めて取り出す A・6点｜水の深さと体積（あふれる分）

👀 まず見るところ

【条件文】部品は「底面積の比は1：3」と「ふたのしてある」。Aの底面積を3、Xを1と直して書き、水の体積を 3×9＝27 と図に置く → ふたがあるので水はXに入らず、Xの体積のうち空きをこえた分だけあふれる。

📚 前提知識

  • 円柱の底面積は、比の数をそのまま使ってよい。Aを3、Xを1とすると、水の体積は 3×9＝27、Aの空きは 3×（10−9）＝3。
  • 沈めた物の体積のぶんだけ水面が上がる。空きより大きければ、差があふれる。あふれた水はもどらない。

🔍 整理して解く

  1. Aの底面積3、水27、空き3を図に書く。Xの体積は 1×6＝6。
  2. Xを底まで沈めると、6の体積ぶん水が上がる。空きは3なので、6−3＝3があふれる。
  3. Xを取り出すと、残る水は 27−3＝24。水面の高さは 24÷3＝8cm。
  4. 落としやすい所: 「水面は10cmまで上がる」で止めない。聞かれているのは取り出した後。あふれた3を27から引く。
答え：8cm

5 (2) 水が入る容器Bを沈めて取り出す B・7点｜水の深さと体積（水が入り始める瞬間）

👀 まず見るところ

【条件文】部品は「最大9.5cmまで上がり」と「9cmで一致」。9.5cmは「Bのふちが水面に着いた瞬間」、9cmは「Bが底にあり満水」の絵に直して描く → 1枚目からBの容積、2枚目からBの高さが出る。2枚が描ければ手を付ける。

📚 前提知識

  • ふたのない容器は、ふちが水面より下がった瞬間から水が入り、水面はそこから下がる。だから水面がいちばん高いのは、ふちがちょうど水面に着いたとき。
  • そのとき、Aの水面より下は「水」と「Bの容積」でちょうどうまっている。水27は変わらないので、Bの容積＝3×9.5−27。
  • Bが底についたとき、外も中も9cmで止まっている。水は外から中へ、外の水面がふちより高い間だけ入る。止まった高さ9cmがBのふちの高さ。

🔍 整理して解く

  1. 水が入り始める瞬間の絵を描く。Aの水面は9.5cm。水面より下は水27とBの容積。Bの容積＝3×9.5−27＝28.5−27＝1.5。9.5cm＜10cmなので、ここまでにあふれてはいない。
  2. Bが底についた絵を描く。外も中も9cmで一致しているので、Bの高さは9cm。Bの底面積は 1.5÷9＝1/6。
  3. Bの中には9cmまで水が入っている。その体積は 1/6×9＝1.5。Bを取り出すと、この1.5もいっしょに出ていく。
  4. 残る水は 27−1.5＝25.5。水面の高さは 25.5÷3＝8.5cm。
  5. たしかめ。Bが底についたとき、外の水は 27−1.5＝25.5、Bの容積1.5。合わせて27＝3×9。水面9cmと合う。
答え：8.5cm
コツ：「最大○cm」は、水が入り始める瞬間の合図。その瞬間の絵で「水面より下＝水＋容器の容積」の式を立てる。

5 (3) 途中まで水が入った容器Cを沈めて取り出す C・7点｜水の深さと体積（あふれた後の移動）

👀 まず見るところ

【条件文】本番では後回し。部品は「水面の高さが7cm」と「Cの途中まで水が入り…5cm」。中が5cmで止まり外が7cm → Cのふちは7cm、と直して書く。あふれた後の「外で減った水＝Cに入った水」でCの底面積が出る。

📚 前提知識

  • 水は外の水面がふちより高い間だけ入る。中が5cmで止まり、外が7cmなら、ふちの高さ（Cの高さ）は7cm。Cが底についたとき、Aの水面より下は「外の水」と「Cの7cm分の柱」でできている。

🔍 整理して解く

  1. 終わりの絵（Cが底）を描く。Cの底面積を□とすると、水の合計は 7×3−7×□＋5×□＝21−2×□。これは27より少ないので、途中であふれている。あふれたあと、Cのふちが水面に着くまで水面は10cmのまま → 水が入り始める瞬間の絵は「Aが10cmまでいっぱい、Cのふちも10cm」。
  2. 2枚の絵を比べる。どちらもCの柱の高さは7で同じ。外の水は 10×3−7×□ から 7×3−7×□ へ、3×3＝9だけ減った。この9がCの中の5cm分 → 5×□＝9、□＝1.8。
  3. Cを取り出すと、外の水だけ残る。(3−1.8)×7＝8.4。水面の高さは 8.4÷3＝2.8cm。
答え：2.8cm
コツ：声の教育社の解説は、入り始めの絵の「外側の7〜10cm」（高さ3）と終わりの絵の「Cの中の3〜5cm」（高さ2）が同じ体積、として底面積の比 2：3 → 3×3/5＝1.8 と出している。「外で減った9＝中に入った9」と同じこと。

3〜5 まとめ この回で繰り返し出た入口

  • 並べる・くっつける問題は、両端から「となりに入れるものの条件」を書く（3）。候補が2つずつにしぼれ、行きどまりで(×, ×)も判断できる。
  • 比が2種類ある正方形は1辺を最小公倍数にして長さを書き、線をのばして外に「ちょうちょ型」を作る（4）。
  • 容器を沈める問題は「水が入り始める瞬間」と「底についたとき」の2枚の絵を描き、水面より下＝水＋容器の体積で式にする（5）。
