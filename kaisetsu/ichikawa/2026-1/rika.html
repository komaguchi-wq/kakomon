1 (1) ホバリング中に1枚のプロペラが支える力 A・4点｜条件文・計算

👀 まず見るところ

【まざり型→条件文】部品は「ドローンの重さは60g」と「対角線の交点が重心」に丸。重心が長方形のまん中＝4枚のプロペラから等しい距離、と図2に書く → 60gを4等分すれば決まる。25cmという高さと表の80gは、この問には使わない。

📚 前提知識

  • 空中で静止（ホバリング）しているとき、プロペラが支える力の合計＝ドローンの重さ。重心が4枚のまん中にあれば、4枚に等しく分かれる。

🔍 こう読み解く

  1. 支える力の合計は重さと同じ60g。
  2. 重心は対角線の交点＝4枚から同じ位置 → 60÷4＝15（g）。割り切れるので四捨五入はいらない。

答え：15g

1 (2) 台ばかりが示す値の説明文 A・4点｜素材文・穴うめ計算

  3. 落としやすい所: 1に80と書くこと。「支えるためなら」の文は理想の値（60）で、80は実際に表で測った値。

1 (6) 回転数と電池の消費 B・4点｜素材文・正しいもの

👀 まず見るところ

📚 前提知識

  • 空気は気温が高い・気圧が低いほどうすい（密度が小さい）。うすい空気では1回転あたり押し出せる空気が少ないので、同じ力を出すには回転数を上げる。

🔍 こう読み解く

  1. エ「気圧が低い山地では回転数を大きく」→ 空気がうすい → 回転数を上げる → ○。
  2. イ「気温が高い地域では小さくてすむ」→ 気温が高いと空気はうすい → むしろ大きく必要 → ×。ウ「プロペラを大きくすると回転数も大きく」→ 1回転で押せる空気が増えるので回転数は小さくてすむ → ×。
  3. ア「低速で前進の方が回転数を大きく」→ (4)のとおり速く進むほど後方のプロペラをより速く回してかたむける必要がある → 低速の方が小さくてよい → ×（自分で切った）。
答え：エ

2 (2) 最も濃くなる操作 B・4点｜条件文・濃さの計算

👀 まず見るところ

【条件文】部品は定義「元の体積の10分の1にすることを『10倍に濃縮』」。濃さ＝元の果汁の量÷最後の体積、に直して書く。5つ全部は計算せず、同じ800L同士・500L同士で「倍率が大きく、加える水が少ない」方を残してから2つだけ計算すれば、時間をかける価値がある。

📚 前提知識

  • 濃さは「果汁の成分の量÷全体の体積」。成分の量は元の果汁の量に比例するので、元の量÷最後の体積が大きいほど濃い。

🔍 こう読み解く

  1. ア・イ・ウ（800L）: 倍率はイ・ウの5倍が大きく、加える水はウの50Lが少ない → ウが一番濃い。エ・オ（500L）: 倍率3倍のオ。
  2. ウ: 800×1/5＝160（L）、水を加えて 160＋50＝210（L）→ 800÷210＝3.8…（倍）。
  3. オ: 500×1/3＝500/3（L）、水を加えて 500/3＋50＝650/3（L）→ 500÷650/3＝2.3…（倍）。
  4. 3.8…倍＞2.3…倍 なので ウ。
答え：ウ

2 (6) 半分とけた状態でふたを開けると B・4点｜素材文・正しいもの

2 (7) とけ具合と味の濃さ B・4点｜素材文・正しいもの

👀 まず見るところ

【素材文】設問は「たくさんとけているとき」と「少しとけているとき」の味の濃さ。部品は「凍らせた」→ 凍るときは水だけが先に凍り、濃い部分が最後に凍る、と順番を書く → とけるときはその逆で、濃い部分が先にとける。

📚 前提知識

  • ものがとけた水は凍りにくい（凍る温度が下がる）。だからジュースは水の部分が先に凍り、糖分などをふくむ濃い部分が最後に凍る。

🔍 こう読み解く

  1. 凍る順: 水だけ → だんだん濃い部分 → 最も濃い部分（最後）。
  2. とける順はその逆: 最も濃い部分が先にとけ、あとから水の部分がとけてうすまる。
  3. 少しとけたときの液体＝濃い部分だけ → 味が濃い → イ。凍らせたジュースの最初の一口が濃くて最後が水っぽいのはこのため。
答え：イ

【資料問題】部品は吹き出しの「メダカI」と「メダカII」の5項目を見くらべて変わった4つ（光沢・目の位置・体型・体色）を書き出すことと、但し書き「新しい形質を1つずつ」に丸。あとは表のC・D・Eを「Iと1つだけちがうもの」から順に並べるだけで決まる。

📚 前提知識（あれば答え合わせに使う）

  • かけ合わせでは、両親の形質のどちらかが子に受け継がれる（図1）。この問題では「1回のかけ合わせで変わるのは1つ」と決められているので、1つずつちがいを追えばよい。

🔍 こう読み解く

  1. IとIIで同じなのは「ヒレ：長い」だけ。変わるのは 光沢・目の位置・体型・体色の4つ＝1〜4に1つずつ入る。
  2. 表のC・D・Eのうち、Iと1か所しかちがわないのは D（体色が白→黒）。だから 1＝黒。
  3. Dと1か所ちがうのは C（光沢あり→なし）→ 2＝光沢なし。Cと1か所ちがうのは E（細い→太い）→ 3＝太い。残った目の位置（上→横）が 4＝横。
  4. 整理すると次の表。表で「黒・光沢なし・太い・横」の並びは カ。
    IDCEII
    光沢ありありなしなしなし
    目の位置上上上上横
    体型細い細い細い太い太い
    体色白黒黒黒黒
    変わった形質1 黒2 光沢なし3 太い4 横
答え：カ
コツ：選択肢ア〜クは「黒・光沢なし・太い・横」の並べかえ。表から順番を決めてから選択肢を見ると、見まちがいがない。

3 (6) シャチがラッコを食べるようになると、ラッコ・ウニ・ジャイアントケルプはどう変わるか B・4点｜資料問題・矢印をたどる

👀 まず見るところ

【資料問題】部品は本文の「シャチが…ラッコを食べるようになりました」と、図3の縦1列「ジャイアントケルプ→ウニ→ラッコ」の矢印。ラッコからシャチへの点線の矢印が実線に変わったと図に書きこめば、下へ1段ずつ＋－が決まる。

📚 前提知識

  • 矢印は「食べられる→食べる」の向き。食べる側が増えると食べられる側は減り、食べる側が減ると食べられる側は増える。1段ごとに＋と－が入れかわる。

🔍 こう読み解く

  1. シャチに食べられるようになったラッコは 減る（－）。
  2. ラッコが減ると、ラッコに食べられていたウニは食べられる数が減って増える（＋）。
  3. ウニが増えると、ウニに食べられるジャイアントケルプは減る（－）。
  4. 3つとも変化するので「△」はこの問題では使わない。完答なので、矢印を1本ずつ指でたどって書く。
答え：ラッコ…－・ウニ…＋・ジャイアントケルプ…－

3 (7) 逃げ出したハイブリッド魚の増殖を防ぐためにもたせる形質 B・5点｜記述

👀 まず見るところ

【素材文】設問は「どのような形質をもたせるか」。部品は「増殖による問題を防ぐ」と「生まれてくるハイブリッド魚に」に丸 → 増えられない＝子をつくれない魚にする、と決まる。「具体的に」は、子をつくる仕組みの言葉（精子・卵）で書けという指示。

📚 前提知識

  • 本文の最初の段落: 子ができるのは精子と卵が結合（受精）したとき。精子や卵がつくれなければ、在来魚との間にも子は生まれない。
  • 本文の問題点の3つめ「在来魚との間に子が生まれ、在来魚本来の個体数が減少する」は、ハイブリッド魚が子をつくれると起こる。

✍️ 答案の組み立て

  1. 要素A（何を）: 精子や卵（卵だけ・精子だけでなく両方）。
  2. 要素B（どうする）: まったくつくれない形質。「つくりにくい」では増殖が止まらないので「まったく」を入れる。
  3. 「精子や卵がまったくつくれない形質」の形にまとめる。別の書き方として「卵や精子に受精する能力がまったくない形質」も可（声の教育社の解説）。「外に逃げないようにする」は設問の「形質」に答えていない。
答え：精子や卵がまったくつくれない形質。

4 (2) 40万年前と現在をくらべた宮古島の変化 B・4点｜資料問題・グラフと数値の大小

👀 まず見るところ

【資料問題】部品は資料の正体「平均海水面の高さ・m・現在を0mとする・万年前」を1行と、問題文の「40万年前までは，島全体が海底」「現在の最高地点は海抜110m程度」に丸。海水面の変化はグラフの40万年前の値で決まり、土地の持ち上がりは110mとの差で決まる。

📚 前提知識

  • 島が海底から陸になるには「海水面が下がる」か「土地が隆起する」かのどちらか、または両方。設問はこの2つの量の大小を聞いている。
  • グラフは「現在の海水面を0m」としているので、プラスは今より海面が高かった時期。

🔍 こう読み解く

  1. グラフの横軸40万年前を読む → 海水面は0mより上の 約30m（声の教育社の読み）。40万年前から現在までに海水面は約30m「低下」した。「上昇」のウ・エはここで消える。
  2. 40万年前、島の最高地点（今110mの所）は海底だった＝そのときの海水面（＋30m）より低かった。
  3. 今は110mなので、土地は少なくとも 110－30＝80m以上持ち上がった。海水面の低下30mより土地の隆起80m以上の方が大きい → ア。
  4. 本番で手を付けるかどうか: グラフの40万年前の値を読んだ時点で「海面は下がった」と言えれば、あとは引き算だけなので取る。
答え：ア

4 (3) 宮古島周辺に断層を生じさせた力 B・4点｜資料問題・断面図と地図

👀 まず見るところ

【資料問題】部品は図3の東西断面で「断層をはさんでどちら側が下がったか」と、図2で「断層の線がのびる向き」（北西－南東）。下がり方で「引っぱる／つぶす」、線の向きで「北東－南西／北西－南東」が決まる。

📚 前提知識

  • 断層面の上に乗っている側（上盤）が ずり落ちていれば正断層＝両側から引っぱられてできる。乗り上がっていれば逆断層＝両側からつぶされてできる。
  • 断層は力の向きと垂直に近い向きにのびる。引っぱる力の向きは、断層の線と直角。

🔍 こう読み解く

  1. 図3の東西断面: 断層の線は西から東へ下がる向きにかたむき、東側（上に乗っている側）の地層が1段ずつ下がっている → ずり落ち＝正断層＝引っぱられる力。「つぶされる」のイ・エが消える。
  2. 図2の断層の線は、左上（北西）から右下（南東）へのびている。引っぱる力はこれと直角 → 北東－南西。
  3. 「引っぱる」×「北東－南西」＝ア。
  4. 本番で手を付けるかどうか: 図3で「どちらが下がったか」が見えたら取れる。見えなければ、図2の向きだけで ア・イ に絞って先へ進む。
答え：ア

4 (4) 琉球石灰岩を利用した地下ダムの利点として誤っているもの A・4点｜素材文・誤っているもの

👀 まず見るところ

【素材文】聞かれ方「誤っているもの」に線。部品は本文の「地下の石灰岩層に水をためる」＝水は地面の下にあって流れ落ちない、に丸。ア〜オを「地下に水がある」と合うかどうかで1つずつ○×をつける。

📚 前提知識

  • 水力発電は、高い所から流れ落ちる水の勢いで発電機を回す。地下にためた水には落差がないので発電には向かない。
  • 地下ダムは地表を変えないので、生態系への影響が小さく、ダムの上の土地もそのまま使える（本文の「地表部分を今までと同じように利用できます」）。

🔍 こう読み解く

  1. ア「水力発電を行いやすい」→ 地下の水は流れ落ちない → ×＝これが誤り。
  2. イ 水はかたい石灰岩の穴の中にたくわえられるので、水位が下がっても地盤はしずみにくい → ○。ウ 地下は日光が当たらず微生物が増えにくい → ○。
  3. エ 本文の「地表部分を今までと同じように利用できる」と同じ内容 → ○。オ 地下の止水壁にひびが入っても、地表のダムのように水があふれ出すことはない → ○。
  4. 落としやすい所: 本文に書かれている利点（エ）を「書いてあるから答えではない」と先に外すと速い。
答え：ア

4 (5) 水を最も多くためられる地下ダムの位置 B・4点｜資料問題・断面図から地図へ

👀 まず見るところ

【資料問題】部品は図3の北南断面で「地層は南へ行くほど下がる」ことと、条件文の「厚さや傾きがどこでも変わらない」に丸。水は低い方＝南へ流れるので、止水壁は南のはしに、しかも断層と断層の間に置く、と決まる。

📚 前提知識

  • 石灰岩層にしみこんだ水は、下の泥岩層（水を通さない）の上を、層のかたむきに沿って低い方へ流れる。せき止める壁は流れの 下流側（低い側） に置くと、上流の広い範囲の水がたまる。
  • (4)の本文: 両側に水を通しにくい層（断層でずれた泥岩層）があれば横の壁はいらない → 2本の断層にはさまれた帯の中に造る。

🔍 こう読み解く

  1. 図3の北南断面: 表土層も石灰岩層も泥岩層も南へ下がる。かたむきはどこも同じなので、水は島のどこでも 南へ流れる → 壁は南側。ア・イ（島の真ん中）が消える。
  2. ウとエはどちらも南。エは北西－南東にのびる2本の太い断層にはさまれた長い帯の南のはし。帯の北の方からの水がすべてここに集まる。
  3. ウは太い断層の西側で、その帯は北へ進むとすぐに入り江（海）で切れている。ためられる範囲がエより小さい → エ。
  4. 本番で手を付けるかどうか: 「南へ下がる」が図3で読めたら、ウ・エの2択までは行ける。
答え：エ

4 (6) 条件に合う止水壁を東西断面図に図示する B・5点｜条件文・作図

👀 まず見るところ

【条件文】部品は「なるべく多くの水をためられる」「できる限り小さく」「石灰岩層内のみ」の3つに丸。(5)の黒い棒（東西向きの壁）を真横から見た断面が解答らんなので、壁は「水がたまる高さまで・それより上には造らない」と決まる。

📚 前提知識

  • 水は南へ流れる（(5)）ので、止水壁は東西にのびて流れを横切る。解答らんの東西断面図は、その 壁そのものの断面＝壁がおおう範囲を黒くぬる。
  • 泥岩層は水を通さない。真ん中のブロックの石灰岩層は、西は断層の向こうの泥岩層、東は自分の泥岩層（東へ上がって断層にぶつかる）でふさがれている。ふさがれているのは 両側とも泥岩がある高さまで。それより上の水は、断層をこえてとなりの石灰岩層へもれてしまう。

🔍 こう読み解く

  1. 解答らんの真ん中のブロック（2本の断層の間）の石灰岩層に水をためる。下は自分の泥岩層、西は断層の向こうの泥岩層でふさがれている。東は、自分の泥岩層の上面が東の断層にぶつかる所までしかふさがれていない。
  2. ためられる水面の上限＝泥岩層の上面が東の断層にぶつかる点の高さ。そこから西へ水平な線を引き、西の断層にぶつかるまでのばす（下の図の赤い点線）。西どなりの泥岩層はこの高さより上まであるので、西側はもれない。
  3. この水平線より下で、真ん中の泥岩層の上面より上の部分（三角形）が、壁がおおうべき範囲。ここを黒くぬる。これより上に造っても水は東へもれるので、「できる限り小さく」にも合う。
  4. 表土層や泥岩層にはみ出さない（「石灰岩層内のみ」）。
  5. 本番で手を付けるかどうか: (5)で「断層の間にためる」が見えていれば、2本の断層の間の石灰岩層の下の方をぬるだけで部分点がねらえる。上限の高さまで合わせられれば満点。
答え：右の図（2本の断層にはさまれた真ん中の石灰岩層のうち、泥岩層の上面が東の断層にぶつかる高さより下の部分を黒くぬる。左は西の断層、下は泥岩層の上面、上はその高さの水平線でかこまれた三角形）

3〜4 まとめ この回で繰り返し出た入口

  • 「1つずつ」「1本ずつ」たどる問題（3(3)の表・3(6)の矢印）は、頭の中でやらず表や図に書きこむと落とさない。
  • 大問4は図3の断面図が3問分の根拠: 東西断面「どちらが下がったか」→(3)、北南断面「南へ下がる」→(5)(6)。1つの図を何に使うか、設問ごとに決め直す。
  • 覚え直しはこの3つ: オスの背びれに切れこみ／ずり落ち＝正断層＝引っぱる力／地下ダムは落差がないので水力発電には使えない。
