1 (1) 0.625×（□−2/3）÷1/3＝1 の□ A・5点｜逆算

👀 まず見るところ

【条件文】部品は「□にあてはまる数」と、式の外側にある「÷1/3＝1」。0.625 は 5/8 に直して書く（直して書く）→ あとは外側から順に、÷ は ×、× は ÷ でもどす。

📚 前提知識

  • 逆算は、計算した順の反対からもどす。「÷1/3 をして1になった」なら、その前は 1×1/3。たとえば 6÷2＝3 なら、6＝3×2。
  • 0.125＝1/8。だから 0.625 は 1/8 が5つ分で 5/8。小数のまま分数でわると、途中で止まる。

🔍 整理して解く

  1. 0.625 を 5/8 に書きかえる。式は 5/8×（□−2/3）÷1/3＝1。
  2. いちばん外側の ÷1/3 をもどす。 
    5/8×（□−2/3）＝1×1/3＝1/3
  3. 次に ×5/8 をもどす。わり算はひっくり返してかける。 
    □−2/3＝1/3÷5/8＝1/3×8/5＝8/15
  4. 最後に −2/3 をもどす。通分して 2/3＝10/15。 
    □＝8/15＋10/15＝18/15＝6/5＝1 1/5
  5. たしかめ。1 1/5−2/3＝18/15−10/15＝8/15。8/15×5/8＝1/3。1/3÷1/3＝1。合っている。落としやすいのは、18/15 を約分せずに書くところと、答えを帯分数に直し忘れるところ。
答え：1 1/5

1 (2) 食塩水をAからB、BからAへ移す A・5点｜濃度（やりとり・てんびん）

👀 まず見るところ

【条件文】部品は「BからAに何gか移し」と「Bの食塩水の濃度は5%」。Bから出してもBの濃度は変わらないから、この5%は「Aから50g入れた直後のB」の濃度として表に置く（図に置く）→ Bの食塩の重さが分かり、Aの濃度が決まる。

📚 前提知識

  • 食塩水をくみ出しても、残りの濃度は変わらない。5%の200gから75gくんでも、残りは5%のまま。
  • 食塩の重さ＝食塩水の重さ×濃度。2%の150gなら、食塩は 150×0.02＝3g。
  • 2つの食塩水を混ぜるときはてんびん。濃度の差の比が 1：2 なら、重さの比はその逆で 2：1。

🔍 整理して解く

  1. やりとりを表に書く。分からない濃度はア、イと置く。
    いつAB
    はじめア% 300g2% 150g（食塩3g）
    AからBへ50gア% 250g5% 200g（食塩10g）
    BからAへ□g11% （250＋□）g5% （200−□）g
  2. 50g入れたあとのBは、5%の200g。食塩は 200×0.05＝10g。もとの3gをひくと、Aから来た50gの中に食塩が 10−3＝7g。
  3. Aの濃度アは 7÷50＝0.14 → 14%。
  4. BからAへもどす。14%の250gと5%の□gを混ぜて11%。てんびんを書く。
  5. 濃度の差は 14−11＝3 と 11−5＝6。重さの比は逆の 2：1。250gが2にあたるから、□＝250÷2＝125g。（式で書くなら 250×3＝□×6。）
  6. たしかめ。食塩は 250×0.14＋125×0.05＝35＋6.25＝41.25g。375gの11%は 41.25g。合っている。落としやすいのは、5%を「最後のB」だけの話と思って、2段目に使えないところ。
答え：125g

1 (3) 4グループ100人の平均は少なくとも何点以上か B・5点｜条件の整理・平均

👀 まず見るところ

【条件文】部品は3回出てくる「いずれか一方のグループだけ全員が80点以上」と、聞かれ方「少なくとも何点以上」。「一方だけ」は、Aが○ならBは×、Bが×ならCは○…と表に置く（図に置く）→ ○×の組は2通りしかない。2通りと見えたら、手を付ける価値がある。

📚 前提知識

  • 「少なくとも何点以上」は、いちばん低くなる場合の平均を出せばよい。全員が60点以上なので、いちばん低い点は60点。
  • 「全員が80点以上」でないグループは、「80点未満の人が1人はいる」というだけ。だから全員60点でもよい。
  • 平均は 合計÷人数。人数がちがうグループは、点数×人数をたしてから100でわる。

🔍 整理して解く

  1. Aが○（全員80点以上）だとして、条件を順にたどる。AかBの一方だけ → Bは×。BかCの一方だけ → Cは○。CかDの一方だけ → Dは×。Aが×なら、すべて反対になる。
    A（15人）B（20人）C（25人）D（40人）
    場合ア○ 80点以上× ○ 80点以上×
    場合イ×○ 80点以上×○ 80点以上
  2. いちばん低くするには、○のグループは全員ちょうど80点、×のグループは全員60点にする。
  3. 場合アの平均を出す。 
    （80×15＋60×20＋80×25＋60×40）÷100
＝（1200＋1200＋2000＋2400）÷100＝68
  4. 場合イの平均を出す。 
    （60×15＋80×20＋60×25＋80×40）÷100
＝（900＋1600＋1500＋3200）÷100＝72
  5. 低いほうは68点。どの場合でも、平均はこれより低くならない。だから少なくとも68点以上。
答え：68点以上
コツ：「少なくとも」「多くとも」と聞かれたら、いちばん極端な場合（全員ぎりぎりの点）を作って計算する。人数の多いD（40人）が60点になる場合アのほうが低くなる、と見当をつけてから計算すると速い。

1 (4) 五角形を貼り合わせて最初の1枚に重なるのは何枚目か A・5点｜角度・正多角形の外角

👀 まず見るところ

【条件文】部品は「角アの大きさが30度」と、聞かれ方「初めて最初の五角形とぴったり重なる」。つなぎ目に集まる角（90°と 30＋90＝120°）を図に置く → 残りの角イが、上の辺が作る正多角形の内角。外角が分かれば 360÷外角 で枚数が決まる。

📚 前提知識

  • 五角形ABCDEの角Aは、三角形の30°と正方形の90°を合わせて 120°。正方形の角D・Eは90°。
  • 正多角形は、1つの外角が分かれば 360÷外角 で辺の数が出る。外角が30°なら 360÷30＝12 で正十二角形。
  • 1周ぴったりで元にもどるなら、次の1枚が最初の1枚に重なる。12枚で1周なら、重なるのは13枚目。

🔍 整理して解く

  1. 図2の2枚目は、1枚目のED に 2枚目のAB を合わせて貼ってある。つなぎ目（1枚目のE＝2枚目のA）に集まる角を書きこむ。
  2. つなぎ目の1周は360°。1枚目の角E＝90°、2枚目の角A＝120°。残りの角イは 360−90−120＝150°。
  3. 赤い辺（各五角形のAE）はどれも同じ長さで、つなぎ目の角はどこも150°。だから赤い辺は正多角形を作る。内角150°の外角は 180−150＝30°。360÷30＝12 → 正十二角形。
  4. 五角形を12枚貼るとちょうど1周する。13枚目が最初の五角形にぴったり重なる。落としやすいのは、12枚目と答えてしまうところ。「12枚で1周、重なるのは次の1枚」と数える。
答え：13枚目
コツ：「同じ形を同じ向きに貼って1周」と見たら、1枚ごとに何度回るか（＝外角）をさがす。ここでは30°ずつ回るから 360÷30＝12枚で1周。

1 (5) 直方体をP・Q・Eを通る平面で切った小さい方の体積 A・5点｜立体の切断・すい台

👀 まず見るところ

【条件文】部品は「3点P，Q，Eを通る平面で切って」と「小さい方の立体の体積」。DP＝2cm、CQ＝4cm は PH＝4cm、QG＝2cm に直して図に書く → 向かい合う面の切り口は平行。Qから PE に平行な線を引けば、4つ目の点Rが決まる。

📚 前提知識

  • 向かい合う面（面AEHDと面BFGC）にできる切り口の線は平行。だから PE と QR は平行。
  • 三角すいの体積は 底面積×高さ÷3。先を切り落とした形（すい台）は、大きい三角すい−小さい三角すいで出す。
  • 平行な線で切った三角形は相似。PH：HE＝4：10＝2：5 なら、QG：GR も 2：5。

🔍 整理して解く

  1. 切り口を描く。Qから PE と平行に線を引き、辺FGと交わる点をRとする。PH：HE＝4：10＝2：5 だから QG：GR＝2：5。QG＝2cm なので GR＝5cm。
  2. 小さい方の立体は、E・H・G・R・P・Q を頂点とする立体。三角形PEH（底10cm・高さ4cm）と三角形QRG（底5cm・高さ2cm）は平行で、大きさは 2：1。三角すいの先を切ったすい台になっている。
  3. PQ・HG・ER をのばすと、1つの点Oで交わる。三角形EFR と三角形OGR は FR＝GR＝5cm で合同だから、OG＝EF＝8cm。OH＝8＋8＝16cm。
  4. 大きい三角すい O-PEH。底面は三角形PEH、高さは OH＝16cm。 
    10×4÷2×16÷3＝320/3（cm³）
  5. 小さい三角すい O-QRG。底面は三角形QRG、高さは OG＝8cm。 
    5×2÷2×8÷3＝40/3（cm³）
  6. ひく。320/3−40/3＝280/3＝93 1/3cm³。たしかめ。直方体は 8×10×6＝480cm³ で、その半分240cm³より小さい。小さい方で合っている。落としやすいのは、OG を R の位置から出さずに適当に決めるところ。FR＝GR だから OG＝EF。
答え：93 1/3cm³
コツ：切り口の形が分かったら「どの2つの面が平行か」を見る。平行な2面にはさまれた立体で、断面が相似の三角形なら、すい台として「大きいすい−小さいすい」。

2 (1) 船の静水時の速さ A・6点｜流水算

👀 まず見るところ

【条件文】部品は「7.2km」と「上りは45分，下りは30分」。答えは分速何mだから、7.2kmは7200mに直して書く（直して書く）→ 上りと下りの速さが出て、静水時の速さはその平均。

📚 前提知識

  • 上りの速さ＝静水時−流れ、下りの速さ＝静水時＋流れ。だから静水時＝（上り＋下り）÷2、流れ＝（下り−上り）÷2。たとえば上り160・下り240なら、静水時200・流れ40。

🔍 整理して解く

  1. 7.2km＝7200m。上りの速さは 7200÷45＝分速160m。下りの速さは 7200÷30＝分速240m。
  2. 静水時の速さは（160＋240）÷2＝分速200m。
  3. 流れの速さも出しておく。（240−160）÷2＝分速40m。(2)(3)で使うので、余白に「上り160・下り240・流れ40」と書いておく。落としやすいのは、kmをmに直し忘れて 7.2÷45 とするところ。
答え：分速200m

2 (2) 上りで故障。修理にかかった時間 A・6点｜流水算・速さと比

👀 まず見るところ

【条件文】部品は「修理している間も船は流されたため」と「65分かかりました」。ふだんの上り45分との差 65−45＝20分 を「流された時間＋もどす時間」に直して書く → 同じ道のりを 40 と 160 で進むから、時間の比 4：1 で20分を分ける。

📚 前提知識

  • 修理中はエンジンが止まっているので、船は流れの速さ 分速40mで下流へもどる。もどった分を上り直す速さは、上りの速さ 分速160m。
  • 同じ道のりなら、時間の比は速さの逆比。速さが 40：160＝1：4 なら、時間は 4：1。

🔍 整理して解く

  1. 線の図を書く。故障した地点をP、流されて止まった地点をQとする。
  2. A→P と P→B（黒い矢印）をつなぐと、ふつうの上り1回分＝45分。だから余計にかかった 65−45＝20分は、P→Q（流される）と Q→P（上り直す）の合計。
  3. PQの道のりは同じ。速さは 40 と 160 で 1：4。だから時間は 4：1。
  4. 流された時間（＝修理の時間）は 20×4/5＝16分。
  5. たしかめ。16分で 40×16＝640m 流される。640÷160＝4分で上り直す。16＋4＝20分。合っている。落としやすいのは、20分をそのまま修理の時間と答えるところ。
答え：16分間

  • 下りは、流されている間も目的地に近づいている。だから下りの余計な時間＝修理の時間−「流された道のりをふつうに下る時間」。速さは 40：240＝1：6 だから、時間の比は 6：1。

3 ア・イ・ウ 正三角形が2個・3個・4個のときの経路の数 A・3点×3｜場合の数（なぞって数える）

👀 まず見るところ

【条件文】部品は「すべての頂点をちょうど1回ずつ通り」と「ゴールGまで」。Sから出る線は上と横の2本だけなので、「上に行く」「横に行く」の2つに分けて図に赤でなぞる。2個・3個・4個は、なぞって数えるだけで決まる。

📚 前提知識

  • 「頂点を1回ずつ全部通る」は、点を飛ばしてもだめ、同じ点にもどってもだめ。線のほうは使い残してよい。2個の図なら、S→上→下→G と S→下→上→G の2本で全部。
  • 場合分けの軸は「Sの次にどこへ行くか」。Sから出る線は2本なので、場合は2つで足りる。

🔍 整理して解く

  1. 2個のとき。Sの次に上の点へ行く経路と、横の点へ行く経路を1本ずつなぞる。全部で2通り（ア）。
  2. 3個のとき。Sの次に上へ行くと、残りは2個の形と同じで2通り。Sの次に横へ行くと、点を全部通る道は1通りだけ。合わせて 2＋1＝3通り（イ）。
  3. 4個のとき。上へ行くと3個の形で3通り。横へ行くと1通り。合わせて 3＋1＝4通り（ウ）。
  4. 落としやすい所: 「横へ行く」経路は、Sのとなりの上の点を飛ばしやすい。なぞったあとに、通っていない点が残っていないかを数える。
答え：ア 2、イ 3、ウ 4

3 エ・オ・カ・キ 5個のとき、Sの次にA／Bへ行った場合 A・3点×4｜場合の数（小さい形にもどす）

👀 まず見るところ

👀 まず見るところ
