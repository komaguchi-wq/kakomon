2 (1) 石灰石の加熱で出る気体・残った粉末の性質 A・9点｜素材文・空らん3つ

👀 まず見るところ

【素材文】空らんごとに直前の手がかり1語に丸。1は「石灰水に通すと、白くにごった」、2は「フェノールフタレイン液を加えると赤く」、3は「塩酸を十分に加えると、赤色の溶液が」。3語とも、気体・液性・色の定番の合図。

📚 前提知識

  • 石灰水を白くにごらせる気体は二酸化炭素。石灰石（炭酸カルシウム）は強く熱すると二酸化炭素を出して生石灰（酸化カルシウム）になる。
  • フェノールフタレイン液は、酸性・中性では無色、アルカリ性で赤。加熱後の粉末を水に溶かすとアルカリ性になる。
  • アルカリ性の液に酸（塩酸）を十分に加えると中和されて酸性（または中性）になり、赤色は消えて無色にもどる。

🔍 こう読み解く

  1. 1：白くにごる → 二酸化炭素。
  2. 2：フェノールフタレイン液が赤 → アルカリ性。
  3. 3：塩酸を「十分に」加えたので、アルカリ性ではなくなる → 赤が消えて無色。
  4. 落としやすい所: 3を「青」「黄」など別の色にしない。フェノールフタレイン液の色は赤か無色の2つだけ。
答え：1…二酸化炭素　2…アルカリ　3…無

2 (2) 最初の数十秒間に気体が激しく通過した理由 B・5点｜記述・まざり型

👀 まず見るところ

【まざり型→資料問題】設問が示す2つの事実に丸。表1「3分間は、粉末の重さがほとんど変化していない」＝気体はほとんど出ていない。実験結果②「1分間は、石灰水は白くにごらなかった」＝通ったのは二酸化炭素ではない。残る候補は、試験管の中にもともとあった空気。

📚 前提知識

  • 空気はあたためると体積が大きくなる（ぼう張）。閉じた試験管を加熱すると、ふくらんだ分の空気がガラス管の先から押し出される。
  • 石灰水は二酸化炭素では白くにごるが、空気が通ってもにごらない。

✍️ 答案の組み立て

  1. 要素A（表1から）：加熱を始めたばかりのころは、気体がほとんど発生していない。
  2. 要素B（理由の中心）：試験管内の空気が加熱されてぼう張した。
  3. 要素C（結果）：その空気がガラス管から出てきて石灰水を通った。
  4. 判断材料: 「二酸化炭素ではない」が言えれば要素Bにたどり着ける。白くにごらなかった、を見た時点で書き始めてよい。
模範解答：加熱を始めたばかりのころは気体がほとんど発生していないが，試験管内の空気が加熱されてぼう張し，ガラス管から出てくるから。
コツ：「気体が出た」と「二酸化炭素が出た」を分けて考える。石灰水がにごらない気体の通過は、空気の出入りを疑う。

2 (3) 火を消す前にガラス管を抜く理由 A・4点｜記述・条件文

👀 まず見るところ

【条件文】部品は「ガスバーナーの火を消す前に」と「石灰水の中からガラス管を抜く」。順番が指定されているときは「逆にしたら何が起こるか」を1行で書く → 火を消すと試験管内の気体が冷えて縮み、石灰水が吸いこまれる。

📚 前提知識

  • 加熱をやめると試験管内の気体は冷えて体積が減る。ガラス管の先が液体の中にあると、その液体が試験管へ逆流する。
  • 熱い試験管に冷たい液体がふれると、急な温度変化でガラスが割れるおそれがある。

✍️ 答案の組み立て

  1. 要素A：石灰水が逆流して試験管内に入る。
  2. 要素B：それを防ぐため（「〜ため。」で結ぶ）。
  3. 落としやすい所: 「試験管が割れるのを防ぐため」だけでは、何が起きて割れるのかが抜ける。逆流を先に書く。
模範解答：石灰水が逆流して試験管内に入るのを防ぐため。

2 (6) 粉末1.00gがちょうど反応する塩酸の重さ A・4点｜資料問題・比例と頭打ち

👀 まず見るところ

【資料問題】表2の各列で「出た気体」を書き足す。塩酸1.00gごとに0.08gずつ増え、5.00gと6.00gでは0.34gで止まる。止まった0.34gが総量（表1の1.00−0.66と同じ）。「0.08gあたり塩酸1.00g」に直して書けば、総量に必要な塩酸が決まる。

📚 前提知識

  • 塩酸が足りない間は、気体は塩酸の量に比例して出る。粉末がなくなると、塩酸を増やしても気体は増えない（頭打ち）。

🔍 こう読み解く

  1. 出た気体の表を書く。
    塩酸(g)01.002.003.004.005.006.00
    気体(g)00.080.160.240.320.340.34
  2. 塩酸1.00gで気体0.08g。総量0.34gを出すのに必要な塩酸は 1.00×0.34÷0.08＝4.25g。
  3. 検算: 4.00gで0.32、4.25gで0.34、5.00gでも0.34 → 4.00と5.00の間で頭打ちになっているので合う。
  4. 落としやすい所: 「5.00g」と答えない。表の値は1.00gきざみなので、ちょうどの値は比例計算で出す。
答え：4.25g

2 (7) 粉末3.00gに塩酸15.00gを加えたとき B・4点｜条件文・どちらが余るか

👀 まず見るところ

【条件文】部品は「粉末3.00g」「塩酸15.00g」。(6)で変わった数は粉末の量 → 粉末3.00gに必要な塩酸を先に出す（4.25×3）。15.00gと比べてどちらが余るかが決まれば手を付けてよい。

📚 前提知識

  • 2つの量を混ぜる問題は、先に「ちょうど反応する組」を作り、どちらが余るかを決める。気体の量は、足りない方（全部使い切る方）で決まる。

🔍 こう読み解く

  1. 粉末3.00gとちょうど反応する塩酸は 4.25×3.00÷1.00＝12.75g。
  2. 加える塩酸は15.00g ＞ 12.75g → 塩酸が余り、粉末はぜんぶ反応する。
  3. 気体は粉末の量で決まる。0.34×3.00÷1.00＝1.02g。
答え：1.02g
コツ：余る方（塩酸15.00g）で計算して 0.08×15＝1.20g と答えるのが典型的なまちがい。必要量との比べ方を1行目に書く。

3 (1) 桃・栗・柿・蓼に共通しない特徴 A・3点｜素材文・誤っているもの

👀 まず見るところ

【素材文】設問は「1〜4に共通する特徴として誤っているもの」。部品は「1 2 三年 3 八年」「4 食う虫も好き好き」の空らんに、桃・栗・柿・蓼と丸 → 4つとも双子葉類と決まれば、選択肢は分類の知識だけで切れる。

📚 前提知識

  • ことわざ「桃栗三年柿八年」（実がなるまで年月がかかる）、「蓼食う虫も好き好き」（人の好みはさまざま）。

🔍 こう読み解く
