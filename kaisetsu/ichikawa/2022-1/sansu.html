【条件文】部品は「2022÷120」と「2.75÷3/4」。小数は分数に直して書く（2.75＝11/4）。3つのかっこを先にそれぞれ計算し、最後に ÷ と × を1本の式にして約分する。

1 (3) 水を入れながら排水する水そう A・6点｜ニュートン算

👀 まず見るところ

【条件文】部品は「毎分10Lの割合で水を入れ続けています」と「Aのみで9分」「Bのみで24分」。空になる時間は「出す量−入る10L」＝減る速さの話に直して書く → 減る速さの比は時間の逆比 24:9＝8:3 と決まる。

📚 前提知識

  • 同じ量を9分と24分で減らす → 1分に減る量の比は、時間の逆比。24:9 ＝ 8:3。
  • 排水管が出す量 ＝ 1分に減る量 ＋ 入ってくる10L。

🔍 整理して解く

  1. 1分に減る量を、A＝⑧、B＝③ とおく。出す量は 10L をたした形で表に書く。
    1分に減る量入る量1分に出す量
    A⑧10L⑧＋10
    B③10L③＋10
    差⑤⑤＝5L
  2. 「AはBより1分あたり5L多く出す」→ ⑤＝5L → ①＝1L。
  3. Aで減らすと1分に 8L。9分で空 → 容量は 8×9＝72L。

1 (4) 長方形と正五角形の重なり・印の角の和 B・6点｜角度（三角形の外角）

👀 まず見るところ

【条件文】部品は「正五角形」と「角の大きさの和」。正五角形は 1つの角108°・外角72° を図に置く。印は2つとも辺が交わる点にあるので、ア・イを別々に出さず、三角形で和を作る。108と72を書いて三角形が見えたら手を付ける。

📚 前提知識

  • 正五角形の外角は 360÷5＝72°、1つの角は 180−72＝108°。
  • 三角形の外角は、となり合わない2つの角の和。
  • 長方形の向かい合う辺は平行。平行な2本の線を1本の線が横切ると、Zの形の角（錯角）は等しい。

🔍 整理して解く

  1. 記号をつける。下の交点を P、ア の向かい側の角を ア′（対頂角で等しい）。正五角形の右のかどを A、Aから下りる辺と長方形の辺が交わる点を B。
  2. 赤い三角形（P・正五角形のかど・B）。角は ア′・108°・●。180−108＝72 だから、ア＋●＝72。
  3. 正五角形の A につながる上の辺を、A の先にのばす。長方形の P・B を通る辺ものばして、交わる点を C。三角形ABC で、A の角は正五角形の外角 72°（▲）、B の角は ●（対頂角）。
  4. C の外側の角 イ′ は三角形ABC の外角。イ′＝●＋72。長方形の2辺は平行だから、Zの形で イ′＝イ。
  5. ア＋イ ＝ ア＋（●＋72）＝（ア＋●）＋72 ＝ 72＋72 ＝ 144°。
答え：144度
コツ：「2つの角の和」を聞かれたら、片方ずつ出せなくてよい。ア＋● と ●＋72 のように、同じ角（●）を通して2つをつなぐ。

👀 まず見るところ

【条件文】部品は「滑らないように1回転」と「ADが通過した部分」。回転の中心は直線についている右下のかど。C→P→Q→F と6cmずつ右へ移る、と図に置く → 中心ごとに A と D がえがく弧をコンパスで描けば決まる。

  2. 1回目（中心C）。A は半径AC（対角線）の弧で右上へ、D は半径6cmの弧で P へ。AD はこの2つの弧の間を通る。

  4. 3回目（中心Q）。A は中心。D は半径6cmの四分円で Q の真上へ。2回目と3回目の四分円は重なる。
  5. 4回目（中心F）。A は半径6cmの弧で E へ、D は半径FH（対角線）の弧で H へ。
  6. 弧で囲まれた部分に斜線。落としやすい所: 1回目と4回目で、対角線の長さの弧を忘れない（Aの通り道は6cmより外側）。

👀 まず見るところ

【条件文】部品は「Cを ア g」（相手だけ変わり、重さは同じ）と「1.5%高く」。Aとの濃度の差を 3（8−5）と 5（10−5）に直して書く → 混ぜる重さが同じなら、上がり幅も 3:5 と決まる。(1)で10%が出ていれば手を付ける。

📚 前提知識

4 エ・オ・カ・キ 各位の和を1通りにしぼる・使わない数 B・12点｜9個の和の範囲でしぼる

👀 まず見るところ

【条件文】部品は「異なる9つの数が入る」。これを「9個の和は 36以上45以下」に直して書く（0〜9の合計45から、使わない1つを引いた数）。3つの位の和をたしてこの範囲に入る組だけが残る。ア〜ウが出ていれば計算は3行なので、手を付ける価値がある。

📚 前提知識

  • 0から9までの10個の和は 45。（0＋9）×10÷2 で出せる。9個だけ使うなら、45から使わない1つを引く。使わないのが9なら 36、0なら 45。だから9個の和は 36〜45。
  • C＋F＋I と B＋E＋H と A＋D＋G をぜんぶたすと、9個の文字の和になる。位ごとの和の候補を、この1本の式でつなぐ。

🔍 整理して解く

  1. ア〜ウの候補と「9個の和は 36〜45」を並べて書く。
    位の和候補（ア〜ウ）
    C＋F＋I12，22
    B＋E＋H10，11，20，21
    A＋D＋G18，19
    3つをたした和36 以上 45 以下
  2. まず C＋F＋I が 22 だとすると、残り6個（B・E・H・A・D・G）の和は 36−22＝14 から 45−22＝23 まで。ところが B＋E＋H は10以上、A＋D＋G は18以上で、たすと 28以上になる。23をこえるので合わない。だから C＋F＋I＝12。これがエ。
  3. C＋F＋I＝12 なので、十の位へのくり上がりは1。B＋E＋H に1をたした一の位が2 → B＋E＋H は 11 か 21。残り6個の和は 36−12＝24 から 45−12＝33 まで。21 だと A＋D＋G の18をたして 39 で33をこえる。だから B＋E＋H＝11。これがオ。
    C＋F＋I残り6個の和B＋E＋H＋A＋D＋G の最小合うか
    2214〜2310＋18＝28× こえる
    1224〜3311＋18＝29○（21＋18＝39 は×）
  4. 十の位の和は 11＋1＝12。百の位へのくり上がりは1。A＋D＋G＋1＝20 なので A＋D＋G＝19。これがカ。
  5. 9個の和は 12＋11＋19＝42。使わない数は 45−42＝3。これがキ。
  6. たしかめ。会話文の最初の例 674＋674＋674 は同じ数を使っているので、ここでは候補にならない。3を使わない組で、たとえば 701＋452＋869＝2022 が作れる。
答え：エ 12／オ 11／カ 19／キ 3
コツ：「0〜9から異なる9つ」と見たら、「全部の和は 36〜45」と先に1行書く。位ごとの候補をこの1本でつなぐと、場合分けが一気に消える。

4 ク A＝7のとき、残りの入れ方は何通り B・3点｜組を決めてから並べ方をかける

👀 まず見るところ

【条件文】部品は「Aが7のとき」。カの A＋D＋G＝19 から「D＋G＝12」に直して書く。使える数は3と7を除いた 0，1，2，4，5，6，8，9。この中で2つの和が12になる組は4と8だけなので、残り6個を 11 と 12 の組に分けるだけになる。

📚 前提知識

  • 3つの数を3つの場所（B・E・H）に入れる並べ方は 3×2×1＝6通り。たとえば 0，2，9 を B・E・H に入れるなら、Bに3通り、Eに残り2通り、Hは1通り。
  • 数える順番は「どの数を使うか（組）」を先に決め、「どこに入れるか（並べ方）」をあとでかける。組ごとに並べ方の数は同じなので、組の数×並べ方で出る。

🔍 整理して解く

  1. 使う数を書き出す。キより3は使わない。Aに7を使ったので、残りは 0，1，2，4，5，6，8，9 の8個。
  2. D＋G＝19−7＝12。残りの8個から2つで12になるのは 4と8 だけ（3＋9 は3が使えない、6＋6 は同じ数、5＋7 は7が使用済み）。
  3. 残った 0，1，2，5，6，9 を、B＋E＋H＝11 の組と C＋F＋I＝12 の組に分ける。和が11になる3つは 0＋2＋9 と 0＋5＋6 の2つだけ。残りの3つがそれぞれ 1＋5＋6＝12、1＋2＋9＝12 になるので、分け方は 2通り。
    D・G（和12）B・E・H の組（和11）C・F・I の組（和12）
    4，80，2，91，5，6
    4，80，5，61，2，9
  4. 1つの分け方ごとに並べ方を数える。D・G は 2通り、B・E・H は 6通り、C・F・I は 6通り。2×6×6＝72通り。
  5. 分け方が2通りあるので、72×2＝144通り。
  6. たしかめ。上の表の1行目で 701＋452＋869 を計算すると 2022。合っている。
答え：144
コツ：「和が11になる3つ」をさがすときは、いちばん小さい0を入れる場合と入れない場合に分けると、もれなく数えられる（0を入れないと、1＋2＋5＝8、1＋2＋6＝9 の次に小さいのは 1＋2＋9＝12 と 1＋5＋6＝12 で、11は作れない）。

4 まとめ この大問で繰り返し出た入口

  • 「異なる数」と見たら、和の範囲（3つなら3〜24、9つなら36〜45）を先に1行書く。候補はこの範囲でしぼる。
  • 筆算は位ごとに「和＋くり上がり」で見る。くり上がりは1とは限らない（和が22なら2）。
  • 場合の数は「使う数の組」を先に決め、並べ方（3×2×1）をあとでかける。

5 (1)(i) 1に操作を5回行う A・5点｜操作の追跡

👀 まず見るところ

【条件文】部品は「10の倍数のときは10で割り」と「5回行ったあと」。操作は1回ごとに矢印で横に書き、矢印の数を5本と決めて丸 → 10の倍数が出た所だけ割り算になる。

📚 前提知識

  • 「3倍して2を加える」は、3×□＋2 のこと。1なら 3×1＋2＝5。5なら 3×5＋2＝17。
  • 10の倍数かどうかは、一の位が0かどうかで見る。17 も 53 も一の位が 0 ではないので、3倍して2をたす。

🔍 整理して解く

  1. はじめの数 1 を左に書き、矢印を5本引く。1回ごとに「一の位は0か」を見てから計算する。
    はじめ1回目2回目3回目4回目5回目
    151753161485
  2. 一の位は 1・5・7・3・1 と進み、0 は一度も出ない。5回とも 3×□＋2 のまま。161×3＋2＝485。
  3. 落としやすい所: 矢印は5本、数は6個。「数が5個になったら終わり」にすると、161 で止まって1回足りない。
答え：485

5 (2) 「10で割る」を1回も行わない数 B・6点｜一の位の追いかけ

👀 まず見るところ

【条件文】部品は「1から100まで」と「10で割るという操作を1回も行わない」。「10で割る」を「一の位が0になる」に直して書く → 一の位だけを表で追えば決まる。(1)で 80→8 を見ていれば手を付ける。

📚 前提知識

  • 奇数を3倍しても奇数。2をたしても奇数。たとえば 7→23→71。だから奇数は、何回操作しても一の位が0にならない。
  • 3倍して2をたしたあとの一の位は、もとの一の位だけで決まる。12→38 も 32→98 も、一の位は 2→8。十の位は関係ない。

🔍 整理して解く

  1. 奇数（一の位が 1・3・5・7・9）は、10で割る操作を1回もしない。
  2. 偶数は一の位だけを表で追う。0 が出たら「割る」。同じ数字にもどったら終わり。
    はじめの一の位1回目2回目3回目10で割る？
    2860割る
    4444割らない（ずっと4）
    60割る
    860割る
    0はじめから10の倍数割る
  3. 1回も割らないのは、一の位が 1・3・4・5・7・9 の6通り。十の位は 0〜9 の10通りずつ（4、14、…、94 のように）。
  4. 全部で 10×6＝60個。たしかめ: 100 は一の位が 0 だから、数えない。
答え：60個
コツ：「10で割る」「10の倍数」と見たら、一の位だけの話に直す。一の位 4 は 3×4＋2＝14 で 4 にもどる、と1回計算して確かめると表が信じられる。

5 (3) 「10で割る」をちょうど1回だけ行う数 C・6点｜一の位と十の位の追いかけ

👀 まず見るところ

【条件文】部品は「ちょうど1回だけ」。「1回だけ」を「10で割ったあとの数が(2)の仲間（一の位 1・3・4・5・7・9）」に直して書く。本番では後回し。(2)が出ていて時間が残ったら、一の位 2 の10個を書き出す。

📚 前提知識

  • 一の位が同じで十の位だけがちがう2つの数（12と32）を3倍すると、十の位もちがう数になる。32×3 は 30×3＋2×3 と分けられる。十の位に加わる 3×0、3×1、…、3×9 の一の位は 0・3・6・9・2・5・8・1・4・7 と全部ちがう。

🔍 整理して解く

  1. 一の位が 2 の数（02、12、…、92）を、10で割るところまで進めて表にする。割ったあとの数の一の位を見る。
    はじめ→→→（10の倍数）10で割ったあともう割らない？

    123811635035○

  3. 一の位が 6・8・0 の数も同じく6個ずつ。たとえば 10、20、…、100 は割ると 1、2、…、10 で、仲間は 1・3・4・5・7・9 の6個。全部で 6×4＝24個。

  • 操作の回数は矢印の本数で数える。数の個数は回数＋1。
  • (3)のような「ちょうど1回」は、1回目のあとが「もう起きない形」になる数をさがす。
