👀 まず見るところ

📚 前提知識

  • 「どの席を大人にするか」と「どの大人・どの子どもが座るか」は別に数えて、かけ算する。
  • 3人のならべ方は 3×2×1＝6通り。4人のならべ方は 4×3×2×1＝24通り。
  • 「子どもの隣に大人が最低1人」→ 子どもだけの列を作れない。3人がけの列は、端の子どもの隣が1席しかないことに気をつける。

🔍 整理して解く

  2. 1列目のもう1席（運転席の隣）を大人にすると、残りの大人は1人。2列目か3列目が子どもだけになる → だめ。1列目の左は子ども。
  3. 残りの大人2人は、2列目に1人・3列目に1人。
  4. 3列目は3席。大人が端に座ると、反対の端の子どもの隣は子どもになる → だめ。3列目の大人はまん中。
  5. 2列目は左右どちらでもよい。席の決め方は次の2通り。
    列決め方①決め方②
    1列目子ども・大人（運転席）子ども・大人（運転席）
    2列目大人・子ども子ども・大人
    3列目子ども・大人・子ども子ども・大人・子ども
  6. 決め方①で、大人3人の座り方は 3×2×1＝6通り。子ども4人は 4×3×2×1＝24通り。6×24＝144通り。
  7. 決め方②も同じ144通り。144×2＝288通り。
答え：288通り
コツ：座り方の問題は「席の形を決める」→「人をならべる」の2段。先に席の形だけを図に描くと、2通りしかないことが見える。

👀 まず見るところ

【条件文】部品は「最後にGに進んで終了する」。G に入る矢印を図に置く → B から（余り1）と C から（余り2）の2本。それぞれ「A の数の形」に直して書いて数え、たす。(2) の 2024÷27 がそのまま使えるので、(2) が解けたら手を付ける。

  3. 9×□＋3 が 2024 以下になる□を数える。2024÷9＝224 余り8 → □は 0〜224 の 225個。（□＝224 なら A＝2019。□＝225 なら 2028 で2024をこえる。）

    道A の数の形2024以下になる個数
    道1 A→B→G9×□＋3□＝0〜224 → 225個
    道2 A→B→C→G27×△＋18△＝0〜74 → 75個

5 (3) 牛18日のときの放ち方 B・7点｜条件の整理（順番）

👀 まず見るところ

【条件文】部品は「最も少ない日数」＝牛18日・豚20日と、「すべての草を食べ終えると生えてこない」。1日ごとの草の増減（A＝−6、B＝−4、C＝＋1）に直して書く → 途中で草が0にならない順をさがす。

📚 前提知識

  • 1日の草の変化＝生える3kg−食べる量。A（牛と豚）は 3−9＝−6kg、B（牛だけ）は 3−7＝−4kg、C（豚だけ）は 3−2＝＋1kg。C の日だけ草が増える。
  • 毎日1頭以上なので、A・B・C の日数を合わせて22日。牛がいる日は A＋B＝18、豚がいる日は A＋C＝20。

🔍 整理して解く

  1. 日数を決める。A＋B＋C＝22 と A＋B＝18 から C＝4。A＋C＝20 から A＝16。残りの B＝2。つまり A が16日、B が2日、C が4日。
  2. 草の増減を確かめる。16×（−6）＋2×（−4）＋4×（＋1）＝−96−8＋4＝−100。はじめの100kgが、22日目にちょうど0になる。
  3. 順番を考える。A と B を先にすると、100−96−8 で途中で足りなくなる。草が足りなくなると、もう生えてこない。だから、増える C を先に置く。

    C（豚だけ）4日＋1100＋4＝104kg
    A（牛と豚）16日−6104−96＝8kg
    B（牛だけ）2日−48−8＝0kg
  4. 途中で0にならず、22日目にちょうど食べ終わる。答えは1つでよいので、C×4→A×16→B×2。
  5. 落としやすい所: 日数の組（A16・B2・C4）を出して満足しない。「順番」まで聞かれている。
答え：C×4→A×16→B×2
コツ：「食べ終えると生えてこない」は「途中で0にしてはいけない」の合図。減る日と増える日があるなら、増える日を先に置くと安全に進む。

3〜5 まとめ この3問で繰り返し出た入口

  • 規則で増えていく図は「何番目／半径／個数／色／面積」の表に。面積の合計は1回ごとに半分。
