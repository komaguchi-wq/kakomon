1 (5) ずらした正五角形の角EPA A・6点｜角度（正五角形）

👀 まず見るところ

【条件文】部品は「点D、Eがそれぞれ辺QR、QP上」と「正五角形をずらした」。三角形QDEは二等辺だからQはDEのまん中の真上 → 「まっすぐ下にずらした」と図に書く → 四角形ACRPが長方形になる。

📚 前提知識

  • 正五角形の1つの内角は 540÷5＝108度（五角形の内角の和は 180×3＝540度）。
  • 頂角108度の二等辺三角形の底角は (180−108)÷2＝36度。正五角形の中の三角形QRPがこれ。
  • 正五角形では、対角線ACと辺DEは平行。同じように、対角線PRと辺STも平行。

🔍 整理して解く

  1. 図に、長方形ACRP（青の点線）と、Pのまわりの角を書きこむ。
  2. なぜ「まっすぐ下」か。DE は ST と平行だから、RP とも平行。三角形QDEは三角形QRPを小さくした形で、QD＝QE。だから Q は DE のまん中の真上。正五角形ABCDEの B も DE のまん中の真上。B から Q へは、まっすぐ下。
  3. まっすぐ下にずらしたので、AP も CR もたての線。AC と PR は横の線。だから四角形ACRPは長方形で、角APRは90度。
  4. 三角形QRPは QR＝QP の二等辺三角形。角Qは108度 → 角QPR＝(180−108)÷2＝36度。
  5. 点Eは辺QP上にあるので、角EPA は角QPA と同じ。90−36＝54度。
  6. 落としやすい所: 「DEとSTが平行」はずらしただけなら当たり前。効いている条件は「DがQR上、EがQP上」で、これが「まっすぐ下」を決める。
答え：54度

【条件文】部品は「同じ数だけ豆をもらった」と「7粒ずつ…余ることなく」。余らない＝倍数、に直して書く → 11＋□は7の倍数、7＋□は6の倍数、18＋□は5の倍数。候補を5個ずつ書けば共通が見つかるので、手を付ける価値がある。

    (ア) 0,1,1,1,1,2奇奇偶奇偶奇－最後の 2 は F・G とも偶数のはず → F が合わない ×
    (イ) 0,1,2,1,0,2奇奇偶偶奇奇－0 の次に 2 → F が奇数でも偶数でもあることになる ×

    (エ) 2,1,0,1,2,1偶偶奇奇偶偶奇最後まで合う ○
  2. (ア): 0 → A・B は奇。1 → C は偶。1 → D は奇。1 → E は偶。1 → F は奇。ところが最後の 2 は F・G とも偶。F が食いちがう。
  3. (イ): 0 と 2 がとなり合っている。0 は「E・F とも奇」、2 は「F・G とも偶」。F が両方になれないので、ここだけで消せる。
  4. (ウ): 2 → B・C は偶。すると左の 1 から A は奇。あとは 奇・偶・奇・奇 と続き、最後の 0 も F・G とも奇で合う。
  5. (エ): 2 → A・B は偶。1 → C は奇。0 → D も奇。1 → E は偶。2 → F も偶。1 → G は奇。合う。
  6. たしかめ: (ウ)は 1,2,2,1,2,1,1、(エ)は 2,2,1,1,2,2,1 に操作をすると、ちょうどその列になる。
答え：(ウ)・(エ)
コツ：「ありえるもの」を選ぶ問題は、1つ実際に作れた選択肢が○、作る途中で食いちがった選択肢が×。0 と 2 がとなり合う列は、間の数が奇数でも偶数でもあることになるので、すぐ消せる。

4 (3) 0,1,2 が50個の列に操作25回 C・6点｜周期

👀 まず見るところ

本番では後回し。【条件文】部品は「0，1，2，0，1，2，……の順に50個」と「操作を25回」。左はしの9個くらいで5回目まで書く（直して書く）→ 2回目と5回目が同じ並びになり、あとは3回ごとのくり返し。

📚 前提知識

  • 操作は「偶数か奇数か」だけで決まる。0 と 2 はどちらも偶数なので、元の列は 偶・奇・偶 のくり返しと同じ。列の個数は1回ごとに1個へる。50個から25回で 50－25＝25個。

🔍 整理して解く

  1. 左はしから5回目まで書く。右はしは「50個目は 1」なので、右はしも別に書くと安心。
    回左から（3個ずつ区切る）同じ並び
    元0 1 2 ｜ 0 1 2 ｜ 0 1 2 …
    ①1 1 2 ｜ 1 1 2 ｜ 1 1 2 …
    ②0 1 1 ｜ 0 1 1 ｜ 0 1 1 …★
    ③1 0 1 ｜ 1 0 1 ｜ 1 0 1 …
    ④1 1 0 ｜ 1 1 0 ｜ 1 1 0 …
    ⑤0 1 1 ｜ 0 1 1 ｜ 0 1 1 …★ ②と同じ
  2. ②と⑤が同じ。だから ②③④ の3つが、このあともくり返す。①の次から3回ずつ区切ると、24回分で8かたまり。25回目はかたまりの最後＝④と同じ「1 1 0」のくり返し。
  3. 25回目の列は 50－25＝25個。25÷3＝8 あまり1。「1 1 0」が8回と、最後に 1 が1個。
  4. 和は (1＋1＋0)×8＋1＝17。
答え：17
コツ：操作をくり返す問題は、5回くらい書いて「前と同じ並び」をさがす。同じ並びが出た回から周期が始まる（①は周期に入らない）。

5 (1) 図2に正三角形を1つかき足して展開図にする B・10点｜展開図の作図

👀 まず見るところ

【条件文】部品は「正三角形を1つかき足して」と「コンパスと定規」。図2の面の数を書く（正方形5・正三角形3）→ 足りない正三角形1枚がつけられる辺を数える。作図は通り数のあと。

📚 前提知識

  • 正三角形の作図: 辺の両はしに針を置き、辺の長さを半径にして円の一部をかく。交わった点と両はしを結ぶ。
  • 展開図では、立体の同じ頂点が何か所かに分かれて出てくる。頂点に名前をつけて移すと、どの面が足りないかが分かる。

🔍 整理して解く

  1. 図2の面を数える。正方形5枚、正三角形3枚。正三角形が1枚足りない。
  2. 立体のてっぺんを a、上の正方形の4つの角を b・c・d・e と名前をつける。4枚の正三角形は abc・acd・ade・abe。
  3. 図2に名前を移す。ある正三角形は abc・acd・ade の3枚 → 足りないのは abe。
  4. 三角形 abe をつけられる辺は、辺 ab・辺 ae・辺 be の3か所（下の図の赤い辺）。だから 3通り。
  5. 作図（辺 ab にかき足す例）: a と b に針を置き、辺の長さの円をかく。交点が e。a と e、b と e を結ぶ。線は消さない。
答え：3通り／図…（例）解説の図②を参照のこと。（作図の例は上の図の青い三角形。赤い辺3か所のどこにかき足しても正解）
コツ：「展開図を完成させる」は、面の数を数えて足りない面を決め、その面が立体で接している辺に置く。重なる所にはつけられない。

5 (2) 五角形ABCDEは正三角形何個＋正方形何個 B・6点｜等積移動

👀 まず見るところ

【条件文】部品は「正三角形 ア 個」「正方形 イ 個」。五角形を図1になぞり、左の辺 AC が通る正方形の角に丸 → 三角形 ABC と右半分に分けて、面の何個分かを数える。角 BAC が 60° と気づけば取れる。

📚 前提知識

  • 点 A のまわりの角は 正方形2つ（90°×2）＋正三角形2つ（60°×2）＝300°。残りは 360－300＝60°。
  • 底辺と高さが同じ三角形は、形がちがっても面積が同じ。正方形を対角線で切ると、正方形の半分。

🔍 整理して解く

  1. 角 BAC＝360－(90×2＋60×2)＝60°。AB は1辺の長さなので、B と AC 上の最初の角を結ぶと正三角形（下の図の黄）。
  2. 残りの2つ（緑）は、底辺が1辺で高さが黄と同じ。だから三角形 ABC＝正三角形3個分。
  3. 右半分: A と、左の辺の最初の角と、E を結んだ三角形は正方形の半分（黄）。E と D を結ぶ線は正方形の右の辺より内側を通るので、斜線の三角形は五角形の外。
  4. 斜線の三角形は 底辺が黄の2倍（辺2つ分）、高さが半分（辺の半分）。面積は黄と同じ。黄を斜線の所へ移す。
  5. 移したあとの右半分は 正方形2個＋いちばん下の正三角形1個。左の3個と合わせて 正三角形4個＋正方形2個。
答え：ア 4　イ 2

5 (3) 点Pが辺XYを動くときの切断面 C・6点｜切断面の変化

👀 まず見るところ

本番では後回し。【条件文】部品は「辺QRの真ん中の点と辺RSの真ん中の点」と「辺XYを通って」。3点を組み立てた図に置く → 切り口の角の数＝切った面の数。頂点を通る瞬間だけ角がへる。

📚 前提知識

  • 切り口の角の数は、切った面の数と同じ。切り口が頂点を通ると、そこに集まる面を「角1つ」で通るので角がへる。

🔍 整理して解く

  1. 図3を組み立てる。底が QRST の立方体、上に四角すい。上の正方形の角は図のように U・V・W・X。XY はてっぺん Y から出る辺。QR の真ん中を M、RS の真ん中を N とする。
  2. P＝X のとき: 底・前・右・後ろ・左の5面を切る。切り口は五角形（図①）。P が X をはなれると、上の三角形2枚（右と後ろ）も切る。5＋2＝7 で七角形（図②）。
  3. P が進んで、切り口が上の正方形の角 U と W をちょうど通るとき、右と後ろの面は角だけで通る。五角形（図③）。その先は再び七角形。P がてっぺん Y に着くと、前と左の三角形を Y で通り、五角形（図④）。
答え：五→七→五→七→五
コツ：動く点の切断は、スタート・頂点を通る瞬間・ゴールの3つだけ先に調べる。その間は角が2つ増えた形になる。

4〜5 まとめ この回で繰り返し出た入口

  • 操作の問題は、数そのものでなく「偶数か奇数か」「前と同じ並びか」に直して書く。
  • 展開図の問題は、面の数を数えて立体の形を先に決め、頂点に名前をつけて移す。
  • 面積は、角度60°と「底辺×高さが同じ三角形」で正三角形・正方形の何個分かに直す。
