1 (1) 68×(2 1/4−1.5)＋17×98 A・6点｜計算のくふう

👀 まず見るところ

【条件文】部品は「68×」と「17×98」。68は17×4 → 前半を「17×□」の形に直して書く。すると 17×(□＋98) にまとめられて、かけ算が1回ですむ。

📚 前提知識

  • A×B＋A×C＝A×(B＋C)。たとえば 17×3＋17×98 は、17×(3＋98)＝17×101。
  • 2 1/4＝9/4、1.5＝6/4。ひくと 3/4。

🔍 整理して解く

  1. かっこの中を先に出す。2 1/4−1.5＝9/4−6/4＝3/4。
  2. 68×3/4＝51。51は 17×3。ここで前半を 17×3 と書き直す。
  3. 17×3＋17×98＝17×(3＋98)＝17×101＝1717。
  4. 落としやすい所は、1.5 を分数に直さずに 2 1/4−1.5 を小数で計算し、0.75×68 を筆算してしまうこと。68×3/4 なら 68÷4×3 で暗算できる。
答え：1717

1 (2) 本Aを持っている生徒の人数 B・6点｜比と整数の条件

👀 まず見るところ

【条件文】部品は「人数の比が1：2」と「8：7」。2種類の比を ①② と ［8］［7］ に分けて線分図に置く → 全体55人＝①＋②−［8］＋［7］。比が2本あって人数が1つしか無い → 「人数は整数」で候補をしぼる型。式が立ったら手を付ける価値がある。

📚 前提知識

  • 全体＝Aを持つ人＋Bを持つ人−両方持つ人＋どちらも持たない人。両方持つ人は A にも B にも数えられているので1回ひく。
  • 比の数は人数だから整数。たとえば ［8］＋［7］＝［15］ が55人をこえることはない → ［1］あたりの人数は 55÷15＝3.6… より小さい。

🔍 整理して解く

  1. 線分図を描く。Aを①、Bを②。重なり（両方）を 8、右はし（どちらも持たない）を 7 と書く。 図：○は1：2の比、四角［ ］は8：7の比。単位がちがうので別の記号で書く。
  2. 式を整理する。①＋②−［8］＋［7］＝③−［1］。これが55人。だから ③＝55＋［1］。
  3. ［1］あたりが何人か、候補をしぼる。［8］＋［7］＝［15］ は55人以下。55÷15＝3.6… だから、［1］は 1・2・3 のどれか。
  4. ③＝55＋［1］ は3でわり切れる数。55＋1＝56、55＋2＝57、55＋3＝58。3の倍数は57だけ。だから ［1］＝2人。
  5. ①＝57÷3＝19人。
  6. たしかめ。A 19人、B 38人、両方 16人、どちらも持たない 14人。19＋38−16＋14＝55。合っている。
答え：19人
コツ：比が2種類あって、人数が1つしか書いていない → 「人数は整数」「全体をこえない」の2つで候補を書き出す。式を立てたあとに手が止まったら、この2つを思い出す。

1 (3) 自転車のBさんがAさんを追い抜く時刻 A・6点｜旅人算（到着からもどす）

👀 まず見るところ

【条件文】部品は「修理に10分間」と「Aさんより3分早く学校に到着」。Aの到着40分から「Bの到着＝37分」に直して書く → 走った時間は 37−12−10＝15分 と決まる。追い抜いた時刻は、到着の瞬間からもどす。

📚 前提知識

  • 止まっていた時間は走った時間に入れない。出発から到着までの時間から、止まった10分をひく。
  • 追いこしのあと、2人の差は1分に（速さの差）ずつ開く。分速200と75なら、1分で125mずつ。

🔍 整理して解く

  1. Aの到着は 3000÷75＝40分後。Bの到着は3分早いので 37分後。グラフに2人を描く。 図：横が時間、たてが駅からの道のり。Bの横ばいが修理の10分。
  2. Bが走った時間は、(37−12)−10＝15分。3000mを15分で走ったので、分速は 3000÷15＝200m。
  3. Bが着いた37分のとき、Aは学校まであと 75×3＝225m。この225mは、追い抜いたあとに開いた差。
  4. 差は1分に 200−75＝125m ずつ開く。だから追い抜きは 225÷125＝1.8分 前。37−1.8＝35.2分。
  5. 0.2分＝60×0.2＝12秒。追い抜いたのは 7時35分12秒。
  6. 落としやすい所は、0.2分をそのまま「20秒」と書くこと。1分は60秒なので 0.2分＝12秒。
答え：分速200m／7時35分12秒
コツ：故障した場所が分からなくても、走った時間の合計は出る。「追い抜いたのはいつか」は、スタートから追うより、到着の瞬間の差からもどすほうが早い。

1 (4) 15の倍数を入れ替えると6の倍数 A・6点｜倍数の見分け方・場合の数

👀 まず見るところ

【条件文】部品は「一の位の数と百の位の数を入れ替えて」と「三桁の6の倍数」。もとの数 AB5・入れ替えた数 5BA と2行に並べて置く → 一の位は5に決まり、Aは0以外の偶数、各位の和は3の倍数、と条件が3つそろう。

📚 前提知識

  • 15の倍数＝3の倍数かつ5の倍数。一の位は0か5。各位の和が3の倍数。
  • 6の倍数＝2の倍数かつ3の倍数。一の位が偶数。各位の和が3の倍数。たとえば 528 は 5＋2＋8＝15 で偶数だから6の倍数。
  • 入れ替えても数字は同じ3つ。だから各位の和は変わらない。3の倍数の条件は一度調べれば両方にきく。

🔍 整理して解く

  1. 一の位を決める。15の倍数の一の位は0か5。0だと入れ替えた数が 0BA で三桁にならない。だから一の位は5。もとの数は AB5、入れ替えた数は 5BA。
  2. Aを決める。5BA は6の倍数だから偶数。Aは 2・4・6・8（0は三桁にならない）。
  3. 和の条件。A＋B＋5 が3の倍数。つまり A＋B は 1・4・7・10・13・16 のどれか。Aごとに当てはまるBを書き出す。
    A（百の位）当てはまるB（A＋Bが 1,4,7,10,13,16）個数
    22, 5, 83
    40, 3, 6, 94
    61, 4, 73
    82, 5, 83
    Bは0から9まで。A＋Bは大きくても 8＋9＝17 だから、次の19は出てこない。
  4. 合計 3＋4＋3＋3＝13通り。
  5. たしかめ。たとえば 435 → 534。435＝15×29、534＝6×89。合っている。
  6. 落としやすい所は、A＝4 のときの B＝0（405 → 504）を数えもらすこと。Bは0でもよい。
答え：13通り
コツ：「入れ替える」問題は、もとの数と入れ替えた数を □ の形で2行に並べて書く。一の位・偶数・各位の和、の順に条件をつぶすと数えもれが出にくい。

1 (5) 正方形・正三角形・直角二等辺三角形と角EAF A・6点｜角度（二等辺三角形さがし）

👀 まず見るところ

【条件文】部品は「正三角形」と「角FECが90度の直角二等辺三角形」。正方形の1辺＝正三角形の辺＝EF、と同じ長さに印を付けて図に置く → DA＝DE で三角形DAE は二等辺三角形。角EAFは、角DAC（45度）から両わきの角をひいて出す。

📚 前提知識

  • 二等辺三角形の底角は等しい。頂点の角が150度なら、底角は (180−150)÷2＝15度。
  • 直角二等辺三角形の2つの角は45度。正方形の対角線は角を45度ずつに分ける。
  • 2辺とその間の角が等しい三角形は合同。合同なら残りの辺も等しい。

🔍 整理して解く

  1. 同じ長さの辺に印を付ける。DA＝DC＝DE＝EC＝EF。ACを結んで（CFは三角形ECFの辺としてもう引いてある）、分かる角を書きこむ。 図：青の破線が引き足したAC。Aのまわりに 15°・？・15° が並び、合わせて角DAC＝45°。
  2. 三角形DAE。DA＝DE で二等辺。角EDA＝90＋60＝150度。だから角DAE＝(180−150)÷2＝15度。
  3. 三角形DAC と三角形ECF。DA＝EC、DC＝EF、間の角はどちらも90度。合同なので AC＝CF。
  4. 三角形CFA。CA＝CF で二等辺。角ACF＝45＋60＋45＝150度。だから角CAF＝15度。
  5. 角EAF＝角DAC−角DAE−角CAF＝45−15−15＝15度。
  6. 落としやすい所は、Fの位置を見て「角EAFは角DAEより大きい」と思いこむこと。図は正確でないことがあるので、計算で決める。
答え：15度
コツ：正方形と正三角形がくっついていたら、「同じ長さの辺」に全部印を付ける。頂点の角が 90＋60＝150度 の二等辺三角形が出てきたら、底角15度が合図。

2 (1) 回した後の対角線BDの作図 B・7点｜作図（コンパスと定規）

👀 まず見るところ

【条件文】部品は「Bを中心にCが円周とぶつかるまで時計回りに回す」と「作図に用いた線は消さずに残し」。回したCは「Bから6cm」かつ「円周上」＝弧と円周の交点、と直して置く。Dの行き先も2つの長さの交点で決まる。手順が言えるなら手を付ける。

📚 前提知識

  • 回転しても、Bからの長さは変わらない。BC＝6cm、BD＝対角線の長さのまま。
  • 作図で点を決めるときは、「2つの長さの交点」にする。コンパスで長さを写して弧を2本かくと、交わった所が求める点。
  • 回しても正方形の辺の長さは変わらない。C′D′＝CD＝6cm。

🔍 整理して解く

  1. Bを中心に半径BC（6cm）の弧をかく。円周と交わった点が C′（回したあとのC）。
  2. C′を中心に半径6cm（C′D′＝CD）の弧をかく。さらにBを中心に半径BD（対角線をコンパスで写す）の弧をかく。2本の交点が D′。
  3. BとD′を定規で結ぶ。これが回したあとの対角線。D′の位置に D と書く。 図：①が C′、②と③の交点が D′。赤い線 BD′ が答え。弧は消さずに残す。
  4. たしかめ。D′は円の内側にある。BD′ の長さはもとの BD と同じ。向きは時計回りに少し回っている。
答え：解説の図2を参照のこと。（Bを中心に半径BCの弧をかいて円周との交点をC′とし、C′から半径6cmの弧とBから半径BDの弧の交点をD′とする。BとD′を結んだ線が回した後の対角線。D′の位置に D と書く）
コツ：「回したあとの点」の作図は、回転の中心からの長さ＋もう1つの長さ、の2本の弧で決める。弧はうすくてよいが、消さない。

2 (2) 対角線BDが通過した部分の面積 B・7点｜おうぎ形の面積（正六角形）

👀 まず見るところ

【条件文】部品は「半径6cmの円」と「1辺の長さが6cm」。通過した部分はBを中心にBDを半径とするおうぎ形、と直して置く。半径と辺が同じ6cm → A・B・C′は正六角形の角 → 角ABC′＝120度と決まる。おうぎ形の形が見えたら手を付ける価値がある。

📚 前提知識

  • 円の半径と同じ長さの辺で円の中を区切ると、正六角形になる。正六角形の1つの角は120度。
  • 対角線BDの長さは出せなくても、BD×BD は出せる。正方形の面積＝対角線×対角線÷2 だから、BD×BD＝36×2＝72。
  • おうぎ形の面積＝半径×半径×3.14×（中心角÷360）。

🔍 整理して解く

  1. 対角線BDが通った所をかげにする。Bを中心に、BDからBD′まで回ったおうぎ形。 図：青の破線が正六角形。かげがBDの通った所（中心角30°のおうぎ形）。
  2. 中心角を出す。AB＝BC′＝6cm＝円の半径なので、A・B・C′は正六角形の角。角ABC′＝60×2＝120度。
  3. 角ABD＝45度、角D′BC′＝45度（どちらも正方形の対角線）。角DBD′＝120−45×2＝30度。
  4. 半径BDは、BD×BD で使う。正方形の面積 6×6＝36＝BD×BD÷2 だから、BD×BD＝72。
  5. 面積＝72×3.14×30/360＝72×3.14×1/12＝6×3.14＝18.84cm²。
答え：18.84cm²
コツ：半径が出せない正方形の対角線は「対角線×対角線＝面積×2」で使う。円の中に半径と同じ長さの辺があったら、正六角形（60度・120度）がかくれている。

👀 まず見るところ

【条件文】部品は「毎朝決まった量の仕事が追加される」と「ちょうど23日間」。Aの 5×23＝115 からもとの60をひいた55が追加分。初日を除く22回で1日2.5、と直して書く → Bは「1日に 6−2.5 ずつ減る」で解ける。Aの式が立てば手を付ける。

📚 前提知識

  • 仕事が増えていくときは、「やった量＝はじめの量＋増えた量」。Aが23日でやった 115 のうち、もとの60をひいた55が増えた分。
  • 追加は「始めた日の翌日以降」の毎朝。23日間なら、追加は 23−1＝22回。
  • 2日目からは、朝に2.5増えて、Bが6やる。1日で 6−2.5＝3.5 ずつ減る。

🔍 整理して解く

  1. 1日に追加される量を出す。Aは 5×23＝115。増えた分は 115−60＝55。追加は22回だから、55÷22＝2.5。
  2. Bの1日目。朝の追加は無い。60−6＝54 残る。
  3. 2日目からは、1日に 6−2.5＝3.5 ずつ減る。表で見る。
    日朝の追加Bが終えた後の残り
    1日目なし60−6＝54
    2日目＋2.554−3.5＝50.5
    3日目＋2.550.5−3.5＝47
    ……1日に3.5ずつ減る
    16日目＋2.554−3.5×15＝1.5（まだ残る）
    17日目＋2.51.5＋2.5＝4 → 6やって終わり
  4. 54÷3.5＝15 3/7。2日目から数えて16日目に終わる。始めた日から数えると 1＋16＝17日目。
