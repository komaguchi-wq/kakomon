2 (1) 油の密度を正確に求める操作（すべて選ぶ） B・3点｜実験操作・すべて選ぶ

👀 まず見るところ

【条件文】部品は式「密度＝重さ÷体積」と聞かれ方「正確に」「すべて選びなさい」に丸。「油の重さ」と「油の体積」をそれぞれどの器具で正確にはかるか、に直して考える → 体積はメスシリンダー、と決まれば2つ選べる。

📚 前提知識

  • ビーカーの目盛りは目安で誤差が大きい。体積を正確にはかる器具はメスシリンダー。
  • 液体だけの重さ＝（液体を入れた容器全体の重さ）−（容器だけの重さ）。

🔍 こう読み解く

  1. 体積: ビーカーの目盛りを読むウは「正確」に合わない → ×。メスシリンダーの目盛りを読むエ → ○。

  3. アはビーカーの話。ビーカーを使わないので不要 → ×。よってイとエ。
答え：イ・エ
コツ：「すべて選ぶ」は、エだけで止めない。エの数値から油だけの重さを出すのに何を引くか、まで考える。

2 (6) 透明な氷ができる理由 A・4点｜素材文・正しいもの

👀 まず見るところ

【素材文】設問は「透明度の高い氷ができるのはなぜか」。部品は本文の「気泡などの不純物が氷の中に閉じこめられ」（白くにごる原因）と図2の「外側から少しずつ固める」に丸 → 「少しずつ固まるとき気泡が追い出される」文が正解。

📚 前提知識

  • 水は外側（冷やされる側）からこおる。ゆっくりこおると、とけていた空気などは、まだ水のほうへ追い出される。一気に周りからこおると、中に閉じこめられて白くにごる。

🔍 こう読み解く

  1. 白くにごる原因は「気泡が閉じこめられる」こと。透明にするには、こおるときに気泡を追い出す必要がある → ア。
  2. イ「温度が上昇」→ ふきあげても温度は上がらない、こおる話と逆 → ×。ウ「体積が大きくなる」→ 透明かどうかと関係ない → ×。エ「瞬間的に氷にかわる」→ 一気にこおると気泡を閉じこめる、図2の「少しずつ」と逆 → ×。
  3. オ「ふきあげると気体を放出」→ ふきあげただけで気体が出ていくとは本文にも図2にも書かれていない。透明になるのは「ふきあげながら外側から少しずつ固める」ときに気泡が追い出されるから（声教の説明も「少しずつこおるとき不純物が追い出される」）。固まる過程に触れていないので × と切る。
答え：ア

2 (7) 家庭用の氷と業務用の氷の密度 A・4点｜条件文・正しいもの

4 (1) 電磁石の極と方位磁針 A・9点｜穴うめ・語群から選ぶ

👀 まず見るところ

【まざり型→素材文】部品は「方位磁針AのS極が鉄しんの方へ向きました」と「電流を流す向きだけを変えた」。図1のa側に「N」と書きこむ（図に置く）→ S極が引かれる側はN極、電流が逆なら極も逆、と順に決まる。

  • 異なる極は引き合う。方位磁針のS極が向く側＝N極。
  • 電磁石は、電流の向きを逆にすると N と S が入れかわる。エナメル線を巻く向きを逆にしても入れかわる。両方逆にすると元のまま。

🔍 こう読み解く

  1. 1：方位磁針AのS極がa側を向いた → a側はN極。図1のaに N、bに S と書く。
  2. 2：電流の向きだけ逆 → a側がS極、b側がN極に入れかわる。方位磁針Bはb側（図1の右）にあるので、BのS極はb側のN極に引かれて図1の左側を向く。

  4. 落としやすい所：2 は「図1の」左右で答える。Bの針がコイルの方（左）を向く、と図で確かめる。

4 (4) 電磁石の力をつくり出したもの B・3点｜記述

4 (5) ⑤から⑥のとき A〜Cは何極か B・9点｜資料問題・図3と表3

👀 まず見るところ

【資料問題】部品は資料の正体「表3＝①〜④の間に電磁石A〜Cが何極か」と、図3の「●＝磁石の力が大きいところ」。①→②の表3と図3を見比べる（正体を1行）→「●が通る電磁石＝なし、通ったあと＝同じ極、来る前＝反対の極」の決まりが見える。この決まりが言えたら手を付ける。

📚 前提知識

  • 同じ極は反発、異なる極は引き合う。
  • モーターは「通りすぎた極を後ろから押し、近づく極を前から引く」ように電磁石の極を切りかえ続ける（声教）。

🔍 こう読み解く

  1. ①→②で決まりを確かめる：①の N極（右）は右回りで下がり、右下のBを通る → 表3のBは「なし」。S極（左）は上のAへ近づく → Aは反対の N極。Cは S極が通りすぎた直後 → 同じ S極。表3の1行目「N極・なし・S極」と合う。
  2. ⑤→⑥：⑤で N極は左上、⑥で右上 → 上のAを通る → A＝なし。
  3. S極は⑤で右下（Bを通りすぎた直後）、⑥で左下（Cに近づく）→ Bは通りすぎた S極と同じS極（反発で押す）、Cは近づく S極と反対の N極（引く）。
  4. 落としやすい所：「通る電磁石」はNとSのどちらでも「なし」。残り2つは「通った極と同じ／近づく極と反対」で決める。
答え：電磁石A…なし　電磁石B…S極　電磁石C…N極

  • 表は「2種でちがう行」「1つだけ大きい行」から見る（3(5) 丸まる、4(3) 鉄だけ90°）。表に無い理由の選択肢は先に消す。
  • 方位磁針のS極が向く側＝N極。電流の向き・巻く向きのどちらか1つを逆にすると極が逆、両方なら元のまま（4(1)）。
