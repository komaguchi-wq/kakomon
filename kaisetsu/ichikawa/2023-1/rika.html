1 (4) 仮説のもとになった事実 A・3点｜素材文・選択

👀 まず見るところ

【素材文】設問は仮説の「もととなる事実」。部品は下線部「種子の発芽には光が必要である」に丸。事実＝すでに確かめられていること、仮説＝これから確かめたい推測。選択肢を「確かめ済み」と「まだ推測」に3語で分ければ、事実は1つしか残らない。

📚 前提知識

  • 発芽したあとの植物は、葉で光合成をして養分をつくり成長する。これは学校で確かめ済みの事実。
  • 種子は(1)(3)のとおり、たくわえた養分で芽を出す。発芽の段階で光合成はしていない。

🔍 こう読み解く

  1. イ・ウ・オ・カは「光が必要」「光であたためられる必要」と言っていて、仮説と同じ「まだ確かめていない推測」→ 事実ではない。
  2. アは「種子が光合成で養分をつくる」。種子は養分をたくわえていて、光合成はしない → 事実としてまちがい。
  3. 残ったエ「発芽したあとの植物は光合成をして成長する」が確かめ済みの事実。「あとの植物に光が要る → 発芽にも要るのでは」と考えたのが市川さんの仮説。
  4. 落としやすい所: 「光が必要」と書いてある選択肢に引かれてイやオを選ばない。聞かれているのは仮説でなく、その手前の事実。
答え：エ

1 (5) 実験からわかる結論（20字以内） A・4点｜資料問題・記述

👀 まず見るところ

【資料問題】部品は図2の正体「3種類の種子の発芽率・%・光あり／光なし」を1行と、設問の条件「20字以内」に丸。白い棒と灰色の棒がどの種子でも同じ高さ → 光があってもなくても発芽率は変わらない。知識がなくても決まる。

📚 前提知識（あれば答え合わせに使う）

  • 仮説は「光が必要である」。結果が仮説と合わなければ、結論は仮説を打ち消す形「必要ではない」になる。

✍️ 答案の組み立て

  1. 何について: 「種子の発芽には」（設問の「この実験で使った種子について」を受ける）。
  2. わかったこと: 「光が必要ではない」。光あり・光なしで発芽率がほぼ同じ、が根拠。
  3. 言いすぎに注意: 「光があると発芽しない」「光は発芽をさまたげる」とは図2から言えない（光ありでも発芽している）。「光は関係ない」まではよい。
模範解答：種子の発芽には光が必要ではない。
コツ：結論の文は「仮説の文の語尾を結果に合わせて直す」と字数が収まる。「光が必要である」→「光が必要ではない」。

1 (6) 光発芽種子と暗発芽種子（①②） A・6点｜素材文・空らん

👀 まず見るところ

【素材文】①の手がかりは直前の「発芽したあと、すぐに光合成を行える」、②は「深くなるほど水を含んでいる」。それぞれ1語に丸をして、「だから種子は／だから環境は」とつなげる。レポートは空らんの直前の文が理由になっている。

📚 前提知識

  • 種子にたくわえた養分は、発芽して光合成を始めるまでの食料。すぐ光合成できるなら、たくわえは少なくてすむ＝種子は小さくてよい。
  • 「適応」＝その環境で生きのこりやすい性質が残ること。深い土の中で発芽する性質は、地表が乾燥しやすい所で有利。

🔍 こう読み解く

  1. ①: 光発芽種子は光のある所で発芽する → 発芽後すぐ光合成で養分をつくれる → 種子の中の養分は少なくてよい → 種子は比較的小さい（ア）。
  2. ②: 暗発芽種子は深い土の中で発芽する。深い土は水を多く含む → 地表がかわいていても水を確保できる → 乾燥した環境に適応した性質（イ）。
  3. 落としやすい所: ②で「土は水を含んでいる」の言葉に引かれて「水分の多い」を選ばない。聞かれているのは「種子がどんな環境で生きのこるために身につけた性質か」。
答え：① ア　② イ

2 (2) 軽石の性質 A・4点｜素材文・選択

👀 まず見るところ

【素材文】部品は会話文の「パンの断面のように穴の開いた石」と「海岸に流れ着いた」に丸。穴に空気が入っている石は軽い、海を流れてくるのは浮くから → 水に浮く性質に決まる。

📚 前提知識

  • 軽石は、噴出した溶岩が急に冷えて固まるとき、中のガスがぬけた穴がたくさん残った岩石。穴に空気を含むので水に浮くものが多い。

🔍 こう読み解く

  1. 会話文の「穴の開いた石」「海岸に流れ着いた」の2つから、軽くて浮く石だとわかる。
  2. ア・ウは岩石一般の性質ではなく、イ（水酸化ナトリウム水溶液で気体）はアルミニウムなどの金属の話 → ×。

答え：エ

3 (5) 水にしずめた物体Dにはたらく浮力 A・4点｜条件文・差で考える

4 (2) 気体検知管の使い方で誤っているもの A・4点｜素材文・誤っているもの

👀 まず見るところ

【素材文】設問の「誤っているもの」に丸。部品は選択肢の中の言い切りの言葉、ウの「ただちに目盛りを読む」に丸 → 検知管の薬品が色を変えるには時間がかかるので、すぐ読むのはまちがい。これが答え。

📚 前提知識

  • 気体検知管の手順: 調べたい気体用の検知管を選ぶ → 両端を折る → 採取器にさす → ハンドルを一気に引く → 決められた時間だけ待つ → 色が変わった境目の目盛りを読む。

🔍 こう読み解く

  1. ア（気体の種類で変える）・イ（両端を折ってさす）・エ（ななめなら中間）・オ（酸素用は熱い）は、どれも正しい手順のとおり。
  2. ウだけが手順とちがう。ハンドルを引いたあとは決められた時間待ってから読む。落としやすい所: オを「触らない」が変だと感じて選ぶこと。酸素用が熱くなるのは本当の性質。
答え：ウ
