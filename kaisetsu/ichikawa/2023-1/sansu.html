1 (1) 分数と小数のまざった計算 A・6点｜四則計算

👀 まず見るところ

【条件文】部品は「1.25」と「6 1/2÷2/3」。1.25 は 5/4 に、÷2/3 は ×3/2 に直して書く → 小かっこの中が分数だけになり、計算の順番（小かっこ→中かっこ→22/7 をかける）どおりに進められる。

📚 前提知識

  • 小数は分数に直す。1.25＝1 1/4＝5/4。0.25 が 1/4 と同じだから。
  • 分数のわり算は、わる数をひっくり返してかけ算。6 1/2÷2/3＝13/2×3/2。

1 (2) 3人の年齢（3倍・5倍→2倍になる年） A・6点｜年齢算

👀 まず見るところ

【条件文】部品は「Bさんの年齢がAさんの年齢の2倍になる年」と「Cさんの年齢は48歳」。今年の3人を ①③⑤ で図に置く → 何年たっても年齢の差は変わらないので、差 ② を手がかりに「その年」のAが出る。48歳は今年でなく「その年」のC。

📚 前提知識

  • 年齢の差は何年たっても同じ。たとえば 8歳と24歳の差16は、8年後の16歳と32歳でも16。
  • 「BがAの2倍」の年は、BとAの差がそのままAの年齢と同じ。2倍−1倍＝1倍。

🔍 整理して解く

  1. 今年の年齢を A＝①、B＝③、C＝⑤ と書く。BとAの差は ③−①＝②。
    ABC
    今年①③⑤
    BがAの2倍の年②（差と同じ）④⑤＋①＝⑥＝48歳
  2. その年のAは差と同じ ②。今年の①から①ふえている。だから「その年」は ①年後。
  3. その年のCは ⑤＋①＝⑥。これが48歳だから ①＝48÷6＝8歳。
  4. 今年のBは ③＝8×3＝24歳。
  5. たしかめ。8年後は A16・B32・C48。B は A の2倍で、C は48歳。合っている。
  6. 落としやすい所は、48歳を今年のCと読んで ⑤＝48 としてしまうこと。
答え：24歳

1 (3) 校庭の周りに等間隔で木を植える A・6点｜植木算・最大公約数

👀 まず見るところ

【条件文】部品は「等間隔」「できるだけ少なく」と、角にも木。間かくは 4つの長さの最大公約数に直して書く → 本数は「周りの長さ÷間かく」。周りの長さは、へこんだ2辺を外側へ動かして長方形にすると一気に出る。

📚 前提知識

  • 角に木があり、どの辺も同じ間かくで割り切れるなら、間かくは辺の長さの公約数。いちばん少なくするなら最大公約数。
  • 輪のように一周に植えるとき、本数＝周りの長さ÷間かく。はしが無いので＋1はしない。たとえば周り12m・間かく3mなら4本。
  • L字の周りは、へこみの2辺を外へ動かしても長さが変わらない。

🔍 整理して解く

  1. 4つの長さを連除法にかける。 
     2 ) 104  52  156  182
13 )  52  26   78   91
       4   2    6    7     → 間かく＝2×13＝26m
  2. 周りの長さ。図の ア（たて 156−104＝52m）と イ（横 182−52＝130m）を外側へ動かすと、たて156m・横182mの長方形の周りと同じ。（156＋182）×2＝676m。
  3. 本数は 676÷26＝26本。
  4. たしかめ。6つの辺を26で割ると 7・6・2・2・5・4。合計26で合っている。
  5. 落としやすい所は、図に書いていない 130m と 52m の辺。この2つも26で割り切れるかを見てから答える。

1 (4) AからBに水を移す→容積の比 A・6点｜割合と比

👀 まず見るところ

【条件文】部品は「AからBにいくらか水を移した」。Aから減った水＝Bにふえた水、と直して書く → （Aの容積）×（7/8−19/25）＝（Bの容積）×（9/10−4/5）の形になり、あとは逆比。

📚 前提知識

  • 移した水は同じ1つの量。Aでは「容積の何分のいくつ減ったか」、Bでは「容積の何分のいくつふえたか」で表せる。
  • A×2＝B×3 のとき、A：B＝3：2。かける数が小さいほうが大きい（逆比）。

🔍 整理して解く

  1. Aの減った割合。7/8−19/25＝175/200−152/200＝23/200。
  2. Bのふえた割合。9/10−4/5＝9/10−8/10＝1/10。
  3. A×23/200＝B×1/10。逆比にする。A：B＝1/10：23/200。
  4. 200倍して整数に。A：B＝20：23。
  5. たしかめ。A＝20、B＝23 とすると、移した水は 20×23/200＝2.3、23×1/10＝2.3 で同じ。
  6. 落としやすい所は、23/200：1/10 とそのまま比にしてしまうこと。かける数は逆にする。
答え：20：23

👀 まず見るところ

【条件文】部品は「B君は60分」（下り）と(1)で出した「150分」（上り）。同じ PQ だから、時間の比 60：150＝2：5 を速さの比 5：2 に直して書く → 静水＝（5＋2）÷2、流れ＝（5−2）÷2 が出る。流れは A君にも共通。

    下り上り静水流れ
    A君1078.51.5
    B君523.51.5

2 (3) 流れが1.5倍の日に出会うまでの時間 A・6点｜流水算・出会い

👀 まず見るところ

【条件文】部品は「流れの速さが通常時の1.5倍」と「何分後に出会う」。出会う時間は 道のり÷速さの和、と直して書く → A君は下り（＋流れ）、B君は上り（−流れ）。和をとると流れが消えるので、流れが変わっても答えは変わらない。

📚 前提知識

  • 向かい合って進む2人が出会うまでの時間＝道のり÷（2人の速さの和）。
  • （静水A＋流れ）＋（静水B−流れ）＝静水A＋静水B。流れは足してひくので消える。

🔍 整理して解く

  1. 速さの和＝A君の静水＋B君の静水＝8.5＋3.5＝12。流れの大きさは関係ない。
  2. 道のりは 300。300÷12＝25分後。
  3. たしかめ。流れは 1.5×1.5＝2.25。A君の下り 8.5＋2.25＝10.75、B君の上り 3.5−2.25＝1.25。和は 12 で同じ。
  4. 落としやすい所は、1.5倍につられて速さを全部計算し直すこと。和では流れが消えると気づけば1行で終わる。
答え：25分後
コツ：B君の上りの速さ 1.25 はまだ 0 より大きい。もし流れが静水より速いと上れなくなるので、そこだけ頭の中で確かめる。

【条件文】部品は「辺BCのちょうど真ん中から」「Dから」と、Qは時計まわり・Rは反時計まわり。図に進む向きの矢印と 5cm ごとの●を置く → QとRの間の道のりが●を数えるだけで30cmと出て、あとは出会いの計算。

3 (2) PとRが重なっていた時間 A・6点｜点の移動・最小公倍数

👀 まず見るところ

【条件文】部品は「毎秒1cm」（PもRも同じ速さ）と「重なっていたのは何秒間」。P と R が同じ道を同じ向きに通る部分 F→A→B→C を図に太く書く → 同じ速さだから、F に同時に来れば C まで25秒間ずっと重なる。

📚 前提知識

  • 同じ速さで同じ向きに進む2点は、一度並ぶと離れない。並んでいる時間＝いっしょに通る道の長さ÷速さ。
  • P は1周30cm（30秒）、R は1周40cm（40秒）。30と40の最小公倍数120秒ごとに、2点はまったく同じ動きをくり返す。

🔍 整理して解く

  1. P は三角形を C→A→B の向きに、R は六角形を D→E→F→A→B→C の向きに回る。2点がいっしょに通るのは F→A→B→C の25cm。入口は F、出口は C。
  2. 最初の120秒で、F に来る時刻をならべる。
    F に来る時刻（秒後）
    P（1周30秒）10・40・70・100
    R（1周40秒）10・50・90
    同時に F に来るのは10秒後だけ。
  3. 10秒後に F で合流し、25cm を進んで35秒後に C で別れる。120秒のうち重なるのは 25秒間。
  4. 300秒は 120×2＋60。あまりの60秒（240〜300秒）にも 250〜275秒の重なりが入る。25×3＝75秒間。
  5. 落としやすい所は、あまりの60秒を数え忘れて 25×2＝50 とすること。「あまり」の中に10〜35秒が入るかを見る。
答え：75秒間

3 (3) 5分後に止まったときの角CTP B・6点｜角度（正三角形・二等辺三角形）

👀 まず見るところ

【条件文】部品は「5分後に3つの点が止まった」と「PEとRCの交わる点をT」。300秒後の P と R の場所を先に図に置く → P は BC の真ん中、R は AB の真ん中。この2点が置けたら、あとは角度だけの問題なので手を付ける価値がある。

  4. 三角形PCF。PC＝5cm、CF＝5cm、間の角C＝60度だから正三角形。FP＝FC＝FE＝5cm。
