1 (1) 小数と分数のまじった計算 A・6点｜計算

👀 まず見るところ

【条件文】部品は、かっこの中の「7.5×0.6」と「3.75×0.8」。この2つを先に計算して紙に書く → 4.5−3＝1.5 になる。あとは ×5分の3、÷1.8 を左から順にかけるだけ。

📚 前提知識

  • 小数のかけ算は、整数にしてから位をもどす。7.5×0.6 は 75×6＝450 → 4.5。3.75×0.8 は 375×8＝3000 → 3。
  • ×5分の3 は「×3÷5」。1.5×3÷5＝4.5÷5＝0.9。

🔍 整理して解く

  1. かっこの中を出す。7.5×0.6＝4.5、3.75×0.8＝3。
  2. ひく。4.5−3＝1.5。
  3. 1.5×5分の3＝0.9。
  4. 0.9÷1.8＝0.5（0.9 は 1.8 の半分）。
  5. 落としやすい所は 3.75×0.8。375×8＝3000 なので、ちょうど3になる。小数点の位置を確かめる。
答え：0.5

1 (2) 3・5・7で割った余りから2桁の整数N A・6点｜余りの問題（不足をそろえる）

👀 まず見るところ

【条件文】部品は「3で割ると1余り」「5で割ると3余り」。どちらも「あと2あれば割り切れる」に直して書く → Nは15の倍数より2小さい数と決まる。7の条件は、候補を書き出してから当てはめる。

📚 前提知識

  • 「3で割ると1余る」は、2をたすと3で割り切れる。4→6、7→9。「5で割ると3余る」も、2をたすと5で割り切れる。8→10。
  • 2をたすと3でも5でも割り切れる → 2をたすと15の倍数。つまりNは「15の倍数−2」。

🔍 整理して解く

  1. 2つの条件を「あと2で割り切れる」の形に直して、余白に書く。
  2. 15の倍数より2小さい2桁の数を書き出す。13、28、43、58、73、88 の6個。
  3. それぞれを7で割って、余りが4のものをさがす。
    候補132843587388
    7で割った余り601234
  4. 88 だけが余り4。確かめ: 88÷3＝29余り1、88÷5＝17余り3。
  5. 落としやすい所は、余り（1と3）をそろえようとして止まること。余りがちがうときは、足りない数（不足）をそろえる。
答え：88

1 (3) 2が3つ以上現れる4桁の整数 A・6点｜場合の数（0の置けない場所）

👀 まず見るところ

【条件文】部品は「2が3つ以上」と「4桁の整数」。「2が4つ」と「2が3つ＋ちがう数字1つ」に分けて書く → ちがう数字が 0のときだけ先頭に置けないので、0は別に数える。

📚 前提知識

  • 「3つ以上」は3つの場合と4つの場合の両方。2222 も数に入れる。
  • 4桁の整数は、千の位に0を置けない。0222 は3桁の222になってしまう。

🔍 整理して解く

  1. 2が4つ: 2222 の1個。
  2. 2が3つ＋□（□は2以外）: □の場所は □222、2□22、22□2、222□ の4か所。
  3. □が0のとき、先頭はだめ → 2220、2202、2022 の3個。
  4. □が0と2以外（1、3〜9 の8通り）のとき、4か所どこでもよい → 4×8＝32個。
    □に入る数字置ける場所個数
    2（2222）—1
    0先頭以外の3か所3
    1、3〜9（8通り）4か所32
    合計36
  5. 合わせて 1＋3＋32＝36個。落としやすい所は、0も4か所に置けるとして 4×9＋1＝37 としてしまうこと。
答え：36個

1 (4) 面積の等しい5つの三角形と AD：DE：EC A・6点｜辺の比と面積の比

👀 まず見るところ

【条件文】部品は「5つの三角形の面積がすべて等しく」と求めるもの「AD：DE：EC」。5つの三角形に①と書きこむ（図に置く）→ 同じ頂点から見て高さが同じ三角形は、面積の比がそのまま AC 上の底辺の比になる。

📚 前提知識

  • 高さが同じ2つの三角形は、面積の比と底辺の比が同じ。面積が2と1なら、底辺も2：1。
  • AD、DE、EC を1つの比にするときは、AE＝AD＋DE を通してつなぐ（連比）。

🔍 整理して解く

  1. 5つの三角形に1と書く。辺AB上の下の点をFとする。Fから見ると、三角形AFD（1＋1＝2）と三角形DFE（1）は、底辺がどちらもAC上で高さが同じ → AD：DE＝2：1。
  2. 次にBから見る。三角形ABE（1＋1＋1＋1＝4）と三角形EBC（1）も、底辺がAC上で高さが同じ → AE：EC＝4：1。
  3. AD＝2、DE＝1 とすると、AE＝3。EC は AE の4分の1 → 3×4分の1＝4分の3。
  4. AD：DE：EC＝2：1：4分の3。全部を4倍して 8：4：3。
  5. 落としやすい所は、「AE：EC＝4：1」の1をそのまま EC＝1 と書くこと。AE は3なので、EC は3の4分の1。
答え：8：4：3
コツ：「面積が等しい三角形に分けた」と見たら、まず全部に①を書く。次に「同じ頂点・底辺が同じ直線上」の組をさがす。

1 (5) 正方形6個を直線lの周りに1回転した体積 A・6点｜回転体（折り返して動かす）

👀 まず見るところ

【条件文】部品は「直線lの周りに1回転」と「正方形を6個」。lの右側の正方形を左側に折り返して図に置く → 同じ高さでは、軸から遠いほうだけが残る。折り返すと階段の形になる。

📚 前提知識

  • 回転体は、軸の左右の形を片側に折り返してから回しても同じ立体になる。同じ高さで軸からの距離が同じなら、同じ円を描くから。
  • 軸と平行に（上下に）動かしても、軸からの距離は変わらない。だから体積も変わらない。
  • 円柱の体積＝半径×半径×3.14×高さ。

🔍 整理して解く

  1. 右側の3個を左側に折り返す（図の青）。左の3個と合わせて、6個の階段になる。
  2. 上の3個を、軸と平行に2つ下へ動かす（図の矢印）。横3cm・たて2cmの長方形になる。
  3. 回すと、底面の半径3cm、高さ2cmの円柱。3×3×3.14×2＝18×3.14＝56.52。
  4. 確かめ: 高さ1cmごとに見ると、半径1の円（1）、半径2の円（4）、半径1〜3の輪（9−1＝8）、半径2〜3の輪（9−4＝5）。1＋4＋8＋5＝18。同じ18×3.14。
  5. 落としやすい所は、左右の正方形を別々に回して体積をたすこと。同じ高さで重なる部分を2回数えてしまう。
答え：56.52cm³
コツ：「軸の両側に図形がある回転体」は、まず片側に折り返す。そのあと、軸と平行な向きになら自由に動かしてよい。

2 (1) 20gずつ同時に入れかえたBの濃度 A・6点｜濃度（食塩の重さをたす）

👀 まず見るところ

【条件文】部品は「それぞれ20gずつ取り出して」と「同時に」。同時だから、Bに入るのはもとの7%の20g。Bを「3%が80g＋7%が20g」に直して書く → 食塩の重さをたすだけで出る。

📚 前提知識

  • 食塩の重さ＝食塩水の重さ×濃度。3%の80gなら 80×0.03＝2.4g。
  • 濃度＝食塩の重さ÷食塩水の重さ×100。

🔍 整理して解く

  1. Bに残る3%の食塩水は 100−20＝80g。そこに7%の20gが入る。
  2. 食塩の重さをたす。80×0.03＝2.4g、20×0.07＝1.4g → 2.4＋1.4＝3.8g。
    Bの中身食塩水食塩
    3%（残り）80g2.4g
    7%（Aから）20g1.4g
    合計100g3.8g
  3. 食塩水は 80＋20＝100g。濃度は 3.8÷100×100＝3.8%。
  4. 落としやすい所は「同時に」。Aから来る20gは、まだ何も混ざっていない7%のまま。
答え：3.8%

2 (2) 同じ量ずつ入れかえてBが3.6%になる量 A・6点｜濃度（てんびん図）

👀 まず見るところ

【条件文】部品は「同じ量ずつ」と「3.6%」。取り出す量を□gと書き、Bの中身を「7%の□g＋3%の(100−□)g → 3.6%」に直す → てんびん図で、重さの比が出る。

📚 前提知識

  • てんびん図: 濃度の差（うでの長さ）の比と、混ぜた食塩水の重さの比は逆になる。うでが1：2なら重さは2：1。
  • 2つの重さの和は100gと決まっている。比が出れば、100gを比で分けるだけ。

🔍 整理して解く

  1. てんびん図を書く。左に7%（□g）、右に3%（100−□g）、支点に3.6%。
  2. うでの長さは 7−3.6＝3.4 と 3.6−3＝0.6 → 3.4：0.6＝17：3。
  3. 重さの比は逆で、□：(100−□)＝3：17。
  4. 和が100g → □＝100×20分の3＝15g。
  5. 確かめ: 15×0.07＋85×0.03＝1.05＋2.55＝3.6g。100gで3.6%。合っている。
  6. 落としやすい所は比を逆にすること。支点3.6%は3%のすぐ近くなので、3%のほうがずっと多い。15と85を逆にしたら気づける。
答え：15g

2 (3) ア g を往復させてAが5.4%になる量 B・6点｜濃度（食塩の合計は変わらない＋てんびん図）

👀 まず見るところ

【条件文】部品は「濃度が5.4%」と、2回とも同じ「ア」g。Aは出した分がもどるので「最後も50g」に直して書く → 食塩の合計は変わらないから、Bの最後の濃度が先に決まる。「Aが50gにもどる」が見えたら、手を付ける価値がある。

📚 前提知識

  • 食塩水をやりとりしても、AとBの食塩の合計は変わらない。食塩が増えたり減ったりしないから。
  • 食塩水を取り出しても、残った食塩水の濃度は変わらない。だからBの濃度は、1回目のあとも最後も同じ。
  • 濃度のちがう2つを混ぜるときは、てんびん図（うでの比と重さの比は逆）。

🔍 整理して解く

  1. やりとりを表に書く。Aは アg 出して アg もどるので、最後は50g。
    AB
    はじめ7%・50g3%・100g
    1回目のあと（A→B アg）7%・(50−ア)g？%・(100＋ア)g
    2回目のあと（B→A アg）5.4%・50g？%・100g
  2. 食塩の合計は、はじめの 50×0.07＋100×0.03＝3.5＋3＝6.5g。最後も同じ。
  3. 最後のAの食塩は 50×0.054＝2.7g。だからBの食塩は 6.5−2.7＝3.8g。Bは100gなので、Bの濃度（？%）は 3.8%。
  4. 2回目を てんびん図にする。Aに残った7%の(50−ア)g と、Bから来た3.8%の アg を混ぜて5.4%。
  5. うでの長さは 7−5.4＝1.6 と 5.4−3.8＝1.6 で同じ → 重さも同じ → ア＝50÷2＝25。
  6. 確かめ: 1回目でBは 7%の25g（食塩1.75g）が入って125g・食塩4.75g → 4.75÷125＝0.038 で3.8%。3で出した値と合う。
答え：25
コツ：やりとりの問題は「食塩の合計」と「もとの重さにもどる容器」の2つが合図。最後の状態から逆に、もう一方の濃度を出す。

3 (1) AとCが10秒で出会う A・6点｜向かい合う旅人算（速さの和と比）

👀 まず見るところ

【条件文】部品は「10秒後に、AとCがはじめて重なった」と「2：3：6の速さ」。AはPから反時計まわり、CはQから時計まわり → 向かい合って進む。図のPからQまでの80cmに「AとCで10秒」と書きこむ（図に置く）→ 速さの和が出る。

📚 前提知識

  • 向かい合って進む2点が出会うとき、2点が動いた長さをたすと、はじめの間の長さになる。ここでは 80cm。だから速さの和は 80÷10。

  2. AとCの速さの和は、80÷10＝8（cm／秒）。

  4. 確かめ。10秒で Aは20cm、Cは60cm。たして80cm。合っている。落としやすい所は、比を 2：3：6 のまま使ってAを 8×2/11 としてしまうこと。使うのはAとCの2つだけ。

4 (1) PがBC上に重なるまでの道すじの作図 B・6点｜転がる正三角形（頂点の軌跡）

👀 まず見るところ

【条件文】部品は「すべることなく反時計まわりに」転がす、と「はじめてPがBC上に重なるまで」。回転の中心を順に図に置く（1回目はQ＝A、2回目はB）→ Pの道すじは「中心A・半径3cm」と「中心B・半径1cm」の弧2本。中心が2つ見えたら手を付ける。

📚 前提知識

  • 転がる図形の頂点は、回転の中心を中心とする円の弧を描く。半径は「中心からその頂点までの長さ」。中心が変わるたびに半径も変わる。
  • 1回の回転は、次の辺が台形の辺にぴたりと重なるまで。正三角形の辺PQが辺ABの延長に重なった所で、中心がAからBに移る。

🔍 整理して解く

  1. 1回目の中心はA（＝Q）。Pは半径AP＝3cmの弧を描く。辺QPが直線ABに重なるまで回るから、終わりのPは直線AB上でAから3cmの点F。AB＝2cmだから、FはBの1cm先。
  2. 2回目の中心はB。Pは半径BF＝1cmの弧を描き、BC上の点P′に着く。これで「はじめてPがBC上に重なる」。
  3. 作図の手順。①直線ABをBの先へのばす。②コンパスをAP（3cm）に開き、Aを中心にPからFまで弧をかく。③コンパスをBF（1cm）に開き、Bを中心にFからBC上まで弧をかく。太線2本が答え。
  4. 落としやすい所は、1回目の弧をBの真上あたりで止めること。Fは「Aから3cm」で、Bより先にある。弧は左回り（反時計まわり）にかく。
答え：解説の図1を参照のこと。（中心A・半径AP＝3cmの弧をPからF（直線AB上でBの1cm先）まで、続けて中心B・半径BF＝1cmの弧をFからBC上まで。この2本の弧が道すじ）

4 (2) PがDA上にもどるまでの道すじの長さ B・7点｜転がる正三角形（弧の長さの合計）

👀 まず見るところ

【条件文】部品は「はじめてPがDA上に重なるまで」と台形の「AB＝CD＝2cm」。回転の中心を A→B→P→K→C→D と順に図に置く。Pが中心のときPは動かない → 弧は半径3cmが3本、半径1cmが2本。同じ半径の中心角をたしてから長さを出す。

📚 前提知識

  • 弧の長さ＝半径×2×3.14×中心角/360。同じ半径の弧は、中心角を先にたしてから1回だけ計算する。
  • 台形ABCDは左右が同じ形（AB＝CD）。だから 角A＝角D、角B＝角C。ADとBCが平行だから、角A＋角B＝180°。角の大きさそのものは分からなくてよい。

🔍 整理して解く

  1. Pの道すじを、回転の中心ごとに表にする。辺BC（7cm）の上では、Bの1cm先でPが着地 → 次はPが中心（動かない）→ Rが着地した点K（Bから4cm）が中心 → QがちょうどCに着く。
    回転の中心Pまでの長さ（半径）中心角
    ①A3cm360−60−角A
    ②B1cm180−角B
    P（BC上）0Pは動かない
    ③K（BC上・Bから4cm）3cm180−60＝120
    ④C3cm360−60−角B
    ⑤D1cm180−角A
  2. 半径3cmの中心角をたす。（360−60−角A）＋120＋（360−60−角B）＝720−（角A＋角B）＝720−180＝540°。
  3. 半径1cmの中心角をたす。（180−角B）＋（180−角A）＝360−180＝180°。
  4. 長さを出す。3×2×3.14×540/360＝9×3.14。1×2×3.14×180/360＝1×3.14。合計 （9＋1）×3.14＝31.4（cm）。
  5. 落としやすい所は、Cを中心にする回転で半径を2cmにすること。Cに着いているのはQで、Pは3cmはなれている。半径1cmになるのは、BとDのときだけ。
答え：31.4cm
コツ：角Aと角Bの値を出そうとしない。「和が180°」だけで中心角の合計が決まる。半径ごとに中心角をたしてから3.14をかけると、計算は1回で済む。

5 (1) 6枚のカードを操作して終わりの数を出す A・7点｜決まりどおりにたどる（条件の整理）

👀 まず見るところ

【まざり型→条件文】この小問は決まりどおりに動かす問題。部品は①の「左から見ていき、マークがある隣り合う2枚」と②の3つの決まり（同じ数字＝和／同じマーク＝積／ちがう＝左だけ数字）に丸 → 例の「2261」と同じ形で、1手ごとに1行書く。

📚 前提知識

  • ②の3つの決まり。同じ数字 → たして1枚に。同じマーク → かけて1枚に。どちらもちがう → 左のカードだけ数字にして、右のカードはそのまま残す（枚数は減らない）。
  • 「①に戻る」＝そのたびに、いちばん左から見直す。マークのあるカードが1枚だけになったら、そのカードを数字にして終わり。

🔍 整理して解く

  1. ♠をS、♡をHと書いて、1手ずつ表にする。
    手並び見つけた2枚決まり
    はじめS1 H2 S2 H3 H1 S3S1・H2ちがう → 左のS1を「1」に
    11 H2 S2 H3 H1 S3H2・S2同じ数字 → 2＋2＝4
    21 4 H3 H1 S3H3・H1同じマーク → 3×1＝3
    31 4 3 S3S3だけ1枚 → 「3」にして終了
    終わり1 4 3 3
  2. 左から読んで 1433。
  3. 落としやすい所は、「ちがう」ときに右のカード（H2）まで数字にすること。右は残るから、次の手で S2 とペアになる。
答え：1433

5 (2) 終わりの数 21361 からもとの並びをもどす B・7点｜逆算の場合分け（左から決める）

👀 まず見るところ

【まざり型→条件文】部品は「21361」（5けた＝6枚が5枚に減った）と「一番左のカードは♠」。枚数が減るのは和か積のときだけ → 「6を作った1回のほかは全部『ちがう』」に直して書く。すると 2・1・3・1 はカードの数字そのもの。左から順に決まる。

📚 前提知識

  • 和か積のとき2枚が1枚になる（1枚減る）。「ちがう」ときは枚数が減らず、左のカードの数字がそのまま残る。
  • 「ちがう」と決まった2枚は、マークも数字もちがう。前のカードが分かれば、次のカードのマークが決まる。

🔍 整理して解く

  1. 6枚→5枚だから、和か積は1回だけ。「ちがう」で残った数字は 2・1・3・1。6だけが和か積でできた数。
  2. 左から決める。アは♠で数字2 → S2。イはアと「ちがう」からマークH、数字1 → H1。ウはイと「ちがう」からS、数字3 → S3。
  3. エはウ（S3）と「ちがう」からマークH。H1はもう使った。H3だとウと同じ数字で和になってしまう → H2。
  4. 6は H2 とオで作る。同じ数字の和（2＋2）は、もう1枚の2（S2）をアで使ったのでできない → 同じマークの積 2×3 → オ＝H3。カは残りの S1（1枚だけ残って「1」）。
    アイウエオカ
    S2H1S3H2H3S1
    2132×3＝61
  5. 確かめ。S2 H1 S3 H2 H3 S1 を(1)と同じ手順で動かすと 2 1 3 6 1。合っている。
答え：2番目…H1・5番目…H3
コツ：終わりの数の「けた数」を見て、何回減ったかを先に数える。あとは左端から順に決まる問題なので、Bでも時間をかける価値がある。

5 (3) 8枚で終わりの数が 426122 になる並び方 C・7点｜場合分けの数え上げ

👀 まず見るところ

【まざり型→条件文】本番では後回し。合図は「426122」の6けた → 8枚が減った回数は、「1と2」が別々なら2回、「12」で1枚なら3回。12＝3×4（H3とH4、またはS3とS4）。場合分けが2段になり、時間がかかる。

📚 前提知識

  • 減った回数＝和か積の回数。残りはすべて「ちがう」で、左のカードの数字がそのまま残る。

🔍 整理して解く

  1. 「1」「2」が別々（2回減る）の場合。終わりの「2、2」は、2枚とも2のカードそのものにはできない（同じ数字なら和になる）→ どちらかの2は「1と1」か「1と2」から作る。ところが、2のカード（S2・H2）は2けた目と終わりで使い切り、1のカードも1枚使っている → 作れない。0通り。
  2. 「12」が1枚（3回減る）の場合。6＝2×3、12＝3×4 と決まり、残りの1回の場所で3通りに分ける。そのうち成り立つのは2通り。
    型並び（例）入れかえ
    4・（1＋1）・6・12・2S4 H1 S1 S2 S3 H3 H4 H2S2とS3／H3とH4 → 2×2＝4通り
    4・2・6・12・（1と1）S4 H2 S3 S2 H3 H4 S1 H1H3とH4／S1とH1 → 2×2＝4通り
  3. 合わせて 4＋4＝8通り。
答え：8通り

3〜5 まとめ この回で繰り返し出た入口

  • 動く点の問題は、「重なった時刻」の図を1枚描いてから。向きが変わる点も、速さは変わらない。
  • 転がる図形は、回転の中心と「中心から頂点までの長さ（半径）」を表にする。同じ半径の中心角はたしてから計算。
  • 操作の問題は、終わりの数の「けた数」から減った回数を数え、左端から1枚ずつ決める。
